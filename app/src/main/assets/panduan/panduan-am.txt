እንኳን ወደ Create Aplikasi በ Al Kautsar በደህና መጡ
Create Aplikasi ላፕቶፕ ሳያስፈልግ በቀጥታ በስልክ ላይ የሚሰራ የ Android መተግበሪያ ሰሪ መተግበሪያ ነው። ይህ መተግበሪያ ማንኛውም ሰው የራሱን የ Android መተግበሪያ እንዲፈጥር ያስችለዋል፣ መተግበሪያ መፍጠር ገና እየተማሩ ያሉ ተጠቃሚዎችን እና የስክሪን አንባቢ ተጠቃሚዎችን ጨምሮ። ይህን መተግበሪያ ለመጠቀም የሚያገለግል ሙሉ መመሪያ በዚህ ስለ መሳሪያ ስክሪን ላይ ይገኛል።

ይህ መተግበሪያ ምንድን ነው እና ለማን ነው
Create Aplikasi በስልክ ላይ የሚሰራ የ Android መተግበሪያ ሰሪ መሳሪያ ነው። ይህ መተግበሪያ የራሱን የ Android መተግበሪያ መፍጠር ለሚፈልግ ማንኛውም ሰው የታሰበ ነው፣ ጀማሪዎችን እና የስክሪን አንባቢ ተጠቃሚዎችን ጨምሮ። ይህ መተግበሪያ የኮድ አርታኢ፣ ፕሮጀክቶችን ለመሞከር አሂድ የሚባል ቁልፍ፣ APK ለመፍጠር ገንባ የሚባል ቁልፍ፣ እና APK ን ለመፈረም እና ለመጫን ምናሌዎችን ይሰጣል።

የዚህ መተግበሪያ ዓላማ
ይህ መተግበሪያ ማንኛውም ሰው የራሱን የ Android መተግበሪያ በቀላሉ፣ በቀጥታ ከስልክ እንዲፈጥር ተደርጎ የተሰራ ነው። አዲስ ተጠቃሚዎች እንኳ ወዲያውኑ እንዲሞክሩት በይነገጹ በተቻለ መጠን ቀላል ተደርጓል።

አዲስ ፕሮጀክት እንዴት እንደሚፈጠር፣ ደረጃ በደረጃ
1. በዋናው ምናሌ ውስጥ ፕሮጀክት ፍጠር የሚለውን ይጫኑ።
2. የፕሮጀክቱን አይነት ይምረጡ፦ HTML፣ ድር ጣቢያ፣ Java፣ Kotlin፣ Compose፣ ወይም Python።
3. የመተግበሪያውን ስም ይሙሉ፣ ለምሳሌ፦ Garuda Decode።
4. የጥቅሉን ስም (package name) ይሙሉ፣ ለምሳሌ፦ com.android.garudadecode። የጥቅሉ ስም በትንንሽ ፊደላት መሆን እና ነጥብ ተለይተው ቢያንስ ሁለት ክፍሎች ሊኖሩት ይገባል።
5. የመተግበሪያውን እትም ይሙሉ፣ ለምሳሌ፦ 1.0፣ እና የትም ኮድን በቁጥር መልክ፣ ለምሳሌ፦ 1። ባዶ ከተተወ፣ እትሙ በራስ-ሰር 1.0 እና የትም ኮድ 1 ይሞላል።
6. አስፈላጊ ከሆነ ዝቅተኛ SDK እና ዒላማ SDK ይሙሉ። ባዶ ከተተወ፣ ነባሪ እሴቶች ይጠቀማሉ። ዝቅተኛ SDK የሚደገፍ ዝቅተኛው የ Android እትም ነው፣ ለምሳሌ፦ 21 ማለት Android 5.0 ማለት ነው። ከፍተኛው ዒላማ SDK 36 (Android 16) ነው።
7. የመተግበሪያ ፈቃዶችን ለመምረጥ ፈቃድ ምረጥ የሚለውን ቁልፍ ይጫኑ፣ ለምሳሌ፦ INTERNET። የ INTERNET ፈቃድ አስቀድሞ በነባሪ ተምርጧል። መተግበሪያው በእውነት የሚያስፈልጉትን ፈቃዶች ብቻ ምልክት ያድርጉ።
8. ከፈለጉ፣ የ APK መጠን አነስተኛ እንዲሆን "የተለዩ 64 ቢት እና 32 ቢት አርክቴክቸሮችን ተጠቀም" የሚለውን ምልክት ያድርጉ፣ እና የራስዎን keystore መጠቀም ከፈለጉ "የግል ፊርማ ተጠቀም" የሚለውን ምልክት ያድርጉ።
9. ፕሮጀክት ፍጠር የሚለውን ይጫኑ። አዲሱ ፕሮጀክት በ Download/project አቃፊ ውስጥ ይቀመጣል እና ወዲያውኑ በፕሮጀክቶችን አስተዳድር ውስጥ ይታያል።

የሚገኙ የፕሮጀክት አይነቶች
• HTML፦ ከ index.html፣ style.css እና script.js የሚገኝ እይታ፣ በ WebView በኩል ይሰራል። በቀጥታ በስልክ ላይ ይገነባል።
• ድር ጣቢያ፦ ከ index.html፣ tentang.html፣ kontak.html፣ style.css እና script.js የሚገኝ ምናሌ (መነሻ፣ ስለ፣ እውቂያ) ያለው ድር ጣቢያ፣ በ WebView በኩል ይሰራል። በቀጥታ በስልክ ላይ ይገነባል።
• Java፦ በስልክ ላይ ይገነባል። MainActivity በ app/src/main/java/<የጥቅል-ስም>/MainActivity.java ውስጥ ይገኛል። እይታው ከ app/src/main/res/layout/activity_main.xml፣ ጽሑፉ ከ app/src/main/res/values/strings.xml፣ ገጽታው ከ app/src/main/res/values/styles.xml።
• Kotlin፦ በመተግበሪያው ውስጥ በተካተተው የ Kotlin አጠናቃሪ በመጠቀም በመሣሪያው ላይ (ከመስመር ውጭ) ሊገነባ ይችላል፣ ወይም በ GitHub Actions በኩል። MainActivity በ app/src/main/java/<የጥቅል-ስም>/MainActivity.kt ውስጥ ይገኛል፣ እና የ res ፋይሎች ከ Java ፕሮጀክት ጋር አንድ ናቸው። የመጀመሪያው የ Kotlin ግንባታ በአጠናቃሪው ትልቅ መጠን የተነሳ ቀርፋፋ ነው፣ እና ወደ Kotlin ክላሶች የሚያመለክቱ .java ፋይሎች ገና ሊገነቡ አይችሉም (.java ፋይሎች ከ .kt ፋይሎች በፊት ይጠናቀራሉ)።
• Compose፦ በይነገጹ በ Jetpack Compose (የ XML አቀማመጥ አይደለም) የተፈጠረ ዘመናዊ የ Android መተግበሪያ። MainActivity በ app/src/main/java/<የጥቅል-ስም>/MainActivity.kt ውስጥ ይገኛል። የ Compose ፕሮጀክቶች በ GitHub Actions በኩል (ፕሮጀክት ገንባ ምናሌ፣ ከዚያ በመስመር ላይ ገንባ) ወይም በ Termux ውስጥ በ Gradle ይገነባሉ፣ ምክንያቱም Compose በመሣሪያው ላይ የማይገኙ የ Jetpack Compose ቤተ-መጻሕፍቶችን ይፈልጋል።
• Python፦ የመተግበሪያው አመክንዮ በ Python ቋንቋ (Chaquopy) በ app/src/main/python/main.py ውስጥ ይጻፋል፣ እና በአስተናጋጁ MainActivity.java በ app/src/main/java/<የጥቅል-ስም>/MainActivity.java ይሰራል። የ Python ፕሮጀክቶች በቀጥታ በስልክ ላይ ሊገነቡ ይችላሉ (የ Chaquopy የሩጫ ጊዜ በመተግበሪያው ውስጥ ተካቷል) እንዲሁም በ GitHub Actions በኩል። የ Python ፕሮጀክት ዝቅተኛ SDK 24 (Android 7.0) ነው።

የ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች የፋይል አደረጃጀት
የ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች እንደተለመደው የ Android ፕሮጀክቶች ተደራጅተዋል። በ app አቃፊ ውስጥ src አቃፊ አለ፣ እና በውስጡ main አቃፊ አለ። በ main አቃፊ ውስጥ ከ java አቃፊ ጎን AndroidManifest.xml አለ፣ layout/activity_main.xml እና values/strings.xml እንዲሁም values/styles.xml የያዘ res አቃፊ አለ፣ እና ለ HTML እና ድር ጣቢያ index.html የያዘ assets አቃፊ አለ (ድር ጣቢያ tentang.html እና kontak.html እንዲሁ አሉት)። የ HTML እና ድር ጣቢያ ፕሮጀክቶችም በ app/src/main/java/<የጥቅል-ስም>/MainActivity.java ውስጥ የራሳቸው MainActivity አላቸው፣ ይህም index.html ን በ WebView ውስጥ ይጭናል እና በ AndroidManifest ውስጥ አስጀማሪ ይሆናል። የ Python ፕሮጀክት በ app/src/main/python/main.py ውስጥ የ Python ኮድ እና በ app/src/main/java/<የጥቅል-ስም>/MainActivity.java ውስጥ አስተናጋጅ MainActivity.java አለው። AndroidManifest.xml፣ አቀማመጥ፣ strings እና styles በ አርታኢ ውስጥ ሊከፈቱ እና ሊቀየሩ ይችላሉ፣ ልክ እንደ MainActivity። ማኒፌስታቸው አሁንም ከ app አቃፊ ጎን የሆኑ የቆዩ ፕሮጀክቶች አሁንም ሊገነቡ ይችላሉ፣ ምክንያቱም በሚገነባበት ጊዜ መተግበሪያው በመጀመሪያ በ app/src/main/ ውስጥ AndroidManifest.xml ን ይፈትሻል፣ ከዚያ ከ app አቃፊ ጎን ያለውን፣ እና በመጨረሻ የፕሮጀክት ውሂብ ፋይልን።

የፈቃድ ደንቦች (አስፈላጊ)
ፕሮጀክት ሲፈጠር ምልክት የተደረገባቸው ፈቃዶች እንደ ፕሮጀክቱ አይነት በአንድ ቦታ ብቻ ይመዘገባሉ። ለ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች፣ ምልክት የተደረገባቸው ፈቃዶች የሚመዘገቡት በ app/src/main/ ውስጥ፣ ከ java አቃፊ ጎን፣ በፕሮጀክት አቃፊ ውስጥ ባለው AndroidManifest.xml ውስጥ ብቻ ነው። ለ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች የፕሮጀክት ውሂብ ፋይል የፈቃድ ዝርዝር አልያዘም። Java ን ከመረጡ በኋላ INTERNET እና CAMERA ምልክት ካደረጉ፣ በ AndroidManifest.xml ውስጥ የሚመዘገበው INTERNET እና CAMERA ብቻ ነው፣ ሌሎች ፈቃዶች ሳይጨመሩ። በሚገነባበት ጊዜ፣ መተግበሪያው ፈቃዶቹን ከተመሳሳይ ቦታ ያነባል፦ ለ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች ከ app/src/main/ ውስጥ ካለው AndroidManifest.xml (ካልኖረ፣ ለቆዩ ፕሮጀክቶች ከ app አቃፊ ጎን ካለው AndroidManifest.xml)፣ እና ለቆዩ ፕሮጀክቶች ከፕሮጀክት ውሂብ ፋይል።

አርታኢውን እንዴት እንደሚጠቀሙ
ፕሮጀክቶችን አስተዳድር ይክፈቱ፣ አርታኢውን ለመክፈት የፕሮጀክቱን ስም ይንኩ። በአርታኢው ውስጥ ፋይሎች ሊከፈቱ፣ ኮድ ሊጻፍ፣ እና ለውጦች ሊቀመጡ ይችላሉ። ለ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች፣ ፋይሎች በ app/src/main አቃፊ ውስጥ ተደራጅተዋል። ፕሮጀክት ለማጋራት፣ ZIP ላክ የሚለውን ይጠቀሙ (ከዚህ በታች ያለውን ክፍል ይመልከቱ)።

ፕሮጀክት እንዴት እንደሚሰራ
በአርታኢው ውስጥ ፕሮጀክቱን ለመሞከር አሂድ የሚለውን ይጫኑ። ለ HTML እና ድር ጣቢያ ፕሮጀክቶች፣ የሚሰራው index.html በ WebView በኩል ነው። ስህተት ከተከሰተ፣ የስህተት መልእክቱን ያንብቡ፣ ኮዱን ያርሙ፣ ከዚያ እንደገና ያሂዱ።

APK እንዴት እንደሚገነባ
በአርታኢው ውስጥ ገንባ የሚለውን ይጫኑ። ሁለት የግንባታ መንገዶች አሉ። በመጀመሪያ፣ በመሣሪያው ላይ መገንባት፦ ኢንተርኔት ሳያስፈልግ በቀጥታ በስልክ ላይ መገንባት፣ ለ HTML፣ ድር ጣቢያ፣ Java፣ Kotlin እና Python ፕሮጀክቶች። ሁለተኛ፣ በ GitHub Actions በኩል በመስመር ላይ መገንባት፦ በ GitHub በኩል በኢንተርኔት መገንባት፣ እና ለሁሉም የፕሮጀክት አይነቶች ሊጠቀምበት ይችላል። የ Compose ፕሮጀክቶች ሊገነቡ የሚችሉት በሁለተኛው መንገድ ብቻ ነው (በመስመር ላይ ገንባ) ወይም በ Termux ውስጥ በ Gradle፣ ምክንያቱም Compose በመሣሪያው ላይ የማይገኙ የ Jetpack Compose ቤተ-መጻሕፍቶችን ይፈልጋል። የመጀመሪያው የግንባታ ውጤት ገና አልተፈረመም። ከዚያ በኋላ መተግበሪያው ይፈርመዋል፦ በራስ-ሰር በነባሪ ቁልፍ፣ ወይም ፕሮጀክቱ ሲፈጠር "የግል ፊርማ ተጠቀም" የሚለው ሳጥን ምልክት ከተደረገ በግል ፊርማ።

APK እንዴት እንደሚጫን
APK ዝግጁ ሲሆን፣ ለመጫን ጫን የሚለውን ይጫኑ። በ Android 8 እና ከዚያ በላይ፣ ስልኩ በመጀመሪያ "ከዚህ ምንጭ ፍቀድ" ይጠይቃል፣ ምክንያቱም ይህ መተግበሪያ APK ከ Play Store ውጭ ይጫናል። ያን ፈቃድ አንድ ጊዜ በቅንብሮች ውስጥ ያንቁ፣ ከዚያ ወደ መተግበሪያው ይመለሱ፦ ጫን እንደገና መጫን ሳያስፈልግ መጫኑ በራስ-ሰር ይቀጥላል። የ ጫን ቁልፍ ካልታየ፣ ግንባታው መጠናቀቁን እና APK መፈጠሩን ያረጋግጡ።

መተግበሪያ እንዴት እንደሚፈረም
እያንዳንዱ APK ሊጫን እንዲችል መፈረም አለበት። ሁለት ምርጫዎች አሉ። በመጀመሪያ፣ ነባሪ ቁልፍ፦ መተግበሪያው ምንም ሳያደርጉ በራስ-ሰር ይፈርማል። ሁለተኛ፣ የግል ፊርማ፦ በመጀመሪያ በዋናው ምናሌ ውስጥ ባለው Keystore ፍጠር ምናሌ በኩል keystore ይፍጠሩ፣ የይለፍ ቃሉን በደንብ ያስቀምጡ፣ ከዚያ ፕሮጀክት ሲፈጥሩ "የግል ፊርማ ተጠቀም" የሚለውን ምልክት ያድርጉ። Keystore በ Download/project/signing ውስጥ ይቀመጣል።

ፕሮጀክትን ወደ ZIP መላክ
ፕሮጀክቶችን ለጓደኞች ማጋራት እንዲቻል ZIP ላክ ይሰጣል። እንደሚከተለው ነው፦ በፕሮጀክቶችን አስተዳድር ውስጥ፣ የፕሮጀክቱን ስም ለረጅም ጊዜ ይጫኑ፣ ከዚያ ZIP ላክ የሚለውን ይምረጡ። ውጤቱ በ Download/project/<የፕሮጀክትስም>.zip ውስጥ ይቀመጣል። የ bin አቃፊ አልተካተተም፣ ስለዚህ መጠኑ አነስተኛ ነው፣ ጥቂት አስር KB ብቻ። ያ ZIP ፋይል ለጓደኞች ሊላክ ወይም ወደ GitHub ሊሰቀል ይችላል።

ፈቃድ (የሚከፈልበት እትም)
መተግበሪያ ለመሸጥ፣ ፕሮጀክት ሲፈጥሩ "ፈቃድ አንቃ" የሚለውን ምልክት ያድርጉ፣ ከዚያ የ WhatsApp ቁጥርዎን ይሙሉ። የተገነባው መተግበሪያ ለመጀመሪያ ጊዜ ሲከፈት የፈቃድ ኮድ ይጠይቃል፦ ተጠቃሚው የመሣሪያውን መታወቂያ ያያል፣ ያን መታወቂያ ወደ WhatsAppዎ ለመላክ የመሣሪያ መታወቂያ ላክ የሚለውን ቁልፍ ይጫናል፣ ከዚያ እርስዎ የፈቃድ ኮዱን መልሰው ይልካሉ። የፈቃድ ኮድ ከመሣሪያ መታወቂያ እና ከፕሮጀክት የይለፍ ቃል (በፕሮጀክት ውሂብ ፋይል ውስጥ lisensi_seed) ይሰላል — ያን የይለፍ ቃል በደንብ ያስቀምጡ እና አያጋሩት። ትክክለኛ ኮድ ከገባ በኋላ፣ መተግበሪያው ይከፈታል እና ኮድ እንደገና አይጠይቅም።

ኢንተርኔት ሳይኖር አገልጋይ የሚያስፈልገውን መተግበሪያ ለመሞከር፡ በዋና ምናሌ ላይ የአካባቢ ማይክሮ አገልጋይ የሚለውን ይክፈቱ፣ የመንገድ ፍቺ ይጻፉ (ለምሳሌ GET /halo እና የ JSON መልሱ)፣ ከዚያ አገልጋይ ጀምር የሚለውን ይንኩ። IDE በተመሳሳይ ስልክ ላይ ትንሽ የ HTTP አገልጋይ ያሄዳል (HTTP ብቻ፣ ያለ TLS፣ ለተመሳሳይ የ Wi-Fi ኔትወርክ) እና እያንዳንዱን ጥያቄ እና መልስ በማያ ገጹ ላይ ይመዘግባል። መንገዶች እንደ {nama} ያሉ መለኪያዎችን እና ቀላል የ API ቁልፍ መጠቀም ይችላሉ። ይህ አገልጋይ ለስልክ ላይ ሙከራ ብቻ ነው፤ የተገነባ APK ገና አገልጋይ ሊሆን አይችልም፣ እና ማያ ገጹ ሲዘጋ አገልጋዩ ይቆማል።

የደህንነት ኦዲተር
ፕሮጀክት ከመለቀቁ በፊት በፕሮጀክት ኮድ ውስጥ ያሉ የደህንነት ቀዳዳዎችን ለማረጋገጥ፡ በዋና ምናሌ ላይ የደህንነት ኦዲተር የሚለውን ይክፈቱ፣ ፕሮጀክት ይምረጡ፣ ከዚያ ምርመራ ጀምር የሚለውን ይንኩ። IDE ኮዱን፣ ማኒፌስቱን እና የፕሮጀክቱን ውቅር ይቃኛል እና ግኝቶችን ከከፍተኛው እስከ ዝቅተኛው አደጋ ድረስ ይዘግባል — በኮዱ ውስጥ የተጋለጡ የ API ቁልፎች፣ ያለ ፈቃድ የተጋለጡ አካላት፣ JavaScript ን ከ JavaScript በይነገጽ ጋር የሚያነቃ WebView፣ ደካማ ክሪፕቶ (MD5፣ SHA1፣ DES)፣ ያለ TLS ያሉ http አድራሻዎች እና በቀጥታ በኮዱ ውስጥ የተጻፉ የይለፍ ቃሎች — ከእያንዳንዱ ግኝት ፋይል እና የመስመር ቁጥር ጋር። ደህንነታቸው የተጠበቀ ጥገና ላሏቸው ግኝቶች (ለምሳሌ MD5 ን በ SHA-256 ወይም http ን በ https መተካት) ጥገና ተግብር የሚለውን ይንኩ፤ ለ API ቁልፎች እና የይለፍ ቃሎች፣ IDE የተጠቆመውን ጥገና ብቻ ያሳያል ምክንያቱም ምትክ መወሰን ያለበት ገንቢው ራሱ ነው። ይህ ምርመራ በኮዱ ውስጥ ያሉ የጽሑፍ ንድፎችን ያነባል፣ bytecode አይደለም፣ ስለዚህ አንዳንድ ግኝቶች በእውነቱ ደህንነታቸው የተጠበቀ ሊሆኑ ይችላሉ፣ እና ያለ ንድፍ ያለው ቀዳዳ ምርመራውን ሊያልፍ ይችላል — ከመተግበርዎ በፊት ያረጋግጡ።

የተጠቃሚ በይነገጽ ፈታኝ ሮቦት
መተግበሪያ መልክ በጽሑፍ ሁኔታዎች በራስ-ሰር ለመሞከር፡ በዋና ምናሌ ላይ የተጠቃሚ በይነገጽ ፈታኝ ሮቦት የሚለውን ይክፈቱ፣ ፕሮጀክት ይምረጡ፣ ከዚያ ሁኔታ በራስ-ሰር ፍጠር የሚለውን ይንኩ። IDE የፕሮጀክቱን ማኒፌስት እና አቀማመጦች ያነባል እና የጽሑፍ እርምጃዎችን ያቀፈ ሁኔታ ይጽፋል (አዝራር ይንኩ፣ መስክ ይሙሉ፣ ይጠብቁ፣ ይመለሱ)። የሁኔታውን የአሂድ ምዝገባ ከጊዜ ማህተሞቹ ጋር ለማየት የሙከራ ሩጫ አድርግ የሚለውን ይንኩ። በዚህ ደረጃ፣ ሮቦቱ ማስመሰያ ብቻ ያሄዳል (የሙከራ ሩጫ) — በስልኩ ላይ እውነተኛ የአዝራር መንካት እና እውነተኛ ብልሽቶችን መያዝ ቀጣዩ ደረጃ ነው፣ ስለዚህ እዚህ ያለው የብልሽት ሪፖርት አሁንም የናሙና ቅርጸት ነው።

የኮድ የጊዜ ጉዞ
የ Git ትዕዛዞችን ሳይጽፉ ፕሮጀክትን ወደ ቀደም የኮድ ሁኔታ ለመመለስ፡ በዋና ምናሌ ላይ የኮድ የጊዜ ጉዞ የሚለውን ይክፈቱ፣ ፕሮጀክት ይምረጡ፣ ለጊዜ ነጥቡ መለያ ይሙሉ (ባዶ መተው ይቻላል)፣ ከዚያ የጊዜ ነጥብ መዝግብ የሚለውን ይንኩ። IDE የፕሮጀክቱን የምንጭ ፋይሎች ቅጂ ከ hash እሴቶቻቸው ጋር በፕሮጀክቱ ውስጥ ባለው .riwayat ማህደር ውስጥ ያስቀምጣል። የጊዜ ነጥቦች ዝርዝር ሁሉንም ያሳያል፤ ሁለት ነጥቦችን ይምረጡ ከዚያም የተጨመሩ፣ የተቀየሩ ወይም የተሰረዙ ፋይሎችን እና ተግባሮችን ለማየት አነጻጽር የሚለውን ይንኩ። የድሮ ሁኔታን ለመመለስ መልስ የሚለውን ይንኩ — ከመመለስዎ በፊት፣ IDE ሁልጊዜ መጀመሪያ የአሁኑን ሁኔታ ምትኬ ያደርጋል፣ ስለዚህ ምንም አይጠፋም። ፕሮጀክቱን ወደ አዲስ ማህደር ለመቅዳት እና ዋናውን ፕሮጀክት ሳያደናቅፉ ለውጦችን ለመሞከር የሙከራ ቅጂ ፍጠር የሚለውን ይንኩ። የምንጭ ፋይሎች ብቻ ይመዘገባሉ።

የሞጁል ፋብሪካ
የፕሮጀክት ክፍል ሌላ ፕሮጀክት ሊጠቀምበት እንደ ሞጁል ለመጠቅለል፡ በዋና ምናሌ ላይ የሞጁል ፋብሪካ የሚለውን ይክፈቱ፣ የምንጭ ፕሮጀክት ይምረጡ፣ የሚጠቅለሉትን የማያ፣ የክፍል፣ የሕብረቁምፊ እና የፈቃድ ፋይሎች ምልክት ያድርጉ፣ ከዚያ እንደ ሞጁል ጠቅልል የሚለውን ይንኩ። IDE የ ZIP ማህደር ከ JSON ሜታዳታ ጋር ይጽፋል (የሞጁል ስም፣ ስሪት፣ ጥቅም ላይ የዋሉ ሕብረቁምፊዎች እና ፈቃዶች)። ሞጁል በሌላ ፕሮጀክት ውስጥ ለመጫን፣ የሞጁል ፋብሪካ የሚለውን ይክፈቱ፣ የዒላማ ፕሮጀክት ይምረጡ፣ ከዚያ ሞጁል ጫን የሚለውን ይንኩ እና የሞጁሉን .zip ፋይል ይምረጡ — ውህደቱ ሕብረቁምፊዎችን እና ፈቃዶችን ያክላል ያለውን ኮድ ሳይደራረብ፣ እና ስሙ በዒላማ ፕሮጀክቱ ውስጥ አስቀድሞ ጥቅም ላይ ከዋለ ፋይል አይቀላቅልም። ሞጁል ቤተ-መጽሐፍትንም ሆነ የግንባታ ቅንብሮችን አብሮ አያመጣም።

የኮድ መዋቅር መכתብ
በአርታዒ ውስጥ በድምፅ ኮድ ለመጻፍ፡ ፕሮጀክት በአርታዒ ውስጥ ይክፈቱ፣ ከዚያ የኮድ መዋቅር መכתብ የሚለውን ቁልፍ ይንኩ። ትዕዛዞችን በኢንዶኔዥያኛ ይስጡ፣ ለምሳሌ buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil ወይም buat variabel teks nama sama dengan Budi — IDE ንግግሩን ወደ አገባብ ትክክለኛ የ Java፣ Kotlin፣ Python ወይም Compose ኮድ ብሎክ ይለውጣል እና በጠቋሚው ቦታ ላይ ያስገባዋል፣ ከዚያም አጭር ማጠቃለያ በ Jieshuo በኩል በድምፅ ያነባል። መכתብ የስርዓቱን ውስጠ-ገብ የድምፅ ግቤት አገልግሎት ይጠቀማል፣ ያለ ተጨማሪ የማይክሮፎን ፈቃድ፣ እና ቀድሞ የተመዘገቡ የትዕዛዝ ንድፎችን ብቻ ያውቃል፤ ከእነዚህ ንድፎች ውጪ ያለው ንግግር ወደ ኮድ አይቀየርም። እንደ ቃል የተነገሩ ቁጥሮች (ለምሳሌ 'lima') ገና ወደ አኃዝ አይቀየሩም።

የአካባቢ የትብብር ክፍል (ያለ ኢንተርኔት)
ኢንተርኔት ሳይኖር በአንድ ክፍል ውስጥ አብሮ ለመስራት፡ በዋና ምናሌ ላይ ትብብር የሚለውን ይክፈቱ፣ ከዚያ የአካባቢ የትብብር ክፍል ክፍሉን ይክፈቱ። አንድ ስልክ ክፍለ ጊዜ ይከፍታል (IDE የአካባቢ IP አድራሻ እና 6-አኃዝ PIN ያሳያል)፣ ሌላ ስልክ በዚያ አድራሻ እና PIN ይቀላቀላል። የጽሑፍ ለውጦች እንደ የመስመር ልዩነቶች ይላካሉ፣ የተገነባ APK ወደ ሞካሪው ስልክ ሊዘጋጅ ይችላል፣ እና ከሞካሪው ስልክ የብልሽት ሪፖርቶች ተመልሰው ይቀበላሉ። አንድ ክፍለ ጊዜ ለአንድ ጓደኛ ብቻ ነው፤ ሁለት ሰዎች በትክክል ተመሳሳይ መስመር በተመሳሳይ ጊዜ ከቀየሩ፣ የመጨረሻው ለውጥ ጥቅም ላይ ይውላል። PIN በአካባቢ ኔትወርክ ላይ እንደ ግልጽ ጽሑፍ ይላካል። ይህ ክፍል ገና በእውነተኛ ስልክ ላይ አልተሞከረም።

የ AI ቅንብሮች
መተግበሪያዎችን ለመፍጠር የ AI አቅራቢ እና የ API ቁልፎችን ለማዘጋጀት፡ በዋና ምናሌ ላይ፣ በ ቅንብሮች ቡድን ውስጥ፣ የ AI ቅንብሮች የሚለውን ይንኩ (አገናኝ ቁልፉ አጠገብ)። ከሚገኙት ዝርዝር ውስጥ የሚጠቀሙትን አቅራቢ ይምረጡ፣ እና አንድ ሞዴል ከተሳሳተ IDE በራስ-ሰር ከተመሳሳይ አቅራቢ ቀጣዩን ሞዴል እንዲሞክር አቅራቢ ሲሳሳት ሞዴል ቀይር የሚለውን ምልክት ያድርጉ። የመጠባበቂያ ቁልፎችን ለመጨመር የ API ቁልፎችን አስተዳድር የሚለውን ይንኩ (ስም እና ቁልፍ ይሙሉ ከዚያም አስቀምጥ የሚለውን ይንኩ፤ ቁልፎቹ ተደብቀው ይታያሉ፣ የመጨረሻዎቹ 4 ቁምፊዎች ብቻ ይታያሉ)። ቁልፎቹ በስልኩ ላይ ይቀመጣሉ እና መተግበሪያ ሲፈጠር ከተመረጠው አቅራቢ በስተቀር ሌላ ቦታ በጭራሽ አይላኩም። ማስታወሻ፡ በአሁኑ ጊዜ፣ የአቅራቢ እና የቁልፍ ምርጫ ብቻ ይመዘገባል እና በ AI Pembuat Aplikasi ማያ ላይ ይታያል — መተግበሪያዎችን መፍጠር አሁንም በስልኩ ላይ ያለውን የአካባቢ AI ይጠቀማል (ያለ ኢንተርኔት)፤ የመስመር ላይ አቅራቢዎችን መጠቀም በኋላ ይመጣል።

አገናኝ
APK ለመተንተን እና ከዚያ ለመላክ፡ በዋና ምናሌ ላይ፣ በ ቅንብሮች ቡድን ውስጥ፣ አገናኝ የሚለውን ይንኩ (የ AI ቅንብሮች ቁልፉ አጠገብ)። ከስልኩ APK ፋይል ይምረጡ፣ IDE ይዘቱን ያነባል (የጥቅል ስም፣ ስሪት፣ የእንቅስቃሴዎች ዝርዝር) እና ከዚያ APK ላክ የሚለውን ይንኩ በስርዓት ማጋሪያ ምናሌ በኩል ለመላክ (ለምሳሌ WhatsApp ወይም Drive)።

ቋንቋ እና ድምጽ
የመተግበሪያውን ቋንቋ ለመቀየር፡ ቅንብሮች የሚለውን ይክፈቱ፣ ከዚያ የመተግበሪያ ቋንቋ የሚለውን፣ ከዚያም ቋንቋ ይምረጡ ወይም ስርዓቱን ተከተል የሚለውን ይምረጡ። ዋና ማያ ገጹ እና አብዛኞቹ ማያ ገጾች መተግበሪያውን ሳይዘጉ ወይም እንደገና ሳያስጀምሩ ወዲያውኑ ወደ የተመረጠው ቋንቋ ይቀየራሉ፤ አንዳንድ ማያ ገጾች (ለምሳሌ Terminal፣ ትብብር፣ የ AI ቅንብሮች እና ቁልፎችን አስተዳድር) እንደገና እስኪከፈቱ ድረስ አሁንም የድሮውን ቋንቋ ይጠቀማሉ። ስርዓቱን ተከተል የሚለውን ከመረጡ፣ ቋንቋው የስልኩን የስርዓት ቋንቋ ይከተላል።
