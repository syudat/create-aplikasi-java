እንኳን ወደ Create Aplikasi በ Al Kautsar በደህና መጡ
Create Aplikasi ላፕቶፕ ሳያስፈልግ በቀጥታ በስልክ ላይ የሚሰራ የ Android መተግበሪያ ሰሪ መተግበሪያ ነው። ይህ መተግበሪያ ማንኛውም ሰው የራሱን የ Android መተግበሪያ እንዲፈጥር ያስችለዋል፣ መተግበሪያ መፍጠር ገና እየተማሩ ያሉ ተጠቃሚዎችን እና የስክሪን አንባቢ ተጠቃሚዎችን ጨምሮ። ይህን መተግበሪያ ለመጠቀም የሚያገለግል ሙሉ መመሪያ በዚህ ስለ መሳሪያ ስክሪን ላይ ይገኛል።

ይህ መተግበሪያ ምንድን ነው እና ለማን ነው
Create Aplikasi በስልክ ላይ የሚሰራ የ Android መተግበሪያ ሰሪ መሳሪያ ነው። ይህ መተግበሪያ የራሱን የ Android መተግበሪያ መፍጠር ለሚፈልግ ማንኛውም ሰው የታሰበ ነው፣ ጀማሪዎችን እና የስክሪን አንባቢ ተጠቃሚዎችን ጨምሮ። ይህ መተግበሪያ የኮድ አርታኢ፣ ፕሮጀክቶችን ለመሞከር አሂድ የሚባል ቁልፍ፣ APK ለመፍጠር ገንባ የሚባል ቁልፍ፣ እና APK ን ለመፈረም እና ለመጫን ምናሌዎችን ይሰጣል።

የዚህ መተግበሪያ ዓላማ
ይህ መተግበሪያ ማንኛውም ሰው የራሱን የ Android መተግበሪያ በቀላሉ፣ በቀጥታ ከስልክ እንዲፈጥር ተደርጎ የተሰራ ነው። አዲስ ተጠቃሚዎች እንኳ ወዲያውኑ እንዲሞክሩት በይነገጹ በተቻለ መጠን ቀላል ተደርጓል።

አዲስ ፕሮጀክት እንዴት እንደሚፈጠር፣ ደረጃ በደረጃ
1. በዋናው ምናሌ ውስጥ ፕሮጀክት ፍጠር የሚለውን ይጫኑ።
2. የፕሮጀክቱን አይነት ይምረጡ፦ HTML፣ ድር ጣቢያ፣ Java፣ Kotlin፣ Compose፣ ወይም Python።
3. የመተግበሪያውን ስም ይሙሉ፣ ለምሳሌ፦ Garuda Decode።
4. የጥቅሉን ስም (package name) ይሙሉ፣ ለምሳሌ፦ com.android.garudadecode። የጥቅሉ ስም በትንንሽ ፊደላት መሆን እና ነጥብ ተለይተው ቢያንስ ሁለት ክፍሎች ሊኖሩት ይገባል።
5. የመተግበሪያውን እትም ይሙሉ፣ ለምሳሌ፦ 1.0፣ እና የትም ኮድን በቁጥር መልክ፣ ለምሳሌ፦ 1። ባዶ ከተተወ፣ እትሙ በራስ-ሰር 1.0 እና የትም ኮድ 1 ይሞላል።
6. አስፈላጊ ከሆነ ዝቅተኛ SDK እና ዒላማ SDK ይሙሉ። ባዶ ከተተወ፣ ነባሪ እሴቶች ይጠቀማሉ። ዝቅተኛ SDK የሚደገፍ ዝቅተኛው የ Android እትም ነው፣ ለምሳሌ፦ 21 ማለት Android 5.0 ማለት ነው። ከፍተኛው ዒላማ SDK 36 (Android 16) ነው።
7. የመተግበሪያ ፈቃዶችን ለመምረጥ ፈቃድ ምረጥ የሚለውን ቁልፍ ይጫኑ፣ ለምሳሌ፦ INTERNET። የ INTERNET ፈቃድ አስቀድሞ በነባሪ ተምርጧል። መተግበሪያው በእውነት የሚያስፈልጉትን ፈቃዶች ብቻ ምልክት ያድርጉ።
8. ከፈለጉ፣ የ APK መጠን አነስተኛ እንዲሆን "የተለዩ 64 ቢት እና 32 ቢት አርክቴክቸሮችን ተጠቀም" የሚለውን ምልክት ያድርጉ፣ እና የራስዎን keystore መጠቀም ከፈለጉ "የግል ፊርማ ተጠቀም" የሚለውን ምልክት ያድርጉ።
9. ፕሮጀክት ፍጠር የሚለውን ይጫኑ። አዲሱ ፕሮጀክት በ Download/project አቃፊ ውስጥ ይቀመጣል እና ወዲያውኑ በፕሮጀክቶችን አስተዳድር ውስጥ ይታያል።

የሚገኙ የፕሮጀክት አይነቶች
• HTML፦ ከ index.html፣ style.css እና script.js የሚገኝ እይታ፣ በ WebView በኩል ይሰራል። በቀጥታ በስልክ ላይ ይገነባል።
• ድር ጣቢያ፦ ከ index.html፣ tentang.html፣ kontak.html፣ style.css እና script.js የሚገኝ ምናሌ (መነሻ፣ ስለ፣ እውቂያ) ያለው ድር ጣቢያ፣ በ WebView በኩል ይሰራል። በቀጥታ በስልክ ላይ ይገነባል።
• Java፦ በስልክ ላይ ይገነባል። MainActivity በ app/src/main/java/<የጥቅል-ስም>/MainActivity.java ውስጥ ይገኛል። እይታው ከ app/src/main/res/layout/activity_main.xml፣ ጽሑፉ ከ app/src/main/res/values/strings.xml፣ ገጽታው ከ app/src/main/res/values/styles.xml።
• Kotlin፦ በመተግበሪያው ውስጥ በተካተተው የ Kotlin አጠናቃሪ በመጠቀም በመሣሪያው ላይ (ከመስመር ውጭ) ሊገነባ ይችላል፣ ወይም በ GitHub Actions በኩል። MainActivity በ app/src/main/java/<የጥቅል-ስም>/MainActivity.kt ውስጥ ይገኛል፣ እና የ res ፋይሎች ከ Java ፕሮጀክት ጋር አንድ ናቸው። የመጀመሪያው የ Kotlin ግንባታ በአጠናቃሪው ትልቅ መጠን የተነሳ ቀርፋፋ ነው፣ እና ወደ Kotlin ክላሶች የሚያመለክቱ .java ፋይሎች ገና ሊገነቡ አይችሉም (.java ፋይሎች ከ .kt ፋይሎች በፊት ይጠናቀራሉ)።
• Compose፦ በይነገጹ በ Jetpack Compose (የ XML አቀማመጥ አይደለም) የተፈጠረ ዘመናዊ የ Android መተግበሪያ። MainActivity በ app/src/main/java/<የጥቅል-ስም>/MainActivity.kt ውስጥ ይገኛል። የ Compose ፕሮጀክቶች በ GitHub Actions በኩል (ፕሮጀክት ገንባ ምናሌ፣ ከዚያ በመስመር ላይ ገንባ) ወይም በ Termux ውስጥ በ Gradle ይገነባሉ፣ ምክንያቱም Compose በመሣሪያው ላይ የማይገኙ የ Jetpack Compose ቤተ-መጻሕፍቶችን ይፈልጋል።
• Python፦ የመተግበሪያው አመክንዮ በ Python ቋንቋ (Chaquopy) በ app/src/main/python/main.py ውስጥ ይጻፋል፣ እና በአስተናጋጁ MainActivity.java በ app/src/main/java/<የጥቅል-ስም>/MainActivity.java ይሰራል። የ Python ፕሮጀክቶች በቀጥታ በስልክ ላይ ሊገነቡ ይችላሉ (የ Chaquopy የሩጫ ጊዜ በመተግበሪያው ውስጥ ተካቷል) እንዲሁም በ GitHub Actions በኩል። የ Python ፕሮጀክት ዝቅተኛ SDK 24 (Android 7.0) ነው።

የፕሮጀክት ሥነ-ሕንጻ ቀይር
ያለ አዲስ ፕሮጀክት ሳይፈጥሩ ያለውን የፕሮጀክት ሥነ-ሕንጻ ምርጫዎች ለመቀየር፤ በዋና ምናሌው ውስጥ «የፕሮጀክት ሥነ-ሕንጻ ቀይር» ን ይጫኑ፣ ከዚያም ፕሮጀክቱን ይምረጡ እና «64-ቢት APK ይገንቡ (arm64-v8a)» ወይም «32-ቢት APK ይገንቡ (armeabi-v7a)» የሚለውን የማረጋገጫ ሳጥን ይለውጡ፤ ወይም በ«ፕሮጀክቶችን አስተዳድር» ውስጥ የፕሮጀክቱን ስም ረዘም ላለ ጊዜ ይጫኑ እና ለዚያ ፕሮጀክት በቀጥታ ተመሳሳይ ማያ ገጽ ለመክፈት «ሥነ-ሕንጻ ቀይር» ን ይምረጡ። ሕጉ ይህ ነው፦ ሁለቱም የማረጋገጫ ሳጥኖች ከበሩ፣ ግንባታው ሁለት የተለያዩ APK ፋይሎችን ይፈጥራል፣ አንዱ 64-ቢት እና አንዱ 32-ቢት፤ አንድ የማረጋገጫ ሳጥን ብቻ ከበራ፣ ግንባታው በአንድ ነጠላ ሁለንተናዊ APK ይፈጥራል፣ ይህም በ64-ቢት እና 32-ቢት መሣሪያዎች ላይ መሥራቱን ይቀጥላል። ለአንድ ልዩነት ብቻ የተለየ APK እስካሁን አይደገፍም፣ ምክንያቱም የግንባታ መንገዱ የተከፈለ ወይም ሁለንተናዊ ምርጫን ብቻ ያውቃል፣ ነገር ግን የእያንዳንዱ ልዩነት ምርጫ ማያ ገጹ እንደገና ሲከፈት እንዳይጠፋ በፕሮጀክቱ ውስጥ ተቀምጦ ይቆያል።

የ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች የፋይል አደረጃጀት
የ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች እንደተለመደው የ Android ፕሮጀክቶች ተደራጅተዋል። በ app አቃፊ ውስጥ src አቃፊ አለ፣ እና በውስጡ main አቃፊ አለ። በ main አቃፊ ውስጥ ከ java አቃፊ ጎን AndroidManifest.xml አለ፣ layout/activity_main.xml እና values/strings.xml እንዲሁም values/styles.xml የያዘ res አቃፊ አለ፣ እና ለ HTML እና ድር ጣቢያ index.html የያዘ assets አቃፊ አለ (ድር ጣቢያ tentang.html እና kontak.html እንዲሁ አሉት)። የ HTML እና ድር ጣቢያ ፕሮጀክቶችም በ app/src/main/java/<የጥቅል-ስም>/MainActivity.java ውስጥ የራሳቸው MainActivity አላቸው፣ ይህም index.html ን በ WebView ውስጥ ይጭናል እና በ AndroidManifest ውስጥ አስጀማሪ ይሆናል። የ Python ፕሮጀክት በ app/src/main/python/main.py ውስጥ የ Python ኮድ እና በ app/src/main/java/<የጥቅል-ስም>/MainActivity.java ውስጥ አስተናጋጅ MainActivity.java አለው። AndroidManifest.xml፣ አቀማመጥ፣ strings እና styles በ አርታኢ ውስጥ ሊከፈቱ እና ሊቀየሩ ይችላሉ፣ ልክ እንደ MainActivity። ማኒፌስታቸው አሁንም ከ app አቃፊ ጎን የሆኑ የቆዩ ፕሮጀክቶች አሁንም ሊገነቡ ይችላሉ፣ ምክንያቱም በሚገነባበት ጊዜ መተግበሪያው በመጀመሪያ በ app/src/main/ ውስጥ AndroidManifest.xml ን ይፈትሻል፣ ከዚያ ከ app አቃፊ ጎን ያለውን፣ እና በመጨረሻ የፕሮጀክት ውሂብ ፋይልን።

የፈቃድ ደንቦች (አስፈላጊ)
ፕሮጀክት ሲፈጠር ምልክት የተደረገባቸው ፈቃዶች እንደ ፕሮጀክቱ አይነት በአንድ ቦታ ብቻ ይመዘገባሉ። ለ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች፣ ምልክት የተደረገባቸው ፈቃዶች የሚመዘገቡት በ app/src/main/ ውስጥ፣ ከ java አቃፊ ጎን፣ በፕሮጀክት አቃፊ ውስጥ ባለው AndroidManifest.xml ውስጥ ብቻ ነው። ለ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች የፕሮጀክት ውሂብ ፋይል የፈቃድ ዝርዝር አልያዘም። Java ን ከመረጡ በኋላ INTERNET እና CAMERA ምልክት ካደረጉ፣ በ AndroidManifest.xml ውስጥ የሚመዘገበው INTERNET እና CAMERA ብቻ ነው፣ ሌሎች ፈቃዶች ሳይጨመሩ። በሚገነባበት ጊዜ፣ መተግበሪያው ፈቃዶቹን ከተመሳሳይ ቦታ ያነባል፦ ለ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች ከ app/src/main/ ውስጥ ካለው AndroidManifest.xml (ካልኖረ፣ ለቆዩ ፕሮጀክቶች ከ app አቃፊ ጎን ካለው AndroidManifest.xml)፣ እና ለቆዩ ፕሮጀክቶች ከፕሮጀክት ውሂብ ፋይል።

አርታኢውን እንዴት እንደሚጠቀሙ
ፕሮጀክቶችን አስተዳድር ይክፈቱ፣ አርታኢውን ለመክፈት የፕሮጀክቱን ስም ይንኩ። በአርታኢው ውስጥ ፋይሎች ሊከፈቱ፣ ኮድ ሊጻፍ፣ እና ለውጦች ሊቀመጡ ይችላሉ። ለ Java፣ HTML፣ ድር ጣቢያ፣ Kotlin፣ Compose እና Python ፕሮጀክቶች፣ ፋይሎች በ app/src/main አቃፊ ውስጥ ተደራጅተዋል። ፕሮጀክት ለማጋራት፣ ZIP ላክ የሚለውን ይጠቀሙ (ከዚህ በታች ያለውን ክፍል ይመልከቱ)።

ፕሮጀክት እንዴት እንደሚሰራ
በአርታኢው ውስጥ ፕሮጀክቱን ለመሞከር አሂድ የሚለውን ይጫኑ። ለ HTML እና ድር ጣቢያ ፕሮጀክቶች፣ የሚሰራው index.html በ WebView በኩል ነው። ስህተት ከተከሰተ፣ የስህተት መልእክቱን ያንብቡ፣ ኮዱን ያርሙ፣ ከዚያ እንደገና ያሂዱ።

APK እንዴት እንደሚገነባ
በአርታኢው ውስጥ ገንባ የሚለውን ይጫኑ። ሁለት የግንባታ መንገዶች አሉ። በመጀመሪያ፣ በመሣሪያው ላይ መገንባት፦ ኢንተርኔት ሳያስፈልግ በቀጥታ በስልክ ላይ መገንባት፣ ለ HTML፣ ድር ጣቢያ፣ Java፣ Kotlin እና Python ፕሮጀክቶች። ሁለተኛ፣ በ GitHub Actions በኩል በመስመር ላይ መገንባት፦ በ GitHub በኩል በኢንተርኔት መገንባት፣ እና ለሁሉም የፕሮጀክት አይነቶች ሊጠቀምበት ይችላል። የ Compose ፕሮጀክቶች ሊገነቡ የሚችሉት በሁለተኛው መንገድ ብቻ ነው (በመስመር ላይ ገንባ) ወይም በ Termux ውስጥ በ Gradle፣ ምክንያቱም Compose በመሣሪያው ላይ የማይገኙ የ Jetpack Compose ቤተ-መጻሕፍቶችን ይፈልጋል። የመጀመሪያው የግንባታ ውጤት ገና አልተፈረመም። ከዚያ በኋላ መተግበሪያው ይፈርመዋል፦ በራስ-ሰር በነባሪ ቁልፍ፣ ወይም ፕሮጀክቱ ሲፈጠር "የግል ፊርማ ተጠቀም" የሚለው ሳጥን ምልክት ከተደረገ በግል ፊርማ።

APK እንዴት እንደሚጫን
APK ዝግጁ ሲሆን፣ ለመጫን ጫን የሚለውን ይጫኑ። በ Android 8 እና ከዚያ በላይ፣ ስልኩ በመጀመሪያ "ከዚህ ምንጭ ፍቀድ" ይጠይቃል፣ ምክንያቱም ይህ መተግበሪያ APK ከ Play Store ውጭ ይጫናል። ያን ፈቃድ አንድ ጊዜ በቅንብሮች ውስጥ ያንቁ፣ ከዚያ ወደ መተግበሪያው ይመለሱ፦ ጫን እንደገና መጫን ሳያስፈልግ መጫኑ በራስ-ሰር ይቀጥላል። የ ጫን ቁልፍ ካልታየ፣ ግንባታው መጠናቀቁን እና APK መፈጠሩን ያረጋግጡ።

መተግበሪያ እንዴት እንደሚፈረም
እያንዳንዱ APK ሊጫን እንዲችል መፈረም አለበት። ሁለት ምርጫዎች አሉ። በመጀመሪያ፣ ነባሪ ቁልፍ፦ መተግበሪያው ምንም ሳያደርጉ በራስ-ሰር ይፈርማል። ሁለተኛ፣ የግል ፊርማ፦ በመጀመሪያ በዋናው ምናሌ ውስጥ ባለው Keystore ፍጠር ምናሌ በኩል keystore ይፍጠሩ፣ የይለፍ ቃሉን በደንብ ያስቀምጡ፣ ከዚያ ፕሮጀክት ሲፈጥሩ "የግል ፊርማ ተጠቀም" የሚለውን ምልክት ያድርጉ። Keystore በ Download/project/signing ውስጥ ይቀመጣል።

ፕሮጀክቶችን ለጓደኞች ማጋራት እንዲቻል ZIP ላክ ይሰጣል። እንደሚከተለው ነው፦ በፕሮጀክቶችን አስተዳድር ውስጥ፣ የፕሮጀክቱን ስም ለረጅም ጊዜ ይጫኑ፣ ከዚያ ZIP ላክ የሚለውን ይምረጡ። ውጤቱ በ Download/project/<የፕሮጀክትስም>.zip ውስጥ ይቀመጣል። የ bin አቃፊ አልተካተተም፣ ስለዚህ መጠኑ አነስተኛ ነው፣ ጥቂት አስር KB ብቻ። ያ ZIP ፋይል ለጓደኞች ሊላክ ወይም ወደ GitHub ሊሰቀል ይችላል።

የ JAWS ቅጥያ
የ JAWS ቅጥያ የ Jieshuo (CSR) የቅጥያ ሞተርን ይጠቀማል፣ የስክሪን አንባቢውን አይደለም። በዚህም ምክንያት፣ ተጠቃሚው TalkBack እየተጠቀመ ቢሆንም ንድፉ አሁንም ሊሰራ ይችላል። እንደሚከተለው ነው፦ በዋናው ምናሌ ውስጥ የ JAWS ቅጥያ ይክፈቱ። ራስ-ሰር ጠቅ ማድረግ በራሱ ስለሚሰራ፣ አገልግሎቱ በመጀመሪያ በተደራሽነት ቅንብሮች ውስጥ መንቃት አለበት። ከዚያ በኋላ አዲስ ንድፍ ሊፈጠር ይችላል፦ የንድፉን ስም ይተይቡ፣ እሺ ይጫኑ፣ ከዚያ ሳጥኑን ይሙሉ።

የጠቅታዎች ዝርዝር የተለየ ሆኖ ይቀመጣል ንጽህና ይኖረው ዘንድ

መስፈርቶች
Android 5.0 ወይም ከዚያ በላይ አዲስ። የማከማቻ ፈቃድ፦ በ Android 11 እና ከዚያ በላይ የሁሉም ፋይሎች መድረሻ ፈቃድ ይጠቀማል፣ በ Android 10 እና ከዚያ በታች የተለመደ የማከማቻ ፈቃድ (ማከማቻ አንብብ/ጻፍ) ይጠቀማል ምክንያቱም Android 10 የሁሉም ፋይሎች መድረሻ ፈቃድ የለውም። በመሣሪያው ላይ መገንባት የ ARM ፕሮሰሰር (32 ወይም 64 ቢት) ያለው ስልክ ይፈልጋል። በ GitHub Actions በኩል በመስመር ላይ መገንባት ኢንተርኔት እና የ GitHub ማስመሰያ ይፈልጋል። የ Kotlin ፕሮጀክቶች በመሣሪያው ላይ ሊገነቡ ይችላሉ፣ ግን የመጀመሪያ ግንባታቸው በአጠናቃሪው ትልቅ መጠን የተነሳ ቀርፋፋ እና ተጨማሪ ትውስታ ይጠቀማል። የ Compose ፕሮጀክቶች በ GitHub Actions በኩል ወይም በ Termux ውስጥ በ Gradle ይገነባሉ። የ Python ፕሮጀክቶች Android 7.0 ወይም ከዚያ በላይ አዲስ (ዝቅተኛ SDK 24) ይፈልጋሉ እና ውጤቱ APK የ Python የሩጫ ጊዜን (Chaquopy) ከመደበኛ ቤተ-መጽሐፉ ጋር ስለሚያካትት ትልቅ ነው።

Terminal
በዋናው ስክሪን ላይ ያለው የ Terminal ምናሌ በዚህ መተግበሪያ ውስጥ ተርሚናል ይከፍታል። እንደ ls ያሉ ትዕዛዞች የፕሮጀክት አቃፊ ይዘትን ለማየት፣ cd አቃፊዎችን ለመቀየር፣ እና git ኮድን ለማስተዳደር ሊጠቀሙ ይችላሉ። የትዕዛዝ ውጤት የስክሪን አንባቢ ሊያነበው በሚችል ጽሑፍ መልክ ይታያል፣ እና የመጨረሻውን ውጤት ለማዳመጥ ውጤቱን አንብብ የሚባል ቁልፍ አለ። ይህ ተርሚናል የስልኩን የስርዓት ሼል ይጠቀማል፣ ስለዚህ እንደ nano እና vim ያሉ በይነተገናኝ ፕሮግራሞች እዚህ ገና ሊጠቀሙ አይችሉም።

ፈቃድ (የሚከፈልበት እትም)

ፕሮጀክት ከመገንባትዎ በፊት ለጓደኛ ለማሳየት: በፕሮጀክቶችን አስተዳድር ውስጥ የፕሮጀክቱን ስም ረዘም ላለ ጊዜ ይጫኑ እና ከዚያ ወደ ጓደኛ ስልክ ቅድመ እይታ ይምረጡ። መተግበሪያው የፕሮጀክቱን ዋና ፋይሎች (index.html፣ MainActivity ወይም main.py) እና መመሪያዎች ያሉበትን አኑብ-እኔ.txt ፋይል እና info.txt የያዘ ትንሽ የቅድመ እይታ ጥቅል ይፈጥራል። ጥቅሉ እንደ ZIP በ WhatsApp ወይም Telegram ይላካል። የሚቀበለው ጓደኛ ቅድመ እይታውን በቀጥታ መክፈት ይችላል: የ HTML ገጾች በአሳሹ ውስጥ ይከፈታሉ፣ የ Java/Kotlin/Python ኮድ እንደ ጽሑፍ ይነበባል።

የፕሮጀክት ገበያ
የፕሮጀክት ገበያ በአንድ መጫኛ ወደ ፕሮጀክት አቃፊ ሊጫኑ የሚችሉ አብሮገነብ የምሳሌ ፕሮጀክቶችን ይዟል: ካልኩሌተር፣ ማስታወሻዎች፣ የተግባር ዝርዝር፣ የድር ካልኩሌተር፣ የመገለጫ ድር ጣቢያ፣ ቆጣሪ፣ ዲጂታል ሰዓት እና የድር ጥያቄና መልስ። የመስመር ላይ ገበያ (ምሳሌዎችን ከኢንተርኔት ማውረድ) ገና አልተገኘም፣ ስለዚህ ይህ ገበያ ቀድሞውኑ በመተግበሪያው ውስጥ ያሉ ምሳሌዎችን ይዟል። የተጫነ ፕሮጀክት በፕሮጀክቶችን አስተዳድር ውስጥ እንደ እርስዎ የፈጠሩት ፕሮጀክት ሊከፈት እና ሊለወጥ ይችላል።

ቀጥተኛ ትብብር
ከጓደኛ ጋር በፕሮጀክት ላይ አብሮ ለመስራት: በዋና ምናሌ ውስጥ ትብብር ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ የለውጥ ማስታወሻ (ምን እንደተለወጠ) ይጻፉ እና ከዚያ ለትብብር አጋራ ይጫኑ። ፕሮጀክቱ እንደ ZIP ከውስጡ ካለው CATATAN.txt ፋይል ጋር ይላካል። ጓደኛዎ በላዩ ይሰራል እና ZIP ን ወደ ኋላ ይልካል; መልስ ተቀበል ይጫኑ፣ መጀመሪያ የለውጥ ማስታወሻውን ያንብቡ እና ከዚያ የድሮውን ፕሮጀክት ለመተካት ተግብር ይምረጡ ወይም ከተጸጸቱ አቋርጥ ይምረጡ። ያለ CATATAN.txt ያለው ZIP የትብብር ጥቅል አይደለም — ለመደበኛ የፕሮጀክት ZIP፣ በፕሮጀክቶችን አስተዳድር ውስጥ ፕሮጀክት አስገባ ይጠቀሙ።

ራስ-ሰር የመተግበሪያ ተርጓሚ
የመተግበሪያ ጽሑፍ ወደ ሌላ ቋንቋ ለመተርጎም: በዋና ምናሌ ውስጥ የመተግበሪያ ተርጓሚ ይክፈቱ፣ ፕሮጀክቱን እና የዒላማ ቋንቋውን (እንግሊዝኛ፣ አረብኛ ወይም ጃቫኒዝ) ይምረጡ እና ከዚያ ተርጉም ይጫኑ። መዝገበ ቃላቱ ቀድሞውኑ በስልኩ ውስጥ ነው (ያለ ኢንተርኔት፣ ያለ ወጪ) እና የተለመዱ የዕለት ተዕለት ቃላትን ይዟል; ጽሑፍ ከ strings.xml፣ ከአቀማመጥ እና ከኮድ ይነበባል እና ከዚያ ይተረጎማል። ውጤቱ ወደ values-ቋንቋ/strings.xml አቃፊ (ፕሮጀክቱ strings.xml ካለው) እና ወደ ትርጉም-ቋንቋ.txt ሪፖርት በፕሮጀክት አቃፊ ውስጥ ይጻፋል። በመዝገበ ቃላቱ ውስጥ ገና ያልተገኙ ቃላት እንደሆኑ ይቀራሉ እና ሪፖርት ይደረጋሉ — ስለዚህ የትኞቹን ቃላት እርስዎ እራስዎ መተርጎም እንዳለብዎ ያውቃሉ።

ኮድ የሌለው የጨዋታ ሰሪ
ኮድ ሳይጽፉ ጨዋታ ለመፍጠር: በዋና ምናሌ ውስጥ ኮድ የሌለው የጨዋታ ሰሪ ይክፈቱ፣ የጨዋታውን አይነት (ቁጥር ገምት፣ ጥያቄና መልስ ወይም ኮከብ ያዝ) ይምረጡ፣ የጨዋታውን ስም፣ መጠን (ደረጃዎች/ጥያቄዎች/ኮከቦች) እና የድል መልእክት ይሙሉ እና ከዚያ ጨዋታ ፍጠር ይጫኑ። ጨዋታው እንደ እውነተኛ ፕሮጀክት ይፈጠራል፣ በፕሮጀክቶችን አስተዳድር ውስጥ በቀጥታ ሊሄድ ይችላል እና እንደ ሌላ ማንኛውም ፕሮጀክት እንደ APK ሊገነባ ይችላል።

ራስ-ሰር የመተግበሪያ ሙከራ
ፕሮጀክት ከመገንባትዎ በፊት ለመፈተሽ: በፕሮጀክቶችን አስተዳድር ውስጥ የፕሮጀክቱን ስም ረዘም ላለ ጊዜ ይጫኑ እና ከዚያ ራስ-ሰር ሙከራ ይምረጡ። IDE 10 ነገሮችን ያለ APK መገንባት ይፈትሻል — የግዴታ ፋይሎች አሉ (የፕሮጀክት ውሂብ ፋይል፣ ማኒፌስት፣ ዋና ፋይል፣ አቀማመጥ፣ ሕብረቁምፊዎች)፣ የጥቅል ስም እና ስሪት፣ ጥቅም ላይ የዋሉ ፈቃዶች፣ አዶ እና በኮድ ውስጥ ያሉ የቅንፍ ሚዛን። ውጤቱ በእያንዳንዱ ንጥል (አልፏል/ወድቋል ከመልእክት ጋር) ይታያል እና በ Jieshuo በድምጽ ይነበባል። መጀመሪያ የወደቁትን ሁሉ ያስተካክሉ እና ከዚያ ፕሮጀክት ገንባ ይጫኑ።

AI የኮድ መርማሪ
የፕሮጀክት ኮድ ብዙውን ጊዜ ችግር የሚያስከትሉ ንድፎችን ለመፈተሽ: በዋና ምናሌ ውስጥ ኮድ አረጋግጥ ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ ኮድ አረጋግጥ ይጫኑ። መርማሪው በስልኩ ውስጥ ይሰራል (ያለ ኢንተርኔት) እና ጥቅም ላይ ያልዋሉ ተለዋዋጮችን፣ ባዶ ተግባራትን፣ በግልጽ ማለቂያ የሌላቸው ዑደቶችን፣ በኮድ ውስጥ በቀጥታ የተጻፈ ጽሑፍ (በ strings.xml ውስጥ ይሻላል)፣ አደገኛ ፈቃዶች እና APIዎች፣ TODO/FIXME ምልክቶችን እና ተለዋዋጭ አፈጻጸምን ይፈልጋል። እያንዳንዱ ግኝት የፋይል ስም፣ የመስመር ቁጥር እና የማስተካከያ ሀሳብ ይዟል። ይህ መርማሪ በንድፍ ላይ የተመሰረተ ነው፣ እውነተኛ AI አይደለም — ንድፍ የማይከተሉ ችግሮች አሁንም ሊያመልጡ ይችላሉ።

መተግበሪያዎችን ደረጃ በደረጃ ለመፍጠር ለመማር: በዋና ምናሌ ውስጥ የመማር ሁነታ ይክፈቱ። 5 ትምህርቶች አሉ: የመጀመሪያ ፕሮጀክትዎን ይፍጠሩ፣ አዝራር ይጨምሩ፣ ቀለም ይለውጡ፣ ድምጽ ይጨምሩ እና APK ይገንቡ። ማብራሪያውን እና የተግባር ልምምድን ለማንበብ ትምህርት ይንኩ፣ ተግባሩን ያድርጉ እና ከዚያ ተግባር ምረጥ ይጫኑ — IDE ተግባሩ መከናወኑን በእውነት ይፈትሻል (ፕሮጀክቱን እና በስልክዎ ላይ ያለውን APK በመቃኘት)። ያለፉ ትምህርቶች እንደተጠናቀቁ ምልክት ተደርጎባቸዋል እና ይቀመጣሉ።

የደመና ማመሳሰል
ፕሮጀክት ወደ ደመና ምትኬ ለመስራት: በዋና ምናሌ ውስጥ የደመና ማመሳሰል ይክፈቱ። የአካባቢ ምትኬ የፕሮጀክት ZIP ን በጊዜ ማህተም ወደ Download/cloud አቃፊ ያስቀምጣል እና ከምትኬ ዝርዝር በማንኛውም ጊዜ ሊመለስ ይችላል። የ GitHub ምትኬ የፕሮጀክት ZIP ን ወደ የግል ማከማቻዎ ይጭናል (ከ GitHub ቅንብሮች ቶከን በመጠቀም) እና እንደገና ሊወርድ ይችላል። ይህ በእጅ የሚሰራ ምትኬ እና መመለሻ ነው — ሙሉ አውቶማቲክ ባለሁለት መንገድ ማመሳሰል አገልጋይ ይፈልጋል፣ ስለዚህ ገና አልተገኘም።

አውቶማቲክ Backend ፈጣሪ
የአገልጋይ ኮድ ሳይጽፉ Backend ለመፍጠር: በዋና ምናሌ ውስጥ Backend ፈጣሪ ይክፈቱ፣ የ Backend አይነት (ማስታወሻዎች፣ የተግባር ዝርዝር ወይም የማስታወቂያ ሰሌዳ) ይምረጡ፣ የፕሮጀክቱን ስም ይሙሉ እና ከዚያ Backend ፍጠር ይጫኑ። IDE በቅጽ ገጽ እና በስልኩ የአካባቢ ማከማቻ (localStorage) ውስጥ በተቀመጠ የውሂብ ዝርዝር እውነተኛ HTML ፕሮጀክት ይፈጥራል — ውሂብ ይቀመጣል እና መተግበሪያው ሲሄድ እንደገና ሊነበብ ይችላል። ይህ Backend በስልክ ላይ ይሰራል; የኢንተርኔት አገልጋይ ስለሌለ ሁለት ስልኮች ገና ተመሳሳይ ውሂብ መጋራት አይችሉም።

ራስ-ሰር የ테ማ ዲዛይነር
ለፕሮጀክት የቀለም ገጽታ ለመስጠት: በዋና ምናሌ ውስጥ የገጽታ ዲዛይነር ይክፈቱ፣ ፕሮጀክቱን እና ገጽታውን (ብርሃን፣ ጨለማ፣ ሰማያዊ፣ አረንጓዴ፣ ቀይ ወይም ወይን ጠጅ) ይምረጡ። ቅድመ እይታው የገጽታውን ስድስት ቀለሞች (ዋና፣ ጨለማ ዋና፣ አክሰንት፣ ዳራ፣ ጽሑፍ፣ ሁለተኛ ጽሑፍ) ያሳያል እና በ Jieshuo በድምጽ ይነበባል። ቴማ ተግብር ይጫኑ — IDE colors.xml እና styles.xml (app_theme ስልት) ወደ ፕሮጀክቱ ይጽፋል፣ ፕሮጀክቱ ሲሄድ ወይም ሲገነባ በቀጥታ ጥቅም ላይ ይውላል።

የአኒሜሽን ሰሪ
ለፕሮጀክት አኒሜሽን ለመስጠት: በዋና ምናሌ ውስጥ የአኒሜሽን ሰሪ ይክፈቱ፣ ፕሮጀክቱን፣ የአኒሜሽን አይነት (መጥፋት፣ መንሸራተት፣ መሽከርከር፣ መዝለል ወይም መምታት)፣ ቆይታ (100 እስከ 10000 ሚሊ ሰከንድ) እና ዒላማ (አዝራር፣ ጽሑፍ ወይም ምስል) ይምረጡ እና ከዚያ አኒሜሽን ፍጠር ይጫኑ። IDE እውነተኛ የአኒሜሽን ፋይል ይጽፋል (res/anim/anim_<አይነት>.xml ለ Java/Kotlin/Compose ፕሮጀክቶች፣ ወይም animasi.css ለ HTML/ድር ጣቢያ ፕሮጀክቶች) በማያ ገጽ ላይ ከሚታየው የአጠቃቀም ምሳሌ ኮድ ጋር።

የድርጊት መቅዳቻ
ሥራን በራስ-ሰር ለመድገም: IDE የተከናወኑ እርምጃዎችን ይመዘግባል (ፕሮጀክት መክፈት፣ ማሄድ፣ መገንባት፣ ወደ ውጭ መላክ፣ ምትኬ ማድረግ፣ ፕሮጀክት መፍጠር፣ ፋይል ማስቀመጥ)። በዋና ምናሌ ውስጥ የድርጊት መቅዳቻ ይክፈቱ የተመዘገቡ እርምጃዎችን ዝርዝር ከእቅዳቸው ጋር ለማየት እና ከዚያ እንደገና አጫውት ይጫኑ — IDE ራስ-ሰር ሊሆኑ የሚችሉ እርምጃዎችን እንደገና ያሄዳል (ምትኬ እና ፕሮጀክት መፍጠር በቦታው ይሰራሉ; ማሄድ፣ መገንባት እና ወደ ውጭ መላክ ዋና ማያቸውን ይከፍታሉ; መክፈት እና ማስቀመጥ አርታኢውን ይከፍታሉ)። ራስ-ሰር ሊሆኑ የማይችሉ እርምጃዎች ይዘለላሉ እና በመጨረሻ ሪፖርት ይደረጋሉ።

ራስ-ሰር ደህንነት
የፕሮጀክት ደህንነት ለመፈተሽ: በዋና ምናሌ ውስጥ ራስ-ሰር ደህንነት ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ ደህንነት ምረጥ ይጫኑ። IDE 8 ነገሮችን በአካባቢ ይፈትሻል (ያለ ኢንተርኔት): አደገኛ ፈቃዶች (አካባቢ፣ SMS፣ ጥሪዎች፣ ካሜራ፣ ማይክሮፎን፣ እውቂያዎች)፣ ውሂብ በ HTTP መላክ፣ SMS መላክ፣ ወጪ ጥሪዎች፣ በኮድ ውስጥ በቀጥታ የተጻፈ የይለፍ ቃል ወይም ቁልፍ፣ ያለ ጥበቃ WebView፣ ያለ ፈቃድ የተላከ አካል እና ያለ ምስጠራ http አድራሻ። እያንዳንዱ ግኝት ደህንነቱ የተጠበቀ፣ ማስጠንቅቂያ ወይም አደጋ ደረጃን ከማስተካከያ ሀሳብ ጋር ያገኛል፣ እና ማጠቃለያው በ Jieshuo በድምጽ ይነበባል።

AI ከመስመር ውጭ
ያለ ኢንተርኔት የጽሑፍ እና የኮድ እርዳታዎችን ለመጠቀም: በዋና ምናሌ ውስጥ AI ከመስመር ውጭ ይክፈቱ። 4 መሳሪያዎች አሉ: ጽሑፍ አስተካክል (ትላልቅ ፊደሎች፣ ሥርዓተ ነጥብ እና ድርብ ክፍተቶች)፣ ጽሑፍ አጠቃልል (3ቱን በጣም አስፈላጊ ዓረፍተ ነገሮች ይወስዳል)፣ የመተግበሪያ ስም ፍጠር (ከተጻፈው መግለጫ) እና የተለዋዋጭ ስሞችን ሀሳብ አቅርብ (በፕሮጀክቱ ውስጥ የ 1–2 ፊደል ተለዋዋጭ ስሞችን ይፈልጋል)። እነዚህ በስልኩ ውስጥ ያሉ ቀላል ህጎች ናቸው፣ እውነተኛ AI ሞዴል አይደሉም። የጽሑፍ ማስተካከያ ውጤት በተግብር አዝራር የፕሮጀክቱን strings.xml ላይ ሊተገበር ይችላል።

ለመነሻ ማያ Widget ለመፍጠር: በዋና ምናሌ ውስጥ ዊጀቶች እና ዎልፔፐሮች ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ የ Widget ጽሑፍ ይሙሉ እና ከዚያ Widget ፍጠር ይጫኑ። IDE WidgetSaya.java፣ የ Widget አቀማመጥ፣ የ Widget መረጃ ይጽፋል እና ተቀባይ ወደ ፕሮጀክቱ AndroidManifest.xml ይጨምራል — ፕሮጀክቱን ይገንቡ እና ከዚያ Widget ን ከስልኩ መነሻ ማያ ይጫኑ። ለዎልፔፐር: ጽሑፉን እና የዳራ እና የጽሑፍ ቀለሞችን ይሙሉ፣ ቅድመ እይታ ያድርጉ እና ከዚያ እንደ PNG ወደ Download አቃፊ ያስቀምጡት ወይም በቀጥታ እንደ ስልክ ዎልፔፐር ያዘጋጁት።

የማህበራዊ ሚዲያ ውህደት
ለመተግበሪያ የማጋራት አዝራሮችን ለመጨመር: በዋና ምናሌ ውስጥ የማህበራዊ ሚዲያ ውህደት ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ ወደ WhatsApp፣ Facebook ወይም Telegram (ወይም ሦስቱንም በአንድ ጊዜ) ማጋራት ይጨምሩ። IDE እውነተኛ የማጋራት ኮድ ወደ ፕሮጀክቱ ዋና ፋይል (MainActivity ወይም index.html) ይጽፋል። የማጋራት ሙከራ አዝራር የማጋሪያ መራጭን ከ IDE ከምሳሌ ጽሑፍ ጋር ይከፍታል፣ ስለዚህ መተግበሪያው ከመገንባቱ በፊት ፍሰቱ ሊሰማ ይችላል።

መተግበሪያ ከምስል
ከምስል የጋለሪ መተግበሪያ ለመፍጠር: በዋና ምናሌ ውስጥ መተግበሪያ ከምስል ይክፈቱ እና ከጋለሪው ምስል ይምረጡ። IDE የምስሉን መጠን እና የበላይ ቀለም ይተነትናል እና ከዚያ እውነተኛ የጋለሪ መተግበሪያ ፕሮጀክት ይፈጥራል: ምስሉ ወደ ፕሮጀክቱ assets ይገለበጣል፣ የገጽታ ቀለም ከምስሉ የበላይ ቀለም ይወሰዳል እና የመተግበሪያው ስም ከምስል ፋይል ስም ይወሰዳል። የጋለሪ መተግበሪያውን ለማሄድ ወይም ለመገንባት ፕሮጀክቶችን አስተዳድር ይክፈቱ።

በይነተገናኝ Terminal (VT ተንታኝ)
በ Terminal ውስጥ በይነተገናኝ ፕሮግራሞችን ለመጠቀም: በዋና ምናሌ ውስጥ Terminal ይክፈቱ እና ከዚያ nano፣ vim፣ top ወይም htop ያሂዱ። Terminal አሁን VT ተንታኝ ይጠቀማል (የፍርግርግ ማያ ከ 24 ረድፎች x 80 አምዶች) ስለዚህ እነዚህ ፕሮግራሞች በትክክል ይታያሉ — ጠቋሚው ይንቀሳቀሳል፣ መስመሮች ይሰረዛሉ እና ማያው እንደ እውነተኛ terminal ይለወጣል። በይነተገናኝ ፕሮግራሞችን ለመቆጣጠር ለ Tab፣ ወደ ላይ ቀስት፣ ወደ ታች ቀስት እና Esc ልዩ አዝራሮች አሉ። ውጤቱ አሁንም Jieshuo ሊያነብ የሚችል ጽሑፍ ነው; የመጨረሻውን መስመር ለመስማት ማያ ገጽ አንብብ ይጫኑ።

Terminal Exec (የመተግበሪያ ባይነሪ)
በመተግበሪያ አቃፊ ውስጥ ያለ ሁለትዮሽ ፋይል (ለምሳሌ aapt2፣ ECJ፣ D8) ከ Terminal ለማሄድ: ትእዛዙን እንደተለመደው ይጻፉ። IDE libkautsarexec.so ይጠቀማል ስለዚህ በመተግበሪያ አቃፊ ውስጥ ያሉ ሁለትዮሽ ፋይሎች በ Android 10 እና አዳዲስ ስሪቶች ላይ ሊሄዱ ይችላሉ። በዚህ ስልክ ላይ የሁለትዮሽ exec መንገድ የሚሰራ መሆኑን ለመፈተሽ በ Terminal ውስጥ የExec ሙከራ ይጫኑ — ውጤቱ እንደነበረው ይታያል። exec በስርዓቱ ከተዘጋ፣ የስርዓት ትእዛዞች እና የ shell ስክሪፕቶች አሁንም ይሰራሉ; ሁለትዮሽ ፋይሉን በምትኩ በፕሮጀክት ገንባ ምናሌ በኩል ያሂዱ።

Terminal ህያው እንዲቆይ (KeepAlive)
ማያ ሲቀይሩ shell ን በሥራ ላይ ለማቆየት: Terminal ይክፈቱ፣ ትእዛዝ ያሂዱ እና ከዚያ ተመለስ ይጫኑ ወይም ወደ ሌላ ማያ ይቀይሩ — shell አይሞትም፣ እና የ Terminal ማሳወቂያ መታየቱን ይቀጥላል ስለዚህ በአንድ መጫኛ መመለስ ይችላሉ። የተሄዱ ትእዛዞች በታሪክ ውስጥ ይቀመጣሉ (የታሪክ አዝራር ወይም ወደ ላይ/ወደ ታች ቀስቶች በትእዛዝ መስክ ውስጥ) እና ብዙ ጊዜ ጥቅም ላይ የዋሉ ትእዛዞች እንደ ተወዳጆች ሊቀመጡ ይችላሉ (የተወዳጆች አዝራር)። ሲጨርሱ shell ዝጋ ይጫኑ፣ shell በእውነት እንዲያልቅ። በፕሮጀክት ምናሌ እና በአርታኢ ምናሌ ውስጥ በ Terminal ውስጥ ገንባ አዝራርም አለ: Terminal በፕሮጀክት አቃፊ ውስጥ ሲከፈት የግንባታ ትእዛዙ ቀድሞውኑ ተሞልቷል።

የ Terminal መሳሪያዎችን ጫን (ሙከራ)
አሁንም እየተሞከረ ያለ ባህሪ: በ Terminal ውስጥ የ Terminal መሳሪያዎችን ጫን (ሙከራ) አዝራር አለ Termux አካባቢን ከአዘጋጁ alat-termux repo (github.com/syudat/alat-termux) መስታወት ለመጫን፣ እንደ ሌላ መንገድ ከ Termux ጫን አዝራር በተጨማሪ ከኦፊሴላዊው Termux እትም የሚወስደው። የመስታወቱ ይዘት ከኦፊሴላዊው እትም ጋር በትክክል ተመሳሳይ ነው እና በመጫን ወቅት በ SHA-256 ይፈተሻል። አካባቢው ሲጫን፣ pkg update እና pkg install ትእዛዞች ጥቅም ላይ ሊውሉ ይችላሉ፣ እና ተጨማሪ መሳሪያዎች ከ repo ውስጥ ወደ terminalም ይጫናሉ: info-terminal የአካባቢ መረጃን ለማየት፣ bersih-terminal መሸጎጫውን ለማጽዳት እና cadangkan-proyek የፕሮጀክት አቃፊን ወደ አንድ ቀን ያለው tar.gz ፋይል ለመዝገብ። ከዚያ መተግበሪያው መሰረታዊ የ Linux ጥቅሎችን (git, python, curl, wget, nano, openssh, zip, unzip) እና የ APK ግንባታ መሳሪያዎችን ከፊርማ ጋር (openjdk-21, kotlin, gradle, ecj, aapt2, d8, apksigner, clang, cmake, ninja, make) ከኦፊሴላዊው Termux repo በራስ-ሰር ይጭናል፣ ስለዚህ terminal ወዲያውኑ መተግበሪያዎችን ለመገንባት ዝግጁ ነው። ትላልቅ ጥቅሎችን (መቶዎች MB) ማውረድ ረጅም ጊዜ ሊወስድ ይችላል። መጫኑ በሚሰራበት ጊዜ፣ እድገት እና የትእዛዝ ውጤት በ Terminal ዋና ማያ ላይ ይታያሉ፣ እና የመጨረሻው ውጤት በማያ አንባቢ በድምጽ ይነበባል። የጥቅል መጫኑ ገና ካልተጠናቀቀ፣ ለመቀጠል የ Terminal መሳሪያዎችን ጫን (ሙከራ) እንደገና ይጫኑ።

ሙሉ የድምጽ ሁነታ
IDE ን ሙሉ በሙሉ በድምጽ ለመቆጣጠር: በዋና ምናሌ ውስጥ ሙሉ የድምጽ ሁነታ ይክፈቱ እና ከዚያ ማዳመጥ ጀምር ይጫኑ። IDE ያለማቋረጥ ያዳምጣል — ለእያንዳንዱ ትእዛዝ አዝራር መጫን አያስፈልግም — ትእዛዙን ያሂዳል እና በድምጽ ይመልሳል። 26 ትእዛዞች አሉ: ፍጠር፣ ገንባ፣ ክፈት፣ አሂድ፣ ዝርዝር፣ ፈልግ፣ ሰርዝ፣ ሞክር፣ ምረጥ፣ ወደ ውጭ ላክ፣ ምትኬ አድርግ፣ አጋራ፣ አዶ ፍጠር፣ ተርጉም፣ በ Terminal ውስጥ ገንባ፣ ማያ አንብብ፣ ሁሉንም ማያዎች ክፈት (ደህንነት፣ AI ከመስመር ውጭ፣ Widget፣ ማህበራዊ ሚዲያ፣ ጨዋታ፣ መማር፣ ደመና፣ Backend፣ ገጽታ፣ አኒሜሽን፣ መቅዳቻን ጨምሮ)፣ ተመለስ፣ ዝጋ እና እርዳታ። ሁነታው ንቁ ሆኖ ከተተወ፣ ይህ ማያ እንደገና ሲከፈት ማዳመጥ በራስ-ሰር ይቀጥላል። ሁነታውን ለማጥፋት ማዳመጥ አቁም ይጫኑ። ስልኩ የድምጽ ማወቂያ አገልግሎት ከሌለው፣ ትእዛዞች አሁንም በጽሑፍ ሳጥን ውስጥ ሊጻፉ ይችላሉ።

የኮድ ተርጓሚ
ኮድ በቋንቋዎች መካከል ያለ ኢንተርኔት ለመተርጎም: በዋና ምናሌ ውስጥ የኮድ ተርጓሚ ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ የምንጭ ፋይል (.java/.kt) ይምረጡ እና ከዚያ አቅጣጫ ይምረጡ: Java ወደ Kotlin። ተርጉም ይጫኑ — ውጤቱ ሊተረጎሙ የማይችሉ መስመሮችን ሪፖርት ጋር ይታያል (እነዚህ መስመሮች እንደሆኑ ይቀራሉ እና ምልክት ይደረግባቸዋል)። አዲስ ፋይል (ስም-ትርጉም.java/.kt) በተመሳሳይ አቃፊ ውስጥ ለመጻፍ ውጤት አስቀምጥ ይጫኑ; ዋናው ፋይል በጭራሽ አይተካም። ይህ የንድፍ ህግ ተርጓሚ ነው፣ ማጠናከሪያ አይደለም — ከመጠቀምዎ በፊት ውጤቱን ሁልጊዜ ያረጋግጡ።

Git በመተግበሪያው ውስጥ
Git በ IDE ውስጥ ያለ Termux ለመጠቀም: በዋና ምናሌ ውስጥ Git በመተግበሪያው ውስጥ ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ የ Git Repo ፍጠር ይጫኑ በአካባቢ repo (.git) በዚያ ፕሮጀክት ውስጥ ለመፍጠር። ከመጨረሻው Commit ጋር ሲነጻጸር አዲስ፣ የተለወጡ ወይም የተሰረዙ ፋይሎችን ለማየት ሁኔታ ምረጥ ይጫኑ; የ Commit መልእክት ይሙሉ እና ከዚያ የፕሮጀክቱን ቅጽበታዊ ምስል ለማስቀመጥ Commit ይጫኑ; የ Commit ታሪክን ለማየት የ Commit መዝገብ ይመልከቱ ይጫኑ። Push ወደ GitHub እና Pull ከ GitHub በ GitHub ቶከን (pembuat-aplikasi-build repo) በኩል ቅጽበታዊ ምስሎችን ይጠቀማሉ — የ git ፕሮቶኮል አይደለም። Clone፣ Push (system-git) እና Pull (system-git) የሚሄዱት የ git ሁለትዮሽ በስልኩ ላይ ሲጫን ብቻ ነው (ብዙውን ጊዜ አይደለም)። ይህ ሙሉ git አይደለም: ምንም merge፣ branch ወይም diff የለም — እያንዳንዱ Commit የፕሮጀክቱን ሙሉ ZIP ቅጽበታዊ ምስል ያስቀምጣል።

የማስታወቂያ ሰሪ
ወደ ተገነባ መተግበሪያ ማስታወቂያዎችን ለመጨመር: በዋና ምናሌ ውስጥ የማስታወቂያ ሰሪ ይክፈቱ፣ ፕሮጀክቱን፣ አቅራቢውን (AdMob፣ Unity Ads ወይም AppLovin) እና የማስታወቂያ አይነት (Banner፣ Interstitial ወይም የተሸለመ) ይምረጡ። የማስታወቂያ ክፍል መታወቂያ ካለዎት ይሙሉት — ባዶ ማለት የሙከራ መታወቂያ ጥቅም ላይ ይውላል (AdMob የ Google ኦፊሴላዊ የሙከራ መታወቂያ ይጠቀማል; Unity የምሳሌ Game ID ይጠቀማል; AppLovin ባዶ ቦታ ይጠቀማል)። የ Java እና Kotlin ኮድ እና መመሪያውን ለማየት የማስታወቂያ ኮድ ፍጠር ይጫኑ; ሁሉንም ወደ ማስታወቂያ-<አቅራቢ>-<አይነት>.txt ፋይል በፕሮጀክቱ ውስጥ ለመጻፍ ወደ ፕሮጀክት አስቀምጥ ይጫኑ። ይህ የኮድ አብነት + መመሪያ ነው፣ የማስታወቂያ SDK አይደለም — SDK በ IDE ውስጥ አልተካተተም; እውነተኛ ማስታወቂያዎች የሚታዩት የአቅራቢ መለያ ሲፈጥሩ፣ የማስታወቂያ ክፍል ሲፈጥሩ፣ የራስዎን ክፍል መታወቂያ ሲለጥፉ እና የ SDK ጥገኝነት ወደ ፕሮጀክቱ build.gradle ሲጨምሩ ብቻ ነው።

የህጻናት ሁነታ
IDE ን ከልጅ ጋር አብሮ ለመጠቀም: በዋና ምናሌ ውስጥ የህጻናት ሁነታ ይክፈቱ። ማያው በትላልቅ አዝራሮች ቀላል ነው እና 4 ደህንነታቸው የተጠበቁ እርምጃዎች ብቻ አሉት: ፕሮጀክት ፍጠር (ከደህንነታቸው የተጠበቁ አብነቶች: ካልኩሌተር፣ ቁጥር ገምት፣ ጥያቄና መልስ፣ ኮከብ ያዝ)፣ ፕሮጀክት ክፈት፣ አሂድ እና የመማር ሁነታ። በዚህ ማያ ላይ ለመሰረዝ፣ ወደ ውጭ ለመላክ፣ ምትኬ ለማድረግ ወይም ቶከን ለማዘጋጀት አዝራር የለም። በመጀመሪያ መግቢያ ላይ የ 4 አሃዝ PIN ይፈጥራሉ — ይህ PIN ወላጅ ከልጆች ሁነታ ለመውጣት ይጠቀምበታል (ከልጆች ሁነታ ውጣ አዝራር ወይም ተመለስ አዝራር)። ይህ PIN ለትንንሽ ልጆች ቀላል ጥበቃ ነው፣ እውነተኛ ደህንነት አይደለም።

የሰዓት መተግበሪያ (Wear OS) ወይም የቴሌቪዥን መተግበሪያ (Android TV) ለመፍጠር: በዋና ምናሌ ውስጥ የ Wear OS እና TV መተግበሪያ ሰሪ ይክፈቱ እና ዒላማ ይምረጡ (Wear OS፣ Android TV ወይም ሁለቱም)። የፕሮጀክቱን ስም ይሙሉ እና ከዚያ አዲስ የ Wear/TV ፕሮጀክት ፍጠር ይጫኑ — IDE የ Java ፕሮጀክት ይፈጥራል እና ከዚያ ያስተካክለዋል — ወይም ያለ ፕሮጀክት ይምረጡ እና ከዚያ ወደዚህ ፕሮጀክት ተግብር ይጫኑ። ማስተካከያዎች: uses-feature በማኒፌስት ውስጥ፣ LEANBACK_LAUNCHER ምድብ + banner ለ TV እና የተስተካከለ activity_main.xml አቀማመጥ (Wear: ትንሽ ማያ; TV: ለ D-pad የሚስማማ ትልቅ ማያ)። ሙሉ ማብራሪያ ወደ wear-tv.txt በፕሮጀክቱ ውስጥ ይጻፋል። ይህ የፕሮጀክት አብነት ነው — ግንባታ + ሙከራ አሁንም የ Wear OS ወይም Android TV መሳሪያ/አስመሳይ ይፈልጋል; የ TV banner (banner.png 320x180) በራስ-ሰር አይፈጠርም፣ እርስዎ እራስዎ መጨመር አለብዎት (ለምሳሌ በአዶ ፈጣሪ በኩል)።

የፕሮጀክት ካርታ
የፕሮጀክት መዋቅር ለማየት: በዋና ምናሌ ውስጥ የፕሮጀክት ካርታ ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ ካርታ አሳይ ይጫኑ — IDE የአቃፊዎች እና የፋይሎች ዝርዝር ከመጠኖቻቸው ጋር፣ ጠቅላላ መጠን፣ መጠን በፋይል አይነት እና አስፈላጊ ፋይሎች (ዋና ፋይል፣ ማኒፌስት፣ አቀማመጥ፣ ሕብረቁምፊዎች፣ አዶ፣ ድር ገጽ) ያሳያል። ተመሳሳይ ካርታ ወደ ፕሮጀክቱ ሥር ለመጻፍ peta-proyek.txt አስቀምጥ ይጫኑ። bin/ አቃፊ (የግንባታ ውጤት) እና .git/ አቃፊ (የአካባቢ repo) በካርታው ውስጥ አልተካተቱም ምክንያቱም ይዘታቸው እንደገና ሊፈጠር ይችላል።

የAPK መጠን ካልኩሌተር
የተገነባ APK መጠን ከመገንባትዎ በፊት ለመገመት: በዋና ምናሌ ውስጥ የAPK መጠን ካልኩሌተር ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ ግምት አስላ ይጫኑ። IDE በምድብ ዝርዝሮችን ያሳያል (ኮድ/DEX፣ ሀብቶች፣ ንብረቶች፣ አብሮገነብ ቤተ-መጻሕፍት፣ ማኒፌስት + resources.arsc፣ አጠቃላይ ወጪዎች)፣ ጠቅላላ ግምት፣ 5ቱ ትላልቅ ፋይሎች እና ለመቀነስ ሀሳቦች (ለምሳሌ ትላልቅ ምስሎች በመፍትሔ ይቀንሳሉ፣ ትላልቅ ድምጾች በርዝመት ይቆርጣሉ)። ይህ ግምት ነው፣ ትክክለኛ መጠን አይደለም — እውነተኛው መጠን በ aapt2 መጨናነቅ፣ ጥቅም ላይ ያልዋለ ኮድ ማስወገድ (R8) እና የግንባታ ውጤት ሀብቶች ምክንያት ሊለያይ ይችላል።

የAPK ተንታኝ
የተጠናቀቀ APK ይዘት ለማንበብ (እንደ APK ተንታኝ በ Android Studio): በዋና ምናሌ ውስጥ የAPK ተንታኝ ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ የግንባታ ውጤት APK ትንተና ይጫኑ። IDE በዚያ ፕሮጀክት bin አቃፊ ውስጥ ያለውን የቅርብ ጊዜ APK ያነባል እና የጥቅል ስም፣ ስሪት፣ ዝቅተኛ እና ዒላማ SDK፣ ጥቅም ላይ የዋሉ ፈቃዶች ዝርዝር፣ የ dex ፋይሎች ብዛት፣ የመጠን ዝርዝሮች በክፍል (የፕሮግራም ኮድ፣ ሀብቶች፣ ንብረቶች፣ አብሮገነብ ቤተ-መጻሕፍት፣ ፊርማ) እና 10ቱ ትላልቅ ግቤቶችን ሪፖርት ያደርጋል። የትኛው ክፍል APK ን ትልቅ እንደሚያደርግ እና የተገነባው መተግበሪያ የትኞቹን ፈቃዶች እንደሚጠቀም ለማወቅ ጠቃሚ ነው።

የስክሪን መጠን ቅድመ እይታ
የፕሮጀክት መልክ በአንድ ጊዜ በብዙ የማያ መጠኖች ላይ ለመፈተሽ (እንደ Android Studio): በዋና ምናሌ ውስጥ የስክሪን መጠን ቅድመ እይታ ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ የማያ ገጽ መጠን ምረጥ ይጫኑ። IDE የፕሮጀክቱን ሁሉንም አቀማመጦች ያነባል እና ስፋታቸው ቋሚ ሆኖ የተጻፈ (ለምሳሌ 400dp) እና የማያ ስፋት 320፣ 360፣ 411 ወይም 480 dp የሚያልፉ ንጥሎችን ሪፖርት ያደርጋል፣ ምክንያቱም እንደዚህ ያለ ንጥል በትንሽ ማያ ባለው ስልክ ላይ ሊሸፈን ወይም ሊፈስ ይችላል። match_parent ወይም wrap_content ስፋት ያላቸው ንጥሎች በራስ-ሰር ወደ ማያው ይላመዳሉ እና መፈተሽ አያስፈልጋቸውም።

የሀብት አስተዳዳሪ
የፕሮጀክት ሁሉንም ሀብቶች በአንድ ቦታ ለማየት እና ለማስተዳደር (እንደ የሀብት አስተዳዳሪ በ Android Studio): በዋና ምናሌ ውስጥ የሀብት አስተዳዳሪ ይክፈቱ፣ ፕሮጀክቱን ይምረጡ እና ከዚያ ሃብቶች ይመልከቱ ይጫኑ። IDE የፋይሎች ብዛት እና መጠን በምድብ (drawable፣ layout፣ values፣ mipmap እና ሌሎች)፣ የ strings.xml፣ colors.xml እና styles.xml ይዘትን ሪፖርት ያደርጋል። ከተመሳሳይ ማያ አዲስ ሕብረቁምፊ ወደ strings.xml እና አዲስ ቀለም ወደ colors.xml ስም እና እሴት በመሙላት ሊጨመር ይችላል — ስሙ ይፈተሻል እና ተደጋጋሚዎች ይጣላሉ፣ ስለዚህ የ XML ፋይል አይበላሽም።

ቀላል የአፈጻጸም ክትትል
የሚሄድ መተግበሪያ RAM እና ፕሮሰሰር አጠቃቀም ለመከታተል (እንደ Profiler በ Android Studio፣ ቀላል ስሪት): በዋና ምናሌ ውስጥ ቀላል የአፈጻጸም ክትትል ይክፈቱ፣ መጀመሪያ ለመፈተሽ የሚፈልጉትን መተግበሪያ ያሂዱ (ለምሳሌ እየተሞከረ ያለው የተገነባ መተግበሪያ)፣ የጥቅል ስሙን ይሙሉ — ወይም ፕሮጀክት ይምረጡ እና ከዚያ የጥቅል ስም ከፕሮጀክት ሙላ ይጫኑ — እና ከዚያ ክትትል ጀምር ይጫኑ። በየሁለት ሰከንዶች IDE የዚያ መተግበሪያ RAM (PSS) እና CPU ከስልኩ ነፃ RAM ጋር ይመዘግባል; አማካይ እና ጫፍ ማጠቃለያ ለማየት አቁም ይጫኑ። ምንም ተጨማሪ ፈቃድ የለም። በአዲስ የ Android ስሪቶች ውስጥ፣ ወደ ሌላ መተግበሪያ ፕሮሰሰር የማንበብ መዳረሻ በስርዓቱ የተገደበ ነው፣ ስለዚህ CPU ሊነበብ ካልቻለ፣ ሪፖርቱ እንደነበረው ይናገራል እና የ RAM ክትትል ይቀጥላል።

የተደራሽነት ምርመራ
ፕሮጀክት ከመለቀቁ በፊት አቀማመጡ ለስክሪን አንባቢዎች (TalkBack/Jieshuo) ተስማሚ መሆኑን ለማረጋገጥ፡ በዋና ምናሌ ላይ የተደራሽነት ምርመራ የሚለውን ይክፈቱ፣ ፕሮጀክት ይምረጡ፣ ከዚያ የአቀማመጥ ዝርዝር ጫን የሚለውን ይንኩ እና የአቀማመጥ ፋይል ይምረጡ። IDE ያንን የ XML ፋይል ያነባል እና መለያ የሌላቸውን አዝራሮች ከመስመር ቁጥራቸው ጋር፣ ደጋግሞ ጥቅም ላይ የዋሉ መለያዎች እና እርስ በርስ የሚደራረቡ ንጥረ ነገሮችን ይዘግባል፣ ከዚያም Jieshuo እንደሚያነብባቸው የትኩረት ቅደም ተከተል ግልባጭ ይገነባል። አዝራር መለያ ከሌለው፣ መለያውን ይሙሉ እና ከዚያ መለያዎችን በራስ-ሰር አስገባ የሚለውን ይንኩ — መለያው በአቀማመጥ ፋይሉ ውስጥ እንደ contentDescription ይጻፋል። ይህ ምርመራ የአቀማመጥ XML ብቻ ያነባል፤ የ Compose እይታዎች እና የተጠናቀቁ APK ፋይሎች ገና አልተቃኙም።

የብልሽት ምርመራ
በልዩ መታወቂያ ያለው የብልሽት ምዝግብ ማስታወሻ መተግበሪያው ለምን እራሱን እንደሚዘጋ ለማወቅ፤ በዋና ምናሌው ውስጥ «የብልሽት ምርመራ» ን ይክፈቱ፣ ከምዝግብ ማስታወሻ ዝርዝር ውስጥ የብልሽት መታወቂያ ይምረጡ፣ ከዚያም «ያረጋግጡ» ን ይጫኑ። IDE በምዝግብ ማስታወሻው ውስጥ ያለውን ክፍል እና የመስመር ቁጥር ከፕሮጀክት ምንጭ ጋር ያዛምዳል እና ምክንያቱን በኢንዶኔዥያኛ ያብራራል (ለምሳሌ ባዶ ማጣቀሻ፣ እስካሁን ያልተጠየቀ ፈቃድ፣ ወይም JSON ስህተት)፣ ከኮድ ጥገና ሀሳብ ጋር። «ጥገና ተግብር» ን ብቻ ይጫኑ የምንጭ መስመር ብልሽቱ ሲከሰት እንደነበረ አሁንም ሲሆን፤ ከተቀየረ፣ ጥገናው ይከለከላል እና IDE እራስዎ እንዲያረጋግጡ ይጠይቅዎታል። ለተገነቡ መተግበሪያዎች ብልሽቶች፣ «የብልሽት መያዣ ወደ ፕሮጀክቱ ያስገቡ» ን ይጫኑ፣ ከዚያም APK እንደተለመደው ይገንቡ፦ የተገነባው መተግበሪያ የራሱን ብልሽቶች ይይዛል እና ምዝግብ ማስታወሻውን በስልኩ ላይ ይጽፋል፣ እና ያ ምዝግብ ማስታወሻ «የተገነባ መተግበሪያ ብልሽት ምዝግብ ማስታወሻ ፈልግ» አዝራር ሊገኝ ይችላል። ታማኝ ገደብ፦ ምዝግብ ማስታወሻውን ወደ ሕዝብ Download ማህደር በAndroid 11 እና ከዚያ በላይ መቅዳት ያለ ሁሉም ፋይሎች መዳረሻ ፈቃድ ሊሳካ አይችልም።

ትራንስፓይለር በተለያዩ ፓራዳይም መካከል
ቀላል የ Java ኮድ ወደ Kotlin፣ ወይም ቀላል የ XML አቀማመጥ ወደ Compose ኮድ ለመቀየር፡ በዋና ምናሌ ላይ ትራንስፓይለር በተለያዩ ፓራዳይም መካከል የሚለውን ይክፈቱ፣ ፕሮጀክት እና ፋይል ይምረጡ፣ ከዚያ ቅድመ እይታ የሚለውን ይንኩ። IDE የመቀየር ውጤቱን እንደ ጽሑፍ ያሳያል — መጀመሪያ ያረጋግጡ፣ ምክንያቱም እሱ የማያውቃቸው መስመሮች እንደነበሩ ይተዋሉ እና በ Java ውስጥ ያለው static የሚለው ቃል በ Kotlin ውስጥ ይጣላል (ከመጠቀምዎ በፊት ትርጉሙን ያረጋግጡ)። ከ XML ወደ Compose መቀየር ጽሑፍን፣ ፍንጮችን እና አቅጣጫን ብቻ ይለውጣል — መጠን፣ ቀለም እና ሌሎች ባህሪያት ገና አልተካተቱም። ውጤቱ ትክክል ከሆነ፣ የዒላማ ፋይሉን ለመጻፍ ወደ ፋይል ተግብር የሚለውን ይንኩ፤ የምንጭ ፋይል አይለወጥም። ደህንነታቸው የተጠበቁ፣ የተለመዱ ንድፎች ብቻ ይቀየራሉ።

የአካባቢ ማይክሮ አገልጋይ
ኢንተርኔት ሳይጠቀሙ አገልጋይ የሚፈልግ መተግበሪያ ለመሞከር፤ በዋና ምናሌው ውስጥ «የአካባቢ ማይክሮ አገልጋይ» ን ይክፈቱ፣ የመንገድ ትርጉሞችን ይጻፉ (ለምሳሌ GET /halo እና የJSON መልሱ)፣ ከዚያም «አገልጋይ ጀምር» ን ይጫኑ። IDE በተመሳሳይ ስልክ ላይ ትንሽ HTTP አገልጋይ ያሂዳል (HTTP ብቻ፣ TLS የለም፣ ለተመሳሳይ Wi-Fi አውታረ መረብ) እና እያንዳንዱን ጥያቄ እና መልስ በማያ ገጽ ላይ ይመዘግባል። መንገዶች እንደ {nama} ያሉ መለኪያዎችን እና ቀላል API ቁልፍ ሊጠቀሙ ይችላሉ። አገልጋዩ በተገነባው APK ውስጥም ሊታሸግ ይችላል፦ «አገልጋይ ወደ ፕሮጀክቱ ያሽጉ» ን ይጫኑ፣ እና የአገልጋይ ምንጭ፣ ንብረቶች እና ማኒፌስቶ ወደ ፕሮጀክቱ ይገባሉ፣ ስለዚህ የተገነባው መተግበሪያ ሲሠራ ራሱ አገልጋይ ይሆናል። በIDE ውስጥ ያለው አገልጋይ ማያ ገጹ ሲዘጋ ይቆማል።

የደህንነት ኦዲተር
ከመታተሙ በፊት የፕሮጀክት ኮድን ለደህንነት ክፍተቶች ለማረጋገጥ፤ በዋና ምናሌው ውስጥ «የደህንነት ኦዲተር» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ ከዚያም «ምርመራ ጀምር» ን ይጫኑ። IDE የፕሮጀክት ኮድ፣ ማኒፌስቶ እና ውቅር ይቃኛል እና ከከፍተኛ እስከ ዝቅተኛ አደጋ ድረስ ግኝቶችን ሪፖርት ያደርጋል — በኮድ ውስጥ ክፍት የተተወ API ቁልፍ፣ ያለ ፈቃድ የተጋለጠ ክፍል፣ JavaScript ን በJavaScript በይነገጹ የሚያነቃ WebView፣ ደካማ ክሪፕቶ (MD5፣ SHA1፣ DES)፣ ያለ TLS ያለው http አድራሻ፣ እና በኮድ ውስጥ በቀጥታ የተጻፈ የይለፍ ቃል — ከፋይሎቻቸው እና ከመስመር ቁጥሮቻቸው ጋር። ለደህንነቱ የተጠበቀ ጥገና ላሉ ግኝቶች (ለምሳሌ MD5 ን ወደ SHA-256 ወይም http ን ወደ https ቀይር)፣ «ጥገና ተግብር» ን ይጫኑ፤ ለAPI ቁልፎች እና የይለፍ ቃሎች፣ IDE የጥገና ሀሳብ ብቻ ያሳያል፣ ምክንያቱም ምትኩን ገንቢው ራሱ መወሰን አለበት። ምርመራው አሁን በተገነባው APK ውስጥ እውነተኛ DEX ባይትኮድንም ይተነትናል (በኮድ ውስጥ ያሉ የጽሑፍ ንድፎች ብቻ አይደሉም)፣ ስለዚህ የተጠሩ አደገኛ API ዎች እና በDEX ውስጥ የተካተቱ ሚስጥሮችም ይያዛሉ፤ ንድፍ የማይከተሉ ክፍተቶች አሁንም ከምርመራ ሊያመልጡ ይችላሉ — ከመተግበሩ በፊት ያረጋግጡ።

የተጠቃሚ በይነገጽ ፈታኝ ሮቦት
መተግበሪያ ማያ ገጽን በጽሑፍ ሁኔታዎች በራስ-ሰር ለመሞከር፤ በዋና ምናሌው ውስጥ «የተጠቃሚ በይነገጽ ፈታኝ ሮቦት» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ ከዚያም «ሁኔታ በራስ-ሰር ፍጠር» ን ይጫኑ። IDE የፕሮጀክት ማኒፌስቶ እና አቀማመጥ ያነባል እና ሁኔታውን እንደ ጽሑፍ እርምጃዎች ይጽፋል (አዝራር ይጫኑ፣ መስክ ይሙሉ፣ ይጠብቁ፣ ይመለሱ)። የሁኔታውን የአፈጻጸም ምዝግብ ማስታወሻ ከጊዜ ማህተሞቹ ጋር ለማየት «የሙከራ ሩጫ አድርግ» ን ይጫኑ — ይህ የሙከራ ሩጫ አሁንም የቅደም ተከተል ማስመሰል ብቻ ነው። ለእውነተኛ ሙከራ፣ «የሙከራ ወኪል ወደ ፕሮጀክቱ ያስገቡ» ን ይጫኑ፦ IDE የሙከራ ወኪሉን ከሁኔታ ንብረቶች ጋር ወደ ፕሮጀክቱ ያስገባል፤ APK እንደተለመደው ይገንቡ፣ ይጫኑት፣ ከዚያም «ሙከራ» አዶውን ይክፈቱ — ወኪሉ በተገነባው መተግበሪያ ውስጥ ይሠራል እና በእውነት አዝራሮችን ይጫናል፣ እውነተኛ መስኮችን ይሞላል፣ እና ይሸብልላል፣ ከዚያም ሪፖርቱን በማያ ገጽ ላይ በተያዙ እውነተኛ ብልሽቶች ያሳያል። ወኪሉን እንደገና ለማስወገድ፣ «የሙከራ ወኪል ከፕሮጀክቱ ያስወግዱ» ን ይጫኑ። ወኪሉ በመተግበሪያው የራሱ ሂደት ውስጥ ይሠራል፣ ስለዚህ የመዳረሻ አገልግሎት ወይም የስርዓት አውቶሜሽን አያስፈልገውም።

የኮድ የጊዜ ጉዞ
የ Git ትዕዛዞችን ሳይጽፉ ፕሮጀክትን ወደ ቀደም የኮድ ሁኔታ ለመመለስ፡ በዋና ምናሌ ላይ የኮድ የጊዜ ጉዞ የሚለውን ይክፈቱ፣ ፕሮጀክት ይምረጡ፣ ለጊዜ ነጥቡ መለያ ይሙሉ (ባዶ መተው ይቻላል)፣ ከዚያ የጊዜ ነጥብ መዝግብ የሚለውን ይንኩ። IDE የፕሮጀክቱን የምንጭ ፋይሎች ቅጂ ከ hash እሴቶቻቸው ጋር በፕሮጀክቱ ውስጥ ባለው .riwayat ማህደር ውስጥ ያስቀምጣል። የጊዜ ነጥቦች ዝርዝር ሁሉንም ያሳያል፤ ሁለት ነጥቦችን ይምረጡ ከዚያም የተጨመሩ፣ የተቀየሩ ወይም የተሰረዙ ፋይሎችን እና ተግባሮችን ለማየት አነጻጽር የሚለውን ይንኩ። የድሮ ሁኔታን ለመመለስ መልስ የሚለውን ይንኩ — ከመመለስዎ በፊት፣ IDE ሁልጊዜ መጀመሪያ የአሁኑን ሁኔታ ምትኬ ያደርጋል፣ ስለዚህ ምንም አይጠፋም። ፕሮጀክቱን ወደ አዲስ ማህደር ለመቅዳት እና ዋናውን ፕሮጀክት ሳያደናቅፉ ለውጦችን ለመሞከር የሙከራ ቅጂ ፍጠር የሚለውን ይንኩ። የምንጭ ፋይሎች ብቻ ይመዘገባሉ።

የሞጁል ፋብሪካ
የፕሮጀክት ክፍል ሌላ ፕሮጀክት ሊጠቀምበት እንደ ሞጁል ለመጠቅለል፡ በዋና ምናሌ ላይ የሞጁል ፋብሪካ የሚለውን ይክፈቱ፣ የምንጭ ፕሮጀክት ይምረጡ፣ የሚጠቅለሉትን የማያ፣ የክፍል፣ የሕብረቁምፊ እና የፈቃድ ፋይሎች ምልክት ያድርጉ፣ ከዚያ እንደ ሞጁል ጠቅልል የሚለውን ይንኩ። IDE የ ZIP ማህደር ከ JSON ሜታዳታ ጋር ይጽፋል (የሞጁል ስም፣ ስሪት፣ ጥቅም ላይ የዋሉ ሕብረቁምፊዎች እና ፈቃዶች)። ሞጁል በሌላ ፕሮጀክት ውስጥ ለመጫን፣ የሞጁል ፋብሪካ የሚለውን ይክፈቱ፣ የዒላማ ፕሮጀክት ይምረጡ፣ ከዚያ ሞጁል ጫን የሚለውን ይንኩ እና የሞጁሉን .zip ፋይል ይምረጡ — ውህደቱ ሕብረቁምፊዎችን እና ፈቃዶችን ያክላል ያለውን ኮድ ሳይደራረብ፣ እና ስሙ በዒላማ ፕሮጀክቱ ውስጥ አስቀድሞ ጥቅም ላይ ከዋለ ፋይል አይቀላቅልም። ሞጁል ቤተ-መጽሐፍትንም ሆነ የግንባታ ቅንብሮችን አብሮ አያመጣም።

ፖሊሞርፊክ ጋሻ እና የንብረት ማጠራቀሚያ
ከመታተሙ በፊት መለያ ስሞችን በዘፈቀደ ለማድረግ እና የፕሮጀክት ንብረቶችን ለማመስጠር፤ በዋና ምናሌው ውስጥ «ፖሊሞርፊክ ጋሻ እና የንብረት ማጠራቀሚያ» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ ከዚያም «ስሞችን በዘፈቀደ ያድርጉ እና ንብረቶችን ያመስጥሩ» ን ይጫኑ። IDE በምንጭ ኮድ ውስጥ ያሉትን የክፍል እና የዘዴ ስሞች ይቃኛል፣ በዘፈቀደ ስም ካርታ ይፈጥራል፣ እነዚህን ስሞች በተጠናቀሩ DEX ፋይሎች ውስጥ እንደገና ይጽፋል (የተተኪ ስሞች ሁሉም ማካካሻዎች ትክክለኛ ሆነው እንዲቆዩ እንደ ዋናዎቹ እኩል ርዝመት ይደረጋሉ፣ ከዚያም የDEX ራስጌ ቼክሰም እና SHA-1 ፊርማ እንደገና ይሰላሉ)፣ የፕሮጀክት ንብረት ፋይሎችን በፕሮጀክቱ ውስጥ ባለው brankas-aset ማህደር ውስጥ በAES-GCM ያመስጥራል፣ እና የብልሽት ምዝግብ ማስታወሻዎችን ሲያነብ ዋናዎቹ ስሞች እንዲመለሱ የተመሰጠረ የመልሶ ማግኛ ካርታ (perisai-peta.brankas) ያስቀምጣል። የማመስጠሪያ ቁልፉ አሁን ከፕሮጀክት ስም ሳይሆን ከገንቢው የይለፍ ቃል በPBKDF2፣ 20,000 ድግግሞሾች የተገኘ ነው። እንደ ግልጽ ጽሑፍ፣ የማብራሪያ ስም እና የአራሚ ስም የሚጠቀሙ ስሞች ሆን ብለው እንደገና አይጻፉም፣ እና በግንባታ መንገድ ውስጥ ያሉ የDEX እንደገና መጻፍ ማስገቢያ ነጥቦች አሁንም በእውነተኛ ስልክ ላይ መሞከርን እየጠበቁ ነው።

የእምነት ሰንሰለት እና የአካባቢ ጠባቂ
ከመታተሙ በፊት የፊርማ ቁልፍ ሰንሰለት እና የስልክ አካባቢን ለማረጋገጥ፤ በዋና ምናሌው ውስጥ «የእምነት ሰንሰለት እና የአካባቢ ጠባቂ» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ ከዚያም «ሰንሰለት እና አካባቢን ያረጋግጡ» ን ይጫኑ። IDE ከፕሮጀክት ጥቅል ስም 5 ትውልድ ያለው የቁልፍ ሰንሰለት ይገነባል እና ታማኝነቱን ያረጋግጣል፣ በማህደረ ትውስታ ውስጥ ያሉ የኮድ ክፍሎች ይዘት ከዲስክ ላይ ካሉ ፋይሎች ጋር በማነጻጸር እውነተኛ የማህደረ ትውስታ ታማኝነትን ያረጋግጣል እና ስም የሌላቸው የሚፈጸሙ (RWX) ካርታዎችን፣ የውጭ ቤተ-መጻሕፍትን እና የmemfd ካርታዎችን ሪፖርት ያደርጋል፣ ከዚያም የራሱን የሂደት ማህደረ ትውስታ ካርታ እና የመሣሪያ ባሕርያት ለFrida፣ Xposed ወይም ኢሙሌተር ዱካዎች ይቃኛል። የማጠራቀሚያ ቁልፉ ሲገኝ የሃርድዌር ደህንነት ቺፕን በሚጠቀም በAndroidKeyStore ውስጥ ባለው AES ቁልፍ ተጠቅልሏል፣ እና የቁልፍ መሽከርከር አሁን እውነተኛ ነው፣ የመርሃግብር v3 የፊርማ ሰርተፊኬት የዘር ሐረግን በመጠቀም፦ የድሮው ቁልፍ ወደ አዲሱ ቁልፍ የመሽከርከር ማስረጃ ላይ ይፈርማል እና APK በዚያ የዘር ሐረግ እንደገና ይፈረማል። ውጤቱ «ደህንነቱ የተጠበቀ»፣ «ጥንቃቄ» ወይም «አደገኛ» የአደጋ ደረጃ ከጽሑፍ ማስረጃ ጋር ነው። ስርዓቱ የማህደረ ትውስታ ማንበብን ከከለከለ፣ ማረጋገጫው «ማረጋገጥ አይቻልም» ተብሎ ሪፖርት ይደረጋል፣ ደህንነቱ የተጠበቀ አይደለም፤ እና ቁልፍ በእውነት የሃርድዌር ደህንነት ቺፕን የሚጠቀም መሆኑ በእውነተኛ መሣሪያ ላይ ብቻ ማረጋገጥ ይቻላል።

የጽሑፍ ዛፍ አቀማመጥ አርክቴክት
ማያ ገጽ ሳያዩ ለመንደፍ፤ በዋና ምናሌው ውስጥ «የጽሑፍ ዛፍ አቀማመጥ አርክቴክት» ን ይክፈቱ፣ ፕሮጀክቱን እና የአቀማመጥ ፋይልን ይምረጡ፣ ከዚያም «አቀማመጥን ያረጋግጡ» ን ይጫኑ። IDE የXML አቀማመጥን እንደ ጽሑፍ ዛፍ ያነባል እና የእያንዳንዱ ንጥል አካል የቦታ መግለጫ በድምፅ ያነባል (ለምሳሌ ከታች በቀኝ፣ 45 በመቶ የማያ ገጽ ስፋት) እና ከዚያም በሂሳብ መካከል መደራረብን እና በ360 dp ስፋት ከማያ ገጽ ውጭ የሚወጡ ንጥሎችን ሪፖርት ያደርጋል። አሁን የሚቆጠሩት LinearLayout እና ቀላል የdp መጠኖች፣ ሙሉ ConstraintLayout (ሁሉም ገደቦች፣ አድልዎ፣ ሰንሰለቶች፣ መመሪያዎች፣ እንቅፋቶች፣ የመቶኛ ስፋቶች፣ 0dp match_constraint እና የመጠን ሬሾዎች) እና የCompose ማያ ገጾች (Column፣ Row እና Box ከመጠን ማሻሻያዎቻቸው ጋር) ናቸው። በሚሠራበት ጊዜ የሚቀየሩ MotionLayout እና ConstraintSet ብቻ አሁንም ያልታወቀ ቦታ ተብለው ሪፖርት ይደረጋሉ፣ ምክንያቱም እሴቶቻቸው መተግበሪያው በሚሠራበት ጊዜ ብቻ ናቸው።

በሁሉም ማያ ገጾች እና ፕሮጀክቶች ላይ ርቀቶችን፣ ቅርጸ-ቁምፊዎችን እና ማዕዘኖችን አንድ ወጥ ለማድረግ፤ በዋና ምናሌው ውስጥ «የንድፍ ስርዓት ስቱዲዮ» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ የንድፍ ቶከኖችን ይጻፉ (ለምሳሌ jarak=8, huruf=16, sudut=12)፣ ክፍል ይምረጡ፣ ከዚያም «ክፍሎችን ይፍጠሩ» ን ይጫኑ። IDE ቶከኖቹን ያረጋግጣል — የመሠረት ርቀት 4 እስከ 16 dp፣ የመሠረት ቅርጸ-ቁምፊ 12 እስከ 20 sp፣ ማዕዘኖች 0 እስከ 32 dp፣ እና ዝቅተኛው የመንካት አካባቢ 48 dp — ከዚያም ለመጠቀም ዝግጁ የሆኑ የXML ክፍሎችን (komponen-studio.xml) ከXML ጭብጥ (tema-studio.xml) እና Compose ጭብጥ (tema-studio.kt) ጋር በፕሮጀክት ማህደር ውስጥ ይጽፋል። ቶከኖች በፕሮጀክቶች መካከል በተጋራ ቶከን ቤተ-መጽሐፍት ውስጥ እንደ ስም የተሰጠው ስብስብ ሊቀመጡ ይችላሉ፣ እና አንድ ነጠላ የማመሳሰል ትእዛዝ የቤተ-መጽሐፍቱን አዳዲስ ቶከኖች ያንን ስብስብ የሚጠቀሙ ሁሉንም ፕሮጀክቶች ላይ ይተገብራል። ክፍሎች በአቀማመጥ ውስጥ የሚለጠፍ እና ከዚያም በ«የጽሑፍ ዛፍ አቀማመጥ አርክቴክት» የሚረጋገጥ ጽሑፍ ሆነው ይፈጠራሉ፤ በጡባዊ ላይ ያለው ባለ ሁለት አምድ ማስተካከያ በሚሠራበት ጊዜ ከመሣሪያ መለያ ይልቅ የማያ ገጽ ስፋት ብቃትን ይጠቀማል።

የትርጉም መልሶ ማዋቀር እና የAST አሰስ
ትርጉሞችን ለማግኘት እና ምልክት ስሞችን ሌላ ኮድ በድንገት ተመሳሳይ ስም ያለው ሳይሰብሩ ለመቀየር፤ በዋና ምናሌው ውስጥ «የትርጉም መልሶ ማዋቀር እና የAST አሰስ» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ ከዚያም ሁሉንም ክፍሎች እና ዘዴዎች ከፋይሎቻቸው እና ከመስመር ቁጥሮቻቸው ጋር ለማየት «የፕሮጀክት ምልክቶችን ይቃኙ» ን ይጫኑ። የምልክቱን ስም ይተይቡ፣ ከዚያም ትርጉሙን እና የሚጠሩት ሁሉንም ፋይሎች ለማየት «የፕሮጀክት ምልክቶችን ይቃኙ» ን እንደገና ይጫኑ። ስም ለመቀየር፣ አዲሱን ስም ይተይቡ፣ በእያንዳንዱ ፋይል ውስጥ ያለውን ክስተት ቁጥር ለማየት «የስም መቀየር ቅድመ እይታ» ን ይጫኑ፣ ከዚያም «ስም መቀየር ተግብር» ን ይጫኑ። ማውጫው አሁን በእጅ የተሰራ AST መተንተኛ ይጠቀማል (ሌክሰር እና ተደጋጋሚ መተንተኛ ለJava እና Kotlin ንዑስ ስብስብ)፣ ስለዚህ በፋይሎች መካከል ያሉ የዘዴ ስም መቀየሮች ይፈታሉ እና በሌሎች ፋይሎች ውስጥ ያሉ ጠሪዎችም ይለወጣሉ፤ የኮድ እገዳን ወደ አዲስ ተግባር የማውጣት አዝራር አሁን በዚህ ማያ ገጽ ላይ ነው። ይህ መተንተኛ አሁንም አነስተኛ ነው፦ በጣም ውስብስብ ጄኔሪክስ፣ መለኪያ ያላቸው ማብራሪያዎች እና ስም የሌላቸው ክፍሎች እንደነበሩ ይቃኛሉ፣ የነጸብራቅ እና የበይነገጽ ጥሪዎች ግን አይፈቱም።

ደረጃ በደረጃ አራሚ እና የማህደረ ትውስታ መርማሪ

ስርዓቱ ሂደቱን ሲገድል፣ አውታረ መረቡ ሲቋረጥ፣ ማያ ገጹ ሲሽከረከር፣ ወይም የባትሪ ቁጠባ ሲበራ የመተግበሪያውን ጽናት ለመሞከር፤ በዋና ምናሌው ውስጥ «የከፋ የመሣሪያ ሁኔታ አስመሳይ እና የማህደረ ትውስታ ፍሳሽ ኦዲተር» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ ከዚያም «ማስመሰል ያሂዱ» ን ይጫኑ። IDE ከተመሰለ ማያ ገጽ ሽክርክር ጋር ሦስት የጭንቀት ሁኔታዎችን ያሂዳል እና ማያ ገጾቻቸው ከተዘጉ በኋላም በማህደረ ትውስታ ውስጥ የተያዙ ነገሮችን ይከታተላል፣ ከዚያም የጠፋ መረጃ እና የሚፈሱ የነገር ሰንሰለቶችን ሪፖርት ያደርጋል። የማስቀመጥ እና የማገገም ሁኔታ አሁን ከተጠቃሚው የራሱ ፕሮጀክት ምንጭ ነው የሚነበበው፣ ከቋሚ ምሳሌ አይደለም፤ የአካባቢ loopback አገልጋይ የአውታረ መረብ መቋረጥን ለመለካት በሙከራው መሃል በእውነት ይቆማል፤ እውነተኛ heap dump ይወሰዳል እና ይተነተናል፣ ሁለት dumps ይነጻጸራሉ እና የመያዝ ሰንሰለት ከGC ሥሮች ይከታተላል፤ እና የመተግበሪያው የራሱ ሂደት ሁኔታውን ካስቀመጠ በኋላ በእውነት ይገደላል፣ ከዚያም እንደገና ሲከፈት የትኛው መረጃ እንደሚመለስ ይረጋገጣል። ከተለመደ መተግበሪያ አሁንም የማይቻሉት፦ የስልክ ሬዲዮ ወይም Wi-Fi ማጥፋት እና ሌሎች መተግበሪያዎችን በግዳጅ ማቆም — ሁለቱም የስርዓት ፈቃድ ይጠይቃሉ፤ በምትኩ፣ የጀርባ መተግበሪያዎች በkillBackgroundProcesses ይገደላሉ፣ ፈቃዱ አስቀድሞ በማኒፌስቱ ውስጥ ነው፣ በማያ ገጽ ላይ ታማኝ መለያ ጋር።

የፕሮጀክት ንድፍ አርክቴክት
ትልቅ የመተግበሪያ ሀሳብ ወደ ደረጃ በደረጃ የሥራ እቅድ ለመቀየር፤ በዋና ምናሌው ውስጥ «የፕሮጀክት ንድፍ አርክቴክት» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ የመተግበሪያ ሀሳቡን ይጻፉ (ለምሳሌ በክፍያዎች ያለው ትንሽ የግሮሰሪ ሱቅ ካሺየር መተግበሪያ)፣ ከዚያም «ንድፍ ይፍጠሩ» ን ይጫኑ። IDE ሞጁሎችን፣ የፋይል ዝርዝር እና ትናንሽ ምዕራፎችን ይገነባል፣ ከዚያም እንደ cetak-biru.txt በፕሮጀክት ማህደር ውስጥ ያስቀምጣል። ምዕራፍ በተጠናቀቀ ቁጥር፣ «ቀጣዩን ምዕራፍ እንደተጠናቀቀ ምልክት ያድርጉ» ን ይጫኑ፣ ወይም የተቀመጠውን ንድፍ እንደገና ለመክፈት «የተቀመጠ ንድፍ ጫን» ን ይጫኑ። ንቁ AI አቅራቢ በ«የ AI ቅንብሮች» ውስጥ ከተመረጠ እና ቁልፉ ካለ፣ ንድፉ የሚገነባው በዚያ አቅራቢ ነው፤ ቁልፉ ከጠፋ ወይም አቅራቢው ሊደረስበት ካልቻለ፣ IDE ወደ ከመስመር ውጭ ቁልፍ ቃል ንድፎች ይመለሳል እና ይህን ገደብ በታማኝነት ይናገራል። የአቅራቢው መልስ ለቅርጸት ብቻ ይረጋገጣል (ሞጁሎች እና ምዕራፎች አሉ)፣ ለይዘት እውነት አይደለም — ከመገንባትዎ በፊት ሁልጊዜ ንድፉን ይገምግሙ።

መተግበሪያን በቀጥታ ከስልክ ወደ Google Play Store ለማዘጋጀት፤ በዋና ምናሌው ውስጥ «የመተግበሪያ ጥቅል ፋብሪካ እና የPlay Store ዝግጁነት» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ ከዚያም «የAAB ጥቅል ይገንቡ» ን ይጫኑ። IDE እውነተኛ BundleConfig.pb በመጠቀም ከፕሮጀክት ማኒፌስቶ፣ ሀብቶች እና ንብረቶች .aab ፋይል ይገነባል፣ የጥቅል መዋቅርን ያረጋግጣል፣ ከዚያም ጥቅሉን ወደ እውነተኛ ልዩነት APK ዎች (መሠረታዊ፣ በአርክቴክቸር፣ በቋንቋ፣ እና ሁለንተናዊ) ከዚያ ክፍፍል ከተለኩ መጠኖች ጋር ይከፍላል፣ ግምቶች አይደሉም። ጥቅሉ በተመሳሳይ የፕሮጀክት ቁልፍ በJAR v1 ይፈረማል፣ ይህም ለAPK ፊርማ ጥቅም ላይ ይውላል፣ እና የፊርማ ሰንሰለቱ በክሪፕቶግራፊ ይረጋገጣል። ይህ ማያ ገጽ የPlay ዝግጁነትን ይመረምራል — የዒላማ SDK ከ35 በታች ከሆነ «ከፍተኛ» ተብሎ ምልክት ይደረግበታል፣ ምክንያቱም Play Store 35 ወይም ከዚያ በላይ ይጠይቃል፣ እና የጠፋ 64-ቢት ቤተ-መጽሐፍትም «ከፍተኛ» ተብሎ ምልክት ይደረግበታል። እውነተኛ bundletool በመሣሪያው ላይ መሥራት አይችልም፣ ምክንያቱም bundletool JVM ይጠይቃል Android ግን JVM የለውም፤ ከላይ ያለው መንገድ በመሣሪያው ላይ በጣም ቅርብ እውነተኛ መንገድ ነው።

የOTA ማዘመኛ ሞተር እና ደረጃ በደረጃ ማውጫዎች
ተጠቃሚዎችን ሙሉ APK እንደገና እንዲያወርዱ ሳያስገድዱ ትንሽ ጥገና ለመላክ፤ በዋና ምናሌው ውስጥ «የOTA ማዘመኛ ሞተር እና ደረጃ በደረጃ ማውጫዎች» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ የድሮውን እና አዲሱን የስሪት ይዘት ይጻፉ፣ ከዚያም «የጥገና ጥቅል ይፍጠሩ» ን ይጫኑ። IDE ልዩነቱን ያሰላል እና አዲሱን ይዘት SHA-256 የጣት አሻራ ያለው የጥገና ጥቅል (patch-ota.zip) ይፈጥራል፣ ከዚያም ይህ መሣሪያ በመጀመሪያው 10 በመቶ የማውጫ ደረጃ ላይ መሆኑን ያረጋግጣል። ጥገናዎች አሁን በማንኛውም ፋይል ላይ ባይነሪ ዴልታ ይደግፋሉ (DEX እና APK ጨምሮ)፣ በRSA-2048 ፊርማ የታሸጉ ናቸው እና ከመተግበሩ በፊት በሚታመን የሕዝብ ቁልፍ ይረጋገጣሉ፣ እና ከገንቢው አገልጋይ ከማውጫ ዝርዝሩ ጋር ሊወርዱ ይችላሉ፤ መተግበር ከተሳካ፣ የድሮው ፋይል ሳይነካ ይቀራል። ጥገናን በሚሠራ መተግበሪያ ላይ መተግበር የሚደረገው በፕሮጀክት ቁልፍ እንደገና በመፈረም እና በPackageInstaller በኩል ነው፣ ምክንያቱም የሚሠራ ሂደት ኮድ ከራሱ ውስጥ መተካት የማይቻል ነው — APK ተቆልፏል እና DEX አስቀድሞ ተጭኗል።

የቡድን ኮድ ግምገማ ስቱዲዮ
የሥራ ባልደረባ ለውጦችን ለመገምገም እና የGit ቀስቶችን ሳያነቡ የመዋሃድ ግጭቶችን ለመፍታት፤ በዋና ምናሌው ውስጥ «የቡድን ኮድ ግምገማ ስቱዲዮ» ን ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ ሦስት የጽሑፍ ስሪቶችን ይተይቡ (መሠረታዊ፣ አካባቢያዊ፣ የሥራ ባልደረባ)፣ ከዚያም «የቡድን ግምገማ ይክፈቱ» ን ይጫኑ። IDE ሦስቱን በJava አገባብ ክፍሎች መሠረት ያዋህዳል — በተመሳሳይ መስመር ላይ ሁለት ለውጦች ግን በተለያዩ መግለጫዎች ውስጥ ከእንግዲህ ግጭት አይቆጠሩም — እና እያንዳንዱን ግጭት እንደ ድምጽ ምርጫ ያሳያል፦ የአካባቢ ስሪት ይጠቀሙ፣ የሥራ ባልደረባ ስሪት ይጠቀሙ፣ ወይም ሁለቱንም ያዋህዱ — የውጤት መስመር በመጀመሪያው የግጭት ቦታ ላይ ይገባል፣ ስለዚህ የመስመር ቅደም ተከተል ትክክለኛ ሆኖ ይቆያል — ከዚያም ውጤቱን ወደ gabung-hasil.txt በፕሮጀክቱ ውስጥ ይጽፋል። ከታች የፕሮጀክቱ የሥራ ሰሌዳ ነው፦ የሥራ ርዕስ ይተይቡ ከዚያም «ሥራ ይጨምሩ» ን ይጫኑ፤ ሥራዎች በፕሮጀክቱ ውስጥ ባለው .tugas ማህደር ውስጥ እንደ ጽሑፍ ይቀመጣሉ እና በመተግበሪያው ውስጥ ባለው Git ውስጥ በcommits ይመሳሰላሉ፣ ስለዚህ ሰሌዳው ከማንኛውም commit ታሪክ እንደገና ሊነበብ ይችላል። ይህ የአገባብ ክፍፍል ሙሉ AST መተንተኛ አይደለም እና በመተግበሪያው ውስጥ ያለው Git ለእያንዳንዱ commit ሙሉ ቅጽበታዊ ምስል ያስቀምጣል፤ የተለየ የማመሳሰል አገልጋይ የለም።

በአርታዒ ውስጥ በድምፅ ኮድ ለመጻፍ፡ ፕሮጀክት በአርታዒ ውስጥ ይክፈቱ፣ ከዚያ የኮድ መዋቅር መכתብ የሚለውን ቁልፍ ይንኩ። ትዕዛዞችን በኢንዶኔዥያኛ ይስጡ፣ ለምሳሌ buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil ወይም buat variabel teks nama sama dengan Budi — IDE ንግግሩን ወደ አገባብ ትክክለኛ የ Java፣ Kotlin፣ Python ወይም Compose ኮድ ብሎክ ይለውጣል እና በጠቋሚው ቦታ ላይ ያስገባዋል፣ ከዚያም አጭር ማጠቃለያ በ Jieshuo በኩል በድምፅ ያነባል። መכתብ የስርዓቱን ውስጠ-ገብ የድምፅ ግቤት አገልግሎት ይጠቀማል፣ ያለ ተጨማሪ የማይክሮፎን ፈቃድ፣ እና ቀድሞ የተመዘገቡ የትዕዛዝ ንድፎችን ብቻ ያውቃል፤ ከእነዚህ ንድፎች ውጪ ያለው ንግግር ወደ ኮድ አይቀየርም። እንደ ቃል የተነገሩ ቁጥሮች (ለምሳሌ 'lima') ገና ወደ አኃዝ አይቀየሩም።

የአካባቢ የትብብር ክፍል (ያለ ኢንተርኔት)
ኢንተርኔት ሳይኖር በአንድ ክፍል ውስጥ አብሮ ለመስራት፡ በዋና ምናሌ ላይ ትብብር የሚለውን ይክፈቱ፣ ከዚያ የአካባቢ የትብብር ክፍል ክፍሉን ይክፈቱ። አንድ ስልክ ክፍለ ጊዜ ይከፍታል (IDE የአካባቢ IP አድራሻ እና 6-አኃዝ PIN ያሳያል)፣ ሌላ ስልክ በዚያ አድራሻ እና PIN ይቀላቀላል። የጽሑፍ ለውጦች እንደ የመስመር ልዩነቶች ይላካሉ፣ የተገነባ APK ወደ ሞካሪው ስልክ ሊዘጋጅ ይችላል፣ እና ከሞካሪው ስልክ የብልሽት ሪፖርቶች ተመልሰው ይቀበላሉ። አንድ ክፍለ ጊዜ ለአንድ ጓደኛ ብቻ ነው፤ ሁለት ሰዎች በትክክል ተመሳሳይ መስመር በተመሳሳይ ጊዜ ከቀየሩ፣ የመጨረሻው ለውጥ ጥቅም ላይ ይውላል። PIN በአካባቢ ኔትወርክ ላይ እንደ ግልጽ ጽሑፍ ይላካል። ይህ ክፍል ገና በእውነተኛ ስልክ ላይ አልተሞከረም።

የ AI ቅንብሮች
መተግበሪያዎችን ለመገንባት AI አቅራቢ እና API ቁልፎችን ለማዘጋጀት፤ በዋና ምናሌው ውስጥ፣ በቅንብሮች ቡድን ውስጥ፣ «የ AI ቅንብሮች» ን ይጫኑ («አገናኝ» አዝራር አጠገብ)። ከሚገኙ ዝርዝር ውስጥ የሚጠቀሙበትን አቅራቢ ይምረጡ፣ እና ሞዴል ከተሳካ IDE በራስ-ሰር ከተመሳሳይ አቅራቢ ቀጣዩን ሞዴል እንዲሞክር «አቅራቢ ሲሳሳት ሞዴል ቀይር» ን ምልክት ያድርጉ። የመጠባበቂያ ቁልፎችን ለመጨመር «የ API ቁልፎችን አስተዳድር» ን ይጫኑ (ስም እና ቁልፍ ይተይቡ፣ ከዚያም «አስቀምጥ» ን ይጫኑ፤ ቁልፎች ተሸፍነው ይታያሉ፣ የመጨረሻዎቹ 4 ቁምፊዎች ብቻ ይታያሉ)። ቁልፎች በስልኩ ላይ ይቀመጣሉ እና መተግበሪያን ሲገነቡ ወደ ተመረጠው አቅራቢ በስተቀር ወደ ሌላ ቦታ በፍጹም አይላኩም። የተመረጠው አቅራቢ አሁን በእውነት በ«የፕሮጀክት ንድፍ አርክቴክት» እና «የኮድ አመክንዮ ፍሰት ተራኪ» ጥቅም ላይ ይውላል፤ በ«የ AI መተግበሪያ ፈጣሪ» ማያ ገጽ ላይ መተግበሪያ መገንባት አሁንም በስልኩ ላይ ያለውን የአካባቢ AI ይጠቀማል (ኢንተርኔት ሳይጠቀም)።

አገናኝ
APK ለመተንተን እና ከዚያ ለመላክ፡ በዋና ምናሌ ላይ፣ በ ቅንብሮች ቡድን ውስጥ፣ አገናኝ የሚለውን ይንኩ (የ AI ቅንብሮች ቁልፉ አጠገብ)። ከስልኩ APK ፋይል ይምረጡ፣ IDE ይዘቱን ያነባል (የጥቅል ስም፣ ስሪት፣ የእንቅስቃሴዎች ዝርዝር) እና ከዚያ APK ላክ የሚለውን ይንኩ በስርዓት ማጋሪያ ምናሌ በኩል ለመላክ (ለምሳሌ WhatsApp ወይም Drive)።

ቋንቋ እና ድምጽ
የመተግበሪያውን ቋንቋ ለመቀየር፡ ቅንብሮች የሚለውን ይክፈቱ፣ ከዚያ የመተግበሪያ ቋንቋ የሚለውን፣ ከዚያም ቋንቋ ይምረጡ ወይም ስርዓቱን ተከተል የሚለውን ይምረጡ። ዋና ማያ ገጹ እና አብዛኞቹ ማያ ገጾች መተግበሪያውን ሳይዘጉ ወይም እንደገና ሳያስጀምሩ ወዲያውኑ ወደ የተመረጠው ቋንቋ ይቀየራሉ፤ አንዳንድ ማያ ገጾች (ለምሳሌ Terminal፣ ትብብር፣ የ AI ቅንብሮች እና ቁልፎችን አስተዳድር) እንደገና እስኪከፈቱ ድረስ አሁንም የድሮውን ቋንቋ ይጠቀማሉ። ስርዓቱን ተከተል የሚለውን ከመረጡ፣ ቋንቋው የስልኩን የስርዓት ቋንቋ ይከተላል።

በፕሮጀክት ነባሪ ፊርማ እና Anti Tamper
ከስሪት 5.7 ጀምሮ፣ የግል ፊርማ የማይጠቀም ፕሮጀክት በፕሮጀክቱ የራሱ አብሮገነብ ቁልፍ ይፈርማል (አንድ ጊዜ በፕሮጀክቱ ውስጥ ባለው tanda-tangan-bawaan አቃፊ ውስጥ ተፈጥሮ ከዚያም ቀጥሎ ጥቅም ላይ ይውላል)፣ ስለዚህ አብሮገነብ ፊርማ ከፕሮጀክት ወደ ፕሮጀክት ይለያል — ከአሁን በኋላ ለሁሉም መተግበሪያዎች የተጋራ ቁልፍ አይደለም። tanda-tangan-bawaan አቃፊን አያስወግዱ: ያለዚያ ቁልፍ፣ አዲስ APK ለተመሳሳይ ፕሮጀክት የድሮውን APK መተካት አይችልም። የእያንዳንዱ ፕሮጀክት ቅንብሮች (ተለይቶ የቀረበ አርክቴክቸር፣ የግል ፊርማ፣ Anti Tamper፣ የተመረጠ keystore፣ SDK) አሁን በፕሮጀክቱ ውስጥ ባለው settings.gradle ፋይል ውስጥ ይቀመጣሉ እና ፕሮጀክቱ በተገነባ ቁጥር እንደገና ይነበባሉ። በቅንብሮች፣ በፊርማ ምድብ ውስጥ፣ ለተገነባ መተግበሪያ Anti Tamper ማረጋገጫ ሳጥን አለ: ንቁ ከሆነ፣ የተገነባው መተግበሪያ በመሳሪያው ላይ ፊርማውን እና የ dex ይዘቱን በተከፈተ ቁጥር ይፈትሻል; በሌላ ሰው እንደገና ከተፈረመ ወይም ከተለወጠ፣ መተግበሪያው መሄድ እምቢ ይላል። እንደ Frida/Xposed ያሉ የማረም እና የመርፌ መሳሪያዎችም ይታወቃሉ፣ እና የመተግበሪያው መስኮት ከማያ ቀረጻ ተቆልፏል።

የዴሞ ቪዲዮ ሰሪ
የተገነባ መተግበሪያ የዴሞ ቪዲዮ ለመፍጠር: በዋና ምናሌ ውስጥ የዴሞ ቪዲዮ ሰሪ ይክፈቱ፣ ፕሮጀክቱን ይምረጡ፣ የቪዲዮውን ርዕስ ይሙሉ እና ከዚያ የማሳያ ቪዲዮ ስክሪፕት ፍጠር ይጫኑ — IDE video-demo.txt ን በ 5 መደበኛ ትዕይንቶች (መክፈቻ፣ ዋና እይታ፣ ተግባር 1፣ ተግባር 2፣ መዝጊያ) ከትረካ ጽሑፍ እና የእያንዳንዱ ትዕይንት ቆይታ ጋር ይጽፋል። ከፕሮጀክቱ ምስሎች (አዶ + የማያ ቅጽበቶች ካሉ) video-demo.html ለመፍጠር የ HTML Slideshow ፍጠር ይጫኑ በየ 5 ሰከንዶች በራስ-ሰር የሚለዋወጡ። ይህ .mp4 ቪዲዮ አይደለም — ለእውነተኛ ቪዲዮ፣ video-demo.html በስልኩ አሳሽ ውስጥ ይክፈቱ እና ከዚያ ማያውን ይቅረጹ፣ ወይም በሚሄድበት መተግበሪያ ሲቀርጹ በ video-demo.txt ውስጥ ያለውን ትረካ ያንብቡ።

የ IDE መልክ አሁን እንደ Android Studio ተስተካክሏል (መልክ ብቻ — ሁሉም አዝራሮች፣ ምናሌዎች እና ፍሰቶች በትክክል እንደቀድሞው ይቆያሉ): ቀላል ግራጫ ዳራ፣ ደማቅ ጥቁር የማያ ርዕሶች፣ ሰማያዊ አዝራሮች ከነጭ ጽሑፍ ጋር እና ነጭ የግቤት ሳጥኖች ከቀጭን ክፈፍ ጋር። ዋና ምናሌው በእይታ ተቧድኗል (የፈጣሪ ተግባራት፣ ደመና፣ ገጽታ እና ሌሎች፣ ድምጽ፣ ኮድ እና አዳዲስ ተግባራት፣ መሳሪያዎች) የአዝራሮችን ቅደም ተከተል ሳይለውጥ። Terminal አሁንም ጨለማ ፓነል ይጠቀማል እንደ Terminal መስኮት በ Android Studio፣ እና የኮድ አርታኢ አሁንም ነጭ ዳራ እና ጥቁር ጽሑፍ አለው። ሁሉም ጽሑፍ አሁንም በ Jieshuo በግልጽ ይነበባል።

ቅንብሮች
መተግበሪያውን ለማዘጋጀት: በዋና ማያ ላይ ያለውን የአማራጮች ምናሌ ይክፈቱ እና ከዚያ ቅንብሮች ይጫኑ። በውስጡ 12 ምድቦች አሉ: የGitHub ቅንብሮች (ደህንነት፣ የግል ፊርማ፣ የግንባታ ታሪክ እና የ GitHub ቶከን)፣ በመሳሪያ ላይ የ APK ግንባታ ቅንብሮች (የ keystore የይለፍ ቃል እና የግንባታ ታሪክ በመሳሪያ ላይ ማስቀመጥ)፣ ገጽታ (የመተግበሪያ ቀለም)፣ ፊርማ (ለግል ፊርማ keystore መፍጠር እና ለተገነባ መተግበሪያ Anti Tamper ማረጋገጫ ሳጥን)፣ የፕሮጀክት አቃፊ (የፕሮጀክት አቃፊ ቦታ)፣ ቋንቋ እና ድምጽ (የበይነገጽ ቋንቋ እና የድምጽ ሁነታ ንግግር ፍጥነት)፣ የጽሑፍ መጠን እና መልክ (የአርታኢ የፊደል መጠን)፣ ግንባታ (ነባሪ የዒላማ SDK እና ለፕሮጀክት ፍጠር ማያ ነባሪ የአርክቴክቸር ክፍፍል)፣ ማሳወቂያዎች (ግንባታ ሲጠናቀቅ ድምጽ)፣ ራስ-ሰር ምትኬ (የፕሮጀክት ምትኬ መርሃ ግብር)፣ የአዘጋጅ መገለጫ (ስም፣ የ WhatsApp ቁጥር እና በለገስ ማያ ላይ የሚታይ መለያ) እና ግላዊነት እና ውሂብ (ቅንብሮችን ዳግም ማስጀመር እና የመተግበሪያ ውሂብ መሰረዝ)። እያንዳንዱ ምድብ ወደ ቀዳሚው ማያ ተመለስ አዝራር አለው ወደ ምድብ ምናሌ ለመመለስ። አሁን የተቀመጡ ቅንብሮች (ገና ያልተተገበሩ) በማያ ገጽ ላይ በታማኝነት ይገለጻሉ።

ለገንቢው ለግሱ
ለገንቢው ለመለገስ ወይም ሰላም ለመስጠት: በዋና ማያ ላይ፣ ስለ መሳሪያው አዝራር አጠገብ ያለውን ለገንቢው ለግሱ አዝራር ይጫኑ። በለገስ ማያ ላይ የ BRI መለያ ቅዳ አዝራር አለ — የአዘጋጁን የመለያ ቁጥር ለመቅዳት ይጫኑት እና ከዚያ ወደ ባንክ መተግበሪያዎ ይለጥፉት። ገንቢውን በ WhatsApp ላይ ሰላም በል ክፍልም አለ: ስምዎን እና የትውልድ ከተማዎን ይሙሉ እና ከዚያ በ WhatsApp ላይ ላክ ይጫኑ — WhatsApp በሰላም መልእክት ቀድሞውኑ ተሞልቶ ይከፈታል፣ በ WhatsApp ላይ ላክ ብቻ ይጫኑ እና ከዚያ ወደ መተግበሪያው ይመለሱ። WhatsApp ሌሎች መተግበሪያዎች መልእክቶችን በራስ-ሰር እንዲልኩ አይፈቅድም፣ ስለዚህ መላኩ አሁንም በ WhatsApp ውስጥ እርስዎ እራስዎ ይደረጋል።

የ Terminal ተወዳጅ ትዕዛዞች
በ Terminal ውስጥ ብዙ ጊዜ ጥቅም ላይ የሚውሉ ትእዛዞችን ለማስቀመጥ: Terminal ይክፈቱ እና ከዚያ ተወዳጆች ይጫኑ። አዲስ ተወዳጅ ጨምር ይጫኑ፣ ስም (ለምሳሌ ፋይል ይመልከቱ) እና ትእዛዙን (ለምሳሌ ls -la) ይሙሉ እና ከዚያ አስቀምጥ ይጫኑ — ተወዳጁ በስልኩ ላይ በቋሚነት ይቀመጣል። በ terminal ውስጥ በቀጥታ ለማሄድ የተወዳጁን ስም ይጫኑ; ተወዳጅ ሰርዝ ይጫኑ እና ከዚያ ለመሰረዝ አንዱን ይምረጡ (በማረጋገጫ)። ቀድሞውኑ 3 አብሮገነብ ተወዳጆች አሉ: ፋይል ይመልከቱ (ls -la)፣ ቦታ ይፈትሹ (df -h) እና ማያ ገጽ አጽዳ (clear) — ሁሉም ሊሰረዙ ይችላሉ። ባዶ ትእዛዝ ሊቀመጥም ሆነ ሊሄድም አይችልም; Terminal በመልእክት እና በድምጽ ያሳውቅዎታል ይህ ከተከሰተ።

ትንታኔ እና ጥራት
የመተግበሪያ አጠቃቀም እና የብልሽት ሪፖርቶች ማጠቃለያ ለማየት: በዋና ማያ ላይ፣ ለገንቢው ለግሱ አዝራር አጠገብ ያለውን ትንታኔ እና ጥራት አዝራር ይጫኑ። ይህ ማያ መተግበሪያው ስንት ጊዜ እንደተከፈተ፣ የትኞቹ ማያዎች ብዙ ጊዜ እንደሚከፈቱ፣ የብልሽቶች ብዛት እና የቅርብ ጊዜ ብልሽቶች ዝርዝር ከአጭር የማስተካከያ ሀሳቦች ጋር ያሳያል። ይህ ውሂብ በስልክዎ ላይ ብቻ ይቀመጣል እና ወደምንም ቦታ አይላክም። ሁሉንም ይህን ውሂብ ለመሰረዝ የማረጋገጫ ንግግር ያለው የትንታኔ ውሂብ ሰርዝ አዝራር አለ። የቅርብ ጊዜ ማያ የሚመዘገበው ለዋና ማያ እና ለዚህ ማያ ብቻ ነው።

መደምደሚያ
Create Aplikasi ን ስለተጠቀሙ እናመሰግናለን። ይህ መሳሪያ እርስዎን እና ከስልክ Android መተግበሪያዎችን መፍጠር መማር የሚፈልጉትን ሁሉ እንደሚረዳ ተስፋ እናደርጋለን። ችግሮች ከተከሰቱ፣ ከዚህ መመሪያ ደረጃ በደረጃ ያስተካክሏቸው እና እንደገና ለመሞከር አያመንቱ።
