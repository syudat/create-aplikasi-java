Καλώς ήρθατε στο Create Aplikasi by Al Kautsar
Το Create Aplikasi είναι μια εφαρμογή δημιουργίας εφαρμογών Android που λειτουργεί απευθείας στο τηλέφωνο, χωρίς να χρειάζεται φορητός υπολογιστής. Αυτή η εφαρμογή επιτρέπει σε οποιονδήποτε να δημιουργήσει τη δική του εφαρμογή Android, συμπεριλαμβανομένων των χρηστών που μόλις μαθαίνουν να δημιουργούν εφαρμογές και των χρηστών προγραμμάτων ανάγνωσης οθόνης. Ο πλήρης οδηγός χρήσης αυτής της εφαρμογής είναι διαθέσιμος σε αυτήν την οθόνη Tentang Alat.

Τι είναι αυτή η εφαρμογή και για ποιους προορίζεται
Το Create Aplikasi είναι ένα εργαλείο δημιουργίας εφαρμογών Android που λειτουργεί στο τηλέφωνο. Αυτή η εφαρμογή απευθύνεται σε όποιον θέλει να δημιουργήσει τη δική του εφαρμογή Android, συμπεριλαμβανομένων των αρχαρίων και των χρηστών προγραμμάτων ανάγνωσης οθόνης. Αυτή η εφαρμογή παρέχει έναν επεξεργαστή κώδικα, ένα κουμπί Jalankan για τη δοκιμή έργων, ένα κουμπί Bangun για τη δημιουργία APK, καθώς και μενού για την υπογραφή και την εγκατάσταση του APK.

Ο σκοπός αυτής της εφαρμογής
Αυτή η εφαρμογή δημιουργήθηκε ώστε ο καθένας να μπορεί να δημιουργήσει εύκολα τη δική του εφαρμογή Android, απευθείας από το τηλέφωνο. Η εμφάνισή της έγινε όσο το δυνατόν πιο απλή, ώστε ακόμη και οι νέοι χρήστες να μπορούν να τη δοκιμάσουν αμέσως.

Πώς να δημιουργήσετε ένα νέο έργο, βήμα προς βήμα
1. Πατήστε Buat Project στο κύριο μενού.
2. Επιλέξτε τον τύπο έργου: HTML, Situs Web, Java, Kotlin, Compose ή Python.
3. Συμπληρώστε το όνομα της εφαρμογής, παράδειγμα: Garuda Decode.
4. Συμπληρώστε το όνομα του πακέτου (package name), παράδειγμα: com.android.garudadecode. Το όνομα του πακέτου πρέπει να χρησιμοποιεί πεζά γράμματα και να αποτελείται από τουλάχιστον δύο μέρη που χωρίζονται με τελεία.
5. Συμπληρώστε την έκδοση της εφαρμογής, παράδειγμα: 1.0, και τον κωδικό έκδοσης ως αριθμό, παράδειγμα: 1. Εάν αφεθεί κενό, η έκδοση θα συμπληρωθεί αυτόματα με 1.0 και ο κωδικός έκδοσης με 1.
6. Συμπληρώστε το ελάχιστο SDK και το SDK στόχου, εάν χρειάζεται. Εάν αφεθούν κενά, θα χρησιμοποιηθούν οι προεπιλεγμένες τιμές. Το ελάχιστο SDK είναι η χαμηλότερη υποστηριζόμενη έκδοση Android, παράδειγμα: το 21 σημαίνει Android 5.0. Το μέγιστο SDK στόχου είναι 36 (Android 16).
7. Πατήστε το κουμπί Pilih Izin για να επιλέξετε τα δικαιώματα της εφαρμογής, παράδειγμα: INTERNET. Το δικαίωμα INTERNET είναι επιλεγμένο από προεπιλογή. Επιλέξτε μόνο τα δικαιώματα που πραγματικά χρειάζεται η εφαρμογή.
8. Εάν το επιθυμείτε, επιλέξτε "Gunakan arsitektur terpisah 64 bit dan 32 bit" ώστε το μέγεθος του APK να είναι μικρότερο, και επιλέξτε "Gunakan tanda tangan pribadi" εάν θέλετε να χρησιμοποιήσετε ένα keystore που φτιάξατε εσείς.
9. Πατήστε Buat Proyek. Το νέο έργο αποθηκεύεται στον φάκελο Download/project και εμφανίζεται αμέσως στο Kelola Project.

Διαθέσιμοι τύποι έργων
• HTML: προβολή από τα index.html, style.css και script.js, λειτουργεί μέσω WebView. Δημιουργείται απευθείας στο τηλέφωνο.
• Situs Web: ιστότοπος με μενού (Beranda, Tentang, Kontak) από τα index.html, tentang.html, kontak.html, style.css και script.js, λειτουργεί μέσω WebView. Δημιουργείται απευθείας στο τηλέφωνο.
• Java: δημιουργείται στο τηλέφωνο. Το MainActivity βρίσκεται στο app/src/main/java/<nama-paket>/MainActivity.java. Η προβολή προέρχεται από το app/src/main/res/layout/activity_main.xml, το κείμενο από το app/src/main/res/values/strings.xml και το θέμα από το app/src/main/res/values/styles.xml.
• Kotlin: μπορεί να δημιουργηθεί στη συσκευή (εκτός σύνδεσης) χρησιμοποιώντας τον μεταγλωττιστή Kotlin που περιλαμβάνεται στην εφαρμογή, ή μέσω GitHub Actions. Το MainActivity βρίσκεται στο app/src/main/java/<nama-paket>/MainActivity.kt, και τα αρχεία res είναι τα ίδια όπως σε ένα έργο Java. Η πρώτη δημιουργία Kotlin είναι πιο αργή λόγω του μεγάλου μεγέθους του μεταγλωττιστή, και τα αρχεία .java που αναφέρονται σε κλάσεις Kotlin δεν μπορούν ακόμη να δημιουργηθούν (τα αρχεία .java μεταγλωττίζονται πριν από τα αρχεία .kt).
• Compose: μια σύγχρονη εφαρμογή Android της οποίας η διεπαφή δημιουργείται με το Jetpack Compose (όχι με διάταξη XML). Το MainActivity βρίσκεται στο app/src/main/java/<nama-paket>/MainActivity.kt. Τα έργα Compose δημιουργούνται μέσω GitHub Actions (μενού Bangun proyek, έπειτα Bangun online) ή στο Termux με Gradle, επειδή το Compose απαιτεί τις βιβλιοθήκες Jetpack Compose που δεν είναι διαθέσιμες στη συσκευή.
• Python: η λογική της εφαρμογής γράφεται σε Python (Chaquopy) στο app/src/main/python/main.py και εκτελείται από τον κεντρικό υπολογιστή MainActivity.java στο app/src/main/java/<nama-paket>/MainActivity.java. Τα έργα Python μπορούν να δημιουργηθούν απευθείας στο τηλέφωνο (ο χρόνος εκτέλεσης Chaquopy περιλαμβάνεται στην εφαρμογή) ή μέσω GitHub Actions. Το ελάχιστο SDK για έργα Python είναι 24 (Android 7.0).

Δομή αρχείων έργων Java, HTML, Situs Web, Kotlin, Compose και Python
Τα έργα Java, HTML, Situs Web, Kotlin, Compose και Python είναι οργανωμένα όπως τα έργα Android γενικά. Μέσα στον φάκελο app υπάρχει ο φάκελος src, και μέσα σε αυτόν υπάρχει ο φάκελος main. Μέσα στον φάκελο main υπάρχει το AndroidManifest.xml δίπλα στον φάκελο java, ο φάκελος res που περιέχει τα layout/activity_main.xml και values/strings.xml καθώς και values/styles.xml, και για τα HTML και Situs Web υπάρχει ο φάκελος assets που περιέχει το index.html (το Situs Web έχει επίσης τα tentang.html και kontak.html). Τα έργα HTML και Situs Web έχουν επίσης το δικό τους MainActivity στο app/src/main/java/<nama-paket>/MainActivity.java, το οποίο φορτώνει το index.html στο WebView και γίνεται ο εκκινητής (launcher) στο AndroidManifest. Τα έργα Python έχουν κώδικα Python στο app/src/main/python/main.py και τον κεντρικό υπολογιστή MainActivity.java στο app/src/main/java/<nama-paket>/MainActivity.java. Τα AndroidManifest.xml, διάταξη, strings και styles μπορούν να ανοιχτούν και να τροποποιηθούν στον επεξεργαστή, όπως και το MainActivity. Τα παλαιότερα έργα των οποίων το manifest βρίσκεται ακόμη δίπλα στον φάκελο app μπορούν ακόμη να δημιουργηθούν, επειδή κατά τη δημιουργία η εφαρμογή ελέγχει πρώτα το AndroidManifest.xml στο app/src/main/, έπειτα αυτό που βρίσκεται δίπλα στον φάκελο app, και τέλος το αρχείο δεδομένων του έργου.

Κανόνες δικαιωμάτων (σημαντικό)
Τα δικαιώματα που επιλέγονται κατά τη δημιουργία ενός έργου καταγράφονται μόνο σε ένα μέρος, ανάλογα με τον τύπο του έργου. Για έργα Java, HTML, Situs Web, Kotlin, Compose και Python, τα επιλεγμένα δικαιώματα καταγράφονται ΜΟΝΟ στο AndroidManifest.xml που βρίσκεται στο app/src/main/, δίπλα στον φάκελο java, μέσα στον φάκελο του έργου. Το αρχείο δεδομένων έργου για έργα Java, HTML, Situs Web, Kotlin, Compose και Python δεν περιέχει λίστα δικαιωμάτων. Εάν επιλέξετε Java και στη συνέχεια επιλέξετε INTERNET και CAMERA, αυτά που καταγράφονται στο AndroidManifest.xml είναι μόνο τα INTERNET και CAMERA, χωρίς να συνοδεύονται από άλλα δικαιώματα. Κατά τη δημιουργία, η εφαρμογή διαβάζει τα δικαιώματα από το ίδιο μέρος: από το AndroidManifest.xml στο app/src/main/ για έργα Java, HTML, Situs Web, Kotlin, Compose και Python (εάν δεν υπάρχει, από το AndroidManifest.xml δίπλα στον φάκελο app για παλαιότερα έργα), και από το αρχείο δεδομένων έργου για παλαιότερα έργα.

Πώς να χρησιμοποιήσετε τον επεξεργαστή
Ανοίξτε το Kelola Project, πατήστε το όνομα ενός έργου για να ανοίξετε τον επεξεργαστή. Στον επεξεργαστή, τα αρχεία μπορούν να ανοιχτούν, ο κώδικας μπορεί να γραφτεί και οι αλλαγές μπορούν να αποθηκευτούν. Για έργα Java, HTML, Situs Web, Kotlin, Compose και Python, τα αρχεία βρίσκονται μέσα στον φάκελο app/src/main. Για να μοιραστείτε ένα έργο, χρησιμοποιήστε το Ekspor ZIP (δείτε την ενότητα παρακάτω).

Πώς να εκτελέσετε ένα έργο
Στον επεξεργαστή, πατήστε Jalankan για να δοκιμάσετε το έργο. Για έργα HTML και Situs Web, αυτό που εκτελείται είναι το index.html μέσω WebView. Εάν παρουσιαστεί σφάλμα, διαβάστε το μήνυμα σφάλματος, διορθώστε τον κώδικα και εκτελέστε ξανά.

Πώς να δημιουργήσετε ένα APK
Στον επεξεργαστή, πατήστε Bangun. Υπάρχουν δύο τρόποι δημιουργίας. Πρώτον, Bangun di perangkat: δημιουργεί απευθείας στο τηλέφωνο χωρίς διαδίκτυο, για έργα HTML, Situs Web, Java, Kotlin και Python. Δεύτερον, Bangun online μέσω GitHub Actions: δημιουργεί μέσω διαδικτύου στο GitHub και μπορεί να χρησιμοποιηθεί για όλους τους τύπους έργων. Τα έργα Compose μπορούν να δημιουργηθούν μόνο με τον δεύτερο τρόπο (Bangun online) ή στο Termux με Gradle, επειδή το Compose απαιτεί τις βιβλιοθήκες Jetpack Compose που δεν είναι διαθέσιμες στη συσκευή. Το αποτέλεσμα της πρώτης δημιουργίας δεν είναι ακόμη υπογεγραμμένο. Στη συνέχεια η εφαρμογή το υπογράφει: αυτόματα με το προεπιλεγμένο κλειδί ή με προσωπική υπογραφή, εάν το πλαίσιο "Gunakan tanda tangan pribadi" ήταν επιλεγμένο κατά τη δημιουργία του έργου.

Πώς να εγκαταστήσετε ένα APK
Όταν το APK είναι έτοιμο, πατήστε Pasang για να το εγκαταστήσετε. Σε Android 8 και νεότερες εκδόσεις, το τηλέφωνο θα ζητήσει πρώτα το "Izinkan dari sumber ini", επειδή αυτή η εφαρμογή εγκαθιστά APK εκτός του Play Store. Ενεργοποιήστε αυτό το δικαίωμα μία φορά στις Ρυθμίσεις και, στη συνέχεια, επιστρέψτε στην εφαρμογή: η εγκατάσταση θα συνεχιστεί αυτόματα χωρίς να χρειαστεί να πατήσετε ξανά Pasang. Εάν το κουμπί Pasang δεν εμφανίζεται, βεβαιωθείτε ότι η δημιουργία έχει ολοκληρωθεί και ότι το APK έχει δημιουργηθεί.

Πώς να υπογράψετε μια εφαρμογή
Κάθε APK πρέπει να υπογράφεται για να μπορεί να εγκατασταθεί. Υπάρχουν δύο επιλογές. Πρώτον, το προεπιλεγμένο κλειδί: η εφαρμογή υπογράφει μόνη της αυτόματα, χωρίς να χρειάζεται να κάνετε τίποτα. Δεύτερον, η προσωπική υπογραφή: δημιουργήστε πρώτα ένα keystore μέσω του μενού Buat Keystore στο κύριο μενού, φυλάξτε καλά τον κωδικό πρόσβασής του και, στη συνέχεια, επιλέξτε "Gunakan tanda tangan pribadi" κατά τη δημιουργία ενός έργου. Το keystore αποθηκεύεται στο Download/project/signing.

Εξαγωγή έργου ως ZIP
Το Ekspor ZIP παρέχεται ώστε τα έργα να μπορούν να μοιραστούν σε φίλους. Ο τρόπος: στο Kelola Project, πατήστε παρατεταμένα το όνομα ενός έργου και, στη συνέχεια, επιλέξτε Ekspor ZIP. Το αποτέλεσμα αποθηκεύεται στο Download/project/<NamaProyek>.zip. Ο φάκελος bin δεν περιλαμβάνεται, οπότε το μέγεθος είναι μικρό, μόνο μερικές δεκάδες KB. Το αρχείο ZIP μπορεί να σταλεί σε έναν φίλο ή να ανεβεί στο GitHub.

Ekstensi JAWS
Το Ekstensi JAWS χρησιμοποιεί τη μηχανή επέκτασης του Jieshuo (CSR), όχι το πρόγραμμα ανάγνωσης οθόνης του. Με αυτόν τον τρόπο, ο σχεδιασμός μπορεί να συνεχίσει να λειτουργεί ακόμη και αν ο χρήστης χρησιμοποιεί το TalkBack. Ο τρόπος: ανοίξτε το Ekstensi JAWS στο κύριο μενού. Επειδή τα αυτόματα κλικ λειτουργούν από μόνα τους, η υπηρεσία πρέπει πρώτα να ενεργοποιηθεί στις Ρυθμίσεις προσβασιμότητας. Μετά από αυτό, μπορεί να δημιουργηθεί ένας νέος σχεδιασμός: πληκτρολογήστε το όνομα του σχεδιασμού, πατήστε OK και, στη συνέχεια, συμπληρώστε τα πλαίσιά του.

Το Daftar Klik διαχωρίζεται για να είναι τακτοποιημένο
Μέσα στον σχεδιασμό υπάρχουν δύο πλαίσια: το πλαίσιο σεναρίου και το πλαίσιο Daftar Klik. Η λίστα κουμπιών αποθηκεύεται ξεχωριστά στο αρχείο daftar_klik.txt, ένα όνομα ανά γραμμή. Παράδειγμα περιεχομένου: tombolSimpan, tombolHapus, tombolBuka. Για να ανοίξετε μια εφαρμογή, απλώς γράψτε >WhatsApp σε αυτήν τη λίστα. Οι παλαιότεροι σχεδιασμοί που δεν έχουν ακόμη αρχείο daftar_klik.txt θα εμφανίσουν αυτό το προεπιλεγμένο παράδειγμα.

Απλές λειτουργίες που παρέχονται
• klikTombol("tombolSimpan") — κάνει κλικ σε ένα κουμπί με βάση το κείμενό του.
• klikDaftarTombol(daftar) — κάνει κλικ στη λίστα στο daftar_klik.txt, ένα κουμπί ανά γραμμή, με τη σειρά, και στη συνέχεια αναφέρει πόσα πέτυχαν και πόσα δεν βρέθηκαν.
• bukaAplikasi("WhatsApp") — ανοίγει μια εφαρμογή με βάση το όνομά της, ή γράψτε ">WhatsApp" στη λίστα.
• klik(540, 1200) — κάνει κλικ σε συντεταγμένες οθόνης.
Όλες οι λειτουργίες έχουν γίνει απλές αρχικά. Αφού εξοικειωθείτε, μπορούν να προστεθούν επιπλέον λειτουργίες αργότερα.

Σχετικά με τα προγράμματα ανάγνωσης οθόνης
Αυτή η εφαρμογή έχει σχεδιαστεί ώστε να είναι φιλική προς τα προγράμματα ανάγνωσης οθόνης. Κάθε πεδίο συμπλήρωσης έχει μια ετικέτα και ένα παράδειγμα συμπλήρωσης, και όλα τα κουμπιά είναι προσβάσιμα χωρίς περίπλοκες χειρονομίες. Το Ekstensi JAWS έχει δημιουργηθεί ώστε να συνεχίζει να λειτουργεί ακόμη και αν ο χρήστης χρησιμοποιεί το TalkBack, επειδή αυτό που χρησιμοποιείται είναι η μηχανή επέκτασής του, όχι το πρόγραμμα ανάγνωσης οθόνης του.

Απόρρητο και ασφάλεια
Τα έργα και τα keystore αποθηκεύονται στο τηλέφωνό σας. Το διακριτικό (token) του GitHub χρησιμοποιείται μόνο για διαδικτυακές δημιουργίες και αποθηκεύεται μέσα σε αυτήν την εφαρμογή. Μην μοιράζεστε το διακριτικό σας ή τον κωδικό πρόσβασης του keystore σας με κανέναν. Εάν χρησιμοποιείτε προσωπική υπογραφή, φυλάξτε το keystore και τον κωδικό πρόσβασής του σε ασφαλές μέρος, επειδή εάν χαθούν, το παλιό APK δεν μπορεί να ενημερωθεί με την ίδια υπογραφή.

Απαιτήσεις
Android 5.0 ή νεότερο. Δικαίωμα αποθήκευσης: στο Android 11 και νεότερες εκδόσεις χρησιμοποιείται το δικαίωμα πρόσβασης σε όλα τα αρχεία, στο Android 10 και παλαιότερες εκδόσεις χρησιμοποιείται το συνηθισμένο δικαίωμα αποθήκευσης (ανάγνωση/εγγραφή αποθήκευσης), επειδή το Android 10 δεν διαθέτει δικαίωμα πρόσβασης σε όλα τα αρχεία. Η δημιουργία στη συσκευή απαιτεί τηλέφωνο με επεξεργαστή ARM (32 ή 64 bit). Η διαδικτυακή δημιουργία μέσω GitHub Actions απαιτεί διαδίκτυο και ένα διακριτικό GitHub. Τα έργα Kotlin μπορούν να δημιουργηθούν στη συσκευή, αλλά η πρώτη τους δημιουργία είναι πιο αργή και χρησιμοποιεί περισσότερη μνήμη λόγω του μεγάλου μεγέθους του μεταγλωττιστή Kotlin. Τα έργα Compose δημιουργούνται μέσω GitHub Actions ή στο Termux με Gradle. Τα έργα Python απαιτούν Android 7.0 ή νεότερο (ελάχιστο SDK 24), και το παραγόμενο APK είναι μεγαλύτερο επειδή περιλαμβάνει τον χρόνο εκτέλεσης της Python (Chaquopy) μαζί με την τυπική βιβλιοθήκη της.

Terminal
Το μενού Terminal στην αρχική οθόνη ανοίγει ένα τερματικό μέσα σε αυτήν την εφαρμογή. Εντολές όπως ls μπορούν να χρησιμοποιηθούν για να δείτε τα περιεχόμενα του φακέλου έργου, cd για να αλλάξετε φάκελο και git για τη διαχείριση κώδικα. Η έξοδος των εντολών εμφανίζεται ως κείμενο που μπορεί να διαβαστεί από ένα πρόγραμμα ανάγνωσης οθόνης, και υπάρχει ένα κουμπί Bacakan hasil για να ακούσετε το τελευταίο αποτέλεσμα. Αυτό το τερματικό χρησιμοποιεί το κέλυφος συστήματος του τηλεφώνου, οπότε διαδραστικά προγράμματα όπως τα nano και vim δεν μπορούν ακόμη να χρησιμοποιηθούν εδώ.

Άδεια χρήσης (έκδοση επί πληρωμή)
Για να πουλήσετε μια εφαρμογή, επιλέξτε "Aktifkan Lisensi" κατά τη δημιουργία ενός έργου και, στη συνέχεια, συμπληρώστε τον αριθμό WhatsApp σας. Η εφαρμογή που δημιουργείται θα ζητήσει έναν κωδικό άδειας την πρώτη φορά που θα ανοίξει: ο χρήστης βλέπει το αναγνωριστικό της συσκευής του, πατά το κουμπί Kirim ID Perangkat για να στείλει αυτό το αναγνωριστικό στο WhatsApp σας, και στη συνέχεια εσείς απαντάτε με τον κωδικό άδειας. Ο κωδικός άδειας υπολογίζεται από το αναγνωριστικό συσκευής και τον κωδικό πρόσβασης του έργου (lisensi_seed στο αρχείο δεδομένων του έργου) — φυλάξτε καλά αυτόν τον κωδικό πρόσβασης και μην τον μοιράζεστε. Αφού εισαχθεί ο σωστός κωδικός, η εφαρμογή ανοίγει και δεν ζητά ξανά τον κωδικό.

Αυτόματος δημιουργός εικονιδίων
Το εικονίδιο των νέων έργων είναι ακόμη διαφανές, οπότε ο Pembuat Ikon είναι διαθέσιμος στο κύριο μενού. Ο τρόπος: πατήστε Pembuat Ikon, γράψτε ένα ή δύο γράμματα (για παράδειγμα τα αρχικά του ονόματος της εφαρμογής), επιλέξτε ένα χρώμα φόντου και ένα χρώμα γραμμάτων, δείτε την προεπισκόπησή του και, στη συνέχεια, πατήστε Simpan ke Proyek για να χρησιμοποιήσετε το εικονίδιο στο επιλεγμένο έργο, ή Simpan ke Download για να χρησιμοποιήσετε το αρχείο PNG του αλλού. Αφού δημιουργηθεί ένα έργο, η εφαρμογή προσφέρει επίσης τη δημιουργία ενός εικονιδίου. Το παλιό εικονίδιο ενός έργου μπορεί να αντικατασταθεί ανά πάσα στιγμή από το μενού έργου στο Kelola Project (πατήστε παρατεταμένα το όνομα του έργου και, στη συνέχεια, επιλέξτε Ganti Ikon).

Έτοιμα πρότυπα έργων
Εάν δεν θέλετε να ξεκινήσετε από ένα κενό έργο, επιλέξτε ένα πρότυπο κατά τη δημιουργία ενός έργου: Kalkulator (Java), Catatan (Java), Daftar Tugas (Kotlin), Kalkulator Web (HTML), Situs Profil (Situs Web) ή Penghitung (Compose). Η επιλογή ενός προτύπου αλλάζει αυτόματα τον τύπο έργου ώστε να ακολουθεί το πρότυπο, και το έργο δημιουργείται με έτοιμο αρχικό κώδικα — έτοιμο για εκτέλεση ή τροποποίηση. Εάν ο τύπος έργου αλλάξει ξανά χειροκίνητα μετά την επιλογή ενός προτύπου, το πρότυπο ακυρώνεται και το έργο επιστρέφει σε κενό. Για πρότυπα HTML και Situs Web, το πρότυπο αντικαθιστά το περιεχόμενο του index.html, συμπεριλαμβανομένου του σεναρίου HTML που πληκτρολογήθηκε στη φόρμα.

Δημιουργία αντιγράφων ασφαλείας και επαναφορά έργων
Για να μην χαθούν τα έργα, υπάρχει μια λειτουργία δημιουργίας αντιγράφων ασφαλείας. Ο τρόπος: στο Kelola Project, πατήστε παρατεταμένα το όνομα ενός έργου και, στη συνέχεια, επιλέξτε Cadangkan. Το αντίγραφο ασφαλείας αποθηκεύεται ως ZIP στον φάκελο Download/backup με το όνομα του έργου και την ημερομηνία, παράδειγμα: GarudaDecode-2026-11-14-123045.zip. Το περιεχόμενό του είναι το ίδιο με το Ekspor ZIP (όλο το περιεχόμενο του έργου, χωρίς τον φάκελο bin). Για επαναφορά: ανοίξτε το μενού στο Kelola Project, επιλέξτε Pulihkan cadangan και, στη συνέχεια, επιλέξτε το αρχείο αντιγράφου ασφαλείας. Εάν το όνομα του έργου υπάρχει ήδη, η εφαρμογή θα ρωτήσει: Να αντικατασταθεί το παλιό έργο ή να αποθηκευτεί με νέο όνομα.

Κοινή χρήση και εισαγωγή έργων
Για να μοιραστείτε ένα έργο σε έναν φίλο: στο Kelola Project, πατήστε παρατεταμένα το όνομα ενός έργου και, στη συνέχεια, επιλέξτε Bagikan. Το έργο αποστέλλεται ως ZIP μέσω εφαρμογών κοινής χρήσης (WhatsApp, Telegram και άλλες). Για να λάβετε ένα έργο από έναν φίλο: ανοίξτε το μενού στο Kelola Project, επιλέξτε Impor proyek και, στη συνέχεια, επιλέξτε το αρχείο ZIP του. Το αρχείο ZIP πρέπει να περιέχει ένα αρχείο δεδομένων έργου — εάν δεν υπάρχει, το αρχείο απορρίπτεται με ένα σαφές μήνυμα, επειδή το αρχείο αυτό δεν είναι έργο του Create Aplikasi. Εάν το όνομα του έργου υπάρχει ήδη, η εφαρμογή θα ρωτήσει: Να αντικατασταθεί το παλιό έργο ή να αποθηκευτεί με νέο όνομα.

Αναζήτηση και φιλτράρισμα έργων
Εάν τα έργα είναι ήδη πολλά, στο Kelola Project υπάρχει ένα πλαίσιο αναζήτησης και ένα φίλτρο τύπου. Πληκτρολογήστε ένα όνομα έργου στο πλαίσιο αναζήτησης και η λίστα φιλτράρεται αμέσως (δεν γίνεται διάκριση πεζών-κεφαλαίων). Το φίλτρο τύπου περιορίζει τη λίστα σε έναν μόνο τύπο: Όλα, HTML, Situs Web, Java, Kotlin, Compose ή Python. Το μενού κάθε έργου μπορεί ακόμη να ανοιχτεί όπως συνήθως από τη φιλτραρισμένη λίστα.

Δημιουργήστε εφαρμογές με τη φωνή
Αν δεν θέλεις να πληκτρολογήσεις, χρησιμοποίησε τη φωνή: πάτησε Δημιουργία με φωνή στο κύριο μενού και μετά πες μια εντολή. Εντολές που μπορείς να πεις: "Buat proyek kalkulator", "Bangun proyek Kalkulator", "Buka proyek Kalkulator", "Jalankan proyek Kalkulator", "Daftar proyek", "Buka ikon", "Kembali" και "Bantuan". Η εφαρμογή απαντά με φωνή και κείμενο, ώστε να μπορεί να χρησιμοποιηθεί χωρίς να κοιτάς την οθόνη. Η αναγνώριση φωνής χρησιμοποιεί την ενσωματωμένη εφαρμογή αναγνώρισης φωνής του τηλεφώνου (δωρεάν· μπορεί να λειτουργεί χωρίς σύνδεση αν είναι εγκατεστημένο το πακέτο ινδονησιακής γλώσσας). Αν το τηλέφωνο δεν έχει αναγνώριση φωνής, οι εντολές μπορούν να πληκτρολογηθούν στο πλαίσιο κειμένου της ίδιας οθόνης.

Έλεγχος Προσβασιμότητας
Για να ελέγξεις αν η διάταξη ενός έργου είναι φιλική προς τους αναγνώστες οθόνης (TalkBack/Jieshuo) πριν από την κυκλοφορία: άνοιξε τον Έλεγχο Προσβασιμότητας στο κύριο μενού, διάλεξε ένα έργο και μετά πάτησε Φόρτωση Λίστας Διατάξεων και διάλεξε ένα αρχείο διάταξης. Το IDE διαβάζει εκείνο το αρχείο XML και αναφέρει κουμπιά χωρίς ετικέτα με τον αριθμό γραμμής τους, ετικέτες που χρησιμοποιούνται επανειλημμένα και στοιχεία που επικαλύπτονται, και στη συνέχεια δημιουργεί μια μεταγραφή της σειράς εστίασης όπως την διαβάζει δυνατά το Jieshuo. Αν ένα κουμπί δεν έχει ετικέτα, συμπλήρωσε την ετικέτα του και μετά πάτησε Εισαγωγή Ετικετών Αυτόματα — η ετικέτα γράφεται στο αρχείο διάταξης ως contentDescription. Αυτός ο έλεγχος διαβάζει μόνο το XML της διάταξης· οι προβολές Compose και τα ολοκληρωμένα APK δεν σαρώνται ακόμα.

Νεκροψία Σφάλματος
Για να μάθεις γιατί μια εφαρμογή κλείνει μόνη της από ένα αρχείο καταγραφής σφάλματος με μοναδικό ID: άνοιξε τη Νεκροψία Σφάλματος στο κύριο μενού, διάλεξε ένα ID σφάλματος από τη λίστα καταγραφών και μετά πάτησε Έλεγχος. Το IDE αντιστοιχίζει την κλάση και τον αριθμό γραμμής στο αρχείο με τον πηγαίο κώδικα του έργου και εξηγεί την αιτία στα ινδονησιακά (για παράδειγμα μια κενή αναφορά, μια άδεια που δεν έχει ζητηθεί ακόμα ή ένα σφάλμα JSON), μαζί με μια προτεινόμενη διόρθωση κώδικα. Πάτησε Εφαρμογή Διόρθωσης μόνο αν η γραμμή πηγής είναι ακόμα ακριβώς η ίδια όπως όταν συνέβη το σφάλμα· αν έχει αλλάξει, η διόρθωση απορρίπτεται και το IDE σου ζητά να ελέγξεις μόνος σου. Αυτό που διαβάζεται είναι το ίδιο το αρχείο καταγραφής σφαλμάτων του IDE, όχι το αρχείο μιας δημιουργημένης εφαρμογής.

Μεταγλωττιστής Μεταξύ Παραδειγμάτων
Για να μετατρέψεις απλό κώδικα Java σε Kotlin ή μια απλή διάταξη XML σε κώδικα Compose: άνοιξε τον Μεταγλωττιστή Μεταξύ Παραδειγμάτων στο κύριο μενού, διάλεξε ένα έργο και ένα αρχείο και μετά πάτησε Προεπισκόπηση. Το IDE εμφανίζει το αποτέλεσμα της μετατροπής ως κείμενο — έλεγξέ το πρώτα, γιατί οι γραμμές που δεν αναγνωρίζει αφήνονται όπως είναι και η λέξη static της Java παραλείπεται στην Kotlin (έλεγξε τη σημασία της πριν τη χρησιμοποιήσεις). Η μετατροπή από XML σε Compose αλλάζει μόνο το κείμενο, τις υποδείξεις και τον προσανατολισμό — το μέγεθος, το χρώμα και άλλα χαρακτηριστικά δεν περιλαμβάνονται ακόμα. Αν το αποτέλεσμα είναι σωστό, πάτησε Εφαρμογή στο Αρχείο για να γράψεις το αρχείο-στόχο· το αρχείο-πηγή δεν αλλάζει. Μόνο ασφαλή, συνηθισμένα μοτίβα μετατρέπονται.

Τοπικός Μικροδιακομιστής
Για να δοκιμάσεις μια εφαρμογή που χρειάζεται διακομιστή χωρίς ίντερνετ: άνοιξε τον Τοπικό Μικροδιακομιστή στο κύριο μενού, γράψε έναν ορισμό διαδρομής (για παράδειγμα GET /halo ακολουθούμενο από την απάντησή του JSON) και μετά πάτησε Έναρξη Διακομιστή. Το IDE εκτελεί έναν μικρό διακομιστή HTTP στο ίδιο τηλέφωνο (μόνο HTTP, χωρίς TLS, για το ίδιο δίκτυο Wi-Fi) και καταγράφει κάθε αίτημα και απάντηση στην οθόνη. Οι διαδρομές μπορούν να χρησιμοποιούν παραμέτρους όπως {nama} και ένα απλό κλειδί API. Αυτός ο διακομιστής είναι μόνο για δοκιμές στο τηλέφωνο· ένα δημιουργημένο APK δεν μπορεί ακόμα να γίνει διακομιστής, και ο διακομιστής σταματά όταν κλείσει η οθόνη του.

Ελεγκτής Ασφαλείας
Για να ελέγξεις τα κενά ασφαλείας στον κώδικα ενός έργου πριν από την κυκλοφορία: άνοιξε τον Ελεγκτή Ασφαλείας στο κύριο μενού, διάλεξε ένα έργο και μετά πάτησε Έναρξη Σάρωσης. Το IDE σαρώνει τον κώδικα, το manifest και τη διαμόρφωση του έργου και αναφέρει ευρήματα από τον υψηλότερο στον χαμηλότερο κίνδυνο — κλειδιά API που εκτίθενται στον κώδικα, συστατικά που εκτίθενται χωρίς άδεια, ένα WebView που ενεργοποιεί τη JavaScript μαζί με μια διεπαφή JavaScript, αδύναμη κρυπτογραφία (MD5, SHA1, DES), διευθύνσεις http χωρίς TLS και κωδικούς που γράφονται απευθείας στον κώδικα — με το αρχείο και τον αριθμό γραμμής κάθε ευρήματος. Για ευρήματα με ασφαλή διόρθωση (για παράδειγμα αντικατάσταση του MD5 με SHA-256 ή του http με https) πάτησε Εφαρμογή Διόρθωσης· για τα κλειδιά API και τους κωδικούς, το IDE δείχνει μόνο την προτεινόμενη διόρθωση, γιατί την αντικατάσταση πρέπει να την αποφασίσει ο ίδιος ο προγραμματιστής. Αυτή η σάρωση διαβάζει μοτίβα κειμένου στον κώδικα, όχι bytecode, οπότε ορισμένα ευρήματα μπορεί στην πραγματικότητα να είναι ασφαλή και ένα κενό χωρίς μοτίβο μπορεί να ξεφύγει από τη σάρωση — έλεγξε πριν εφαρμόσεις.

Ρομπότ Δοκιμής Διεπαφής
Για να δοκιμάσεις αυτόματα την εμφάνιση μιας εφαρμογής με σενάρια κειμένου: άνοιξε το Ρομπότ Δοκιμής Διεπαφής στο κύριο μενού, διάλεξε ένα έργο και μετά πάτησε Δημιουργία Σεναρίου Αυτόματα. Το IDE διαβάζει το manifest και τις διατάξεις του έργου και γράφει ένα σενάριο από βήματα κειμένου (πάτησε ένα κουμπί, συμπλήρωσε ένα πεδίο, περίμενε, επέστρεψε). Πάτησε Εκτέλεση Dry Run για να δεις το αρχείο καταγραφής εκτέλεσης του σεναρίου με τις χρονικές σημάνσεις του. Σε αυτό το στάδιο, το ρομπότ εκτελεί μόνο μια προσομοίωση (dry run) — τα πραγματικά πατήματα κουμπιών στο τηλέφωνο και η σύλληψη πραγματικών σφαλμάτων είναι το επόμενο στάδιο, οπότε η αναφορά σφάλματος εδώ είναι ακόμα ένα δείγμα μορφής.

Ταξίδι στον Χρόνο του Κώδικα
Για να επαναφέρεις ένα έργο σε μια προηγούμενη κατάσταση κώδικα χωρίς να πληκτρολογήσεις εντολές Git: άνοιξε το Ταξίδι στον Χρόνο του Κώδικα στο κύριο μενού, διάλεξε ένα έργο, συμπλήρωσε μια ετικέτα για το χρονικό σημείο (μπορεί να μείνει κενή) και μετά πάτησε Καταγραφή Χρονικού Σημείου. Το IDE αποθηκεύει ένα αντίγραφο των αρχείων πηγής του έργου μαζί με τα hash τους στον φάκελο .riwayat μέσα στο έργο. Η λίστα των χρονικών σημείων τα δείχνει όλα· διάλεξε δύο σημεία και μετά πάτησε Σύγκριση για να δεις τα αρχεία και τις συναρτήσεις που προστέθηκαν, άλλαξαν ή διαγράφηκαν. Πάτησε Επαναφορά για να φέρεις πίσω μια παλιά κατάσταση — πριν από την επαναφορά, το IDE κάνει πάντα πρώτα ένα αντίγραφο ασφαλείας της τρέχουσας κατάστασης, οπότε τίποτα δεν χάνεται. Πάτησε Δημιουργία Πειραματικού Αντιγράφου για να αντιγράψεις το έργο σε έναν νέο φάκελο και να δοκιμάσεις αλλαγές χωρίς να ενοχλήσεις το αρχικό έργο. Μόνο τα αρχεία πηγής καταγράφονται.

Εργοστάσιο Μονάδων
Για να συσκευάσεις ένα μέρος ενός έργου ως μονάδα που μπορεί να χρησιμοποιήσει ένα άλλο έργο: άνοιξε το Εργοστάσιο Μονάδων στο κύριο μενού, διάλεξε ένα έργο-πηγή, βάλε τικ στα αρχεία οθόνης, κλάσης, συμβολοσειρών και αδειών που θα συσκευαστούν και μετά πάτησε Συσκευασία ως Μονάδα. Το IDE γράφει ένα αρχείο ZIP μαζί με μεταδεδομένα JSON (όνομα μονάδας, έκδοση, χρησιμοποιούμενες συμβολοσειρές και άδειες). Για να εγκαταστήσεις μια μονάδα σε ένα άλλο έργο, άνοιξε το Εργοστάσιο Μονάδων, διάλεξε το έργο-στόχο και μετά πάτησε Εγκατάσταση Μονάδας και διάλεξε το αρχείο .zip της μονάδας — η συγχώνευση προσθέτει συμβολοσειρές και άδειες χωρίς να αντικαθιστά τον υπάρχοντα κώδικα και δεν συγχωνεύει ένα αρχείο αν το όνομά του χρησιμοποιείται ήδη στο έργο-στόχο. Μια μονάδα δεν φέρνει μαζί της ούτε βιβλιοθήκες ούτε ρυθμίσεις δημιουργίας.

Υπαγόρευση Δομής Κώδικα
Για να γράψεις κώδικα με τη φωνή μέσα στον επεξεργαστή: άνοιξε ένα έργο στον Επεξεργαστή και μετά πάτησε το κουμπί Υπαγόρευση Δομής Κώδικα. Μίλησε εντολές στα ινδονησιακά, για παράδειγμα buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil ή buat variabel teks nama sama dengan Budi — το IDE μετατρέπει την ομιλία σε ένα συντακτικά έγκυρο μπλοκ κώδικα Java, Kotlin, Python ή Compose και το εισάγει στη θέση του δρομέα, και στη συνέχεια διαβάζει δυνατά μια σύντομη περίληψη μέσω του Jieshuo. Η υπαγόρευση χρησιμοποιεί την ενσωματωμένη υπηρεσία εισαγωγής φωνής του συστήματος, χωρίς επιπλέον άδεια μικροφώνου, και αναγνωρίζει μόνο τα ήδη καταχωρισμένα μοτίβα εντολών· η ομιλία εκτός αυτών των μοτίβων δεν μετατρέπεται σε κώδικα. Οι αριθμοί που λέγονται ως λέξεις (για παράδειγμα 'lima') δεν μετατρέπονται ακόμα σε ψηφία.

Τοπικός Χώρος Συνεργασίας (χωρίς ίντερνετ)
Για να δουλέψεις μαζί σε ένα δωμάτιο χωρίς ίντερνετ: άνοιξε τη Συνεργασία στο κύριο μενού και μετά άνοιξε την ενότητα Τοπικός Χώρος Συνεργασίας. Ένα τηλέφωνο ανοίγει μια συνεδρία (το IDE δείχνει μια τοπική διεύθυνση IP και ένα 6ψήφιο PIN), ένα άλλο τηλέφωνο συμμετέχει με εκείνη τη διεύθυνση και το PIN. Οι αλλαγές κειμένου αποστέλλονται ως διαφορές γραμμών, ένα δημιουργημένο APK μπορεί να σταλεί στο τηλέφωνο του δοκιμαστή και οι αναφορές σφαλμάτων από το τηλέφωνο του δοκιμαστή λαμβάνονται πίσω. Μια συνεδρία είναι μόνο για έναν φίλο· αν δύο άνθρωποι αλλάξουν ακριβώς την ίδια γραμμή ταυτόχρονα, χρησιμοποιείται η τελευταία αλλαγή. Το PIN αποστέλλεται ως απλό κείμενο στο τοπικό δίκτυο. Αυτό το δωμάτιο δεν έχει δοκιμαστεί ακόμα σε πραγματικό τηλέφωνο.

Ρυθμίσεις AI
Για να ρυθμίσεις τον πάροχο AI και τα κλειδιά API για τη δημιουργία εφαρμογών: πάτησε στο κύριο μενού, στην ομάδα Ρυθμίσεις, τις Ρυθμίσεις AI (δίπλα στο κουμπί Σύνδεσμος). Διάλεξε τον πάροχο που θα χρησιμοποιηθεί από τη διαθέσιμη λίστα και βάλε τικ στο Αλλαγή μοντέλου σε σφάλμα παρόχου ώστε το IDE να δοκιμάζει αυτόματα το επόμενο μοντέλο από τον ίδιο πάροχο αν ένα μοντέλο αποτύχει. Πάτησε Διαχείριση κλειδιών API για να προσθέσεις εφεδρικά κλειδιά (συμπλήρωσε το όνομα και το κλειδί και μετά πάτησε Αποθήκευση· τα κλειδιά εμφανίζονται καλυμμένα, μόνο τα τελευταία 4 χαρακτήρες είναι ορατά). Τα κλειδιά αποθηκεύονται στο τηλέφωνο και δεν αποστέλλονται ποτέ πουθενά αλλού εκτός από τον επιλεγμένο πάροχο κατά τη δημιουργία μιας εφαρμογής. Σημείωση: προς το παρόν, η επιλογή παρόχου και κλειδιού μόνο καταγράφεται και εμφανίζεται στην οθόνη AI Pembuat Aplikasi — η δημιουργία εφαρμογών εξακολουθεί να χρησιμοποιεί την τοπική AI του τηλεφώνου (χωρίς ίντερνετ)· η χρήση διαδικτυακών παρόχων έρχεται αργότερα.

Σύνδεσμος
Για να αναλύσεις ένα APK και μετά να το στείλεις: πάτησε στο κύριο μενού, στην ομάδα Ρυθμίσεις, τον Σύνδεσμο (δίπλα στο κουμπί Ρυθμίσεις AI). Διάλεξε ένα αρχείο APK από το τηλέφωνο, το IDE διαβάζει το περιεχόμενό του (όνομα πακέτου, έκδοση, λίστα δραστηριοτήτων) και μετά πάτησε Αποστολή APK για να το στείλεις μέσω του μενού κοινής χρήσης του συστήματος (για παράδειγμα WhatsApp ή Drive).

Γλώσσα και ήχος
Για να αλλάξεις τη γλώσσα της εφαρμογής: άνοιξε τις Ρυθμίσεις, μετά τη Γλώσσα εφαρμογής και μετά διάλεξε μια γλώσσα ή Ακολουθεί το σύστημα. Η κύρια οθόνη και οι περισσότερες οθόνες αλλάζουν αμέσως στη επιλεγμένη γλώσσα χωρίς να κλείσεις ή να επανεκκινήσεις την εφαρμογή· ορισμένες οθόνες (για παράδειγμα Terminal, Συνεργασία, Ρυθμίσεις AI και Διαχείριση κλειδιών) εξακολουθούν να χρησιμοποιούν την παλιά γλώσσα μέχρι να ανοιχτούν ξανά. Αν επιλέξεις Ακολουθεί το σύστημα, η γλώσσα ακολουθεί τη γλώσσα συστήματος του τηλεφώνου.
