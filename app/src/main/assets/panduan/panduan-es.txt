Bienvenido a Create Aplikasi by Al Kautsar
Create Aplikasi es una aplicación creadora de aplicaciones Android que funciona directamente en el teléfono, sin necesidad de una computadora portátil. Esta aplicación permite que cualquiera cree sus propias aplicaciones Android, incluidos los usuarios que recién están aprendiendo a crear aplicaciones y los usuarios de lectores de pantalla. La guía completa de uso de esta aplicación está disponible en esta pantalla Acerca de esta herramienta.

Qué es esta aplicación y para quién es
Create Aplikasi es una herramienta creadora de aplicaciones Android que funciona en el teléfono. Esta aplicación está dirigida a cualquiera que quiera crear sus propias aplicaciones Android, incluidos principiantes y usuarios de lectores de pantalla. Esta aplicación proporciona un editor de código, un botón Ejecutar para probar proyectos, un botón Compilar para crear un APK, y menús para firmar e instalar el APK.

Propósito de esta aplicación
Esta aplicación fue creada para que cualquiera pueda crear sus propias aplicaciones Android fácilmente, directamente desde el teléfono. Su interfaz está hecha lo más sencilla posible para que incluso los usuarios nuevos puedan probarla de inmediato.

Cómo crear un proyecto nuevo, paso a paso
1. Pulsa Crear proyecto en el menú principal.
2. Elige el tipo de proyecto: HTML, Sitio web, Java, Kotlin, Compose o Python.
3. Escribe el nombre de la aplicación, por ejemplo: Garuda Decode.
4. Escribe el nombre del paquete (package name), por ejemplo: com.android.garudadecode. El nombre del paquete debe usar letras minúsculas y constar de al menos dos partes separadas por puntos.
5. Escribe la versión de la aplicación, por ejemplo: 1.0, y un código de versión en forma de número, por ejemplo: 1. Si se deja vacío, la versión se completará automáticamente con 1.0 y el código de versión 1.
6. Escribe el SDK mínimo y el SDK de destino si es necesario. Si se dejan vacíos, se usarán los valores predeterminados. El SDK mínimo es la versión de Android más baja admitida, por ejemplo: 21 significa Android 5.0. El SDK de destino máximo es 36 (Android 16).
7. Pulsa el botón Seleccionar permisos para elegir los permisos de la aplicación, por ejemplo: INTERNET. El permiso INTERNET ya está marcado de forma predeterminada. Marca solo los permisos que la aplicación realmente necesita.
8. Si lo deseas, marca "Usar arquitecturas separadas de 64 bits y 32 bits" para que el tamaño del APK sea menor, y marca "Usar firma personal" si quieres usar tu propio keystore.
9. Pulsa Crear proyecto. El proyecto nuevo se guarda en la carpeta Download/project y aparece de inmediato en Gestionar proyectos.

Tipos de proyecto disponibles
• HTML: visualización desde index.html, style.css y script.js, ejecutándose a través de WebView. Se compila directamente en el teléfono.
• Sitio web: un sitio web con menús (Inicio, Acerca de, Contacto) desde index.html, tentang.html, kontak.html, style.css y script.js, ejecutándose a través de WebView. Se compila directamente en el teléfono.
• Java: se compila en el teléfono. MainActivity se encuentra en app/src/main/java/<nombre-del-paquete>/MainActivity.java. La visualización proviene de app/src/main/res/layout/activity_main.xml, el texto de app/src/main/res/values/strings.xml y el tema de app/src/main/res/values/styles.xml.
• Kotlin: se puede compilar en el dispositivo (sin conexión) usando el compilador de Kotlin incluido en la aplicación, o a través de GitHub Actions. MainActivity se encuentra en app/src/main/java/<nombre-del-paquete>/MainActivity.kt, y los archivos res son los mismos que en un proyecto Java. La primera compilación de Kotlin es más lenta debido al gran tamaño del compilador, y los archivos .java que hacen referencia a clases de Kotlin aún no se pueden compilar (los archivos .java se compilan antes que los archivos .kt).
• Compose: una aplicación Android moderna cuya interfaz se crea con Jetpack Compose (no con diseños XML). MainActivity se encuentra en app/src/main/java/<nombre-del-paquete>/MainActivity.kt. Los proyectos Compose se compilan a través de GitHub Actions (el menú Compilar proyecto, luego Compilar en línea) o en Termux con Gradle, porque Compose requiere las bibliotecas de Jetpack Compose, que no están disponibles en el dispositivo.
• Python: la lógica de la aplicación se escribe en el lenguaje Python (Chaquopy) en app/src/main/python/main.py, y la ejecuta el host MainActivity.java en app/src/main/java/<nombre-del-paquete>/MainActivity.java. Los proyectos Python se pueden compilar directamente en el teléfono (el entorno de ejecución de Chaquopy está incluido en la aplicación) o a través de GitHub Actions. El SDK mínimo para proyectos Python es 24 (Android 7.0).

Estructura de archivos de los proyectos Java, HTML, Sitio web, Kotlin, Compose y Python
Los proyectos Java, HTML, Sitio web, Kotlin, Compose y Python están estructurados como los proyectos Android en general. Dentro de la carpeta app está la carpeta src, y dentro de ella está la carpeta main. Dentro de la carpeta main está AndroidManifest.xml junto a la carpeta java, la carpeta res que contiene layout/activity_main.xml y values/strings.xml así como values/styles.xml, y para HTML y Sitio web está la carpeta assets que contiene index.html (Sitio web también tiene tentang.html y kontak.html). Los proyectos HTML y Sitio web también tienen su propio MainActivity en app/src/main/java/<nombre-del-paquete>/MainActivity.java, que carga index.html en un WebView y se convierte en el lanzador en el AndroidManifest. Los proyectos Python tienen el código Python en app/src/main/python/main.py y el host MainActivity.java en app/src/main/java/<nombre-del-paquete>/MainActivity.java. AndroidManifest.xml, los diseños, las cadenas y los estilos se pueden abrir y cambiar en el editor, igual que MainActivity. Los proyectos antiguos cuyo manifiesto aún está junto a la carpeta app todavía se pueden compilar, porque al compilar, la aplicación comprueba primero AndroidManifest.xml en app/src/main/, luego el que está junto a la carpeta app, y por último el archivo de datos del proyecto.

Reglas de permisos (importante)
Los permisos marcados al crear un proyecto se registran en un solo lugar, según el tipo de proyecto. Para los proyectos Java, HTML, Sitio web, Kotlin, Compose y Python, los permisos marcados se registran SOLO en AndroidManifest.xml ubicado en app/src/main/, junto a la carpeta java, dentro de la carpeta del proyecto. El archivo de datos del proyecto para los proyectos Java, HTML, Sitio web, Kotlin, Compose y Python no contiene una lista de permisos. Si eliges Java y luego marcas INTERNET y CAMERA, lo que se registra en AndroidManifest.xml es solo INTERNET y CAMERA, sin que se incluya ningún otro permiso. Al compilar, la aplicación lee los permisos del mismo lugar: desde AndroidManifest.xml en app/src/main/ para los proyectos Java, HTML, Sitio web, Kotlin, Compose y Python (si no hay ninguno, desde AndroidManifest.xml junto a la carpeta app para proyectos antiguos), y desde el archivo de datos del proyecto para proyectos antiguos.

Cómo usar el editor
Abre Gestionar proyectos, toca el nombre de un proyecto para abrir el editor. En el editor, los archivos se pueden abrir, se puede escribir código y los cambios se pueden guardar. Para los proyectos Java, HTML, Sitio web, Kotlin, Compose y Python, los archivos están organizados dentro de la carpeta app/src/main. Para compartir un proyecto, usa Exportar ZIP (consulta la sección siguiente).

Cómo ejecutar un proyecto
En el editor, pulsa Ejecutar para probar el proyecto. Para los proyectos HTML y Sitio web, lo que se ejecuta es index.html a través de WebView. Si ocurre un error, lee el mensaje de error, corrige el código y luego ejecútalo de nuevo.

Cómo compilar un APK
En el editor, pulsa Compilar. Hay dos formas de compilar. Primera, Compilar en el dispositivo: compila directamente en el teléfono sin internet, para proyectos HTML, Sitio web, Java, Kotlin y Python. Segunda, Compilar en línea a través de GitHub Actions: compila por internet en GitHub, y se puede usar para todos los tipos de proyecto. Los proyectos Compose solo se pueden compilar de la segunda forma (Compilar en línea) o en Termux con Gradle, porque Compose requiere las bibliotecas de Jetpack Compose, que no están disponibles en el dispositivo. El resultado de la primera compilación aún no está firmado. Después, la aplicación lo firma: automáticamente con la clave incorporada, o con una firma personal si la casilla "Usar firma personal" estaba marcada al crear el proyecto.

Cómo instalar un APK
Cuando el APK esté listo, pulsa Instalar para instalarlo. En Android 8 y versiones superiores, el teléfono pedirá primero "Permitir desde esta fuente", porque esta aplicación instala APK desde fuera de Play Store. Activa ese permiso una vez en Ajustes, luego vuelve a la aplicación: la instalación continuará automáticamente sin necesidad de pulsar Instalar de nuevo. Si el botón Instalar no aparece, asegúrate de que la compilación haya terminado y el APK haya sido creado.

Cómo firmar una aplicación
Todo APK debe estar firmado para poder instalarse. Hay dos opciones disponibles. Primera, la clave incorporada: la aplicación lo firma por sí misma automáticamente, sin que tengas que hacer nada. Segunda, una firma personal: crea primero un keystore a través del menú Crear keystore en el menú principal, guarda su contraseña con cuidado, luego marca "Usar firma personal" al crear el proyecto. El keystore se guarda en Download/project/signing.

Exportar un proyecto a ZIP
Exportar ZIP se proporciona para que los proyectos se puedan compartir con amigos. Cómo hacerlo: en Gestionar proyectos, mantén pulsado el nombre del proyecto, luego elige Exportar ZIP. El resultado se guarda en Download/project/<NombreDelProyecto>.zip. La carpeta bin no se incluye, por lo que el tamaño es pequeño, solo decenas de KB. Ese archivo ZIP se puede enviar a amigos o subir a GitHub.

Extensión JAWS
La Extensión JAWS utiliza el motor de extensiones de Jieshuo (CSR), no su lector de pantalla. De ese modo, los diseños pueden seguir funcionando aunque el usuario use TalkBack. Cómo hacerlo: abre Extensión JAWS en el menú principal. Como el clic automático funciona por sí solo, el servicio debe activarse primero en Ajustes de accesibilidad. Después de eso, se puede crear un diseño nuevo: escribe el nombre del diseño, pulsa OK, luego completa sus casillas.

Lista de clics separada para mayor orden
Dentro de un diseño hay dos casillas: la casilla de script y la casilla Lista de clics. La lista de botones se guarda por separado en el archivo daftar_klik.txt, un nombre por línea. Un ejemplo de su contenido: tombolSimpan, tombolHapus, tombolBuka. Para abrir una aplicación, simplemente escribe >WhatsApp en esa lista. Los diseños antiguos que aún no tengan un archivo daftar_klik.txt mostrarán ese ejemplo predeterminado.

Funciones sencillas proporcionadas
• klikTombol("tombolSimpan") — hace clic en un botón según su texto.
• klikDaftarTombol(daftar) — hace clic en la lista en daftar_klik.txt, un botón por línea, en orden, y luego informa cuántos tuvieron éxito y cuántos no se encontraron.
• bukaAplikasi("WhatsApp") — abre una aplicación por su nombre, o escribe ">WhatsApp" en la lista.
• klik(540, 1200) — hace clic en las coordenadas de la pantalla.
Todas las funciones se hacen sencillas primero. Una vez que te acostumbres a ellas, se pueden agregar funciones adicionales más adelante.

Acerca de los lectores de pantalla
Esta aplicación está diseñada para ser compatible con lectores de pantalla. Cada campo de entrada tiene una etiqueta y un ejemplo de cómo completarlo, y se puede llegar a todos los botones sin gestos complicados. La Extensión JAWS está hecha para seguir funcionando aunque el usuario use TalkBack, porque lo que se utiliza es su motor de extensiones, no su lector de pantalla.

Privacidad y seguridad
Los proyectos y los keystores se guardan en tu teléfono. El token de GitHub solo se usa para compilaciones en línea y se guarda dentro de esta aplicación. No compartas tu token ni la contraseña de tu keystore con nadie. Si usas una firma personal, guarda el keystore y su contraseña en un lugar seguro, porque si se pierden, los APK antiguos no se pueden actualizar con la misma firma.

Requisitos
Android 5.0 o más reciente. Permiso de almacenamiento: en Android 11 y versiones superiores usa el permiso de acceso a todos los archivos, en Android 10 y versiones inferiores usa el permiso de almacenamiento normal (lectura/escritura de almacenamiento) porque Android 10 no tiene el permiso de acceso a todos los archivos. Compilar en el dispositivo requiere un teléfono con procesador ARM (32 o 64 bits). Compilar en línea a través de GitHub Actions requiere internet y un token de GitHub. Los proyectos Kotlin se pueden compilar en el dispositivo, pero la primera compilación es más lenta y usa más memoria debido al gran tamaño del compilador de Kotlin. Los proyectos Compose se compilan a través de GitHub Actions o en Termux con Gradle. Los proyectos Python requieren Android 7.0 o más reciente (SDK mínimo 24) y el APK resultante es más grande porque incluye el entorno de ejecución de Python (Chaquopy) junto con su biblioteca estándar.

Terminal
El menú Terminal en la pantalla principal abre una terminal dentro de esta aplicación. Comandos como ls se pueden usar para ver el contenido de la carpeta del proyecto, cd para moverse entre carpetas, y git para gestionar el código. La salida de los comandos aparece como texto que puede leer un lector de pantalla, y hay un botón Leer resultado en voz alta para escuchar el último resultado. Esta terminal usa el shell del sistema del teléfono, por lo que los programas interactivos como nano y vim aún no se pueden usar aquí.

Licencia (versión de pago)
Para vender una aplicación, marca "Activar licencia" al crear el proyecto, luego escribe tu número de WhatsApp. La aplicación compilada pedirá un código de licencia cuando se abra por primera vez: el usuario ve su ID de dispositivo, pulsa el botón Enviar ID de dispositivo para enviar ese ID a tu WhatsApp, y luego tú respondes con el código de licencia. El código de licencia se calcula a partir del ID de dispositivo y la contraseña del proyecto (lisensi_seed en el archivo de datos del proyecto) — guarda esa contraseña con cuidado y no la compartas. Después de introducir el código correcto, la aplicación se abre y no vuelve a pedir un código.

Creador Automático de Iconos
Los iconos de los proyectos nuevos aún son transparentes, por lo que hay un Creador de iconos disponible en el menú principal. Cómo hacerlo: pulsa Creador de iconos, escribe una o dos letras (por ejemplo las iniciales del nombre de la aplicación), elige un color de fondo y un color de texto, mira la vista previa, luego pulsa Guardar en el proyecto para usar ese icono en el proyecto seleccionado, o Guardar en Descargas para usar su archivo PNG en otro lugar. Después de crear un proyecto, la aplicación también ofrece crear un icono. El icono antiguo de un proyecto se puede reemplazar en cualquier momento desde el menú del proyecto en Gestionar proyectos (mantén pulsado el nombre del proyecto, luego elige Cambiar icono).

Plantillas de Proyecto Listas para Usar
Si no quieres empezar desde un proyecto vacío, elige una plantilla al crear un proyecto: Calculadora (Java), Notas (Java), Lista de tareas (Kotlin), Calculadora web (HTML), Sitio de perfil (Sitio web) o Contador (Compose). Elegir una plantilla cambia automáticamente el tipo de proyecto para seguir esa plantilla, y el proyecto se crea con código inicial ya listo — solo tienes que ejecutarlo o cambiarlo. Si el tipo de proyecto se cambia manualmente de nuevo después de elegir una plantilla, la plantilla se cancela y el proyecto vuelve a estar vacío. Para las plantillas HTML y Sitio web, la plantilla reemplaza el contenido de index.html, incluido el script HTML escrito en el formulario.

Copia de Seguridad y Restauración de Proyectos
Para que los proyectos no se pierdan, hay una función de copia de seguridad disponible. Cómo hacerlo: en Gestionar proyectos, mantén pulsado el nombre del proyecto, luego elige Hacer copia de seguridad. La copia de seguridad se guarda como un ZIP en la carpeta Download/backup con el nombre del proyecto y la fecha, por ejemplo: GarudaDecode-2026-11-14-123045.zip. Su contenido es el mismo que Exportar ZIP (todo el contenido del proyecto, sin la carpeta bin). Para restaurar: abre el menú en Gestionar proyectos, elige Restaurar copia de seguridad, luego elige el archivo de copia de seguridad. Si el nombre del proyecto ya existe, la aplicación preguntará: Sobrescribir el proyecto antiguo, o guardar con un Nombre nuevo.

Compartir e Importar Proyectos
Para compartir un proyecto con amigos: en Gestionar proyectos, mantén pulsado el nombre del proyecto, luego elige Compartir. El proyecto se envía como un ZIP a través de aplicaciones para compartir (WhatsApp, Telegram y otras). Para recibir un proyecto de un amigo: abre el menú en Gestionar proyectos, elige Importar proyecto, luego elige el archivo ZIP. Ese archivo ZIP debe contener un archivo de datos del proyecto — si no hay ninguno, el archivo se rechaza con un mensaje claro, porque ese archivo no es un proyecto de Create Aplikasi. Si el nombre del proyecto ya existe, la aplicación preguntará: Sobrescribir el proyecto antiguo, o guardar con un Nombre nuevo.

Búsqueda y Filtro de Proyectos
Si ya hay muchos proyectos, en Gestionar proyectos hay un cuadro de búsqueda y un filtro por tipo. Escribe el nombre del proyecto en el cuadro de búsqueda, y la lista se filtra de inmediato (no se distinguen mayúsculas y minúsculas). El filtro por tipo limita la lista a un solo tipo: Todos, HTML, Sitio web, Java, Kotlin, Compose o Python. El menú de cada proyecto se puede seguir abriendo como siempre desde la lista ya filtrada.

Crear Aplicaciones con la Voz
