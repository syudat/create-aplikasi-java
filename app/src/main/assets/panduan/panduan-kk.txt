Create Aplikasi by Al Kautsar қосымшасына қош келдіңіз
Create Aplikasi — тікелей телефонда, ноутбуксыз жұмыс істейтін Android қосымша жасаушы қосымша. Бұл қосымша кез келген адамға өзінің Android қосымшасын жасауға мүмкіндік береді, соның ішінде қосымша жасауды жаңадан үйреніп жүргендер мен экран оқу құралын пайдаланушыларға да. Бұл қосымшаны қолданудың толық нұсқаулығы осы Tentang Alat экранында қолжетімді.

Бұл қандай қосымша және ол кімге арналған
Create Aplikasi — телефонда жұмыс істейтін Android қосымша жасау құралы. Бұл қосымша өзінің Android қосымшасын жасағысы келетін кез келген адамға, соның ішінде жаңа бастаушылар мен экран оқу құралын пайдаланушыларға арналған. Бұл қосымшада код редакторы, жобаны сынауға арналған Jalankan батырмасы, APK жасауға арналған Bangun батырмасы, сондай-ақ APK-ға қол қою және орнату мәзірі бар.

Бұл қосымшаның мақсаты
Бұл қосымша кез келген адам өз Android қосымшасын тікелей телефоннан оңай жасай алуы үшін жасалған. Оның көрінісі жаңа пайдаланушылар да бірден байқап көре алатындай мүмкіндігінше қарапайым етіп жасалған.

Жаңа жобаны қадам-қадаммен жасау жолы
1. Басты мәзірде Buat Project батырмасын басыңыз.
2. Жоба түрін таңдаңыз: HTML, Situs Web, Java, Kotlin, Compose немесе Python.
3. Қосымша атауын толтырыңыз, мысалы: Garuda Decode.
4. Пакет атауын (package name) толтырыңыз, мысалы: com.android.garudadecode. Пакет атауы кіші әріптерден тұруы және нүктемен бөлінген кемінде екі бөліктен құралуы тиіс.
5. Қосымша нұсқасын, мысалы: 1.0, және сан түріндегі нұсқа кодын, мысалы: 1 толтырыңыз. Бос қалдырылса, нұсқа автоматты түрде 1.0, ал нұсқа коды 1 болып толтырылады.
6. Қажет болса, ең төменгі SDK мен мақсатты SDK толтырыңыз. Бос қалдырылса, әдепкі мәндер пайдаланылады. Ең төменгі SDK — қолдау көрсетілетін ең төменгі Android нұсқасы, мысалы: 21 дегеніміз Android 5.0. Мақсатты SDK-ның ең жоғары мәні — 36 (Android 16).
7. Қосымша рұқсаттарын таңдау үшін Pilih Izin батырмасын басыңыз, мысалы: INTERNET. INTERNET рұқсаты әдепкі бойынша белгіленген. Тек қосымшаға шынымен қажет рұқсаттарды ғана белгілеңіз.
8. Қаласаңыз, APK өлшемі кішірек болуы үшін "Gunakan arsitektur terpisah 64 bit dan 32 bit" құсбелгісін қойыңыз, және өз keystore-ыңызды пайдаланғыңыз келсе, "Gunakan tanda tangan pribadi" құсбелгісін қойыңыз.
9. Buat Proyek батырмасын басыңыз. Жаңа жоба Download/project қалтасына сақталады және бірден Kelola Project ішінде көрінеді.

Қолжетімді жоба түрлері
• HTML: WebView арқылы жұмыс істейтін index.html, style.css және script.js файлдарынан тұратын көрініс. Тікелей телефонда құрастырылады.
• Situs Web: WebView арқылы жұмыс істейтін index.html, tentang.html, kontak.html, style.css және script.js файлдарынан тұратын, мәзірі (Beranda, Tentang, Kontak) бар веб-сайт. Тікелей телефонда құрастырылады.
• Java: телефонда құрастырылады. MainActivity app/src/main/java/<nama-paket>/MainActivity.java ішінде орналасқан. Көрініс app/src/main/res/layout/activity_main.xml ішінен, мәтін app/src/main/res/values/strings.xml ішінен, ал тақырып app/src/main/res/values/styles.xml ішінен алынады.
• Kotlin: қосымшаға енгізілген Kotlin компиляторы арқылы құрылғыда (offline) немесе GitHub Actions арқылы құрастырылуы мүмкін. MainActivity app/src/main/java/<nama-paket>/MainActivity.kt ішінде орналасқан, ал res файлдары Java жобасындағыдай. Компилятор өлшемі үлкен болғандықтан, алғашқы Kotlin құрастыруы баяуырақ, және Kotlin кластарына сілтеме жасайтын .java файлдарын әзірге құрастыру мүмкін емес (.java файлдары .kt файлдарынан бұрын компиляцияланады).
• Compose: интерфейсі Jetpack Compose көмегімен жасалған заманауи Android қосымшасы (XML орналасуы емес). MainActivity app/src/main/java/<nama-paket>/MainActivity.kt ішінде орналасқан. Compose жобалары GitHub Actions арқылы (Bangun proyek мәзірі, содан кейін Bangun online) немесе Gradle көмегімен Termux ішінде құрастырылады, өйткені Compose құрылғыда қолжетімсіз Jetpack Compose кітапханаларын қажет етеді.
• Python: қосымша логикасы Python тілінде (Chaquopy) app/src/main/python/main.py ішінде жазылады және app/src/main/java/<nama-paket>/MainActivity.java ішіндегі MainActivity хосты арқылы іске қосылады. Python жобаларын тікелей телефонда (Chaquopy жұмыс ортасы қосымшаға енгізілген) немесе GitHub Actions арқылы құрастыруға болады. Python жобасының ең төменгі SDK-сы — 24 (Android 7.0).

Жоба архитектурасын өзгерту
Жаңа жоба жасамай, бар жобаның архитектура таңдауларын өзгерту үшін: негізгі мәзірде «Жоба архитектурасын өзгерту» түймесін басыңыз, содан кейін жобаны таңдап, «64 биттік APK құрастыру (arm64-v8a)» немесе «32 биттік APK құрастыру (armeabi-v7a)» құсбелгісін өзгертіңіз; немесе «Жобаларды басқару» бөлімінде жоба атауын ұзақ басып, сол жоба үшін сол экранды тікелей ашу үшін «Архитектураны өзгерту» таңдаңыз. Ереже: егер екі құсбелгі де қосулы болса, құрастыру екі бөлек APK файлын жасайды, бірі 64 биттік және бірі 32 биттік; егер тек бір құсбелгі қосулы болса, құрастыру 64 биттік және 32 биттік құрылғыларда да жұмысын жалғастыратын бір ғана әмбебап APK файлын жасайды. Тек бір нұсқа үшін бөлек APK әлі қолдау көрсетілмейді, себебі құрастыру жолы бөлінген немесе әмбебап таңдауды ғана біледі, бірақ әр нұсқаның таңдауы экран қайта ашылғанда жоғалмауы үшін жоба ішінде сақталған күйінде қалады.

Java, HTML, Situs Web, Kotlin, Compose және Python жобаларының файл құрылымы
Java, HTML, Situs Web, Kotlin, Compose және Python жобалары жалпы Android жобалары сияқты құрылады. app қалтасының ішінде src қалтасы, ал оның ішінде main қалтасы бар. main қалтасының ішінде java қалтасының жанында AndroidManifest.xml, layout/activity_main.xml және values/strings.xml мен values/styles.xml файлдарын қамтитын res қалтасы, ал HTML мен Situs Web үшін index.html файлын қамтитын assets қалтасы (Situs Web-те tentang.html және kontak.html да бар) орналасқан. HTML және Situs Web жобаларында да app/src/main/java/<nama-paket>/MainActivity.java ішінде өз MainActivity-і бар, ол index.html файлын WebView ішіне жүктейді және AndroidManifest ішінде іске қосқыш (launcher) болады. Python жобасының Python коды app/src/main/python/main.py ішінде, ал хост MainActivity.java app/src/main/java/<nama-paket>/MainActivity.java ішінде орналасқан. AndroidManifest.xml, layout, strings және styles файлдарын MainActivity сияқты редакторда ашып, өзгертуге болады. Manifest-і әлі app қалтасының жанында орналасқан ескі жобаларды да құрастыруға болады, өйткені құрастыру кезінде қосымша алдымен app/src/main/ ішіндегі AndroidManifest.xml файлын, содан кейін app қалтасының жанындағысын, ең соңында жоба деректері файлын тексереді.

Рұқсат ережелері (маңызды)
Жоба жасау кезінде белгіленген рұқсаттар жоба түріне қарай тек бір жерде жазылады. Java, HTML, Situs Web, Kotlin, Compose және Python жобалары үшін белгіленген рұқсаттар ТЕК жоба қалтасының ішіндегі java қалтасының жанында, app/src/main/ ішінде орналасқан AndroidManifest.xml ішінде жазылады. Java, HTML, Situs Web, Kotlin, Compose және Python жобаларының жоба деректері файлында рұқсаттар тізімі жоқ. Java таңдап, INTERNET пен CAMERA белгілесеңіз, AndroidManifest.xml ішінде басқа рұқсаттар қосылмай, тек INTERNET пен CAMERA ғана жазылады. Құрастыру кезінде қосымша рұқсаттарды сол жерден оқиды: Java, HTML, Situs Web, Kotlin, Compose және Python жобалары үшін app/src/main/ ішіндегі AndroidManifest.xml файлынан (болмаса, ескі жобалар үшін app қалтасының жанындағы AndroidManifest.xml файлынан), ал ескі жобалар үшін жоба деректері файлынан.

Редакторды пайдалану жолы
Kelola Project ашыңыз, редакторды ашу үшін жоба атауын түртіңіз. Редакторда файлдарды ашуға, код жазуға және өзгерістерді сақтауға болады. Java, HTML, Situs Web, Kotlin, Compose және Python жобалары үшін файлдар app/src/main қалтасының ішінде орналасқан. Жобаны бөлісу үшін Ekspor ZIP пайдаланыңыз (төмендегі бөлімді қараңыз).

Жобаны іске қосу жолы
Редакторда жобаны сынау үшін Jalankan батырмасын басыңыз. HTML және Situs Web жобалары үшін index.html WebView арқылы іске қосылады. Қате орын алса, қате туралы хабарламаны оқыңыз, кодты түзетіңіз, содан кейін қайта іске қосыңыз.

APK құрастыру жолы
Редакторда Bangun батырмасын басыңыз. Құрастырудың екі жолы бар. Біріншісі, құрылғыда құрастыру: HTML, Situs Web, Java, Kotlin және Python жобалары үшін интернетсіз тікелей телефонда құрастырады. Екіншісі, GitHub Actions арқылы онлайн құрастыру: интернет арқылы GitHub-та құрастырады және жобалардың барлық түрлері үшін пайдаланылуы мүмкін. Compose жобаларын тек екінші жолмен (Bangun online) немесе Gradle көмегімен Termux ішінде құрастыруға болады, өйткені Compose құрылғыда қолжетімсіз Jetpack Compose кітапханаларын қажет етеді. Алғашқы құрастыру нәтижесіне әлі қол қойылмаған. Содан кейін қосымша оған қол қояды: автоматты түрде кіріктірілген кілтпен немесе жоба жасау кезінде "Gunakan tanda tangan pribadi" құсбелгісі қойылған болса, жеке қолтаңбамен.

APK орнату жолы
APK дайын болғаннан кейін, оны орнату үшін Pasang батырмасын басыңыз. Android 8 және одан жоғары нұсқаларда телефон алдымен "Izinkan dari sumber ini" рұқсатын сұрайды, өйткені бұл қосымша APK-ны Play Store-дан тыс орнатады. Бұл рұқсатты Pengaturan ішінде бір рет қосыңыз, содан кейін қосымшаға оралыңыз: орнату Pasang батырмасын қайта баспай-ақ автоматты түрде жалғасады. Pasang батырмасы көрінбесе, құрастырудың аяқталғанын және APK жасалғанын тексеріңіз.

Қосымшаға қол қою жолы
Орнатылуы үшін әрбір APK-ға қол қойылуы тиіс. Екі таңдау бар. Біріншісі, кіріктірілген кілт: қосымша ештеңе істемей-ақ өзі автоматты түрде қол қояды. Екіншісі, жеке қолтаңба: алдымен басты мәзірдегі Buat Keystore мәзірі арқылы keystore жасаңыз, оның құпия сөзін жақсылап сақтаңыз, содан кейін жоба жасау кезінде "Gunakan tanda tangan pribadi" құсбелгісін қойыңыз. Keystore Download/project/signing ішінде сақталады.

Жобаны ZIP ретінде экспорттау
Ekspor ZIP жобаны достармен бөлісу үшін ұсынылады. Жолы: Kelola Project ішінде жоба атауын ұзақ басып тұрыңыз, содан кейін Ekspor ZIP таңдаңыз. Нәтижесі Download/project/<NamaProyek>.zip ретінде сақталады. bin қалтасы қосылмайды, сондықтан өлшемі кішкентай, бар болғаны ондаған KB. Бұл ZIP файлын достарға жіберуге немесе GitHub-қа жүктеуге болады.

Ekstensi JAWS
Ekstensi JAWS Jieshuo (CSR) кеңейтім механизмін пайдаланады, оның экран оқу құралын емес. Осылайша, пайдаланушы TalkBack пайдаланса да дизайн жұмыс істей береді. Жолы: басты мәзірде Ekstensi JAWS ашыңыз. Автоматты шерту өздігінен жұмыс істейтіндіктен, қызметті алдымен Pengaturan Aksesibilitas ішінде қосу керек. Содан кейін жаңа дизайн жасауға болады: дизайн атауын теріңіз, OK басыңыз, содан кейін оның ұяшығын толтырыңыз.

Daftar Klik ұқыпты болу үшін бөлінген
Дизайн ішінде екі ұяшық бар: скрипт ұяшығы және Daftar Klik ұяшығы. Батырмалар тізімі daftar_klik.txt файлында бөлек сақталады, әр жолға бір атаудан. Оның мазмұнының мысалы: tombolSimpan, tombolHapus, tombolBuka. Қосымшаны ашу үшін тізімге >WhatsApp деп жазыңыз. Әлі daftar_klik.txt файлы жоқ ескі дизайндар осы әдепкі мысалды көрсетеді.

Ұсынылатын қарапайым функциялар
• klikTombol("tombolSimpan") — мәтіні бойынша бір батырманы шерту.
• klikDaftarTombol(daftar) — daftar_klik.txt ішіндегі тізімді шерту, әр жолға бір батырмадан, ретімен, содан кейін қаншасы сәтті болғанын және қаншасы табылмағанын хабарлайды.
• bukaAplikasi("WhatsApp") — қосымшаны атауы бойынша ашу немесе тізімге ">WhatsApp" деп жазу.
• klik(540, 1200) — экран координаталарында шерту.
Барлық функциялар алдымен қарапайым етіп жасалған. Үйреніп алғаннан кейін қосымша функцияларды кейін қосуға болады.

Экран оқу құралы туралы
Бұл қосымша экран оқу құралына ыңғайлы етіп жасалған. Әрбір енгізу өрісінің белгісі мен толтыру мысалы бар, және барлық батырмаларға күрделі қимылдарсыз жетуге болады. Ekstensi JAWS пайдаланушы TalkBack пайдаланса да жұмыс істей беретіндей етіп жасалған, өйткені пайдаланылатыны — оның кеңейтім механизмі, экран оқу құралы емес.

Құпиялылық және қауіпсіздік
Жобалар мен keystore телефоныңызда сақталады. GitHub токені тек онлайн құрастыру үшін пайдаланылады және осы қосымшаның ішінде сақталады. Токеніңізді немесе keystore құпия сөзіңізді ешкіммен бөліспеңіз. Жеке қолтаңбаны пайдалансаңыз, keystore мен оның құпия сөзін қауіпсіз жерде сақтаңыз, өйткені олар жоғалса, ескі APK-ны сол қолтаңбамен жаңарту мүмкін болмайды.

Талаптар
Android 5.0 немесе одан жаңасы. Сақтау рұқсаты: Android 11 және одан жоғары нұсқаларда барлық файлдарға қол жеткізу рұқсаты пайдаланылады, Android 10 және одан төмен нұсқаларда кәдімгі сақтау рұқсаты (сақтауды оқу/жазу) пайдаланылады, өйткені Android 10-да барлық файлдарға қол жеткізу рұқсаты жоқ. Құрылғыда құрастыру ARM процессорлы (32 немесе 64 бит) телефонды қажет етеді. GitHub Actions арқылы онлайн құрастыру интернет пен GitHub токенін қажет етеді. Kotlin жобаларын құрылғыда құрастыруға болады, бірақ Kotlin компиляторының өлшемі үлкен болғандықтан, алғашқы құрастыру баяуырақ және көбірек жад пайдаланады. Compose жобалары GitHub Actions арқылы немесе Gradle көмегімен Termux ішінде құрастырылады. Python жобалары Android 7.0 немесе одан жаңасын (ең төменгі SDK 24) қажет етеді, және нәтижесіндегі APK Python жұмыс ортасын (Chaquopy) және оның стандартты кітапханасын қамтитындықтан үлкенірек болады.

Terminal
Басты экрандағы Terminal мәзірі осы қосымшаның ішінде терминал ашады. ls сияқты пәрмендерді жоба қалтасының мазмұнын көру үшін, cd пәрменін қалталар арасында ауысу үшін, ал git пәрменін кодты басқару үшін пайдалануға болады. Пәрмен шығысы экран оқу құралы оқи алатын мәтін ретінде көрсетіледі, және соңғы нәтижені тыңдауға арналған Bacakan hasil батырмасы бар. Бұл терминал телефонның жүйелік shell-ін пайдаланады, сондықтан nano және vim сияқты интерактивті бағдарламаларды мұнда әзірге пайдалану мүмкін емес.

Lisensi (ақылы нұсқа)
Қосымшаларды сату үшін жоба жасау кезінде "Aktifkan Lisensi" құсбелгісін қойыңыз, содан кейін WhatsApp нөміріңізді толтырыңыз. Құрастырылған қосымша алғаш ашылған кезде лицензия кодын сұрайды: пайдаланушы өз құрылғысының ID-сін көреді, ID Perangkat жіберу үшін Kirim ID Perangkat батырмасын басып, сол ID-ді сіздің WhatsApp-ыңызға жібереді, содан кейін сіз оның лицензия кодын қайтарасыз. Лицензия коды құрылғы ID-сінен және жоба құпия сөзінен (жоба деректері файлындағы lisensi_seed) есептеледі — бұл құпия сөзді жақсылап сақтаңыз және оны бөліспеңіз. Дұрыс код енгізілгеннен кейін қосымша ашылады және кодты қайта сұрамайды.

Pembuat Ikon Otomatis
Жаңа жобаның белгішесі әлі мөлдір, сондықтан басты мәзірде Pembuat Ikon қолжетімді. Жолы: Pembuat Ikon батырмасын басыңыз, бір немесе екі әріп жазыңыз (мысалы, қосымша атауының бас әріптері), фон түсі мен мәтін түсін таңдаңыз, алдын ала қарауды көріңіз, содан кейін белгішені таңдалған жобада пайдалану үшін Simpan ke Proyek батырмасын немесе оның PNG файлын басқа жерде пайдалану үшін Simpan ke Download батырмасын басыңыз. Жоба жасалғаннан кейін қосымша белгіше жасауды да ұсынады. Жобаның ескі белгішесін Kelola Project ішіндегі жоба мәзірінен кез келген уақытта ауыстыруға болады (жоба атауын ұзақ басып тұрыңыз, содан кейін Ganti Ikon таңдаңыз).

Үлгіні таңдағаннан кейін жоба түрін қолмен қайта өзгертсеңіз, үлгі жойылып, жоба қайтадан бос болады. Дауысты тану телефонның кіріктірілген дауысты тану қолданбасын қолданады (тегін; индонезиялық тіл бумасы орнатылған болса, офлайн жұмыс істей алады). AI қолданба жасаушы
AI қолданба жасаушы экранында қалаған қолданбаңызды жазыңыз немесе айтыңыз, мысалы: «сақтау түймесі бар жазба қолданбасы». Қолданба телефон ішіндегі кілт сөздерді талдайды (интернетсіз, ақысыз), содан кейін ең сәйкес үлгіден нақты жоба жасайды: калькулятор, жазбалар, тапсырмалар тізімі, веб-калькулятор, профиль сайты немесе санауыш. Сипаттамаңызға әлі сәйкес үлгі болмаса, қолданба бос жоба жасайды және оны адал айтады — түсінгендей кейіп танытпайды. AI жасаған жобаны Жобаларды басқару бөлімінде тікелей ашуға болады.

Досыңыздың телефонына тікелей алдын ала қарау
Жобаны құрастырмас бұрын досыңызға көрсету үшін: Жобаларды басқару бөлімінде жоба атауын ұзақ басып, содан кейін Досыңыздың телефонына алдын ала қарау таңдаңыз. Қолданба жобаның негізгі файлдарын (index.html, MainActivity немесе main.py) және нұсқаулары бар ОҚЫҢЫЗ-МЕНІ.txt файлын және info.txt файлын қамтитын шағын алдын ала қарау бумасын жасайды. Бума ZIP ретінде WhatsApp немесе Telegram арқылы жіберіледі. Оны алған досыңыз алдын ала қарауды тікелей аша алады: HTML беттері браузерде ашылады, Java/Kotlin/Python коды мәтін ретінде оқылады.

Жобалар дүкені
Жобалар дүкені бір түртумен жоба бумасына орнатуға болатын кіріктірілген үлгі жобаларды қамтиды: Калькулятор, Жазбалар, Тапсырмалар тізімі, Веб-калькулятор, Профиль сайты, Санауыш, Сандық сағат және Веб-викторина. Онлайн дүкен (интернеттен үлгілерді жүктеу) әлі жоқ, сондықтан бұл дүкенде қолданбада бұрыннан бар үлгілер бар. Орнатылған жобаны Жобаларды басқару бөлімінде өзіңіз жасаған жоба сияқты ашып, өзгертуге болады.

Тікелей ынтымақтастық
Досыңызбен бірге жобада жұмыс істеу үшін: негізгі мәзірде Ынтымақтастық ашыңыз, жобаны таңдаңыз, өзгеріс жазбасын жазыңыз (не өзгерді) және содан кейін Ынтымақтастық үшін бөлісу басыңыз. Жоба ішінде CATATAN.txt файлы бар ZIP ретінде жіберіледі. Досыңыз онымен жұмыс істеп, ZIP-ті қайтарады; сіз Жауапты қабылдау басасыз, алдымен өзгеріс жазбасын оқып, содан кейін ескі жобаны ауыстыру үшін Қолдану таңдайсыз немесе ойыңызды өзгертсеңіз Болдырмау таңдайсыз. CATATAN.txt жоқ ZIP ынтымақтастық бумасы емес — кәдімгі жоба ZIP үшін Жобаларды басқару бөліміндегі Жобаны импорттау пайдаланыңыз.

Қолданбаны автоматты аударушы
Қолданба мәтінін басқа тілге аудару үшін: негізгі мәзірде Қолданба аудармашысы ашыңыз, жобаны және мақсатты тілді (ағылшын, араб немесе жава) таңдап, содан кейін Аудару басыңыз. Сөздік телефон ішінде бұрыннан бар (интернетсіз, ақысыз) және күнделікті жиі қолданылатын сөздерді қамтиды; мәтін strings.xml, орналасу және кодтан оқылып, содан кейін аударылады. Нәтиже values-тіл/strings.xml бумасына (жобада strings.xml болса) және жоба бумасындағы аударма-тіл.txt есебіне жазылады. Сөздікте әлі жоқ сөздер сол күйінде қалдырылып, хабарланады — сондықтан қай сөздерді өзіңіз аударуыңыз керек екенін білесіз.

Кодсыз ойын жасаушы
Код жазбай ойын жасау үшін: негізгі мәзірде Кодсыз ойын жасаушы ашыңыз, ойын түрін таңдаңыз (Санды тап, Викторина немесе Жұлдызды ұста), ойын атауын, санын (деңгейлер/сұрақтар/жұлдыздар) және жеңіс хабарын толтырып, содан кейін Ойын жасау басыңыз. Ойын Жобаларды басқару бөлімінде тікелей іске қосуға және кез келген басқа жоба сияқты APK ретінде құрастыруға болатын нақты жоба ретінде жасалады.

Қолданбаны автоматты сынау
Жобаны құрастырмас бұрын тексеру үшін: Жобаларды басқару бөлімінде жоба атауын ұзақ басып, содан кейін Автоматты сынақ таңдаңыз. IDE APK құрастырмай 10 нәрсені тексереді — міндетті файлдар бар (жоба деректер файлы, манифест, негізгі файл, орналасу, жолдар), бума атауы мен нұсқасы, қолданылған рұқсаттар, белгіше және код жақшаларының тепе-теңдігі. Нәтиже әр тармақ бойынша көрсетіледі (ӨТТІ/ӨТПЕДІ хабармен) және Jieshuo дауыстап оқиды. Алдымен ӨТПЕГЕНнің бәрін түзетіп, содан кейін Жобаны құрастыру басыңыз.

AI код тексерушісі
Жоба кодын жиі ақау тудыратын үлгілерге тексеру үшін: негізгі мәзірде Кодты тексеру ашыңыз, жобаны таңдап, содан кейін Кодты тексеру басыңыз. Тексеруші телефон ішінде жұмыс істейді (интернетсіз) және пайдаланылмаған айнымалыларды, бос функцияларды, анық шексіз циклдарды, кодқа тікелей жазылған мәтінді (strings.xml ішінде жақсы), қауіпті рұқсаттар мен API-лерді, TODO/FIXME белгілерін және динамикалық орындауды іздейді. Әр табылған нәрседе файл атауы, жол нөмірі және түзету ұсынысы бар. Бұл тексеруші үлгіге негізделген, нақты AI емес — үлгіге сәйкес келмейтін ақаулар бәрібір өтіп кетуі мүмкін.

Интерактивті оқу режимі
Қолданбаларды қадамдап жасауды үйрену үшін: негізгі мәзірде Үйрену режимі ашыңыз. 5 сабақ бар: Алғашқы жобаңызды жасаңыз, Түйме қосыңыз, Түсті өзгертіңіз, Дыбыс қосыңыз және APK құрастырыңыз. Түсіндірмесі мен жаттығу тапсырмасын оқу үшін сабақты түртіңіз, тапсырманы орындап, содан кейін Тапсырманы тексеру басыңыз — IDE тапсырманың орындалғанын шынымен тексереді (телефондағы жобаны және APK-ны сканерлеу арқылы). Өткен сабақтар аяқталды деп белгіленіп, сақталады.

Бұлтпен синхрондау
Жобаның бұлтқа сақтық көшірмесін жасау үшін: негізгі мәзірде Бұлтпен синхрондау ашыңыз. Жергілікті сақтық көшірме жоба ZIP-ін уақыт белгісімен Download/cloud бумасына сақтайды және сақтық көшірмелер тізімінен кез келген уақытта қалпына келтіруге болады. GitHub сақтық көшірмесі жоба ZIP-ін жеке репозиторийіңізге жүктейді (GitHub баптауларынан токенді пайдаланып) және қайта жүктеуге болады. Бұл қолмен жасалған сақтық көшірме және қалпына келтіру — толық автоматты екі жақты синхрондау серверді қажет етеді, сондықтан ол әлі жоқ.

Автоматты Backend жасаушы
Сервер кодын жазбай Backend жасау үшін: негізгі мәзірде Backend жасаушы ашыңыз, Backend түрін таңдаңыз (Жазбалар, Тапсырмалар тізімі немесе Хабарландыру тақтасы), жоба атауын толтырып, содан кейін Backend жасау басыңыз. IDE пішін беті және телефонның жергілікті сақтау орнында (localStorage) сақталған деректер тізімі бар нақты HTML жоба жасайды — деректер сақталады және қолданба іске қосылғанда қайта оқылуы мүмкін. Бұл Backend телефонда жұмыс істейді; интернет сервері болмағандықтан екі телефон әлі бірдей деректерді бөлісе алмайды.

Тақырыпты автоматты дизайнер
Жобаға түс тақырыбын беру үшін: негізгі мәзірде Тақырып дизайнері ашыңыз, жобаны және тақырыпты таңдаңыз (Ашық, Қараңғы, Көк, Жасыл, Қызыл немесе Күлгін). Алдын ала қарау тақырыптың алты түсін көрсетеді (негізгі, қараңғы негізгі, екпін, фон, мәтін, қосымша мәтін) және Jieshuo дауыстап оқиды. Тақырыпты қолдану басыңыз — IDE colors.xml және styles.xml (app_theme стилі) файлдарын жобаға жазады, олар жоба іске қосылғанда немесе құрастырылғанда тікелей қолданылады.

Анимация жасаушы
Жобаға анимация беру үшін: негізгі мәзірде Анимация жасаушы ашыңыз, жобаны, анимация түрін (Өшу, Сырғу, Айналу, Секіру немесе Соғу), ұзақтығын (100-ден 10000 миллисекундқа дейін) және мақсатты (түйме, мәтін немесе сурет) таңдап, содан кейін Анимация жасау басыңыз. IDE нақты анимация файлын жазады (Java/Kotlin/Compose жобалары үшін res/anim/anim_<түрі>.xml немесе HTML/веб-сайт жобалары үшін animasi.css) экранда көрсетілген пайдаланудың үлгі кодымен бірге.

Әрекет жазушы
Жұмысты автоматты түрде қайталау үшін: IDE орындалған әрекеттерді жазады (жобаны ашу, іске қосу, құрастыру, экспорттау, сақтық көшірме жасау, жоба жасау, файлды сақтау). Негізгі мәзірде Әрекет жазушы ашыңыз жазылған әрекеттердің тізімін олардың жоспарымен көру үшін және содан кейін Қайта ойнату басыңыз — IDE автоматтандыруға болатын әрекеттерді қайта орындайды (сақтық көшірме және жоба жасау орнында орындалады; іске қосу, құрастыру және экспорттау негізгі экранын ашады; ашу және сақтау редакторды ашады). Автоматтандыруға болмайтын әрекеттер өткізіліп, соңында хабарланады.

Автоматты қауіпсіздік
Жобаның қауіпсіздігін тексеру үшін: негізгі мәзірде Автоматты қауіпсіздік ашыңыз, жобаны таңдап, содан кейін Қауіпсіздікті тексеру басыңыз. IDE 8 нәрсені жергілікті тексереді (интернетсіз): қауіпті рұқсаттар (орын, SMS, қоңыраулар, камера, микрофон, байланыстар), HTTP арқылы деректерді жіберу, SMS жіберу, шығыс қоңыраулар, кодқа тікелей жазылған құпия сөз немесе кілт, қорғаныссыз WebView, рұқсатсыз экспортталған компонент және шифрланбаған http мекенжайы. Әр табылған нәрсе ҚАУІПСІЗ, ЕСКЕРТУ немесе ҚАУІП деңгейін түзету ұсынысымен алады, ал қорытынды Jieshuo дауыстап оқылады.

AI офлайн
Интернетсіз мәтін және код көмекшілерін пайдалану үшін: негізгі мәзірде AI офлайн ашыңыз. 4 құрал бар: Мәтінді түзету (бас әріптер, тыныс белгілері және қос бос орындар), Мәтінді қорытындылау (ең маңызды 3 сөйлемді алады), Қолданба атауын жасау (жазылған сипаттамадан) және Айнымалы атауларын ұсыну (жобадағы 1–2 әріпті айнымалы атауларды іздейді). Бұлар телефон ішіндегі қарапайым ережелер, нақты AI моделі емес. Мәтінді түзету нәтижесін Қолдану түймесімен жобаның strings.xml файлына қолдануға болады.

Widget және тұсқағаз жасаушы
Басты экранға виджет жасау үшін: негізгі мәзірде Виджет және тұсқағаз ашыңыз, жобаны таңдап, виджет мәтінін толтырып, содан кейін Widget жасау басыңыз. IDE WidgetSaya.java, виджет орналасуын, виджет ақпаратын жазады және жобаның AndroidManifest.xml файлына қабылдағыш қосады — жобаны құрастырып, содан кейін виджетті телефонның басты экранынан орнатыңыз. Тұсқағаз үшін: мәтінді және фон мен мәтін түстерін толтырып, алдын ала қарау жасап, содан кейін оны PNG ретінде Download бумасына сақтаңыз немесе телефон тұсқағазы ретінде тікелей орнатыңыз.

Әлеуметтік желілерді біріктіру
Қолданбаға бөлісу түймелерін қосу үшін: негізгі мәзірде Әлеуметтік желілерді біріктіру ашыңыз, жобаны таңдап, содан кейін WhatsApp, Facebook немесе Telegram-ға бөлісуді қосыңыз (немесе үшеуін бірден). IDE жобаның негізгі файлына (MainActivity немесе index.html) нақты бөлісу кодын жазады. Бөлісу сынағы түймесі IDE-ден үлгі мәтінімен бөлісу таңдағышын ашады, сондықтан қолданба құрастырылмай тұрып ағынды сезінуге болады.

Суреттен қолданба
Суреттен галерея қолданбасын жасау үшін: негізгі мәзірде Суреттен қолданба ашыңыз және галереядан сурет таңдаңыз. IDE суреттің өлшемі мен басым түсін талдайды, содан кейін нақты галерея қолданбасының жобасын жасайды: сурет жобаның assets бумасына көшіріледі, тақырып түсі суреттің басым түсінен алынады, ал қолданба атауы сурет файлының атауынан алынады. Галерея қолданбасын іске қосу немесе құрастыру үшін Жобаларды басқару ашыңыз.

Интерактивті терминал (VT талдаушысы)
Терминалда интерактивті бағдарламаларды пайдалану үшін: негізгі мәзірде Терминал ашыңыз, содан кейін nano, vim, top немесе htop іске қосыңыз. Терминал енді VT талдаушысын пайдаланады (24 жол x 80 баған торлы экран), сондықтан бұл бағдарламалар дұрыс көрсетіледі — курсор қозғалады, жолдар жойылады және экран нақты терминалдағыдай өзгереді. Интерактивті бағдарламаларды басқару үшін Tab, Жоғары көрсеткі, Төмен көрсеткі және Esc арнайы түймелері бар. Шығыс әлі Jieshuo оқи алатын мәтін; соңғы жолды есту үшін Экранды оқу басыңыз.

Terminal Exec (қолданба бинарлық файлы)
Қолданба бумасындағы екілік файлды (мысалы aapt2, ECJ, D8) Терминалдан іске қосу үшін: пәрменді әдеттегідей жазыңыз. IDE libkautsarexec.so пайдаланады, сондықтан қолданба бумасындағы екілік файлдарды Android 10 және одан жаңа нұсқаларда іске қосуға болады. Осы телефонда екілік exec жолының жұмыс істейтінін тексеру үшін Терминалдағы Exec сынағы басыңыз — нәтиже сол күйінде көрсетіледі. Егер exec жүйе арқылы бұғатталса, жүйелік пәрмендер мен shell сценарийлері әлі жұмыс істейді; екілік файлды оның орнына Жобаны құрастыру мәзірі арқылы іске қосыңыз.

Terminal тірі қалады (KeepAlive)
Экранды ауыстырған кезде shell-ді жұмыста ұстау үшін: Терминал ашыңыз, пәрменді іске қосып, содан кейін Артқа басыңыз немесе басқа экранға ауысыңыз — shell ӨЛМЕЙДІ, ал Терминал хабарландыруы көрсетілуді жалғастырады, сондықтан бір түртумен оралуға болады. Іске қосылған пәрмендер тарихта сақталады (Тарих түймесі немесе пәрмен өрісіндегі жоғары/төмен көрсеткілер) және жиі қолданылатын пәрмендерді таңдаулы ретінде сақтауға болады (Таңдаулылар түймесі). Аяқтаған кезде shell шынымен аяқталуы үшін Shell жабу басыңыз. Жоба мәзірінде және редактор мәзірінде Терминал ішінде құрастыру түймесі де бар: Терминал құрастыру пәрмені бұрыннан толтырылған жоба бумасында ашылады.

Terminal құралдарын орнату (сынақ)
Әлі сыналып жатқан мүмкіндік: Терминалда әзірлеушінің alat-termux репозиторийіндегі (github.com/syudat/alat-termux) айнадан Termux ортасын орнату үшін Terminal құралдарын орнату (сынақ) түймесі бар, ресми Termux шығарылымынан алатын Termux орнату түймесінен басқа жол ретінде. Айнаның мазмұны ресми шығарылыммен дәл бірдей және орнату кезінде SHA-256 арқылы тексеріледі. Орта орнатылған кезде pkg update және pkg install пәрмендерін пайдалануға болады, ал репозиторийден қосымша құралдар терминалға да орнатылады: info-terminal орта туралы ақпаратты көру үшін, bersih-terminal кэшті тазалау үшін және cadangkan-proyek жоба бумасын бір күні белгіленген tar.gz файлына мұрағаттау үшін. Содан кейін қолданба ресми Termux репозиторийінен негізгі Linux бумаларын (git, python, curl, wget, nano, openssh, zip, unzip) және қол қоюы бар APK құрастыру құралдарын (openjdk-21, kotlin, gradle, ecj, aapt2, d8, apksigner, clang, cmake, ninja, make) автоматты түрде орнатады, сондықтан терминал қолданбаларды құрастыруға бірден дайын. Үлкен бумаларды (жүздеген МБ) жүктеу ұзақ уақыт алуы мүмкін. Орнату жұмыс істеп тұрғанда, орындалу барысы мен пәрмен шығысы Терминалдың негізгі экранында көрсетіледі, ал соңғы нәтиже экран оқу құралымен дауыстап оқылады. Егер бума орнату әлі аяқталмаса, жалғастыру үшін Terminal құралдарын орнату (сынақ) қайта басыңыз.

Толық дауыс режимі
IDE-ді дауыспен толығымен басқару үшін: негізгі мәзірде Толық дауыс режимі ашыңыз, содан кейін Тыңдауды бастау басыңыз. IDE үздіксіз тыңдайды — әр пәрмен үшін түймені басудың қажеті жоқ — пәрменді іске қосып, дауыспен жауап береді. 26 пәрмен бар: жасау, құрастыру, ашу, іске қосу, тізімдеу, іздеу, жою, сынау, тексеру, экспорттау, сақтық көшірме жасау, бөлісу, белгіше жасау, аудару, Терминал ішінде құрастыру, экранды оқу, барлық экрандарды ашу (қауіпсіздік, AI офлайн, виджет, әлеуметтік медиа, ойын, оқу, бұлт, Backend, тақырып, анимация, жазушыны қоса), артқа, жабу және көмек. Егер режим белсенді қалдырылса, тыңдау осы экран қайта ашылғанда автоматты түрде жалғасады. Режимді өшіру үшін Тыңдауды тоқтату басыңыз. Егер телефонда дауысты тану қызметі болмаса, пәрмендерді мәтін өрісіне жазуға болады.

Код аудармашысы
Кодты интернетсіз тілдер арасында аудару үшін: негізгі мәзірде Код аудармашысы ашыңыз, жобаны таңдап, бастапқы файлды (.java/.kt) таңдап, содан кейін бағытты таңдаңыз: Java-дан Kotlin-ге. Аудару басыңыз — нәтиже аударуға болмайтын жолдар туралы есеппен бірге көрсетіледі (бұл жолдар сол күйінде сақталып, белгіленеді). Сол бумада ЖАҢА файл (атауы-аударма.java/.kt) жазу үшін Нәтижені сақтау басыңыз; түпнұсқа файл ешқашан қайта жазылмайды. Бұл үлгі ережелерінің аудармашысы, компилятор емес — қолданар алдында нәтижені әрқашан тексеріңіз.

Қолданбадағы Git
IDE-де Termux-сыз Git пайдалану үшін: негізгі мәзірде Қолданбадағы Git ашыңыз, жобаны таңдап, содан кейін Git репозиторийін жасау басыңыз осы жобада жергілікті репозиторий (.git) жасау үшін. Соңғы commit-пен салыстырғанда жаңа, өзгертілген немесе жойылған файлдарды көру үшін Күйді тексеру басыңыз; commit хабарын толтырып, содан кейін жобаның суретін сақтау үшін Commit басыңыз; commit тарихын көру үшін Commit журналын көру басыңыз. GitHub-ға Push және GitHub-тан Pull GitHub токені арқылы суреттерді пайдаланады (pembuat-aplikasi-build репозиторийі) — git хаттамасы емес. Clone, Push (system-git) және Pull (system-git) телефонда git екілік файлы орнатылған кезде ғана іске қосылады (әдетте жоқ). Бұл толық git емес: біріктіру, тармақ немесе айырмашылық жоқ — әр commit жобаның толық ZIP суретін сақтайды.

Жарнама жасаушы
Құрастырылған қолданбаға жарнама қосу үшін: негізгі мәзірде Жарнама жасаушы ашыңыз, жобаны, жеткізушіні (AdMob, Unity Ads немесе AppLovin) және жарнама түрін (Banner, Interstitial немесе Сыйақы берілетін) таңдаңыз. Егер бар болса, жарнама бірлігінің ID-ін толтырыңыз — бос дегеніміз сынақ ID қолданылады (AdMob Google-дің ресми сынақ ID-ін пайдаланады; Unity үлгі Game ID пайдаланады; AppLovin бос орынды пайдаланады). Java және Kotlin коды мен нұсқаулықты көру үшін Жарнама кодын жасау басыңыз; барлығын жобадағы жарнама-<жеткізуші>-<түрі>.txt файлына жазу үшін Жобаға сақтау басыңыз. Бұл код үлгісі + нұсқаулық, жарнама SDK емес — SDK IDE-ге кірмейді; нақты жарнамалар жеткізуші тіркелгісін жасағанда, жарнама бірлігін жасағанда, өз бірлік ID-іңізді қойғанда және SDK тәуелділігін жобаның build.gradle файлына қосқанда ғана көрсетіледі.

Бала режимі
IDE-ді баламен бірге пайдалану үшін: негізгі мәзірде Бала режимі ашыңыз. Экран үлкен түймелермен жеңілдетілген және тек 4 қауіпсіз әрекеті бар: Жоба жасау (қауіпсіз үлгілерден: Калькулятор, Санды тап, Викторина, Жұлдызды ұста), Жобаны ашу, Іске қосу және Үйрену режимі. Бұл экранда жою, экспорттау, сақтық көшірме жасау немесе токен орнату түймесі жоқ. Алғаш кіргенде 4 таңбалы PIN жасайсыз — бұл PIN-ді ата-ана Балалар режимінен шығу үшін пайдаланады (Балалар режимінен шығу түймесі немесе Артқа түймесі). Бұл PIN кішкентай балаларға арналған жеңіл қорғаныс, нақты қауіпсіздік емес.

Wear OS және TV қолданба жасаушысы
Сағат қолданбасын (Wear OS) немесе теледидар қолданбасын (Android TV) жасау үшін: негізгі мәзірде Wear OS және TV қолданба жасаушысы ашыңыз және мақсатты таңдаңыз (Wear OS, Android TV немесе екеуі де). Жоба атауын толтырып, содан кейін Жаңа Wear/TV жобасын жасау басыңыз — IDE Java жобасын жасайды, содан кейін оны бейімдейді — немесе бар жобаны таңдап, содан кейін Осы жобаға қолдану басыңыз. Бейімдеулер: манифестегі uses-feature, LEANBACK_LAUNCHER санаты + теледидарға арналған баннер және бейімделген activity_main.xml орналасуы (Wear: кішкентай экран; TV: D-pad-ке сай келетін үлкен экран). Толық түсіндірме жобадағы wear-tv.txt файлына жазылады. Бұл жоба үлгісі — құрастыру + сынау үшін әлі Wear OS немесе Android TV құрылғысы/эмуляторы қажет; теледидар баннері (banner.png 320x180) автоматты түрде жасалмайды, оны өзіңіз қосуыңыз керек (мысалы, Белгіше жасаушы арқылы).

Жоба картасы
Жобаның құрылымын көру үшін: негізгі мәзірде Жоба картасы ашыңыз, жобаны таңдап, содан кейін Картаны көрсету басыңыз — IDE бумалар мен файлдардың тізімін олардың өлшемдерімен, жалпы өлшемді, файл түрі бойынша өлшемді және маңызды файлдарды (негізгі файл, манифест, орналасу, жолдар, белгіше, веб-бет) көрсетеді. Сол картаны жоба түбіріне жазу үшін peta-proyek.txt сақтау басыңыз. bin/ бумасы (құрастыру нәтижесі) және .git/ бумасы (жергілікті репозиторий) картаға кірмейді, өйткені олардың мазмұнын қайта жасауға болады.

APK өлшем калькуляторы
Құрастырылған APK өлшемін құрастырмас бұрын бағалау үшін: негізгі мәзірде APK өлшем калькуляторы ашыңыз, жобаны таңдап, содан кейін Болжамды есептеу басыңыз. IDE санат бойынша мәліметтерді көрсетеді (код/DEX, ресурстар, активтер, кіріктірілген кітапханалар, манифест + resources.arsc, үстеме шығындар), жалпы болжамды, ең үлкен 5 файлды және кішірейту ұсыныстарын (мысалы, үлкен суреттер ажыратымдылықта кішірейтіледі, үлкен дыбыстар ұзындықта қысқартылады). Бұл БОЛЖАМ, дәл өлшем емес — нақты өлшем aapt2 қысуына, пайдаланылмаған кодты жоюға (R8) және құрастыру нәтижесінің ресурстарына байланысты өзгеруі мүмкін.

APK талдаушысы
Дайын APK мазмұнын оқу үшін (Android Studio-дағы APK талдаушысы сияқты): негізгі мәзірде APK талдаушысы ашыңыз, жобаны таңдап, содан кейін Құрастыру нәтижесінің APK талдауы басыңыз. IDE осы жобаның bin бумасындағы ең соңғы APK-ны оқып, бума атауын, нұсқасын, ең төменгі және мақсатты SDK-ны, қолданылған рұқсаттар тізімін, dex файлдарының санын, бөлік бойынша өлшем мәліметтерін (бағдарлама коды, ресурстар, активтер, кіріктірілген кітапханалар, қолтаңба) және ең үлкен 10 жазбаны хабарлайды. APK-ны қай бөлік үлкен ететінін және құрастырылған қолданба қандай рұқсаттарды қолданатынын білуге пайдалы.

Экран өлшемін алдын ала қарау
Жобаның сыртқы түрін бір уақытта көптеген экран өлшемдерінде тексеру үшін (Android Studio-дағыдай): негізгі мәзірде Экран өлшемін алдын ала қарау ашыңыз, жобаны таңдап, содан кейін Экран өлшемін тексеру басыңыз. IDE жобаның барлық орналасуларын оқып, ені тұрақты жазылған (мысалы 400dp) және 320, 360, 411 немесе 480 dp экран енінен асатын элементтерді хабарлайды, өйткені мұндай элемент кішкентай экраны бар телефонда жабылып немесе асып кетуі мүмкін. match_parent немесе wrap_content ені бар элементтер экранға автоматты түрде бейімделеді және тексеруді қажет етпейді.

Ресурс менеджері
Жобаның барлық ресурстарын бір жерде көру және басқару үшін (Android Studio-дағы Ресурс менеджері сияқты): негізгі мәзірде Ресурс менеджері ашыңыз, жобаны таңдап, содан кейін Ресурстарды көру басыңыз. IDE файлдар саны мен өлшемін санат бойынша (drawable, layout, values, mipmap және басқалар), strings.xml, colors.xml және styles.xml мазмұнын хабарлайды. Сол экраннан атауы мен мәнін толтыру арқылы strings.xml-ге жаңа жол және colors.xml-ге жаңа түс қосуға болады — атауы тексеріледі және қайталанатындар қабылданбайды, сондықтан XML файлы бұзылмайды.

Жеңіл өнімділік мониторы
Іске қосылған қолданбаның RAM және процессор пайдалануын бақылау үшін (Android Studio-дағы Profiler сияқты, жеңіл нұсқа): негізгі мәзірде Жеңіл өнімділік мониторы ашыңыз, алдымен тексергіңіз келетін қолданбаны іске қосыңыз (мысалы, сыналып жатқан құрастырылған қолданба), оның бума атауын толтырыңыз — немесе жобаны таңдап, содан кейін Жобадан пакет атауын толтыру басыңыз — содан кейін Бақылауды бастау басыңыз. Әр екі секунд сайын IDE осы қолданбаның RAM (PSS) және CPU-ын телефонның бос RAM-ымен бірге жазады; орташа және ең жоғары қорытындыны көру үшін Тоқтату басыңыз. Қосымша рұқсат жоқ. Android-тың жаңа нұсқаларында басқа қолданбаның процессорына оқу рұқсаты жүйемен шектелген, сондықтан CPU оқылмаса, есеп оны сол күйінде айтады және RAM бақылауы жалғасады.

Қолжетімділік аудиті
Жобаның орналасуы шығарар алдында экран оқу құралдарына (TalkBack/Jieshuo) ыңғайлы екенін тексеру үшін: басты мәзірде Қолжетімділік аудиті бөлімін ашып, жобаны таңдап, содан кейін Орналасу тізімін жүктеу түймесін басып, орналасу файлын таңдаңыз. IDE сол XML файлын оқып, белгісі жоқ түймелерді олардың жол нөмірлерімен, қайта-қайта қолданылған белгілерді және бір-бірін жабатын элементтерді хабарлайды, содан кейін Jieshuo дауыстап оқитындай фокус ретінің транскрипциясын жасайды. Түймеде белгі болмаса, оның белгісін толтырып, содан кейін Белгіні автоматты түрде қою түймесін басыңыз — белгі орналасу файлында contentDescription ретінде жазылады. Бұл тексеру тек орналасу XML-ін оқиды; Compose көріністері мен дайын APK файлдары әлі сканерленбейді.

Crash аутопсиясы
Бірегей ID бар құлау журналынан қолданбаның неге өзін жабатынын білу үшін: негізгі мәзірде «Crash аутопсиясы» ашыңыз, журнал тізімінен құлау ID-ін таңдаңыз, содан кейін «Тексеру» түймесін басыңыз. IDE журналдағы сынып пен жол нөмірін жоба көзімен сәйкестендіреді және себебін индонезия тілінде түсіндіреді (мысалы, бос сілтеме, әлі сұралмаған рұқсат немесе JSON қатесі), код түзету ұсынысымен. «Түзетпені қолдану» түймесін тек бастапқы жол құлау болған кездегідей әлі болғанда ғана басыңыз; егер ол өзгерсе, түзету қабылданбайды және IDE сізден өзіңіз тексеруді сұрайды. Құрастырылған қолданба құлаулары үшін «Құлау ұстағышын жобаға енгізу» түймесін басыңыз, содан кейін APK-ді әдеттегідей құрыңыз: құрастырылған қолданба өз құлауларын өзі ұстайды және журналын телефонға жазады, және бұл журналды «Құрастырылған қолданба құлау журналын табу» түймесімен табуға болады. Адал шектеу: журналды Android 11 және одан жоғарыда жалпы Download қалтасына көшіру барлық файлдарға қол жеткізу рұқсатынсыз сәтсіз болуы мүмкін.

Парадигмааралық transpiler
Қарапайым Java кодын Kotlin-ге немесе қарапайым XML орналасуын Compose кодына түрлендіру үшін: басты мәзірде Парадигмааралық transpiler бөлімін ашып, жоба мен файлды таңдап, содан кейін Алдын ала қарау түймесін басыңыз. IDE түрлендіру нәтижесін мәтін ретінде көрсетеді — алдымен оны тексеріңіз, себебі ол танымайтын жолдар сол күйінде қалады, ал Java-дағы static сөзі Kotlin-де алынып тасталады (қолданар алдында оның мағынасын тексеріңіз). XML-ден Compose-ге түрлендіру тек мәтінді, нұсқауларды және бағдарды өзгертеді — өлшем, түс және басқа атрибуттар әлі қамтылмайды. Нәтиже дұрыс болса, мақсатты файлды жазу үшін Файлға қолдану түймесін басыңыз; қайнар файл өзгермейді. Тек қауіпсіз, қарапайым үлгілер түрлендіріледі.

Жергілікті микро сервер
Интернетсіз серверді қажет ететін қолданбаны сынау үшін: негізгі мәзірде «Жергілікті микро сервер» ашыңыз, маршрут анықтамаларын жазыңыз (мысалы, GET /halo, одан кейін оның JSON жауабы), содан кейін «Серверді бастау» түймесін басыңыз. IDE сол телефонда шағын HTTP серверді іске қосады (тек HTTP, TLS жоқ, сол Wi-Fi желісі үшін) және әр сұрау мен жауапты экранда тіркейді. Маршруттар {nama} сияқты параметрлерді және қарапайым API кілтін пайдалана алады. Серверді құрастырылған APK-ге де орауға болады: «Серверді жобаға орау» түймесін басыңыз, және сервер көзі, активтері мен манифесті жобаға енгізіледі, сондықтан құрастырылған қолданба іске қосылғанда өзі серверге айналады. IDE ішіндегі сервер оның экраны жабылғанда тоқтайды.

Қауіпсіздік аудиторы
Жарияламас бұрын жоба кодын қауіпсіздік олқылықтары үшін тексеру үшін: негізгі мәзірде «Қауіпсіздік аудиторы» ашыңыз, жобаны таңдаңыз, содан кейін «Сканерлеуді бастау» түймесін басыңыз. IDE жоба кодын, манифестті және конфигурацияны сканерлейді және жоғарыдан төмен тәуекелге дейінгі нәтижелерді хабарлайды — кодта ашық қалдырылған API кілті, рұқсатсыз ашылған компонент, JavaScript интерфейсінде JavaScript-ті қосатын WebView, әлсіз крипто (MD5, SHA1, DES), TLS жоқ http мекенжайы және кодқа тікелей жазылған құпия сөз — олардың файлдары мен жол нөмірлерімен. Түзетуі қауіпсіз нәтижелер үшін (мысалы, MD5-ті SHA-256-ға немесе http-ті https-ке өзгертіңіз) «Түзетуді қолдану» түймесін басыңыз; API кілттері мен құпия сөздер үшін IDE тек түзету ұсынысын көрсетеді, себебі ауыстыруды әзірлеуші өзі шешуі керек. Сканерлеу енді құрастырылған APK ішіндегі нақты DEX байткодын да талдайды (кодтағы мәтін үлгілері ғана емес), сондықтан шақырылған қауіпті API-лар мен DEX-ке енгізілген құпиялар да ұсталады; үлгіні ұстанбайтын олқылықтар сканерлеуден әлі қашып кетуі мүмкін — қолданар алдында тексеріңіз.

Интерфейсті тексеру роботы
Мәтін сценарийлері арқылы қолданба экранын автоматты түрде сынау үшін: негізгі мәзірде «Интерфейсті тексеру роботы» ашыңыз, жобаны таңдаңыз, содан кейін «Сценарийді автоматты түрде жасау» түймесін басыңыз. IDE жоба манифесті мен орналасуын оқиды және сценарийді мәтін қадамдары ретінде жазады (түймені басыңыз, өрісті толтырыңыз, күтіңіз, қайтыңыз). Сценарийдің орындалу журналын оның уақыт белгілерімен көру үшін «Dry Run іске қосу» түймесін басыңыз — бұл dry run әлі тек реттілікті модельдеу ғана. Нақты сынау үшін «Тест агентін жобаға енгізу» түймесін басыңыз: IDE сценарий активтерімен тест агентін жобаға енгізеді; APK-ді әдеттегідей құрыңыз, орнатыңыз, содан кейін «Тест» белгішесін ашыңыз — агент құрастырылған қолданба ішінде жұмыс істейді және шынымен түймелерді басады, нақты өрістерді толтырады және айналдырады, содан кейін оның есебін экранда ұсталған нақты құлаулармен көрсетеді. Агентті қайта жою үшін «Тест агентін жобадан жою» түймесін басыңыз. Агент қолданбаның өз процесі ішінде жұмыс істейді, сондықтан оған қолжетімділік қызметі немесе жүйе автоматизациясы қажет емес.

Код уақытына саяхат
Git пәрмендерін жазбай-ақ жобаны бұрынғы код күйіне қайтару үшін: басты мәзірде Код уақытына саяхат бөлімін ашып, жобаны таңдап, уақыт нүктесіне белгі толтырыңыз (бос қалдыруға болады), содан кейін Уақыт нүктесін жазу түймесін басыңыз. IDE жобаның қайнар файлдарының көшірмесін олардың hash мәндерімен бірге жоба ішіндегі .riwayat қалтасына сақтайды. Уақыт нүктелерінің тізімі олардың бәрін көрсетеді; екі нүктені таңдап, содан кейін қосылған, өзгертілген немесе жойылған файлдар мен функцияларды көру үшін Салыстыру түймесін басыңыз. Ескі күйді қайтару үшін Қалпына келтіру түймесін басыңыз — қалпына келтіру алдында IDE әрқашан алдымен ағымдағы күйдің сақтық көшірмесін жасайды, сондықтан ештеңе жоғалмайды. Жобаны жаңа қалтаға көшіру және бастапқы жобаға кедергі келтірмей өзгерістерді сынау үшін Тәжірибе көшірмесін жасау түймесін басыңыз. Тек қайнар файлдар жазылады.

Модуль фабрикасы
Жобаның бір бөлігін басқа жоба қолдана алатын модуль ретінде орау үшін: басты мәзірде Модуль фабрикасы бөлімін ашып, қайнар жобаны таңдап, оралатын экран, сынып, жол және рұқсат файлдарын белгілеп, содан кейін Модуль ретінде орау түймесін басыңыз. IDE JSON метадеректерімен бірге ZIP мұрағатын жазады (модуль атауы, нұсқасы, қолданылған жолдар және рұқсаттар). Модульді басқа жобаға орнату үшін Модуль фабрикасы бөлімін ашып, мақсатты жобаны таңдап, содан кейін Модульді орнату түймесін басып, модульдің .zip файлын таңдаңыз — біріктіру жолдар мен рұқсаттарды қолданыстағы кодты қайта жазбай қосады және файлың атауы мақсатты жобада бұрыннан қолданылып жатса, файлды біріктірмейді. Модуль кітапханаларды да, құрастыру параметрлерін де өзімен бірге алып жүрмейді.

Полиморфты қалқан және активтер қоймасы
Жарияламас бұрын идентификатор атауларын кездейсоқ өзгерту және жоба активтерін шифрлау үшін: негізгі мәзірде «Полиморфты қалқан және активтер қоймасы» ашыңыз, жобаны таңдаңыз, содан кейін «Атауларды кездейсоқ өзгерту және активтерді шифрлау» түймесін басыңыз. IDE бастапқы кодтағы сынып және әдіс атауларын сканерлейді, кездейсоқ атау картасын жасайды, бұл атауларды құрастырылған DEX файлдарының ішінде қайта жазады (алмастыру атаулары барлық ығысулар жарамды болып қалуы үшін түпнұсқалармен бірдей ұзындықта жасалады, содан кейін DEX тақырыбының бақылау қосындысы және SHA-1 қолтаңбасы қайта есептеледі), жоба актив файлдарын жоба ішіндегі brankas-aset қалтасында AES-GCM көмегімен шифрлайды және құлау журналдарын оқығанда түпнұсқа атауларды қалпына келтіруге болатындай шифрланған қалпына келтіру картасын (perisai-peta.brankas) сақтайды. Шифрлау кілті енді жоба атауынан емес, әзірлеуші құпия сөзінен PBKDF2, 20 000 итерация арқылы алынады. Жай мәтін, аннотация атауы және жөндеу атауы ретінде де қолданылатын атаулар әдейі қайта жазылмайды, және құрастыру жолындағы DEX қайта жазуды енгізу нүктелері әлі нақты телефонда сынауды күтуде.

Сенім тізбегі және ортаны қорғаушы
Жарияламас бұрын қолтаңба кілті тізбегін және телефон ортасын тексеру үшін: негізгі мәзірде «Сенім тізбегі және ортаны қорғаушы» ашыңыз, жобаны таңдаңыз, содан кейін «Тізбек пен ортаны тексеру» түймесін басыңыз. IDE жоба бума атауынан 5 буыннан тұратын кілт тізбегін құрады және оның тұтастығын тексереді, жадтағы код бөліктерінің мазмұнын дискідегі файлдармен салыстыру арқылы нақты жад тұтастығын тексереді және аты жоқ орындалатын (RWX) салыстыруларды, шетелдік кітапханаларды және memfd салыстыруларын хабарлайды, содан кейін өз процесс жад картасын және құрылғы сипаттарын Frida, Xposed немесе эмулятор іздері үшін сканерлейді. Қойма кілті қолжетімді болғанда аппараттық қауіпсіздік чипін пайдаланатын AndroidKeyStore ішіндегі AES кілтімен оралған, және кілт айналымы енді нақты, v3 сұлба қолтаңба сертификатының тегі арқылы: ескі кілт жаңа кілтке айналым дәлеліне қол қояды және APK сол текпен қайта қол қойылады. Нәтиже — мәтіндік дәлелмен «қауіпсіз», «сақ» немесе «қауіпті» тәуекел деңгейі. Егер жүйе жадты оқудан бас тартса, тексеру «тексеру мүмкін емес» деп хабарланады, қауіпсіз емес; және кілттің аппараттық қауіпсіздік чипін шынымен пайдаланатынын тек нақты құрылғыда ғана растауға болады.

Мәтін ағашының орналасу сәулетшісі
Экранды көрмей жобалау үшін: негізгі мәзірде «Мәтін ағашының орналасу сәулетшісі» ашыңыз, жобаны және орналасу файлын таңдаңыз, содан кейін «Орналасуды тексеру» түймесін басыңыз. IDE XML орналасуын мәтін ағашы ретінде оқиды және әр элементтің орналасу сипаттамасын дауыстап оқиды (мысалы, төменгі оң жақта, экран енінің 45 пайызы), содан кейін элементтер арасындағы қабаттасуларды және 360 dp енінде экраннан шығып кететін элементтерді математикалық түрде хабарлайды. Қазір есептелетіндер: LinearLayout және қарапайым dp өлшемдері, толық ConstraintLayout (барлық шектеулер, бейімділік, тізбектер, бағыттаушылар, кедергілер, пайыздық ендер, 0dp match_constraint және өлшем қатынастары) және Compose экрандары (Column, Row және Box олардың өлшем модификаторларымен). Орындалу кезінде өзгеретін MotionLayout және ConstraintSet ғана белгісіз орын ретінде хабарлана береді, себебі олардың мәндері қолданба іске қосылғанда ғана болады.

Дизайн жүйесі студиясы
Барлық экрандар мен жобаларда қашықтықтарды, қаріптерді және бұрыштарды біркелкі ету үшін: негізгі мәзірде «Дизайн жүйесі студиясы» ашыңыз, жобаны таңдаңыз, дизайн токендерін жазыңыз (мысалы jarak=8, huruf=16, sudut=12), компонентті таңдаңыз, содан кейін «Компоненттер жасау» түймесін басыңыз. IDE токендерді тексереді — негізгі қашықтық 4-тен 16 dp-ге дейін, негізгі қаріп 12-ден 20 sp-ге дейін, бұрыштар 0-ден 32 dp-ге дейін және ең аз жанасу аумағы 48 dp — содан кейін пайдалануға дайын XML компоненттерін (komponen-studio.xml) XML тақырыбымен (tema-studio.xml) және Compose тақырыбымен (tema-studio.kt) жоба қалтасына жазады. Токендерді жобалар арасындағы ортақ токен кітапханасында аталған жиынтық ретінде де сақтауға болады, және бір синхрондау пәрмені кітапхананың ең жаңа токендерін сол жиынтықты пайдаланатын барлық жобаларға қолданады. Компоненттер орналасуға қойылып, содан кейін «Мәтін ағашының орналасу сәулетшісі» арқылы тексерілетін мәтін ретінде жасалады; планшеттегі екі бағандық реттеу іске қосылғанда құрылғы идентификаторының орнына экран ені біліктілігін пайдаланады.

Семантикалық рефакторинг және AST навигациясы
Анықтамаларды табу және таңба атауларын кездейсоқ бірдей атауы бар басқа кодты бұзбай өзгерту үшін: негізгі мәзірде «Семантикалық рефакторинг және AST навигациясы» ашыңыз, жобаны таңдаңыз, содан кейін барлық сыныптар мен әдістерді олардың файлдары мен жол нөмірлерімен көру үшін «Жоба таңбаларын сканерлеу» түймесін басыңыз. Таңба атауын теріңіз, содан кейін оның анықтамасын және оны шақыратын барлық файлдарды көру үшін «Жоба таңбаларын сканерлеу» түймесін қайта басыңыз. Атын өзгерту үшін жаңа атауды теріңіз, әр файлдағы кездесулер санын көру үшін «Атын өзгертуді алдын ала қарау» түймесін басыңыз, содан кейін «Атын өзгертуді қолдану» түймесін басыңыз. Индекс енді қолмен жасалған AST талдауышын пайдаланады (Java және Kotlin ішкі жиыны үшін лексер және рекурсивті талдауыш), сондықтан файлдар арасындағы әдіс атауларын өзгерту шешіледі және басқа файлдардағы шақырушылар да өзгереді; код блогын жаңа функцияға шығару түймесі енді осы экранда орналасқан. Бұл талдауыш әлі минималды: өте күрделі дженериктер, параметрленген аннотациялар және анонимді сыныптар сол қалпында сканерленеді, ал рефлексия және интерфейс арқылы шақырулар шешілмейді.

Қадамдық жөндеуші және жадты тексеруші
Журналдардан болжамай, бағдарлама ағынының ортасында айнымалы мазмұнын зерттеу үшін: негізгі мәзірде «Қадамдық жөндеуші және жадты тексеруші» ашыңыз, жобаны таңдаңыз, орындау бақылауын жазыңыз (әр жолға бір қадам, пішім жол нөмірі, код, содан кейін | арқылы бөлінген айнымалылар мен мәндер, мысалы 10|int total = harga * jumlah;|harga=5000, jumlah=3, total=15000), тоқтау нүктесінің жол нөмірін теріңіз, содан кейін «Жөндеу бақылауын орындау» түймесін басыңыз. IDE бірінші тоқтау нүктесіне дейін іске қосылады және белсенді жолды Jieshuo арқылы оның айнымалы мәндерімен дауыстап оқиды. Бір жол алға жылжу үшін «Бір жолдық қадам» түймесін басыңыз, шақырылған функцияға кіру үшін «Функцияға кіру» түймесін басыңыз (шақыру стегімен) немесе келесі тоқтау нүктесіне өту үшін «Бағдарламаны жалғастыру» түймесін басыңыз. Бұл бақылау жөндеушісі әлі жазылған немесе қолмен жазылған бақылауды ұстанады; оның жанында JDWP сым протоколына арналған таза Java клиенті бар, ол қол алысуды, тоқтау нүктелерін орнатуды, ішке, үстінен және сыртқа қадам басуды және TCP арқылы немесе тыңдау режимінде VM-ді кідіртуді және жалғастыруды істей алады. Қалыпты қолданба ішінен нақты процесті кідірту әлі толық мүмкін емес, себебі процестің JDWP сокеті тек adbd арқылы ашылады — дәлелденген жол сымсыз жөндеуді және мақсатты қабық арқылы іске қосуды талап етеді, бұл қолданбаның өзі істей алатынынан асып түседі.

Офлайн тәуелділік менеджері
Интернетсіз үшінші тарап кітапханаларын пайдалану және құрастыру алдында нұсқа қақтығыстарын болдырмау үшін: негізгі мәзірде «Офлайн тәуелділік менеджері» ашыңыз, жобаны таңдаңыз, содан кейін «Тәуелділіктерді тексеру» түймесін басыңыз. IDE жобаның барлық .gradle файлдарын оқиды, Download/brankas-bersama қалтасындағы жобалар арасындағы ортақ қойманы тексереді және қақтығыстарды шешеді — егер екі кітапхана бір артефактінің әртүрлі нұсқаларын сұраса, ең жоғары нұсқа пайдаланылады және қақтығыс хабарланады. Кітапхананы жүктеп алу үшін оның координаталарын теріңіз (пішім топ:артефакт:нұсқа, мысалы com.google.code.gson:gson:2.10.1), содан кейін «Тәуелділіктерді тексеру» түймесін басыңыз: желіде болғанда AAR, JAR немесе WHL файлдары шынымен Maven, Google немесе PyPI-ден олардың транзитивті тәуелділік графымен (рекурсивті, циклдар үзіледі, тереңдігі 25 деңгейге дейін) жүктеледі, және тек сәтті жүктелген файлдар қолжетімді ретінде тіркеледі. Желіде жоқ кезде ортақ қоймада бұрыннан бар кітапханаларды ғана пайдалануға болады. Maven нұсқа диапазондары шешілмейді, және жүктелген файлдар тек SHA-1 арқылы тексеріледі, PGP тексерусіз.

Дерекқор мен сақтауды тексеруші
Кесте мазмұнын басып шығаратын код жазбай, жоба дерекқорының мазмұнын тексеру және сынау үшін: негізгі мәзірде «Дерекқор мен сақтауды тексеруші» ашыңыз, жобаны және дерекқор файлын (.db, .sqlite немесе .sqlite3) таңдаңыз, содан кейін «Дерекқорды ашу» түймесін басыңыз. IDE оның барлық кестелерінің схемасын толық SQLite бет талдауышымен (асып кеткен беттері бар B-ағаш) оқиды және алғашқы 20 жолды Jieshuo дауыстап оқитын мәтін кестесі ретінде көрсетеді. SELECT сұрауын жазыңыз және «Сұрауды орындау» түймесін басыңыз (мысалы SELECT nama FROM pengguna WHERE kota = 'Makassar') — сұраулар енді JOIN, GROUP BY, ORDER BY және LIKE қолдайды және телефондағы нақты Android SQLite қозғалтқышымен орындалады. Мәнді өзгерту үшін жол нөмірін (1 = бірінші жол), баған атауын және жаңа мәнді теріңіз, содан кейін «Ұяшық мәнін өзгерту» түймесін басыңыз — мән .db файлына қайта жазылады. Кестенің ағымдағы күйін жобада <дерекқор-атауы>.cadangan.txt файлы ретінде сақтау үшін «Сақтық көшірмені сақтау» түймесін басыңыз. SharedPreferences және DataStore де оқуға болады. Әлі оқуға болмайтындар: шифрланған дерекқорлар, расталмаған WAL өзгерістері және мамандандырылған DataStore Proto ішіндегі терілген мәндер (тек жалпы өріс көрінісі ретінде көрсетіледі).

Бірлік тест зауыты және фаззинг
Қолданбаны бөліспес бұрын логика олқылықтарын табу үшін: негізгі мәзірде «Бірлік тест зауыты және фаззинг» ашыңыз, жобаны және код файлын таңдаңыз, содан кейін «Тесттер жасау және орындау» түймесін басыңыз. IDE файлдағы функция қолтаңбаларын оқиды, кәдімгі және шекаралық тест жағдайларын жасайды (бос мәтін, null, максималды сандар, оғаш таңбалар), содан кейін бұл тесттерді шынымен орындайды: жоба коды құрастырылады және әр @Test әдісі 5 секундтық шекпен орындалады, сондықтан нәтиже олардың нақты мәндерімен нақты өткендер мен сәтсіздіктер болып табылады. Фаззинг те жоба функцияларында шынымен орындалады (рефлексия арқылы, әр шақыруға 2 секунд, ең көбі 20 әдіс), және жол қамту пайызы түпнұсқа жол нөмірлерін сақтайтын аспаптау арқылы шынымен есептеледі. Нәтиже қанша тест өткенін және сәтсіз болғанын, қанша код жолы мен функция табылғанын және қандай тест жағдайлары жасалғанын хабарлайды. Жасалған тесттер JUnit-пен дәл бірдей API пайдаланады, бірақ аннотация және бекіту анықтамалары жасалған тест файлының ішінде жазылады, себебі нақты JUnit кітапханасы қолданбаға енгізілмеген.

Құрылғының шекті жағдайын модельдеуші және жад ағып кетуін тексеруші
Жүйе оның процесін өлтіргенде, желі үзілгенде, экран айналғанда немесе батарея үнемдеу қосылғанда қолданбаның төзімділігін сынау үшін: негізгі мәзірде «Құрылғының шекті жағдайын модельдеуші және жад ағып кетуін тексеруші» ашыңыз, жобаны таңдаңыз, содан кейін «Модельдеуді орындау» түймесін басыңыз. IDE модельденген экран айналуымен үш стресс сценарийін орындайды және олардың экраны жабылғаннан кейін де жадта ұсталған нысандарды бақылайды, содан кейін жоғалған деректер мен ағып жатқан нысан тізбектерін хабарлайды. Сақтау және қалпына келтіру күйі енді тұрақты мысалдан емес, пайдаланушының өз жоба көзінен оқылады; жергілікті loopback сервер желі үзілуін өлшеу үшін сынақ ортасында шынымен тоқтатылады; нақты heap dump алынып, талданады, екі dump салыстырылады және ұстау тізбегі GC түбірлерінен бақыланады; және қолданбаның өз процесі оның күйі сақталғаннан кейін шынымен өлтіріледі, содан кейін қайта ашылғанда қандай деректер қайтарылатыны тексеріледі. Қалыпты қолданбадан әлі мүмкін емес нәрселер: телефон радиосын немесе Wi-Fi өшіру және басқа қолданбаларды мәжбүрлеп тоқтату — екеуі де жүйе рұқсатын талап етеді; оның орнына фондық қолданбалар killBackgroundProcesses арқылы өлтіріледі, оның рұқсаты манифестте бұрыннан бар, экранда адал белгімен.

Жобаның сызба сәулетшісі
Үлкен қолданба идеясын қадамдық жұмыс жоспарына айналдыру үшін: негізгі мәзірде «Жобаның сызба сәулетшісі» ашыңыз, жобаны таңдаңыз, қолданба идеясын жазыңыз (мысалы, бөліп төлеумен шағын азық-түлік дүкенінің касса қолданбасы), содан кейін «Сызба жасау» түймесін басыңыз. IDE модульдерді, файл тізімін және шағын кезеңдерді құрады, содан кейін оларды жоба қалтасында cetak-biru.txt ретінде сақтайды. Кезең аяқталған сайын «Келесі кезеңді аяқталды деп белгілеу» түймесін басыңыз немесе сақталған сызбаны қайта ашу үшін «Сақталған сызбаны жүктеу» түймесін басыңыз. Егер белсенді AI провайдері «AI баптаулары» бөлімінде таңдалып, оның кілті қолжетімді болса, сызбаны сол провайдер құрады; егер кілт жоқ болса немесе провайдерге қол жеткізу мүмкін болмаса, IDE офлайн кілт сөз үлгілеріне қайтады және бұл шектеуді адал айтады. Провайдер жауабы тек пішім үшін тексеріледі (модульдер мен кезеңдер бар), мазмұн ақиқаты үшін емес — құрастыру алдында әрқашан сызбаны қарап шығыңыз.

Код логикасының ағынын баяндаушы
Ұзын кодты синтаксисті жолма-жол тыңдамай түсіну үшін: негізгі мәзірде «Код логикасының ағынын баяндаушы» ашыңыз, жобаны және код файлын таңдаңыз, содан кейін «Код баяндауы» түймесін басыңыз. IDE әр жолды индонезия сөйлеміне айналдырады (мысалы, егер жиынтық 100000-нан асса, келесі блокты орындаңыз), әдістер арасындағы шақыру картасын және әдістер арасындағы деректер ағыны талдауын (жіберілетін, пайдаланылатын немесе еленбейтін мәндер) көрсетеді және нәзік ықтимал қателерді олардың жол нөмірлерімен белгілейді — == арқылы салыстырылған String, жабылмай ашылған ағын және екі түрлі әдісте жазылған айнымалы. Егер белсенді AI провайдері «AI баптаулары» бөлімінде таңдалса, сол провайдерден ағын қорытындысы да қолжетімді; егер ол жоқ болса, экран офлайн баяндауды пайдаланады және бұл шектеуді айтады. Баяндау, шақыру картасы және деректер ағыны офлайн мәтін үлгісі талдауын пайдаланады, толық AST талдауышын емес — ашылу жақшасы өз жолында тұрған әдістер, сынып өрістері және рефлексия арқылы шақырулар бақыланбайды — және деректер жарысы ескертулері шын мәнінде тек кезектесіп пайдаланылатын айнымалы үшін пайда болуы мүмкін.

Қолданба бумасының зауыты және Play Store дайындығы
Телефоннан тікелей Google Play Store үшін қолданбаны дайындау үшін: негізгі мәзірде «Қолданба бумасының зауыты және Play Store дайындығы» ашыңыз, жобаны таңдаңыз, содан кейін «AAB бумасын құру» түймесін басыңыз. IDE нақты BundleConfig.pb көмегімен жоба манифестінен, ресурстардан және активтерден .aab файлын құрады, бума құрылымын тексереді, содан кейін буманы нақты нұсқа APK-дарына бөледі (негізгі, архитектура бойынша, тіл бойынша және әмбебап) сол бөлінуден өлшенген өлшемдермен, бағалаулар емес. Бума APK қол қою үшін пайдаланылатын сол жоба кілтімен JAR v1 арқылы қол қойылады, және оның қолтаңба тізбегі криптографиялық түрде тексеріледі. Бұл экран Play дайындығын да тексереді — 35-тен төмен мақсатты SDK «жоғары» деп белгіленеді, себебі Play Store 35 немесе одан жоғарыны талап етеді, және жоқ 64 биттік кітапхана да «жоғары» деп белгіленеді. Нақты bundletool құрылғыда жұмыс істей алмайды, себебі bundletool JVM талап етеді, ал Android-та JVM жоқ; жоғарыдағы жол құрылғыдағы ең жақын нақты жол.

OTA жаңарту қозғалтқышы және кезеңдік шығарылымдар
Пайдаланушыларды бүкіл APK-ді қайта жүктеуге мәжбүрлемей, шағын түзетуді жіберу үшін: негізгі мәзірде «OTA жаңарту қозғалтқышы және кезеңдік шығарылымдар» ашыңыз, жобаны таңдаңыз, ескі және жаңа нұсқа мазмұнын жазыңыз, содан кейін «Түзету бумасын жасау» түймесін басыңыз. IDE айырмашылықты есептейді және жаңа мазмұнның SHA-256 саусақ ізі бар түзету бумасын (patch-ota.zip) жасайды, содан кейін бұл құрылғы бірінші 10 пайыздық шығарылым қадамында екенін тексереді. Түзетулер енді кез келген файлда екілік дельтаны қолдайды (DEX және APK қоса), RSA-2048 қолтаңбасымен оралады және қолданар алдында сенімді ашық кілтпен тексеріледі және әзірлеуші серверінен оның шығарылым тізімімен жүктеп алуға болады; қолдану сәтсіз болса, ескі файл қол тигізбей қалады. Жұмыс істеп тұрған қолданбаға түзетуді қолдану жоба кілтімен қайта қол қою және PackageInstaller арқылы жасалады, себебі жұмыс істеп тұрған процестің кодын өз ішінен ауыстыру мүмкін емес — APK құлыпталған және DEX әлдеқашан жүктелген.

Топтық код шолу студиясы
Әріптес өзгерістерін қарап шығу және Git жебелерін оқымай біріктіру қақтығыстарын шешу үшін: негізгі мәзірде «Топтық код шолу студиясы» ашыңыз, жобаны таңдаңыз, үш мәтін нұсқасын теріңіз (негізгі, жергілікті, әріптес), содан кейін «Топтық шолуды ашу» түймесін басыңыз. IDE үшеуін Java синтаксис бірліктері негізінде біріктіреді — бір жолдағы екі өзгеріс, бірақ әртүрлі мәлімдемелерде енді қақтығыс деп есептелмейді — және әр қақтығысты дауыс беру таңдауы ретінде көрсетеді: жергілікті нұсқаны пайдаланыңыз, әріптес нұсқасын пайдаланыңыз немесе екеуін де біріктіріңіз — нәтиже жолы жол реті дұрыс болып қалуы үшін түпнұсқа қақтығыс орнына енгізіледі — содан кейін нәтижені жобада gabung-hasil.txt файлына жазады. Төменде жобаның жұмыс тақтасы орналасқан: тапсырма тақырыбын теріңіз, содан кейін «Тапсырма қосу» түймесін басыңыз; тапсырмалар жоба ішіндегі .tugas қалтасында мәтін ретінде сақталады және қолданба ішіндегі Git-те commit-тер арқылы синхрондалады, сондықтан тақтаны кез келген commit тарихынан қайта оқуға болады. Бұл синтаксис бөлінуі толық AST талдауышы емес және қолданба ішіндегі Git әр commit үшін толық суретті сақтайды; бөлек синхрондау сервері жоқ.

Код құрылымын дауыстап айту
Редактор ішінде дауыспен код жазу үшін: жобаны Редакторда ашып, содан кейін Код құрылымын дауыстап айту түймесін басыңыз. Пәрмендерді индонезия тілінде айтыңыз, мысалы buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil немесе buat variabel teks nama sama dengan Budi — IDE сөйлеуді синтаксистік тұрғыдан дұрыс Java, Kotlin, Python немесе Compose код блогына айналдырып, оны курсор орнына қояды, содан кейін Jieshuo арқылы қысқаша түйіндемені дауыстап оқиды. Дауыстап айту жүйенің кіріктірілген дауыс енгізу қызметін қолданады, қосымша микрофон рұқсатынсыз, және тек бұрыннан тіркелген пәрмен үлгілерін ғана таниды; осы үлгілерден тыс сөйлеу кодқа айналмайды. Сөзбен айтылған сандар (мысалы, 'lima') әлі цифрларға айналмайды.

Жергілікті бірлескен жұмыс бөлмесі (интернетсіз)
Интернетсіз бір бөлмеде бірге жұмыс істеу үшін: басты мәзірде Ынтымақтастық бөлімін ашып, содан кейін Жергілікті бірлескен жұмыс бөлмесі бөлімін ашыңыз. Бір телефон сеанс ашады (IDE жергілікті IP мекенжайы мен 6 таңбалы PIN көрсетеді), басқа телефон сол мекенжай мен PIN арқылы қосылады. Мәтін өзгерістері жол айырмашылықтары ретінде жіберіледі, құрастырылған APK сынаушының телефонына жіберілуі мүмкін, ал сынаушының телефонынан келген crash есептері кері қабылданады. Бір сеанс тек бір досқа арналған; егер екі адам дәл сол жолды бір уақытта өзгертсе, соңғы өзгеріс қолданылады. PIN жергілікті желіде ашық мәтін ретінде жіберіледі. Бұл бөлме нақты телефонда әлі сыналған жоқ.

AI баптаулары
Қолданбаларды құру үшін AI провайдерін және API кілттерін орнату үшін: негізгі мәзірде, параметрлер тобында «AI баптаулары» түймесін басыңыз («Коннектор» түймесінің жанында). Қолжетімді тізімнен пайдаланылатын провайдерді таңдаңыз және модель сәтсіз болса, IDE сол провайдердің келесі моделін автоматты түрде сынап көруі үшін «Провайдер қате бергенде модельді ауыстыру» белгісін қойыңыз. Сақтық кілттерді қосу үшін «API кілттерін басқару» түймесін басыңыз (атын және кілтті теріңіз, содан кейін «Сақтау» түймесін басыңыз; кілттер маскаланған түрде көрсетіледі, тек соңғы 4 таңба көрінеді). Кілттер телефонда сақталады және қолданбаны құру кезінде таңдалған провайдерден басқа ешқайда жіберілмейді. Таңдалған провайдер енді шынымен «Жобаның сызба сәулетшісі» және «Код логикасының ағынын баяндаушы» арқылы пайдаланылады; «AI қолданба жасаушы» экранында қолданба құру әлі телефондағы жергілікті AI пайдаланады (интернетсіз).

Коннектор
APK талдап, содан кейін оны жіберу үшін: басты мәзірде, Параметрлер тобында, Коннектор түймесін басыңыз (AI баптаулары түймесінің жанында). Телефоннан APK файлын таңдаңыз, IDE оның мазмұнын оқиды (бума атауы, нұсқасы, әрекеттер тізімі), содан кейін оны жүйенің бөлісу мәзірі арқылы жіберу үшін APK жіберу түймесін басыңыз (мысалы, WhatsApp немесе Drive).

Тіл және дауыс
Қолданбаның тілін өзгерту үшін: Параметрлер бөлімін ашып, содан кейін Қолданба тілі бөлімін ашып, тілді немесе Жүйеге сәйкес опциясын таңдаңыз. Басты экран және көптеген экрандар қолданбаны жапқансыз немесе қайта іске қоспай-ақ бірден таңдалған тілге ауысады; кейбір экрандар (мысалы, Терминал, Ынтымақтастық, AI баптаулары және Кілттерді басқару) қайта ашылғанша ескі тілді қолдана береді. Жүйеге сәйкес опциясын таңдасаңыз, тіл телефонның жүйелік тілін ұстанады.

Әр жобаға әдепкі қолтаңба және Anti Tamper
5.7 нұсқасынан бастап, жеке қолтаңбаны пайдаланбайтын жоба жобаның өз кіріктірілген кілтімен қол қойылады (жоба ішіндегі tanda-tangan-bawaan бумасында бір рет жасалып, содан кейін әрі қарай пайдаланылады), сондықтан кіріктірілген қолтаңба жобадан жобаға ерекшеленеді — енді барлық қолданбаларға ортақ кілт емес. tanda-tangan-bawaan бумасын жоймаңыз: осы кілтсіз жаңа APK сол жобаның ескі APK-сын ауыстыра алмайды. Әр жобаның параметрлері (бөлек архитектура, жеке қолтаңба, Anti Tamper, таңдалған keystore, SDK) енді жоба ішіндегі settings.gradle файлына сақталады және жоба құрастырылған сайын қайта оқылады. Параметрлер, Қолтаңба санатында, құрастырылған қолданбаға арналған Anti Tamper құсбелгісі бар: егер ол белсенді болса, құрастырылған қолданба құрылғыда қолтаңбасын және dex мазмұнын әр ашылған сайын тексереді; егер оны басқа біреу қайта қол қойған немесе өзгерткен болса, қолданба іске қосудан бас тартады. Frida/Xposed сияқты жөндеу және енгізу құралдары да анықталады, ал қолданба терезесі экран жазудан құлыпталған.

Демо бейне жасаушы
Құрастырылған қолданбаның демо бейнесін жасау үшін: негізгі мәзірде Демо бейне жасаушы ашыңыз, жобаны таңдап, бейне атауын толтырып, содан кейін Демо видео скриптін жасау басыңыз — IDE 5 стандартты көрінісі (ашылу, негізгі көрініс, 1-функция, 2-функция, жабылу) бар video-demo.txt файлын баяндау мәтінімен және әр көріністің ұзақтығымен бірге жазады. Жоба суреттерінен (белгіше + экран суреттері, егер бар болса) video-demo.html жасау үшін HTML Slideshow жасау басыңыз, олар әр 5 секунд сайын автоматты түрде ауысады. Бұл .mp4 бейне ЕМЕС — нақты бейне үшін video-demo.html файлын телефон браузерінде ашып, содан кейін экранды жазыңыз немесе іске қосылған қолданбаны жазып жатқанда video-demo.txt файлындағы баяндауды оқыңыз.

Android Studio стиліндегі жаңа көрініс
IDE сыртқы түрі енді Android Studio сияқты ретке келтірілді (тек сыртқы түрі — барлық түймелер, мәзірлер және ағындар дәл бұрынғыдай қалады): ашық сұр фон, қалың қара экран тақырыптары, ақ мәтіні бар көк түймелер және жұқа жиегі бар ақ енгізу өрістері. Негізгі мәзір көрнекі түрде топтастырылған (Жасаушының функциялары, Бұлт, Тақырып және басқалар, Дауыс, Код және жаңа функциялар, Құралдар) түймелердің ретін өзгертпестен. Терминал Android Studio-дағы Терминал терезесі сияқты қараңғы панельді әлі пайдаланады, ал код редакторының фоны әлі ақ, мәтіні қара. Барлық мәтін Jieshuo арқылы әлі анық оқылады.

Параметрлер
Қолданбаны баптау үшін: негізгі экрандағы опциялар мәзірін ашып, содан кейін Параметрлер басыңыз. Ішінде 12 санат бар: GitHub баптаулары (қауіпсіздік, жеке қолтаңба, құрастыру тарихы және GitHub токені), Құрылғыда APK құрастыру баптаулары (keystore құпия сөзін және құрастыру тарихын құрылғыда сақтау), Тақырып (қолданба түсі), Қолтаңба (жеке қолтаңбаға арналған keystore жасау және құрастырылған қолданбаға арналған Anti Tamper құсбелгісі), Жоба бумасы (жоба бумасының орны), Тіл және дауыс (интерфейс тілі және дауыс режимінің сөйлеу жылдамдығы), Мәтін өлшемі және сыртқы түрі (редактордың қаріп өлшемі), Құрастыру (Жоба жасау экранына арналған әдепкі мақсатты SDK және әдепкі архитектура бөлінісі), Хабарландырулар (құрастыру аяқталғанда дыбыс), Автоматты сақтық көшірме (жобаның сақтық көшірме кестесі), Әзірлеуші профилі (аты, WhatsApp нөмірі және қайырымдылық экранында көрсетілген шот) және Құпиялылық және деректер (параметрлерді қалпына келтіру және қолданба деректерін жою). Әр санатта санат мәзіріне оралу үшін Алдыңғыға оралу түймесі бар. Жаңа ғана сақталған параметрлер (әлі қолданылмаған) экранда адал түсіндіріледі.

Әзірлеушіге қайырымдылық
Әзірлеушіге қайырымдылық жасау немесе сәлем беру үшін: негізгі экранда Құрал туралы түймесінің жанындағы Әзірлеушіге қайырымдылық түймесін басыңыз. Қайырымдылық экранында BRI шотын көшіру түймесі бар — әзірлеушінің шот нөмірін көшіру үшін оны басып, содан кейін оны банк қолданбаңызға қойыңыз. Әзірлеушіге WhatsApp-та сәлем беру бөлімі де бар: атыңызды және туған қалаңызды толтырып, содан кейін WhatsApp-та жіберу басыңыз — WhatsApp сәлем хабары бұрыннан толтырылған күйде ашылады, тек WhatsApp-та жіберу басып, содан кейін қолданбаға оралыңыз. WhatsApp басқа қолданбаларға хабарларды автоматты түрде жіберуге рұқсат бермейді, сондықтан жіберуді әлі WhatsApp-та өзіңіз жасайсыз.

Терминалдың сүйікті командалары
Терминалда жиі қолданылатын пәрмендерді сақтау үшін: Терминал ашыңыз, содан кейін Таңдаулылар басыңыз. Жаңа сүйікті қосу басыңыз, атауын (мысалы Файлды көру) және оның пәрменін (мысалы ls -la) толтырып, содан кейін Сақтау басыңыз — сүйікті телефонда тұрақты сақталады. Оны терминалда тікелей іске қосу үшін сүйікті атауын басыңыз; Сүйіктіні жою басып, содан кейін жою үшін біреуін таңдаңыз (растаумен). Бұрыннан 3 кіріктірілген сүйікті бар: Файлды көру (ls -la), Орынды тексеру (df -h) және Экранды тазалау (clear) — барлығын жоюға болады. Бос пәрменді сақтауға да, іске қосуға да болмайды; Терминал бұл орын алса, хабармен және дауыспен хабарлайды.

Аналитика және сапа
Қолданбаны пайдалану және ақау туралы есептердің қорытындысын көру үшін: негізгі экранда Әзірлеушіге қайырымдылық түймесінің жанындағы Аналитика және сапа түймесін басыңыз. Бұл экран қолданбаның неше рет ашылғанын, қай экрандар жиі ашылатынын, ақаулар санын және қысқа түзету ұсыныстары бар соңғы ақаулар тізімін көрсетеді. Бұл деректер тек телефоныңызда сақталады және ешқайда жіберілмейді. Барлық деректерді жою үшін растау диалогы бар Аналитика деректерін жою түймесі бар. Соңғы экран тек негізгі экран мен осы экран үшін жазылады.

Қорытынды
Create Aplikasi қолданғаныңыз үшін рахмет. Бұл құрал сізге және телефоннан Android қолданбаларын жасауды үйренгісі келетін барлық адамға көмектеседі деп үміттенеміз. Ақаулар туындаса, оларды осы нұсқаулықтан қадамдап түзетіп, қайта көруден тартынбаңыз.
