ប្រភេទគម្រោងដែលមាន
• HTML៖ ការបង្ហាញពី index.html, style.css, និង script.js ដែលដំណើរការតាមរយៈ WebView។ បង្កើតដោយផ្ទាល់នៅលើទូរស័ព្ទ។
• Situs Web៖ គេហទំព័រដែលមានម៉ឺនុយ (Beranda, Tentang, Kontak) ពី index.html, tentang.html, kontak.html, style.css, និង script.js ដែលដំណើរការតាមរយៈ WebView។ បង្កើតដោយផ្ទាល់នៅលើទូរស័ព្ទ។
• Java៖ បង្កើតនៅលើទូរស័ព្ទ។ MainActivity ស្ថិតនៅក្នុង app/src/main/java/<nama-paket>/MainActivity.java។ ការបង្ហាញមកពី app/src/main/res/layout/activity_main.xml អត្ថបទមកពី app/src/main/res/values/strings.xml និងប្រធានបទមកពី app/src/main/res/values/styles.xml។
• Kotlin៖ អាចបង្កើតនៅលើឧបករណ៍ (offline) ដោយប្រើកម្មវិធីចងក្រង Kotlin ដែលរួមបញ្ចូលក្នុងកម្មវិធី ឬតាមរយៈ GitHub Actions។ MainActivity ស្ថិតនៅក្នុង app/src/main/java/<nama-paket>/MainActivity.kt ហើយឯកសារ res គឺដូចគ្នានឹងគម្រោង Java ដែរ។ ការបង្កើត Kotlin លើកដំបូងយឺតជាងមុនដោយសារទំហំធំនៃកម្មវិធីចងក្រង ហើយឯកសារ .java ដែលយោងទៅថ្នាក់ Kotlin មិនទាន់អាចបង្កើតបាននៅឡើយទេ (ឯកសារ .java ត្រូវបានចងក្រងមុនឯកសារ .kt)។
• Compose៖ កម្មវិធី Android ទំនើបដែលចំណុចប្រទាក់របស់វាត្រូវបានបង្កើតដោយ Jetpack Compose (មិនមែនជា layout XML ទេ)។ MainActivity ស្ថិតនៅក្នុង app/src/main/java/<nama-paket>/MainActivity.kt។ គម្រោង Compose ត្រូវបានបង្កើតតាមរយៈ GitHub Actions (ម៉ឺនុយ Bangun proyek បន្ទាប់មក Bangun online) ឬនៅក្នុង Termux ដោយប្រើ Gradle ព្រោះ Compose ត្រូវការបណ្ណាល័យ Jetpack Compose ដែលមិនមាននៅលើឧបករណ៍។
• Python៖ តក្កវិជ្ជានៃកម្មវិធីត្រូវបានសរសេរជាភាសា Python (Chaquopy) នៅក្នុង app/src/main/python/main.py ហើយត្រូវបានដំណើរការដោយ host MainActivity.java នៅក្នុង app/src/main/java/<nama-paket>/MainActivity.java។ គម្រោង Python អាចបង្កើតដោយផ្ទាល់នៅលើទូរស័ព្ទ (runtime Chaquopy ត្រូវបានរួមបញ្ចូលក្នុងកម្មវិធី) ឬតាមរយៈ GitHub Actions។ SDK អប្បបរមានៃគម្រោង Python គឺ 24 (Android 7.0)។

ផ្លាស់ប្តូរស្ថាបត្យកម្មគម្រោង
ដើម្បីផ្លាស់ប្តូរជម្រើសស្ថាបត្យកម្មរបស់គម្រោងដែលមានស្រាប់ដោយមិនបង្កើតគម្រោងថ្មី៖ ចុច «ផ្លាស់ប្តូរស្ថាបត្យកម្មគម្រោង» នៅក្នុងម៉ឺនុយមេ បន្ទាប់មកជ្រើសរើសគម្រោង ហើយផ្លាស់ប្តូរប្រអប់ធីក «សាងសង់ APK 64 ប៊ីត (arm64-v8a)» ឬ «សាងសង់ APK 32 ប៊ីត (armeabi-v7a)»។ ឬចុចឱ្យយូរលើឈ្មោះគម្រោងនៅក្នុង «គ្រប់គ្រងគម្រោង» ហើយជ្រើសរើស «ផ្លាស់ប្តូរស្ថាបត្យកម្ម» ដើម្បីបើកអេក្រង់ដូចគ្នាដោយផ្ទាល់សម្រាប់គម្រោងនោះ។ ច្បាប់គឺ៖ ប្រសិនបើប្រអប់ធីកទាំងពីរត្រូវបានបើក ការសាងសង់បង្កើតឯកសារ APK ដាច់ដោយឡែកពីរ មួយ 64 ប៊ីត និងមួយ 32 ប៊ីត។ ប្រសិនបើប្រអប់ធីកតែមួយត្រូវបានបើក ការសាងសង់បង្កើតឯកសារ APK សកលតែមួយដែលនៅតែដំណើរការលើឧបករណ៍ 64 ប៊ីត និង 32 ប៊ីតទាំងពីរ។ ឯកសារ APK ដាច់ដោយឡែកសម្រាប់តែវ៉ារ្យ៉ង់មួយមិនទាន់ត្រូវបានគាំទ្រទេ ពីព្រោះផ្លូវសាងសង់ដឹងតែជម្រើសដែលបានបំបែក ឬសកលប៉ុណ្ណោះ ប៉ុន្តែជម្រើសនៃវ៉ារ្យ៉ង់នីមួយៗនៅតែត្រូវបានរក្សាទុកក្នុងគម្រោង ដូច្នេះវាមិនបាត់បង់នៅពេលអេក្រង់ត្រូវបានបើកម្តងទៀតទេ។

ដើម្បីធ្វើការលើគម្រោងមួយជាមួយមិត្តភក្តិ — បើកកិច្ចសហការនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង សរសេរកំណត់ចំណាំផ្លាស់ប្តូរ (តើមានអ្វីផ្លាស់ប្តូរ) ហើយចុចចែករំលែកសម្រាប់កិច្ចសហការ។ គម្រោងត្រូវបានផ្ញើជា ZIP ជាមួយនឹងឯកសារ CATATAN.txt នៅខាងក្នុង។ មិត្តភក្តិរបស់អ្នកធ្វើការលើវា ហើយផ្ញើ ZIP មកវិញ។ អ្នកចុចទទួលយកចម្លើយ ជាដំបូងអានកំណត់ចំណាំផ្លាស់ប្តូរ បន្ទាប់មកជ្រើសរើសអនុវត្ត ដើម្បីជំនួសគម្រោងចាស់ ឬបោះបង់ ប្រសិនបើអ្នកផ្លាស់ប្តូរចិត្ត។ ZIP ដោយគ្មាន CATATAN.txt មិនមែនជាកញ្ចប់កិច្ចសហការទេ — សម្រាប់ ZIP គម្រោងធម្មតា សូមប្រើនាំចូលគម្រោងនៅក្នុងគ្រប់គ្រងគម្រោង។

កម្មវិធីបកប្រែកម្មវិធីដោយស្វ័យប្រវត្តិ
ដើម្បីបកប្រែអត្ថបទរបស់កម្មវិធីទៅជាភាសាផ្សេង — បើកអ្នកបកប្រែកម្មវិធីនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង និងភាសាគោលដៅ (អង់គ្លេស អារ៉ាប់ ឬជប៉ុន) ហើយចុចបកប្រែ។ វចនានុក្រមមាននៅក្នុងទូរសព្ទរួចហើយ (ដោយគ្មានអ៊ីនធឺណិត ដោយឥតគិតថ្លៃ) ហើយមានពាក្យប្រើប្រចាំថ្ងៃ។ អត្ថបទត្រូវបានអានពី strings.xml ប្លង់ និងកូដ ហើយត្រូវបានបកប្រែ។ លទ្ធផលត្រូវបានសរសេរទៅក្នុងថត values-ភាសា/strings.xml (ប្រសិនបើគម្រោងមាន strings.xml) និងរបាយការណ៍ terjemahan-ភាសា.txt នៅក្នុងថតគម្រោង។ ពាក្យដែលមិនទាន់មាននៅក្នុងវចនានុក្រមត្រូវបានទុកដដែល និងរាយការណ៍ — ដូច្នេះអ្នកដឹងថាពាក្យណាដែលអ្នកត្រូវបកប្រែដោយខ្លួនឯង។

អ្នកបង្កើតហ្គេមដោយគ្មានកូដ
ដើម្បីបង្កើតហ្គេមដោយមិនសរសេរកូដ — បើកកម្មវិធីបង្កើតហ្គេមដោយគ្មានកូដនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសប្រភេទហ្គេម (ទាយលេខ កម្រងសំណួរ ឬចាប់ផ្កាយ) បំពេញឈ្មោះហ្គេម ចំនួន (កម្រិត/សំណួរ/ផ្កាយ) និងសារឈ្នះ ហើយចុចបង្កើតហ្គេម។ ហ្គេមត្រូវបានបង្កើតជាគម្រោងពិតប្រាកដដែលអាចដំណើរការដោយផ្ទាល់នៅក្នុងគ្រប់គ្រងគម្រោង ហើយសាងសង់ជា APK ដូចជាគម្រោងផ្សេងទៀត។

សាកល្បងកម្មវិធីដោយស្វ័យប្រវត្តិ
ដើម្បីពិនិត្យគម្រោងមុនពេលសាងសង់ — នៅក្នុងគ្រប់គ្រងគម្រោង សូមចុចឱ្យជាប់លើឈ្មោះគម្រោង ហើយជ្រើសរើសការធ្វើតេស្តដោយស្វ័យប្រវត្តិ។ IDE ពិនិត្យរឿង ១០ យ៉ាងដោយមិនសាងសង់ APK — ឯកសារចាំបាច់មានវត្តមាន (ឯកសារទិន្នន័យគម្រោង manifest ឯកសារសំខាន់ ប្លង់ ខ្សែអក្សរ) ឈ្មោះកញ្ចប់ និងកំណែ ការអនុញ្ញាតដែលបានប្រើ រូបតំណាង និងតុល្យភាពនៃដង្កៀបកូដ។ លទ្ធផលត្រូវបានបង្ហាញធាតុមួយម្តងមួយៗ (ជាមួយនឹងសារជោគជ័យ/បរាជ័យ) ហើយ Jieshuo អានវាដោយសំឡេង។ ជួសជុលអ្វីៗដែលបរាជ័យជាមុនសិន បន្ទាប់មកចុចសាងសង់គម្រោង។

AI ពិនិត្យកូដ
ដើម្បីពិនិត្យកូដគម្រោងសម្រាប់គំរូដែលជារឿយៗបង្កបញ្ហា — បើកពិនិត្យកូដនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង ហើយចុចពិនិត្យកូដ។ កម្មវិធីពិនិត្យដំណើរការនៅក្នុងទូរសព្ទ (ដោយគ្មានអ៊ីនធឺណិត) ហើយស្វែងរកអថេរដែលមិនបានប្រើ មុខងារទទេ រង្វិលជុំគ្មានទីបញ្ចប់ដែលច្បាស់ អត្ថបទដែលសរសេរដោយផ្ទាល់ទៅក្នុងកូដ (ប្រសើរជាងនៅក្នុង strings.xml) ការអនុញ្ញាត និង API ដែលមានគ្រោះថ្នាក់ សញ្ញាសម្គាល់ TODO/FIXME និងចលនាដែលកំពុងដំណើរការ។ ការរកឃើញនីមួយៗរួមមានឈ្មោះឯកសារ លេខបន្ទាត់ និងការណែនាំសម្រាប់ការជួសជុល។ កម្មវិធីពិនិត្យនេះផ្អែកលើគំរូ ហើយមិនមែនជា AI ពិតប្រាកដទេ — បញ្ហាដែលមិនអនុវត្តតាមគំរូនៅតែអាចខកខានបាន។

របៀបរៀនអន្តរកម្ម
ដើម្បីរៀនបង្កើតកម្មវិធីជាជំហានៗ — បើករបៀបរៀននៅក្នុងម៉ឺនុយមេ។ មានមេរៀន ៥ — បង្កើតគម្រោងដំបូងរបស់អ្នក បន្ថែមប៊ូតុង ផ្លាស់ប្តូរពណ៌ បន្ថែមសំឡេង និងសាងសង់ APK។ ចុចមេរៀនមួយដើម្បីអានការពន្យល់ និងកិច្ចការអនុវត្តន៍ ធ្វើកិច្ចការ ហើយចុចពិនិត្យកិច្ចការ — IDE ពិតជាពិនិត្យថាតើកិច្ចការបានបញ្ចប់ឬអត់ (ដោយស្កេនគម្រោង និង APK របស់អ្នកនៅលើទូរសព្ទ)។ មេរៀនដែលបានបញ្ចប់ជោគជ័យត្រូវបានសម្គាល់ថាបានបញ្ចប់ និងរក្សាទុក។

សមកាលកម្ម Cloud
ដើម្បីបម្រុងទុកគម្រោងទៅ Cloud — បើកធ្វើសមកាលកម្ម Cloud នៅក្នុងម៉ឺនុយមេ។ ការបម្រុងទុកក្នុងស្រុករក្សាទុកគម្រោង ZIP ដែលមានត្រាពេលវេលាទៅក្នុងថត Download/cloud ហើយអាចស្តារឡើងវិញបានគ្រប់ពេលពីបញ្ជីបម្រុងទុក។ ការបម្រុងទុក GitHub បង្ហោះគម្រោង ZIP ទៅកាន់ repo ឯកជនរបស់អ្នក (ដោយប្រើថូខឹនពីការកំណត់ GitHub) ហើយអាចទាញយកឡើងវិញបាន។ នេះគឺជាការបម្រុងទុក និងស្តារដោយដៃ — ការធ្វើសមកាលកម្មពីរទិសពេញលេញដោយស្វ័យប្រវត្តិតម្រូវឱ្យមានម៉ាស៊ីនមេ ដូច្នេះវាមិនទាន់មានទេ។

កម្មវិធីបង្កើត Backend ដោយស្វ័យប្រវត្តិ
ដើម្បីបង្កើត Backend ដោយមិនសរសេរកូដម៉ាស៊ីនមេ — បើកកម្មវិធីបង្កើត Backend នៅក្នុងម៉ឺនុយមេ ជ្រើសរើសប្រភេទ Backend (កំណត់ចំណាំ បញ្ជីកិច្ចការ ឬផ្ទាំងប្រកាស) បំពេញឈ្មោះគម្រោង ហើយចុចបង្កើត Backend។ IDE បង្កើតគម្រោង HTML ពិតប្រាកដជាមួយនឹងទម្រង់ទំព័រ និងបញ្ជីទិន្នន័យដែលបានរក្សាទុកក្នុងការផ្ទុកក្នុងស្រុករបស់ទូរសព្ទ (localStorage) — ទិន្នន័យត្រូវបានរក្សាទុក និងអានឡើងវិញនៅពេលកម្មវិធីដំណើរការ។ Backend នេះដំណើរការលើទូរសព្ទតែមួយ។ មិនមានម៉ាស៊ីនមេអ៊ីនធឺណិតទេ ដូច្នេះទូរសព្ទពីរមិនទាន់អាចចែករំលែកទិន្នន័យដូចគ្នាបានទេ។

ដើម្បីផ្តល់ឱ្យគម្រោងនូវពណ៌ Theme — បើកអ្នករចនា Theme នៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង និង Theme (ពន្លឺ ងងឹត ខៀវ បៃតង ក្រហម ឬស្វាយ)។ ការមើលជាមុនបង្ហាញពណ៌ទាំង ៦ របស់ Theme (សំខាន់ សំខាន់ងងឹត សំឡេងផ្ទៃខាងក្រោយ អត្ថបទ អត្ថបទបន្ទាប់បន្សំ) ហើយ Jieshuo អានវាដោយសំឡេង។ ចុចអនុវត្ត Theme — IDE សរសេរ colors.xml និង styles.xml (រចនាប័ទ្ម app_theme) ទៅក្នុងគម្រោង ដែលត្រូវបានប្រើដោយផ្ទាល់នៅពេលគម្រោងដំណើរការ ឬសាងសង់។

អ្នកបង្កើតចលនា
ដើម្បីផ្តល់ឱ្យគម្រោងនូវចលនា — បើកកម្មវិធីបង្កើតចលនានៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង ប្រភេទចលនា (រសាយ រអិល បង្វិល លោត ឬលោតឡើង) រយៈពេល (១០០ ទៅ ១០០០០ មិល្លីវិនាទី) និងគោលដៅ (ប៊ូតុង អត្ថបទ ឬរូបភាព) ហើយចុចបង្កើតចលនា។ IDE សរសេរឯកសារចលនាពិតប្រាកដ (res/anim/anim_<ប្រភេទ>.xml សម្រាប់គម្រោង Java/Kotlin/Compose ឬ animasi.css សម្រាប់គម្រោង HTML/គេហទំព័រ) ជាមួយនឹងកូដគំរូប្រើប្រាស់ដែលបង្ហាញនៅលើអេក្រង់។

អ្នកថតសកម្មភាព
ដើម្បីធ្វើការងារឡើងវិញដោយស្វ័យប្រវត្តិ — IDE កត់ត្រាសកម្មភាពដែលអ្នកបានធ្វើ (បើកគម្រោង ដំណើរការ សាងសង់ នាំចេញ បម្រុងទុក បង្កើតគម្រោង រក្សាទុកឯកសារ)។ បើកកម្មវិធីថតសកម្មភាពនៅក្នុងម៉ឺនុយមេ ហើយមើលបញ្ជីសកម្មភាពដែលបានកត់ត្រាជាមួយនឹងលំដាប់របស់វា ហើយចុចចាក់ឡើងវិញ — IDE ធ្វើសកម្មភាពដែលអាចធ្វើស្វ័យប្រវត្តិឡើងវិញ (ការបម្រុងទុក និងការបង្កើតគម្រោងត្រូវបានធ្វើនៅទីនោះ។ ការដំណើរការ ការសាងសង់ និងការនាំចេញបើកអេក្រង់សំខាន់របស់វា។ ការបើក និងការរក្សាទុកបើកកម្មវិធីកែសម្រួល)។ សកម្មភាពដែលមិនអាចធ្វើស្វ័យប្រវត្តិបានត្រូវបានរំលង និងរាយការណ៍នៅចុងបញ្ចប់។

សុវត្ថិភាពស្វ័យប្រវត្តិ
ដើម្បីពិនិត្យសុវត្ថិភាពរបស់គម្រោង — បើកសុវត្ថិភាពដោយស្វ័យប្រវត្តិនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង ហើយចុចពិនិត្យសុវត្ថិភាព។ IDE ពិនិត្យរឿង ៨ យ៉ាងក្នុងស្រុក (ដោយគ្មានអ៊ីនធឺណិត) — ការអនុញ្ញាតដែលមានគ្រោះថ្នាក់ (ទីតាំង SMS ការហៅ កាមេរ៉ា មីក្រូហ្វូន ទំនាក់ទំនង) ការផ្ញើទិន្នន័យតាមរយៈ HTTP ការផ្ញើ SMS ការហៅចេញ ពាក្យសម្ងាត់ ឬសោដែលសរសេរដោយផ្ទាល់ទៅក្នុងកូដ WebView ដែលមិនបានការពារ សមាសធាតុដែលបាននាំចេញដោយគ្មានការអនុញ្ញាត និងអាសយដ្ឋាន http ដែលមិនបានអ៊ិនគ្រីប។ ការរកឃើញនីមួយៗទទួលបានកម្រិតមានសុវត្ថិភាព ការព្រមាន ឬគ្រោះថ្នាក់ជាមួយនឹងការណែនាំសម្រាប់ការជួសជុល ហើយសង្ខេបត្រូវបាន Jieshuo អានដោយសំឡេង។

AI ក្រៅបណ្តាញ
ដើម្បីប្រើជំនួយអត្ថបទ និងកូដដោយគ្មានអ៊ីនធឺណិត — បើក AI ក្រៅបណ្តាញនៅក្នុងម៉ឺនុយមេ។ មានឧបករណ៍ ៤ — កែអត្ថបទ (អក្សរធំ វណ្ណយុត្តិ និងចន្លោះពីរដង) សង្ខេបអត្ថបទ (យកប្រយោគសំខាន់បំផុត ៣) បង្កើតឈ្មោះកម្មវិធី (ពីការពិពណ៌នាដែលបានសរសេរ) និងណែនាំឈ្មោះអថេរ (ស្វែងរកឈ្មោះអថេរ ១–២ តួអក្សរនៅក្នុងគម្រោង)។ ទាំងនេះគឺជាច្បាប់សាមញ្ញនៅក្នុងទូរសព្ទ មិនមែនជាម៉ូដែល AI ពិតប្រាកដទេ។ លទ្ធផលកែអត្ថបទអាចអនុវត្តទៅ strings.xml របស់គម្រោងដោយប៊ូតុងអនុវត្ត។

អ្នកបង្កើត Widget និង Wallpaper
ដើម្បីបង្កើត Widget សម្រាប់អេក្រង់ដើម — បើក Widget និង Wallpaper នៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង បំពេញអត្ថបទ Widget ហើយចុចបង្កើត Widget។ IDE សរសេរ WidgetSaya.java ប្លង់ Widget ព័ត៌មាន Widget ហើយបន្ថែមអ្នកទទួលទៅ AndroidManifest.xml របស់គម្រោង — សាងសង់គម្រោង ហើយបន្ថែម Widget ពីអេក្រង់ដើមរបស់ទូរសព្ទ។ សម្រាប់ Wallpaper — បំពេញអត្ថបទ និងពណ៌ផ្ទៃខាងក្រោយ និងអត្ថបទ ធ្វើការមើលជាមុន ហើយរក្សាទុកជា PNG ទៅក្នុងថត Download ឬកំណត់ដោយផ្ទាល់ជា Wallpaper ទូរសព្ទ។

ការរួមបញ្ចូលបណ្តាញសង្គម
ដើម្បីបន្ថែមប៊ូតុងចែករំលែកទៅកម្មវិធី — បើកការរួមបញ្ចូលប្រព័ន្ធផ្សព្វផ្សាយសង្គមនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង ហើយបន្ថែមការចែករំលែកទៅ WhatsApp Facebook ឬ Telegram (ឬទាំងបីក្នុងពេលតែមួយ)។ IDE សរសេរកូដចែករំលែកពិតប្រាកដទៅក្នុងឯកសារសំខាន់របស់គម្រោង (MainActivity ឬ index.html)។ ប៊ូតុងសាកល្បងការចែករំលែកបើកកម្មវិធីជ្រើសរើសការចែករំលែកពី IDE ជាមួយនឹងអត្ថបទគំរូ ដូច្នេះអ្នកអាចមានអារម្មណ៍ពីលំហូរមុនពេលសាងសង់កម្មវិធី។

កម្មវិធីពីរូបភាព
ដើម្បីបង្កើតកម្មវិធីវិចិត្រសាលរូបថតពីរូបភាព — បើកកម្មវិធីពីរូបភាពនៅក្នុងម៉ឺនុយមេ ហើយជ្រើសរើសរូបភាពពីវិចិត្រសាលរូបថត។ IDE វិភាគទំហំ និងពណ៌សំខាន់របស់រូបភាព ហើយបង្កើតគម្រោងកម្មវិធីវិចិត្រសាលរូបថតពិតប្រាកដ — រូបភាពត្រូវបានចម្លងទៅ assets របស់គម្រោង ពណ៌ Theme ត្រូវបានយកពីពណ៌សំខាន់របស់រូបភាព ឈ្មោះកម្មវិធីត្រូវបានយកពីឈ្មោះឯកសាររូបភាព។ បើកគ្រប់គ្រងគម្រោងដើម្បីដំណើរការ ឬសាងសង់កម្មវិធីវិចិត្រសាលរូបថត។

ដើម្បីប្រើកម្មវិធីអន្តរកម្មនៅក្នុងស្ថានីយ — បើកស្ថានីយនៅក្នុងម៉ឺនុយមេ ហើយដំណើរការ nano vim top ឬ htop។ ស្ថានីយឥឡូវនេះប្រើកម្មវិធីញែក VT (ក្រឡាចត្រង្គអេក្រង់ ២៤ ជួរ x ៨០ ជួរ) ដូច្នេះកម្មវិធីទាំងនេះត្រូវបានបង្ហាញយ៉ាងត្រឹមត្រូវ — ទស្សន៍ទ្រនិចផ្លាស់ទី បន្ទាត់ត្រូវបានលុប អេក្រង់ផ្លាស់ប្តូរដូចជាស្ថានីយពិតប្រាកដ។ មានប៊ូតុងពិសេសសម្រាប់ Tab ព្រួញឡើង ព្រួញចុះ និង Esc ដើម្បីគ្រប់គ្រងកម្មវិធីអន្តរកម្ម។ លទ្ធផលនៅតែជាអត្ថបទដែល Jieshuo អាចអានបាន។ ចុចអានអេក្រង់ដើម្បីស្តាប់បន្ទាត់ចុងក្រោយ។

Terminal Exec (គោលពីរនៃកម្មវិធី)
ដើម្បីដំណើរការឯកសារប្រព័ន្ធគោលពីថតកម្មវិធី (ឧទាហរណ៍ aapt2 ECJ D8) ពីស្ថានីយ — វាយបញ្ចូលពាក្យបញ្ជាដូចធម្មតា។ IDE ប្រើ libkautsarexec.so ដូច្នេះឯកសារប្រព័ន្ធគោលនៅក្នុងថតកម្មវិធីអាចដំណើរការនៅលើ Android 10 និងថ្មីជាងនេះ។ ដើម្បីពិនិត្យថាតើផ្លូវ exec ប្រព័ន្ធគោលដំណើរការនៅលើទូរសព្ទនេះឬអត់ សូមចុចសាកល្បង Exec នៅក្នុងស្ថានីយ — លទ្ធផលត្រូវបានបង្ហាញតាមដែលវាមាន។ ប្រសិនបើប្រព័ន្ធទប់ស្កាត់ exec ពាក្យបញ្ជាប្រព័ន្ធ និងស្គ្រីប shell នៅតែដំណើរការ។ ដំណើរការឯកសារប្រព័ន្ធគោលតាមរយៈម៉ឺនុយសាងសង់គម្រោង។

Terminal នៅតែមានជីវិត (KeepAlive)
ដើម្បីរក្សា shell ឱ្យនៅដំណើរការនៅពេលអ្នកប្តូរអេក្រង់ — បើកស្ថានីយ ដំណើរការពាក្យបញ្ជា ហើយចុចត្រឡប់ ឬប្តូរទៅអេក្រង់ផ្សេង — shell មិនស្លាប់ទេ ការជូនដំណឹងស្ថានីយនៅតែបង្ហាញ ដូច្នេះអ្នកអាចត្រឡប់មកវិញដោយចុចតែម្តង។ ពាក្យបញ្ជាដែលបានដំណើរការត្រូវបានរក្សាទុកនៅក្នុងប្រវត្តិ (ប៊ូតុងប្រវត្តិ ឬព្រួញឡើង/ចុះនៅក្នុងវាលពាក្យបញ្ជា) ហើយពាក្យបញ្ជាដែលប្រើញឹកញាប់អាចរក្សាទុកជាចំណូលចិត្ត (ប៊ូតុងចំណូលចិត្ត)។ នៅពេលរួចរាល់ សូមចុចបិទ shell ដើម្បីបញ្ចប់ shell ពិតប្រាកដ។ ម៉ឺនុយគម្រោង និងម៉ឺនុយកម្មវិធីកែសម្រួលក៏មានប៊ូតុងសាងសង់នៅក្នុងស្ថានីយផងដែរ — ស្ថានីយបើកនៅក្នុងថតគម្រោងជាមួយនឹងពាក្យបញ្ជាសាងសង់ដែលបានបំពេញជាមុន។

ដំឡើងឧបករណ៍ Terminal (សាកល្បង)
មុខងារសាកល្បង — នៅក្នុងស្ថានីយមានប៊ូតុងដំឡើងឧបករណ៍ស្ថានីយ (សាកល្បង) ដើម្បីដំឡើងបរិស្ថាន Termux ពី repo alat-termux របស់អ្នកអភិវឌ្ឍន៍ (github.com/syudat/alat-termux) ជាផ្លូវជំនួសបន្ថែមលើប៊ូតុងដំឡើង Termux ដែលយកពីការចេញផ្សាយ Termux ផ្លូវការ។ មាតិកានៃកញ្ចក់គឺដូចគ្នាបេះបិទនឹងការចេញផ្សាយផ្លូវការ ហើយត្រូវបានពិនិត្យដោយ SHA-256 កំឡុងពេលដំឡើង។ បន្ទាប់ពីបរិស្ថានត្រូវបានដំឡើង អ្នកអាចប្រើពាក្យបញ្ជា pkg update និង pkg install ហើយឧបករណ៍បន្ថែមពី repo ក៏ត្រូវបានដំឡើងទៅក្នុងស្ថានីយផងដែរ — info-terminal ដើម្បីមើលព័ត៌មានបរិស្ថាន bersih-terminal ដើម្បីសម្អាតឃ្លាំងសម្ងាត់ និង cadangkan-proyek ដើម្បីរក្សាទុកថតគម្រោងទៅក្នុងឯកសារ tar.gz តែមួយដែលមានកាលបរិច្ឆេទ។ បន្ទាប់មកកម្មវិធីដំឡើងដោយស្វ័យប្រវត្តិនូវកញ្ចប់ Linux មូលដ្ឋាន (git python curl wget nano openssh zip unzip) និងឧបករណ៍សាងសង់ APK ដែលបានចុះហត្ថលេខា (openjdk-21 kotlin gradle ecj aapt2 d8 apksigner clang cmake ninja make) ពី repo Termux ផ្លូវការ ដូច្នេះស្ថានីយរួចរាល់ភ្លាមៗដើម្បីសាងសង់កម្មវិធី។ ការទាញយកកញ្ចប់ធំៗ (រាប់រយ MB) អាចចំណាយពេលយូរ។ ខណៈពេលដំឡើងដំណើរការ វឌ្ឍនភាព និងលទ្ធផលពាក្យបញ្ជាត្រូវបានបង្ហាញនៅលើអេក្រង់សំខាន់របស់ស្ថានីយ ហើយលទ្ធផលចុងក្រោយត្រូវបានអានដោយសំឡេងដោយកម្មវិធីអានអេក្រង់។ ប្រសិនបើការដំឡើងកញ្ចប់មិនទាន់បញ្ចប់ សូមចុចដំឡើងឧបករណ៍ស្ថានីយ (សាកល្បង) ម្តងទៀតដើម្បីបន្ត។

របៀបសំឡេងពេញលេញ
ដើម្បីគ្រប់គ្រង IDE ទាំងស្រុងដោយសំឡេង — បើករបៀបសំឡេងពេញលេញនៅក្នុងម៉ឺនុយមេ ហើយចុចចាប់ផ្តើមស្តាប់។ IDE ស្តាប់ជាបន្តបន្ទាប់ — មិនចាំបាច់ចុចប៊ូតុងសម្រាប់ពាក្យបញ្ជានីមួយៗទេ — ដំណើរការពាក្យបញ្ជា ហើយឆ្លើយដោយសំឡេង។ មានពាក្យបញ្ជា ២៦ — បង្កើត សាងសង់ បើក ដំណើរការ រាយបញ្ជី ស្វែងរក លុប សាកល្បង ពិនិត្យ នាំចេញ បម្រុងទុក ចែករំលែក បង្កើតរូបតំណាង បកប្រែ សាងសង់នៅក្នុងស្ថានីយ អានអេក្រង់ បើកអេក្រង់ទាំងអស់ (រួមទាំងសុវត្ថិភាព AI ក្រៅបណ្តាញ Widget ប្រព័ន្ធផ្សព្វផ្សាយសង្គម ហ្គេម ការរៀន Cloud Backend Theme ចលនា កម្មវិធីថត) ត្រឡប់ បិទ និងជំនួយ។ ប្រសិនបើរបៀបនៅតែសកម្ម ការស្តាប់បន្តដោយស្វ័យប្រវត្តិនៅពេលអ្នកបើកអេក្រង់នេះឡើងវិញ។ ដើម្បីបិទរបៀប សូមចុចឈប់ស្តាប់។ ប្រសិនបើទូរសព្ទមិនមានសេវាសម្គាល់សំឡេងទេ ពាក្យបញ្ជានៅតែអាចវាយបញ្ចូលក្នុងវាលអត្ថបទបាន។

អ្នកបកប្រែកូដ
ដើម្បីបកប្រែកូដរវាងភាសាដោយគ្មានអ៊ីនធឺណិត — បើកអ្នកបកប្រែកូដនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង ជ្រើសរើសឯកសារប្រភព (.java/.kt) ហើយជ្រើសរើសទិសដៅ — Java ទៅ Kotlin។ ចុចបកប្រែ — លទ្ធផលត្រូវបានបង្ហាញជាមួយនឹងរបាយការណ៍នៃបន្ទាត់ដែលមិនអាចបកប្រែបាន (បន្ទាត់ទាំងនេះត្រូវបានទុកដដែល និងសម្គាល់)។ ចុចរក្សាទុកលទ្ធផលដើម្បីសរសេរឯកសារថ្មីនៅក្នុងថតដូចគ្នា (ឈ្មោះ-បកប្រែ.java/.kt)។ ឯកសារដើមមិនដែលត្រូវបានជំនួសទេ។ នេះគឺជាកម្មវិធីបកប្រែតាមគំរូ មិនមែនជាកម្មវិធីចងក្រងទេ — តែងតែពិនិត្យលទ្ធផលមុនពេលប្រើវា។

ដើម្បីប្រើ Git នៅក្នុង IDE ដោយមិនចាំបាច់មាន Termux — បើក Git នៅក្នុងកម្មវិធីនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង ហើយចុចបង្កើត Git Repo ដើម្បីបង្កើត repo ក្នុងស្រុក (.git) នៅក្នុងគម្រោងនោះ។ ចុចពិនិត្យស្ថានភាពដើម្បីមើលឯកសារថ្មី ផ្លាស់ប្តូរ ឬលុបបើប្រៀបធៀបនឹង Commit ចុងក្រោយ។ បំពេញសារ Commit ហើយចុច Commit ដើម្បីរក្សាទុករូបថតរបស់គម្រោង។ ចុចមើល Commit Log ដើម្បីមើលប្រវត្តិ Commit។ Push ទៅ GitHub និង Pull ពី GitHub ប្រើរូបថតតាមរយៈថូខឹន GitHub (repo pembuat-aplikasi-build) — មិនមែនជាពិធីការ git ទេ។ Clone Push (system-git) និង Pull (system-git) ដំណើរការតែនៅពេលដែលប្រព័ន្ធគោល git ត្រូវបានដំឡើងនៅលើទូរសព្ទ (ជាធម្មតាមិនមានទេ)។ នេះមិនមែនជា Git ពេញលេញទេ — មិនមានការបញ្ចូលគ្នា សាខា ឬភាពខុសគ្នាទេ — Commit នីមួយៗរក្សាទុករូបថត ZIP ពេញលេញរបស់គម្រោង។

អ្នកបង្កើតពាណិជ្ជកម្ម
ដើម្បីបន្ថែមការផ្សាយពាណិជ្ជកម្មទៅកម្មវិធីដែលបានសាងសង់ — បើកកម្មវិធីបង្កើតការផ្សាយពាណិជ្ជកម្មនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង អ្នកផ្តល់សេវា (AdMob Unity Ads ឬ AppLovin) និងប្រភេទការផ្សាយពាណិជ្ជកម្ម (Banner Interstitial ឬទទួលបានរង្វាន់)។ បំពេញលេខសម្គាល់ឯកតាការផ្សាយពាណិជ្ជកម្មប្រសិនបើអ្នកមាន — ប្រសិនបើទទេ លេខសម្គាល់សាកល្បងត្រូវបានប្រើ (AdMob ប្រើលេខសម្គាល់សាកល្បងផ្លូវការរបស់ Google។ Unity ប្រើ Game ID គំរូ។ AppLovin ប្រើកន្លែងទទេ)។ ចុចបង្កើតកូដផ្សាយពាណិជ្ជកម្មដើម្បីមើលកូដ Java និង Kotlin និងការណែនាំ។ ចុចរក្សាទុកទៅក្នុងគម្រោងដើម្បីសរសេរអ្វីៗទាំងអស់ទៅក្នុងឯកសារ iklan-<អ្នកផ្តល់សេវា>-<ប្រភេទ>.txt នៅក្នុងគម្រោង។ នេះគឺជាគំរូកូដ + ការណែនាំ មិនមែនជា SDK ការផ្សាយពាណិជ្ជកម្មទេ — SDK មិនត្រូវបានរួមបញ្ចូលនៅក្នុង IDE ទេ។ ការផ្សាយពាណិជ្ជកម្មពិតប្រាកដលេចឡើងតែនៅពេលអ្នកបង្កើតគណនីអ្នកផ្តល់សេវា បង្កើតឯកតាការផ្សាយពាណិជ្ជកម្ម បិទភ្ជាប់លេខសម្គាល់ឯកតារបស់អ្នក និងបន្ថែមភាពអាស្រ័យ SDK ទៅ build.gradle របស់គម្រោង។

របៀបកុមារ
ដើម្បីប្រើ IDE ជាមួយកុមារ — បើករបៀបកុមារនៅក្នុងម៉ឺនុយមេ។ អេក្រង់ត្រូវបានធ្វើឱ្យសាមញ្ញជាមួយនឹងប៊ូតុងធំៗ ហើយមានតែសកម្មភាពសុវត្ថិភាព ៤ ប៉ុណ្ណោះ — បង្កើតគម្រោង (ពីគំរូសុវត្ថិភាព — ម៉ាស៊ីនគណនា ទាយលេខ កម្រងសំណួរ ចាប់ផ្កាយ) បើកគម្រោង ដំណើរការ និងរបៀបរៀន។ មិនមានប៊ូតុងលុប នាំចេញ បម្រុងទុក ឬកំណត់ថូខឹននៅលើអេក្រង់នេះទេ។ បង្កើត PIN ៤ ខ្ទង់នៅពេលចូលដំបូង — មាតាបិតាប្រើ PIN នេះដើម្បីចាកចេញពីរបៀបកុមារ (ប៊ូតុងចាកចេញពីរបៀបកុមារ ឬប៊ូតុងត្រឡប់)។ PIN នេះគឺជាការការពារស្រាលសម្រាប់កុមារតូចៗ មិនមែនជាសុវត្ថិភាពពិតប្រាកដទេ។

អ្នកបង្កើតកម្មវិធី Wear OS & TV
ដើម្បីបង្កើតកម្មវិធីនាឡិកា (Wear OS) ឬកម្មវិធីទូរទស្សន៍ (Android TV) — បើកកម្មវិធីបង្កើតកម្មវិធី Wear OS & TV នៅក្នុងម៉ឺនុយមេ ហើយជ្រើសរើសគោលដៅ (Wear OS Android TV ឬទាំងពីរ)។ បំពេញឈ្មោះគម្រោង ហើយចុចបង្កើតគម្រោងថ្មី Wear/TV — IDE បង្កើត និងកែប្រែគម្រោង Java — ឬជ្រើសរើសគម្រោងដែលមានស្រាប់ ហើយចុចអនុវត្តទៅគម្រោងនេះ។ ការកែប្រែ — uses-feature នៅក្នុង manifest ប្រភេទ LEANBACK_LAUNCHER និងបដាសម្រាប់ TV និងប្លង់ activity_main.xml ដែលបានកែប្រែ (Wear - អេក្រង់តូច។ TV - អេក្រង់ធំដែលសមនឹង D-pad)។ ការពន្យល់ពេញលេញត្រូវបានសរសេរទៅ wear-tv.txt នៅក្នុងគម្រោង។ នេះគឺជាគំរូគម្រោង — ការសាងសង់ + ការសាកល្បងនៅតែត្រូវការឧបករណ៍ Wear OS ឬ Android TV/កម្មវិធីត្រាប់តាម។ បដា TV (banner.png 320x180) មិនត្រូវបានបង្កើតដោយស្វ័យប្រវត្តិទេ ត្រូវបន្ថែមដោយខ្លួនឯង (ឧទាហរណ៍តាមរយៈកម្មវិធីបង្កើតរូបតំណាង)។

ផែនទីគម្រោង
ដើម្បីមើលរចនាសម្ព័ន្ធរបស់គម្រោង — បើកផែនទីគម្រោងនៅក្នុងម៉ឺនុយមេ ជ្រើសរើសគម្រោង ហើយចុចបង្ហាញផែនទី — IDE បង្ហាញបញ្ជីថត និងឯកសារជាមួយនឹងទំហំរបស់វា ទំហំសរុប ទំហំតាមប្រភេទឯកសារ និងឯកសារសំខាន់ៗ (ឯកសារសំខាន់ manifest ប្លង់ ខ្សែអក្សរ រូបតំណាង ទំព័របណ្តាញ)។ ចុចរក្សាទុក peta-proyek.txt ដើម្បីសរសេរផែនទីដូចគ្នាទៅឫសគម្រោង។ ថត bin/ (លទ្ធផលសាងសង់) និងថត .git/ (repo ក្នុងស្រុក) មិនត្រូវបានរួមបញ្ចូលនៅក្នុងផែនទីទេ ពីព្រោះមាតិការបស់វាអាចបង្កើតឡើងវិញបាន។

ម៉ាស៊ីនគណនាទំហំ APK

ដើម្បីកំណត់រចនាសម្ព័ន្ធកម្មវិធី — បើកម៉ឺនុយជម្រើសនៅលើអេក្រង់ដើម ហើយចុចការកំណត់។ នៅខាងក្នុងមានប្រភេទ ១២ — ការកំណត់ GitHub (សុវត្ថិភាព ហត្ថលេខាផ្ទាល់ខ្លួន កំណត់ហេតុសាងសង់ និងថូខឹន GitHub) ការកំណត់ការសាងសង់ APK នៅលើឧបករណ៍ (ពាក្យសម្ងាត់ keystore និងការរក្សាទុកកំណត់ហេតុសាងសង់នៅលើឧបករណ៍) Theme (ពណ៌កម្មវិធី) ហត្ថលេខា (ការបង្កើត keystore សម្រាប់ហត្ថលេខាផ្ទាល់ខ្លួន និងប្រអប់ធីក Anti Tamper សម្រាប់កម្មវិធីដែលបានសាងសង់) ថតគម្រោង (ទីតាំងថតគម្រោង) ភាសា និងសំឡេង (ភាសាចំណុចប្រទាក់ និងល្បឿននិយាយរបស់របៀបសំឡេង) ទំហំអត្ថបទ និងរូបរាង (ទំហំពុម្ពអក្សររបស់កម្មវិធីកែសម្រួល) ការសាងសង់ (SDK គោលដៅលំនាំដើម និងការបំបែកស្ថាបត្យកម្មលំនាំដើមសម្រាប់អេក្រង់បង្កើតគម្រោង) ការជូនដំណឹង (សំឡេងនៅពេលការសាងសង់បញ្ចប់) ការបម្រុងទុកដោយស្វ័យប្រវត្តិ (កាលវិភាគបម្រុងទុកគម្រោង) ប្រវត្តិរូបអ្នកអភិវឌ្ឍន៍ (ឈ្មោះ លេខ WhatsApp និងគណនីដែលបង្ហាញនៅលើអេក្រង់បរិច្ចាគ) និងឯកជនភាព និងទិន្នន័យ (ការកំណត់ឡើងវិញនូវការកំណត់ និងការលុបទិន្នន័យកម្មវិធី)។ ប្រភេទនីមួយៗមានប៊ូតុងត្រឡប់ទៅមុនដើម្បីត្រឡប់ទៅម៉ឺនុយប្រភេទ។ ការកំណត់ដែលបានរក្សាទុកឥឡូវនេះ (មិនទាន់បានអនុវត្ត) ត្រូវបានពន្យល់ដោយស្មោះត្រង់នៅលើអេក្រង់។

បរិច្ចាគដល់អ្នកអភិវឌ្ឍន៍
ដើម្បីបរិច្ចាគដល់អ្នកអភិវឌ្ឍន៍ ឬជំរាបសួរគាត់ — ចុចប៊ូតុងបរិច្ចាគដល់អ្នកអភិវឌ្ឍន៍នៅជិតប៊ូតុងអំពីឧបករណ៍នៅលើអេក្រង់ដើម។ អេក្រង់បរិច្ចាគមានប៊ូតុងចម្លងគណនី BRI — ចុចវាដើម្បីចម្លងលេខគណនីរបស់អ្នកអភិវឌ្ឍន៍ ហើយបិទភ្ជាប់វាទៅក្នុងកម្មវិធីធនាគាររបស់អ្នក។ វាក៏មានផ្នែកជំរាបសួរអ្នកអភិវឌ្ឍន៍នៅលើ WhatsApp — បំពេញឈ្មោះ និងស្រុកកំណើតរបស់អ្នក ហើយចុចផ្ញើនៅលើ WhatsApp — WhatsApp បើកជាមួយនឹងសារជំរាបសួរដែលបានបំពេញជាមុន ចុចផ្ញើនៅលើ WhatsApp តែប៉ុណ្ណោះ ហើយត្រឡប់ទៅកម្មវិធីវិញ។ WhatsApp មិនអនុញ្ញាតឱ្យកម្មវិធីផ្សេងផ្ញើសារដោយស្វ័យប្រវត្តិទេ ដូច្នេះការផ្ញើត្រូវបានបន្តដោយអ្នកផ្ទាល់នៅក្នុង WhatsApp។

ពាក្យបញ្ជាដែលចូលចិត្តរបស់ស្ថានីយ
ដើម្បីរក្សាទុកពាក្យបញ្ជាដែលប្រើញឹកញាប់នៅក្នុងស្ថានីយ — បើកស្ថានីយ ហើយចុចចំណូលចិត្ត។ ចុចបន្ថែមចំណូលចិត្តថ្មី បំពេញឈ្មោះ (ឧទាហរណ៍ មើលឯកសារ) និងពាក្យបញ្ជារបស់វា (ឧទាហរណ៍ ls -la) ហើយចុចរក្សាទុក — ចំណូលចិត្តត្រូវបានរក្សាទុកជាអចិន្ត្រៃយ៍នៅលើទូរសព្ទ។ ចុចឈ្មោះចំណូលចិត្តដើម្បីដំណើរការវាដោយផ្ទាល់នៅក្នុងស្ថានីយ។ ចុចលុបចំណូលចិត្ត ហើយជ្រើសរើសមួយដើម្បីលុប (ជាមួយនឹងការបញ្ជាក់)។ មានចំណូលចិត្តដែលបានដំឡើងជាមុន ៣ រួចហើយ — មើលឯកសារ (ls -la) ពិនិត្យទំហំទំនេរ (df -h) និងសម្អាតអេក្រង់ (clear) — ទាំងអស់អាចលុបបាន។ ពាក្យបញ្ជាទទេមិនអាចរក្សាទុក ឬដំណើរការបានទេ។ ស្ថានីយជូនដំណឹងអំពីរឿងនេះដោយសារ និងសំឡេងប្រសិនបើវាកើតឡើង។

វិភាគ និងគុណភាព
ដើម្បីមើលសង្ខេបនៃការប្រើប្រាស់កម្មវិធី និងរបាយការណ៍គាំង — ចុចប៊ូតុងវិភាគ និងគុណភាពនៅជិតប៊ូតុងបរិច្ចាគដល់អ្នកអភិវឌ្ឍន៍នៅលើអេក្រង់ដើម។ អេក្រង់នេះបង្ហាញចំនួនដងដែលកម្មវិធីត្រូវបានបើក អេក្រង់ដែលបើកញឹកញាប់បំផុត ចំនួនគាំង និងបញ្ជីគាំងចុងក្រោយជាមួយនឹងការណែនាំជួសជុលខ្លីៗ។ ទិន្នន័យនេះត្រូវបានរក្សាទុកតែនៅលើទូរសព្ទរបស់អ្នក ហើយមិនត្រូវបានផ្ញើទៅកន្លែងណាទេ។ មានប៊ូតុងលុបទិន្នន័យវិភាគជាមួយនឹងការសន្ទនាបញ្ជាក់ដើម្បីលុបទិន្នន័យទាំងអស់នេះ។ មានតែអេក្រង់ចុងក្រោយប៉ុណ្ណោះដែលត្រូវបានកត់ត្រាសម្រាប់អេក្រង់ដើម និងអេក្រង់នេះ។
