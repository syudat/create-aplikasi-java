ដើម្បីពិនិត្យរន្ធសុវត្ថិភាពនៅក្នុងកូដគម្រោងមុនពេលចេញផ្សាយ៖ បើក អ្នកត្រួតពិនិត្យសុវត្ថិភាព នៅលើម៉ឺនុយមេ ជ្រើសគម្រោងមួយ រួចចុច ចាប់ផ្តើមការស្កេន។ IDE ស្កេនកូដ manifest និងការកំណត់រចនាសម្ព័ន្ធគម្រោង ហើយរាយការណ៍ការរកឃើញពីហានិភ័យខ្ពស់បំផុតទៅទាបបំផុត — កូនសោ API ដែលត្រូវបានបង្ហាញក្នុងកូដ សមាសភាគដែលត្រូវបានបង្ហាញដោយគ្មានការអនុញ្ញាត WebView ដែលបើក JavaScript រួមជាមួយចំណុចប្រទាក់ JavaScript គ្រីបតូខ្សោយ (MD5, SHA1, DES) អាសយដ្ឋាន http ដោយគ្មាន TLS និងពាក្យសម្ងាត់ដែលបានសរសេរដោយផ្ទាល់ក្នុងកូដ — ជាមួយឯកសារនិងលេខបន្ទាត់នៃការរកឃើញនីមួយៗ។ សម្រាប់ការរកឃើញដែលមានការជួសជុលប្រកបដោយសុវត្ថិភាព (ឧទាហរណ៍ ការជំនួស MD5 ដោយ SHA-256 ឬ http ដោយ https) ចុច អនុវត្តការជួសជុល សម្រាប់កូនសោ API និងពាក្យសម្ងាត់ IDE បង្ហាញតែការជួសជុលដែលបានស្នើ ពីព្រោះការជំនួសត្រូវតែសម្រេចដោយអ្នកអភិវឌ្ឍន៍ខ្លួនឯង។ ការស្កេននេះអានលំនាំអត្ថបទនៅក្នុងកូដ មិនមែន bytecode ទេ ដូច្នេះការរកឃើញខ្លះអាចមានសុវត្ថិភាពពិតប្រាកដ ហើយរន្ធដែលគ្មានលំនាំអាចរួចផុតពីការស្កេន — សូមពិនិត្យមុនពេលអនុវត្ត។

មនុស្សយន្តសាកល្បងចំណុចប្រទាក់
ដើម្បីសាកល្បងរូបរាងរបស់កម្មវិធីដោយស្វ័យប្រវត្តិជាមួយសេណារីយ៉ូអត្ថបទ៖ បើក មនុស្សយន្តសាកល្បងចំណុចប្រទាក់ នៅលើម៉ឺនុយមេ ជ្រើសគម្រោងមួយ រួចចុច បង្កើតសេណារីយ៉ូដោយស្វ័យប្រវត្តិ។ IDE អាន manifest និងប្លង់របស់គម្រោង ហើយសរសេរសេណារីយ៉ូពីជំហានអត្ថបទ (ចុចប៊ូតុងមួយ បំពេញវាលមួយ រង់ចាំ ត្រឡប់ក្រោយ)។ ចុច ដំណើរការ Dry Run ដើម្បីមើលកំណត់ហេតុដំណើរការរបស់សេណារីយ៉ូជាមួយត្រាពេលវេលារបស់វា។ នៅដំណាក់កាលនេះ មនុស្សយន្តដំណើរការតែការក្លែងធ្វើ (dry run) — ការចុចប៊ូតុងពិតប្រាកដនៅលើទូរស័ព្ទនិងការចាប់ Crash ពិតប្រាកដជាដំណាក់កាលបន្ទាប់ ដូច្នេះរបាយការណ៍ Crash នៅទីនេះនៅតែជាទម្រង់គំរូ។

ការធ្វើដំណើរពេលវេលាកូដ

រោងចក្រម៉ូឌុល
ដើម្បីវេចខ្ចប់ផ្នែកមួយនៃគម្រោងជាម៉ូឌុលដែលគម្រោងមួយផ្សេងទៀតអាចប្រើបាន៖ បើក រោងចក្រម៉ូឌុល នៅលើម៉ឺនុយមេ ជ្រើសគម្រោងប្រភពមួយ ធីកឯកសារអេក្រង់ ថ្នាក់ ខ្សែអក្សរ និងការអនុញ្ញាតដែលត្រូវវេចខ្ចប់ រួចចុច វេចខ្ចប់ជាម៉ូឌុល។ IDE សរសេរបណ្ណសារ ZIP រួមជាមួយទិន្នន័យមេតា JSON (ឈ្មោះម៉ូឌុល កំណែ ខ្សែអក្សរដែលបានប្រើ និងការអនុញ្ញាត)។ ដើម្បីដំឡើងម៉ូឌុលមួយនៅក្នុងគម្រោងមួយផ្សេងទៀត បើក រោងចក្រម៉ូឌុល ជ្រើសគម្រោងគោលដៅ រួចចុច ដំឡើងម៉ូឌុល ហើយជ្រើសឯកសារ .zip របស់ម៉ូឌុល — ការបញ្ចូលគ្នាបន្ថែមខ្សែអក្សរនិងការអនុញ្ញាតដោយមិនសរសេរជាន់លើកូដដែលមានស្រាប់ ហើយមិនបញ្ចូលឯកសារមួយប្រសិនបើឈ្មោះរបស់វាត្រូវបានប្រើរួចហើយនៅក្នុងគម្រោងគោលដៅ។ ម៉ូឌុលមួយមិនយកបណ្ណាល័យឬការកំណត់សាងសង់ទៅជាមួយទេ។

ស្ថាបត្យករប្លង់មែកធាងអត្ថបទ

ដើម្បីកំណត់អ្នកផ្តល់សេវា AI និងកូនសោ API សម្រាប់ការបង្កើតកម្មវិធី៖ ចុចនៅលើម៉ឺនុយមេ នៅក្នុងក្រុម ការកំណត់ លើ ការកំណត់ AI (នៅជាប់ប៊ូតុង ឧបករណ៍ភ្ជាប់)។ ជ្រើសអ្នកផ្តល់សេវាដែលត្រូវប្រើពីបញ្ជីដែលមាន ហើយធីក ប្តូរម៉ូដែលនៅពេលអ្នកផ្តល់សេវាមានកំហុស ដើម្បីឱ្យ IDE សាកល្បងម៉ូដែលបន្ទាប់ដោយស្វ័យប្រវត្តិពីអ្នកផ្តល់សេវាដូចគ្នា ប្រសិនបើម៉ូដែលមួយបរាជ័យ។ ចុច គ្រប់គ្រងកូនសោ API ដើម្បីបន្ថែមកូនសោបម្រុង (បំពេញឈ្មោះនិងកូនសោ រួចចុច រក្សាទុក កូនសោត្រូវបានបង្ហាញដោយបិទបាំង មានតែ 4 តួអក្សរចុងក្រោយប៉ុណ្ណោះដែលអាចមើលឃើញ)។ កូនសោត្រូវបានរក្សាទុកនៅលើទូរស័ព្ទ ហើយមិនដែលត្រូវបានផ្ញើទៅកន្លែងផ្សេងក្រៅពីអ្នកផ្តល់សេវាដែលបានជ្រើសនៅពេលកម្មវិធីត្រូវបានបង្កើតទេ។ សូមកត់សម្គាល់៖ សម្រាប់ពេលនេះ ការជ្រើសរើសអ្នកផ្តល់សេវានិងកូនសោត្រូវបានកត់ត្រាតែប៉ុណ្ណោះ ហើយបង្ហាញនៅលើអេក្រង់ AI Pembuat Aplikasi — ការបង្កើតកម្មវិធីនៅតែប្រើ AI ក្នុងស្រុកនៅលើទូរស័ព្ទ (ដោយគ្មានអ៊ីនធឺណិត) ការប្រើប្រាស់អ្នកផ្តល់សេវាអនឡាញនឹងមកដល់នៅពេលក្រោយ។

ឧបករណ៍ភ្ជាប់
ដើម្បីវិភាគ APK មួយ រួចផ្ញើវា៖ ចុចនៅលើម៉ឺនុយមេ នៅក្នុងក្រុម ការកំណត់ លើ ឧបករណ៍ភ្ជាប់ (នៅជាប់ប៊ូតុង ការកំណត់ AI)។ ជ្រើសឯកសារ APK ពីទូរស័ព្ទ IDE អានមាតិការបស់វា (ឈ្មោះកញ្ចប់ កំណែ បញ្ជីសកម្មភាព) រួចចុច ផ្ញើ APK ដើម្បីផ្ញើវាតាមរយៈម៉ឺនុយចែករំលែករបស់ប្រព័ន្ធ (ឧទាហរណ៍ WhatsApp ឬ Drive)។

ភាសា និងសំឡេង
ដើម្បីផ្លាស់ប្តូរភាសារបស់កម្មវិធី៖ បើក ការកំណត់ រួច ភាសាកម្មវិធី រួចជ្រើសភាសាមួយ ឬ តាមប្រព័ន្ធ។ អេក្រង់មេនិងអេក្រង់ភាគច្រើនប្តូរភ្លាមៗទៅភាសាដែលបានជ្រើសដោយមិនចាំបាច់បិទឬចាប់ផ្តើមកម្មវិធីឡើងវិញ អេក្រង់ខ្លះ (ឧទាហរណ៍ Terminal, កិច្ចសហការ, ការកំណត់ AI និង គ្រប់គ្រងកូនសោ) នៅតែប្រើភាសាចាស់រហូតដល់វាត្រូវបានបើកម្តងទៀត។ ប្រសិនបើអ្នកជ្រើស តាមប្រព័ន្ធ ភាសាធ្វើតាមភាសាប្រព័ន្ធរបស់ទូរស័ព្ទ។
