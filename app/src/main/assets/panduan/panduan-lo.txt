ຍິນດີຕ້ອນຮັບສູ່ Create Aplikasi by Al Kautsar
Create Aplikasi ແມ່ນແອັບສ້າງແອັບ Android ທີ່ເຮັດວຽກໂດຍກົງໃນໂທລະສັບ ໂດຍບໍ່ຕ້ອງໃຊ້ແລັບທັອບ. ແອັບນີ້ຊ່ວຍໃຫ້ທຸກຄົນສ້າງແອັບ Android ຂອງຕົນເອງໄດ້ ລວມທັງຜູ້ທີ່ຫາກໍ່ເລີ່ມຮຽນສ້າງແອັບ ແລະ ຜູ້ໃຊ້ໂປຣແກຣມອ່ານໜ້າຈໍ. ຄູ່ມືການໃຊ້ແອັບນີ້ແບບເຕັມຮູບແບບມີຢູ່ໃນໜ້າຈໍ Tentang Alat ນີ້.

ແອັບນີ້ແມ່ນຫຍັງ ແລະ ສຳລັບໃຜ
Create Aplikasi ແມ່ນເຄື່ອງມືສ້າງແອັບ Android ທີ່ເຮັດວຽກໃນໂທລະສັບ. ແອັບນີ້ມີໄວ້ສຳລັບທຸກຄົນທີ່ຢາກສ້າງແອັບ Android ຂອງຕົນເອງ ລວມທັງຜູ້ເລີ່ມຕົ້ນ ແລະ ຜູ້ໃຊ້ໂປຣແກຣມອ່ານໜ້າຈໍ. ແອັບນີ້ມີຕົວແກ້ໄຂໂຄດ ປຸ່ມ Jalankan ເພື່ອທົດສອບໂຄງການ ປຸ່ມ Bangun ເພື່ອສ້າງ APK ແລະ ເມນູສຳລັບເຊັນ ແລະ ຕິດຕັ້ງ APK.

ຈຸດປະສົງຂອງແອັບນີ້
ແອັບນີ້ຖືກສ້າງຂຶ້ນເພື່ອໃຫ້ທຸກຄົນສາມາດສ້າງແອັບ Android ຂອງຕົນເອງໄດ້ຢ່າງງ່າຍດາຍ ໂດຍກົງຈາກໂທລະສັບ. ຮູບລັກສະນະຂອງມັນຖືກເຮັດໃຫ້ງ່າຍທີ່ສຸດເທົ່າທີ່ຈະເຮັດໄດ້ ເພື່ອໃຫ້ຜູ້ໃຊ້ໃໝ່ກໍສາມາດລອງໄດ້ທັນທີ.

ວິທີສ້າງໂຄງການໃໝ່ ທີລະຂັ້ນຕອນ
1. ກົດ Buat Project ໃນເມນູຫຼັກ.
2. ເລືອກປະເພດໂຄງການ: HTML, Situs Web, Java, Kotlin, Compose, ຫຼື Python.
3. ຕື່ມຊື່ແອັບ ຕົວຢ່າງ: Garuda Decode.
4. ຕື່ມຊື່ແພັກເກດ (package name) ຕົວຢ່າງ: com.android.garudadecode. ຊື່ແພັກເກດຕ້ອງໃຊ້ຕົວອັກສອນນ້ອຍ ແລະ ປະກອບດ້ວຍຢ່າງໜ້ອຍສອງສ່ວນທີ່ແຍກດ້ວຍຈຸດ.
5. ຕື່ມເວີຊັນແອັບ ຕົວຢ່າງ: 1.0 ແລະ ລະຫັດເວີຊັນເປັນຕົວເລກ ຕົວຢ່າງ: 1. ຖ້າປ່ອຍວ່າງໄວ້ ເວີຊັນຈະຖືກຕື່ມອັດຕະໂນມັດເປັນ 1.0 ແລະ ລະຫັດເວີຊັນ 1.
6. ຕື່ມ SDK ຕ່ຳສຸດ ແລະ SDK ເປົ້າໝາຍ ຖ້າຈຳເປັນ. ຖ້າປ່ອຍວ່າງໄວ້ ຄ່າເລີ່ມຕົ້ນຈະຖືກໃຊ້. SDK ຕ່ຳສຸດແມ່ນເວີຊັນ Android ຕ່ຳສຸດທີ່ຮອງຮັບ ຕົວຢ່າງ: 21 ໝາຍເຖິງ Android 5.0. SDK ເປົ້າໝາຍສູງສຸດແມ່ນ 36 (Android 16).
7. ກົດປຸ່ມ Pilih Izin ເພື່ອເລືອກສິດອະນຸຍາດຂອງແອັບ ຕົວຢ່າງ: INTERNET. ສິດອະນຸຍາດ INTERNET ຖືກໝາຍໄວ້ເປັນຄ່າເລີ່ມຕົ້ນແລ້ວ. ໝາຍສະເພາະສິດອະນຸຍາດທີ່ແອັບຕ້ອງການແທ້ໆເທົ່ານັ້ນ.
8. ຖ້າຕ້ອງການ ໃຫ້ໝາຍ "Gunakan arsitektur terpisah 64 bit dan 32 bit" ເພື່ອໃຫ້ຂະໜາດ APK ນ້ອຍລົງ ແລະ ໝາຍ "Gunakan tanda tangan pribadi" ຖ້າຢາກໃຊ້ keystore ທີ່ສ້າງເອງ.
9. ກົດ Buat Proyek. ໂຄງການໃໝ່ຈະຖືກບັນທຶກໄວ້ໃນໂຟນເດີ Download/project ແລະ ປາກົດທັນທີໃນ Kelola Project.

ປະເພດໂຄງການທີ່ມີໃຫ້
• HTML: ການແດງຜົນຈາກ index.html, style.css, ແລະ script.js ທີ່ເຮັດວຽກຜ່ານ WebView. ສ້າງໂດຍກົງໃນໂທລະສັບ.
• Situs Web: ເວັບໄຊທີ່ມີເມນູ (Beranda, Tentang, Kontak) ຈາກ index.html, tentang.html, kontak.html, style.css, ແລະ script.js ທີ່ເຮັດວຽກຜ່ານ WebView. ສ້າງໂດຍກົງໃນໂທລະສັບ.
• Java: ສ້າງໃນໂທລະສັບ. MainActivity ຢູ່ໃນ app/src/main/java/<nama-paket>/MainActivity.java. ການແດງຜົນມາຈາກ app/src/main/res/layout/activity_main.xml ຂໍ້ຄວາມມາຈາກ app/src/main/res/values/strings.xml ແລະ ຮູບແບບມາຈາກ app/src/main/res/values/styles.xml.
• Kotlin: ສາມາດສ້າງໃນອຸປະກອນ (offline) ໂດຍໃຊ້ຕົວຄອມໄພລ໌ Kotlin ທີ່ລວມຢູ່ໃນແອັບ ຫຼື ຜ່ານ GitHub Actions. MainActivity ຢູ່ໃນ app/src/main/java/<nama-paket>/MainActivity.kt ແລະ ໄຟລ໌ res ກໍຄືກັນກັບໂຄງການ Java. ການສ້າງ Kotlin ຄັ້ງທຳອິດຈະຊ້າກວ່າເນື່ອງຈາກຂະໜາດຂອງຕົວຄອມໄພລ໌ໃຫຍ່ ແລະ ໄຟລ໌ .java ທີ່ອ້າງອີງຫາຄລາດ Kotlin ຍັງບໍ່ສາມາດສ້າງໄດ້ເທື່ອ (ໄຟລ໌ .java ຖືກຄອມໄພລ໌ກ່ອນໄຟລ໌ .kt).
• Compose: ແອັບ Android ສະໄໝໃໝ່ທີ່ສ່ວນຕິດຕໍ່ຂອງມັນຖືກສ້າງດ້ວຍ Jetpack Compose (ບໍ່ແມ່ນ layout XML). MainActivity ຢູ່ໃນ app/src/main/java/<nama-paket>/MainActivity.kt. ໂຄງການ Compose ຖືກສ້າງຜ່ານ GitHub Actions (ເມນູ Bangun proyek ແລ້ວ Bangun online) ຫຼື ໃນ Termux ດ້ວຍ Gradle ເພາະ Compose ຕ້ອງການໄລບຣາຣີ Jetpack Compose ທີ່ບໍ່ມີໃນອຸປະກອນ.
• Python: ເຫດຜົນຂອງແອັບຖືກຂຽນເປັນພາສາ Python (Chaquopy) ໃນ app/src/main/python/main.py ແລະ ຖືກເຮັດວຽກໂດຍ host MainActivity.java ໃນ app/src/main/java/<nama-paket>/MainActivity.java. ໂຄງການ Python ສາມາດສ້າງໄດ້ໂດຍກົງໃນໂທລະສັບ (runtime Chaquopy ລວມຢູ່ໃນແອັບ) ຫຼື ຜ່ານ GitHub Actions. SDK ຕ່ຳສຸດຂອງໂຄງການ Python ແມ່ນ 24 (Android 7.0).

ໂຄງສ້າງໄຟລ໌ຂອງໂຄງການ Java, HTML, Situs Web, Kotlin, Compose, ແລະ Python
ໂຄງການ Java, HTML, Situs Web, Kotlin, Compose, ແລະ Python ຖືກຈັດລຽງຄືກັບໂຄງການ Android ທົ່ວໄປ. ພາຍໃນໂຟນເດີ app ມີໂຟນເດີ src ແລະ ພາຍໃນນັ້ນມີໂຟນເດີ main. ພາຍໃນໂຟນເດີ main ມີ AndroidManifest.xml ຢູ່ຄຽງຂ້າງໂຟນເດີ java ໂຟນເດີ res ທີ່ມີ layout/activity_main.xml ແລະ values/strings.xml ພ້ອມທັງ values/styles.xml ແລະ ສຳລັບ HTML ແລະ Situs Web ມີໂຟນເດີ assets ທີ່ມີ index.html (Situs Web ຍັງມີ tentang.html ແລະ kontak.html ອີກ). ໂຄງການ HTML ແລະ Situs Web ກໍມີ MainActivity ຂອງຕົນເອງຢູ່ໃນ app/src/main/java/<nama-paket>/MainActivity.java ເຊິ່ງໂຫຼດ index.html ໃນ WebView ແລະ ເປັນ launcher ໃນ AndroidManifest. ໂຄງການ Python ມີໂຄດ Python ຢູ່ໃນ app/src/main/python/main.py ແລະ host MainActivity.java ຢູ່ໃນ app/src/main/java/<nama-paket>/MainActivity.java. AndroidManifest.xml, layout, strings, ແລະ styles ສາມາດເປີດ ແລະ ແກ້ໄຂໃນຕົວແກ້ໄຂໄດ້ ຄືກັນກັບ MainActivity. ໂຄງການເກົ່າທີ່ manifest ຂອງມັນຍັງຢູ່ຄຽງຂ້າງໂຟນເດີ app ກໍຍັງສ້າງໄດ້ ເພາະເວລາສ້າງ ແອັບຈະກວດ AndroidManifest.xml ໃນ app/src/main/ ກ່ອນ ແລ້ວຈຶ່ງອັນທີ່ຢູ່ຄຽງຂ້າງໂຟນເດີ app ແລະ ສຸດທ້າຍແມ່ນໄຟລ໌ຂໍ້ມູນໂຄງການ.

ກົດຂອງສິດອະນຸຍາດ (ສຳຄັນ)
ສິດອະນຸຍາດທີ່ໝາຍໄວ້ເວລາສ້າງໂຄງການຈະຖືກບັນທຶກໄວ້ໃນບ່ອນດຽວເທົ່ານັ້ນ ຕາມປະເພດໂຄງການ. ສຳລັບໂຄງການ Java, HTML, Situs Web, Kotlin, Compose, ແລະ Python ສິດອະນຸຍາດທີ່ໝາຍໄວ້ຈະຖືກບັນທຶກໄວ້ສະເພາະໃນ AndroidManifest.xml ທີ່ຢູ່ໃນ app/src/main/ ຄຽງຂ້າງໂຟນເດີ java ພາຍໃນໂຟນເດີໂຄງການເທົ່ານັ້ນ. ໄຟລ໌ຂໍ້ມູນໂຄງການສຳລັບໂຄງການ Java, HTML, Situs Web, Kotlin, Compose, ແລະ Python ບໍ່ມີລາຍການສິດອະນຸຍາດ. ຖ້າເລືອກ Java ແລ້ວໝາຍ INTERNET ແລະ CAMERA ສິ່ງທີ່ຖືກບັນທຶກໃນ AndroidManifest.xml ຈະມີສະເພາະ INTERNET ແລະ CAMERA ເທົ່ານັ້ນ ໂດຍບໍ່ມີສິດອະນຸຍາດອື່ນປົນມາ. ເວລາສ້າງ ແອັບຈະອ່ານສິດອະນຸຍາດຈາກບ່ອນດຽວກັນນັ້ນ: ຈາກ AndroidManifest.xml ໃນ app/src/main/ ສຳລັບໂຄງການ Java, HTML, Situs Web, Kotlin, Compose, ແລະ Python (ຖ້າບໍ່ມີ ຈາກ AndroidManifest.xml ທີ່ຢູ່ຄຽງຂ້າງໂຟນເດີ app ສຳລັບໂຄງການເກົ່າ) ແລະ ຈາກໄຟລ໌ຂໍ້ມູນໂຄງການສຳລັບໂຄງການເກົ່າ.

ວິທີໃຊ້ຕົວແກ້ໄຂ
ເປີດ Kelola Project ແຕະຊື່ໂຄງການເພື່ອເປີດຕົວແກ້ໄຂ. ໃນຕົວແກ້ໄຂ ສາມາດເປີດໄຟລ໌ ຂຽນໂຄດ ແລະ ບັນທຶກການປ່ຽນແປງໄດ້. ສຳລັບໂຄງການ Java, HTML, Situs Web, Kotlin, Compose, ແລະ Python ໄຟລ໌ຖືກຈັດລຽງຢູ່ໃນໂຟນເດີ app/src/main. ເພື່ອແບ່ງປັນໂຄງການ ໃຫ້ໃຊ້ Ekspor ZIP (ເບິ່ງພາກຂ້າງລຸ່ມ).

ວິທີເຮັດວຽກໂຄງການ
ໃນຕົວແກ້ໄຂ ກົດ Jalankan ເພື່ອທົດສອບໂຄງການ. ສຳລັບໂຄງການ HTML ແລະ Situs Web ສິ່ງທີ່ຖືກເຮັດວຽກແມ່ນ index.html ຜ່ານ WebView. ຖ້າມີຂໍ້ຜິດພາດເກີດຂຶ້ນ ໃຫ້ອ່ານຂໍ້ຄວາມຂໍ້ຜິດພາດ ແກ້ໄຂໂຄດ ແລ້ວເຮັດວຽກອີກຄັ້ງ.

ວິທີສ້າງ APK
ໃນຕົວແກ້ໄຂ ກົດ Bangun. ມີວິທີສ້າງສອງວິທີ. ວິທີທຳອິດ ສ້າງໃນອຸປະກອນ: ສ້າງໂດຍກົງໃນໂທລະສັບໂດຍບໍ່ຕ້ອງໃຊ້ອິນເຕີເນັດ ສຳລັບໂຄງການ HTML, Situs Web, Java, Kotlin, ແລະ Python. ວິທີທີສອງ ສ້າງອອນລາຍຜ່ານ GitHub Actions: ສ້າງຜ່ານອິນເຕີເນັດໃນ GitHub ແລະ ສາມາດໃຊ້ໄດ້ສຳລັບໂຄງການທຸກປະເພດ. ໂຄງການ Compose ສາມາດສ້າງໄດ້ສະເພາະດ້ວຍວິທີທີສອງ (Bangun online) ຫຼື ໃນ Termux ດ້ວຍ Gradle ເພາະ Compose ຕ້ອງການໄລບຣາຣີ Jetpack Compose ທີ່ບໍ່ມີໃນອຸປະກອນ. ຜົນການສ້າງຄັ້ງທຳອິດຍັງບໍ່ທັນໄດ້ເຊັນ. ຈາກນັ້ນແອັບຈະເຊັນໃຫ້: ອັດຕະໂນມັດດ້ວຍກະແຈເລີ່ມຕົ້ນ ຫຼື ດ້ວຍລາຍເຊັນສ່ວນຕົວຖ້າກ່ອງ "Gunakan tanda tangan pribadi" ຖືກໝາຍໄວ້ເວລາສ້າງໂຄງການ.

ວິທີຕິດຕັ້ງ APK
ເມື່ອ APK ພ້ອມແລ້ວ ກົດ Pasang ເພື່ອຕິດຕັ້ງມັນ. ໃນ Android 8 ຂຶ້ນໄປ ໂທລະສັບຈະຂໍ "Izinkan dari sumber ini" ກ່ອນ ເພາະແອັບນີ້ຕິດຕັ້ງ APK ຈາກພາຍນອກ Play Store. ເປີດໃຊ້ສິດອະນຸຍາດນັ້ນໜຶ່ງຄັ້ງໃນ Pengaturan ແລ້ວກັບມາທີ່ແອັບ: ການຕິດຕັ້ງຈະສືບຕໍ່ອັດຕະໂນມັດໂດຍບໍ່ຕ້ອງກົດ Pasang ອີກ. ຖ້າປຸ່ມ Pasang ບໍ່ປາກົດ ໃຫ້ແນ່ໃຈວ່າການສ້າງສຳເລັດແລ້ວ ແລະ APK ຖືກສ້າງແລ້ວ.

ວິທີເຊັນແອັບ
ທຸກ APK ຕ້ອງຖືກເຊັນຈຶ່ງຈະຕິດຕັ້ງໄດ້. ມີສອງທາງເລືອກ. ທາງທຳອິດ ກະແຈເລີ່ມຕົ້ນ: ແອັບເຊັນເອງອັດຕະໂນມັດ ໂດຍບໍ່ຕ້ອງເຮັດຫຍັງເລີຍ. ທາງທີສອງ ລາຍເຊັນສ່ວນຕົວ: ສ້າງ keystore ກ່ອນຜ່ານເມນູ Buat Keystore ໃນເມນູຫຼັກ ເກັບລະຫັດຜ່ານຂອງມັນໄວ້ໃຫ້ດີ ແລ້ວໝາຍ "Gunakan tanda tangan pribadi" ເວລາສ້າງໂຄງການ. Keystore ຖືກເກັບໄວ້ໃນ Download/project/signing.

ສົ່ງອອກໂຄງການເປັນ ZIP
Ekspor ZIP ມີໄວ້ເພື່ອໃຫ້ໂຄງການແບ່ງປັນໃຫ້ໝູ່ໄດ້. ວິທີ: ໃນ Kelola Project ກົດຊື່ໂຄງການຄ້າງໄວ້ດົນ ແລ້ວເລືອກ Ekspor ZIP. ຜົນລັບຈະຖືກບັນທຶກໄວ້ໃນ Download/project/<NamaProyek>.zip. ໂຟນເດີ bin ບໍ່ໄດ້ລວມເຂົ້າໄປ ດັ່ງນັ້ນຂະໜາດຂອງມັນຈຶ່ງນ້ອຍ ພຽງແຕ່ສິບກວ່າ KB ເທົ່ານັ້ນ. ໄຟລ໌ ZIP ນັ້ນສາມາດສົ່ງໃຫ້ໝູ່ ຫຼື ອັບໂຫຼດໄປ GitHub ໄດ້.

Ekstensi JAWS
Ekstensi JAWS ໃຊ້ເຄື່ອງຈັກສ່ວນຂະຫຍາຍຂອງ Jieshuo (CSR) ບໍ່ແມ່ນໂປຣແກຣມອ່ານໜ້າຈໍຂອງມັນ. ດ້ວຍວິທີນີ້ ການອອກແບບຍັງສາມາດເຮັດວຽກໄດ້ເຖິງແມ່ນວ່າຜູ້ໃຊ້ຈະໃຊ້ TalkBack ກໍຕາມ. ວິທີ: ເປີດ Ekstensi JAWS ໃນເມນູຫຼັກ. ເນື່ອງຈາກການຄລິກອັດຕະໂນມັດເຮັດວຽກເອງ ບໍລິການຕ້ອງຖືກເປີດໃຊ້ກ່ອນໃນ Pengaturan Aksesibilitas. ຈາກນັ້ນຈຶ່ງສາມາດສ້າງການອອກແບບໃໝ່ໄດ້: ພິມຊື່ການອອກແບບ ກົດ OK ແລ້ວຕື່ມກ່ອງຂອງມັນ.

Daftar Klik ຖືກແຍກອອກເພື່ອໃຫ້ເປັນລະບຽບ
ພາຍໃນການອອກແບບມີສອງກ່ອງ: ກ່ອງສະຄຣິບ ແລະ ກ່ອງ Daftar Klik. ລາຍການປຸ່ມຖືກເກັບແຍກຕ່າງຫາກໄວ້ໃນໄຟລ໌ daftar_klik.txt ໜຶ່ງຊື່ຕໍ່ໜຶ່ງແຖວ. ຕົວຢ່າງເນື້ອໃນຂອງມັນ: tombolSimpan, tombolHapus, tombolBuka. ເພື່ອເປີດແອັບ ໃຫ້ຂຽນພຽງແຕ່ >WhatsApp ໃນລາຍການນັ້ນ. ການອອກແບບເກົ່າທີ່ຍັງບໍ່ມີໄຟລ໌ daftar_klik.txt ຈະແດງຕົວຢ່າງເລີ່ມຕົ້ນນັ້ນ.

ຟັງຊັນງ່າຍໆທີ່ມີໃຫ້
• klikTombol("tombolSimpan") — ຄລິກປຸ່ມໜຶ່ງຕາມຂໍ້ຄວາມຂອງມັນ.
• klikDaftarTombol(daftar) — ຄລິກລາຍການໃນ daftar_klik.txt ໜຶ່ງປຸ່ມຕໍ່ໜຶ່ງແຖວ ຕາມລຳດັບ ແລ້ວແຈ້ງວ່າມີຈັກອັນທີ່ສຳເລັດ ແລະ ຈັກອັນທີ່ຫາບໍ່ພົບ.
• bukaAplikasi("WhatsApp") — ເປີດແອັບຕາມຊື່ຂອງມັນ ຫຼື ຂຽນ ">WhatsApp" ໃນລາຍການ.
• klik(540, 1200) — ຄລິກທີ່ພິກັດໜ້າຈໍ.
ຟັງຊັນທັງໝົດຖືກເຮັດໃຫ້ງ່າຍໄວ້ກ່ອນ. ເມື່ອຄຸ້ນເຄີຍແລ້ວ ສາມາດເພີ່ມຟັງຊັນເພີ່ມເຕີມໄດ້ໃນພາຍຫຼັງ.

ກ່ຽວກັບໂປຣແກຣມອ່ານໜ້າຈໍ
ແອັບນີ້ຖືກອອກແບບມາໃຫ້ເປັນມິດກັບໂປຣແກຣມອ່ານໜ້າຈໍ. ທຸກຊ່ອງຕື່ມຂໍ້ມູນມີປ້າຍ ແລະ ຕົວຢ່າງການຕື່ມ ແລະ ທຸກປຸ່ມສາມາດເຂົ້າເຖິງໄດ້ໂດຍບໍ່ຕ້ອງໃຊ້ທ່າທາງທີ່ສັບສົນ. Ekstensi JAWS ຖືກສ້າງມາໃຫ້ຍັງເຮັດວຽກໄດ້ເຖິງແມ່ນວ່າຜູ້ໃຊ້ຈະໃຊ້ TalkBack ກໍຕາມ ເພາະສິ່ງທີ່ໃຊ້ແມ່ນເຄື່ອງຈັກສ່ວນຂະຫຍາຍຂອງມັນ ບໍ່ແມ່ນໂປຣແກຣມອ່ານໜ້າຈໍຂອງມັນ.

ຄວາມເປັນສ່ວນຕົວ ແລະ ຄວາມປອດໄພ
ໂຄງການ ແລະ keystore ຖືກເກັບໄວ້ໃນໂທລະສັບຂອງທ່ານ. ໂທເຄັນ GitHub ຖືກໃຊ້ສະເພາະສຳລັບການສ້າງອອນລາຍເທົ່ານັ້ນ ແລະ ຖືກເກັບໄວ້ພາຍໃນແອັບນີ້. ຢ່າແບ່ງປັນໂທເຄັນ ຫຼື ລະຫັດຜ່ານ keystore ຂອງທ່ານໃຫ້ໃຜເລີຍ. ຖ້າໃຊ້ລາຍເຊັນສ່ວນຕົວ ໃຫ້ເກັບ keystore ແລະ ລະຫັດຜ່ານຂອງມັນໄວ້ໃນບ່ອນທີ່ປອດໄພ ເພາະຖ້າຫາຍໄປ APK ເກົ່າຈະບໍ່ສາມາດອັບເດດດ້ວຍລາຍເຊັນດຽວກັນໄດ້ອີກ.

ຄວາມຕ້ອງການ
Android 5.0 ຫຼື ໃໝ່ກວ່າ. ສິດອະນຸຍາດບ່ອນເກັບຂໍ້ມູນ: ໃນ Android 11 ຂຶ້ນໄປໃຊ້ສິດອະນຸຍາດເຂົ້າເຖິງໄຟລ໌ທັງໝົດ ໃນ Android 10 ລົງມາໃຊ້ສິດອະນຸຍາດບ່ອນເກັບຂໍ້ມູນປົກກະຕິ (ອ່ານ/ຂຽນບ່ອນເກັບຂໍ້ມູນ) ເພາະ Android 10 ບໍ່ມີສິດອະນຸຍາດເຂົ້າເຖິງໄຟລ໌ທັງໝົດ. ການສ້າງໃນອຸປະກອນຕ້ອງການໂທລະສັບທີ່ມີໂປຣເຊດເຊີ ARM (32 ຫຼື 64 ບິດ). ການສ້າງອອນລາຍຜ່ານ GitHub Actions ຕ້ອງການອິນເຕີເນັດ ແລະ ໂທເຄັນ GitHub. ໂຄງການ Kotlin ສາມາດສ້າງໃນອຸປະກອນໄດ້ ແຕ່ການສ້າງຄັ້ງທຳອິດຂອງມັນຈະຊ້າກວ່າ ແລະ ໃຊ້ໜ່ວຍຄວາມຈຳຫຼາຍກວ່າເນື່ອງຈາກຂະໜາດຂອງຕົວຄອມໄພລ໌ Kotlin ໃຫຍ່. ໂຄງການ Compose ຖືກສ້າງຜ່ານ GitHub Actions ຫຼື ໃນ Termux ດ້ວຍ Gradle. ໂຄງການ Python ຕ້ອງການ Android 7.0 ຫຼື ໃໝ່ກວ່າ (SDK ຕ່ຳສຸດ 24) ແລະ APK ຜົນລັບຈະໃຫຍ່ກວ່າ ເພາະມັນລວມ runtime Python (Chaquopy) ພ້ອມກັບໄລບຣາຣີມາດຕະຖານຂອງມັນໄວ້.

ເມນູ Terminal ໃນໜ້າຈໍຫຼັກເປີດ terminal ພາຍໃນແອັບນີ້. ຄຳສັ່ງເຊັ່ນ ls ສາມາດໃຊ້ເພື່ອເບິ່ງເນື້ອໃນຂອງໂຟນເດີໂຄງການ cd ເພື່ອຍ້າຍໂຟນເດີ ແລະ git ເພື່ອຈັດການໂຄດ. ຜົນອອກຂອງຄຳສັ່ງຖືກແດງເປັນຂໍ້ຄວາມທີ່ໂປຣແກຣມອ່ານໜ້າຈໍອ່ານໄດ້ ແລະ ມີປຸ່ມ Bacakan hasil ເພື່ອຟັງຜົນລັບສຸດທ້າຍ. Terminal ນີ້ໃຊ້ shell ຂອງລະບົບໂທລະສັບ ດັ່ງນັ້ນໂປຣແກຣມໂຕ້ຕອບເຊັ່ນ nano ແລະ vim ຍັງບໍ່ສາມາດໃຊ້ຢູ່ນີ້ໄດ້ເທື່ອ.

Lisensi (ເວີຊັນເສຍເງິນ)
ເພື່ອຂາຍແອັບ ໃຫ້ໝາຍ "Aktifkan Lisensi" ເວລາສ້າງໂຄງການ ແລ້ວຕື່ມເບີ WhatsApp ຂອງທ່ານ. ແອັບທີ່ສ້າງແລ້ວຈະຂໍລະຫັດໃບອະນຸຍາດເມື່ອເປີດຄັ້ງທຳອິດ: ຜູ້ໃຊ້ເຫັນ ID ອຸປະກອນຂອງຕົນ ກົດປຸ່ມ Kirim ID Perangkat ເພື່ອສົ່ງ ID ນັ້ນໄປຫາ WhatsApp ຂອງທ່ານ ແລ້ວທ່ານຕອບກັບດ້ວຍລະຫັດໃບອະນຸຍາດຂອງພວກເຂົາ. ລະຫັດໃບອະນຸຍາດຖືກຄຳນວນຈາກ ID ອຸປະກອນ ແລະ ລະຫັດຜ່ານໂຄງການ (lisensi_seed ໃນໄຟລ໌ຂໍ້ມູນໂຄງການ) — ເກັບລະຫັດຜ່ານນັ້ນໄວ້ໃຫ້ດີ ແລະ ຢ່າແບ່ງປັນມັນ. ຫຼັງຈາກລະຫັດທີ່ຖືກຕ້ອງຖືກປ້ອນແລ້ວ ແອັບຈະເປີດ ແລະ ບໍ່ຂໍລະຫັດອີກ.

Pembuat Ikon Otomatis
ໄອຄອນຂອງໂຄງການໃໝ່ຍັງໂປ່ງໃສຢູ່ ດັ່ງນັ້ນ Pembuat Ikon ຈຶ່ງມີຢູ່ໃນເມນູຫຼັກ. ວິທີ: ກົດ Pembuat Ikon ຂຽນຕົວອັກສອນໜຶ່ງ ຫຼື ສອງຕົວ (ຕົວຢ່າງ ຕົວຫຍໍ້ຂອງຊື່ແອັບ) ເລືອກສີພື້ນຫຼັງ ແລະ ສີຂໍ້ຄວາມ ເບິ່ງຕົວຢ່າງສະແດງຂອງມັນ ແລ້ວກົດ Simpan ke Proyek ເພື່ອໃຊ້ໄອຄອນນັ້ນໃນໂຄງການທີ່ເລືອກໄວ້ ຫຼື Simpan ke Download ເພື່ອໃຊ້ໄຟລ໌ PNG ຂອງມັນຢູ່ບ່ອນອື່ນ. ຫຼັງຈາກໂຄງການຖືກສ້າງແລ້ວ ແອັບຍັງສະເໜີໃຫ້ສ້າງໄອຄອນອີກດ້ວຍ. ໄອຄອນເກົ່າຂອງໂຄງການສາມາດປ່ຽນໄດ້ທຸກເວລາຈາກເມນູໂຄງການໃນ Kelola Project (ກົດຊື່ໂຄງການຄ້າງໄວ້ດົນ ແລ້ວເລືອກ Ganti Ikon).

Template Proyek Siap Pakai
ຖ້າບໍ່ຢາກເລີ່ມຈາກໂຄງການວ່າງເປົ່າ ໃຫ້ເລືອກແມ່ແບບເວລາສ້າງໂຄງການ: Kalkulator (Java), Catatan (Java), Daftar Tugas (Kotlin), Kalkulator Web (HTML), Situs Profil (Situs Web), ຫຼື Penghitung (Compose). ການເລືອກແມ່ແບບຈະປ່ຽນປະເພດໂຄງການໂດຍອັດຕະໂນມັດໃຫ້ກົງກັບແມ່ແບບນັ້ນ ແລະ ໂຄງການຈະຖືກສ້າງດ້ວຍໂຄດເລີ່ມຕົ້ນທີ່ພ້ອມແລ້ວ — ເຫຼືອພຽງເຮັດວຽກ ຫຼື ແກ້ໄຂມັນເທົ່ານັ້ນ. ຖ້າປະເພດໂຄງການຖືກປ່ຽນດ້ວຍມືອີກຄັ້ງຫຼັງຈາກເລືອກແມ່ແບບແລ້ວ ແມ່ແບບຈະຖືກຍົກເລີກ ແລະ ໂຄງການກັບໄປວ່າງເປົ່າອີກ. ສຳລັບແມ່ແບບ HTML ແລະ Situs Web ແມ່ແບບຈະປ່ຽນແທນເນື້ອໃນຂອງ index.html ລວມທັງສະຄຣິບ HTML ທີ່ພິມໄວ້ໃນແບບຟອມ.

Cadangan dan Pulihkan Proyek
ເພື່ອບໍ່ໃຫ້ໂຄງການຫາຍໄປ ຄຸນສົມບັດສຳຮອງຂໍ້ມູນມີໃຫ້ໃຊ້. ວິທີ: ໃນ Kelola Project ກົດຊື່ໂຄງການຄ້າງໄວ້ດົນ ແລ້ວເລືອກ Cadangkan. ຂໍ້ມູນສຳຮອງຈະຖືກບັນທຶກເປັນ ZIP ໃນໂຟນເດີ Download/backup ພ້ອມຊື່ໂຄງການ ແລະ ວັນທີ ຕົວຢ່າງ: GarudaDecode-2026-11-14-123045.zip. ເນື້ອໃນຂອງມັນຄືກັນກັບ Ekspor ZIP (ເນື້ອໃນໂຄງການທັງໝົດ ໂດຍບໍ່ມີໂຟນເດີ bin). ເພື່ອກູ້ຄືນ: ເປີດເມນູໃນ Kelola Project ເລືອກ Pulihkan cadangan ແລ້ວເລືອກໄຟລ໌ສຳຮອງຂອງມັນ. ຖ້າຊື່ໂຄງການມີຢູ່ແລ້ວ ແອັບຈະຖາມວ່າ: ຂຽນທັບໂຄງການເກົ່າ ຫຼື ບັນທຶກດ້ວຍຊື່ໃໝ່.

Bagikan dan Impor Proyek
ເພື່ອແບ່ງປັນໂຄງການໃຫ້ໝູ່: ໃນ Kelola Project ກົດຊື່ໂຄງການຄ້າງໄວ້ດົນ ແລ້ວເລືອກ Bagikan. ໂຄງການຈະຖືກສົ່ງເປັນ ZIP ຜ່ານແອັບແບ່ງປັນ (WhatsApp, Telegram, ແລະ ອື່ນໆ). ເພື່ອຮັບໂຄງການຈາກໝູ່: ເປີດເມນູໃນ Kelola Project ເລືອກ Impor proyek ແລ້ວເລືອກໄຟລ໌ ZIP ຂອງມັນ. ໄຟລ໌ ZIP ນັ້ນຕ້ອງມີໄຟລ໌ຂໍ້ມູນໂຄງການ — ຖ້າບໍ່ມີ ໄຟລ໌ຈະຖືກປະຕິເສດດ້ວຍຂໍ້ຄວາມທີ່ຊັດເຈນ ເພາະໄຟລ໌ນັ້ນບໍ່ແມ່ນໂຄງການ Create Aplikasi. ຖ້າຊື່ໂຄງການມີຢູ່ແລ້ວ ແອັບຈະຖາມວ່າ: ຂຽນທັບໂຄງການເກົ່າ ຫຼື ບັນທຶກດ້ວຍຊື່ໃໝ່.

Pencarian dan Filter Proyek
ຖ້າໂຄງການມີຫຼາຍແລ້ວ ໃນ Kelola Project ມີກ່ອງຄົ້ນຫາ ແລະ ຕົວກັ່ນຕອງປະເພດ. ພິມຊື່ໂຄງການໃນກ່ອງຄົ້ນຫາ ລາຍການຈະຖືກກັ່ນຕອງທັນທີ (ຕົວອັກສອນໃຫຍ່ ແລະ ຕົວອັກສອນນ້ອຍບໍ່ໄດ້ແຍກແຍະ). ຕົວກັ່ນຕອງປະເພດຈະຈຳກັດລາຍການໃຫ້ເຫຼືອພຽງປະເພດດຽວ: Semua, HTML, Situs Web, Java, Kotlin, Compose, ຫຼື Python. ເມນູຂອງແຕ່ລະໂຄງການຍັງສາມາດເປີດໄດ້ຕາມປົກກະຕິຈາກລາຍການທີ່ກັ່ນຕອງແລ້ວ.
