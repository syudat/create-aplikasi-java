Добро пожаловать в Create Aplikasi by Al Kautsar
Create Aplikasi — это приложение для создания Android-приложений, которое работает прямо на телефоне, без необходимости в ноутбуке. Это приложение позволяет любому создавать собственные Android-приложения, включая пользователей, которые только начинают учиться создавать приложения, и пользователей программ чтения с экрана. Полное руководство по использованию этого приложения доступно на этом экране «Об этом инструменте».

Что это за приложение и для кого оно
Create Aplikasi — это инструмент для создания Android-приложений, который работает на телефоне. Это приложение предназначено для всех, кто хочет создавать собственные Android-приложения, включая новичков и пользователей программ чтения с экрана. Это приложение предоставляет редактор кода, кнопку «Запустить» для тестирования проектов, кнопку «Собрать» для создания APK, а также меню для подписи и установки APK.

Цель этого приложения
Это приложение было создано для того, чтобы любой мог легко создавать собственные Android-приложения прямо с телефона. Его интерфейс сделан максимально простым, чтобы даже новые пользователи могли сразу попробовать.

Как создать новый проект, шаг за шагом
1. Нажмите «Создать проект» в главном меню.
2. Выберите тип проекта: HTML, Веб-сайт, Java, Kotlin, Compose или Python.
3. Введите название приложения, например: Garuda Decode.
4. Введите имя пакета (package name), например: com.android.garudadecode. Имя пакета должно использовать строчные буквы и состоять как минимум из двух частей, разделённых точками.
5. Введите версию приложения, например: 1.0, и код версии в виде числа, например: 1. Если оставить пустым, версия будет автоматически заполнена значением 1.0, а код версии — 1.
6. При необходимости введите минимальный SDK и целевой SDK. Если оставить пустым, будут использованы значения по умолчанию. Минимальный SDK — это самая низкая поддерживаемая версия Android, например: 21 означает Android 5.0. Максимальный целевой SDK — 36 (Android 16).
7. Нажмите кнопку «Выбрать разрешения», чтобы выбрать разрешения приложения, например: INTERNET. Разрешение INTERNET уже отмечено по умолчанию. Отмечайте только те разрешения, которые приложению действительно нужны.
8. При желании отметьте «Использовать отдельные архитектуры 64 бит и 32 бит», чтобы размер APK был меньше, и отметьте «Использовать личную подпись», если хотите использовать собственное хранилище ключей.
9. Нажмите «Создать проект». Новый проект сохраняется в папке Download/project и сразу появляется в разделе «Управление проектами».

Доступные типы проектов
• HTML: отображение из index.html, style.css и script.js, работает через WebView. Собирается прямо на телефоне.
• Веб-сайт: веб-сайт с меню (Главная, О нас, Контакты) из index.html, tentang.html, kontak.html, style.css и script.js, работает через WebView. Собирается прямо на телефоне.
• Java: собирается на телефоне. MainActivity находится в app/src/main/java/<package-name>/MainActivity.java. Отображение берётся из app/src/main/res/layout/activity_main.xml, текст — из app/src/main/res/values/strings.xml, а тема — из app/src/main/res/values/styles.xml.
• Kotlin: может собираться на устройстве (офлайн) с помощью компилятора Kotlin, включённого в приложение, или через GitHub Actions. MainActivity находится в app/src/main/java/<package-name>/MainActivity.kt, а файлы res такие же, как в проекте Java. Первая сборка Kotlin происходит медленнее из-за большого размера компилятора, а файлы .java, ссылающиеся на классы Kotlin, пока не могут быть собраны (файлы .java компилируются раньше файлов .kt).
• Compose: современное Android-приложение, интерфейс которого создаётся с помощью Jetpack Compose (а не XML-разметки). MainActivity находится в app/src/main/java/<package-name>/MainActivity.kt. Проекты Compose собираются через GitHub Actions (меню «Собрать проект», затем «Собрать онлайн») или в Termux с помощью Gradle, потому что Compose требует библиотек Jetpack Compose, которых нет на устройстве.
• Python: логика приложения пишется на языке Python (Chaquopy) в app/src/main/python/main.py и запускается хостом MainActivity.java в app/src/main/java/<package-name>/MainActivity.java. Проекты Python можно собирать прямо на телефоне (среда выполнения Chaquopy включена в приложение) или через GitHub Actions. Минимальный SDK для проектов Python — 24 (Android 7.0).

Структура файлов проектов Java, HTML, Веб-сайт, Kotlin, Compose и Python
Проекты Java, HTML, Веб-сайт, Kotlin, Compose и Python структурированы так же, как Android-проекты в целом. Внутри папки app находится папка src, а внутри неё — папка main. Внутри папки main находится AndroidManifest.xml рядом с папкой java, папка res, содержащая layout/activity_main.xml и values/strings.xml, а также values/styles.xml, а для HTML и Веб-сайта — папка assets, содержащая index.html (у Веб-сайта также есть tentang.html и kontak.html). У проектов HTML и Веб-сайт также есть собственный MainActivity в app/src/main/java/<package-name>/MainActivity.java, который загружает index.html в WebView и становится лаунчером в AndroidManifest. У проектов Python код Python находится в app/src/main/python/main.py, а хост MainActivity.java — в app/src/main/java/<package-name>/MainActivity.java. AndroidManifest.xml, разметку, строки и стили можно открывать и изменять в редакторе, как и MainActivity. Старые проекты, манифест которых всё ещё находится рядом с папкой app, по-прежнему можно собирать, потому что при сборке приложение сначала проверяет AndroidManifest.xml в app/src/main/, затем тот, что рядом с папкой app, и, наконец, файл данных проекта.

Правила разрешений (важно)
Разрешения, отмеченные при создании проекта, записываются только в одном месте, в зависимости от типа проекта. Для проектов Java, HTML, Веб-сайт, Kotlin, Compose и Python отмеченные разрешения записываются ТОЛЬКО в AndroidManifest.xml, расположенный в app/src/main/, рядом с папкой java, внутри папки проекта. Файл данных проекта для проектов Java, HTML, Веб-сайт, Kotlin, Compose и Python не содержит списка разрешений. Если вы выберете Java, а затем отметите INTERNET и CAMERA, в AndroidManifest.xml будет записано только INTERNET и CAMERA, без включения каких-либо других разрешений. При сборке приложение читает разрешения из того же места: из AndroidManifest.xml в app/src/main/ для проектов Java, HTML, Веб-сайт, Kotlin, Compose и Python (если его нет — из AndroidManifest.xml рядом с папкой app для старых проектов) и из файла данных проекта для старых проектов.

Как пользоваться редактором
Откройте «Управление проектами», коснитесь названия проекта, чтобы открыть редактор. В редакторе можно открывать файлы, писать код и сохранять изменения. Для проектов Java, HTML, Веб-сайт, Kotlin, Compose и Python файлы расположены внутри папки app/src/main. Чтобы поделиться проектом, используйте «Экспорт в ZIP» (см. раздел ниже).

Как запустить проект
В редакторе нажмите «Запустить», чтобы протестировать проект. Для проектов HTML и Веб-сайт запускается index.html через WebView. Если произойдёт ошибка, прочитайте сообщение об ошибке, исправьте код, а затем запустите снова.

Как собрать APK
В редакторе нажмите «Собрать». Есть два способа сборки. Первый — «Собрать на устройстве»: собирает прямо на телефоне без интернета, для проектов HTML, Веб-сайт, Java, Kotlin и Python. Второй — «Собрать онлайн» через GitHub Actions: собирает через интернет на GitHub и может использоваться для всех типов проектов. Проекты Compose можно собирать только вторым способом («Собрать онлайн») или в Termux с помощью Gradle, потому что Compose требует библиотек Jetpack Compose, которых нет на устройстве. Результат первой сборки ещё не подписан. После этого приложение подписывает его: автоматически встроенным ключом или личной подписью, если при создании проекта был отмечен флажок «Использовать личную подпись».

Как установить APK
Когда APK будет готов, нажмите «Установить», чтобы установить его. На Android 8 и выше телефон сначала запросит «Разрешить из этого источника», потому что это приложение устанавливает APK не из Play Store. Включите это разрешение один раз в Настройках, затем вернитесь в приложение: установка продолжится автоматически, без необходимости снова нажимать «Установить». Если кнопка «Установить» не появляется, убедитесь, что сборка завершена и APK создан.

Как подписать приложение
Каждый APK должен быть подписан, чтобы его можно было установить. Доступны два варианта. Первый — встроенный ключ: приложение подписывает его само автоматически, вам не нужно ничего делать. Второй — личная подпись: сначала создайте хранилище ключей через меню «Создать хранилище ключей» в главном меню, надёжно сохраните его пароль, затем отметьте «Использовать личную подпись» при создании проекта. Хранилище ключей хранится в Download/project/signing.

Экспорт проекта в ZIP
Экспорт в ZIP предусмотрен для того, чтобы проектами можно было делиться с друзьями. Как это сделать: в разделе «Управление проектами» нажмите и удерживайте название проекта, затем выберите «Экспорт в ZIP». Результат сохраняется в Download/project/<ProjectName>.zip. Папка bin не включается, поэтому размер небольшой, всего десятки КБ. Этот ZIP-файл можно отправить друзьям или загрузить на GitHub.

Расширение JAWS
Расширение JAWS использует движок расширений Jieshuo (CSR), а не его программу чтения с экрана. Таким образом, макеты могут продолжать работать, даже если пользователь использует TalkBack. Как это сделать: откройте «Расширение JAWS» в главном меню. Поскольку автоматический щелчок работает сам по себе, сначала необходимо включить службу в Настройках специальных возможностей. После этого можно создать новый макет: введите название макета, нажмите OK, затем заполните его поля.

Список щелчков хранится отдельно для порядка
Внутри макета есть два поля: поле скрипта и поле «Список щелчков». Список кнопок хранится отдельно в файле daftar_klik.txt, по одному имени в строке. Пример его содержимого: tombolSimpan, tombolHapus, tombolBuka. Чтобы открыть приложение, просто напишите >WhatsApp в этом списке. Старые макеты, у которых ещё нет файла daftar_klik.txt, будут показывать этот пример по умолчанию.

Предоставляемые простые функции
• klikTombol("tombolSimpan") — нажимает одну кнопку по её тексту.
• klikDaftarTombol(daftar) — нажимает список в daftar_klik.txt, по одной кнопке в строке, по порядку, а затем сообщает, сколько удалось и сколько не найдено.
• bukaAplikasi("WhatsApp") — открывает приложение по его названию, или напишите ">WhatsApp" в списке.
• klik(540, 1200) — нажимает по координатам экрана.
Все функции сначала сделаны простыми. Когда вы к ним привыкнете, позже можно будет добавить дополнительные функции.

О программах чтения с экрана
Это приложение разработано так, чтобы быть удобным для программ чтения с экрана. У каждого поля ввода есть подпись и пример заполнения, и до всех кнопок можно добраться без сложных жестов. Расширение JAWS сделано так, чтобы продолжать работать, даже если пользователь использует TalkBack, потому что используется его движок расширений, а не его программа чтения с экрана.

Конфиденциальность и безопасность
Проекты и хранилища ключей хранятся на вашем телефоне. Токен GitHub используется только для онлайн-сборок и хранится внутри этого приложения. Не делитесь своим токеном или паролем хранилища ключей ни с кем. Если вы используете личную подпись, храните хранилище ключей и его пароль в безопасном месте, потому что если они будут потеряны, старые APK нельзя будет обновить той же подписью.

Требования
Android 5.0 или новее. Разрешение на хранение: на Android 11 и выше используется разрешение на доступ ко всем файлам, на Android 10 и ниже используется обычное разрешение на хранение (чтение/запись хранилища), потому что в Android 10 нет разрешения на доступ ко всем файлам. Для сборки на устройстве требуется телефон с процессором ARM (32 или 64 бит). Для онлайн-сборки через GitHub Actions требуются интернет и токен GitHub. Проекты Kotlin можно собирать на устройстве, но первая сборка происходит медленнее и использует больше памяти из-за большого размера компилятора Kotlin. Проекты Compose собираются через GitHub Actions или в Termux с помощью Gradle. Проекты Python требуют Android 7.0 или новее (минимальный SDK 24), а итоговый APK больше, потому что он включает среду выполнения Python (Chaquopy) вместе с её стандартной библиотекой.

Терминал
Меню «Терминал» на главном экране открывает терминал внутри этого приложения. Такие команды, как ls, можно использовать для просмотра содержимого папки проекта, cd — для перемещения между папками, а git — для управления кодом. Вывод команд отображается в виде текста, который может прочитать программа чтения с экрана, и есть кнопка «Прочитать результат вслух», чтобы прослушать последний результат. Этот терминал использует системную оболочку телефона, поэтому интерактивные программы, такие как nano и vim, здесь пока нельзя использовать.

Лицензия (платная версия)
Чтобы продавать приложение, отметьте «Включить лицензию» при создании проекта, затем введите свой номер WhatsApp. Собранное приложение при первом открытии запросит лицензионный код: пользователь видит ID своего устройства, нажимает кнопку «Отправить ID устройства», чтобы отправить этот ID на ваш WhatsApp, а затем вы отвечаете лицензионным кодом. Лицензионный код вычисляется из ID устройства и пароля проекта (lisensi_seed в файле данных проекта) — надёжно храните этот пароль и не делитесь им. После ввода правильного кода приложение открывается и больше не запрашивает код.

Автоматический создатель значков
Значки новых проектов всё ещё прозрачны, поэтому в главном меню доступен Создатель значков. Как это сделать: нажмите «Создатель значков», напишите одну или две буквы (например, инициалы названия приложения), выберите цвет фона и цвет текста, посмотрите предварительный просмотр, затем нажмите «Сохранить в проект», чтобы использовать этот значок в выбранном проекте, или «Сохранить в загрузки», чтобы использовать его PNG-файл в другом месте. После создания проекта приложение также предлагает создать значок. Старый значок проекта можно заменить в любое время из меню проекта в разделе «Управление проектами» (нажмите и удерживайте название проекта, затем выберите «Сменить значок»).

Готовые шаблоны проектов
Если вы не хотите начинать с пустого проекта, выберите шаблон при создании проекта: Калькулятор (Java), Заметки (Java), Список дел (Kotlin), Веб-калькулятор (HTML), Сайт-профиль (Веб-сайт) или Счётчик (Compose). Выбор шаблона автоматически меняет тип проекта в соответствии с этим шаблоном, и проект создаётся с уже готовым начальным кодом — просто запустите или измените его. Если тип проекта снова изменить вручную после выбора шаблона, шаблон отменяется, и проект снова становится пустым. Для шаблонов HTML и Веб-сайт шаблон заменяет содержимое index.html, включая HTML-скрипт, введённый в форме.

Резервное копирование и восстановление проектов
Чтобы проекты не потерялись, доступна функция резервного копирования. Как это сделать: в разделе «Управление проектами» нажмите и удерживайте название проекта, затем выберите «Создать резервную копию». Резервная копия сохраняется в виде ZIP в папке Download/backup с названием проекта и датой, например: GarudaDecode-2026-11-14-123045.zip. Её содержимое такое же, как при экспорте в ZIP (всё содержимое проекта, без папки bin). Для восстановления: откройте меню в разделе «Управление проектами», выберите «Восстановить резервную копию», затем выберите файл резервной копии. Если название проекта уже существует, приложение спросит: Перезаписать старый проект или сохранить с Новым именем.

Поделиться проектами и импортировать проекты
Чтобы поделиться проектом с друзьями: в разделе «Управление проектами» нажмите и удерживайте название проекта, затем выберите «Поделиться». Проект отправляется в виде ZIP через приложения для обмена (WhatsApp, Telegram и другие). Чтобы получить проект от друга: откройте меню в разделе «Управление проектами», выберите «Импортировать проект», затем выберите ZIP-файл. Этот ZIP-файл должен содержать файл данных проекта — если его нет, файл отклоняется с понятным сообщением, потому что этот файл не является проектом Create Aplikasi. Если название проекта уже существует, приложение спросит: Перезаписать старый проект или сохранить с Новым именем.

Поиск и фильтр проектов
Если проектов уже много, в разделе «Управление проектами» есть поле поиска и фильтр по типу. Введите название проекта в поле поиска, и список сразу отфильтруется (прописные и строчные буквы не различаются). Фильтр по типу ограничивает список только одним типом: Все, HTML, Веб-сайт, Java, Kotlin, Compose или Python. Меню каждого проекта по-прежнему можно открыть как обычно из уже отфильтрованного списка.

Создание приложений голосом
