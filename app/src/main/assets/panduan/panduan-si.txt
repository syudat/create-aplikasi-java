Create Aplikasi යනු දුරකථනය මත ක්‍රියාත්මක වන Android යෙදුම් සාදන මෙවලමකි. මෙම යෙදුම තමන්ගේම Android යෙදුමක් සෑදීමට කැමති ඕනෑම කෙනෙකු සඳහා වන අතර, ආරම්භකයින් සහ තිර කියවනය භාවිතා කරන්නන් ද ඇතුළත් වේ. මෙම යෙදුම කේත සංස්කාරකයක්, ව්‍යාපෘතිය පරීක්ෂා කිරීම සඳහා Jalankan බොත්තම, APK එකක් සෑදීම සඳහා Bangun බොත්තම, මෙන්ම APK අත්සන් කිරීම සහ ස්ථාපනය කිරීම සඳහා මෙනු ද සපයයි.

5. යෙදුම් අනුවාදය පුරවන්න, උදාහරණ: 1.0, සහ අංකයක් ලෙස අනුවාද කේතය, උදාහරණ: 1. හිස්ව තැබුවහොත්, අනුවාදය ස්වයංක්‍රීයව 1.0 ලෙසත් අනුවාද කේතය 1 ලෙසත් පුරවනු ලැබේ.

8. අවශ්‍ය නම්, APK ප්‍රමාණය කුඩා කිරීම සඳහා "Gunakan arsitektur terpisah 64 bit dan 32 bit" සලකුණු කරන්න, සහ ඔබ විසින්ම සාදන ලද keystore එකක් භාවිතා කිරීමට අවශ්‍ය නම් "Gunakan tanda tangan pribadi" සලකුණු කරන්න.
9. Buat Proyek ඔබන්න. නව ව්‍යාපෘතිය Download/project ෆෝල්ඩරයේ සුරකින අතර Kelola Project තුළ වහාම දිස් වේ.

ලබා ගත හැකි ව්‍යාපෘති වර්ග
• HTML: WebView හරහා ක්‍රියාත්මක වන index.html, style.css, සහ script.js වලින් සැදුම් ලත් දර්ශනය. දුරකථනය මත කෙලින්ම ගොඩනගනු ලැබේ.
• Situs Web: WebView හරහා ක්‍රියාත්මක වන index.html, tentang.html, kontak.html, style.css, සහ script.js වලින් සැදුම් ලත්, මෙනුවක් (Beranda, Tentang, Kontak) ඇති වෙබ් අඩවිය. දුරකථනය මත කෙලින්ම ගොඩනගනු ලැබේ.
• Java: දුරකථනය මත ගොඩනගනු ලැබේ. MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.java තුළය. දර්ශනය app/src/main/res/layout/activity_main.xml වෙතින්, පෙළ app/src/main/res/values/strings.xml වෙතින්, සහ තේමාව app/src/main/res/values/styles.xml වෙතින් ලැබේ.
• Kotlin: යෙදුමට ඇතුළත් කර ඇති Kotlin සම්පාදකය භාවිතා කර උපාංගය මතම (offline) හෝ GitHub Actions හරහා ගොඩනැගිය හැකිය. MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.kt තුළ වන අතර res ගොනු Java ව්‍යාපෘතියේ ඒවාට සමාන වේ. සම්පාදකයේ විශාල ප්‍රමාණය නිසා පළමු Kotlin ගොඩනැගීම මන්දගාමී වන අතර, Kotlin පන්ති වෙත යොමු වන .java ගොනු තවම ගොඩනැගිය නොහැක (.java ගොනු .kt ගොනුවලට පෙර සම්පාදනය කෙරේ).
• Compose: එහි අතුරුමුහුණත Jetpack Compose භාවිතයෙන් සාදා ඇති නවීන Android යෙදුමකි (XML layout එකක් නොවේ). MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.kt තුළය. Compose ව්‍යාපෘති GitHub Actions හරහා (Bangun proyek මෙනුව, ඉන්පසු Bangun online) හෝ Gradle සමඟ Termux තුළ ගොඩනගනු ලැබේ, මන්ද Compose සඳහා උපාංගය මත ලබා ගත නොහැකි Jetpack Compose පුස්තකාල අවශ්‍ය වන බැවිනි.
• Python: යෙදුම් තර්කය Python භාෂාවෙන් (Chaquopy) app/src/main/python/main.py තුළ ලියා ඇති අතර app/src/main/java/<nama-paket>/MainActivity.java තුළ ඇති MainActivity host එක මගින් ධාවනය කෙරේ. Python ව්‍යාපෘති දුරකථනය මත කෙලින්ම (Chaquopy runtime එක යෙදුමට ඇතුළත් කර ඇත) හෝ GitHub Actions හරහා ගොඩනැගිය හැකිය. Python ව්‍යාපෘතියක අවම SDK එක 24 (Android 7.0) වේ.

ව්‍යාපෘති ගෘහ නිර්මාණ ශිල්පය වෙනස් කරන්න
නව ව්‍යාපෘතියක් නිර්මාණය නොකර පවතින ව්‍යාපෘතියක ගෘහ නිර්මාණ විකල්ප වෙනස් කිරීමට: ප්‍රධාන මෙනුවේ «ව්‍යාපෘති ගෘහ නිර්මාණය වෙනස් කරන්න» ඔබන්න, ඉන්පසු ව්‍යාපෘතිය තෝරා «64-bit APK ගොඩනඟන්න (arm64-v8a)» හෝ «32-bit APK ගොඩනඟන්න (armeabi-v7a)» කොටුව වෙනස් කරන්න; නැතහොත් «ව්‍යාපෘති කළමනාකරණය කරන්න» හි ව්‍යාපෘති නාමය දිගු ඔබා එම ව්‍යාපෘතිය සඳහා එම තිරයම සෘජුවම විවෘත කිරීමට «ගෘහ නිර්මාණය වෙනස් කරන්න» තෝරන්න. රීතිය මෙයයි: කොටු දෙකම සක්‍රිය කර ඇත්නම්, ගොඩනැඟීම APK ගොනු වෙන් වෙන් වශයෙන් දෙකක් සාදයි, එකක් 64-bit සහ එකක් 32-bit; එක් කොටුවක් පමණක් සක්‍රිය කර ඇත්නම්, ගොඩනැඟීම 64-bit සහ 32-bit උපාංග දෙකෙහිම දිගටම ක්‍රියා කරන තනි විශ්ව APK ගොනුවක් සාදයි. තනි ප්‍රභේදයක් සඳහා පමණක් වෙන් වූ APK තවමත් සහාය නොදක්වයි, මන්ද ගොඩනැඟීමේ මාර්ගය දන්නේ බෙදුණු හෝ විශ්ව තේරීම පමණි, නමුත් එක් එක් ප්‍රභේදයේ තේරීම තිරය නැවත විවෘත කළ විට නැති නොවන පරිදි ව්‍යාපෘතිය තුළම සුරකිනු ලැබේ.

Java, HTML, Situs Web, Kotlin, Compose, සහ Python ව්‍යාපෘතිවල ගොනු ව්‍යුහය
Java, HTML, Situs Web, Kotlin, Compose, සහ Python ව්‍යාපෘති සාමාන්‍ය Android ව්‍යාපෘති මෙන් සකස් කර ඇත. app ෆෝල්ඩරය තුළ src ෆෝල්ඩරය ඇති අතර, ඒ තුළ main ෆෝල්ඩරය ඇත. main ෆෝල්ඩරය තුළ java ෆෝල්ඩරය අසල AndroidManifest.xml, layout/activity_main.xml සහ values/strings.xml මෙන්ම values/styles.xml අඩංගු res ෆෝල්ඩරය, සහ HTML සහ Situs Web සඳහා index.html අඩංගු assets ෆෝල්ඩරය (Situs Web හි tentang.html සහ kontak.html ද ඇත) ඇත. HTML සහ Situs Web ව්‍යාපෘතිවලට ද app/src/main/java/<nama-paket>/MainActivity.java තුළ තමන්ගේම MainActivity එකක් ඇති අතර, එය index.html එක WebView තුළට පූරණය කරන අතර AndroidManifest තුළ launcher එක වේ. Python ව්‍යාපෘතියේ Python කේතය app/src/main/python/main.py තුළ ඇති අතර host MainActivity.java ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.java තුළය. AndroidManifest.xml, layout, strings, සහ styles, MainActivity මෙන්ම සංස්කාරකය තුළ විවෘත කර වෙනස් කළ හැකිය. Manifest එක තවමත් app ෆෝල්ඩරය අසල ඇති පැරණි ව්‍යාපෘති ද ගොඩනැගිය හැකිය, මන්ද ගොඩනගන විට යෙදුම පළමුව app/src/main/ තුළ ඇති AndroidManifest.xml එක, ඉන්පසු app ෆෝල්ඩරය අසල ඇති එක, සහ අවසානයේ ව්‍යාපෘති දත්ත ගොනුව පරීක්ෂා කරන බැවිනි.

GitHub Actions හරහා මාර්ගගතව ගොඩනැගීමට අන්තර්ජාලය සහ GitHub ටෝකනයක් අවශ්‍ය වේ. Compose ව්‍යාපෘති GitHub Actions හරහා හෝ Gradle සමඟ Termux තුළ ගොඩනගනු ලැබේ. Python ව්‍යාපෘතිවලට Android 7.0 හෝ ඊට අලුත් (අවම SDK 24) අවශ්‍ය වන අතර, ප්‍රතිඵල APK එකෙහි Python runtime (Chaquopy) සහ එහි සම්මත පුස්තකාලය ඇතුළත් වන බැවින් එය විශාල වේ.

Terminal
ප්‍රධාන තිරයේ ඇති Terminal මෙනුව මෙම යෙදුම තුළ terminal එකක් විවෘත කරයි. ls වැනි විධාන ව්‍යාපෘති ෆෝල්ඩරයේ අන්තර්ගතය බැලීමට, cd ෆෝල්ඩර මාරු කිරීමට, සහ git කේතය කළමනාකරණය කිරීමට භාවිතා කළ හැකිය. විධාන ප්‍රතිදානය තිර කියවනයට කියවිය හැකි පෙළක් ලෙස පෙන්වනු ලබන අතර, අවසාන ප්‍රතිඵලයට සවන් දීමට Bacakan hasil බොත්තමක් ඇත. මෙම terminal එක දුරකථනයේ පද්ධති shell එක භාවිතා කරන බැවින්, nano සහ vim වැනි අන්තර්ක්‍රියාකාරී වැඩසටහන් මෙහි තවම භාවිතා කළ නොහැක.

යෙදුම් විකිණීමට, ව්‍යාපෘතිය සාදන විට "Aktifkan Lisensi" සලකුණු කර, ඉන්පසු ඔබේ WhatsApp අංකය පුරවන්න. ගොඩනගන ලද යෙදුම පළමු වරට විවෘත කරන විට බලපත්‍ර කේතයක් ඉල්ලනු ඇත: භාවිතා කරන්නා තම උපාංග ID එක දකින අතර, Kirim ID Perangkat බොත්තම එබීමෙන් එම ID එක ඔබේ WhatsApp වෙත යවා, ඉන්පසු ඔබ ඔවුන්ගේ බලපත්‍ර කේතය පිළිතුරු ලෙස එවයි. බලපත්‍ර කේතය උපාංග ID එකෙන් සහ ව්‍යාපෘති මුරපදයෙන් (ව්‍යාපෘති දත්ත ගොනුවේ ඇති lisensi_seed) ගණනය කරනු ලැබේ — එම මුරපදය හොඳින් සුරකින්න සහ එය බෙදා නොගන්න. නිවැරදි කේතය ඇතුළත් කළ පසු, යෙදුම විවෘත වන අතර නැවත කේතය ඉල්ලන්නේ නැත.

Pembuat Ikon Otomatis
නව ව්‍යාපෘතියක නිරූපකය තවමත් පාරදෘශ්‍ය බැවින්, ප්‍රධාන මෙනුවේ Pembuat Ikon ලබා ගත හැකිය. ආකාරය: Pembuat Ikon ඔබා, අකුරක් හෝ අකුරු දෙකක් ලියන්න (උදාහරණයක් ලෙස යෙදුමේ නමේ කෙටි යෙදුම), පසුබිම් වර්ණය සහ පෙළ වර්ණය තෝරන්න, එහි පෙරදසුන බලන්න, ඉන්පසු තෝරාගත් ව්‍යාපෘතියේ නිරූපකය භාවිතා කිරීමට Simpan ke Proyek හෝ එහි PNG ගොනුව වෙනත් තැනක භාවිතා කිරීමට Simpan ke Download ඔබන්න. ව්‍යාපෘතිය සාදන ලද පසු, යෙදුම නිරූපකයක් සෑදීමට ද ඉදිරිපත් කරයි. ව්‍යාපෘතියේ පැරණි නිරූපකය Kelola Project තුළ ඇති ව්‍යාපෘති මෙනුවෙන් ඕනෑම වේලාවක වෙනස් කළ හැකිය (ව්‍යාපෘතියේ නම දිගු වේලාවක් ඔබාගෙන සිට, ඉන්පසු Ganti Ikon තෝරන්න).

ව්‍යාපෘති වෙළඳපොළ තුළ එක් ක්ලික් කිරීමකින් ඔබේ ව්‍යාපෘති ෆෝල්ඩරයට එක් කළ හැකි නියැදි ව්‍යාපෘති ඇත - ගණකය, සටහන්, කාර්ය ලැයිස්තුව, වෙබ් ගණකය, පැතිකඩ වෙබ් අඩවිය, ගණකය, ඩිජිටල් ඔරලෝසුව සහ වෙබ් ප්‍රශ්නාවලිය. මාර්ගගත වෙළඳපොළක් (අන්තර්ජාලයෙන් නියැදි බාගත කිරීම) තවමත් නැත, එබැවින් මෙම වෙළඳපොළේ යෙදුම තුළ දැනටමත් ඇති නියැදි අඩංගු වේ. එක් කරන ලද ව්‍යාපෘතිය ඔබ විසින්ම සාදන ලද ව්‍යාපෘතියක් මෙන් ව්‍යාපෘති කළමනාකරණය තුළ විවෘත කර වෙනස් කළ හැකිය.

සෘජු සහයෝගීතාව
මිතුරෙකු සමඟ එක් ව්‍යාපෘතියක වැඩ කිරීමට - ප්‍රධාන මෙනුවේ සහයෝගීතාව විවෘත කරන්න, ව්‍යාපෘතිය තෝරන්න, වෙනස් කිරීමේ සටහනක් (මොනවාද වෙනස් වුණේ) ලියා සහයෝගීතාව සඳහා බෙදා ගන්න ඔබන්න. ව්‍යාපෘතිය ඇතුළත CATATAN.txt ගොනුවක් සහිත ZIP එකක් ලෙස යවනු ලැබේ. ඔබේ මිතුරා එය මත වැඩ කර ZIP එක ආපසු යවයි. ඔබ පිළිතුර ලබන්න ඔබා, පළමුව වෙනස් කිරීමේ සටහන කියවා, ඉන්පසු පැරණි ව්‍යාපෘතිය ප්‍රතිස්ථාපනය කිරීමට යොදන්න තෝරන්න හෝ ඔබ අදහස වෙනස් කළහොත් අවලංගු කරන්න තෝරන්න. CATATAN.txt නොමැති ZIP එකක් සහයෝගීතා පැකේජයක් නොවේ - සාමාන්‍ය ව්‍යාපෘති ZIP එකක් සඳහා ව්‍යාපෘති කළමනාකරණය තුළ ව්‍යාපෘතිය ආයාත කරන්න භාවිතා කරන්න.

ස්වයංක්‍රීය යෙදුම් පරිවර්තකය

කේත රහිත ක්‍රීඩා සාදන්නා

IDE රූපයේ ප්‍රමාණය සහ ප්‍රමුඛ වර්ණය විශ්ලේෂණය කර සැබෑ ඡායාරූප ගැලරි යෙදුම් ව්‍යාපෘතියක් සාදයි - රූපය ව්‍යාපෘතියේ assets වෙත පිටපත් කරනු ලැබේ, තේමා වර්ණය රූපයේ ප්‍රමුඛ වර්ණයෙන් ගනු ලැබේ, යෙදුමේ නම රූප ගොනු නමෙන් ගනු ලැබේ. ඡායාරූප ගැලරි යෙදුම ධාවනය කිරීමට හෝ ගොඩනැගීමට ව්‍යාපෘති කළමනාකරණය විවෘත කරන්න.

අන්තර්ක්‍රියාකාරී Terminal (VT විග්‍රහකය)
Terminal හි අන්තර්ක්‍රියාකාරී වැඩසටහන් භාවිතා කිරීමට - ප්‍රධාන මෙනුවේ Terminal විවෘත කර nano, vim, top හෝ htop ධාවනය කරන්න. Terminal දැන් VT විග්‍රහකය භාවිතා කරයි (පේළි 24 x තීරු 80 තිර ජාලකය) එබැවින් මෙම වැඩසටහන් නිවැරදිව පෙන්වනු ලැබේ - කර්සරය චලනය වේ, පේළි මකා දමනු ලැබේ, තිරය සැබෑ ටර්මිනලයක් මෙන් වෙනස් වේ. අන්තර්ක්‍රියාකාරී වැඩසටහන් පාලනය කිරීමට Tab, ඉහළ ඊතලය, පහළ ඊතලය සහ Esc සඳහා විශේෂ බොත්තම් ඇත. ප්‍රතිඵලය Jieshuo හට කියවිය හැකි පෙළක් ලෙස පවතී. අවසාන පේළිය ඇසීමට තිරය කියවන්න ඔබන්න.

Terminal Exec (යෙදුම් ද්විමය)
යෙදුම් ෆෝල්ඩරයේ ඇති ද්විමය ගොනුවක් (උදාහරණයක් ලෙස aapt2, ECJ, D8) Terminal වෙතින් ධාවනය කිරීමට - විධානය සාමාන්‍ය පරිදි ටයිප් කරන්න. IDE libkautsarexec.so භාවිතා කරයි, එබැවින් යෙදුම් ෆෝල්ඩරයේ ඇති ද්විමය ගොනු Android 10 සහ නව ඒවා මත ධාවනය කළ හැකිය. මෙම දුරකථනයේ ද්විමය exec මාර්ගය ක්‍රියා කරන්නේදැයි පරීක්ෂා කිරීමට Terminal හි Exec පරීක්ෂණය ඔබන්න - ප්‍රතිඵලය ඇති පරිදි පෙන්වනු ලැබේ. පද්ධතිය exec අවහිර කරන්නේ නම් පද්ධති විධාන සහ shell ස්ක්‍රිප්ට් දිගටම ක්‍රියා කරයි. ද්විමය ගොනුව ව්‍යාපෘතිය ගොඩනගන්න මෙනුව හරහා ධාවනය කරන්න.

Terminal සජීවීව තබා ගන්න (KeepAlive)
තිරය මාරු කරන විට shell එක දිගටම ධාවනය වීමට - Terminal විවෘත කරන්න, විධානයක් ධාවනය කර ආපසු ඔබන්න හෝ වෙනත් තිරයකට මාරු වන්න - shell එක මිය යන්නේ නැත, Terminal දැනුම්දීම දිගටම පෙන්වයි, එබැවින් ඔබට එක් ක්ලික් කිරීමකින් ආපසු යා හැකිය. ධාවනය කළ විධාන ඉතිහාසය තුළ සුරකිනු ලැබේ (ඉතිහාසය බොත්තම හෝ විධාන ක්ෂේත්‍රයේ ඉහළ/පහළ ඊතල) සහ නිතර භාවිතා කරන විධාන ප්‍රියතම ලෙස සුරැකිය හැක (ප්‍රියතම බොත්තම). අවසන් වූ විට shell එක සැබවින්ම අවසන් කිරීමට Shell එක වසන්න ඔබන්න. ව්‍යාපෘති මෙනුව සහ සංස්කාරක මෙනුවේ ද Terminal හි ගොඩනගන්න බොත්තමක් ඇත - Terminal ව්‍යාපෘති ෆෝල්ඩරයේ ගොඩනැගීමේ විධානය පෙර පුරවා විවෘත වේ.

Terminal මෙවලම් ස්ථාපනය කරන්න (අත්හදා බැලීම)
අත්හදා බැලීමේ විශේෂාංගයක් - Terminal හි සංවර්ධකයාගේ alat-termux repo (github.com/syudat/alat-termux) වෙතින් Termux පරිසරය ස්ථාපනය කිරීමට Terminal මෙවලම් ස්ථාපනය කරන්න (අත්හදා බැලීම) බොත්තමක් ඇත, නිල Termux නිකුතුවෙන් ගන්නා Termux ස්ථාපනය කරන්න බොත්තමට අමතර මාර්ගයක් ලෙස. දර්පණයේ අන්තර්ගතය නිල නිකුතුවට හරියටම සමාන වන අතර ස්ථාපනය අතරතුර SHA-256 මගින් පරීක්ෂා කරනු ලැබේ. පරිසරය ස්ථාපනය කිරීමෙන් පසු ඔබට pkg update සහ pkg install විධාන භාවිතා කළ හැකි අතර repo වෙතින් අමතර මෙවලම් ද terminal වෙත ස්ථාපනය කරනු ලැබේ - info-terminal පරිසර තොරතුරු බැලීමට, bersih-terminal හැඹිලිය හිස් කිරීමට සහ cadangkan-proyek ව්‍යාපෘති ෆෝල්ඩරය දිනය සහිත තනි tar.gz ගොනුවකට සුරැකීමට. ඉන්පසු යෙදුම මූලික Linux පැකේජ (git, python, curl, wget, nano, openssh, zip, unzip) සහ අත්සන් කළ APK ගොඩනැගීමේ මෙවලම් (openjdk-21, kotlin, gradle, ecj, aapt2, d8, apksigner, clang, cmake, ninja, make) නිල Termux repo වෙතින් ස්වයංක්‍රීයව ස්ථාපනය කරයි, එබැවින් terminal යෙදුම් ගොඩනැගීමට වහාම සූදානම් වේ. විශාල පැකේජ (සිය ගණනක් MB) බාගත කිරීමට කාලය ගත විය හැකිය. ස්ථාපනය ක්‍රියාත්මක වන අතරතුර ප්‍රගතිය සහ විධාන ප්‍රතිඵලය Terminal හි ප්‍රධාන තිරයේ පෙන්වනු ලබන අතර අවසාන ප්‍රතිඵලය තිර කියවනය මගින් හඬින් කියවනු ලැබේ. පැකේජ ස්ථාපනය තවමත් සම්පූර්ණ වී නොමැති නම් දිගටම කරගෙන යාමට Terminal මෙවලම් ස්ථාපනය කරන්න (අත්හදා බැලීම) නැවත ඔබන්න.

සම්පූර්ණ හඬ ප්‍රකාරය
IDE සම්පූර්ණයෙන්ම හඬින් පාලනය කිරීමට - ප්‍රධාන මෙනුවේ සම්පූර්ණ හඬ ප්‍රකාරය විවෘත කර සවන් දීම ආරම්භ කරන්න ඔබන්න. IDE අඛණ්ඩව සවන් දෙයි - එක් එක් විධානය සඳහා බොත්තමක් එබීම අවශ්‍ය නොවේ - විධානය ක්‍රියාත්මක කර හඬින් පිළිතුරු දෙයි. විධාන 26ක් ඇත - සාදන්න, ගොඩනගන්න, විවෘත කරන්න, ධාවනය කරන්න, ලැයිස්තු කරන්න, සොයන්න, මකන්න, පරීක්ෂා කරන්න, පරීක්ෂා කරන්න, අපනයනය කරන්න, උපස්ථ කරන්න, බෙදා ගන්න, නිරූපකය සාදන්න, පරිවර්තනය කරන්න, Terminal හි ගොඩනගන්න, තිරය කියවන්න, සියලු තිර විවෘත කරන්න (ආරක්ෂාව, AI නොබැඳි, Widget, සමාජ මාධ්‍ය, ක්‍රීඩාව, ඉගෙනීම, Cloud, Backend, තේමාව, සජීවීකරණය, පටිගත කරන්නා ඇතුළුව), ආපසු, වසන්න සහ උපකාර. ප්‍රකාරය සක්‍රියව පවතී නම් ඔබ මෙම තිරය නැවත විවෘත කරන විට සවන් දීම ස්වයංක්‍රීයව දිගටම පවතී. ප්‍රකාරය ක්‍රියාවිරහිත කිරීමට සවන් දීම නවත්වන්න ඔබන්න. දුරකථනයේ හඬ හඳුනාගැනීමේ සේවාවක් නොමැති නම් විධාන පෙළ ක්ෂේත්‍රයේ ටයිප් කළ හැකිය.

කේත පරිවර්තකය
අන්තර්ජාලය නොමැතිව භාෂා අතර කේතය පරිවර්තනය කිරීමට - ප්‍රධාන මෙනුවේ කේත පරිවර්තකය විවෘත කරන්න, ව්‍යාපෘතිය තෝරන්න, මූලාශ්‍ර ගොනුව (.java/.kt) තෝරා දිශාව තෝරන්න - Java සිට Kotlin දක්වා. පරිවර්තනය කරන්න ඔබන්න - ප්‍රතිඵලය පරිවර්තනය කළ නොහැකි පේළිවල වාර්තාවක් සමඟ පෙන්වනු ලැබේ (මෙම පේළි එලෙසම තබා සලකුණු කරනු ලැබේ). එම ෆෝල්ඩරයේම නව ගොනුවක් (නම-පරිවර්තනය.java/.kt) ලිවීමට ප්‍රතිඵලය සුරකින්න ඔබන්න. මුල් ගොනුව කිසි විටෙකත් ප්‍රතිස්ථාපනය නොවේ. මෙය රටා නීති පරිවර්තකයකි, සම්පාදකයක් නොවේ - එය භාවිතා කිරීමට පෙර ප්‍රතිඵලය සැමවිටම පරීක්ෂා කරන්න.

යෙදුම තුළ Git
Termux නොමැතිව IDE තුළ Git භාවිතා කිරීමට - ප්‍රධාන මෙනුවේ යෙදුම තුළ Git විවෘත කරන්න, ව්‍යාපෘතිය තෝරා Git Repo සාදන්න ඔබා එම ව්‍යාපෘතියේ දේශීය repo එකක් (.git) සාදන්න. නව, වෙනස් කළ හෝ මකා දැමූ ගොනු අවසාන Commit එක සමඟ සංසන්දනය කර බැලීමට තත්ත්වය පරීක්ෂා කරන්න ඔබන්න. Commit පණිවිඩය පුරවා ව්‍යාපෘතියේ ස්නැප්ෂොට් එකක් සුරැකීමට Commit ඔබන්න. Commit ඉතිහාසය බැලීමට Commit ලොගය බලන්න ඔබන්න. GitHub වෙත Push කිරීම සහ GitHub වෙතින් Pull කිරීම GitHub ටෝකනය (pembuat-aplikasi-build repo) හරහා ස්නැප්ෂොට් භාවිතා කරයි - git ප්‍රොටොකෝලය නොවේ. Clone, Push (පද්ධති git) සහ Pull (පද්ධති git) ක්‍රියා කරන්නේ දුරකථනයේ git ද්විමය ස්ථාපනය කර ඇත්නම් පමණි (සාමාන්‍යයෙන් නැත). මෙය සම්පූර්ණ Git නොවේ - merge, branch, හෝ diff නැත - සෑම Commit එකක්ම ව්‍යාපෘතියේ සම්පූර්ණ ZIP ස්නැප්ෂොට් එකක් සුරකියි.

දැන්වීම් නිර්මාණකරු
ගොඩනඟන ලද යෙදුමට දැන්වීම් එක් කිරීමට - ප්‍රධාන මෙනුවේ දැන්වීම් නිර්මාණකරු විවෘත කරන්න, ව්‍යාපෘතිය, සැපයුම්කරු (AdMob, Unity Ads හෝ AppLovin) සහ දැන්වීම් වර්ගය (Banner, Interstitial හෝ ත්‍යාග ලැබෙන) තෝරන්න. ඔබට තිබේ නම් දැන්වීම් ඒකක ID පුරවන්න - හිස් නම් පරීක්ෂණ ID භාවිතා වේ (AdMob Google හි නිල පරීක්ෂණ ID භාවිතා කරයි. Unity නියැදි Game ID භාවිතා කරයි. AppLovin හිස් ඉඩක් භාවිතා කරයි). Java සහ Kotlin කේතය සහ උපදෙස් බැලීමට දැන්වීම් කේතය සාදන්න ඔබන්න. සියල්ල ව්‍යාපෘතියේ iklan-<සැපයුම්කරු>-<වර්ගය>.txt ගොනුවට ලිවීමට ව්‍යාපෘතියට සුරකින්න ඔබන්න. මෙය කේත අච්චුව + උපදෙස් වන අතර දැන්වීම් SDK එකක් නොවේ - SDK IDE තුළ ඇතුළත් නොවේ. සැබෑ දැන්වීම් දිස්වන්නේ ඔබ සැපයුම්කරු ගිණුමක් සාදන විට, දැන්වීම් ඒකකයක් සාදන විට, ඔබේ ඒකක ID අලවන විට සහ SDK පරායත්තතාව ව්‍යාපෘතියේ build.gradle වෙත එක් කරන විට පමණි.

ව්‍යාපෘතියේ පෙනුම එකවර තිර ප්‍රමාණ කිහිපයකින් පරීක්ෂා කිරීමට (Android Studio හි මෙන්) - ප්‍රධාන මෙනුවේ තිර ප්‍රමාණ පෙරදසුන විවෘත කරන්න, ව්‍යාපෘතිය තෝරා තිර ප්‍රමාණය පරීක්ෂා කරන්න ඔබන්න. IDE ව්‍යාපෘතියේ සියලු පිරිසැලසුම් කියවා ස්ථාවර පළලක් ඇති (උදාහරණයක් ලෙස 400dp) සහ තිර පළල 320, 360, 411 හෝ 480 dp ඉක්මවන මූලද්‍රව්‍ය වාර්තා කරයි, මන්ද කුඩා තිරයක් සහිත දුරකථනයක එවැනි මූලද්‍රව්‍යයක් සැඟවිය හැකි හෝ පිටාර ගැලිය හැකි බැවිනි. match_parent හෝ wrap_content පළල සහිත මූලද්‍රව්‍ය තිරයට ස්වයංක්‍රීයව අනුගත වන අතර පරීක්ෂා කිරීමට අවශ්‍ය නොවේ.

සම්පත් කළමනාකරු
ව්‍යාපෘතියේ සියලු සම්පත් එක් තැනක බැලීමට සහ කළමනාකරණය කිරීමට (Android Studio හි සම්පත් කළමනාකරු මෙන්) - ප්‍රධාන මෙනුවේ සම්පත් කළමනාකරු විවෘත කරන්න, ව්‍යාපෘතිය තෝරා සම්පත් බලන්න ඔබන්න. IDE වර්ගය අනුව ගොනු ගණන සහ ප්‍රමාණය (drawable, layout, values, mipmap සහ වෙනත්), strings.xml, colors.xml සහ styles.xml අන්තර්ගතය වාර්තා කරයි. එම තිරයෙන්ම නම සහ අගය පුරවා strings.xml වෙත නව තන්තුවක් සහ colors.xml වෙත නව වර්ණයක් එක් කළ හැකිය - නම් පරීක්ෂා කරනු ලබන අතර අනුපිටපත් ප්‍රතික්ෂේප කරනු ලැබේ, එබැවින් XML ගොනුව හානි නොවේ.

සැහැල්ලු කාර්යසාධන නිරීක්ෂකය
ධාවනය වන යෙදුමක RAM සහ ප්‍රොසෙසර භාවිතය නිරීක්ෂණය කිරීමට (Android Studio හි Profiler මෙන්, සැහැල්ලු අනුවාදය) - ප්‍රධාන මෙනුවේ සැහැල්ලු කාර්යසාධන නිරීක්ෂකය විවෘත කරන්න, පළමුව ඔබට පරීක්ෂා කිරීමට අවශ්‍ය යෙදුම ධාවනය කරන්න (උදාහරණයක් ලෙස පරීක්ෂා කරනු ලබන ගොඩනඟන ලද යෙදුම), එහි පැකේජ නම පුරවන්න - නැතහොත් ව්‍යාපෘතියක් තෝරා ව්‍යාපෘතියෙන් පැකේජ නම පුරවන්න ඔබන්න - ඉන්පසු නිරීක්ෂණය ආරම්භ කරන්න ඔබන්න. සෑම තත්පර දෙකකට වරක් IDE එම යෙදුමේ RAM (PSS) සහ CPU දුරකථනයේ නිදහස් RAM සමඟ සටහන් කරයි. සාමාන්‍ය සහ උපරිම සාරාංශය බැලීමට නවත්වන්න ඔබන්න. අමතර අවසර නැත. නව Android අනුවාදවල වෙනත් යෙදුමක ප්‍රොසෙසරය කියවීමට ප්‍රවේශය පද්ධතිය විසින් සීමා කර ඇත, එබැවින් CPU කියවිය නොහැකි නම් වාර්තාව එසේ කියන අතර RAM නිරීක්ෂණය දිගටම පවතී.

ප්‍රවේශ්‍යතා විගණනය
ව්‍යාපෘතියක් නිකුත් කිරීමට පෙර එහි පිරිසැලසුම තිර කියවනයට හිතකරද (TalkBack/Jieshuo) යන්න පරීක්ෂා කිරීමට: ප්‍රධාන මෙනුවේ ප්‍රවේශ්‍යතා විගණනය විවෘත කර ව්‍යාපෘතියක් තෝරා ඉන්පසු පිරිසැලසුම් ලැයිස්තුව පූරණය කරන්න ඔබා පිරිසැලසුම් ගොනුවක් තෝරන්න. IDE එම XML ගොනුව කියවා ලේබලයක් නැති බොත්තම් ඒවායේ පේළි අංක සමඟත් නැවත නැවත භාවිතා වන ලේබලත් එකිනෙක අතිච්ඡාදනය වන අංගත් වාර්තා කරයි ඉන්පසු Jieshuo එය හඬ නඟා කියවන ආකාරයට අවධානයේ අනුපිළිවෙලේ පිටපතක් ගොඩනඟයි. බොත්තමකට ලේබලයක් නැත්නම් එහි ලේබලය පුරවා ඉන්පසු ස්වයංක්‍රීයව ලේබල ඇතුළු කරන්න ඔබන්න — ලේබලය පිරිසැලසුම් ගොනුවේ contentDescription ලෙස ලියා ඇත. මෙම පරීක්ෂාව පිරිසැලසුම් XML පමණක් කියවයි; Compose දර්ශන සහ නිමවූ APK තවම ස්කෑන් කර නැත.

ක්‍රෑෂ් පශ්චාත් මරණ පරීක්ෂණය
අද්විතීය හැඳුනුම්පතක් සහිත බිඳවැටීම් ලොගයකින් යෙදුම තනිවම වැසෙන්නේ ඇයි දැයි දැන ගැනීමට: ප්‍රධාන මෙනුවේ «බිඳවැටීම් මරණ පරීක්ෂණය» විවෘත කරන්න, ලොග් ලැයිස්තුවෙන් බිඳවැටීමේ හැඳුනුම්පත තෝරන්න, ඉන්පසු «පරීක්ෂා කරන්න» ඔබන්න. IDE ලොගයේ පන්තිය සහ රේඛා අංකය ව්‍යාපෘති මූලාශ්‍රය සමඟ ගලපා හේතුව ඉන්දුනීසියානු භාෂාවෙන් පැහැදිලි කරයි (උදාහරණයක් ලෙස හිස් යොමුව, තවමත් ඉල්ලා නැති අවසරයක් හෝ JSON දෝෂයක්), කේත පැච් යෝජනාවක් සමඟ. මූලාශ්‍ර රේඛාව බිඳවැටීම සිදු වූ විට තිබූ ආකාරයටම තවමත් පවතී නම් පමණක් «පැච් එක යොදන්න» ඔබන්න; එය වෙනස් වී ඇත්නම්, පැච් එක ප්‍රතික්ෂේප කරනු ලබන අතර IDE ඔබෙන් තනිවම පරීක්ෂා කරන ලෙස ඉල්ලා සිටී. ගොඩනඟන ලද යෙදුමේ බිඳවැටීම් සඳහා «බිඳවැටීම් අල්ලාගන්නා ව්‍යාපෘතියට ඇතුළු කරන්න» ඔබන්න, ඉන්පසු APK සාමාන්‍ය පරිදි ගොඩනඟන්න: ගොඩනඟන ලද යෙදුම එහිම බිඳවැටීම් අල්ලාගෙන එහි ලොගය දුරකථනයේ ලියයි, එම ලොගය «ගොඩනඟන ලද යෙදුම් බිඳවැටීම් ලොගය සොයන්න» බොත්තම සමඟ සොයාගත හැකිය. අවංක සීමාව: ලොගය Android 11 සහ ඉහළ පොදු Download ෆෝල්ඩරයට පිටපත් කිරීම සියලුම ගොනු ප්‍රවේශ අවසරයකින් තොරව අසාර්ථක විය හැකිය.

පරස්පර-පැරඩයිම් ට්‍රාන්ස්පයිලරය
සරල Java කේතය Kotlin බවට හෝ සරල XML පිරිසැලසුම Compose කේතය බවට පරිවර්තනය කිරීමට: ප්‍රධාන මෙනුවේ පරස්පර-පැරඩයිම් ට්‍රාන්ස්පයිලරය විවෘත කර ව්‍යාපෘතියක් සහ ගොනුවක් තෝරා ඉන්පසු පෙරදසුන ඔබන්න. IDE පරිවර්තන ප්‍රතිඵලය පෙළක් ලෙස පෙන්වයි — මුලින්ම එය පරීක්ෂා කරන්න, මන්ද එය හඳුනා නොගන්නා පේළි ඒ ආකාරයෙන්ම තබා ඇති අතර Java හි static වචනය Kotlin හි ඉවත් කර ඇති බැවිනි (භාවිතා කිරීමට පෙර එහි තේරුම පරීක්ෂා කරන්න). XML සිට Compose දක්වා පරිවර්තනය පෙළ ඉඟි සහ දිශානතිය පමණක් වෙනස් කරයි — ප්‍රමාණය වර්ණය සහ අනෙකුත් ගුණාංග තවම ඇතුළත් කර නැත. ප්‍රතිඵලය නිවැරදි නම් ඉලක්ක ගොනුව ලිවීමට ගොනුවට යොදන්න ඔබන්න; මූලාශ්‍ර ගොනුව වෙනස් නොවේ. ආරක්ෂිත සාමාන්‍ය රටා පමණක් පරිවර්තනය වේ.

දේශීය ක්ෂුද්‍ර සේවාදායකය
අන්තර්ජාලය නොමැතිව සේවාදායකයක් අවශ්‍ය යෙදුමක් පරීක්ෂා කිරීමට: ප්‍රධාන මෙනුවේ «දේශීය ක්ෂුද්‍ර සේවාදායකය» විවෘත කරන්න, මාර්ග අර්ථ දැක්වීම් ලියන්න (උදාහරණයක් ලෙස GET /halo ඉන්පසු එහි JSON පිළිතුර) ඉන්පසු «සේවාදායකය අරඹන්න» ඔබන්න. IDE එකම දුරකථනයේ කුඩා HTTP සේවාදායකයක් ක්‍රියාත්මක කරයි (HTTP පමණි, TLS නැත, එකම Wi-Fi ජාලය සඳහා) සහ එක් එක් ඉල්ලීම සහ පිළිතුර තිරයේ සටහන් කරයි. මාර්ගවලට {nama} වැනි පරාමිති සහ සරල API යතුරක් භාවිතා කළ හැකිය. සේවාදායකය ගොඩනඟන ලද APK හිද ඇසුරුම් කළ හැකිය: «සේවාදායකය ව්‍යාපෘතියට බණ්ඩල කරන්න» ඔබන්න, සේවාදායක මූලාශ්‍රය, වත්කම් සහ manifest ව්‍යාපෘතියට ඇතුළු කරනු ලැබේ, එමගින් ගොඩනඟන ලද යෙදුම ක්‍රියාත්මක වන විට එයම සේවාදායකයක් බවට පත්වේ. ආරක්ෂක විගණක
ප්‍රකාශනයට පෙර ව්‍යාපෘති කේතයේ ආරක්ෂක හිඩැස් පරීක්ෂා කිරීමට: ප්‍රධාන මෙනුවේ «ආරක්ෂක විගණක» විවෘත කරන්න, ව්‍යාපෘතිය තෝරන්න, ඉන්පසු «පරිලෝකනය ආරම්භ කරන්න» ඔබන්න. IDE ව්‍යාපෘති කේතය, manifest සහ වින්‍යාසය පරිලෝකනය කර ඉහළ සිට පහළ අවදානම දක්වා සොයාගැනීම් වාර්තා කරයි — කේතයේ විවෘතව තැබූ API යතුර, අවසරයකින් තොරව නිරාවරණය වූ සංරචකය, එහි JavaScript අතුරුමුහුණත සමඟ JavaScript සක්‍රීය කරන WebView, දුර්වල crypto (MD5, SHA1, DES), TLS නොමැති http ලිපිනය සහ කේතයේ සෘජුවම ලියන ලද මුරපදය — ඒවායේ ගොනු සහ රේඛා අංක සමඟ. නිවැරදි කිරීම ආරක්ෂිත වන සොයාගැනීම් සඳහා (උදාහරණයක් ලෙස MD5 SHA-256 ට හෝ http https ට වෙනස් කරන්න) «නිවැරදි කිරීම යොදන්න» ඔබන්න; API යතුරු සහ මුරපද සඳහා IDE නිවැරදි කිරීමේ යෝජනාව පමණක් පෙන්වයි, මන්ද ආදේශනය සංවර්ධකයා විසින්ම තීරණය කළ යුතු බැවිනි. පරිලෝකනය දැන් ගොඩනඟන ලද APK තුළ සැබෑ DEX bytecode ද විශ්ලේෂණය කරයි (කේතයේ පාඨ රටා පමණක් නොවේ), එබැවින් අමතන ලද අනතුරුදායක API සහ DEX හි කාවැදී ඇති රහස් ද අල්ලා ගනු ලැබේ; රටාව අනුගමනය නොකරන හිඩැස් තවමත් පරිලෝකනයෙන් ගැලවිය හැකිය — යෙදීමට පෙර පරීක්ෂා කරන්න.

අතුරුමුහුණත් පරීක්ෂණ රොබෝව
පාඨ අවස්ථා හරහා යෙදුම් තිරය ස්වයංක්‍රීයව පරීක්ෂා කිරීමට: ප්‍රධාන මෙනුවේ «අතුරුමුහුණත් පරීක්ෂණ රොබෝ» විවෘත කරන්න, ව්‍යාපෘතිය තෝරන්න, ඉන්පසු «අවස්ථාව ස්වයංක්‍රීයව සාදන්න» ඔබන්න. IDE ව්‍යාපෘති manifest සහ පිරිසැලසුම කියවා අවස්ථාව පාඨ පියවර ලෙස ලියයි (බොත්තම ඔබන්න, ක්ෂේත්‍රය පුරවන්න, රැඳී සිටින්න, ආපසු යන්න). අවස්ථා ක්‍රියාත්මක කිරීමේ ලොගය එහි කාල මුද්‍රා සමඟ බැලීමට «වියළි ධාවනය ක්‍රියාත්මක කරන්න» ඔබන්න — මෙම වියළි ධාවනය තවමත් අනුපිළිවෙලෙහි සිමියුලේෂණයක් පමණි. සැබෑ පරීක්ෂණයක් සඳහා «පරීක්ෂණ නියෝජිතයා ව්‍යාපෘතියට ඇතුළු කරන්න» ඔබන්න: IDE අවස්ථා වත්කම් සමඟ පරීක්ෂණ නියෝජිතයා ව්‍යාපෘතියට ඇතුළු කරයි; APK සාමාන්‍ය පරිදි ගොඩනඟන්න, එය ස්ථාපනය කරන්න, ඉන්පසු «පරීක්ෂණය» අයිකනය විවෘත කරන්න — නියෝජිතයා ගොඩනඟන ලද යෙදුම තුළ ක්‍රියාත්මක වන අතර ඇත්ත වශයෙන්ම බොත්තම් ඔබයි, සැබෑ ක්ෂේත්‍ර පුරවයි සහ අනුචලනය කරයි, ඉන්පසු තිරයේ අල්ලා ගත් සැබෑ බිඳවැටීම් සමඟ එහි වාර්තාව පෙන්වයි. නියෝජිතයා නැවත ඉවත් කිරීමට «පරීක්ෂණ නියෝජිතයා ව්‍යාපෘතියෙන් ඉවත් කරන්න» ඔබන්න. නියෝජිතයා යෙදුමේම ක්‍රියාවලිය තුළ ක්‍රියාත්මක වේ, එබැවින් එයට ප්‍රවේශ්‍යතා සේවාවක් හෝ පද්ධති ස්වයංක්‍රීයකරණයක් අවශ්‍ය නොවේ.

කේත කාල තරණය
Git විධාන ටයිප් නොකර ව්‍යාපෘතියක් පෙර කේත තත්ත්වයකට යළි ගෙන ඒමට: ප්‍රධාන මෙනුවේ කේත කාල තරණය විවෘත කර ව්‍යාපෘතියක් තෝරා කාල ලක්ෂ්‍යය සඳහා ලේබලයක් පුරවන්න (හිස්ව තැබිය හැකිය) ඉන්පසු දැන් ලක්ෂ්‍යය සටහන් කරන්න ඔබන්න. IDE ව්‍යාපෘතියේ මූලාශ්‍ර ගොනුවල පිටපතක් ඒවායේ hash අගයන් සමඟ ව්‍යාපෘතිය තුළ ඇති .riwayat ෆෝල්ඩරයේ සුරකියි. කාල ලක්ෂ්‍ය ලැයිස්තුව ඒ සියල්ල පෙන්වයි; ලක්ෂ්‍ය දෙකක් තෝරා ඉන්පසු එකතු කරන ලද වෙනස් කරන ලද හෝ මකා දැමූ ගොනු සහ ශ්‍රිත බැලීමට සංසන්දනය කරන්න ඔබන්න. පැරණි තත්ත්වයක් ආපසු ගෙන ඒමට ප්‍රතිස්ථාපනය කරන්න ඔබන්න — ප්‍රතිස්ථාපනය කිරීමට පෙර IDE සැමවිටම මුලින්ම වත්මන් තත්ත්වයේ උපස්ථයක් සාදයි එබැවින් කිසිවක් නැති නොවේ. ව්‍යාපෘතිය නව ෆෝල්ඩරයකට පිටපත් කර මුල් ව්‍යාපෘතියට බාධා නොකර වෙනස්කම් අත්හදා බැලීමට අත්හදා බැලීමේ පිටපත සාදන්න ඔබන්න. මූලාශ්‍ර ගොනු පමණක් සටහන් වේ.

සංස්කාරකය තුළ හඬින් කේතය ලිවීමට: ව්‍යාපෘතියක් සංස්කාරකයේ විවෘත කර ඉන්පසු කේත ව්‍යුහය කථනය බොත්තම ඔබන්න. ඉන්දුනීසියානු භාෂාවෙන් විධාන කියන්න උදාහරණයක් ලෙස buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil හෝ buat variabel teks nama sama dengan Budi — IDE කථනය වාක්‍ය රීති අනුව වලංගු Java, Kotlin, Python හෝ Compose කේත කොටසක් බවට පරිවර්තනය කර එය කර්සරයේ ස්ථානයේ තබන අතර ඉන්පසු Jieshuo හරහා කෙටි සාරාංශයක් හඬ නඟා කියවයි. කථනය පද්ධතියේ ගොඩනගා ඇති හඬ ආදාන සේවාව භාවිතා කරයි අමතර මයික්‍රෆෝන අවසරයකින් තොරව සහ දැනටමත් ලියාපදිංචි කර ඇති විධාන රටා පමණක් හඳුනා ගනී; එම රටාවලින් පිටත කථනය කේතය බවට පරිවර්තනය නොවේ. වචන ලෙස කියන සංඛ්‍යා (උදාහරණයක් ලෙස 'lima') තවම ඉලක්කම් බවට පරිවර්තනය නොවේ.

දේශීය සහයෝගීතා කාමරය (අන්තර්ජාලය නැතිව)
අන්තර්ජාලය නොමැතිව එක් කාමරයක එකට වැඩ කිරීමට: ප්‍රධාන මෙනුවේ සහයෝගීතාව විවෘත කර ඉන්පසු දේශීය සහයෝගීතා කාමරය කොටස විවෘත කරන්න. එක් දුරකථනයක් සැසියක් විවෘත කරයි (IDE දේශීය IP ලිපිනයක් සහ ඉලක්කම් 6 ක PIN එකක් පෙන්වයි) තවත් දුරකථනයක් එම ලිපිනය සහ PIN සමඟ සම්බන්ධ වේ. පෙළ වෙනස්කම් පේළි වෙනස්කම් ලෙස යවනු ලැබේ ගොඩනඟන ලද APK එකක් පරීක්ෂකගේ දුරකථනයට යැවිය හැකි අතර පරීක්ෂකගේ දුරකථනයෙන් Crash වාර්තා ආපසු ලැබේ. එක් සැසියක් එක් මිතුරෙකු සඳහා පමණි; පුද්ගලයන් දෙදෙනෙකු එකම පේළිය හරියටම එකම වේලාවක වෙනස් කළහොත් අවසාන වෙනස භාවිතා වේ. PIN දේශීය ජාලයේ සරල පෙළක් ලෙස යවනු ලැබේ. මෙම කාමරය තවම සැබෑ දුරකථනයක පරීක්ෂා කර නැත.

AI සැකසුම්
යෙදුම් ගොඩනැඟීම සඳහා AI සපයන්නා සහ API යතුරු සැකසීමට: ප්‍රධාන මෙනුවේ, සැකසුම් කණ්ඩායමේ «AI සැකසුම්» ඔබන්න («සම්බන්ධකය» බොත්තම අසල). ඇති ලැයිස්තුවෙන් භාවිතා කිරීමට සපයන්නා තෝරන්න සහ ආකෘතියක් අසාර්ථක වුවහොත් IDE එම සපයන්නාගෙන් ඊළඟ ආකෘතිය ස්වයංක්‍රීයව උත්සාහ කරන පරිදි «සපයන්නා දෝෂයක් ඇති විට ආකෘතිය වෙනස් කරන්න» සලකුණු කරන්න. උපස්ථ යතුරු එක් කිරීමට «API යතුරු කළමනාකරණය කරන්න» ඔබන්න (නම සහ යතුර ටයිප් කරන්න, ඉන්පසු «සුරකින්න» ඔබන්න; යතුරු ආවරණය කර පෙන්වනු ලබන අතර අවසාන අක්ෂර 4 පමණක් දෘශ්‍යමාන වේ). යතුරු දුරකථනයේ සුරකින අතර යෙදුම ගොඩනඟන විට තෝරාගත් සපයන්නා හැර වෙනත් තැනකට කිසි විටෙකත් යවනු නොලැබේ. තෝරාගත් සපයන්නා දැන් ඇත්ත වශයෙන්ම «ව්‍යාපෘති සැලැස්ම ගෘහ නිර්මාණ ශිල්පියා» සහ «කේත තර්ක ප්‍රවාහ කථකයා» විසින් භාවිතා කරනු ලැබේ; «AI යෙදුම් සාදන්නා» තිරයේ යෙදුම් ගොඩනැඟීම තවමත් දුරකථනයේ දේශීය AI භාවිතා කරයි (අන්තර්ජාලය නොමැතිව).

සම්බන්ධකය
