ලබා ගත හැකි ව්‍යාපෘති වර්ග
• HTML: WebView හරහා ක්‍රියාත්මක වන index.html, style.css, සහ script.js වලින් සැදුම් ලත් දර්ශනය. දුරකථනය මත කෙලින්ම ගොඩනගනු ලැබේ.
• Situs Web: WebView හරහා ක්‍රියාත්මක වන index.html, tentang.html, kontak.html, style.css, සහ script.js වලින් සැදුම් ලත්, මෙනුවක් (Beranda, Tentang, Kontak) ඇති වෙබ් අඩවිය. දුරකථනය මත කෙලින්ම ගොඩනගනු ලැබේ.
• Java: දුරකථනය මත ගොඩනගනු ලැබේ. MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.java තුළය. දර්ශනය app/src/main/res/layout/activity_main.xml වෙතින්, පෙළ app/src/main/res/values/strings.xml වෙතින්, සහ තේමාව app/src/main/res/values/styles.xml වෙතින් ලැබේ.
• Kotlin: යෙදුමට ඇතුළත් කර ඇති Kotlin සම්පාදකය භාවිතා කර උපාංගය මතම (offline) හෝ GitHub Actions හරහා ගොඩනැගිය හැකිය. MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.kt තුළ වන අතර res ගොනු Java ව්‍යාපෘතියේ ඒවාට සමාන වේ. සම්පාදකයේ විශාල ප්‍රමාණය නිසා පළමු Kotlin ගොඩනැගීම මන්දගාමී වන අතර, Kotlin පන්ති වෙත යොමු වන .java ගොනු තවම ගොඩනැගිය නොහැක (.java ගොනු .kt ගොනුවලට පෙර සම්පාදනය කෙරේ).
• Compose: එහි අතුරුමුහුණත Jetpack Compose භාවිතයෙන් සාදා ඇති නවීන Android යෙදුමකි (XML layout එකක් නොවේ). MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.kt තුළය. Compose ව්‍යාපෘති GitHub Actions හරහා (Bangun proyek මෙනුව, ඉන්පසු Bangun online) හෝ Gradle සමඟ Termux තුළ ගොඩනගනු ලැබේ, මන්ද Compose සඳහා උපාංගය මත ලබා ගත නොහැකි Jetpack Compose පුස්තකාල අවශ්‍ය වන බැවිනි.
• Python: යෙදුම් තර්කය Python භාෂාවෙන් (Chaquopy) app/src/main/python/main.py තුළ ලියා ඇති අතර app/src/main/java/<nama-paket>/MainActivity.java තුළ ඇති MainActivity host එක මගින් ධාවනය කෙරේ. Python ව්‍යාපෘති දුරකථනය මත කෙලින්ම (Chaquopy runtime එක යෙදුමට ඇතුළත් කර ඇත) හෝ GitHub Actions හරහා ගොඩනැගිය හැකිය. Python ව්‍යාපෘතියක අවම SDK එක 24 (Android 7.0) වේ.

Java, HTML, Situs Web, Kotlin, Compose, සහ Python ව්‍යාපෘති සාමාන්‍ය Android ව්‍යාපෘති මෙන් සකස් කර ඇත. app ෆෝල්ඩරය තුළ src ෆෝල්ඩරය ඇති අතර, ඒ තුළ main ෆෝල්ඩරය ඇත. main ෆෝල්ඩරය තුළ java ෆෝල්ඩරය අසල AndroidManifest.xml, layout/activity_main.xml සහ values/strings.xml මෙන්ම values/styles.xml අඩංගු res ෆෝල්ඩරය, සහ HTML සහ Situs Web සඳහා index.html අඩංගු assets ෆෝල්ඩරය (Situs Web හි tentang.html සහ kontak.html ද ඇත) ඇත. HTML සහ Situs Web ව්‍යාපෘතිවලට ද app/src/main/java/<nama-paket>/MainActivity.java තුළ තමන්ගේම MainActivity එකක් ඇති අතර, එය index.html එක WebView තුළට පූරණය කරන අතර AndroidManifest තුළ launcher එක වේ. Python ව්‍යාපෘතියේ Python කේතය app/src/main/python/main.py තුළ ඇති අතර host MainActivity.java ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.java තුළය. AndroidManifest.xml, layout, strings, සහ styles, MainActivity මෙන්ම සංස්කාරකය තුළ විවෘත කර වෙනස් කළ හැකිය. Manifest එක තවමත් app ෆෝල්ඩරය අසල ඇති පැරණි ව්‍යාපෘති ද ගොඩනැගිය හැකිය, මන්ද ගොඩනගන විට යෙදුම පළමුව app/src/main/ තුළ ඇති AndroidManifest.xml එක, ඉන්පසු app ෆෝල්ඩරය අසල ඇති එක, සහ අවසානයේ ව්‍යාපෘති දත්ත ගොනුව පරීක්ෂා කරන බැවිනි.
