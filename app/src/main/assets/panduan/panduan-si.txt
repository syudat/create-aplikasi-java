ලබා ගත හැකි ව්‍යාපෘති වර්ග
• HTML: WebView හරහා ක්‍රියාත්මක වන index.html, style.css, සහ script.js වලින් සැදුම් ලත් දර්ශනය. දුරකථනය මත කෙලින්ම ගොඩනගනු ලැබේ.
• Situs Web: WebView හරහා ක්‍රියාත්මක වන index.html, tentang.html, kontak.html, style.css, සහ script.js වලින් සැදුම් ලත්, මෙනුවක් (Beranda, Tentang, Kontak) ඇති වෙබ් අඩවිය. දුරකථනය මත කෙලින්ම ගොඩනගනු ලැබේ.
• Java: දුරකථනය මත ගොඩනගනු ලැබේ. MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.java තුළය. දර්ශනය app/src/main/res/layout/activity_main.xml වෙතින්, පෙළ app/src/main/res/values/strings.xml වෙතින්, සහ තේමාව app/src/main/res/values/styles.xml වෙතින් ලැබේ.
• Kotlin: යෙදුමට ඇතුළත් කර ඇති Kotlin සම්පාදකය භාවිතා කර උපාංගය මතම (offline) හෝ GitHub Actions හරහා ගොඩනැගිය හැකිය. MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.kt තුළ වන අතර res ගොනු Java ව්‍යාපෘතියේ ඒවාට සමාන වේ. සම්පාදකයේ විශාල ප්‍රමාණය නිසා පළමු Kotlin ගොඩනැගීම මන්දගාමී වන අතර, Kotlin පන්ති වෙත යොමු වන .java ගොනු තවම ගොඩනැගිය නොහැක (.java ගොනු .kt ගොනුවලට පෙර සම්පාදනය කෙරේ).
• Compose: එහි අතුරුමුහුණත Jetpack Compose භාවිතයෙන් සාදා ඇති නවීන Android යෙදුමකි (XML layout එකක් නොවේ). MainActivity ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.kt තුළය. Compose ව්‍යාපෘති GitHub Actions හරහා (Bangun proyek මෙනුව, ඉන්පසු Bangun online) හෝ Gradle සමඟ Termux තුළ ගොඩනගනු ලැබේ, මන්ද Compose සඳහා උපාංගය මත ලබා ගත නොහැකි Jetpack Compose පුස්තකාල අවශ්‍ය වන බැවිනි.
• Python: යෙදුම් තර්කය Python භාෂාවෙන් (Chaquopy) app/src/main/python/main.py තුළ ලියා ඇති අතර app/src/main/java/<nama-paket>/MainActivity.java තුළ ඇති MainActivity host එක මගින් ධාවනය කෙරේ. Python ව්‍යාපෘති දුරකථනය මත කෙලින්ම (Chaquopy runtime එක යෙදුමට ඇතුළත් කර ඇත) හෝ GitHub Actions හරහා ගොඩනැගිය හැකිය. Python ව්‍යාපෘතියක අවම SDK එක 24 (Android 7.0) වේ.

Java, HTML, Situs Web, Kotlin, Compose, සහ Python ව්‍යාපෘති සාමාන්‍ය Android ව්‍යාපෘති මෙන් සකස් කර ඇත. app ෆෝල්ඩරය තුළ src ෆෝල්ඩරය ඇති අතර, ඒ තුළ main ෆෝල්ඩරය ඇත. main ෆෝල්ඩරය තුළ java ෆෝල්ඩරය අසල AndroidManifest.xml, layout/activity_main.xml සහ values/strings.xml මෙන්ම values/styles.xml අඩංගු res ෆෝල්ඩරය, සහ HTML සහ Situs Web සඳහා index.html අඩංගු assets ෆෝල්ඩරය (Situs Web හි tentang.html සහ kontak.html ද ඇත) ඇත. HTML සහ Situs Web ව්‍යාපෘතිවලට ද app/src/main/java/<nama-paket>/MainActivity.java තුළ තමන්ගේම MainActivity එකක් ඇති අතර, එය index.html එක WebView තුළට පූරණය කරන අතර AndroidManifest තුළ launcher එක වේ. Python ව්‍යාපෘතියේ Python කේතය app/src/main/python/main.py තුළ ඇති අතර host MainActivity.java ඇත්තේ app/src/main/java/<nama-paket>/MainActivity.java තුළය. AndroidManifest.xml, layout, strings, සහ styles, MainActivity මෙන්ම සංස්කාරකය තුළ විවෘත කර වෙනස් කළ හැකිය. Manifest එක තවමත් app ෆෝල්ඩරය අසල ඇති පැරණි ව්‍යාපෘති ද ගොඩනැගිය හැකිය, මන්ද ගොඩනගන විට යෙදුම පළමුව app/src/main/ තුළ ඇති AndroidManifest.xml එක, ඉන්පසු app ෆෝල්ඩරය අසල ඇති එක, සහ අවසානයේ ව්‍යාපෘති දත්ත ගොනුව පරීක්ෂා කරන බැවිනි.

අවසර නීති (වැදගත්)

Java, HTML, Situs Web, Kotlin, Compose, සහ Python ව්‍යාපෘති සඳහා වන ව්‍යාපෘති දත්ත ගොනුවේ අවසර ලැයිස්තුවක් අඩංගු නොවේ. ඔබ Java තෝරා INTERNET සහ CAMERA සලකුණු කළහොත්, AndroidManifest.xml තුළ සටහන් වන්නේ වෙනත් අවසර කිසිවක් එකතු නොවී INTERNET සහ CAMERA පමණි. ගොඩනගන විට, යෙදුම අවසර කියවන්නේ එම ස්ථානයෙන්මය: Java, HTML, Situs Web, Kotlin, Compose, සහ Python ව්‍යාපෘති සඳහා app/src/main/ තුළ ඇති AndroidManifest.xml වෙතින් (නැත්නම්, පැරණි ව්‍යාපෘති සඳහා app ෆෝල්ඩරය අසල ඇති AndroidManifest.xml වෙතින්), සහ පැරණි ව්‍යාපෘති සඳහා ව්‍යාපෘති දත්ත ගොනුව වෙතින්.

XML සිට Compose දක්වා පරිවර්තනය පෙළ ඉඟි සහ දිශානතිය පමණක් වෙනස් කරයි — ප්‍රමාණය වර්ණය සහ අනෙකුත් ගුණාංග තවම ඇතුළත් කර නැත. ප්‍රතිඵලය නිවැරදි නම් ඉලක්ක ගොනුව ලිවීමට ගොනුවට යොදන්න ඔබන්න; මූලාශ්‍ර ගොනුව වෙනස් නොවේ. ආරක්ෂිත සාමාන්‍ය රටා පමණක් පරිවර්තනය වේ.

දේශීය ක්ෂුද්‍ර සේවාදායකය
අන්තර්ජාලය නොමැතිව සේවාදායකයක් අවශ්‍ය යෙදුමක් පරීක්ෂා කිරීමට: ප්‍රධාන මෙනුවේ දේශීය ක්ෂුද්‍ර සේවාදායකය විවෘත කර මාර්ග අර්ථ දැක්වීමක් ලියන්න (උදාහරණයක් ලෙස GET /halo ඉන්පසු එහි JSON පිළිතුර) ඉන්පසු සේවාදායකය අරඹන්න ඔබන්න. IDE එකම දුරකථනයේ කුඩා HTTP සේවාදායකයක් ක්‍රියාත්මක කරයි (HTTP පමණි TLS නැතුව එකම Wi-Fi ජාලය සඳහා) සහ සෑම ඉල්ලීමක් සහ පිළිතුරක්ම තිරයේ සටහන් කරයි. මාර්ගවලට {nama} වැනි පරාමිතීන් සහ සරල API යතුරක් භාවිතා කළ හැකිය. මෙම සේවාදායකය දුරකථනයේ පරීක්ෂා කිරීම සඳහා පමණි; ගොඩනඟන ලද APK එකක් තවම සේවාදායකයක් විය නොහැකි අතර එහි තිරය වැසූ විට සේවාදායකය නතර වේ.

ආරක්ෂක විගණක
ව්‍යාපෘතියක් නිකුත් කිරීමට පෙර ව්‍යාපෘති කේතයේ ඇති ආරක්ෂක සිදුරු පරීක්ෂා කිරීමට: ප්‍රධාන මෙනුවේ ආරක්ෂක විගණක විවෘත කර ව්‍යාපෘතියක් තෝරා ඉන්පසු ස්කෑන් කිරීම අරඹන්න ඔබන්න. IDE කේතය manifest සහ ව්‍යාපෘති වින්‍යාසය ස්කෑන් කර ඉහළම අවදානමේ සිට අඩුම අවදානම දක්වා සොයාගැනීම් වාර්තා කරයි — කේතයේ නිරාවරණය වූ API යතුරු අවසරයකින් තොරව නිරාවරණය වූ සංරචක JavaScript අතුරුමුහුණතක් සමඟ JavaScript සක්‍රීය කරන WebView එකක් දුර්වල ක්‍රිප්ටෝ (MD5, SHA1, DES) TLS නැති http ලිපින සහ කේතයේ සෘජුවම ලියා ඇති මුරපද — එක් එක් සොයාගැනීමේ ගොනුව සහ පේළි අංකය සමඟ. ආරක්ෂිත නිවැරදි කිරීමක් ඇති සොයාගැනීම් සඳහා (උදාහරණයක් ලෙස MD5 SHA-256 මඟින් හෝ http https මඟින් ප්‍රතිස්ථාපනය කිරීම) නිවැරදි කිරීම යොදන්න ඔබන්න; API යතුරු සහ මුරපද සඳහා IDE යෝජිත නිවැරදි කිරීම පමණක් පෙන්වයි මන්ද ආදේශනය සංවර්ධකයා විසින්ම තීරණය කළ යුතු බැවිනි. මෙම ස්කෑන් එක කේතයේ ඇති පෙළ රටා කියවයි bytecode නොවේ එබැවින් සමහර සොයාගැනීම් ඇත්ත වශයෙන්ම ආරක්ෂිත විය හැකි අතර රටාවක් නැති සිදුරක් ස්කෑන් එකෙන් මඟ හැරිය හැක — යෙදීමට පෙර පරීක්ෂා කරන්න.

අතුරුමුහුණත් පරීක්ෂණ රොබෝව
පෙළ අවස්ථා භාවිතයෙන් යෙදුමක පෙනුම ස්වයංක්‍රීයව පරීක්ෂා කිරීමට: ප්‍රධාන මෙනුවේ අතුරුමුහුණත් පරීක්ෂණ රොබෝව විවෘත කර ව්‍යාපෘතියක් තෝරා ඉන්පසු ස්වයංක්‍රීය අවස්ථාව සාදන්න ඔබන්න. IDE ව්‍යාපෘතියේ manifest සහ පිරිසැලසුම් කියවා පෙළ පියවරවලින් අවස්ථාවක් ලියයි (බොත්තමක් ඔබන්න ක්ෂේත්‍රයක් පුරවන්න රැඳී සිටින්න ආපසු යන්න). අවස්ථාවේ ක්‍රියාත්මක වීමේ ලොගය එහි කාල මුද්‍රා සමඟ බැලීමට Dry Run ක්‍රියාත්මක කරන්න ඔබන්න. මෙම අදියරේදී රොබෝවරයා අනුකරණයක් පමණක් ක්‍රියාත්මක කරයි (dry run) — දුරකථනයේ සැබෑ බොත්තම් එබීම සහ සැබෑ Crash අල්ලා ගැනීම ඊළඟ අදියරයි එබැවින් මෙහි Crash වාර්තාව තවමත් නියැදි ආකෘතියකි.

APK එකක් විශ්ලේෂණය කර ඉන්පසු එය යැවීමට: ප්‍රධාන මෙනුවේ සැකසුම් කණ්ඩායමේ සම්බන්ධකය ඔබන්න (AI සැකසුම් බොත්තම අසල). දුරකථනයෙන් APK ගොනුවක් තෝරන්න IDE එහි අන්තර්ගතය කියවයි (පැකේජ නම අනුවාදය ක්‍රියාකාරකම් ලැයිස්තුව) ඉන්පසු පද්ධතියේ බෙදාගැනීමේ මෙනුව හරහා එය යැවීමට APK යවන්න ඔබන්න (උදාහරණයක් ලෙස WhatsApp හෝ Drive).

භාෂාව සහ හඬ
යෙදුමේ භාෂාව වෙනස් කිරීමට: සැකසුම් විවෘත කර ඉන්පසු යෙදුම් භාෂාව විවෘත කර භාෂාවක් තෝරන්න හෝ පද්ධතිය අනුගමනය කරන්න තෝරන්න. ප්‍රධාන තිරය සහ බොහෝ තිර යෙදුම වසා දැමීමෙන් හෝ නැවත ආරම්භ කිරීමෙන් තොරව තෝරාගත් භාෂාවට වහාම මාරු වේ; සමහර තිර (උදාහරණයක් ලෙස Terminal, සහයෝගීතාව, AI සැකසුම් සහ යතුරු කළමනාකරණය) නැවත විවෘත කරන තුරු පැරණි භාෂාව දිගටම භාවිතා කරයි. ඔබ පද්ධතිය අනුගමනය කරන්න තෝරාගතහොත් භාෂාව දුරකථනයේ පද්ධති භාෂාව අනුගමනය කරයි.
