Wilujeng sumping di Create Aplikasi by Al Kautsar
Create Aplikasi nyaéta aplikasi pikeun nyieun aplikasi Android anu jalan langsung dina telepon, tanpa merlukeun laptop. Aplikasi ieu ngidinan saha waé nyieun aplikasi Android sorangan, kaasup pangguna anu kakara diajar nyieun aplikasi jeung pangguna pamaca layar. Pituduh lengkep pikeun ngagunakeun aplikasi ieu sayogi dina layar Tentang Alat ieu.

Aplikasi ieu téh naon jeung pikeun saha
Create Aplikasi nyaéta pakakas pikeun nyieun aplikasi Android anu jalan dina telepon. Aplikasi ieu ditujukeun pikeun saha waé anu hayang nyieun aplikasi Android sorangan, kaasup pamula jeung pangguna pamaca layar. Aplikasi ieu nyayogikeun éditor kode, tombol Jalankan pikeun nguji proyek, tombol Bangun pikeun nyieun APK, sarta menu pikeun nandatanganan jeung masang APK.

Tujuan aplikasi ieu
Aplikasi ieu dijieun sangkan saha waé bisa nyieun aplikasi Android sorangan kalawan gampang, langsung tina telepon. Pidanganna dijieun sasingkat mungkin sangkan pangguna anyar ogé bisa langsung nyobaan.

Cara nyieun proyek anyar, léngkah demi léngkah
1. Pencét Buat Project dina menu utama.
2. Pilih jenis proyek: HTML, Situs Web, Java, Kotlin, Compose, atawa Python.
3. Eusian ngaran aplikasi, conto: Garuda Decode.
4. Eusian ngaran pakét (package name), conto: com.android.garudadecode. Ngaran pakét kudu ngagunakeun aksara leutik jeung diwangun ku sahenteuna dua bagian anu dipisahkeun ku titik.
5. Eusian vérsi aplikasi, conto: 1.0, jeung kode vérsi dina wangun angka, conto: 1. Lamun dikosongkeun, vérsi bakal dieusian otomatis ku 1.0 jeung kode vérsi 1.
6. Eusian SDK minimum jeung SDK target lamun diperlukeun. Lamun dikosongkeun, nilai bawaan bakal digunakeun. SDK minimum nyaéta vérsi Android panghandapna anu didukung, conto: 21 hartina Android 5.0. SDK target maksimum nyaéta 36 (Android 16).
7. Pencét tombol Pilih Izin pikeun milih idin aplikasi, conto: INTERNET. Idin INTERNET geus dicirian sacara bawaan. Cirian ukur idin anu memang diperlukeun ku aplikasi.
8. Lamun dipikahayang, cirian "Gunakan arsitektur terpisah 64 bit dan 32 bit" sangkan ukuran APK leuwih leutik, jeung cirian "Gunakan tanda tangan pribadi" lamun hayang ngagunakeun keystore jieunan sorangan.
9. Pencét Buat Proyek. Proyek anyar disimpen dina folder Download/project jeung langsung katémbong dina Kelola Project.

Jenis proyek anu sayogi
• HTML: pidangan tina index.html, style.css, jeung script.js, jalan ngaliwatan WebView. Dijieun langsung dina telepon.
• Situs Web: website kalawan menu (Beranda, Tentang, Kontak) tina index.html, tentang.html, kontak.html, style.css, jeung script.js, jalan ngaliwatan WebView. Dijieun langsung dina telepon.
• Java: dijieun dina telepon. MainActivity aya di app/src/main/java/<nama-paket>/MainActivity.java. Pidangan tina app/src/main/res/layout/activity_main.xml, téks tina app/src/main/res/values/strings.xml, jeung téma tina app/src/main/res/values/styles.xml.
• Kotlin: bisa dijieun dina alat (offline) ngagunakeun compiler Kotlin anu kaasup dina aplikasi, atawa ngaliwatan GitHub Actions. MainActivity aya di app/src/main/java/<nama-paket>/MainActivity.kt, jeung berkas res sarua jeung proyek Java. Bangun Kotlin munggaran leuwih lila kusabab ukuran compiler anu gedé, jeung berkas .java anu ngarujuk kelas Kotlin tacan bisa dijieun (berkas .java dikompilasi heula saméméh berkas .kt).
• Compose: aplikasi Android modéren anu antarbeungeutna dijieun ku Jetpack Compose (lain layout XML). MainActivity aya di app/src/main/java/<nama-paket>/MainActivity.kt. Proyek Compose dijieun ngaliwatan GitHub Actions (menu Bangun proyek, tuluy Bangun online) atawa di Termux ku Gradle, kusabab Compose merlukeun pustaka Jetpack Compose anu teu sayogi dina alat.
• Python: logika aplikasi ditulis dina basa Python (Chaquopy) di app/src/main/python/main.py, jeung dijalankeun ku host MainActivity.java di app/src/main/java/<nama-paket>/MainActivity.java. Proyek Python bisa dijieun langsung dina telepon (runtime Chaquopy kaasup dina aplikasi) atawa ngaliwatan GitHub Actions. SDK minimum proyek Python nyaéta 24 (Android 7.0).

Robah Arsitéktur Proyék
Pikeun ngarobah pilihan arsitéktur proyék nu geus aya tanpa nyieun proyék anyar: dina menu utama, pencét «Robah Arsitéktur Proyék», tuluy pilih proyék jeung robah kotak centang «Jieun APK 64 bit (arm64-v8a)» atawa «Jieun APK 32 bit (armeabi-v7a)»; atawa dina «Kelola Proyék», pencét lila ngaran proyék jeung pilih «Robah Arsitéktur» pikeun muka layar nu sarua langsung pikeun proyék éta. Aturanna: lamun dua kotak centang dihurungkeun, build nyieun dua APK nu misah, hiji 64 bit jeung hiji 32 bit; lamun ngan hiji kotak centang dihurungkeun, build nyieun hiji APK universal nu tetep jalan dina alat 64 bit jeung 32 bit. APK nu misah pikeun ngan hiji varian can teu dirojong, sabab jalur build ngan nyaho pilihan misah atawa universal, tapi pilihan unggal varian tetep disimpen di jero proyék sangkan teu leungit nalika layar dibuka deui.

Susunan berkas proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python
Proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python disusun kawas proyek Android umumna. Di jero folder app aya folder src, jeung di jerona aya folder main. Di jero folder main aya AndroidManifest.xml di gigireun folder java, folder res anu ngandung layout/activity_main.xml jeung values/strings.xml sarta values/styles.xml, jeung pikeun HTML jeung Situs Web aya folder assets anu ngandung index.html (Situs Web ogé mibanda tentang.html jeung kontak.html). Proyek HTML jeung Situs Web ogé mibanda MainActivity sorangan di app/src/main/java/<nama-paket>/MainActivity.java, anu ngamuat index.html dina WebView jeung jadi launcher dina AndroidManifest. Proyek Python mibanda kode Python di app/src/main/python/main.py jeung host MainActivity.java di app/src/main/java/<nama-paket>/MainActivity.java. AndroidManifest.xml, layout, strings, jeung styles bisa dibuka jeung dirobah dina éditor, sarua jeung MainActivity. Proyek heubeul anu manifest-na masih aya di gigireun folder app masih bisa dijieun, kusabab nalika nyieun, aplikasi mariksa AndroidManifest.xml di app/src/main/ heula, tuluy anu di gigireun folder app, jeung pamungkas berkas data proyek.

Aturan idin (penting)
Idin anu dicirian nalika nyieun proyek ukur kacatet di hiji tempat, luyu jeung jenis proyekna. Pikeun proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python, idin anu dicirian kacatet UKUR dina AndroidManifest.xml anu aya di app/src/main/, di gigireun folder java, di jero folder proyek. Berkas data proyek pikeun proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python teu ngandung daptar idin. Lamun milih Java tuluy nyirian INTERNET jeung CAMERA, anu kacatet dina AndroidManifest.xml ukur INTERNET jeung CAMERA, tanpa idin séjén anu milu. Nalika nyieun, aplikasi maca idin tina tempat anu sarua: tina AndroidManifest.xml di app/src/main/ pikeun proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python (lamun euweuh, tina AndroidManifest.xml di gigireun folder app pikeun proyek heubeul), jeung tina berkas data proyek pikeun proyek heubeul.

Cara ngagunakeun éditor
Buka Kelola Project, toél ngaran proyek pikeun muka éditor. Dina éditor, berkas bisa dibuka, kode bisa ditulis, jeung parobahan bisa disimpen. Pikeun proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python, berkas disusun di jero folder app/src/main. Pikeun ngabagikeun proyek, gunakeun Ekspor ZIP (tempo bagian di handap).

Cara ngajalankeun proyek
Dina éditor, pencét Jalankan pikeun nguji proyek. Pikeun proyek HTML jeung Situs Web, anu dijalankeun nyaéta index.html ngaliwatan WebView. Lamun aya kasalahan, baca pesen kasalahanana, benerkeun kode, tuluy jalankeun deui.

Cara nyieun APK
Dina éditor, pencét Bangun. Aya dua cara nyieun. Kahiji, Bangun di perangkat: nyieun langsung dina telepon tanpa internét, pikeun proyek HTML, Situs Web, Java, Kotlin, jeung Python. Kadua, Bangun online ngaliwatan GitHub Actions: nyieun ngaliwatan internét di GitHub, jeung bisa digunakeun pikeun sakabéh jenis proyek. Proyek Compose ukur bisa dijieun ku cara kadua (Bangun online) atawa di Termux ku Gradle, kusabab Compose merlukeun pustaka Jetpack Compose anu teu sayogi dina alat. Hasil bangun munggaran tacan ditandatanganan. Sanggeus éta aplikasi nandatangananna: otomatis ku konci bawaan, atawa ku tanda tangan pribadi lamun kotak "Gunakan tanda tangan pribadi" dicirian nalika nyieun proyek.

Cara masang APK
Lamun APK geus jadi, pencét Pasang pikeun masangna. Dina Android 8 ka luhur, telepon bakal ménta "Izinkan dari sumber ini" heula, kusabab aplikasi ieu masang APK ti luar Play Store. Aktipkeun idin éta sakali dina Pengaturan, tuluy balik deui ka aplikasi: pamasangan bakal nuluykeun otomatis tanpa kudu mencét Pasang deui. Lamun tombol Pasang teu némbongan, pastikeun bangun geus réngsé jeung APK geus dijieun.

Cara nandatanganan aplikasi
Unggal APK kudu ditandatanganan sangkan bisa dipasang. Sayogi dua pilihan. Kahiji, konci bawaan: aplikasi nandatanganan sorangan sacara otomatis, tanpa kudu ngalakukeun nanaon. Kadua, tanda tangan pribadi: jieun heula keystore ngaliwatan menu Buat Keystore dina menu utama, simpen kecap sandina kalawan alus, tuluy cirian "Gunakan tanda tangan pribadi" nalika nyieun proyek. Keystore disimpen di Download/project/signing.

Ékspor proyek jadi ZIP
Ekspor ZIP disayogikeun sangkan proyek bisa dibagikeun ka babaturan. Carana: dina Kelola Project, tahan lila ngaran proyek, tuluy pilih Ekspor ZIP. Hasilna disimpen di Download/project/<NamaProyek>.zip. Folder bin teu milu diasupkeun, ku kituna ukuranana leutik, ukur puluhan KB. Berkas ZIP éta bisa dikirim ka babaturan atawa diunggah ka GitHub.

Éksténsi JAWS
Éksténsi JAWS ngagunakeun mesin éksténsi ti Jieshuo (CSR), lain pamaca layarna. Ku kituna, rancangan masih bisa jalan sanajan pangguna ngagunakeun TalkBack. Carana: buka Ekstensi JAWS dina menu utama. Kusabab klik otomatis jalan sorangan, layanan kudu diaktipkeun heula dina Pengaturan Aksesibilitas. Sanggeus éta, rancangan anyar bisa dijieun: ketik ngaran rancangan, pencét OK, tuluy eusian kotakna.

Daftar Klik dipisahkeun sangkan rapih
Di jero rancangan aya dua kotak: kotak skrip jeung kotak Daftar Klik. Daptar tombol disimpen misah dina berkas daftar_klik.txt, hiji ngaran per baris. Conto eusina: tombolSimpan, tombolHapus, tombolBuka. Pikeun muka aplikasi, tulis waé >WhatsApp dina daptar éta. Rancangan heubeul anu tacan mibanda berkas daftar_klik.txt bakal némbongkeun conto bawaan éta.

Fungsi basajan anu disayogikeun
• klikTombol("tombolSimpan") — ngaklik hiji tombol dumasar kana téksna.
• klikDaftarTombol(daftar) — ngaklik daptar dina daftar_klik.txt, hiji tombol per baris, ngaruntuy, tuluy ngabéjaan sabaraha anu hasil jeung sabaraha anu teu kapanggih.
• bukaAplikasi("WhatsApp") — muka aplikasi dumasar kana ngaranna, atawa tulis ">WhatsApp" dina daptar.
• klik(540, 1200) — ngaklik dina koordinat layar.
Sakabéh fungsi dijieun basajan heula. Lamun geus biasa, fungsi tambahan bisa ditambahkeun engké.

Ngeunaan pamaca layar
Aplikasi ieu dirancang sangkan ramah pamaca layar. Unggal kolom eusian mibanda labél jeung conto ngeusian, jeung sakabéh tombol bisa kahontal tanpa gestur anu riweuh. Éksténsi JAWS dijieun sangkan masih jalan sanajan pangguna ngagunakeun TalkBack, kusabab anu digunakeun nyaéta mesin éksténsina, lain pamaca layarna.

Privasi jeung kaamanan
Proyek jeung keystore disimpen dina telepon anjeun. Token GitHub ukur dipaké pikeun bangun online jeung disimpen di jero aplikasi ieu. Ulah ngabagikeun token atawa kecap sandi keystore anjeun ka saha waé. Lamun ngagunakeun tanda tangan pribadi, simpen keystore jeung kecap sandina di tempat anu aman, kusabab lamun leungit, APK heubeul teu bisa dianyarkeun ku tanda tangan anu sarua.

Kabutuhan
Android 5.0 atawa leuwih anyar. Idin panyimpenan: dina Android 11 ka luhur ngagunakeun idin aksés sakabéh berkas, dina Android 10 ka handap ngagunakeun idin panyimpenan biasa (maca/nulis panyimpenan) kusabab Android 10 teu mibanda idin aksés sakabéh berkas. Nyieun dina alat merlukeun telepon anu prosésorna ARM (32 atawa 64 bit). Nyieun online ngaliwatan GitHub Actions merlukeun internét jeung token GitHub. Proyek Kotlin bisa dijieun dina alat, tapi bangun munggaranna leuwih lila jeung ngagunakeun memori leuwih loba kusabab ukuran compiler Kotlin anu gedé. Proyek Compose dijieun ngaliwatan GitHub Actions atawa di Termux ku Gradle. Proyek Python merlukeun Android 7.0 atawa leuwih anyar (SDK minimum 24) jeung APK hasilna leuwih gedé kusabab ngasupkeun runtime Python (Chaquopy) jeung pustaka bakuna.

Terminal
Menu Terminal dina layar utama muka terminal di jero aplikasi ieu. Paréntah saperti ls bisa digunakeun pikeun ningali eusi folder proyek, cd pikeun pindah folder, jeung git pikeun ngatur kode. Kaluaran paréntah némbongan minangka téks anu bisa dibaca ku pamaca layar, jeung aya tombol Bacakan hasil pikeun ngadéngékeun hasil pamungkas. Terminal ieu ngagunakeun shell sistem telepon, ku kituna program interaktif saperti nano jeung vim tacan bisa dipaké di dieu.

Lisénsi (vérsi mayar)
Pikeun ngajual aplikasi, cirian "Aktifkan Lisensi" nalika nyieun proyek, tuluy eusian nomer WhatsApp anjeun. Aplikasi hasil bangun bakal ménta kode lisénsi nalika mimiti dibuka: pangguna ningali ID alatna, mencét tombol Kirim ID Perangkat pikeun ngirim ID éta ka WhatsApp anjeun, tuluy anjeun ngawalon ku kode lisénsina. Kode lisénsi diitung tina ID alat jeung kecap sandi proyek (lisensi_seed dina berkas data proyek) — simpen kecap sandi éta kalawan alus jeung ulah dibagikeun. Sanggeus kode anu bener diasupkeun, aplikasi kabuka jeung teu ménta kode deui.

Pembuat Ikon Otomatis
Ikon proyek anyar masih transparan, ku kituna sayogi Pembuat Ikon dina menu utama. Carana: pencét Pembuat Ikon, tulis hiji atawa dua aksara (contona inisial ngaran aplikasi), pilih warna latar jeung warna tulisan, tempo pratayangna, tuluy pencét Simpan ke Proyek pikeun ngagunakeun ikon éta dina proyek anu dipilih, atawa Simpan ke Download pikeun ngagunakeun berkas PNG-na di tempat séjén. Sanggeus proyek dijieun, aplikasi ogé nawaran nyieun ikon. Ikon heubeul proyek bisa diganti iraha waé tina menu proyek dina Kelola Project (tahan lila ngaran proyek, tuluy pilih Ganti Ikon).

Template Proyek Siap Pakai
Lamun teu hayang ngamimitian tina proyek kosong, pilih template nalika nyieun proyek: Kalkulator (Java), Catatan (Java), Daftar Tugas (Kotlin), Kalkulator Web (HTML), Situs Profil (Situs Web), atawa Penghitung (Compose). Milih template sacara otomatis ngarobah jenis proyek nuturkeun template éta, jeung proyek dijieun ku kode awal anu geus jadi — kari dijalankeun atawa dirobah. Lamun jenis proyek dirobah deui sacara manual sanggeus milih template, template dibatalkeun jeung proyek balik kosong. Pikeun template HTML jeung Situs Web, template ngaganti eusi index.html, kaasup skrip HTML anu diketik dina form.

Cadangan jeung Pulihkan Proyek
Sangkan proyek teu leungit, sayogi fitur cadangan. Carana: dina Kelola Project, tahan lila ngaran proyek, tuluy pilih Cadangkan. Cadangan disimpen minangka ZIP dina folder Download/backup kalawan ngaran proyek jeung tanggal, conto: GarudaDecode-2026-11-14-123045.zip. Eusina sarua jeung Ekspor ZIP (sakabéh eusi proyek, tanpa folder bin). Pikeun mulihkeun: buka menu dina Kelola Project, pilih Pulihkan cadangan, tuluy pilih berkas cadanganana. Lamun ngaran proyek geus aya, aplikasi bakal nanyakeun: Timpa proyek lama, atawa simpen ku Nama baru.

Bagikan jeung Impor Proyek
Pikeun ngabagikeun proyek ka babaturan: dina Kelola Project, tahan lila ngaran proyek, tuluy pilih Bagikan. Proyek dikirim minangka ZIP ngaliwatan aplikasi babagi (WhatsApp, Telegram, jeung sajabana). Pikeun nampa proyek ti babaturan: buka menu dina Kelola Project, pilih Impor proyek, tuluy pilih berkas ZIP-na. Berkas ZIP éta kudu ngandung berkas data proyek — lamun euweuh, berkas ditolak ku pesen anu jelas, kusabab berkas éta lain proyek Create Aplikasi. Lamun ngaran proyek geus aya, aplikasi bakal nanyakeun: Timpa proyek lama, atawa simpen ku Nama baru.

Pencarian jeung Filter Proyek
Lamun proyek geus loba, dina Kelola Project aya kotak pencarian jeung panyaring jenis. Ketik ngaran proyek dina kotak pencarian, daptar langsung kasaring (aksara gedé jeung leutik teu dibédakeun). Panyaring jenis ngawatesan daptar kana hiji jenis wungkul: Semua, HTML, Situs Web, Java, Kotlin, Compose, atawa Python. Menu unggal proyek masih bisa dibuka saperti biasa tina daptar anu geus kasaring.

Wangun Aplikasi ku Suara
Upami henteu hoyong ngetik, anggo sora: pencét Ngawangun ku Sora dina ménu utama, teras ucapkeun paréntah. Paréntah anu tiasa diucapkeun: "Buat proyek kalkulator", "Bangun proyek Kalkulator", "Buka proyek Kalkulator", "Jalankan proyek Kalkulator", "Daftar proyek", "Buka ikon", "Kembali", sareng "Bantuan". Aplikasi ngajawab ku sora sareng téks, janten tetep tiasa dianggo tanpa ningali layar. Pangwanoh sora nganggo aplikasi pangwanoh sora bawaan HP (gratis; tiasa jalan offline upami paket basa Indonésia parantos dipasang). Upami HP teu gaduh pangwanoh sora, paréntah tiasa ditulis dina kotak téks dina layar anu sami.

AI Panyieun Aplikasi
Tulis atawa diktekeun aplikasi nu dipikahayang dina layar AI Panyieun Aplikasi, contona: «aplikasi catetan jeung tombol simpen». Aplikasi nganalisis kecap koncina di jero HP sorangan (tanpa internét, tanpa biaya), tuluy nyieun proyék nyata tina template nu pang cocogna: kalkulator, catetan, daptar pancén, kalkulator wéb, situs profil, atawa pangitung. Lamun déskripsi anjeun can aya template nu cocog, aplikasi nyieun proyék kosong sarta ngajelaskeunana kalawan jujur — henteu pura-pura ngarti. Proyék hasil AI bisa langsung dibuka di Kelola Proyék.

Pratinjau Langsung ka HP Réréncangan
Pikeun némbongkeun proyék ka babaturan saméméh diwangun: di Kelola Proyék, pencét lila ngaran proyék, tuluy pilih Pratinjau ke HP Teman. Aplikasi nyieun pakét pratinjau leutik nu eusina bérkas utama proyék (index.html, MainActivity, atawa main.py) ditambah BACA-SAYA.txt nu eusina pitunjuk jeung info.txt. Pakét éta dikirim salaku ZIP ngaliwatan WhatsApp atawa Telegram. Babaturan nu narima bisa langsung muka pratinjau: kaca HTML kabuka dina browser, kode Java/Kotlin/Python dibaca salaku téks.

Pasar Proyék
Pasar Proyék eusina proyék conto bawaan aplikasi nu bisa dipasang ka folder proyék ku hiji ketukan: Kalkulator, Catetan, Daptar Pancén, Kalkulator Wéb, Situs Profil, Pangitung, Jam Digital, jeung Kuis Wéb. Pasar online (undeur conto ti internét) can aya, jadi pasar ieu eusina conto nu geus aya di jero aplikasi. Proyék nu geus dipasang bisa dibuka jeung dirobah di Kelola Proyék kawas proyék jieunan sorangan.

Kolaborasi Langsung
Pikeun ngagarap proyék bareng jeung babaturan: buka Kolaborasi dina ménu utama, pilih proyék, tulis catetan parobahan (naon nu dirobah), tuluy pencét Bagikan untuk Kolaborasi. Proyék dikirim salaku ZIP bareng jeung bérkas CATATAN.txt di jerona. Babaturan anjeun ngagarap tuluy ngabalikeun ZIP-na; anjeun mencét Tarima Waleran, maca heula catetan parobahanna, tuluy milih Terapkeun pikeun nimpa proyék lila atawa Bolay lamun teu jadi. ZIP nu teu eusina CATATAN.txt lain pakét kolaborasi — pikeun ZIP proyék biasa, gunakeun Impor proyek di Kelola Proyék.

Panarjamah Aplikasi Otomatis
Pikeun narjamahkeun téks dina aplikasi ka basa séjén: buka Panerjemah Aplikasi dina ménu utama, pilih proyék jeung basa target (Inggris, Arab, atawa Jawa), tuluy pencét Tarjamahkeun. Kamus geus aya di jero HP (tanpa internét, tanpa biaya) sarta eusina kecap umum sapopoé; téks ti strings.xml, layout, jeung kode dibaca tuluy ditarjamahkeun. Hasilna ditulis ka folder values-basa/strings.xml (lamun proyék mibanda strings.xml) jeung laporan tarjamahan-basa.txt di folder proyék. Kecap nu can aya di kamus ditinggalkeun sakumaha ayana sarta dilaporkeun — sangkan anjeun nyaho kecap mana nu masih kudu ditarjamahkeun sorangan.

Pamadamel Game Tanpa Kode
Pikeun nyieun kaulinan tanpa nulis kode: buka Pamadamel Game Tanpa Kode dina ménu utama, pilih jenis kaulinan (Tebak Angka, Kuis, atawa Tangkep Béntang), eusi ngaran kaulinan, jumlah (level/soal/béntang), jeung pesen meunang, tuluy pencét Buat Game. Kaulinan dijieun salaku proyék nyata nu bisa langsung dijalankeun di Kelola Proyék sarta diwangun jadi APK kawas proyék lianna.

Uji Aplikasi Otomatis
Pikeun mariksa proyék saméméh diwangun: di Kelola Proyék, pencét lila ngaran proyék tuluy pilih Uji Otomatis. IDE mariksa 10 hal tanpa ngawangun APK — bérkas wajib aya (bérkas data proyék, manifest, bérkas utama, layout, strings), ngaran pakét jeung vérsi, idin nu dipaké, ikon, jeung kasaimbangan kurung kode. Hasilna dipintonkeun per item (LULUS/GAGAL jeung pesen) sarta dibacakeun ku Jieshuo. Lereskeun heula sagala nu GAGAL, tuluy pencét Bangun proyek.

AI Pemeriksa Kode
Pikeun mariksa kode proyék tina pola nu mindeng ngabalukarkeun masalah: buka Pariksa Kode dina ménu utama, pilih proyék, tuluy pencét Pariksa Kode. Pamariksa jalan di jero HP (tanpa internét) sarta néangan variabel nu teu dipaké, fungsi kosong, perulangan tanpa eureun nu jelas, téks nu ditulis langsung dina kode (leuwih hadé dina strings.xml), idin jeung API bahaya, pananda TODO/FIXME, jeung palaksanaan dinamis. Unggal pamanggih eusina ngaran bérkas, nomer baris, jeung saran leresan. Pamariksa ieu dumasar pola, lain AI sabenerna — masalah nu teu nuturkeun pola tetep bisa lolos.

Mode Diajar Interaktif
Pikeun diajar nyieun aplikasi léngkah demi léngkah: buka Mode Diajar dina ménu utama. Aya 5 palajaran: Nyieun proyék kahiji, Nambah tombol, Ngarobah warna, Nambah sora, jeung Ngawangun APK. Toél hiji palajaran pikeun maca kateranganana jeung pancén latihanna, pigawé pancénna, tuluy pencét Pariksa tugas — IDE mariksa sabenerna naha pancénna geus dipigawé (ku nyeken proyék jeung APK dina HP anjeun). Palajaran nu lulus ditandaan réngsé sarta disimpen.

Sinkronisasi Cloud
Pikeun nyadangkeun proyék ka cloud: buka Sinkronisasi Cloud dina ménu utama. Cadangan lokal nyimpen ZIP proyék ka folder Download/cloud jeung cap waktu, sarta bisa dipulihkeun iraha waé tina daptar cadangan. Cadangan GitHub ngunggah ZIP proyék ka repo pribadi anjeun (nganggo token ti Setelan GitHub) sarta bisa diundeur deui. Ieu cadangan jeung pulihkeun manual — sinkronisasi otomatis dua arah nu lengkep butuh server, jadi can aya.

Panyieun Backend Otomatis
Pikeun nyieun backend tanpa nulis kode server: buka Panyieun Backend dina ménu utama, pilih jenis backend (Catetan, Daptar Pancén, atawa Papan Pesen), eusi ngaran proyék, tuluy pencét Buat Backend. IDE nyieun proyék HTML nyata jeung kaca formulir sarta daptar data nu disimpen dina panyimpenan lokal HP (localStorage) — data disimpen sarta bisa dibaca deui nalika aplikasi dijalankeun. Backend ieu jalan dina hiji HP; dua HP can bisa ngabagi data nu sarua lantaran euweuh server internét.

Désainer Téma Otomatis
Pikeun méré téma warna ka proyék: buka Désainer Téma dina ménu utama, pilih proyék jeung téma (Caang, Poék, Biru, Héjo, Beureum, atawa Wungu). Pratinjau némbongkeun genep warna téma (primer, primer poék, aksen, latar, téks, téks sékundér) sarta dibacakeun ku Jieshuo. Pencét Terapkan Tema — IDE nulis colors.xml jeung styles.xml (style app_theme) ka proyék, langsung dipaké nalika proyék dijalankeun atawa diwangun.

Panyieun Animasi
Pikeun méré animasi ka proyék: buka Panyieun Animasi dina ménu utama, pilih proyék, jenis animasi (Fade, Gésér, Puter, Luncat, atawa Denyut), durasi (100 nepi ka 10000 milidetik), jeung target (tombol, téks, atawa gambar), tuluy pencét Jieun Animasi. IDE nulis bérkas animasi nyata (res/anim/anim_<jenis>.xml pikeun proyék Java/Kotlin/Compose, atawa animasi.css pikeun proyék HTML/Situs Wéb) bareng jeung conto kode pamakéanna nu dipintonkeun dina layar.

Pangrékam Lampah
Pikeun ngulang pagawéan sacara otomatis: IDE ngarékam lampah nu dilakukeun (buka proyék, jalankeun, wangun, ékspor, cadangan, jieun proyék, simpen bérkas). Buka Pangrékam Lampah dina ménu utama pikeun ningali daptar lampah nu karékam bareng jeung rencanana, tuluy pencét Puter Deui — IDE ngajalankeun deui lampah nu bisa diotomatisasi (cadangan jeung jieun proyék dijalankeun di tempat; jalankeun, wangun, jeung ékspor muka layar utamana; buka jeung simpen muka éditor). Lampah nu teu bisa diotomatisasi diliwatan sarta dilaporkeun di ahir.

Kaamanan Otomatis
Pikeun mariksa kaamanan proyék: buka Kaamanan Otomatis dina ménu utama, pilih proyék, tuluy pencét Periksa Keamanan. IDE mariksa 8 hal sacara lokal (tanpa internét): idin bahaya (lokasi, SMS, telepon, kaméra, mikrofon, kontak), ngirim data via HTTP, ngirim SMS, telepon kaluar, kecap konci atawa konci nu ditulis langsung dina kode, WebView tanpa panyalindungan, komponén nu diékspor tanpa idin, jeung alamat http tanpa énkripsi. Unggal pamanggih dibéré tingkat AMAN, PERINGATAN, atawa BAHAYA bareng jeung saran leresan, sarta ringkesanna dibacakeun ku Jieshuo.

AI Offline
Pikeun maké pakakas bantu téks jeung kode tanpa internét: buka AI Offline dina ménu utama. Aya 4 pakakas: Lereskeun Téks (kapital, tanda baca, jeung spasi ganda), Ringkes Téks (nyokot 3 kalimah nu pang pentingna), Jieun Nami Aplikasi (ti déskripsi nu ditulis), jeung Saran Ngaran Variabel (néangan ngaran variabel 1-2 hurup dina proyék). Ieu aturan saderhana di jero HP, lain modél AI sabenerna. Hasil leresan téks bisa diterapkeun ka strings.xml proyék ku tombol Terapkeun.

Panyieun Widget & Wallpaper
Pikeun nyieun widget layar utama: buka Widget & Wallpaper dina ménu utama, pilih proyék, eusi téks widget, tuluy pencét Buat Widget. IDE nulis WidgetSaya.java, layout widget, info widget, sarta nambahkeun receiver ka AndroidManifest.xml proyék — wangun proyék, tuluy pasang widget ti layar utama HP. Pikeun wallpaper: eusi tulisan jeung warna latar sarta warna tulisan, jieun pratinjau, tuluy simpen salaku PNG ka folder Download atawa langsung pasang salaku wallpaper HP.

Integrasi Media Sosial
Pikeun nambahkeun tombol bagikeun ka aplikasi: buka Integrasi Media Sosial dina ménu utama, pilih proyék, tuluy tambah ngabagi ka WhatsApp, Facebook, atawa Telegram (atawa katiluna sakaligus). IDE nulis kode ngabagi nyata ka bérkas utama proyék (MainActivity atawa index.html). Tombol Uji Ngabagi muka chooser ngabagi ti IDE jeung téks conto, sangkan alurna bisa karasa saméméh ngawangun aplikasi.

Aplikasi tina Gambar
Pikeun nyieun aplikasi galéri ti gambar: buka Aplikasi tina Gambar dina ménu utama, pilih gambar ti galéri. IDE nganalisis ukuran jeung warna dominan gambar, tuluy nyieun proyék aplikasi galéri nyata: gambar disalin ka assets proyék, warna téma dicokot ti warna dominan gambar, jeung ngaran aplikasi dicokot ti ngaran bérkas gambar. Buka Kelola Proyék pikeun ngajalankeun atawa ngawangun aplikasi galéri éta.

Terminal Interaktif (Parser VT)
Pikeun maké program interaktif di Terminal: buka Terminal dina ménu utama, tuluy jalankeun nano, vim, top, atawa htop. Terminal ayeuna maké parser VT (layar grid 24 baris x 80 kolom) sangkan tampilan program éta leres — kursor obah, baris dipupus, jeung layar robah kawas di terminal sabenerna. Aya tombol husus Tab, Panah Luhur, Panah Handap, jeung Esc pikeun ngadalikeun program interaktif. Kaluaran tetep mangrupa téks nu bisa dibaca Jieshuo; pencét Bacakeun layar pikeun ngadéngé baris panungtung.

Terminal Exec (Biner Aplikasi)
Pikeun ngajalankeun binér di folder aplikasi (mis. aapt2, ECJ, D8) ti Terminal: ketik paréntahna kawas biasa. IDE maké libkautsarexec.so sangkan binér di folder aplikasi bisa dieksekusi dina Android 10 ka luhur. Pencét Uji Exec di Terminal pikeun mariksa naha jalur exec binér jalan dina HP ieu — hasilna dipintonkeun sakumaha ayana. Lamun exec diblokir sistem, paréntah sistem jeung skrip shell tetep jalan; jalankeun binér ngaliwatan ménu Bangun proyek salaku gantina.

Terminal Tetap Hidup (KeepAlive)
Pikeun ngantep shell tetep jalan nalika pindah layar: buka Terminal, jalankeun paréntah, tuluy pencét Balik atawa pindah ka layar séjén — shell TEU paéh, jeung béwara Terminal tetep tampil sangkan anjeun bisa balik ku hiji ketukan. Paréntah nu geus dijalankeun disimpen dina riwayat (tombol Riwayat, atawa panah luhur/handap dina kolom paréntah) jeung paréntah nu mindeng dipaké bisa disimpen salaku favorit (tombol Favorit). Pencét Tutup shell lamun geus réngsé, sangkan shell bener-bener dipaéhan. Aya ogé tombol Wangun di Terminal dina ménu proyék jeung dina ménu éditor: Terminal dibuka dina folder proyék jeung paréntah wanguna geus dieusi.

Pasang Alat Terminal (Uji Coba)
Fitur nu masih dina uji coba: di Terminal aya tombol Pasang Alat Terminal pikeun masang lingkungan Termux ti eunteung dina repo alat-termux milik pamekar (github.com/syudat/alat-termux), salaku jalur séjén sajaba ti tombol Pasang Termux nu nyokot ti rilis resmi Termux. Eusi eunteungna sarua persis jeung rilis resmi sarta dipariksa ku SHA-256 nalika pamasangan. Sanggeus lingkungan kapasang, paréntah pkg update jeung pkg install bisa dipaké, sarta pakakas tambahan ti repo ogé dipasang ka terminal: info-terminal pikeun ningali info lingkungan, bersih-terminal pikeun ngabersihan cache, jeung cadangkan-proyek pikeun ngarsipkeun folder proyék jadi hiji bérkas tar.gz nu aya tanggalna. Sanggeus éta aplikasi masang otomatis pakét Linux dasar (git, python, curl, wget, nano, openssh, zip, unzip) jeung pakakas wangun APK bareng jeung tanda tangan (openjdk-21, kotlin, gradle, ecj, aapt2, d8, apksigner, clang, cmake, ninja, make) ti repo resmi Termux, jadi terminal langsung siap dipaké ngawangun aplikasi. Undeur pakét badag (ratusan MB) bisa lila. Nalika pamasangan jalan, kamajuan jeung kaluaran paréntah tampil dina layar utama Terminal, jeung hasil ahirna dibacakeun ku pamaca layar. Lamun pamasangan pakét can anggeus, pencét Pasang Alat Terminal deui pikeun neruskeunana.

Mode Suara Penuh
Pikeun ngadalikeun IDE sagemblengna ku sora: buka Mode Suara Penuh dina ménu utama, tuluy pencét Mulai Mendengarkan. IDE ngadéngékeun terus-terusan — teu perlu mencét tombol pikeun unggal paréntah — ngajalankeun paréntah sarta ngajawab ku sora. Aya 26 paréntah: jieun, wangun, buka, jalankeun, daptar, pilari, pupus, uji, pariksa, ékspor, cadangan, bagikeun, jieun ikon, tarjamahkeun, wangun di terminal, baca layar, buka kabéh layar (kaasup kaamanan, AI offline, widget, média sosial, kaulinan, diajar, cloud, backend, téma, animasi, pangrékam), balik, tutup, jeung pitulung. Lamun mode ditinggalkeun aktif, ngadéngékeun diteruskeun otomatis nalika layar ieu dibuka deui. Pencét Berhenti Mendengarkan pikeun mareuman mode ieu. Lamun HP teu mibanda layanan pangwanoh sora, paréntah tetep bisa ditulis dina kotak téks.

Panerjemah Kode
Pikeun narjamahkeun kode antar basa tanpa internét: buka Panerjemah Kode dina ménu utama, pilih proyék, pilih bérkas sumber (.java/.kt), tuluy pilih arah: Java ka Kotlin. Pencét Tarjamahkeun — hasilna dipintonkeun bareng jeung laporan baris nu teu bisa ditarjamahkeun (baris éta disimpen sakumaha ayana sarta ditandaan). Pencét Simpan hasil pikeun nulis bérkas ANYAR (ngaran-tarjamahan.java/.kt) dina folder nu sarua; bérkas asli teu kungsi ditimpa. Ieu panerjemah aturan pola, lain kompiler — salawasna pariksa hasil saméméh dipaké.

Git di Jero Aplikasi
Pikeun maké Git di jero IDE tanpa Termux: buka Git di Jero Aplikasi dina ménu utama, pilih proyék, tuluy pencét Buat Repo Git pikeun nyieun repo lokal (.git) dina proyék éta. Pencét Pariksa Status pikeun ningali bérkas anyar, robah, atawa dipupus dibandingkeun commit panungtung; eusi pesen commit tuluy pencét Commit pikeun nyimpen snapshot proyék; pencét Tingali Log Commit pikeun ningali riwayat commit. Push ka GitHub jeung Pull ti GitHub maké snapshot ngaliwatan token GitHub (repo pembuat-aplikasi-build) — lain protokol git. Clone, Push (git sistem), jeung Pull (git sistem) ngan jalan lamun binér git kapasang dina HP (biasana euweuh). Ieu lain git lengkep: euweuh merge, branch, atawa diff — unggal commit nyimpen snapshot ZIP lengkep proyék.

Panyieun Iklan
Pikeun nambahkeun iklan ka aplikasi hasil: buka Panyieun Iklan dina ménu utama, pilih proyék, panyadia (AdMob, Unity Ads, atawa AppLovin), jeung jenis iklan (Banner, Interstitial, atawa Rewarded). Eusi ID unit iklan lamun geus boga — kosong hartina maké ID uji (AdMob maké ID uji resmi Google; Unity maké Game ID conto; AppLovin maké rohangan kosong). Pencét Buat Kode Iklan pikeun ningali kode Java, Kotlin, jeung panduan; pencét Simpan ke Proyek pikeun nulis sagalana ka bérkas iklan-<panyadia>-<jenis>.txt dina proyék. Ieu template kode + panduan, lain SDK iklan — SDK teu kaasup dina IDE; iklan sabenerna kakara tampil sanggeus anjeun nyieun akun panyadia, nyieun unit iklan, nempel ID unit sorangan, jeung nambahkeun depéndensi SDK dina build.gradle proyék.

Mode Barudak
Pikeun maké IDE bareng jeung barudak: buka Mode Barudak dina ménu utama. Layar disaderhanakeun ku tombol badag sarta ngan aya 4 lampah aman: Jieun Proyek (ti template aman: Kalkulator, Tebak Angka, Kuis, Tangkep Béntang), Buka Proyek, Jalankeun, jeung Diajar. Euweuh tombol pupus, ékspor, cadangan, atawa setélan token dina layar ieu. Nalika kahiji asup, jieun PIN 4 angka — PIN éta dipaké kolot pikeun kaluar ti Mode Barudak (tombol Kaluar tina Mode Anak atawa tombol Balik). PIN ieu pangjaga hampang pikeun barudak leutik, lain kaamanan sabenerna.

Pamadamel Aplikasi Wear OS & TV
Pikeun nyieun aplikasi jam (Wear OS) atawa TV (Android TV): buka Wear OS & TV dina ménu utama, pilih target (Wear OS, Android TV, atawa duanana). Eusi ngaran proyék tuluy pencét Buat Proyek Baru Wear/TV — IDE nyieun proyék Java tuluy nyaluyukeunana — atawa pilih proyék nu geus aya tuluy pencét Terapkan ke Proyek Ini. Panyaluyuan: uses-feature dina manifest, kategori LEANBACK_LAUNCHER + banner pikeun TV, jeung layout activity_main.xml nu disaluyukeun (Wear: layar leutik; TV: layar badag nu ramah D-pad). Katerangan lengkep ditulis ka wear-tv.txt dina proyék. Ieu template proyék — build + uji tetep butuh perangkat/emulator Wear OS atawa Android TV; banner TV (banner.png 320x180) teu dijieun otomatis, kudu ditambahkeun sorangan (misalna ngaliwatan Panyieun Ikon).

Peta Proyék
Pikeun ningali struktur hiji proyék: buka Peta Proyék dina ménu utama, pilih proyék, tuluy pencét Tampilkeun Peta — IDE nampilkeun daptar folder jeung bérkas bareng jeung ukuranna, total ukuran, ukuran per jenis bérkas, jeung bérkas penting (bérkas utama, manifest, layout, strings, ikon, kaca wéb). Pencét Simpan peta-proyek.txt pikeun nulis peta nu sarua ka akar proyék. Folder bin/ (hasil wanguna) jeung .git/ (repo lokal) teu kaasup dipétakeun lantaran eusina bisa dijieun deui.

Kalkulator Ukuran APK
Pikeun ngira-ngira ukuran APK hasil wanguna saméméh ngawangun: buka Kalkulator Ukuran APK dina ménu utama, pilih proyék, tuluy pencét Itung Perkiraan. IDE nampilkeun rincian per kategori (kode/DEX, resource, aset, library native, manifest + resources.arsc, overhead), total perkiraan, 5 bérkas pangbadagna, jeung saran ngaleutikan (misalna gambar badag dipangleutikeun resolusina, sora badag dipotong durasina). Ieu PERKIRAAN, lain ukuran pasti — ukuran sabenerna bisa béda lantaran komprési aapt2, panghapusan kode teu kapaké (R8), jeung resource hasil wanguna.

Panganalisis APK
Pikeun maca eusi APK nu geus réngsé (kawas Panganalisis APK dina Android Studio): buka Panganalisis APK dina ménu utama, pilih proyék, tuluy pencét Analisis APK Hasil Bangun. IDE maca APK panganyarna dina folder bin proyék éta sarta ngalaporkeun ngaran pakét, vérsi, SDK minimum jeung target, daptar idin nu dipaké, jumlah bérkas dex, rincian ukuran per bagéan (kode program, resource, aset, pustaka native, tanda tangan), jeung 10 éntri pangbadagna. Mangpaat pikeun nyaho bagéan mana nu nyieun APK badag jeung idin naon waé nu dipaké aplikasi hasil.

Pratingal Ukuran Layar
Pikeun mariksa tampilan proyék dina loba ukuran layar sakaligus (kawas dina Android Studio): buka Pratingal Ukuran Layar dina ménu utama, pilih proyék, tuluy pencét Periksa Ukuran Layar. IDE maca kabéh layout proyék sarta ngalaporkeun elemen nu rubakna ditulis tetep (misalna 400dp) sarta ngaleuwihan rubak layar 320, 360, 411, atawa 480 dp, lantaran dina HP layar leutik elemen kitu bisa katutup atawa luber. Elemen jeung rubak match_parent atawa wrap_content nyaluyukeun layar sacara otomatis sarta teu perlu dipariksa.

Pangatur Sumber Daya
Pikeun ningali jeung ngatur kabéh sumber daya proyék dina hiji tempat (kawas Pangatur Sumber Daya dina Android Studio): buka Pangatur Sumber Daya dina ménu utama, pilih proyék, tuluy pencét Lihat Sumber Daya. IDE ngalaporkeun jumlah jeung ukuran bérkas per kategori (drawable, layout, values, mipmap, jeung lianna), eusi strings.xml, colors.xml, jeung styles.xml. Ti layar nu sarua, string anyar bisa ditambahkeun ka strings.xml jeung warna anyar ka colors.xml ku ngeusi ngaran jeung nilaina — ngaran dipariksa jeung duplikat ditolak, sangkan bérkas XML teu ruksak.

Pamantau Kinerja Ringan
Pikeun ngawaskeun pamakéan RAM jeung prosésor aplikasi nu keur jalan (kawas Profiler dina Android Studio, vérsi hampang): buka Pamantau Kinerja Ringan dina ménu utama, jalankeun heula aplikasi nu rék dipariksa (misalna aplikasi hasil wanguna nu keur dicoba), eusi ngaran pakétna — atawa pilih proyék tuluy pencét Isi Nama Paket dari Proyek — tuluy pencét Mulai Pantau. Unggal 2 detik IDE nyatet RAM (PSS) jeung CPU aplikasi éta bareng jeung RAM HP nu bébas; pencét Berhenti pikeun ningali ringkesan rata-rata jeung puncakna. Tanpa idin tambahan. Dina Android vérsi anyar, aksés baca prosésor aplikasi séjén diwatesan sistem, jadi lamun CPU teu kabaca, laporan nyebutkeunana sakumaha ayana sarta RAM tetep kapantau.

Audit Aksesibilitas
Pikeun mariksa naha layout proyék ramah pamaca layar (TalkBack/Jieshuo) sateuacan dirilis: buka Audit Aksesibilitas dina ménu utama, pilih proyék, teras pencét Muat Daptar Layout sareng pilih berkas layout. IDE maca berkas XML éta sareng ngalaporkeun tombol tanpa labél sareng nomer barisna, labél anu dianggo sababaraha kali, sareng unsur anu silih tumpang, teras nyusun transkrip urutan fokus sapertos anu dibacakeun ku Jieshuo. Upami aya tombol tanpa labél, eusian labélna teras pencét Sisipkeun Labél Otomatis — labél ditulis kana berkas layout minangka contentDescription. Pamariksaan ieu ngan maca layout XML; tampilan Compose sareng APK jadi can dipindai.

Autopsi Crash
Pikeun nyaho naha aplikasi nutup sorangan, tina log crash jeung ID unik: buka «Autopsi Crash» dina menu utama, pilih ID crash tina daptar log, tuluy pencét «Pariksa». IDE nyocokkeun kelas jeung nomer baris dina log jeung sumber proyék jeung ngajelaskeun sababna dina basa Indonesia (contona référénsi kosong, idin can dipénta, atawa kasalahan JSON), jeung saran tambalan kode. Pencét «Larapkeun Tambalan» ngan nalika baris sumber masih sarua persis kawas nalika crash kajadian; lamun geus robah, tambalan ditolak jeung IDE ménta anjeun mariksa sorangan. Pikeun crash aplikasi nu dijieun, pencét «Selapkeun Penangkap Crash kana Proyék», tuluy jieun APK sakumaha biasa: aplikasi nu dijieun éta nangkep crashna sorangan jeung nulis logna dina HP, jeung log éta bisa kapanggih maké tombol «Pilari Log Crash Aplikasi nu Dijieun». Wates jujur: nyalin log ka folder Download umum dina Android 11 ka luhur bisa gagal tanpa idin aksés sakabéh file.

Transpiler Lintas-Paradigma
Pikeun ngarobih kode Java saderhana janten Kotlin, atanapi layout XML saderhana janten kode Compose: buka Transpiler Lintas-Paradigma dina ménu utama, pilih proyék sareng berkas, teras pencét Pratinjau. IDE nampilkeun hasil konvérsi minangka téks — pariksa heula, sabab baris anu teu dikenal ditinggalkeun sakumaha ayana sareng kecap static dina Java dileungitkeun dina Kotlin (pariksa hartina sateuacan dianggo). Konvérsi XML ka Compose ngan ngarobih téks, hint, sareng orientasi — ukuran, warna, sareng atribut sanésna can kaasup. Upami hasilna leres, pencét Larapkeun kana Berkas pikeun nulis berkas tujuan; berkas sumber henteu dirobih. Ngan pola umum anu aman anu dikonvérsi.

Server Mikro Lokal
Pikeun nguji aplikasi nu butuh server tanpa internét: buka «Server Mikro Lokal» dina menu utama, tulis definisi rute (contona GET /halo tuluy jawaban JSONna), tuluy pencét «Mimitian Server». IDE ngajalankeun server HTTP leutik dina HP nu sarua (ngan HTTP, tanpa TLS, pikeun jaringan Wi-Fi nu sarua) jeung nyatet unggal paménta jeung jawaban dina layar. Rute bisa maké parameter kawas {nama} jeung konci API basajan. Server ogé bisa dipakét kana APK nu dijieun: pencét «Pakét Server kana Proyék», jeung sumber server, aset, jeung manifes diselapkeun kana proyék, jadi aplikasi nu dijieun sorangan jadi server nalika jalan. Server dina IDE eureun nalika layarna ditutup.

Auditor Kaamanan
Pikeun mariksa kode proyék pikeun longgar kaamanan saméméh dirilis: buka «Auditor Kaamanan» dina menu utama, pilih proyék, tuluy pencét «Mimitian Pamindaian». Studio Sistem Desain

Refactoring Semantik jeung Navigasi AST
Pikeun néangan definisi jeung ngarobah ngaran simbol tanpa ngaruksak kode séjén nu kabeneran mibanda ngaran nu sarua: buka «Refactoring Semantik jeung Navigasi AST» dina menu utama, pilih proyék, tuluy pencét «Pindai Simbol Proyék» pikeun nempo sakabéh kelas jeung métode jeung file jeung nomer barisna. Debugger Léngkah jeung Inspektur Mémori

Debugger jejak ieu masih nuturkeun jejak nu dirékam atawa ditulis leungeun; di gigireunana aya klien Java murni protokol kabel JDWP nu bisa handshake, nempatkeun breakpoint, léngkah asup, léngkah luhur, jeung léngkah kaluar, jeung eureun jeung neruskeun VM liwat TCP atawa dina mode ngadengekeun. Ngeureunkeun prosés nyata ti jero aplikasi biasa masih teu bisa sapinuhna, sabab soket JDWP hiji prosés ngan katingali liwat adbd — jalur nu geus kabuktian butuh debugging nirkabel jeung ngajalankeun target liwat shell, di luar naon nu bisa dipigawé ku aplikasi sorangan.

Ucapkeun paréntah dina basa Indonésia, misalna buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil, atanapi buat variabel teks nama sama dengan Budi — IDE ngarobih ucapan janten blok kode Java, Kotlin, Python, atanapi Compose anu sah sintaksis sareng nyelapkeunana dina posisi kursor, teras maca ringkesanana liwat Jieshuo. Dikte nganggo layanan input sora bawaan sistem, tanpa idin mikropon tambahan, sareng ngan ngakuan pola paréntah anu parantos kadaptar; ucapan di luar pola teu dirobih janten kode. Angka anu diucapkeun ku kecap (misalna 'lima') can dirobih janten digit.

Ruang Kolaborasi Lokal (tanpa internét)
Pikeun damel bareng dina hiji rohangan tanpa internét: buka Kolaborasi dina ménu utama, teras buka bagian Ruang Kolaborasi Lokal. Hiji HP muka sesi (IDE nampilkeun alamat IP lokal sareng PIN 6 digit), HP sanésna gabung sareng alamat sareng PIN éta. Parobihan téks dikirim minangka selisih baris, APK hasil build tiasa dikirim ka HP panguji, sareng laporan crash ti HP panguji ditampi deui. Hiji sesi ngan pikeun hiji sobat; upami dua urang ngarobih baris anu persis sami dina waktos anu sami, parobihan pamungkas anu dianggo. PIN dikirim minangka téks biasa dina jaringan lokal. Rohangan ieu can diuji dina HP nyata.

Setélan AI
Pikeun nyetél panyadia AI jeung konci API pikeun nyieun aplikasi: dina menu utama, dina grup setélan, pencét «Setélan AI» (di gigireun tombol «Konéktor»). Pilih panyadia nu rék dipaké tina daptar nu sadia, jeung centang «Ganti modél nalika provider error» sangkan lamun hiji modél gagal, IDE sacara otomatis nyoba modél salajengna tina panyadia nu sarua. Pencét «Kokolakeun Konci API» pikeun nambahkeun konci cadangan (ketik ngaran jeung konci, tuluy pencét «Simpen»; konci ditembongkeun ditutupan, ngan 4 karakter pamungkas nu katingali). Konci disimpen dina HP jeung teu pernah dikirim ka mana waé kajaba panyadia nu dipilih nalika nyieun aplikasi. Panyadia nu dipilih ayeuna bener-bener dipaké ku «Arsitek Cetak Biru Proyék» jeung «Narator Alur Logika Kode»; nyieun aplikasi dina layar «Pembuat Aplikasi AI» masih maké AI lokal dina HP (tanpa internét).

Konéktor
Pikeun nganalisis APK teras ngirimkeunana: dina ménu utama, dina kelompok Setélan, pencét Konéktor (di gigireun tombol Setélan AI). Pilih berkas APK tina HP, IDE maca eusina (nami paket, vérsi, daptar aktivitas), teras pencét Kirim APK pikeun ngirimkeunana liwat bagikeun sistem (misalna WhatsApp atanapi Drive).

Basa jeung Sora
Pikeun ngaganti basa aplikasi: buka Setélan, teras Basa Aplikasi, teras pilih basa atanapi Nuturkeun Sistem. Tampilan utama sareng kalolobaan layar langsung robih kana basa anu dipilih tanpa kedah nutup atanapi ngamimitian deui aplikasi; sababaraha layar (misalna Terminal, Kolaborasi, Setélan AI, sareng Kokolakeun Konci) masih nganggo basa lami dugi ka dibuka deui. Upami milih Nuturkeun Sistem, basa nuturkeun basa sistem HP.

Tanda Tangan Bawaan per Proyek dan Anti Tamper
Ti vérsi 5.7, proyék nu teu maké tanda tangan pribadi ditandatanganan ku konci bawaan HUSUS proyék éta sorangan (dijieun sakali dina folder tanda-tangan-bawaan di jero proyék, tuluy dipaké terus), jadi tanda tangan bawaan béda-béda antarproyék — teu deui hiji konci babarengan pikeun sakabéh aplikasi. Ulah pupus folder tanda-tangan-bawaan: tanpa konci éta, APK anyar teu bisa nimpa APK lila proyék nu sarua. Setélan tiap proyék (arsitéktur misah, tanda tangan pribadi, anti tamper, keystore kapilih, SDK) ayeuna disimpen dina bérkas settings.gradle di jero proyék sarta dibaca deui unggal proyék diwangun. Dina Setélan kategori Tanda Tangan aya centang Anti tamper aplikasi hasil build: lamun aktif, aplikasi hasil wanguna dina perangkat mariksa tanda tangan jeung eusi dex-na unggal dibuka; lamun ditandatanganan deui atawa dirobah ku batur, aplikasi nolak jalan. Debugger jeung pakakas injeksi kawas Frida/Xposed ogé kadeteksi, sarta jandéla aplikasi dikonci ti rékaman layar.

Panyieun Pidéo Démo
Pikeun nyieun pidéo démo aplikasi hasil: buka Panyieun Pidéo Démo dina ménu utama, pilih proyék, eusi judul pidéo, tuluy pencét Buat Skrip Video Demo — IDE nulis video-demo.txt nu eusina 5 adegan baku (bubuka, tampilan utama, fitur 1, fitur 2, panutup) bareng jeung téks narasi jeung durasi tiap adegan. Pencét Buat Slideshow HTML pikeun nyieun video-demo.html ti gambar-gambar proyék (ikon + tangkapan layar lamun aya) nu ganti otomatis unggal 5 detik. Ieu BUKAN pidéo .mp4 — pikeun pidéo sabenerna, buka video-demo.html dina browser HP tuluy rekam layar, atawa baca narasi dina video-demo.txt bari ngarékam aplikasi nu keur jalan.

Pidangan Énggal ala Android Studio
Pidangan IDE ayeuna dirapikeun kawas Android Studio (ngan pidanganana wungkul — sakabéh tombol, ménu, jeung alur tetep sarua kawas saméméhna): latar abu caang, judul layar kandel warna hideung, tombol biru jeung téks bodas, jeung kotak eusi bodas berbingkai ipis. Ménu utama dikelompokkeun sacara visual (Fitur Panyieun, Cloud Téma & Séjénna, Sora Kode & Fitur Anyar, Pakakas) tanpa ngarobah urutan tombol. Terminal tetep maké panel poék kawas jandéla Terminal dina Android Studio, sarta éditor kode tetep berlatar bodas jeung téks hideung. Sakabéh téks tetep kabaca jelas ku Jieshuo.

Setélan
Pikeun ngatur aplikasi: buka ménu Pilihan dina layar utama tuluy pencét Setélan. Di jerona aya 12 kategori: Setelan GitHub (kaamanan, tanda tangan pribadi, history build, jeung token GitHub), Setelan Wangun APK Perangkat (simpen kecap konci keystore jeung history build dina perangkat), Téma (warna aplikasi), Tanda Tangan (jieun keystore pikeun tanda tangan pribadi jeung centang anti tamper aplikasi hasil build), Folder Proyek (lokasi folder proyék), Basa jeung Sora (basa antarmuka jeung kagancangan sora Mode Sora), Ukuran Téks jeung Pidangan (ukuran font éditor), Build (SDK target bawaan jeung pisah arsitéktur bawaan pikeun layar Jieun Proyek), Bewara (sora nalika wanguna réngsé), Cadangan Otomatis (jadwal cadangan proyék), Profil Pamekar (ngaran, nomer WhatsApp, jeung rekening nu tampil dina layar Donasi), sarta Privasi jeung Data (reset setélan jeung pupus data aplikasi). Unggal kategori mibanda tombol Balik ka Samemehna pikeun balik ka ménu kategori. Setélan nu kakara disimpen wungkul (can diterapkeun) ditulis kateranganana dina layar kalawan jujur.

Donasi ka Pamekar
Pikeun donasi atawa nyapa pamekar: pencét tombol Donasi ka Pamekar dina layar utama, di gigireun tombol Ngeunaan Parabot. Dina layar donasi aya tombol Salin Rekening BRI — pencét pikeun nyalin nomer rekening pamekar, tuluy témpél dina aplikasi bank anjeun. Aya ogé bagéan Sapa Pengembang di WhatsApp: eusi ngaran jeung kota asal, tuluy pencét Kirim di WhatsApp — WhatsApp kabuka jeung pesen sapaan geus dieusi otomatis, tinggal pencét Kirim di WhatsApp tuluy balik ka aplikasi. WhatsApp teu ngidinan aplikasi séjén ngirim pesen sacara otomatis, jadi pangiriman tetep dilakukeun sorangan dina WhatsApp.

Paréntah Favorit Terminal
Pikeun nyimpen paréntah nu mindeng dipaké dina Terminal: buka Terminal tuluy pencét Favorit. Toél Tambih favorit énggal, eusi ngaran (misalna Tingali bérkas) jeung paréntahna (misalna ls -la), tuluy pencét Simpen — favorit disimpen permanén dina HP. Toél ngaran favorit pikeun langsung ngajalankeunana dina terminal; toél Pupus favorit tuluy pilih hiji pikeun mupusna (jeung konfirmasi). Geus aya 3 favorit bawaan: Tingali bérkas (ls -la), Cék rohangan (df -h), jeung Beresihkeun layar (clear) — sadayana bisa dipupus. Paréntah kosong teu bisa disimpen atawa dijalankeun; Terminal méré nyaho ngaliwatan pesen jeung sora lamun hal éta kajadian.

Analitik & Kualitas
Pikeun ningali ringkesan pamakéan aplikasi jeung laporan crash: pencét tombol Analitik & Kualitas dina layar utama, di gigireun tombol Donasi ka Pamekar. Layar ieu nampilkeun sabaraha kali aplikasi dibuka, layar nu pang mindeng dibuka, jumlah crash, jeung daptar crash panungtung bareng jeung saran leresan singget. Data ieu ngan disimpen dina HP anjeun sarta teu dikirim ka mana waé. Aya tombol Hapus Data Analitik jeung dialog konfirmasi pikeun mupus sakabéh data éta. Layar panungtung ngan kacatet pikeun layar utama jeung layar ieu.

Panutup
Hatur nuhun geus maké Create Aplikasi. Mugi pakakas ieu ngabantu anjeun jeung saha waé nu hayang diajar nyieun aplikasi Android ti telepon. Lamun aya kendala, lereskeun léngkah demi léngkah ti panduan ieu, sarta ulah ragu pikeun nyoba deui.
