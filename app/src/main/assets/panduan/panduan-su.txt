Wilujeng sumping di Create Aplikasi by Al Kautsar
Create Aplikasi nyaéta aplikasi pikeun nyieun aplikasi Android anu jalan langsung dina telepon, tanpa merlukeun laptop. Aplikasi ieu ngidinan saha waé nyieun aplikasi Android sorangan, kaasup pangguna anu kakara diajar nyieun aplikasi jeung pangguna pamaca layar. Pituduh lengkep pikeun ngagunakeun aplikasi ieu sayogi dina layar Tentang Alat ieu.

Aplikasi ieu téh naon jeung pikeun saha
Create Aplikasi nyaéta pakakas pikeun nyieun aplikasi Android anu jalan dina telepon. Aplikasi ieu ditujukeun pikeun saha waé anu hayang nyieun aplikasi Android sorangan, kaasup pamula jeung pangguna pamaca layar. Aplikasi ieu nyayogikeun éditor kode, tombol Jalankan pikeun nguji proyek, tombol Bangun pikeun nyieun APK, sarta menu pikeun nandatanganan jeung masang APK.

Tujuan aplikasi ieu
Aplikasi ieu dijieun sangkan saha waé bisa nyieun aplikasi Android sorangan kalawan gampang, langsung tina telepon. Pidanganna dijieun sasingkat mungkin sangkan pangguna anyar ogé bisa langsung nyobaan.

Cara nyieun proyek anyar, léngkah demi léngkah
1. Pencét Buat Project dina menu utama.
2. Pilih jenis proyek: HTML, Situs Web, Java, Kotlin, Compose, atawa Python.
3. Eusian ngaran aplikasi, conto: Garuda Decode.
4. Eusian ngaran pakét (package name), conto: com.android.garudadecode. Ngaran pakét kudu ngagunakeun aksara leutik jeung diwangun ku sahenteuna dua bagian anu dipisahkeun ku titik.
5. Eusian vérsi aplikasi, conto: 1.0, jeung kode vérsi dina wangun angka, conto: 1. Lamun dikosongkeun, vérsi bakal dieusian otomatis ku 1.0 jeung kode vérsi 1.
6. Eusian SDK minimum jeung SDK target lamun diperlukeun. Lamun dikosongkeun, nilai bawaan bakal digunakeun. SDK minimum nyaéta vérsi Android panghandapna anu didukung, conto: 21 hartina Android 5.0. SDK target maksimum nyaéta 36 (Android 16).
7. Pencét tombol Pilih Izin pikeun milih idin aplikasi, conto: INTERNET. Idin INTERNET geus dicirian sacara bawaan. Cirian ukur idin anu memang diperlukeun ku aplikasi.
8. Lamun dipikahayang, cirian "Gunakan arsitektur terpisah 64 bit dan 32 bit" sangkan ukuran APK leuwih leutik, jeung cirian "Gunakan tanda tangan pribadi" lamun hayang ngagunakeun keystore jieunan sorangan.
9. Pencét Buat Proyek. Proyek anyar disimpen dina folder Download/project jeung langsung katémbong dina Kelola Project.

Jenis proyek anu sayogi
• HTML: pidangan tina index.html, style.css, jeung script.js, jalan ngaliwatan WebView. Dijieun langsung dina telepon.
• Situs Web: website kalawan menu (Beranda, Tentang, Kontak) tina index.html, tentang.html, kontak.html, style.css, jeung script.js, jalan ngaliwatan WebView. Dijieun langsung dina telepon.
• Java: dijieun dina telepon. MainActivity aya di app/src/main/java/<nama-paket>/MainActivity.java. Pidangan tina app/src/main/res/layout/activity_main.xml, téks tina app/src/main/res/values/strings.xml, jeung téma tina app/src/main/res/values/styles.xml.
• Kotlin: bisa dijieun dina alat (offline) ngagunakeun compiler Kotlin anu kaasup dina aplikasi, atawa ngaliwatan GitHub Actions. MainActivity aya di app/src/main/java/<nama-paket>/MainActivity.kt, jeung berkas res sarua jeung proyek Java. Bangun Kotlin munggaran leuwih lila kusabab ukuran compiler anu gedé, jeung berkas .java anu ngarujuk kelas Kotlin tacan bisa dijieun (berkas .java dikompilasi heula saméméh berkas .kt).
• Compose: aplikasi Android modéren anu antarbeungeutna dijieun ku Jetpack Compose (lain layout XML). MainActivity aya di app/src/main/java/<nama-paket>/MainActivity.kt. Proyek Compose dijieun ngaliwatan GitHub Actions (menu Bangun proyek, tuluy Bangun online) atawa di Termux ku Gradle, kusabab Compose merlukeun pustaka Jetpack Compose anu teu sayogi dina alat.
• Python: logika aplikasi ditulis dina basa Python (Chaquopy) di app/src/main/python/main.py, jeung dijalankeun ku host MainActivity.java di app/src/main/java/<nama-paket>/MainActivity.java. Proyek Python bisa dijieun langsung dina telepon (runtime Chaquopy kaasup dina aplikasi) atawa ngaliwatan GitHub Actions. SDK minimum proyek Python nyaéta 24 (Android 7.0).

Susunan berkas proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python
Proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python disusun kawas proyek Android umumna. Di jero folder app aya folder src, jeung di jerona aya folder main. Di jero folder main aya AndroidManifest.xml di gigireun folder java, folder res anu ngandung layout/activity_main.xml jeung values/strings.xml sarta values/styles.xml, jeung pikeun HTML jeung Situs Web aya folder assets anu ngandung index.html (Situs Web ogé mibanda tentang.html jeung kontak.html). Proyek HTML jeung Situs Web ogé mibanda MainActivity sorangan di app/src/main/java/<nama-paket>/MainActivity.java, anu ngamuat index.html dina WebView jeung jadi launcher dina AndroidManifest. Proyek Python mibanda kode Python di app/src/main/python/main.py jeung host MainActivity.java di app/src/main/java/<nama-paket>/MainActivity.java. AndroidManifest.xml, layout, strings, jeung styles bisa dibuka jeung dirobah dina éditor, sarua jeung MainActivity. Proyek heubeul anu manifest-na masih aya di gigireun folder app masih bisa dijieun, kusabab nalika nyieun, aplikasi mariksa AndroidManifest.xml di app/src/main/ heula, tuluy anu di gigireun folder app, jeung pamungkas berkas data proyek.

Aturan idin (penting)
Idin anu dicirian nalika nyieun proyek ukur kacatet di hiji tempat, luyu jeung jenis proyekna. Pikeun proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python, idin anu dicirian kacatet UKUR dina AndroidManifest.xml anu aya di app/src/main/, di gigireun folder java, di jero folder proyek. Berkas data proyek pikeun proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python teu ngandung daptar idin. Lamun milih Java tuluy nyirian INTERNET jeung CAMERA, anu kacatet dina AndroidManifest.xml ukur INTERNET jeung CAMERA, tanpa idin séjén anu milu. Nalika nyieun, aplikasi maca idin tina tempat anu sarua: tina AndroidManifest.xml di app/src/main/ pikeun proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python (lamun euweuh, tina AndroidManifest.xml di gigireun folder app pikeun proyek heubeul), jeung tina berkas data proyek pikeun proyek heubeul.

Cara ngagunakeun éditor
Buka Kelola Project, toél ngaran proyek pikeun muka éditor. Dina éditor, berkas bisa dibuka, kode bisa ditulis, jeung parobahan bisa disimpen. Pikeun proyek Java, HTML, Situs Web, Kotlin, Compose, jeung Python, berkas disusun di jero folder app/src/main. Pikeun ngabagikeun proyek, gunakeun Ekspor ZIP (tempo bagian di handap).

Cara ngajalankeun proyek
Dina éditor, pencét Jalankan pikeun nguji proyek. Pikeun proyek HTML jeung Situs Web, anu dijalankeun nyaéta index.html ngaliwatan WebView. Lamun aya kasalahan, baca pesen kasalahanana, benerkeun kode, tuluy jalankeun deui.

Cara nyieun APK
Dina éditor, pencét Bangun. Aya dua cara nyieun. Kahiji, Bangun di perangkat: nyieun langsung dina telepon tanpa internét, pikeun proyek HTML, Situs Web, Java, Kotlin, jeung Python. Kadua, Bangun online ngaliwatan GitHub Actions: nyieun ngaliwatan internét di GitHub, jeung bisa digunakeun pikeun sakabéh jenis proyek. Proyek Compose ukur bisa dijieun ku cara kadua (Bangun online) atawa di Termux ku Gradle, kusabab Compose merlukeun pustaka Jetpack Compose anu teu sayogi dina alat. Hasil bangun munggaran tacan ditandatanganan. Sanggeus éta aplikasi nandatangananna: otomatis ku konci bawaan, atawa ku tanda tangan pribadi lamun kotak "Gunakan tanda tangan pribadi" dicirian nalika nyieun proyek.

Cara masang APK
Lamun APK geus jadi, pencét Pasang pikeun masangna. Dina Android 8 ka luhur, telepon bakal ménta "Izinkan dari sumber ini" heula, kusabab aplikasi ieu masang APK ti luar Play Store. Aktipkeun idin éta sakali dina Pengaturan, tuluy balik deui ka aplikasi: pamasangan bakal nuluykeun otomatis tanpa kudu mencét Pasang deui. Lamun tombol Pasang teu némbongan, pastikeun bangun geus réngsé jeung APK geus dijieun.

Cara nandatanganan aplikasi
Unggal APK kudu ditandatanganan sangkan bisa dipasang. Sayogi dua pilihan. Kahiji, konci bawaan: aplikasi nandatanganan sorangan sacara otomatis, tanpa kudu ngalakukeun nanaon. Kadua, tanda tangan pribadi: jieun heula keystore ngaliwatan menu Buat Keystore dina menu utama, simpen kecap sandina kalawan alus, tuluy cirian "Gunakan tanda tangan pribadi" nalika nyieun proyek. Keystore disimpen di Download/project/signing.

Ékspor proyek jadi ZIP
Ekspor ZIP disayogikeun sangkan proyek bisa dibagikeun ka babaturan. Carana: dina Kelola Project, tahan lila ngaran proyek, tuluy pilih Ekspor ZIP. Hasilna disimpen di Download/project/<NamaProyek>.zip. Folder bin teu milu diasupkeun, ku kituna ukuranana leutik, ukur puluhan KB. Berkas ZIP éta bisa dikirim ka babaturan atawa diunggah ka GitHub.

Éksténsi JAWS
Éksténsi JAWS ngagunakeun mesin éksténsi ti Jieshuo (CSR), lain pamaca layarna. Ku kituna, rancangan masih bisa jalan sanajan pangguna ngagunakeun TalkBack. Carana: buka Ekstensi JAWS dina menu utama. Kusabab klik otomatis jalan sorangan, layanan kudu diaktipkeun heula dina Pengaturan Aksesibilitas. Sanggeus éta, rancangan anyar bisa dijieun: ketik ngaran rancangan, pencét OK, tuluy eusian kotakna.

Daftar Klik dipisahkeun sangkan rapih
Di jero rancangan aya dua kotak: kotak skrip jeung kotak Daftar Klik. Daptar tombol disimpen misah dina berkas daftar_klik.txt, hiji ngaran per baris. Conto eusina: tombolSimpan, tombolHapus, tombolBuka. Pikeun muka aplikasi, tulis waé >WhatsApp dina daptar éta. Rancangan heubeul anu tacan mibanda berkas daftar_klik.txt bakal némbongkeun conto bawaan éta.

Fungsi basajan anu disayogikeun
• klikTombol("tombolSimpan") — ngaklik hiji tombol dumasar kana téksna.
• klikDaftarTombol(daftar) — ngaklik daptar dina daftar_klik.txt, hiji tombol per baris, ngaruntuy, tuluy ngabéjaan sabaraha anu hasil jeung sabaraha anu teu kapanggih.
• bukaAplikasi("WhatsApp") — muka aplikasi dumasar kana ngaranna, atawa tulis ">WhatsApp" dina daptar.
• klik(540, 1200) — ngaklik dina koordinat layar.
Sakabéh fungsi dijieun basajan heula. Lamun geus biasa, fungsi tambahan bisa ditambahkeun engké.

Ngeunaan pamaca layar
Aplikasi ieu dirancang sangkan ramah pamaca layar. Unggal kolom eusian mibanda labél jeung conto ngeusian, jeung sakabéh tombol bisa kahontal tanpa gestur anu riweuh. Éksténsi JAWS dijieun sangkan masih jalan sanajan pangguna ngagunakeun TalkBack, kusabab anu digunakeun nyaéta mesin éksténsina, lain pamaca layarna.

Privasi jeung kaamanan
Proyek jeung keystore disimpen dina telepon anjeun. Token GitHub ukur dipaké pikeun bangun online jeung disimpen di jero aplikasi ieu. Ulah ngabagikeun token atawa kecap sandi keystore anjeun ka saha waé. Lamun ngagunakeun tanda tangan pribadi, simpen keystore jeung kecap sandina di tempat anu aman, kusabab lamun leungit, APK heubeul teu bisa dianyarkeun ku tanda tangan anu sarua.

Kabutuhan
Android 5.0 atawa leuwih anyar. Idin panyimpenan: dina Android 11 ka luhur ngagunakeun idin aksés sakabéh berkas, dina Android 10 ka handap ngagunakeun idin panyimpenan biasa (maca/nulis panyimpenan) kusabab Android 10 teu mibanda idin aksés sakabéh berkas. Nyieun dina alat merlukeun telepon anu prosésorna ARM (32 atawa 64 bit). Nyieun online ngaliwatan GitHub Actions merlukeun internét jeung token GitHub. Proyek Kotlin bisa dijieun dina alat, tapi bangun munggaranna leuwih lila jeung ngagunakeun memori leuwih loba kusabab ukuran compiler Kotlin anu gedé. Proyek Compose dijieun ngaliwatan GitHub Actions atawa di Termux ku Gradle. Proyek Python merlukeun Android 7.0 atawa leuwih anyar (SDK minimum 24) jeung APK hasilna leuwih gedé kusabab ngasupkeun runtime Python (Chaquopy) jeung pustaka bakuna.

Terminal
Menu Terminal dina layar utama muka terminal di jero aplikasi ieu. Paréntah saperti ls bisa digunakeun pikeun ningali eusi folder proyek, cd pikeun pindah folder, jeung git pikeun ngatur kode. Kaluaran paréntah némbongan minangka téks anu bisa dibaca ku pamaca layar, jeung aya tombol Bacakan hasil pikeun ngadéngékeun hasil pamungkas. Terminal ieu ngagunakeun shell sistem telepon, ku kituna program interaktif saperti nano jeung vim tacan bisa dipaké di dieu.

Lisénsi (vérsi mayar)
Pikeun ngajual aplikasi, cirian "Aktifkan Lisensi" nalika nyieun proyek, tuluy eusian nomer WhatsApp anjeun. Aplikasi hasil bangun bakal ménta kode lisénsi nalika mimiti dibuka: pangguna ningali ID alatna, mencét tombol Kirim ID Perangkat pikeun ngirim ID éta ka WhatsApp anjeun, tuluy anjeun ngawalon ku kode lisénsina. Kode lisénsi diitung tina ID alat jeung kecap sandi proyek (lisensi_seed dina berkas data proyek) — simpen kecap sandi éta kalawan alus jeung ulah dibagikeun. Sanggeus kode anu bener diasupkeun, aplikasi kabuka jeung teu ménta kode deui.

Pembuat Ikon Otomatis
Ikon proyek anyar masih transparan, ku kituna sayogi Pembuat Ikon dina menu utama. Carana: pencét Pembuat Ikon, tulis hiji atawa dua aksara (contona inisial ngaran aplikasi), pilih warna latar jeung warna tulisan, tempo pratayangna, tuluy pencét Simpan ke Proyek pikeun ngagunakeun ikon éta dina proyek anu dipilih, atawa Simpan ke Download pikeun ngagunakeun berkas PNG-na di tempat séjén. Sanggeus proyek dijieun, aplikasi ogé nawaran nyieun ikon. Ikon heubeul proyek bisa diganti iraha waé tina menu proyek dina Kelola Project (tahan lila ngaran proyek, tuluy pilih Ganti Ikon).

Template Proyek Siap Pakai
Lamun teu hayang ngamimitian tina proyek kosong, pilih template nalika nyieun proyek: Kalkulator (Java), Catatan (Java), Daftar Tugas (Kotlin), Kalkulator Web (HTML), Situs Profil (Situs Web), atawa Penghitung (Compose). Milih template sacara otomatis ngarobah jenis proyek nuturkeun template éta, jeung proyek dijieun ku kode awal anu geus jadi — kari dijalankeun atawa dirobah. Lamun jenis proyek dirobah deui sacara manual sanggeus milih template, template dibatalkeun jeung proyek balik kosong. Pikeun template HTML jeung Situs Web, template ngaganti eusi index.html, kaasup skrip HTML anu diketik dina form.

Cadangan jeung Pulihkan Proyek
Sangkan proyek teu leungit, sayogi fitur cadangan. Carana: dina Kelola Project, tahan lila ngaran proyek, tuluy pilih Cadangkan. Cadangan disimpen minangka ZIP dina folder Download/backup kalawan ngaran proyek jeung tanggal, conto: GarudaDecode-2026-11-14-123045.zip. Eusina sarua jeung Ekspor ZIP (sakabéh eusi proyek, tanpa folder bin). Pikeun mulihkeun: buka menu dina Kelola Project, pilih Pulihkan cadangan, tuluy pilih berkas cadanganana. Lamun ngaran proyek geus aya, aplikasi bakal nanyakeun: Timpa proyek lama, atawa simpen ku Nama baru.

Bagikan jeung Impor Proyek
Pikeun ngabagikeun proyek ka babaturan: dina Kelola Project, tahan lila ngaran proyek, tuluy pilih Bagikan. Proyek dikirim minangka ZIP ngaliwatan aplikasi babagi (WhatsApp, Telegram, jeung sajabana). Pikeun nampa proyek ti babaturan: buka menu dina Kelola Project, pilih Impor proyek, tuluy pilih berkas ZIP-na. Berkas ZIP éta kudu ngandung berkas data proyek — lamun euweuh, berkas ditolak ku pesen anu jelas, kusabab berkas éta lain proyek Create Aplikasi. Lamun ngaran proyek geus aya, aplikasi bakal nanyakeun: Timpa proyek lama, atawa simpen ku Nama baru.

Pencarian jeung Filter Proyek
Lamun proyek geus loba, dina Kelola Project aya kotak pencarian jeung panyaring jenis. Ketik ngaran proyek dina kotak pencarian, daptar langsung kasaring (aksara gedé jeung leutik teu dibédakeun). Panyaring jenis ngawatesan daptar kana hiji jenis wungkul: Semua, HTML, Situs Web, Java, Kotlin, Compose, atawa Python. Menu unggal proyek masih bisa dibuka saperti biasa tina daptar anu geus kasaring.

Wangun Aplikasi ku Suara
Upami henteu hoyong ngetik, anggo sora: pencét Ngawangun ku Sora dina ménu utama, teras ucapkeun paréntah. Paréntah anu tiasa diucapkeun: "Buat proyek kalkulator", "Bangun proyek Kalkulator", "Buka proyek Kalkulator", "Jalankan proyek Kalkulator", "Daftar proyek", "Buka ikon", "Kembali", sareng "Bantuan". Aplikasi ngajawab ku sora sareng téks, janten tetep tiasa dianggo tanpa ningali layar. Pangwanoh sora nganggo aplikasi pangwanoh sora bawaan HP (gratis; tiasa jalan offline upami paket basa Indonésia parantos dipasang). Upami HP teu gaduh pangwanoh sora, paréntah tiasa ditulis dina kotak téks dina layar anu sami.

Audit Aksesibilitas
Pikeun mariksa naha layout proyék ramah pamaca layar (TalkBack/Jieshuo) sateuacan dirilis: buka Audit Aksesibilitas dina ménu utama, pilih proyék, teras pencét Muat Daptar Layout sareng pilih berkas layout. IDE maca berkas XML éta sareng ngalaporkeun tombol tanpa labél sareng nomer barisna, labél anu dianggo sababaraha kali, sareng unsur anu silih tumpang, teras nyusun transkrip urutan fokus sapertos anu dibacakeun ku Jieshuo. Upami aya tombol tanpa labél, eusian labélna teras pencét Sisipkeun Labél Otomatis — labél ditulis kana berkas layout minangka contentDescription. Pamariksaan ieu ngan maca layout XML; tampilan Compose sareng APK jadi can dipindai.

Autopsi Crash
Pikeun terang naha aplikasi nutup sorangan tina log crash anu ID na unik: buka Autopsi Crash dina ménu utama, pilih ID crash tina daptar log, teras pencét Pariksa. IDE nyocogkeun kelas sareng nomer baris dina log sareng sumber proyék teras ngajelaskeun sababna dina basa Indonésia (misalna rujukan kosong, idin anu can dipénta, atanapi galat JSON), sareng saran tambalan kode. Pencét Larapkeun Tambalan ngan upami baris sumberna masih persis sami sareng nalika crash lumangsung; upami parantos robih, tambalan ditolak sareng IDE ménta anjeun mariksa nyalira. Anu dibaca nyaéta log crash IDE sorangan, sanés log aplikasi hasil build.

Transpiler Lintas-Paradigma
Pikeun ngarobih kode Java saderhana janten Kotlin, atanapi layout XML saderhana janten kode Compose: buka Transpiler Lintas-Paradigma dina ménu utama, pilih proyék sareng berkas, teras pencét Pratinjau. IDE nampilkeun hasil konvérsi minangka téks — pariksa heula, sabab baris anu teu dikenal ditinggalkeun sakumaha ayana sareng kecap static dina Java dileungitkeun dina Kotlin (pariksa hartina sateuacan dianggo). Konvérsi XML ka Compose ngan ngarobih téks, hint, sareng orientasi — ukuran, warna, sareng atribut sanésna can kaasup. Upami hasilna leres, pencét Larapkeun kana Berkas pikeun nulis berkas tujuan; berkas sumber henteu dirobih. Ngan pola umum anu aman anu dikonvérsi.

Server Mikro Lokal
Pikeun nguji aplikasi anu butuh server tanpa internét: buka Server Mikro Lokal dina ménu utama, tulis définisi rute (misalna GET /halo teras jawaban JSON na), teras pencét Mimitian Server. IDE ngajalankeun server HTTP leutik dina HP anu sami (ngan HTTP, tanpa TLS, pikeun jaringan Wi-Fi anu sami) sareng nyatet unggal paménta sareng jawaban dina layar. Rute tiasa nganggo paraméter sapertos {nama} sareng konci API saderhana. Server ieu ngan pikeun pangujian dina HP; APK hasil build can janten server, sareng server eureun upami layarna ditutup.

Auditor Kaamanan
Pikeun mariksa liang kaamanan dina kode proyék sateuacan dirilis: buka Auditor Kaamanan dina ménu utama, pilih proyék, teras pencét Mimitian Pamindaian. IDE mindai kode, manifest, sareng konfigurasi proyék sareng ngalaporkeun pamanggih ti résiko luhur ka handap — konci API anu kakeunaan dina kode, komponén anu kakeunaan tanpa idin, WebView anu ngaktipkeun JavaScript sareng antarmuka JavaScript, kripto lemah (MD5, SHA1, DES), alamat http tanpa TLS, sareng kecap sandi anu ditulis langsung dina kode — sareng berkas sareng nomer barisna. Pikeun pamanggih anu perbaikanana aman (misalna ganti MD5 ka SHA-256 atanapi http ka https), pencét Larapkeun Parbaikan; pikeun konci API sareng kecap sandi, IDE ngan nampilkeun saran perbaikanana sabab panggantina kedah diputuskeun nyalira ku pangembang. Pamindaian ieu maca pola téks dina kode, sanés bytecode, janten tiasa aya pamanggih anu sabenerna aman, sareng liang anu teu boga pola tiasa lolos tina pamindaian — pariksa sateuacan nerapkeun.

Robot Panguji Antarmuka
Pikeun nguji tampilan aplikasi sacara otomatis liwat skénario téks: buka Robot Panguji Antarmuka dina ménu utama, pilih proyék, teras pencét Jieun Skénario Otomatis. IDE maca manifest sareng layout proyék teras nulis skénario awujud léngkah-léngkah téks (pencét tombol, eusian kolom, antosan, uih deui). Pencét Jalankeun Dry Run pikeun ningali log jalanna skénario sareng cap waktuna. Dina tahap ieu robot ngan ngajalankeun simulasi (dry run) — pencétan tombol nyata dina HP sareng néwak crash nyata nyaéta tahap salajengna, janten laporan crash di dieu masih awujud conto.

Perjalanan Waktu Kode
Pikeun mulangkeun proyék kana kaayaan kode saméméhna tanpa ngetik paréntah Git: buka Perjalanan Waktu Kode dina ménu utama, pilih proyék, eusian labél titik waktu (tiasa kosong), teras pencét Rékam Titik Waktu. IDE nyimpen salinan berkas sumber proyék sareng hash na dina polder .riwayat di jero proyék. Daptar titik waktu nampilkeun sadayana; pilih dua titik teras pencét Bandingkeun pikeun ningali berkas sareng fungsi anu ditambah, dirobih, atanapi dipupus. Pencét Mulangkeun pikeun mulangkeun kaayaan lami — sateuacan mulangkeun, IDE sok ngadamel cadangan kaayaan ayeuna heula, janten teu aya anu leungit. Pencét Jieun Salinan Ékspérimén pikeun nyalin proyék ka polder énggal sareng nyobian parobihan tanpa ngaganggu proyék aslina. Ngan berkas sumber anu dirékam.

Pabrik Modul
Pikeun ngemas bagian proyék janten modul anu tiasa dianggo ku proyék sanés: buka Pabrik Modul dina ménu utama, pilih proyék sumber, centang berkas layar, kelas, string, sareng idin anu rék dikemas, teras pencét Kemas minangka Modul. IDE nulis arsip ZIP sareng metadata JSON (nami modul, vérsi, string, sareng idin anu dianggo). Pikeun masang modul ka proyék sanés, buka Pabrik Modul, pilih proyék tujuan, teras pencét Pasang Modul sareng pilih berkas .zip modulna — panggabung nambihan string sareng idin tanpa nimpa kode anu parantos aya, sareng teu ngagabungkeun berkas upami namina parantos dianggo dina proyék tujuan. Modul teu mawa pustaka atanapi setélan build.

Perisai Polimorfik jeung Brankas Aset
Kanggo ngacak ngaran pangenal jeung ngenkripsi aset proyék saméméh dirilis: buka Perisai Polimorfik jeung Brankas Aset di ménu utama, pilih proyék, tuluy pencét Acak ngaran jeung enkripsi aset. IDE mindai ngaran kelas jeung métode dina kode sumber, nyieun peta ngaran acak, ngenkripsi berkas aset proyék maké AES-GCM ka folder brankas-aset di jero proyék, jeung nyimpen peta pamulihan anu dienkripsi (perisai-peta.brankas) sangkan ngaran asli bisa dipulihkeun nalika maca log crash. Konci enkripsi diturunkeun tina ngaran proyék, jadi saha waé anu nyaho ngaran proyék bisa muka brankasna — ieu panyalindungan tina dibaca iseng, lain brankas anu dikonci maké kecap sandi. Anu dijieun di dieu nyaéta peta ngaran jeung brankas aset; nulis ulang ngaran di jero berkas DEX hasil kompilasi téh tahap salajengna, jadi ngaran di jero APK anu geus jadi can milu diacak.

Rantai Kapercayaan jeung Penjaga Lingkungan
Kanggo mariksa rantai konci panandatanganan jeung lingkungan HP saméméh dirilis: buka Rantai Kapercayaan jeung Penjaga Lingkungan di ménu utama, pilih proyék, tuluy pencét Pariksa Rantai jeung Lingkungan. IDE ngawangun rantai konci 5 generasi tina ngaran pakét proyék jeung mariksa kauteuhanna, tuluy mindai peta mémori prosés sorangan jeung sipat alat pikeun tilas Frida, Xposed, atawa émulator. Hasilna nyaéta tingkat résiko Aman, Waspada, atawa Bahaya babarengan jeung bukti téksna. Pamariksaan ieu maca pola téks dina peta mémori jeung sipat sistem, lain integritas mémori asli di tingkat pustaka bawaan, jeung teu ngiket konci kana chip kaamanan perangkat keras — alat injeksi anu nyumputkeun tilas téksna bisa lolos tina pamindaian ieu.

Arsitek Tata Letak Tangkal Téks
Kanggo ngarancang tampilan tanpa ningali layar: buka Arsitek Tata Letak Tangkal Téks di ménu utama, pilih proyék jeung berkas layout, tuluy pencét Pariksa Tata Letak. IDE maca layout XML minangka tangkal téks jeung maca narasi posisi unggal elemen (misalna di katuhu handap, lébar 45 persén layar), tuluy ngalaporkeun tabrakan antar-elemen jeung elemen anu kaluar layar dina lébar 360 dp sacara matematis. Anu diitung nyaéta LinearLayout jeung ukuran dp saderhana; ConstraintLayout jeung tampilan Compose dilaporkeun posisina teu tangtu, lain ditebak.

Studio Sistem Desain
Kanggo nyaruakeun jarak, hurup, jeung sudut di sakabéh layar jeung proyék: buka Studio Sistem Desain di ménu utama, pilih proyék, tulis token desain (misalna jarak=8, huruf=16, sudut=12), pilih komponén, tuluy pencét Jieun Komponén. IDE mvalidasi token — jarak dasar 4 nepi ka 16 dp, hurup dasar 12 nepi ka 20 sp, sudut 0 nepi ka 32 dp, jeung aréa sentuh minimal 48 dp — tuluy nulis komponén XML siap pakai (komponen-studio.xml) babarengan jeung téma XML (tema-studio.xml) jeung téma Compose (tema-studio.kt) di folder proyék. Komponén dijieun minangka téks anu ditempelkeun kana layout tuluy dipariksa maké Arsitek Tata Letak; pangaturan dua kolom di tablet maké qualifier lébar layar, lain deteksi alat nalika ngajalankeun.

Refactoring Semantik jeung Navigasi AST
Kanggo néangan définisi jeung ngaganti ngaran simbol tanpa ngaruksak kode séjén anu kabeneran ngaranna sarua: buka Refactoring Semantik jeung Navigasi AST di ménu utama, pilih proyék, tuluy pencét Pindai Simbol Proyék pikeun ningali sakabéh kelas jeung métode babarengan jeung berkas jeung nomer barisna. Eusian ngaran simbol tuluy pencét Pindai Simbol Proyék deui pikeun ningali définisina jeung sakabéh berkas anu ngageroanana. Pikeun ngaganti ngaran, eusian ngaran anyar, pencét Pratinjau Ganti Ngaran pikeun ningali jumlah kamunculan di unggal berkas, tuluy pencét Terapkeun Ganti Ngaran. Pengindeks ieu maké pola téks, lain parser AST pinuh: ganti ngaran kelas lumaku di sakabéh berkas, sedengkeun ganti ngaran métode ngan di berkas pamilikna — pamanggil di berkas séjén teu milu dirobah, jadi pariksa pratinjau jeung hasil pindai pamanggil saméméh nerapkeun. Ékstraksi blok kode jadi fungsi anyar geus aya di mesin logika, tapi can aya tombolna di layar ieu.

Debugger Léngkah jeung Inspektur Mémori
Kanggo mariksa eusi variabel di tengah alur program tanpa nebak-nebak liwat log: buka Debugger Léngkah jeung Inspektur Mémori di ménu utama, pilih proyék, tulis jejak éksekusi (hiji léngkah per baris, wangunna nomer baris, kode, tuluy variabel jeung nilaina dipisah tanda |, misalna 10|int total = harga * jumlah;|harga=5000, jumlah=3, total=15000), eusian nomer baris titik eureun, tuluy pencét Jalankeun Jejak Debug. IDE ngajalankeun nepi ka titik eureun kahiji jeung maca baris aktif babarengan jeung nilai variabelna liwat Jieshuo. Pencét Léngkah Hiji Baris pikeun maju hiji baris, atawa Teruskeun Program pikeun ngajalankeun nepi ka titik eureun salajengna. Ieu debugger jejak: manéhna nuturkeun jejak éksekusi anu dirékam atawa ditulis leungeun, lain ngeureunkeun aplikasi Android anu keur ngajalankeun — ngeureunkeun prosés anu sabenerna butuh sasak debug jeung can aya di tahap ieu.

Manajer Dependensi Luring
Kanggo maké pustaka pihak katilu tanpa internét jeung ngahindarkeun bentrokan vérsi saméméh build: buka Manajer Dependensi Luring di ménu utama, pilih proyék, tuluy pencét Pariksa Dependensi. IDE maca sakabéh berkas .gradle proyék, mariksa brankas luring (brankas-maven.txt di jero proyék), jeung ngaréngsékeun bentrokan — upama dua pustaka ménta vérsi béda tina artefak anu sarua, vérsi pangluhurna anu dipaké jeung bentrokanna dilaporkeun. Pikeun nyatet pustaka kana brankas, eusian koordinatna (wangun grup:artefak:vérsi, misalna com.google.code.gson:gson:2.10.1) tuluy pencét Pariksa Dependensi. Ngundeur ti Maven, Google, atawa PyPI butuh internét: nalika luring ngan pustaka anu geus aya di brankas anu bisa dipaké, jeung nambah koordinat ngan nyatetna kana indéks — berkas AAR, JAR, atawa WHL-na can diundeur otomatis. Brankas masih disimpen per proyék.

Inspektur Basis Data jeung Panyimpenan
Kanggo mariksa jeung nguji eusi basis data proyék tanpa nulis kode nu nyitak eusi tabél: buka Inspektur Basis Data jeung Panyimpenan di ménu utama, pilih proyék jeung berkas basis data (.db, .sqlite, atawa .sqlite3), tuluy pencét Buka Basis Data. IDE maca skéma tabélna jeung nampilkeun 20 baris kahiji minangka tabél téks anu dibacakeun Jieshuo. Tulis query SELECT saderhana tuluy pencét Jalankeun Query (misalna SELECT nama FROM pengguna WHERE kota = 'Makassar'). Pikeun ngarobah nilai, eusian nomer baris (1 = baris kahiji), ngaran kolom, jeung nilai anyar, tuluy pencét Robah Nilai Sél — nilai éta ditulis balik kana berkas .db. Pencét Simpen Cadangan pikeun nyimpen kaayaan tabél waktu éta minangka berkas <nama-db>.cadangan.txt di proyék. Anu dibaca ngan tabél kahiji; query anu dirojong ngan SELECT saderhana tanpa JOIN atawa GROUP BY; SharedPreferences jeung DataStore can dibaca.

Pabrik Pangujian Unit jeung Fuzzing
Kanggo manggihan celah logika saméméh aplikasi dibagikeun: buka Pabrik Pangujian Unit jeung Fuzzing di ménu utama, pilih proyék jeung berkas kode, tuluy pencét Jieun jeung Jalankeun Uji. IDE maca tanda tangan fungsi di berkas, ngahasilkeun kasus uji normal jeung wates (téks kosong, null, angka maksimal, karakter anéh), ngajalankeun fuzzing kana fungsi conto, jeung nulis kerangka uji JUnit (Uji<NamaKelas>.java) di proyék. Hasilna ngalaporkeun jumlah uji lulus jeung gagal, jumlah baris kode jeung fungsi anu kapanggih, sarta kasus uji anu dijieun. Uji anu dihasilkeun masih kerangka — harepan (expected) kudu ditulis pangembang — jeung fuzzing anu sabenerna anyar ngajalankeun kana fungsi conto, lain kana fungsi proyék; persentase cakupan baris can diitung.

Simulator Kondisi Perangkat Ékstrim jeung Auditor Kabocoran Mémori
Kanggo nguji katahanan aplikasi nalika sistem maéhan prosésna, jaringan pegat, layar diputer, atawa hémat batré aktif: buka Simulator Kondisi Perangkat Ékstrim jeung Auditor Kabocoran Mémori di ménu utama, pilih proyék, tuluy pencét Jalankeun Simulasi. IDE ngajalankeun tilu skénario tekanan babarengan jeung simulasi puter layar jeung ngalacak objék anu katahan di mémori sanggeus layarna ditutup, tuluy ngalaporkeun data anu leungit jeung rantai objék anu bocor. Ieu simulasi kana modél kaayaan, lain maéhan prosés anu sabenerna, lain megatkeun jaringan HP, jeung lain heap dump nyata; modél kaayaan di layar ieu masih conto tetep, lain kaayaan layar proyék pamaké.

Arsitek Cetak Biru Proyék
Kanggo ngarobah gagasan aplikasi gedé jadi rencana gawé bertahap: buka Arsitek Cetak Biru Proyék di ménu utama, pilih proyék, tulis gagasan aplikasina (misalna aplikasi kasir toko kelontong kalawan cicilan), tuluy pencét Jieun Cetak Biru. IDE nyusun modul, daptar berkas, jeung tonggak gawé leutik, tuluy nyimpenna minangka cetak-biru.txt di folder proyék. Pencét Tandaan Tonggak Satuluyna Réngsé unggal hiji tonggak réngsé, atawa pencét Muat Cetak Biru nu Disimpen pikeun muka deui cetak biru anu geus disimpen. Cetak biru disusun tina pola kecap konci di alat, lain tina modél AI online — gagasan anu teu dipikawanoh maké kerangka umum (modél data, panyimpenan, layar, logika) — jeung nyusun liwat panyadia AI aktif can aya di tahap ieu.

Narator Alur Logika Kode
Kanggo ngarti kode panjang tanpa ngadéngékeun sintaks baris per baris: buka Narator Alur Logika Kode di ménu utama, pilih proyék jeung berkas kode, tuluy pencét Narasi Kode. IDE ngarobah unggal baris jadi kalimah basa Indonesia (misalna lamun total leuwih ti 100000, mangka jalankeun blok salajengna), nampilkeun peta panggilan antar-métode, jeung nandaan potensi bug alus babarengan jeung nomer barisna — String dibandingkeun maké ==, stream anu dibuka tanpa ditutup, jeung variabel anu ditulis di dua métode béda. Narasi jeung pamariksaan maké pola téks luring, lain modél AI online jeung lain analisis aliran data pinuh; pola anu teu dipikawanoh dinarasikeun naon ayana minangka baris kode, jeung peringatan balapan data bisa muncul pikeun variabel anu sabenerna ngan dipaké gantian.

Pabrik App Bundle jeung Kesiapan Play Store
Kanggo nyiapkeun aplikasi ka Google Play Store langsung ti HP: buka Pabrik App Bundle jeung Kesiapan Play Store di ménu utama, pilih proyék, tuluy pencét Jieun Bundel AAB. IDE nyusun berkas .aab tina manifest, sumber daya, jeung aset proyék, nyimulasikeun pecahan ukuran undeuran per arsitéktur (arm64-v8a, armeabi-v7a, x86_64) jeung basa, tuluy ngaudit kesiapan Play — target SDK di handap 35 ditandaan Luhur lantaran Play Store meryogikeun 35 atawa leuwih, jeung pustaka 64-bit anu leungit ogé ditandaan Luhur. Bundel anu dihasilkeun nyaéta arsip berstruktur AAB standar; ukuran pecahan nyaéta perkiraan tina ukuran berkas, lain hasil pamisahan bundletool anu sabenerna, jeung panandatanganan bundel pikeun Play Console tetep maké jalur build anu sarua jeung APK.

Mesin Pembaruan OTA jeung Rilis Bertahap
Kanggo ngirim perbaikan leutik tanpa maksa pamaké ngundeur ulang sakabéh APK: buka Mesin Pembaruan OTA jeung Rilis Bertahap di ménu utama, pilih proyék, tulis eusi vérsi heubeul jeung vérsi anyar, tuluy pencét Jieun Paket Patch. IDE ngitung selisih barisna jeung nyieun pakét patch (patch-ota.zip) babarengan jeung sidik jari SHA-256 eusi anyar, tuluy mariksa naha alat ieu asup tahap awal peluncuran 10 persén. Patch di dieu ngan bisa kana berkas téks (skrip, aset, konfigurasi) — patch binér DEX atawa APK can dirojong, jeung patch dilarapkeun nalika aplikasi dibuka deui. Sidik jari di manifest ngan ngabuktikeun kauteuhan eusi, lain kaaslian pangirim, lantaran can maké tanda tangan konci privat.

Studio Tinjauan Kode Tim
Kanggo ninjau parobahan batur jeung ngaréngsékeun konflik panggabungan tanpa maca tanda panah Git: buka Studio Tinjauan Kode Tim di ménu utama, pilih proyék, eusian tilu vérsi téks (dasar, lokal, batur), tuluy pencét Buka Tinjauan Tim. IDE ngagabungkeun katiluna jeung nampilkeun unggal konflik minangka pilihan sora: Paké vérsi lokal, Paké vérsi batur, atawa Gabung kaduana — baris hasil diselapkeun dina posisi konflik asalna sangkan urutan baris tetep bener — tuluy nulis hasilna ka gabung-hasil.txt di proyék. Di handapna aya papan tugas proyék: eusian judul tugas tuluy pencét Tambah Tugas, tugas disimpen minangka téks di folder .tugas di jero proyék. Panggabungan maké pencocokan baris, lain sintaks, jadi dua parobahan dina baris anu sarua sok dianggap konflik sanajan harti na teu tabrakan; papan tugas tersinkron liwat nyalin berkas téksna babarengan jeung riwayat Git, tanpa server sinkronisasi husus.

Dikte Struktur Kode
Pikeun nulis kode ku sora di jero éditor: buka proyék dina Éditor, teras pencét tombol Dikte Struktur Kode. Ucapkeun paréntah dina basa Indonésia, misalna buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil, atanapi buat variabel teks nama sama dengan Budi — IDE ngarobih ucapan janten blok kode Java, Kotlin, Python, atanapi Compose anu sah sintaksis sareng nyelapkeunana dina posisi kursor, teras maca ringkesanana liwat Jieshuo. Dikte nganggo layanan input sora bawaan sistem, tanpa idin mikropon tambahan, sareng ngan ngakuan pola paréntah anu parantos kadaptar; ucapan di luar pola teu dirobih janten kode. Angka anu diucapkeun ku kecap (misalna 'lima') can dirobih janten digit.

Ruang Kolaborasi Lokal (tanpa internét)
Pikeun damel bareng dina hiji rohangan tanpa internét: buka Kolaborasi dina ménu utama, teras buka bagian Ruang Kolaborasi Lokal. Hiji HP muka sesi (IDE nampilkeun alamat IP lokal sareng PIN 6 digit), HP sanésna gabung sareng alamat sareng PIN éta. Parobihan téks dikirim minangka selisih baris, APK hasil build tiasa dikirim ka HP panguji, sareng laporan crash ti HP panguji ditampi deui. Hiji sesi ngan pikeun hiji sobat; upami dua urang ngarobih baris anu persis sami dina waktos anu sami, parobihan pamungkas anu dianggo. PIN dikirim minangka téks biasa dina jaringan lokal. Rohangan ieu can diuji dina HP nyata.

Setélan AI
Pikeun ngatur panyadia AI sareng konci API pikeun nyieun aplikasi: dina ménu utama, dina kelompok Setélan, pencét Setélan AI (di gigireun tombol Konéktor). Pilih panyadia anu dianggo tina daptar anu sayogi, sareng centang Ganti modél nalika provider error supados upami hiji modél gagal, IDE otomatis nyobian modél salajengna ti panyadia anu sami. Pencét Kokolakeun Konci API pikeun nambihan konci cadangan (eusian nami sareng koncina, teras pencét Simpen; konci ditampilkeun disamarkeun, ngan 4 karakter pamungkas anu katingali). Konci disimpen dina HP sareng teu pernah dikirim ka mana waé kajaba ka panyadia anu dipilih nalika nyieun aplikasi. Catetan: ayeuna pilihan panyadia sareng konci ngan dicatet sareng ditampilkeun dina layar AI Pembuat Aplikasi — nyieun aplikasi masih nganggo AI lokal dina HP (tanpa internét); pamakean panyadia online bakal sumping.

Konéktor
Pikeun nganalisis APK teras ngirimkeunana: dina ménu utama, dina kelompok Setélan, pencét Konéktor (di gigireun tombol Setélan AI). Pilih berkas APK tina HP, IDE maca eusina (nami paket, vérsi, daptar aktivitas), teras pencét Kirim APK pikeun ngirimkeunana liwat bagikeun sistem (misalna WhatsApp atanapi Drive).

Basa jeung Sora
Pikeun ngaganti basa aplikasi: buka Setélan, teras Basa Aplikasi, teras pilih basa atanapi Nuturkeun Sistem. Tampilan utama sareng kalolobaan layar langsung robih kana basa anu dipilih tanpa kedah nutup atanapi ngamimitian deui aplikasi; sababaraha layar (misalna Terminal, Kolaborasi, Setélan AI, sareng Kokolakeun Konci) masih nganggo basa lami dugi ka dibuka deui. Upami milih Nuturkeun Sistem, basa nuturkeun basa sistem HP.
