Create Aplikasi என்பது மடிக்கணினி தேவையின்றி, நேரடியாகத் தொலைபேசியில் இயங்கும் ஒரு Android செயலி உருவாக்கும் செயலியாகும். இந்தச் செயலி, செயலிகளை உருவாக்கக் கற்றுக்கொள்ளத் தொடங்கிய பயனர்கள் மற்றும் திரை வாசிப்பான் பயனர்கள் உட்பட, எவரும் தங்கள் சொந்த Android செயலியை உருவாக்க அனுமதிக்கிறது. இந்தச் செயலியைப் பயன்படுத்துவதற்கான முழுமையான வழிகாட்டி இந்த Tentang Alat திரையில் கிடைக்கிறது.

இந்தச் செயலி என்ன, இது யாருக்கானது
Create Aplikasi என்பது தொலைபேசியில் இயங்கும் ஒரு Android செயலி உருவாக்கும் கருவியாகும். இந்தச் செயலி, தொடக்கநிலையினர் மற்றும் திரை வாசிப்பான் பயனர்கள் உட்பட, தங்கள் சொந்த Android செயலியை உருவாக்க விரும்பும் எவருக்கும் ஆனது. இந்தச் செயலி ஒரு குறியீட்டுத் தொகுப்பான், திட்டத்தைச் சோதிக்க Jalankan பொத்தான், APK உருவாக்க Bangun பொத்தான், மற்றும் APK-ஐக் கையொப்பமிட்டு நிறுவுவதற்கான பட்டிகளை வழங்குகிறது.

இந்தச் செயலியின் நோக்கம்
எவரும் எளிதாக, நேரடியாகத் தங்கள் தொலைபேசியிலிருந்து தங்கள் சொந்த Android செயலியை உருவாக்க முடியும் என்பதற்காக இந்தச் செயலி உருவாக்கப்பட்டது. புதிய பயனர்களும் உடனடியாக முயற்சி செய்யும் வகையில் இதன் தோற்றம் முடிந்தவரை எளிமையாக உருவாக்கப்பட்டுள்ளது.

படிப்படியாகப் புதிய திட்டத்தை உருவாக்குவது எப்படி
1. முதன்மைப் பட்டியில் Buat Project-ஐ அழுத்தவும்.
2. திட்ட வகையைத் தேர்ந்தெடுக்கவும்: HTML, Situs Web, Java, Kotlin, Compose, அல்லது Python.
3. செயலியின் பெயரை நிரப்பவும், எடுத்துக்காட்டு: Garuda Decode.
4. தொகுப்புப் பெயரை (package name) நிரப்பவும், எடுத்துக்காட்டு: com.android.garudadecode. தொகுப்புப் பெயர் சிற்றெழுத்துக்களைப் பயன்படுத்த வேண்டும் மற்றும் புள்ளியால் பிரிக்கப்பட்ட குறைந்தது இரண்டு பகுதிகளைக் கொண்டிருக்க வேண்டும்.
5. செயலியின் பதிப்பை நிரப்பவும், எடுத்துக்காட்டு: 1.0, மற்றும் எண் வடிவில் பதிப்புக் குறியீட்டை நிரப்பவும், எடுத்துக்காட்டு: 1. காலியாக விட்டால், பதிப்பு தானாகவே 1.0 என்றும் பதிப்புக் குறியீடு 1 என்றும் நிரப்பப்படும்.
6. தேவைப்பட்டால் குறைந்தபட்ச SDK மற்றும் இலக்கு SDK-ஐ நிரப்பவும். காலியாக விட்டால், இயல்புநிலை மதிப்புகள் பயன்படுத்தப்படும். குறைந்தபட்ச SDK என்பது ஆதரிக்கப்படும் மிகக் குறைந்த Android பதிப்பாகும், எடுத்துக்காட்டு: 21 என்றால் Android 5.0. அதிகபட்ச இலக்கு SDK 36 (Android 16).
7. செயலியின் அனுமதிகளைத் தேர்ந்தெடுக்க Pilih Izin பொத்தானை அழுத்தவும், எடுத்துக்காட்டு: INTERNET. INTERNET அனுமதி இயல்பாகவே முன்கூட்டியே குறிக்கப்பட்டுள்ளது. செயலிக்கு உண்மையில் தேவைப்படும் அனுமதிகளை மட்டுமே குறிக்கவும்.
8. விரும்பினால், APK அளவு சிறியதாக இருக்க "Gunakan arsitektur terpisah 64 bit dan 32 bit" என்பதைக் குறிக்கவும், மேலும் நீங்களே உருவாக்கிய keystore-ஐப் பயன்படுத்த விரும்பினால் "Gunakan tanda tangan pribadi" என்பதைக் குறிக்கவும்.
9. Buat Proyek-ஐ அழுத்தவும். புதிய திட்டம் Download/project கோப்புறையில் சேமிக்கப்பட்டு உடனடியாக Kelola Project-இல் தெரியும்.

கிடைக்கும் திட்ட வகைகள்
• HTML: index.html, style.css, மற்றும் script.js ஆகியவற்றிலிருந்து தோற்றம், WebView வழியாக இயங்குகிறது. நேரடியாகத் தொலைபேசியில் உருவாக்கப்படுகிறது.
• Situs Web: index.html, tentang.html, kontak.html, style.css, மற்றும் script.js ஆகியவற்றிலிருந்து பட்டியுடன் (Beranda, Tentang, Kontak) கூடிய வலைத்தளம், WebView வழியாக இயங்குகிறது. நேரடியாகத் தொலைபேசியில் உருவாக்கப்படுகிறது.
• Java: தொலைபேசியில் உருவாக்கப்படுகிறது. MainActivity app/src/main/java/<nama-paket>/MainActivity.java-இல் உள்ளது. தோற்றம் app/src/main/res/layout/activity_main.xml-இலிருந்தும், உரை app/src/main/res/values/strings.xml-இலிருந்தும், கருப்பொருள் app/src/main/res/values/styles.xml-இலிருந்தும் வருகிறது.
• Kotlin: செயலியில் சேர்க்கப்பட்டுள்ள Kotlin தொகுப்பானைப் பயன்படுத்தி சாதனத்தில் (ஆஃப்லைனில்) உருவாக்கலாம், அல்லது GitHub Actions வழியாக உருவாக்கலாம். MainActivity app/src/main/java/<nama-paket>/MainActivity.kt-இல் உள்ளது, மற்றும் res கோப்புகள் Java திட்டத்தில் உள்ளதைப் போன்றவையே. தொகுப்பானின் பெரிய அளவு காரணமாக முதல் Kotlin உருவாக்கம் மெதுவாக இருக்கும், மேலும் Kotlin வகுப்புகளைக் குறிப்பிடும் .java கோப்புகளை இன்னும் உருவாக்க முடியாது (.java கோப்புகள் .kt கோப்புகளுக்கு முன் தொகுக்கப்படுகின்றன).
• Compose: இடைமுகம் Jetpack Compose கொண்டு உருவாக்கப்பட்ட நவீன Android செயலி (XML தளவமைப்பு அல்ல). MainActivity app/src/main/java/<nama-paket>/MainActivity.kt-இல் உள்ளது. Compose-க்கு சாதனத்தில் கிடைக்காத Jetpack Compose நூலகங்கள் தேவைப்படுவதால், Compose திட்டங்கள் GitHub Actions வழியாக (Bangun proyek பட்டி, பின்னர் Bangun online) அல்லது Termux-இல் Gradle கொண்டு உருவாக்கப்படுகின்றன.
• Python: செயலியின் தர்க்கம் Python மொழியில் (Chaquopy) app/src/main/python/main.py-இல் எழுதப்பட்டு, app/src/main/java/<nama-paket>/MainActivity.java-இல் உள்ள புரவலன் MainActivity.java மூலம் இயக்கப்படுகிறது. Python திட்டங்களை நேரடியாகத் தொலைபேசியில் உருவாக்கலாம் (Chaquopy இயக்க நேரம் செயலியில் சேர்க்கப்பட்டுள்ளது) அல்லது GitHub Actions வழியாகவும் உருவாக்கலாம். Python திட்டங்களுக்கான குறைந்தபட்ச SDK 24 (Android 7.0).

Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களின் கோப்பு அமைப்பு
Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்கள் பொதுவாக Android திட்டங்களைப் போலவே அமைக்கப்பட்டுள்ளன. app கோப்புறையின் உள்ளே src கோப்புறை உள்ளது, அதன் உள்ளே main கோப்புறை உள்ளது. main கோப்புறையின் உள்ளே java கோப்புறைக்கு அருகில் AndroidManifest.xml உள்ளது, layout/activity_main.xml மற்றும் values/strings.xml மற்றும் values/styles.xml ஆகியவற்றைக் கொண்ட res கோப்புறை உள்ளது, மேலும் HTML மற்றும் Situs Web-க்கு index.html-ஐக் கொண்ட assets கோப்புறை உள்ளது (Situs Web-இல் tentang.html மற்றும் kontak.html-ம் உள்ளன). HTML மற்றும் Situs Web திட்டங்களுக்கும் app/src/main/java/<nama-paket>/MainActivity.java-இல் தங்கள் சொந்த MainActivity உள்ளது, இது WebView-இல் index.html-ஐ ஏற்றி AndroidManifest-இல் துவக்கியாகச் செயல்படுகிறது. Python திட்டங்களில் Python குறியீடு app/src/main/python/main.py-இலும் புரவலன் MainActivity.java app/src/main/java/<nama-paket>/MainActivity.java-இலும் உள்ளது. AndroidManifest.xml, தளவமைப்பு, strings, மற்றும் styles ஆகியவற்றை MainActivity-ஐப் போலவே தொகுப்பானில் திறந்து மாற்றலாம். வெளிப்பாடு இன்னும் app கோப்புறைக்கு அருகில் இருக்கும் பழைய திட்டங்களையும் உருவாக்க முடியும், ஏனெனில் உருவாக்கும் போது, செயலி முதலில் app/src/main/-இல் AndroidManifest.xml-ஐச் சரிபார்க்கிறது, பின்னர் app கோப்புறைக்கு அருகில் உள்ளதை, இறுதியாகத் திட்டத் தரவுக் கோப்பைச் சரிபார்க்கிறது.

அனுமதி விதிகள் (முக்கியம்)
திட்டத்தை உருவாக்கும் போது குறிக்கப்படும் அனுமதிகள், திட்ட வகைக்கு ஏற்ப, ஒரே ஒரு இடத்தில் மட்டுமே பதிவு செய்யப்படுகின்றன. Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களுக்கு, குறிக்கப்பட்ட அனுமதிகள் திட்டக் கோப்புறையின் உள்ளே, java கோப்புறைக்கு அருகில், app/src/main/-இல் உள்ள AndroidManifest.xml-இல் மட்டுமே பதிவு செய்யப்படுகின்றன. Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களுக்கான திட்டத் தரவுக் கோப்பில் அனுமதிகளின் பட்டியல் இல்லை. நீங்கள் Java-வைத் தேர்ந்தெடுத்து INTERNET மற்றும் CAMERA-வைக் குறித்தால், AndroidManifest.xml-இல் பதிவாவது INTERNET மற்றும் CAMERA மட்டுமே, வேறு எந்த அனுமதியும் சேராது. உருவாக்கும் போது, செயலி அதே இடத்திலிருந்து அனுமதிகளைப் படிக்கிறது: Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களுக்கு app/src/main/-இல் உள்ள AndroidManifest.xml-இலிருந்து (இல்லாவிட்டால், பழைய திட்டங்களுக்கு app கோப்புறைக்கு அருகில் உள்ள AndroidManifest.xml-இலிருந்து), மற்றும் பழைய திட்டங்களுக்குத் திட்டத் தரவுக் கோப்பிலிருந்து.

தொகுப்பானைப் பயன்படுத்துவது எப்படி
Kelola Project-ஐத் திறந்து, தொகுப்பானைத் திறக்கத் திட்டத்தின் பெயரைத் தட்டவும். தொகுப்பானில், கோப்புகளைத் திறக்கலாம், குறியீட்டை எழுதலாம், மாற்றங்களைச் சேமிக்கலாம். Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களுக்கு, கோப்புகள் app/src/main கோப்புறையின் உள்ளே அமைக்கப்பட்டுள்ளன. ஒரு திட்டத்தைப் பகிர, Ekspor ZIP-ஐப் பயன்படுத்தவும் (கீழே உள்ள பகுதியைப் பார்க்கவும்).

திட்டத்தை இயக்குவது எப்படி
தொகுப்பானில், திட்டத்தைச் சோதிக்க Jalankan-ஐ அழுத்தவும். HTML மற்றும் Situs Web திட்டங்களுக்கு, இயக்கப்படுவது WebView வழியாக index.html ஆகும். பிழை ஏற்பட்டால், பிழைச் செய்தியைப் படித்து, குறியீட்டைச் சரிசெய்து, மீண்டும் இயக்கவும்.

APK-ஐ உருவாக்குவது எப்படி
தொகுப்பானில், Bangun-ஐ அழுத்தவும். உருவாக்க இரண்டு வழிகள் உள்ளன. முதலாவது, Bangun di perangkat: இணையம் இல்லாமல் நேரடியாகத் தொலைபேசியில் உருவாக்குதல், HTML, Situs Web, Java, Kotlin, மற்றும் Python திட்டங்களுக்கு. இரண்டாவது, GitHub Actions வழியாக Bangun online: இணையம் வழியாக GitHub-இல் உருவாக்குதல், மேலும் எல்லா வகைத் திட்டங்களுக்கும் பயன்படுத்தலாம். Compose-க்கு சாதனத்தில் கிடைக்காத Jetpack Compose நூலகங்கள் தேவைப்படுவதால், Compose திட்டங்களை இரண்டாவது வழியில் (Bangun online) அல்லது Termux-இல் Gradle கொண்டு மட்டுமே உருவாக்க முடியும். முதல் உருவாக்கத்தின் முடிவு இன்னும் கையொப்பமிடப்படவில்லை. அதன் பிறகு செயலி அதைக் கையொப்பமிடுகிறது: இயல்புநிலை விசையுடன் தானாகவே, அல்லது திட்டத்தை உருவாக்கும் போது "Gunakan tanda tangan pribadi" பெட்டி குறிக்கப்பட்டிருந்தால் தனிப்பட்ட கையொப்பத்துடன்.

APK-ஐ நிறுவுவது எப்படி
APK தயாரானதும், அதை நிறுவ Pasang-ஐ அழுத்தவும். Android 8 மற்றும் அதற்கு மேல், இந்தச் செயலி Play Store-க்கு வெளியில் இருந்து APK-களை நிறுவுவதால், தொலைபேசி முதலில் "Izinkan dari sumber ini" என்று கேட்கும். Pengaturan-இல் அந்த அனுமதியை ஒருமுறை இயக்கிவிட்டு, செயலிக்குத் திரும்பவும்: Pasang-ஐ மீண்டும் அழுத்த வேண்டியதில்லாமல் நிறுவல் தானாகவே தொடரும். Pasang பொத்தான் தோன்றாவிட்டால், உருவாக்கம் முடிந்துவிட்டதையும் APK உருவாக்கப்பட்டுவிட்டதையும் உறுதிப்படுத்தவும்.

செயலியில் கையொப்பமிடுவது எப்படி
ஒவ்வொரு APK-வும் நிறுவப்படுவதற்குக் கையொப்பமிடப்பட வேண்டும். இரண்டு தேர்வுகள் உள்ளன. முதலாவது, இயல்புநிலை விசை: நீங்கள் எதுவும் செய்ய வேண்டியதில்லாமல், செயலி தானாகவே கையொப்பமிடுகிறது. இரண்டாவது, தனிப்பட்ட கையொப்பம்: முதலில் முதன்மைப் பட்டியில் உள்ள Buat Keystore பட்டி வழியாக ஒரு keystore-ஐ உருவாக்கவும், அதன் கடவுச்சொல்லைப் பத்திரமாக வைக்கவும், பின்னர் திட்டத்தை உருவாக்கும் போது "Gunakan tanda tangan pribadi" என்பதைக் குறிக்கவும். Keystore Download/project/signing-இல் சேமிக்கப்படுகிறது.

திட்டத்தை ZIP ஆக ஏற்றுமதி செய்தல்
நண்பர்களுடன் திட்டங்களைப் பகிர முடியும் என்பதற்காக Ekspor ZIP வழங்கப்படுகிறது. வழிமுறை: Kelola Project-இல், திட்டத்தின் பெயரை நீண்ட நேரம் அழுத்திப் பிடித்து, பின்னர் Ekspor ZIP-ஐத் தேர்ந்தெடுக்கவும். முடிவு Download/project/<NamaProyek>.zip-இல் சேமிக்கப்படுகிறது. bin கோப்புறை சேர்க்கப்படாததால், அளவு சிறியது, வெறும் பத்துக்கணக்கான KB மட்டுமே. அந்த ZIP கோப்பை நண்பருக்கு அனுப்பலாம் அல்லது GitHub-இல் பதிவேற்றலாம்.

JAWS நீட்டிப்பு
JAWS நீட்டிப்பு Jieshuo (CSR)-இன் நீட்டிப்பு இயந்திரத்தைப் பயன்படுத்துகிறது, அதன் திரை வாசிப்பானை அல்ல. இதன் மூலம், பயனர் TalkBack-ஐப் பயன்படுத்தினாலும் வடிவமைப்பு இயங்க முடியும். வழிமுறை: முதன்மைப் பட்டியில் Ekstensi JAWS-ஐத் திறக்கவும். தானியங்கு கிளிக் தானாகவே இயங்குவதால், சேவையை முதலில் Pengaturan Aksesibilitas-இல் இயக்க வேண்டும். அதன் பிறகு, ஒரு புதிய வடிவமைப்பை உருவாக்கலாம்: வடிவமைப்பின் பெயரைத் தட்டச்சு செய்து, OK அழுத்தி, பின்னர் அதன் பெட்டிகளை நிரப்பவும்.

ஒழுங்காக இருக்க Daftar Klik பிரிக்கப்பட்டுள்ளது
வடிவமைப்பின் உள்ளே இரண்டு பெட்டிகள் உள்ளன: ஸ்கிரிப்ட் பெட்டி மற்றும் Daftar Klik பெட்டி. பொத்தான்களின் பட்டியல் daftar_klik.txt கோப்பில் தனியாகச் சேமிக்கப்படுகிறது, ஒரு வரிக்கு ஒரு பெயர். அதன் உள்ளடக்கத்தின் எடுத்துக்காட்டு: tombolSimpan, tombolHapus, tombolBuka. ஒரு செயலியைத் திறக்க, அந்தப் பட்டியில் >WhatsApp என்று எழுதினால் போதும். இன்னும் daftar_klik.txt கோப்பு இல்லாத பழைய வடிவமைப்புகள் அந்த இயல்புநிலை எடுத்துக்காட்டைக் காண்பிக்கும்.

வழங்கப்படும் எளிய செயல்பாடுகள்
• klikTombol("tombolSimpan") — அதன் உரையின் அடிப்படையில் ஒரு பொத்தானைக் கிளிக் செய்கிறது.
• klikDaftarTombol(daftar) — daftar_klik.txt-இல் உள்ள பட்டியலைக் கிளிக் செய்கிறது, ஒரு வரிக்கு ஒரு பொத்தான், வரிசையாக, பின்னர் எத்தனை வெற்றி பெற்றன, எத்தனை கிடைக்கவில்லை என்று தெரிவிக்கிறது.
• bukaAplikasi("WhatsApp") — அதன் பெயரால் ஒரு செயலியைத் திறக்கிறது, அல்லது பட்டியில் ">WhatsApp" என்று எழுதவும்.
• klik(540, 1200) — திரை ஆயங்களில் கிளிக் செய்கிறது.
எல்லாச் செயல்பாடுகளும் முதலில் எளிமையாக உருவாக்கப்பட்டுள்ளன. பழகிய பிறகு, கூடுதல் செயல்பாடுகளைப் பின்னர் சேர்க்கலாம்.

திரை வாசிப்பான் பற்றி
இந்தச் செயலி திரை வாசிப்பானுக்கு ஏற்றதாக வடிவமைக்கப்பட்டுள்ளது. ஒவ்வொரு உள்ளீட்டுப் புலத்திற்கும் ஒரு குறிப்பும் நிரப்பும் எடுத்துக்காட்டும் உள்ளது, மேலும் எல்லாப் பொத்தான்களையும் சிக்கலான சைகைகள் இல்லாமல் அடைய முடியும். JAWS நீட்டிப்பு, பயனர் TalkBack-ஐப் பயன்படுத்தினாலும் இயங்கும் வகையில் உருவாக்கப்பட்டுள்ளது, ஏனெனில் பயன்படுத்தப்படுவது அதன் நீட்டிப்பு இயந்திரமே, அதன் திரை வாசிப்பான் அல்ல.

தனியுரிமை மற்றும் பாதுகாப்பு
திட்டங்களும் keystore-ம் உங்கள் தொலைபேசியில் சேமிக்கப்படுகின்றன. GitHub டோக்கன் ஆன்லைன் உருவாக்கங்களுக்கு மட்டுமே பயன்படுத்தப்படுகிறது மற்றும் இந்தச் செயலியின் உள்ளே சேமிக்கப்படுகிறது. உங்கள் டோக்கனையோ keystore கடவுச்சொல்லையோ யாருடனும் பகிர வேண்டாம். தனிப்பட்ட கையொப்பத்தைப் பயன்படுத்தினால், keystore-ஐயும் அதன் கடவுச்சொல்லையும் பாதுகாப்பான இடத்தில் வைக்கவும், ஏனெனில் அவை தொலைந்தால், பழைய APK-ஐ அதே கையொப்பத்துடன் புதுப்பிக்க முடியாது.

தேவைகள்
Android 5.0 அல்லது அதற்கு மேற்பட்டது. சேமிப்பு அனுமதி: Android 11 மற்றும் அதற்கு மேல் எல்லாக் கோப்புகளுக்குமான அணுகல் அனுமதியைப் பயன்படுத்துகிறது, Android 10 மற்றும் அதற்குக் கீழே வழக்கமான சேமிப்பு அனுமதியைப் (சேமிப்பைப் படி/எழுது) பயன்படுத்துகிறது, ஏனெனில் Android 10-இல் எல்லாக் கோப்புகளுக்குமான அணுகல் அனுமதி இல்லை. சாதனத்தில் உருவாக்க ARM செயலி (32 அல்லது 64 பிட்) கொண்ட தொலைபேசி தேவை. GitHub Actions வழியாக ஆன்லைனில் உருவாக்க இணையமும் GitHub டோக்கனும் தேவை. Kotlin திட்டங்களைச் சாதனத்தில் உருவாக்கலாம், ஆனால் Kotlin தொகுப்பானின் பெரிய அளவு காரணமாக அதன் முதல் உருவாக்கம் மெதுவாகவும் அதிக நினைவகத்தைப் பயன்படுத்தியும் இருக்கும். Compose திட்டங்கள் GitHub Actions வழியாக அல்லது Termux-இல் Gradle கொண்டு உருவாக்கப்படுகின்றன. Python திட்டங்களுக்கு Android 7.0 அல்லது அதற்கு மேற்பட்டது (குறைந்தபட்ச SDK 24) தேவை, மேலும் விளையும் APK பெரியதாக இருக்கும், ஏனெனில் அதில் Python இயக்க நேரம் (Chaquopy) மற்றும் அதன் நிலையான நூலகம் அடங்கும்.

Terminal
முதன்மைத் திரையில் உள்ள Terminal பட்டி இந்தச் செயலியின் உள்ளே ஒரு முனையத்தைத் திறக்கிறது. திட்டக் கோப்புறையின் உள்ளடக்கத்தைப் பார்க்க ls, கோப்புறைகளை மாற்ற cd, குறியீட்டை நிர்வகிக்க git போன்ற கட்டளைகளைப் பயன்படுத்தலாம். கட்டளை வெளியீடு திரை வாசிப்பானால் படிக்கக்கூடிய உரையாகத் தோன்றுகிறது, மேலும் கடைசி முடிவைக் கேட்க Bacakan hasil பொத்தான் உள்ளது. இந்த முனையம் தொலைபேசியின் அமைப்பு ஷெல்லைப் பயன்படுத்துகிறது, எனவே nano மற்றும் vim போன்ற ஊடாடும் நிரல்களை இங்கே இன்னும் பயன்படுத்த முடியாது.

உரிமம் (கட்டணப் பதிப்பு)
செயலிகளை விற்க, திட்டத்தை உருவாக்கும் போது "Aktifkan Lisensi" என்பதைக் குறித்து, பின்னர் உங்கள் WhatsApp எண்ணை நிரப்பவும். உருவாக்கத்தின் விளைவான செயலி முதன்முறை திறக்கப்படும் போது ஒரு உரிமக் குறியீட்டைக் கேட்கும்: பயனர் தங்கள் சாதன ID-ஐப் பார்த்து, அந்த ID-ஐ உங்கள் WhatsApp-க்கு அனுப்ப Kirim ID Perangkat பொத்தானை அழுத்துவார், பின்னர் நீங்கள் உரிமக் குறியீட்டுடன் பதிலளிப்பீர்கள். உரிமக் குறியீடு சாதன ID மற்றும் திட்டக் கடவுச்சொல்லிலிருந்து (திட்டத் தரவுக் கோப்பில் உள்ள lisensi_seed) கணக்கிடப்படுகிறது — அந்தக் கடவுச்சொல்லைப் பத்திரமாக வைத்து, பகிர வேண்டாம். சரியான குறியீடு உள்ளிடப்பட்ட பிறகு, செயலி திறக்கும், மீண்டும் குறியீட்டைக் கேட்காது.

Pembuat Ikon Otomatis
புதிய திட்டச் சின்னங்கள் இன்னும் ஒளிபுகும் தன்மையுடன் இருப்பதால், முதன்மைப் பட்டியில் Pembuat Ikon கிடைக்கிறது. வழிமுறை: Pembuat Ikon-ஐ அழுத்தி, ஒன்று அல்லது இரண்டு எழுத்துக்களை எழுதி (எடுத்துக்காட்டாக, செயலியின் பெயரின் தலைப்பெழுத்துக்கள்), பின்னணி நிறத்தையும் உரை நிறத்தையும் தேர்ந்தெடுத்து, அதன் முன்னோட்டத்தைப் பார்த்து, பின்னர் தேர்ந்தெடுக்கப்பட்ட திட்டத்தில் அந்தச் சின்னத்தைப் பயன்படுத்த Simpan ke Proyek-ஐ அழுத்தவும், அல்லது அதன் PNG கோப்பை வேறு இடத்தில் பயன்படுத்த Simpan ke Download-ஐ அழுத்தவும். ஒரு திட்டம் உருவாக்கப்பட்ட பிறகு, செயலி ஒரு சின்னத்தை உருவாக்கவும் முன்வருகிறது. பழைய திட்டச் சின்னங்களை Kelola Project-இல் உள்ள திட்டப் பட்டியிலிருந்து எந்த நேரத்திலும் மாற்றலாம் (திட்டத்தின் பெயரை நீண்ட நேரம் அழுத்திப் பிடித்து, பின்னர் Ganti Ikon-ஐத் தேர்ந்தெடுக்கவும்).

தயாரான திட்ட வார்ப்புருக்கள்
வெற்றுத் திட்டத்திலிருந்து தொடங்க விரும்பாவிட்டால், திட்டத்தை உருவாக்கும் போது ஒரு வார்ப்புருவைத் தேர்ந்தெடுக்கவும்: Kalkulator (Java), Catatan (Java), Daftar Tugas (Kotlin), Kalkulator Web (HTML), Situs Profil (Situs Web), அல்லது Penghitung (Compose). ஒரு வார்ப்புருவைத் தேர்ந்தெடுப்பது திட்ட வகையைத் தானாகவே அந்த வார்ப்புருவைப் பின்பற்றுமாறு மாற்றுகிறது, மேலும் திட்டம் தயாரான தொடக்கக் குறியீட்டுடன் உருவாக்கப்படுகிறது — அதை இயக்கவோ மாற்றவோ மட்டுமே மீதம் உள்ளது. வார்ப்புருவைத் தேர்ந்தெடுத்த பிறகு திட்ட வகையை மீண்டும் கைமுறையாக மாற்றினால், வார்ப்புரு ரத்து செய்யப்பட்டு, திட்டம் மீண்டும் காலியாகிவிடும். HTML மற்றும் Situs Web வார்ப்புருக்களுக்கு, படிவத்தில் தட்டச்சு செய்யப்பட்ட HTML ஸ்கிரிப்ட் உட்பட, வார்ப்புரு index.html-இன் உள்ளடக்கத்தை மாற்றீடு செய்கிறது.

திட்டக் காப்புப்பிரதி மற்றும் மீட்டமைப்பு

ஒரு நண்பருடன் திட்டத்தைப் பகிர: Kelola Project-இல், திட்டத்தின் பெயரை நீண்ட நேரம் அழுத்திப் பிடித்து, பின்னர் Bagikan-ஐத் தேர்ந்தெடுக்கவும். திட்டம் பகிர்வுச் செயலிகள் (WhatsApp, Telegram, மற்றும் பிற) வழியாக ZIP ஆக அனுப்பப்படுகிறது. ஒரு நண்பரிடமிருந்து திட்டத்தைப் பெற: Kelola Project-இல் பட்டியைத் திறந்து, Impor proyek-ஐத் தேர்ந்தெடுத்து, பின்னர் அதன் ZIP கோப்பைத் தேர்ந்தெடுக்கவும். அந்த ZIP கோப்பில் ஒரு திட்டத் தரவுக் கோப்பு இருக்க வேண்டும் — இல்லாவிட்டால், அந்தக் கோப்பு Create Aplikasi திட்டம் அல்ல என்பதால், கோப்பு தெளிவான செய்தியுடன் நிராகரிக்கப்படும். திட்டத்தின் பெயர் ஏற்கனவே இருந்தால், செயலி கேட்கும்: Timpa proyek lama, அல்லது Nama baru உடன் சேமிக்கவும்.

திட்டத் தேடல் மற்றும் வடிப்பான்
திட்டங்கள் அதிகமானால், Kelola Project-இல் ஒரு தேடல் பெட்டியும் வகை வடிப்பானும் உள்ளது. தேடல் பெட்டியில் திட்டத்தின் பெயரைத் தட்டச்சு செய்யவும், பட்டியல் உடனடியாக வடிகட்டப்படும் (பெரிய மற்றும் சிறிய எழுத்துக்கள் வேறுபடுத்தப்படாது). வகை வடிப்பான் பட்டியலை ஒரே ஒரு வகைக்கு மட்டுப்படுத்துகிறது: Semua, HTML, Situs Web, Java, Kotlin, Compose, அல்லது Python. வடிகட்டப்பட்ட பட்டியலிலிருந்தும் ஒவ்வொரு திட்டத்தின் பட்டியையும் வழக்கம் போலத் திறக்கலாம்.

குரல் மூலம் பயன்பாட்டை உருவாக்கவும்
தட்டச்சு செய்ய விரும்பவில்லை என்றால், குரலைப் பயன்படுத்துங்கள்: முதன்மை பட்டியலில் குரல் மூலம் உருவாக்கவும் என்பதைத் தட்டி, பிறகு ஒரு கட்டளையைப் பேசுங்கள். பேசக்கூடிய கட்டளைகள்: "Buat proyek kalkulator", "Bangun proyek Kalkulator", "Buka proyek Kalkulator", "Jalankan proyek Kalkulator", "Daftar proyek", "Buka ikon", "Kembali" மற்றும் "Bantuan". செயலி குரல் மற்றும் உரை மூலம் பதிலளிக்கிறது, எனவே திரையைப் பார்க்காமலும் பயன்படுத்தலாம். குரல் அடையாளம் தொலைபேசியின் உள்ளமைந்த பேச்சு அடையாள செயலியைப் பயன்படுத்துகிறது (இலவசம்; இந்தோனேசிய மொழித் தொகுப்பு நிறுவப்பட்டிருந்தால் ஆஃப்லைனிலும் இயங்கும்). தொலைபேசியில் குரல் அடையாளம் இல்லை என்றால், அதே திரையில் உள்ள உரைப் பெட்டியில் கட்டளைகளைத் தட்டச்சு செய்யலாம்.

அணுகல் தணிக்கை
வெளியீட்டிற்கு முன் ஒரு திட்டத்தின் அமைப்பு திரை வாசிப்பாளருக்கு (TalkBack/Jieshuo) ஏற்றதா என்பதைச் சரிபார்க்க: முதன்மை பட்டியலில் அணுகல் தணிக்கை என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, பிறகு அமைப்புப் பட்டியலை ஏற்றுக என்பதைத் தட்டி ஓர் அமைப்புக் கோப்பைத் தேர்ந்தெடுங்கள். IDE அந்த XML கோப்பைப் படித்து, லேபிள் இல்லாத பொத்தான்களை அவற்றின் வரி எண்களுடனும், மீண்டும் மீண்டும் பயன்படுத்தப்பட்ட லேபிள்களையும், ஒன்றையொன்று மூடும் கூறுகளையும் தெரிவித்து, பிறகு Jieshuo உரக்க வாசிப்பது போன்ற கவன வரிசைப் பதிவை உருவாக்குகிறது. ஒரு பொத்தானுக்கு லேபிள் இல்லை என்றால், அதன் லேபிளை நிரப்பி, பிறகு தானாக லேபிளைச் செருகுக என்பதைத் தட்டுங்கள் — லேபிள் contentDescription ஆக அமைப்புக் கோப்பில் எழுதப்படும். இந்தச் சரிபார்ப்பு அமைப்பு XML ஐ மட்டுமே படிக்கிறது; Compose காட்சிகளும் முடிக்கப்பட்ட APK களும் இன்னும் வருடப்படவில்லை.

செயலிழப்பு உடற்கூறாய்வு
தனித்துவமான அடையாள எண் கொண்ட செயலிழப்புப் பதிவிலிருந்து ஒரு செயலி ஏன் தானாக மூடுகிறது என்பதை அறிய: முதன்மை பட்டியலில் செயலிழப்பு உடற்கூறாய்வு என்பதைத் திறந்து, பதிவுப் பட்டியலிலிருந்து ஒரு செயலிழப்பு அடையாள எண்ணைத் தேர்ந்து, பிறகு சரிபார்க்கவும் என்பதைத் தட்டுங்கள். IDE பதிவில் உள்ள வகுப்பையும் வரி எண்ணையும் திட்ட மூலத்துடன் பொருத்தி, காரணத்தை இந்தோனேசிய மொழியில் விளக்குகிறது (எடுத்துக்காட்டாக வெற்றுக் குறிப்பு, இன்னும் கேட்கப்படாத அனுமதி, அல்லது JSON பிழை), குறியீடு திருத்தத்தின் பரிந்துரையுடன். மூல வரி செயலிழப்பு நடந்தபோது இருந்தது போலவே இன்னும் இருந்தால் மட்டுமே திருத்தத்தைப் பயன்படுத்துக என்பதைத் தட்டுங்கள்; மாறியிருந்தால் திருத்தம் மறுக்கப்படும், IDE உங்களை நீங்களே சரிபார்க்கச் சொல்லும். படிக்கப்படுவது IDE இன் சொந்த செயலிழப்புப் பதிவு, கட்டப்பட்ட செயலியின் பதிவு அல்ல.

குறுக்கு-முன்னுதாரண மாற்றி
எளிய Java குறியீட்டை Kotlin ஆகவோ, எளிய XML அமைப்பை Compose குறியீடாகவோ மாற்ற: முதன்மை பட்டியலில் குறுக்கு-முன்னுதாரண மாற்றி என்பதைத் திறந்து, திட்டத்தையும் கோப்பையும் தேர்ந்து, பிறகு முன்னோட்டம் என்பதைத் தட்டுங்கள். IDE மாற்ற முடிவை உரையாகக் காட்டுகிறது — முதலில் அதைச் சரிபாருங்கள், ஏனெனில் அது அடையாளம் காணாத வரிகள் அப்படியே விடப்படும், Java வில் உள்ள static என்ற சொல் Kotlin இல் நீக்கப்படும் (பயன்படுத்தும் முன் அதன் பொருளைச் சரிபாருங்கள்). XML இலிருந்து Compose க்கு மாற்றுவது உரை, குறிப்புகள், திசை ஆகியவற்றை மட்டுமே மாற்றும் — அளவு, நிறம் மற்றும் பிற பண்புகள் இன்னும் சேர்க்கப்படவில்லை. முடிவு சரியாக இருந்தால், இலக்குக் கோப்பை எழுத கோப்பில் பயன்படுத்துக என்பதைத் தட்டுங்கள்; மூலக் கோப்பு மாறாது. பாதுகாப்பான, பொதுவான வடிவங்கள் மட்டுமே மாற்றப்படும்.

உள்ளூர் நுண் சேவையகம்
இணையம் இல்லாமல் சேவையகம் தேவைப்படும் செயலியைச் சோதிக்க: முதன்மை பட்டியலில் உள்ளூர் நுண் சேவையகம் என்பதைத் திறந்து, வழி வரையறையை எழுதுங்கள் (எடுத்துக்காட்டாக GET /halo அதைத் தொடர்ந்து அதன் JSON பதில்), பிறகு சேவையகத்தைத் தொடங்குக என்பதைத் தட்டுங்கள். IDE அதே தொலைபேசியில் ஒரு சிறிய HTTP சேவையகத்தை இயக்குகிறது (HTTP மட்டும், TLS இல்லாமல், அதே Wi-Fi வலையமைப்புக்கு) மற்றும் ஒவ்வொரு கோரிக்கையையும் பதிலையும் திரையில் பதிவு செய்கிறது. வழிகள் {nama} போன்ற அளவுருக்களையும் எளிய API விசையையும் பயன்படுத்தலாம். இந்தச் சேவையகம் தொலைபேசியில் சோதிக்க மட்டுமே; கட்டப்பட்ட APK இன்னும் சேவையகமாக முடியாது, அதன் திரை மூடப்பட்டால் சேவையகம் நிற்கும்.

பாதுகாப்பு தணிக்கையாளர்
வெளியீட்டிற்கு முன் திட்டக் குறியீட்டில் உள்ள பாதுகாப்பு ஓட்டைகளைச் சரிபார்க்க: முதன்மை பட்டியலில் பாதுகாப்பு தணிக்கையாளர் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, பிறகு வருடலைத் தொடங்குக என்பதைத் தட்டுங்கள். IDE குறியீடு, அறிக்கை மற்றும் திட்ட உள்ளமைவை வருடி, அதிக ஆபத்திலிருந்து குறைந்த ஆபத்து வரை கண்டுபிடிப்புகளைத் தெரிவிக்கிறது — குறியீட்டில் வெளிப்படையான API விசைகள், அனுமதியின்றி வெளிப்படும் கூறுகள், JavaScript இடைமுகத்துடன் JavaScript ஐ இயக்கும் WebView, பலவீனமான மறையாக்கம் (MD5, SHA1, DES), TLS இல்லாத http முகவரிகள், மற்றும் குறியீட்டில் நேரடியாக எழுதப்பட்ட கடவுச்சொற்கள் — ஒவ்வொன்றின் கோப்பு மற்றும் வரி எண்ணுடன். பாதுகாப்பான திருத்தம் உள்ள கண்டுபிடிப்புகளுக்கு (எடுத்துக்காட்டாக MD5 ஐ SHA-256 ஆக அல்லது http ஐ https ஆக மாற்றுவது) திருத்தத்தைப் பயன்படுத்துக என்பதைத் தட்டுங்கள்; API விசைகள் மற்றும் கடவுச்சொற்களுக்கு IDE பரிந்துரைக்கப்பட்ட திருத்தத்தை மட்டுமே காட்டுகிறது, ஏனெனில் மாற்றீட்டை உருவாக்குநரே முடிவு செய்ய வேண்டும். இந்த வருடல் குறியீட்டில் உள்ள உரை வடிவங்களைப் படிக்கிறது, bytecode ஐ அல்ல, எனவே சில கண்டுபிடிப்புகள் உண்மையில் பாதுகாப்பானதாக இருக்கலாம், வடிவம் இல்லாத ஓட்டை வருடலில் இருந்து தப்பிக்கலாம் — பயன்படுத்தும் முன் சரிபாருங்கள்.

இடைமுக சோதனை ரோபோ
உரை சூழ்நிலைகளைப் பயன்படுத்தி ஒரு செயலியின் தோற்றத்தைத் தானாகச் சோதிக்க: முதன்மை பட்டியலில் இடைமுக சோதனை ரோபோ என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, பிறகு தானாக சூழ்நிலையை உருவாக்குக என்பதைத் தட்டுங்கள். IDE திட்ட அறிக்கை மற்றும் அமைப்புகளைப் படித்து, உரை படிகளால் ஆன சூழ்நிலையை எழுதுகிறது (பொத்தானைத் தட்டுக, புலத்தை நிரப்புக, காத்திருக்கவும், திரும்பவும்). சூழ்நிலை இயக்கப் பதிவை நேர முத்திரைகளுடன் காண உலர் ஓட்டத்தை இயக்குக என்பதைத் தட்டுங்கள். இந்தக் கட்டத்தில் ரோபோ ஒரு உருவகப்படுத்துதலை மட்டுமே இயக்குகிறது (உலர் ஓட்டம்) — தொலைபேசியில் பொத்தான்களை உண்மையில் அழுத்துவதும் உண்மையான செயலிழப்புகளைப் பிடிப்பதும் அடுத்த கட்டம், எனவே இங்குள்ள செயலிழப்பு அறிக்கை இன்னும் மாதிரி வடிவமே.

குறியீட்டு நேரப் பயணம்
Git கட்டளைகளைத் தட்டச்சு செய்யாமல் திட்டத்தை முந்தைய குறியீட்டு நிலைக்குத் திருப்ப: முதன்மை பட்டியலில் குறியீட்டு நேரப் பயணம் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, நேரப் புள்ளி லேபிளை நிரப்பி (காலியாக இருக்கலாம்), பிறகு நேரப் புள்ளியைப் பதிவு செய்க என்பதைத் தட்டுங்கள். IDE திட்ட மூலக் கோப்புகளின் நகலை அவற்றின் hash களுடன் திட்டத்திற்குள் உள்ள .riwayat கோப்புறையில் சேமிக்கிறது. நேரப் புள்ளிப் பட்டியல் அனைத்தையும் காட்டுகிறது; இரண்டு புள்ளிகளைத் தேர்ந்து பிறகு சேர்க்கப்பட்ட, மாற்றப்பட்ட அல்லது நீக்கப்பட்ட கோப்புகள் மற்றும் செயல்பாடுகளைக் காண ஒப்பிடுக என்பதைத் தட்டுங்கள். பழைய நிலையை மீட்க மீட்டெடுக்கவும் என்பதைத் தட்டுங்கள் — மீட்பதற்கு முன் IDE எப்போதும் முதலில் தற்போதைய நிலையின் காப்புப்பிரதியை உருவாக்குகிறது, எனவே எதுவும் இழக்கப்படாது. அசல் திட்டத்தைத் தொந்தரவு செய்யாமல் மாற்றங்களை முயற்சிக்க திட்டத்தைப் புதிய கோப்புறைக்கு நகலெடுக்க சோதனை நகலை உருவாக்குக என்பதைத் தட்டுங்கள். மூலக் கோப்புகள் மட்டுமே பதிவு செய்யப்படும்.

தொகுதித் தொழிற்சாலை
ஒரு திட்டத்தின் ஒரு பகுதியை மற்றொரு திட்டம் பயன்படுத்தக்கூடிய தொகுதியாகப் பொதி செய்ய: முதன்மை பட்டியலில் தொகுதித் தொழிற்சாலை என்பதைத் திறந்து, மூலத் திட்டத்தைத் தேர்ந்து, பொதி செய்ய வேண்டிய திரை, வகுப்பு, சரம் மற்றும் அனுமதிக் கோப்புகளைத் தேர்ந்து, பிறகு தொகுதியாகப் பொதி செய்க என்பதைத் தட்டுங்கள். IDE JSON மெட்டாடேட்டாவுடன் (தொகுதிப் பெயர், பதிப்பு, பயன்படுத்தப்பட்ட சரங்கள் மற்றும் அனுமதிகள்) ZIP காப்பகத்தை எழுதுகிறது. ஒரு தொகுதியை மற்றொரு திட்டத்தில் நிறுவ, தொகுதித் தொழிற்சாலை என்பதைத் திறந்து, இலக்குத் திட்டத்தைத் தேர்ந்து, பிறகு தொகுதியை நிறுவுக என்பதைத் தட்டி தொகுதியின் .zip கோப்பைத் தேர்ந்தெடுங்கள் — இணைப்பு ஏற்கனவே உள்ள குறியீட்டை மேலெழுதாமல் சரங்களையும் அனுமதிகளையும் சேர்க்கிறது, ஒரு கோப்பின் பெயர் இலக்குத் திட்டத்தில் ஏற்கனவே பயன்படுத்தப்பட்டால் அதை இணைக்காது. தொகுதி நூலகங்களையோ கட்டமைப்பு அமைப்புகளையோ கொண்டு வராது.

குறியீட்டு அமைப்பு குரல் கட்டளை
எடிட்டருக்குள் குரல் மூலம் குறியீடு எழுத: எடிட்டரில் ஒரு திட்டத்தைத் திறந்து, பிறகு குறியீட்டு அமைப்பு குரல் கட்டளை பொத்தானைத் தட்டுங்கள். இந்தோனேசிய மொழியில் கட்டளைகளைப் பேசுங்கள், எடுத்துக்காட்டாக buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil, அல்லது buat variabel teks nama sama dengan Budi — IDE பேச்சை இலக்கணப்படி சரியான Java, Kotlin, Python அல்லது Compose குறியீட்டுத் தொகுதியாக மாற்றி கர்சர் நிலையில் செருகி, பிறகு Jieshuo மூலம் சுருக்கமான சுருக்கத்தை உரக்க வாசிக்கிறது. குரல் கட்டளை அமைப்பின் உள்ளமைந்த குரல் உள்ளீட்டுச் சேவையைப் பயன்படுத்துகிறது, கூடுதல் ஒலிவாங்கி அனுமதி தேவையில்லை, ஏற்கனவே பதிவு செய்யப்பட்ட கட்டளை வடிவங்களை மட்டுமே அடையாளம் காண்கிறது; அந்த வடிவங்களுக்கு வெளியே உள்ள பேச்சு குறியீடாக மாற்றப்படாது. சொற்களால் பேசப்படும் எண்கள் (எடுத்துக்காட்டாக 'lima') இன்னும் இலக்கங்களாக மாற்றப்படவில்லை.

உள்ளூர் ஒத்துழைப்பு அறை (இணையம் இல்லாமல்)
இணையம் இல்லாமல் ஒரே அறையில் ஒன்றாக வேலை செய்ய: முதன்மை பட்டியலில் ஒத்துழைப்பு என்பதைத் திறந்து, பிறகு உள்ளூர் ஒத்துழைப்பு அறை பகுதியைத் திறங்கள். ஒரு தொலைபேசி அமர்வைத் திறக்கிறது (IDE உள்ளூர் IP முகவரியையும் 6 இலக்க PIN ஐயும் காட்டுகிறது), மற்றொரு தொலைபேசி அந்த முகவரி மற்றும் PIN மூலம் சேர்கிறது. உரை மாற்றங்கள் வரி வேறுபாடுகளாக அனுப்பப்படுகின்றன, கட்டப்பட்ட APK சோதனையாளரின் தொலைபேசிக்கு அனுப்பப்படலாம், சோதனையாளரின் தொலைபேசியிலிருந்து செயலிழப்பு அறிக்கைகள் திரும்பப் பெறப்படுகின்றன. ஒரு அமர்வு ஒரு நண்பருக்கு மட்டுமே; இரண்டு பேர் ஒரே நேரத்தில் சரியாக அதே வரியை மாற்றினால், கடைசி மாற்றம் பயன்படுத்தப்படும். PIN உள்ளூர் வலையமைப்பில் வெற்று உரையாக அனுப்பப்படுகிறது. இந்த அறை இன்னும் உண்மையான தொலைபேசியில் சோதிக்கப்படவில்லை.

AI அமைப்புகள்
செயலிகளை உருவாக்க AI வழங்குநர் மற்றும் API விசைகளை அமைக்க: முதன்மை பட்டியலில், அமைப்புகள் குழுவில், AI அமைப்புகள் என்பதைத் தட்டுங்கள் (இணைப்பான் பொத்தானுக்கு அடுத்து). கிடைக்கும் பட்டியலிலிருந்து பயன்படுத்த வேண்டிய வழங்குநரைத் தேர்ந்து, வழங்குநர் பிழையானால் மாதிரியை மாற்றவும் என்பதைத் தேர்ந்தெடுங்கள், இதனால் ஒரு மாதிரி தோல்வியுற்றால் IDE அதே வழங்குநரின் அடுத்த மாதிரியைத் தானாக முயற்சிக்கும். காப்பு விசைகளைச் சேர்க்க API விசைகளை நிர்வகிக்கவும் என்பதைத் தட்டுங்கள் (பெயர் மற்றும் விசையை நிரப்பி, பிறகு சேமிக்கவும் என்பதைத் தட்டுங்கள்; விசைகள் மறைத்துக் காட்டப்படும், கடைசி 4 எழுத்துகள் மட்டுமே தெரியும்). விசைகள் தொலைபேசியில் சேமிக்கப்படுகின்றன, செயலியை உருவாக்கும்போது தேர்ந்த வழங்குநருக்குத் தவிர வேறு எங்கும் அனுப்பப்படுவதில்லை. குறிப்பு: தற்போது வழங்குநர் மற்றும் விசைத் தேர்வு பதிவு செய்யப்பட்டு AI Pembuat Aplikasi திரையில் மட்டுமே காட்டப்படுகிறது — செயலி உருவாக்கம் இன்னும் தொலைபேசியில் உள்ள உள்ளூர் AI ஐப் (இணையம் இல்லாமல்) பயன்படுத்துகிறது; ஆன்லைன் வழங்குநர்களின் பயன்பாடு பின்னர் வரும்.

இணைப்பான்
APK ஐ பகுப்பாய்வு செய்து பிறகு அனுப்ப: முதன்மை பட்டியலில், அமைப்புகள் குழுவில், இணைப்பான் என்பதைத் தட்டுங்கள் (AI அமைப்புகள் பொத்தானுக்கு அடுத்து). தொலைபேசியிலிருந்து APK கோப்பைத் தேர்ந்தெடுங்கள், IDE அதன் உள்ளடக்கத்தைப் படிக்கிறது (தொகுப்புப் பெயர், பதிப்பு, செயல்பாடுகளின் பட்டியல்), பிறகு கணினி பகிர்வு பட்டியல் (எடுத்துக்காட்டாக WhatsApp அல்லது Drive) வழியாக அனுப்ப APK அனுப்பவும் என்பதைத் தட்டுங்கள்.

மொழி மற்றும் குரல்
செயலியின் மொழியை மாற்ற: அமைப்புகள் என்பதைத் திறந்து, பிறகு பயன்பாட்டு மொழி என்பதைத் திறந்து, பிறகு ஒரு மொழியை அல்லது கணினியைப் பின்பற்றவும் என்பதைத் தேர்ந்தெடுங்கள். முதன்மைத் திரையும் பெரும்பாலான திரைகளும் செயலியை மூடாமலோ மறுதொடக்கம் செய்யாமலோ உடனடியாகத் தேர்ந்த மொழிக்கு மாறும்; சில திரைகள் (எடுத்துக்காட்டாக Terminal, ஒத்துழைப்பு, AI அமைப்புகள் மற்றும் விசைகளை நிர்வகிக்கவும்) மீண்டும் திறக்கப்படும் வரை பழைய மொழியையே பயன்படுத்தும். கணினியைப் பின்பற்றவும் என்பதைத் தேர்ந்தால், மொழி தொலைபேசியின் கணினி மொழியைப் பின்பற்றும்.
