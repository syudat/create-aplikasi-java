Create Aplikasi by Al Kautsar-க்கு வரவேற்கிறோம்
Create Aplikasi என்பது மடிக்கணினி தேவையின்றி, நேரடியாகத் தொலைபேசியில் இயங்கும் ஒரு Android செயலி உருவாக்கும் செயலியாகும். இந்தச் செயலி, செயலிகளை உருவாக்கக் கற்றுக்கொள்ளத் தொடங்கிய பயனர்கள் மற்றும் திரை வாசிப்பான் பயனர்கள் உட்பட, எவரும் தங்கள் சொந்த Android செயலியை உருவாக்க அனுமதிக்கிறது. இந்தச் செயலியைப் பயன்படுத்துவதற்கான முழுமையான வழிகாட்டி இந்த Tentang Alat திரையில் கிடைக்கிறது.

இந்தச் செயலி என்ன, இது யாருக்கானது
Create Aplikasi என்பது தொலைபேசியில் இயங்கும் ஒரு Android செயலி உருவாக்கும் கருவியாகும். இந்தச் செயலி, தொடக்கநிலையினர் மற்றும் திரை வாசிப்பான் பயனர்கள் உட்பட, தங்கள் சொந்த Android செயலியை உருவாக்க விரும்பும் எவருக்கும் ஆனது. இந்தச் செயலி ஒரு குறியீட்டுத் தொகுப்பான், திட்டத்தைச் சோதிக்க Jalankan பொத்தான், APK உருவாக்க Bangun பொத்தான், மற்றும் APK-ஐக் கையொப்பமிட்டு நிறுவுவதற்கான பட்டிகளை வழங்குகிறது.

இந்தச் செயலியின் நோக்கம்
எவரும் எளிதாக, நேரடியாகத் தங்கள் தொலைபேசியிலிருந்து தங்கள் சொந்த Android செயலியை உருவாக்க முடியும் என்பதற்காக இந்தச் செயலி உருவாக்கப்பட்டது. புதிய பயனர்களும் உடனடியாக முயற்சி செய்யும் வகையில் இதன் தோற்றம் முடிந்தவரை எளிமையாக உருவாக்கப்பட்டுள்ளது.

படிப்படியாகப் புதிய திட்டத்தை உருவாக்குவது எப்படி
1. முதன்மைப் பட்டியில் Buat Project-ஐ அழுத்தவும்.
2. திட்ட வகையைத் தேர்ந்தெடுக்கவும்: HTML, Situs Web, Java, Kotlin, Compose, அல்லது Python.
3. செயலியின் பெயரை நிரப்பவும், எடுத்துக்காட்டு: Garuda Decode.
4. தொகுப்புப் பெயரை (package name) நிரப்பவும், எடுத்துக்காட்டு: com.android.garudadecode. தொகுப்புப் பெயர் சிற்றெழுத்துக்களைப் பயன்படுத்த வேண்டும் மற்றும் புள்ளியால் பிரிக்கப்பட்ட குறைந்தது இரண்டு பகுதிகளைக் கொண்டிருக்க வேண்டும்.
5. செயலியின் பதிப்பை நிரப்பவும், எடுத்துக்காட்டு: 1.0, மற்றும் எண் வடிவில் பதிப்புக் குறியீட்டை நிரப்பவும், எடுத்துக்காட்டு: 1. காலியாக விட்டால், பதிப்பு தானாகவே 1.0 என்றும் பதிப்புக் குறியீடு 1 என்றும் நிரப்பப்படும்.
6. தேவைப்பட்டால் குறைந்தபட்ச SDK மற்றும் இலக்கு SDK-ஐ நிரப்பவும். காலியாக விட்டால், இயல்புநிலை மதிப்புகள் பயன்படுத்தப்படும். குறைந்தபட்ச SDK என்பது ஆதரிக்கப்படும் மிகக் குறைந்த Android பதிப்பாகும், எடுத்துக்காட்டு: 21 என்றால் Android 5.0. அதிகபட்ச இலக்கு SDK 36 (Android 16).
7. செயலியின் அனுமதிகளைத் தேர்ந்தெடுக்க Pilih Izin பொத்தானை அழுத்தவும், எடுத்துக்காட்டு: INTERNET. INTERNET அனுமதி இயல்பாகவே முன்கூட்டியே குறிக்கப்பட்டுள்ளது. செயலிக்கு உண்மையில் தேவைப்படும் அனுமதிகளை மட்டுமே குறிக்கவும்.
8. விரும்பினால், APK அளவு சிறியதாக இருக்க "Gunakan arsitektur terpisah 64 bit dan 32 bit" என்பதைக் குறிக்கவும், மேலும் நீங்களே உருவாக்கிய keystore-ஐப் பயன்படுத்த விரும்பினால் "Gunakan tanda tangan pribadi" என்பதைக் குறிக்கவும்.
9. Buat Proyek-ஐ அழுத்தவும். புதிய திட்டம் Download/project கோப்புறையில் சேமிக்கப்பட்டு உடனடியாக Kelola Project-இல் தெரியும்.

கிடைக்கும் திட்ட வகைகள்
• HTML: index.html, style.css, மற்றும் script.js ஆகியவற்றிலிருந்து தோற்றம், WebView வழியாக இயங்குகிறது. நேரடியாகத் தொலைபேசியில் உருவாக்கப்படுகிறது.
• Situs Web: index.html, tentang.html, kontak.html, style.css, மற்றும் script.js ஆகியவற்றிலிருந்து பட்டியுடன் (Beranda, Tentang, Kontak) கூடிய வலைத்தளம், WebView வழியாக இயங்குகிறது. நேரடியாகத் தொலைபேசியில் உருவாக்கப்படுகிறது.
• Java: தொலைபேசியில் உருவாக்கப்படுகிறது. MainActivity app/src/main/java/<nama-paket>/MainActivity.java-இல் உள்ளது. தோற்றம் app/src/main/res/layout/activity_main.xml-இலிருந்தும், உரை app/src/main/res/values/strings.xml-இலிருந்தும், கருப்பொருள் app/src/main/res/values/styles.xml-இலிருந்தும் வருகிறது.
• Kotlin: செயலியில் சேர்க்கப்பட்டுள்ள Kotlin தொகுப்பானைப் பயன்படுத்தி சாதனத்தில் (ஆஃப்லைனில்) உருவாக்கலாம், அல்லது GitHub Actions வழியாக உருவாக்கலாம். MainActivity app/src/main/java/<nama-paket>/MainActivity.kt-இல் உள்ளது, மற்றும் res கோப்புகள் Java திட்டத்தில் உள்ளதைப் போன்றவையே. தொகுப்பானின் பெரிய அளவு காரணமாக முதல் Kotlin உருவாக்கம் மெதுவாக இருக்கும், மேலும் Kotlin வகுப்புகளைக் குறிப்பிடும் .java கோப்புகளை இன்னும் உருவாக்க முடியாது (.java கோப்புகள் .kt கோப்புகளுக்கு முன் தொகுக்கப்படுகின்றன).
• Compose: இடைமுகம் Jetpack Compose கொண்டு உருவாக்கப்பட்ட நவீன Android செயலி (XML தளவமைப்பு அல்ல). MainActivity app/src/main/java/<nama-paket>/MainActivity.kt-இல் உள்ளது. Compose-க்கு சாதனத்தில் கிடைக்காத Jetpack Compose நூலகங்கள் தேவைப்படுவதால், Compose திட்டங்கள் GitHub Actions வழியாக (Bangun proyek பட்டி, பின்னர் Bangun online) அல்லது Termux-இல் Gradle கொண்டு உருவாக்கப்படுகின்றன.
• Python: செயலியின் தர்க்கம் Python மொழியில் (Chaquopy) app/src/main/python/main.py-இல் எழுதப்பட்டு, app/src/main/java/<nama-paket>/MainActivity.java-இல் உள்ள புரவலன் MainActivity.java மூலம் இயக்கப்படுகிறது. Python திட்டங்களை நேரடியாகத் தொலைபேசியில் உருவாக்கலாம் (Chaquopy இயக்க நேரம் செயலியில் சேர்க்கப்பட்டுள்ளது) அல்லது GitHub Actions வழியாகவும் உருவாக்கலாம். Python திட்டங்களுக்கான குறைந்தபட்ச SDK 24 (Android 7.0).

திட்டக் கட்டமைப்பை மாற்று
ஏற்கனவே உள்ள திட்டத்தின் கட்டமைப்பு விருப்பங்களை புதிய திட்டத்தை உருவாக்காமல் மாற்ற: முதன்மை மெனுவில், «திட்டக் கட்டமைப்பை மாற்று» என்பதை அழுத்தி, திட்டத்தைத் தேர்ந்து, «64-பிட் APK-ஐ உருவாக்கு (arm64-v8a)» அல்லது «32-பிட் APK-ஐ உருவாக்கு (armeabi-v7a)» என்ற தேர்வுப்பெட்டியை மாற்றுக; அல்லது «திட்டத்தை நிர்வகிக்கவும்» என்பதில் திட்டத்தின் பெயரை நீண்ட நேரம் அழுத்தி, அதே திரையை அந்தத் திட்டத்திற்கு நேரடியாகத் திறக்க «கட்டமைப்பை மாற்று» என்பதைத் தேர்ந்தெடுக்கவும். விதி: இரண்டு தேர்வுப்பெட்டிகளும் இயக்கத்தில் இருந்தால், உருவாக்கம் இரண்டு தனி APK களை உருவாக்கும், ஒன்று 64-பிட் மற்றொன்று 32-பிட்; ஒரு தேர்வுப்பெட்டி மட்டும் இயக்கத்தில் இருந்தால், உருவாக்கம் 64-பிட் மற்றும் 32-பிட் சாதனங்களில் தொடர்ந்து இயங்கும் ஒரே ஒரு உலகளாவிய APK ஐ உருவாக்கும். ஒரே ஒரு வகைக்கு மட்டும் தனி APK இன்னும் ஆதரிக்கப்படவில்லை, ஏனெனில் உருவாக்கப் பாதை பிரிவு அல்லது உலகளாவிய தேர்வை மட்டுமே அறியும், ஆனால் ஒவ்வொரு வகையின் தேர்வும் திட்டத்திற்குள் சேமிக்கப்பட்டிருக்கும், திரையை மீண்டும் திறக்கும்போது இழக்கப்படாது.

Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களின் கோப்பு அமைப்பு
Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்கள் பொதுவாக Android திட்டங்களைப் போலவே அமைக்கப்பட்டுள்ளன. app கோப்புறையின் உள்ளே src கோப்புறை உள்ளது, அதன் உள்ளே main கோப்புறை உள்ளது. main கோப்புறையின் உள்ளே java கோப்புறைக்கு அருகில் AndroidManifest.xml உள்ளது, layout/activity_main.xml மற்றும் values/strings.xml மற்றும் values/styles.xml ஆகியவற்றைக் கொண்ட res கோப்புறை உள்ளது, மேலும் HTML மற்றும் Situs Web-க்கு index.html-ஐக் கொண்ட assets கோப்புறை உள்ளது (Situs Web-இல் tentang.html மற்றும் kontak.html-ம் உள்ளன). HTML மற்றும் Situs Web திட்டங்களுக்கும் app/src/main/java/<nama-paket>/MainActivity.java-இல் தங்கள் சொந்த MainActivity உள்ளது, இது WebView-இல் index.html-ஐ ஏற்றி AndroidManifest-இல் துவக்கியாகச் செயல்படுகிறது. Python திட்டங்களில் Python குறியீடு app/src/main/python/main.py-இலும் புரவலன் MainActivity.java app/src/main/java/<nama-paket>/MainActivity.java-இலும் உள்ளது. AndroidManifest.xml, தளவமைப்பு, strings, மற்றும் styles ஆகியவற்றை MainActivity-ஐப் போலவே தொகுப்பானில் திறந்து மாற்றலாம். வெளிப்பாடு இன்னும் app கோப்புறைக்கு அருகில் இருக்கும் பழைய திட்டங்களையும் உருவாக்க முடியும், ஏனெனில் உருவாக்கும் போது, செயலி முதலில் app/src/main/-இல் AndroidManifest.xml-ஐச் சரிபார்க்கிறது, பின்னர் app கோப்புறைக்கு அருகில் உள்ளதை, இறுதியாகத் திட்டத் தரவுக் கோப்பைச் சரிபார்க்கிறது.

அனுமதி விதிகள் (முக்கியம்)
திட்டத்தை உருவாக்கும் போது குறிக்கப்படும் அனுமதிகள், திட்ட வகைக்கு ஏற்ப, ஒரே ஒரு இடத்தில் மட்டுமே பதிவு செய்யப்படுகின்றன. Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களுக்கு, குறிக்கப்பட்ட அனுமதிகள் திட்டக் கோப்புறையின் உள்ளே, java கோப்புறைக்கு அருகில், app/src/main/-இல் உள்ள AndroidManifest.xml-இல் மட்டுமே பதிவு செய்யப்படுகின்றன. Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களுக்கான திட்டத் தரவுக் கோப்பில் அனுமதிகளின் பட்டியல் இல்லை. நீங்கள் Java-வைத் தேர்ந்தெடுத்து INTERNET மற்றும் CAMERA-வைக் குறித்தால், AndroidManifest.xml-இல் பதிவாவது INTERNET மற்றும் CAMERA மட்டுமே, வேறு எந்த அனுமதியும் சேராது. உருவாக்கும் போது, செயலி அதே இடத்திலிருந்து அனுமதிகளைப் படிக்கிறது: Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களுக்கு app/src/main/-இல் உள்ள AndroidManifest.xml-இலிருந்து (இல்லாவிட்டால், பழைய திட்டங்களுக்கு app கோப்புறைக்கு அருகில் உள்ள AndroidManifest.xml-இலிருந்து), மற்றும் பழைய திட்டங்களுக்குத் திட்டத் தரவுக் கோப்பிலிருந்து.

தொகுப்பானைப் பயன்படுத்துவது எப்படி
Kelola Project-ஐத் திறந்து, தொகுப்பானைத் திறக்கத் திட்டத்தின் பெயரைத் தட்டவும். தொகுப்பானில், கோப்புகளைத் திறக்கலாம், குறியீட்டை எழுதலாம், மாற்றங்களைச் சேமிக்கலாம். Java, HTML, Situs Web, Kotlin, Compose, மற்றும் Python திட்டங்களுக்கு, கோப்புகள் app/src/main கோப்புறையின் உள்ளே அமைக்கப்பட்டுள்ளன. ஒரு திட்டத்தைப் பகிர, Ekspor ZIP-ஐப் பயன்படுத்தவும் (கீழே உள்ள பகுதியைப் பார்க்கவும்).

திட்டத்தை இயக்குவது எப்படி
தொகுப்பானில், திட்டத்தைச் சோதிக்க Jalankan-ஐ அழுத்தவும். HTML மற்றும் Situs Web திட்டங்களுக்கு, இயக்கப்படுவது WebView வழியாக index.html ஆகும். பிழை ஏற்பட்டால், பிழைச் செய்தியைப் படித்து, குறியீட்டைச் சரிசெய்து, மீண்டும் இயக்கவும்.

APK-ஐ உருவாக்குவது எப்படி
தொகுப்பானில், Bangun-ஐ அழுத்தவும். உருவாக்க இரண்டு வழிகள் உள்ளன. முதலாவது, Bangun di perangkat: இணையம் இல்லாமல் நேரடியாகத் தொலைபேசியில் உருவாக்குதல், HTML, Situs Web, Java, Kotlin, மற்றும் Python திட்டங்களுக்கு. இரண்டாவது, GitHub Actions வழியாக Bangun online: இணையம் வழியாக GitHub-இல் உருவாக்குதல், மேலும் எல்லா வகைத் திட்டங்களுக்கும் பயன்படுத்தலாம். Compose-க்கு சாதனத்தில் கிடைக்காத Jetpack Compose நூலகங்கள் தேவைப்படுவதால், Compose திட்டங்களை இரண்டாவது வழியில் (Bangun online) அல்லது Termux-இல் Gradle கொண்டு மட்டுமே உருவாக்க முடியும். முதல் உருவாக்கத்தின் முடிவு இன்னும் கையொப்பமிடப்படவில்லை. அதன் பிறகு செயலி அதைக் கையொப்பமிடுகிறது: இயல்புநிலை விசையுடன் தானாகவே, அல்லது திட்டத்தை உருவாக்கும் போது "Gunakan tanda tangan pribadi" பெட்டி குறிக்கப்பட்டிருந்தால் தனிப்பட்ட கையொப்பத்துடன்.

APK-ஐ நிறுவுவது எப்படி
APK தயாரானதும், அதை நிறுவ Pasang-ஐ அழுத்தவும். Android 8 மற்றும் அதற்கு மேல், இந்தச் செயலி Play Store-க்கு வெளியில் இருந்து APK-களை நிறுவுவதால், தொலைபேசி முதலில் "Izinkan dari sumber ini" என்று கேட்கும். Pengaturan-இல் அந்த அனுமதியை ஒருமுறை இயக்கிவிட்டு, செயலிக்குத் திரும்பவும்: Pasang-ஐ மீண்டும் அழுத்த வேண்டியதில்லாமல் நிறுவல் தானாகவே தொடரும். Pasang பொத்தான் தோன்றாவிட்டால், உருவாக்கம் முடிந்துவிட்டதையும் APK உருவாக்கப்பட்டுவிட்டதையும் உறுதிப்படுத்தவும்.

செயலியில் கையொப்பமிடுவது எப்படி
ஒவ்வொரு APK-வும் நிறுவப்படுவதற்குக் கையொப்பமிடப்பட வேண்டும். இரண்டு தேர்வுகள் உள்ளன. முதலாவது, இயல்புநிலை விசை: நீங்கள் எதுவும் செய்ய வேண்டியதில்லாமல், செயலி தானாகவே கையொப்பமிடுகிறது. இரண்டாவது, தனிப்பட்ட கையொப்பம்: முதலில் முதன்மைப் பட்டியில் உள்ள Buat Keystore பட்டி வழியாக ஒரு keystore-ஐ உருவாக்கவும், அதன் கடவுச்சொல்லைப் பத்திரமாக வைக்கவும், பின்னர் திட்டத்தை உருவாக்கும் போது "Gunakan tanda tangan pribadi" என்பதைக் குறிக்கவும். Keystore Download/project/signing-இல் சேமிக்கப்படுகிறது.

திட்டத்தை ZIP ஆக ஏற்றுமதி செய்தல்
நண்பர்களுடன் திட்டங்களைப் பகிர முடியும் என்பதற்காக Ekspor ZIP வழங்கப்படுகிறது. வழிமுறை: Kelola Project-இல், திட்டத்தின் பெயரை நீண்ட நேரம் அழுத்திப் பிடித்து, பின்னர் Ekspor ZIP-ஐத் தேர்ந்தெடுக்கவும். முடிவு Download/project/<NamaProyek>.zip-இல் சேமிக்கப்படுகிறது. bin கோப்புறை சேர்க்கப்படாததால், அளவு சிறியது, வெறும் பத்துக்கணக்கான KB மட்டுமே. அந்த ZIP கோப்பை நண்பருக்கு அனுப்பலாம் அல்லது GitHub-இல் பதிவேற்றலாம்.

JAWS நீட்டிப்பு
JAWS நீட்டிப்பு Jieshuo (CSR)-இன் நீட்டிப்பு இயந்திரத்தைப் பயன்படுத்துகிறது, அதன் திரை வாசிப்பானை அல்ல. இதன் மூலம், பயனர் TalkBack-ஐப் பயன்படுத்தினாலும் வடிவமைப்பு இயங்க முடியும். வழிமுறை: முதன்மைப் பட்டியில் Ekstensi JAWS-ஐத் திறக்கவும். தானியங்கு கிளிக் தானாகவே இயங்குவதால், சேவையை முதலில் Pengaturan Aksesibilitas-இல் இயக்க வேண்டும். அதன் பிறகு, ஒரு புதிய வடிவமைப்பை உருவாக்கலாம்: வடிவமைப்பின் பெயரைத் தட்டச்சு செய்து, OK அழுத்தி, பின்னர் அதன் பெட்டிகளை நிரப்பவும்.

ஒழுங்காக இருக்க Daftar Klik பிரிக்கப்பட்டுள்ளது
வடிவமைப்பின் உள்ளே இரண்டு பெட்டிகள் உள்ளன: ஸ்கிரிப்ட் பெட்டி மற்றும் Daftar Klik பெட்டி. பொத்தான்களின் பட்டியல் daftar_klik.txt கோப்பில் தனியாகச் சேமிக்கப்படுகிறது, ஒரு வரிக்கு ஒரு பெயர். அதன் உள்ளடக்கத்தின் எடுத்துக்காட்டு: tombolSimpan, tombolHapus, tombolBuka. ஒரு செயலியைத் திறக்க, அந்தப் பட்டியில் >WhatsApp என்று எழுதினால் போதும். இன்னும் daftar_klik.txt கோப்பு இல்லாத பழைய வடிவமைப்புகள் அந்த இயல்புநிலை எடுத்துக்காட்டைக் காண்பிக்கும்.

வழங்கப்படும் எளிய செயல்பாடுகள்
• klikTombol("tombolSimpan") — அதன் உரையின் அடிப்படையில் ஒரு பொத்தானைக் கிளிக் செய்கிறது.
• klikDaftarTombol(daftar) — daftar_klik.txt-இல் உள்ள பட்டியலைக் கிளிக் செய்கிறது, ஒரு வரிக்கு ஒரு பொத்தான், வரிசையாக, பின்னர் எத்தனை வெற்றி பெற்றன, எத்தனை கிடைக்கவில்லை என்று தெரிவிக்கிறது.
• bukaAplikasi("WhatsApp") — அதன் பெயரால் ஒரு செயலியைத் திறக்கிறது, அல்லது பட்டியில் ">WhatsApp" என்று எழுதவும்.
• klik(540, 1200) — திரை ஆயங்களில் கிளிக் செய்கிறது.
எல்லாச் செயல்பாடுகளும் முதலில் எளிமையாக உருவாக்கப்பட்டுள்ளன. பழகிய பிறகு, கூடுதல் செயல்பாடுகளைப் பின்னர் சேர்க்கலாம்.

திரை வாசிப்பான் பற்றி
இந்தச் செயலி திரை வாசிப்பானுக்கு ஏற்றதாக வடிவமைக்கப்பட்டுள்ளது. ஒவ்வொரு உள்ளீட்டுப் புலத்திற்கும் ஒரு குறிப்பும் நிரப்பும் எடுத்துக்காட்டும் உள்ளது, மேலும் எல்லாப் பொத்தான்களையும் சிக்கலான சைகைகள் இல்லாமல் அடைய முடியும். JAWS நீட்டிப்பு, பயனர் TalkBack-ஐப் பயன்படுத்தினாலும் இயங்கும் வகையில் உருவாக்கப்பட்டுள்ளது, ஏனெனில் பயன்படுத்தப்படுவது அதன் நீட்டிப்பு இயந்திரமே, அதன் திரை வாசிப்பான் அல்ல.

தனியுரிமை மற்றும் பாதுகாப்பு
திட்டங்களும் keystore-ம் உங்கள் தொலைபேசியில் சேமிக்கப்படுகின்றன. GitHub டோக்கன் ஆன்லைன் உருவாக்கங்களுக்கு மட்டுமே பயன்படுத்தப்படுகிறது மற்றும் இந்தச் செயலியின் உள்ளே சேமிக்கப்படுகிறது. உங்கள் டோக்கனையோ keystore கடவுச்சொல்லையோ யாருடனும் பகிர வேண்டாம். தனிப்பட்ட கையொப்பத்தைப் பயன்படுத்தினால், keystore-ஐயும் அதன் கடவுச்சொல்லையும் பாதுகாப்பான இடத்தில் வைக்கவும், ஏனெனில் அவை தொலைந்தால், பழைய APK-ஐ அதே கையொப்பத்துடன் புதுப்பிக்க முடியாது.

தேவைகள்
Android 5.0 அல்லது அதற்கு மேற்பட்டது. சேமிப்பு அனுமதி: Android 11 மற்றும் அதற்கு மேல் எல்லாக் கோப்புகளுக்குமான அணுகல் அனுமதியைப் பயன்படுத்துகிறது, Android 10 மற்றும் அதற்குக் கீழே வழக்கமான சேமிப்பு அனுமதியைப் (சேமிப்பைப் படி/எழுது) பயன்படுத்துகிறது, ஏனெனில் Android 10-இல் எல்லாக் கோப்புகளுக்குமான அணுகல் அனுமதி இல்லை. சாதனத்தில் உருவாக்க ARM செயலி (32 அல்லது 64 பிட்) கொண்ட தொலைபேசி தேவை. GitHub Actions வழியாக ஆன்லைனில் உருவாக்க இணையமும் GitHub டோக்கனும் தேவை. Kotlin திட்டங்களைச் சாதனத்தில் உருவாக்கலாம், ஆனால் Kotlin தொகுப்பானின் பெரிய அளவு காரணமாக அதன் முதல் உருவாக்கம் மெதுவாகவும் அதிக நினைவகத்தைப் பயன்படுத்தியும் இருக்கும். Compose திட்டங்கள் GitHub Actions வழியாக அல்லது Termux-இல் Gradle கொண்டு உருவாக்கப்படுகின்றன. Python திட்டங்களுக்கு Android 7.0 அல்லது அதற்கு மேற்பட்டது (குறைந்தபட்ச SDK 24) தேவை, மேலும் விளையும் APK பெரியதாக இருக்கும், ஏனெனில் அதில் Python இயக்க நேரம் (Chaquopy) மற்றும் அதன் நிலையான நூலகம் அடங்கும்.

Terminal
முதன்மைத் திரையில் உள்ள Terminal பட்டி இந்தச் செயலியின் உள்ளே ஒரு முனையத்தைத் திறக்கிறது. திட்டக் கோப்புறையின் உள்ளடக்கத்தைப் பார்க்க ls, கோப்புறைகளை மாற்ற cd, குறியீட்டை நிர்வகிக்க git போன்ற கட்டளைகளைப் பயன்படுத்தலாம். கட்டளை வெளியீடு திரை வாசிப்பானால் படிக்கக்கூடிய உரையாகத் தோன்றுகிறது, மேலும் கடைசி முடிவைக் கேட்க Bacakan hasil பொத்தான் உள்ளது. இந்த முனையம் தொலைபேசியின் அமைப்பு ஷெல்லைப் பயன்படுத்துகிறது, எனவே nano மற்றும் vim போன்ற ஊடாடும் நிரல்களை இங்கே இன்னும் பயன்படுத்த முடியாது.

உரிமம் (கட்டணப் பதிப்பு)
செயலிகளை விற்க, திட்டத்தை உருவாக்கும் போது "Aktifkan Lisensi" என்பதைக் குறித்து, பின்னர் உங்கள் WhatsApp எண்ணை நிரப்பவும். உருவாக்கத்தின் விளைவான செயலி முதன்முறை திறக்கப்படும் போது ஒரு உரிமக் குறியீட்டைக் கேட்கும்: பயனர் தங்கள் சாதன ID-ஐப் பார்த்து, அந்த ID-ஐ உங்கள் WhatsApp-க்கு அனுப்ப Kirim ID Perangkat பொத்தானை அழுத்துவார், பின்னர் நீங்கள் உரிமக் குறியீட்டுடன் பதிலளிப்பீர்கள். உரிமக் குறியீடு சாதன ID மற்றும் திட்டக் கடவுச்சொல்லிலிருந்து (திட்டத் தரவுக் கோப்பில் உள்ள lisensi_seed) கணக்கிடப்படுகிறது — அந்தக் கடவுச்சொல்லைப் பத்திரமாக வைத்து, பகிர வேண்டாம். சரியான குறியீடு உள்ளிடப்பட்ட பிறகு, செயலி திறக்கும், மீண்டும் குறியீட்டைக் கேட்காது.

Pembuat Ikon Otomatis
புதிய திட்டச் சின்னங்கள் இன்னும் ஒளிபுகும் தன்மையுடன் இருப்பதால், முதன்மைப் பட்டியில் Pembuat Ikon கிடைக்கிறது. வழிமுறை: Pembuat Ikon-ஐ அழுத்தி, ஒன்று அல்லது இரண்டு எழுத்துக்களை எழுதி (எடுத்துக்காட்டாக, செயலியின் பெயரின் தலைப்பெழுத்துக்கள்), பின்னணி நிறத்தையும் உரை நிறத்தையும் தேர்ந்தெடுத்து, அதன் முன்னோட்டத்தைப் பார்த்து, பின்னர் தேர்ந்தெடுக்கப்பட்ட திட்டத்தில் அந்தச் சின்னத்தைப் பயன்படுத்த Simpan ke Proyek-ஐ அழுத்தவும், அல்லது அதன் PNG கோப்பை வேறு இடத்தில் பயன்படுத்த Simpan ke Download-ஐ அழுத்தவும். ஒரு திட்டம் உருவாக்கப்பட்ட பிறகு, செயலி ஒரு சின்னத்தை உருவாக்கவும் முன்வருகிறது. பழைய திட்டச் சின்னங்களை Kelola Project-இல் உள்ள திட்டப் பட்டியிலிருந்து எந்த நேரத்திலும் மாற்றலாம் (திட்டத்தின் பெயரை நீண்ட நேரம் அழுத்திப் பிடித்து, பின்னர் Ganti Ikon-ஐத் தேர்ந்தெடுக்கவும்).

தயாரான திட்ட வார்ப்புருக்கள்
வெற்றுத் திட்டத்திலிருந்து தொடங்க விரும்பாவிட்டால், திட்டத்தை உருவாக்கும் போது ஒரு வார்ப்புருவைத் தேர்ந்தெடுக்கவும்: Kalkulator (Java), Catatan (Java), Daftar Tugas (Kotlin), Kalkulator Web (HTML), Situs Profil (Situs Web), அல்லது Penghitung (Compose). ஒரு வார்ப்புருவைத் தேர்ந்தெடுப்பது திட்ட வகையைத் தானாகவே அந்த வார்ப்புருவைப் பின்பற்றுமாறு மாற்றுகிறது, மேலும் திட்டம் தயாரான தொடக்கக் குறியீட்டுடன் உருவாக்கப்படுகிறது — அதை இயக்கவோ மாற்றவோ மட்டுமே மீதம் உள்ளது. வார்ப்புருவைத் தேர்ந்தெடுத்த பிறகு திட்ட வகையை மீண்டும் கைமுறையாக மாற்றினால், வார்ப்புரு ரத்து செய்யப்பட்டு, திட்டம் மீண்டும் காலியாகிவிடும். HTML மற்றும் Situs Web வார்ப்புருக்களுக்கு, படிவத்தில் தட்டச்சு செய்யப்பட்ட HTML ஸ்கிரிப்ட் உட்பட, வார்ப்புரு index.html-இன் உள்ளடக்கத்தை மாற்றீடு செய்கிறது.

திட்டக் காப்புப்பிரதி மற்றும் மீட்டமைப்பு
திட்டங்கள் தொலைந்து போகாமல் இருக்க, ஒரு காப்புப்பிரதி அம்சம் உள்ளது. வழிமுறை: Kelola Project-இல், திட்டத்தின் பெயரை நீண்ட நேரம் அழுத்திப் பிடித்து, பின்னர் Cadangkan-ஐத் தேர்ந்தெடுக்கவும். காப்புப்பிரதி Download/backup கோப்புறையில் திட்டத்தின் பெயர் மற்றும் தேதியுடன் ZIP ஆகச் சேமிக்கப்படுகிறது, எடுத்துக்காட்டு: GarudaDecode-2026-11-14-123045.zip. அதன் உள்ளடக்கம் Ekspor ZIP-ஐப் போன்றதே (முழுத் திட்டம், bin கோப்புறை இல்லாமல்). மீட்டமைக்க: Kelola Project-இல் பட்டியைத் திறந்து, Pulihkan cadangan-ஐத் தேர்ந்தெடுத்து, பின்னர் காப்புப்பிரதிக் கோப்பைத் தேர்ந்தெடுக்கவும். திட்டத்தின் பெயர் ஏற்கனவே இருந்தால், செயலி கேட்கும்: Timpa proyek lama, அல்லது Nama baru உடன் சேமிக்கவும்.

திட்டங்களைப் பகிர்தல் மற்றும் இறக்குமதி செய்தல்
ஒரு நண்பருடன் திட்டத்தைப் பகிர: Kelola Project-இல், திட்டத்தின் பெயரை நீண்ட நேரம் அழுத்திப் பிடித்து, பின்னர் Bagikan-ஐத் தேர்ந்தெடுக்கவும். திட்டம் பகிர்வுச் செயலிகள் (WhatsApp, Telegram, மற்றும் பிற) வழியாக ZIP ஆக அனுப்பப்படுகிறது. ஒரு நண்பரிடமிருந்து திட்டத்தைப் பெற: Kelola Project-இல் பட்டியைத் திறந்து, Impor proyek-ஐத் தேர்ந்தெடுத்து, பின்னர் அதன் ZIP கோப்பைத் தேர்ந்தெடுக்கவும். அந்த ZIP கோப்பில் ஒரு திட்டத் தரவுக் கோப்பு இருக்க வேண்டும் — இல்லாவிட்டால், அந்தக் கோப்பு Create Aplikasi திட்டம் அல்ல என்பதால், கோப்பு தெளிவான செய்தியுடன் நிராகரிக்கப்படும். திட்டத்தின் பெயர் ஏற்கனவே இருந்தால், செயலி கேட்கும்: Timpa proyek lama, அல்லது Nama baru உடன் சேமிக்கவும்.

திட்டத் தேடல் மற்றும் வடிப்பான்
திட்டங்கள் அதிகமானால், Kelola Project-இல் ஒரு தேடல் பெட்டியும் வகை வடிப்பானும் உள்ளது. தேடல் பெட்டியில் திட்டத்தின் பெயரைத் தட்டச்சு செய்யவும், பட்டியல் உடனடியாக வடிகட்டப்படும் (பெரிய மற்றும் சிறிய எழுத்துக்கள் வேறுபடுத்தப்படாது). வகை வடிப்பான் பட்டியலை ஒரே ஒரு வகைக்கு மட்டுப்படுத்துகிறது: Semua, HTML, Situs Web, Java, Kotlin, Compose, அல்லது Python. வடிகட்டப்பட்ட பட்டியலிலிருந்தும் ஒவ்வொரு திட்டத்தின் பட்டியையும் வழக்கம் போலத் திறக்கலாம்.

குரல் மூலம் பயன்பாட்டை உருவாக்கவும்
தட்டச்சு செய்ய விரும்பவில்லை என்றால், குரலைப் பயன்படுத்துங்கள்: முதன்மை பட்டியலில் குரல் மூலம் உருவாக்கவும் என்பதைத் தட்டி, பிறகு ஒரு கட்டளையைப் பேசுங்கள். பேசக்கூடிய கட்டளைகள்: "Buat proyek kalkulator", "Bangun proyek Kalkulator", "Buka proyek Kalkulator", "Jalankan proyek Kalkulator", "Daftar proyek", "Buka ikon", "Kembali" மற்றும் "Bantuan". செயலி குரல் மற்றும் உரை மூலம் பதிலளிக்கிறது, எனவே திரையைப் பார்க்காமலும் பயன்படுத்தலாம். குரல் அடையாளம் தொலைபேசியின் உள்ளமைந்த பேச்சு அடையாள செயலியைப் பயன்படுத்துகிறது (இலவசம்; இந்தோனேசிய மொழித் தொகுப்பு நிறுவப்பட்டிருந்தால் ஆஃப்லைனிலும் இயங்கும்). தொலைபேசியில் குரல் அடையாளம் இல்லை என்றால், அதே திரையில் உள்ள உரைப் பெட்டியில் கட்டளைகளைத் தட்டச்சு செய்யலாம்.

AI பயன்பாட்டு உருவாக்கி திரையில் விரும்பிய பயன்பாட்டைத் தட்டச்சு செய்யுங்கள் அல்லது குரலில் கூறுங்கள், எடுத்துக்காட்டு: «சேமி பொத்தானுடன் கூடிய குறிப்பு பயன்பாடு». பயன்பாடு தொலைபேசியின் உள்ளேயே முக்கியச் சொற்களைப் பகுப்பாய்வு செய்கிறது (இணையம் இல்லாமல், கட்டணம் இல்லாமல்), பின்னர் மிகவும் பொருந்தும் வார்ப்புருவிலிருந்து உண்மையான திட்டத்தை உருவாக்குகிறது: கால்குலேட்டர், குறிப்புகள், பணிப்பட்டியல், வலை கால்குலேட்டர், சுயவிவரத் தளம் அல்லது எண்ணி. உங்கள் விளக்கத்திற்கு இன்னும் பொருந்தும் வார்ப்புரு இல்லையெனில், பயன்பாடு வெற்றுத் திட்டத்தை உருவாக்கி அதை நேர்மையாகக் கூறுகிறது — புரிந்துகொண்டதாக நடிக்காது. AI ஆல் உருவாக்கப்பட்ட திட்டத்தைத் திட்டத்தை நிர்வகிக்கவும் இல் நேரடியாகத் திறக்கலாம்.

நண்பரின் தொலைபேசிக்கு நேரடி முன்னோட்டம்
உருவாக்குவதற்கு முன் திட்டத்தை நண்பருக்குக் காட்ட: திட்டத்தை நிர்வகிக்கவும் இல் திட்டப் பெயரை நீண்ட நேரம் அழுத்தி, நண்பரின் தொலைபேசிக்கு முன்னோட்டம் என்பதைத் தேர்ந்தெடுக்கவும். பயன்பாடு திட்டத்தின் முக்கியக் கோப்புகள் (index.html, MainActivity அல்லது main.py) மற்றும் வழிமுறைகள் கொண்ட BACA-SAYA.txt, info.txt ஆகியவற்றைக் கொண்ட சிறிய முன்னோட்டத் தொகுப்பை உருவாக்குகிறது. தொகுப்பு ZIP ஆக WhatsApp அல்லது Telegram வழியாக அனுப்பப்படுகிறது. பெறும் நண்பர் முன்னோட்டத்தை உடனே திறக்கலாம்: HTML பக்கங்கள் உலாவியில் திறக்கும், Java/Kotlin/Python குறியீடு உரையாகப் படிக்கப்படும்.

திட்டச் சந்தை
திட்டச் சந்தை ஒரே தட்டலில் திட்டக் கோப்புறையில் நிறுவக்கூடிய உள்ளமைக்கப்பட்ட மாதிரித் திட்டங்களைக் கொண்டுள்ளது: கால்குலேட்டர், குறிப்புகள், பணிப்பட்டியல், வலை கால்குலேட்டர், சுயவிவரத் தளம், எண்ணி, டிஜிட்டல் கடிகாரம் மற்றும் வலை வினாடி வினா. ஆன்லைன் சந்தை (இணையத்திலிருந்து மாதிரிகளைப் பதிவிறக்குதல்) இன்னும் கிடைக்கவில்லை, எனவே இந்தச் சந்தையில் பயன்பாட்டின் உள்ளே ஏற்கனவே உள்ள மாதிரிகள் உள்ளன. நிறுவப்பட்ட திட்டத்தை நீங்களே உருவாக்கிய திட்டத்தைப் போலத் திட்டத்தை நிர்வகிக்கவும் இல் திறந்து மாற்றலாம்.

நேரடி ஒத்துழைப்பு
நண்பருடன் சேர்ந்து திட்டத்தில் பணியாற்ற: முதன்மைப் பட்டியலில் ஒத்துழைப்பு என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, மாற்றக் குறிப்பை (எது மாற்றப்பட்டது) எழுதி, ஒத்துழைப்புக்காகப் பகிரவும் என்பதை அழுத்தவும். திட்டம் அதன் உள்ளே CATATAN.txt கோப்புடன் ZIP ஆக அனுப்பப்படுகிறது. உங்கள் நண்பர் அதில் பணியாற்றி ZIP ஐத் திருப்பி அனுப்புகிறார்; நீங்கள் பதிலைப் பெறவும் என்பதை அழுத்தி, முதலில் மாற்றக் குறிப்பைப் படித்து, பின்னர் பழைய திட்டத்தை மேலெழுத பயன்படுத்து என்பதைத் தேர்ந்தெடுக்கவும் அல்லது மனம் மாறினால் ரத்து செய்யவும் என்பதைத் தேர்ந்தெடுக்கவும். CATATAN.txt இல்லாத ZIP ஒத்துழைப்புத் தொகுப்பு அல்ல — சாதாரணத் திட்ட ZIP க்கு, திட்டத்தை நிர்வகிக்கவும் இல் திட்டத்தை இறக்குமதி செய்யவும் என்பதைப் பயன்படுத்தவும்.

தானியங்கு பயன்பாட்டு மொழிபெயர்ப்பாளர்
பயன்பாட்டில் உள்ள உரையை வேறொரு மொழிக்கு மொழிபெயர்க்க: முதன்மைப் பட்டியலில் பயன்பாட்டு மொழிபெயர்ப்பாளர் என்பதைத் திறந்து, திட்டத்தையும் இலக்கு மொழியையும் (ஆங்கிலம், அரபு அல்லது ஜாவானீஸ்) தேர்ந்தெடுத்து, மொழிபெயர் என்பதை அழுத்தவும். அகராதி ஏற்கனவே தொலைபேசியின் உள்ளே உள்ளது (இணையம் இல்லாமல், கட்டணம் இல்லாமல்) மற்றும் அன்றாடப் பொதுவான சொற்களைக் கொண்டுள்ளது; strings.xml, அமைப்பு மற்றும் குறியீட்டிலிருந்து உரை படிக்கப்பட்டு பின்னர் மொழிபெயர்க்கப்படுகிறது. முடிவு values-மொழி/strings.xml கோப்புறையில் எழுதப்படுகிறது (திட்டத்தில் strings.xml இருந்தால்) மற்றும் மொழிபெயர்ப்பு-மொழி.txt அறிக்கை திட்டக் கோப்புறையில் எழுதப்படுகிறது. அகராதியில் இன்னும் இல்லாத சொற்கள் அப்படியே விடப்பட்டு அறிவிக்கப்படுகின்றன — எனவே எந்தச் சொற்களை நீங்களே மொழிபெயர்க்க வேண்டும் என்பது உங்களுக்குத் தெரியும்.

குறியீடு இல்லாத விளையாட்டு உருவாக்குநர்
குறியீடு எழுதாமல் விளையாட்டை உருவாக்க: முதன்மைப் பட்டியலில் குறியீடு இல்லாத விளையாட்டு உருவாக்குநர் என்பதைத் திறந்து, விளையாட்டு வகையைத் (எண்ணை யூகி, வினாடி வினா அல்லது நட்சத்திரத்தைப் பிடி) தேர்ந்தெடுத்து, விளையாட்டுப் பெயர், அளவு (நிலைகள்/கேள்விகள்/நட்சத்திரங்கள்) மற்றும் வெற்றிச் செய்தியை நிரப்பி, விளையாட்டை உருவாக்கவும் என்பதை அழுத்தவும். விளையாட்டு உண்மையான திட்டமாக உருவாக்கப்படுகிறது, இதைத் திட்டத்தை நிர்வகிக்கவும் இல் நேரடியாக இயக்கலாம் மற்றும் வேறு எந்தத் திட்டத்தையும் போல APK ஆக உருவாக்கலாம்.

தானியங்கு பயன்பாட்டுச் சோதனை
உருவாக்குவதற்கு முன் திட்டத்தைச் சரிபார்க்க: திட்டத்தை நிர்வகிக்கவும் இல் திட்டப் பெயரை நீண்ட நேரம் அழுத்தி, தானியங்குச் சோதனை என்பதைத் தேர்ந்தெடுக்கவும். IDE APK ஐ உருவாக்காமல் 10 விஷயங்களைச் சரிபார்க்கிறது — கட்டாயக் கோப்புகள் உள்ளன (திட்டத் தரவுக் கோப்பு, அறிக்கை, முதன்மைக் கோப்பு, அமைப்பு, சரங்கள்), தொகுப்புப் பெயர் மற்றும் பதிப்பு, பயன்படுத்தப்பட்ட அனுமதிகள், ஐகான் மற்றும் குறியீடு அடைப்புக்குறிகளின் சமநிலை. முடிவு ஒவ்வொரு உருப்படிக்கும் காட்டப்படுகிறது (தேர்ச்சி/தோல்வி செய்தியுடன்) மற்றும் Jieshuo ஆல் உரக்கப் படிக்கப்படுகிறது. முதலில் தோல்வியுற்ற அனைத்தையும் சரிசெய்து, பின்னர் திட்டத்தை உருவாக்கவும் என்பதை அழுத்தவும்.

AI குறியீடு சரிபார்ப்பான்
அடிக்கடி சிக்கலை ஏற்படுத்தும் வடிவங்களுக்காகத் திட்டக் குறியீட்டைச் சரிபார்க்க: முதன்மைப் பட்டியலில் குறியீட்டைச் சரிபார்க்கவும் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, குறியீட்டைச் சரிபார்க்கவும் என்பதை அழுத்தவும். சரிபார்ப்பான் தொலைபேசியின் உள்ளே இயங்குகிறது (இணையம் இல்லாமல்) மற்றும் பயன்படுத்தப்படாத மாறிகள், வெற்றுச் செயல்பாடுகள், தெளிவாக முடிவில்லாத சுழற்சிகள், குறியீட்டில் நேரடியாக எழுதப்பட்ட உரை (strings.xml இல் இருப்பது நல்லது), ஆபத்தான அனுமதிகள் மற்றும் API கள், TODO/FIXME குறிப்பான்கள் மற்றும் மாறும் செயல்பாட்டைத் தேடுகிறது. ஒவ்வொரு கண்டுபிடிப்பிலும் கோப்புப் பெயர், வரி எண் மற்றும் சரிசெய்தல் பரிந்துரை உள்ளது. இந்தச் சரிபார்ப்பான் வடிவ அடிப்படையிலானது, உண்மையான AI அல்ல — வடிவத்தைப் பின்பற்றாத சிக்கல்கள் இன்னும் தப்பிக்கலாம்.

ஊடாடும் கற்றல் பயன்முறை
படிப்படியாகப் பயன்பாடுகளை உருவாக்கக் கற்றுக்கொள்ள: முதன்மைப் பட்டியலில் கற்றல் பயன்முறை என்பதைத் திறக்கவும். 5 பாடங்கள் உள்ளன: முதல் திட்டத்தை உருவாக்குதல், பொத்தானைச் சேர்த்தல், நிறத்தை மாற்றுதல், ஒலியைச் சேர்த்தல் மற்றும் APK ஐ உருவாக்குதல். விளக்கத்தையும் பயிற்சிப் பணியையும் படிக்க ஒரு பாடத்தைத் தட்டவும், பணியைச் செய்யவும், பின்னர் பணியைச் சரிபார்க்கவும் என்பதை அழுத்தவும் — IDE பணி உண்மையில் செய்யப்பட்டதா என்பதைச் சரிபார்க்கிறது (உங்கள் தொலைபேசியில் திட்டத்தையும் APK ஐயும் ஸ்கேன் செய்வதன் மூலம்). தேர்ச்சி பெற்ற பாடங்கள் முடிந்ததாகக் குறிக்கப்பட்டுச் சேமிக்கப்படுகின்றன.

மேக ஒத்திசைவு
திட்டத்தை மேகத்திற்குக் காப்புப் பிரதி எடுக்க: முதன்மைப் பட்டியலில் மேக ஒத்திசைவு என்பதைத் திறக்கவும். உள்ளூர்க் காப்புப்பிரதி திட்ட ZIP ஐ நேர முத்திரையுடன் Download/cloud கோப்புறையில் சேமிக்கிறது, மேலும் காப்புப்பிரதிப் பட்டியலிலிருந்து எப்போது வேண்டுமானாலும் மீட்டெடுக்கலாம். GitHub காப்புப்பிரதி திட்ட ZIP ஐ உங்கள் தனிப்பட்ட களஞ்சியத்தில் பதிவேற்றுகிறது (GitHub அமைப்புகளிலிருந்து டோக்கனைப் பயன்படுத்தி) மற்றும் மீண்டும் பதிவிறக்கலாம். இது கைமுறைக் காப்புப்பிரதி மற்றும் மீட்டெடுப்பு — முழு தானியங்கு இருவழி ஒத்திசைவுக்குச் சேவையகம் தேவை, எனவே இன்னும் கிடைக்கவில்லை.

தானியங்கு பின்புல உருவாக்கி
சேவையகக் குறியீடு எழுதாமல் பின்புலத்தை உருவாக்க: முதன்மைப் பட்டியலில் பின்புல உருவாக்கி என்பதைத் திறந்து, பின்புல வகையைத் (குறிப்புகள், பணிப்பட்டியல் அல்லது செய்திப் பலகை) தேர்ந்தெடுத்து, திட்டப் பெயரை நிரப்பி, Backend ஐ உருவாக்கவும் என்பதை அழுத்தவும். IDE படிவப் பக்கம் மற்றும் தொலைபேசியின் உள்ளூர் சேமிப்பகத்தில் (localStorage) சேமிக்கப்பட்ட தரவுப் பட்டியலுடன் உண்மையான HTML திட்டத்தை உருவாக்குகிறது — தரவு சேமிக்கப்பட்டு பயன்பாடு இயக்கப்படும்போது மீண்டும் படிக்கப்படலாம். இந்தப் பின்புலம் ஒரு தொலைபேசியில் இயங்குகிறது; இணையச் சேவையகம் இல்லாததால் இரண்டு தொலைபேசிகள் இன்னும் ஒரே தரவைப் பகிர முடியாது.

தானியங்கு தீம் வடிவமைப்பாளர்
திட்டத்திற்கு வண்ணக் கருப்பொருளை வழங்க: முதன்மைப் பட்டியலில் தீம் வடிவமைப்பாளர் என்பதைத் திறந்து, திட்டத்தையும் கருப்பொருளையும் (ஒளி, இருள், நீலம், பச்சை, சிவப்பு அல்லது ஊதா) தேர்ந்தெடுக்கவும். முன்னோட்டம் கருப்பொருளின் ஆறு நிறங்களைக் (முதன்மை, அடர் முதன்மை, உச்சரிப்பு, பின்னணி, உரை, இரண்டாம் நிலை உரை) காட்டுகிறது மற்றும் Jieshuo ஆல் உரக்கப் படிக்கப்படுகிறது. தீமைப் பயன்படுத்தவும் என்பதை அழுத்தவும் — IDE colors.xml மற்றும் styles.xml (app_theme பாணி) ஐத் திட்டத்தில் எழுதுகிறது, இது திட்டம் இயக்கப்படும்போது அல்லது உருவாக்கப்படும்போது நேரடியாகப் பயன்படுத்தப்படுகிறது.

அனிமேஷன் உருவாக்கி
திட்டத்திற்கு அனிமேஷன் வழங்க: முதன்மைப் பட்டியலில் அனிமேஷன் உருவாக்கி என்பதைத் திறந்து, திட்டம், அனிமேஷன் வகை (மறைதல், நழுவுதல், சுழற்சி, துள்ளல் அல்லது துடிப்பு), கால அளவு (100 முதல் 10000 மில்லி வினாடிகள்) மற்றும் இலக்கு (பொத்தான், உரை அல்லது படம்) ஆகியவற்றைத் தேர்ந்தெடுத்து, அனிமேஷனை உருவாக்கவும் என்பதை அழுத்தவும். IDE உண்மையான அனிமேஷன் கோப்பை எழுதுகிறது (Java/Kotlin/Compose திட்டங்களுக்கு res/anim/anim_<வகை>.xml, அல்லது HTML/வலைத்தளத் திட்டங்களுக்கு animasi.css) திரையில் காட்டப்படும் மாதிரிப் பயன்பாட்டுக் குறியீட்டுடன்.

செயல் பதிவாளர்
வேலையைத் தானாக மீண்டும் செய்ய: IDE செய்யப்பட்ட செயல்களைப் பதிவு செய்கிறது (திட்டத்தைத் திறத்தல், இயக்குதல், உருவாக்குதல், ஏற்றுமதி செய்தல், காப்புப்பிரதி எடுத்தல், திட்டத்தை உருவாக்குதல், கோப்பைச் சேமித்தல்). முதன்மைப் பட்டியலில் செயல் பதிவாளர் என்பதைத் திறந்து பதிவு செய்யப்பட்ட செயல்களின் பட்டியலை அவற்றின் திட்டத்துடன் பார்த்து, மீண்டும் இயக்கு என்பதை அழுத்தவும் — IDE தானியங்காக்கக்கூடிய செயல்களை மீண்டும் இயக்குகிறது (காப்புப்பிரதி மற்றும் திட்ட உருவாக்கம் அந்த இடத்திலேயே இயங்கும்; இயக்கு, உருவாக்கு மற்றும் ஏற்றுமதி தங்கள் முதன்மைத் திரையைத் திறக்கும்; திற மற்றும் சேமி திருத்தியைத் திறக்கும்). தானியங்காக்க முடியாத செயல்கள் தவிர்க்கப்பட்டு இறுதியில் அறிவிக்கப்படுகின்றன.

தானியங்கு பாதுகாப்பு
திட்டத்தின் பாதுகாப்பைச் சரிபார்க்க: முதன்மைப் பட்டியலில் தானியங்கு பாதுகாப்பு என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, பாதுகாப்பைச் சரிபார்க்கவும் என்பதை அழுத்தவும். IDE 8 விஷயங்களை உள்ளூரில் சரிபார்க்கிறது (இணையம் இல்லாமல்): ஆபத்தான அனுமதிகள் (இருப்பிடம், SMS, அழைப்புகள், கேமரா, மைக்ரோஃபோன், தொடர்புகள்), HTTP வழியாகத் தரவை அனுப்புதல், SMS அனுப்புதல், வெளிச்செல்லும் அழைப்புகள், குறியீட்டில் நேரடியாக எழுதப்பட்ட கடவுச்சொல் அல்லது விசை, பாதுகாப்பற்ற WebView, அனுமதியின்றி ஏற்றுமதி செய்யப்பட்ட கூறு மற்றும் குறியாக்கம் செய்யப்படாத http முகவரி. ஒவ்வொரு கண்டுபிடிப்புக்கும் சரிசெய்தல் பரிந்துரையுடன் பாதுகாப்பானது, எச்சரிக்கை அல்லது ஆபத்து என்ற நிலை வழங்கப்படுகிறது, மேலும் சுருக்கம் Jieshuo ஆல் உரக்கப் படிக்கப்படுகிறது.

AI ஆஃப்லைன்
இணையம் இல்லாமல் உரை மற்றும் குறியீடு உதவிக் கருவிகளைப் பயன்படுத்த: முதன்மைப் பட்டியலில் AI ஆஃப்லைன் என்பதைத் திறக்கவும். 4 கருவிகள் உள்ளன: உரையைச் சரிசெய்யவும் (பெரிய எழுத்துக்கள், நிறுத்தற்குறிகள் மற்றும் இரட்டை இடைவெளிகள்), உரையைச் சுருக்கவும் (மிக முக்கியமான 3 வாக்கியங்களை எடுக்கிறது), பயன்பாட்டுப் பெயரை உருவாக்கவும் (எழுதப்பட்ட விளக்கத்திலிருந்து) மற்றும் மாறிப் பெயரைப் பரிந்துரைக்கவும் (திட்டத்தில் 1-2 எழுத்து மாறிப் பெயர்களைத் தேடுகிறது). இவை தொலைபேசியின் உள்ளே உள்ள எளிய விதிகள், உண்மையான AI மாதிரி அல்ல. உரைச் சரிசெய்தல் முடிவைப் பயன்படுத்து பொத்தான் மூலம் திட்டத்தின் strings.xml இல் பயன்படுத்தலாம்.

விட்ஜெட் & வால்பேப்பர் உருவாக்கி
முகப்புத் திரை விட்ஜெட்டை உருவாக்க: முதன்மைப் பட்டியலில் விட்ஜெட்கள் & வால்பேப்பர் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, விட்ஜெட் உரையை நிரப்பி, Widget ஐ உருவாக்கவும் என்பதை அழுத்தவும். IDE WidgetSaya.java, விட்ஜெட் அமைப்பு, விட்ஜெட் தகவல் ஆகியவற்றை எழுதி, திட்டத்தின் AndroidManifest.xml இல் ஒரு பெறுநரைச் சேர்க்கிறது — திட்டத்தை உருவாக்கி, பின்னர் தொலைபேசியின் முகப்புத் திரையிலிருந்து விட்ஜெட்டை நிறுவவும். வால்பேப்பருக்கு: எழுத்து மற்றும் பின்னணி மற்றும் உரை நிறங்களை நிரப்பி, முன்னோட்டத்தை உருவாக்கி, பின்னர் அதை PNG ஆக Download கோப்புறையில் சேமிக்கவும் அல்லது நேரடியாகத் தொலைபேசி வால்பேப்பராக அமைக்கவும்.

சமூக ஊடக ஒருங்கிணைப்பு
பயன்பாட்டில் பகிர்வு பொத்தான்களைச் சேர்க்க: முதன்மைப் பட்டியலில் சமூக ஊடக ஒருங்கிணைப்பு என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, WhatsApp, Facebook அல்லது Telegram இல் பகிர்வைச் சேர்க்கவும் (அல்லது மூன்றையும் ஒரே நேரத்தில்). IDE உண்மையான பகிர்வுக் குறியீட்டைத் திட்டத்தின் முதன்மைக் கோப்பில் (MainActivity அல்லது index.html) எழுதுகிறது. பகிர்வுச் சோதனை பொத்தான் IDE இலிருந்து மாதிரி உரையுடன் பகிர்வுத் தேர்வியைத் திறக்கிறது, இதனால் பயன்பாட்டை உருவாக்குவதற்கு முன்பே ஓட்டத்தை உணர முடியும்.

படத்திலிருந்து பயன்பாடு
படத்திலிருந்து காட்சியகப் பயன்பாட்டை உருவாக்க: முதன்மைப் பட்டியலில் படத்திலிருந்து பயன்பாடு என்பதைத் திறந்து, காட்சியகத்திலிருந்து படத்தைத் தேர்ந்தெடுக்கவும். IDE படத்தின் அளவு மற்றும் ஆதிக்க நிறத்தைப் பகுப்பாய்வு செய்து, பின்னர் உண்மையான காட்சியகப் பயன்பாட்டுத் திட்டத்தை உருவாக்குகிறது: படம் திட்டத்தின் assets இல் நகலெடுக்கப்படுகிறது, கருப்பொருள் நிறம் படத்தின் ஆதிக்க நிறத்திலிருந்து எடுக்கப்படுகிறது, மேலும் பயன்பாட்டுப் பெயர் படக் கோப்பின் பெயரிலிருந்து எடுக்கப்படுகிறது. அந்தக் காட்சியகப் பயன்பாட்டை இயக்க அல்லது உருவாக்கத் திட்டத்தை நிர்வகிக்கவும் என்பதைத் திறக்கவும்.

ஊடாடும் முனையம் (VT பாகுபடுத்தி)
Terminal இல் ஊடாடும் நிரல்களைப் பயன்படுத்த: முதன்மைப் பட்டியலில் Terminal என்பதைத் திறந்து, nano, vim, top அல்லது htop ஐ இயக்கவும். Terminal இப்போது VT பாகுபடுத்தியைப் (24 வரிசை x 80 நெடுவரிசை கட்டத் திரை) பயன்படுத்துகிறது, இதனால் அந்த நிரல்கள் சரியாகக் காட்டப்படுகின்றன — கர்சர் நகரும், வரிகள் அழிக்கப்படும், மேலும் திரை உண்மையான முனையத்தைப் போல மாறும். ஊடாடும் நிரல்களைக் கட்டுப்படுத்த Tab, மேல் அம்பு, கீழ் அம்பு மற்றும் Esc என்ற சிறப்புப் பொத்தான்கள் உள்ளன. வெளியீடு இன்னும் Jieshuo படிக்கக்கூடிய உரையாகவே உள்ளது; கடைசி வரியைக் கேட்கத் திரையைப் படிக்கவும் என்பதை அழுத்தவும்.

Terminal Exec (பயன்பாட்டு பைனரி)
Terminal இலிருந்து பயன்பாட்டுக் கோப்புறையில் உள்ள பைனரியை (எ.கா. aapt2, ECJ, D8) இயக்க: கட்டளையை வழக்கம் போல் தட்டச்சு செய்யவும். IDE libkautsarexec.so ஐப் பயன்படுத்துகிறது, இதனால் பயன்பாட்டுக் கோப்புறையில் உள்ள பைனரிகள் Android 10 மற்றும் அதற்கு மேல் இயங்கும். இந்தத் தொலைபேசியில் பைனரி exec பாதை இயங்குகிறதா என்பதைச் சரிபார்க்க Terminal இல் Exec சோதனை என்பதை அழுத்தவும் — முடிவு அப்படியே காட்டப்படுகிறது. exec கணினியால் தடுக்கப்பட்டால், கணினிக் கட்டளைகள் மற்றும் shell ஸ்கிரிப்டுகள் இன்னும் இயங்கும்; பைனரியைத் திட்டத்தை உருவாக்கவும் பட்டியலிலிருந்து இயக்கவும்.

Terminal தொடர்ந்து இயங்கும் (KeepAlive)
வேறு திரைக்குச் செல்லும்போது shell இயங்கிக்கொண்டே இருக்க: Terminal ஐத் திறந்து, கட்டளையை இயக்கி, பின்னர் பின்செல்லவும் என்பதை அழுத்தவும் அல்லது வேறு திரைக்குச் செல்லவும் — shell இறக்காது, மேலும் Terminal அறிவிப்பு தொடர்ந்து காட்டப்படும், இதனால் ஒரே தட்டலில் நீங்கள் திரும்பலாம். இயக்கப்பட்ட கட்டளைகள் வரலாற்றில் சேமிக்கப்படுகின்றன (வரலாறு பொத்தான், அல்லது கட்டளைப் புலத்தில் மேல்/கீழ் அம்புகள்) மற்றும் அடிக்கடி பயன்படுத்தப்படும் கட்டளைகளைப் பிடித்தவையாகச் சேமிக்கலாம் (பிடித்தவை பொத்தான்). முடிந்ததும் shell ஐ மூடவும் என்பதை அழுத்தவும், இதனால் shell உண்மையில் முடிவடையும். திட்டப் பட்டியலிலும் திருத்திப் பட்டியலிலும் Terminal இல் உருவாக்கவும் பொத்தானும் உள்ளது: Terminal திட்டக் கோப்புறையில் உருவாக்கக் கட்டளை ஏற்கனவே நிரப்பப்பட்ட நிலையில் திறக்கிறது.

Terminal கருவிகளை நிறுவவும் (சோதனை)
இன்னும் சோதனையில் உள்ள அம்சம்: Terminal இல் டெவலப்பரின் alat-termux களஞ்சியத்தில் (github.com/syudat/alat-termux) உள்ள கண்ணாடியிலிருந்து Termux சூழலை நிறுவ Terminal கருவிகளை நிறுவவும் பொத்தான் உள்ளது, இது அதிகாரப்பூர்வ Termux வெளியீட்டிலிருந்து எடுக்கும் Termux ஐ நிறுவவும் பொத்தானுக்கு கூடுதலாக மற்றொரு வழியாகும். கண்ணாடியின் உள்ளடக்கம் அதிகாரப்பூர்வ வெளியீட்டைப் போலவே உள்ளது மற்றும் நிறுவலின் போது SHA-256 மூலம் சரிபார்க்கப்படுகிறது. சூழல் நிறுவப்பட்ட பிறகு, pkg update மற்றும் pkg install கட்டளைகளைப் பயன்படுத்தலாம், மேலும் களஞ்சியத்திலிருந்து கூடுதல் கருவிகளும் முனையத்தில் நிறுவப்படுகின்றன: சூழல் தகவலைப் பார்க்க info-terminal, தற்காலிகச் சேமிப்பைச் சுத்தம் செய்ய bersih-terminal, மற்றும் திட்டக் கோப்புறையைத் தேதியிடப்பட்ட ஒரு tar.gz கோப்பாகக் காப்பகப்படுத்த cadangkan-proyek. அதன் பிறகு பயன்பாடு அடிப்படை Linux தொகுப்புகள் (git, python, curl, wget, nano, openssh, zip, unzip) மற்றும் கையொப்பத்துடன் கூடிய APK உருவாக்கக் கருவிகள் (openjdk-21, kotlin, gradle, ecj, aapt2, d8, apksigner, clang, cmake, ninja, make) ஆகியவற்றை அதிகாரப்பூர்வ Termux களஞ்சியத்திலிருந்து தானாக நிறுவுகிறது, இதனால் முனையம் உடனடியாகப் பயன்பாடுகளை உருவாக்கத் தயாராக உள்ளது. பெரிய தொகுப்புகளைப் பதிவிறக்குவதற்கு (நூற்றுக்கணக்கான MB) நீண்ட நேரம் ஆகலாம். நிறுவல் இயங்கும்போது, முன்னேற்றமும் கட்டளை வெளியீடும் Terminal முதன்மைத் திரையில் தோன்றும், மேலும் இறுதி முடிவு திரை வாசகரால் உரக்கப் படிக்கப்படுகிறது. தொகுப்பு நிறுவல் இன்னும் முடியவில்லை என்றால், தொடர Terminal கருவிகளை நிறுவவும் என்பதை மீண்டும் அழுத்தவும்.

முழு குரல் பயன்முறை
IDE ஐ முழுமையாகக் குரலால் கட்டுப்படுத்த: முதன்மைப் பட்டியலில் முழு குரல் பயன்முறை என்பதைத் திறந்து, கேட்கத் தொடங்கவும் என்பதை அழுத்தவும். IDE தொடர்ந்து கேட்கிறது — ஒவ்வொரு கட்டளைக்கும் பொத்தானை அழுத்த வேண்டியதில்லை — கட்டளையை இயக்கி குரலால் பதிலளிக்கிறது. 26 கட்டளைகள் உள்ளன: உருவாக்கு, உருவாக்கு, திற, இயக்கு, பட்டியலிடு, தேடு, நீக்கு, சோதி, சரிபார், ஏற்றுமதி செய், காப்புப்பிரதி எடு, பகிர், ஐகானை உருவாக்கு, மொழிபெயர், Terminal இல் உருவாக்கு, திரையைப் படி, அனைத்துத் திரைகளையும் திற (பாதுகாப்பு, AI ஆஃப்லைன், விட்ஜெட், சமூக ஊடகம், விளையாட்டு, கற்றல், மேகம், பின்புலம், தீம், அனிமேஷன், பதிவாளர் உட்பட), திரும்பு, மூடு மற்றும் உதவி. பயன்முறை செயலில் விடப்பட்டால், இந்தத் திரை மீண்டும் திறக்கப்படும்போது கேட்பது தானாகத் தொடர்கிறது. இந்தப் பயன்முறையை அணைக்கக் கேட்பதை நிறுத்தவும் என்பதை அழுத்தவும். தொலைபேசியில் குரல் அறிதல் சேவை இல்லையென்றாலும், கட்டளைகளை உரைப் பெட்டியில் எழுதலாம்.

குறியீடு மொழிபெயர்ப்பாளர்
இணையம் இல்லாமல் மொழிகளுக்கு இடையே குறியீட்டை மொழிபெயர்க்க: முதன்மைப் பட்டியலில் குறியீடு மொழிபெயர்ப்பாளர் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, மூலக் கோப்பை (.java/.kt) தேர்ந்தெடுத்து, பின்னர் திசையைத் தேர்ந்தெடுக்கவும்: Java இலிருந்து Kotlin க்கு. மொழிபெயர் என்பதை அழுத்தவும் — முடிவு மொழிபெயர்க்க முடியாத வரிகளின் அறிக்கையுடன் காட்டப்படுகிறது (அந்த வரிகள் அப்படியே வைக்கப்பட்டு குறிக்கப்படுகின்றன). முடிவைச் சேமிக்கவும் என்பதை அழுத்தி அதே கோப்புறையில் புதிய கோப்பை (பெயர்-மொழிபெயர்ப்பு.java/.kt) எழுதவும்; அசல் கோப்பு ஒருபோதும் மேலெழுதப்படாது. இது வடிவ விதி மொழிபெயர்ப்பான், தொகுப்பி அல்ல — பயன்படுத்துவதற்கு முன் எப்போதும் முடிவைச் சரிபார்க்கவும்.

பயன்பாட்டில் Git
Termux இல்லாமல் IDE இல் Git ஐப் பயன்படுத்த: முதன்மைப் பட்டியலில் பயன்பாட்டில் Git என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, Git Repo ஐ உருவாக்கவும் என்பதை அழுத்தி அந்தத் திட்டத்தில் உள்ளூர் களஞ்சியத்தை (.git) உருவாக்கவும். கடைசி commit உடன் ஒப்பிடும்போது புதிய, மாற்றப்பட்ட அல்லது நீக்கப்பட்ட கோப்புகளைப் பார்க்க நிலையைச் சரிபார்க்கவும் என்பதை அழுத்தவும்; commit செய்தியை நிரப்பி, திட்டத்தின் snapshot ஐச் சேமிக்க Commit என்பதை அழுத்தவும்; commit வரலாற்றைப் பார்க்க Commit Log ஐப் பார்க்கவும் என்பதை அழுத்தவும். GitHub க்கு Push மற்றும் GitHub இலிருந்து Pull ஆகியவை GitHub டோக்கன் வழியாக snapshot களைப் பயன்படுத்துகின்றன (pembuat-aplikasi-build களஞ்சியம்) — git நெறிமுறை அல்ல. Clone, Push (கணினி git) மற்றும் Pull (கணினி git) ஆகியவை git பைனரி தொலைபேசியில் நிறுவப்பட்டிருந்தால் மட்டுமே இயங்கும் (பொதுவாக இல்லை). இது முழு git அல்ல: merge, branch அல்லது diff இல்லை — ஒவ்வொரு commit உம் திட்டத்தின் முழு ZIP snapshot ஐச் சேமிக்கிறது.

விளம்பர உருவாக்கி
உருவாக்கப்பட்ட பயன்பாட்டில் விளம்பரங்களைச் சேர்க்க: முதன்மைப் பட்டியலில் விளம்பர உருவாக்கி என்பதைத் திறந்து, திட்டம், வழங்குநர் (AdMob, Unity Ads அல்லது AppLovin) மற்றும் விளம்பர வகை (பதாகை, இடைச்செருகல் அல்லது வெகுமதி) ஆகியவற்றைத் தேர்ந்தெடுக்கவும். ஏற்கனவே இருந்தால் விளம்பர அலகு ID ஐ நிரப்பவும் — காலியாக இருப்பது சோதனை ID ஐப் பயன்படுத்துவதாகும் (AdMob Google இன் அதிகாரப்பூர்வ சோதனை ID ஐப் பயன்படுத்துகிறது; Unity மாதிரி Game ID ஐப் பயன்படுத்துகிறது; AppLovin வெற்றிடத்தைப் பயன்படுத்துகிறது). Java மற்றும் Kotlin குறியீடு மற்றும் வழிகாட்டியைப் பார்க்க விளம்பரக் குறியீட்டை உருவாக்கவும் என்பதை அழுத்தவும்; எல்லாவற்றையும் திட்டத்தில் விளம்பர-<வழங்குநர்>-<வகை>.txt கோப்பில் எழுதத் திட்டத்தில் சேமிக்கவும் என்பதை அழுத்தவும். இது குறியீடு வார்ப்புரு + வழிகாட்டி, விளம்பர SDK அல்ல — SDK IDE இல் சேர்க்கப்படவில்லை; வழங்குநர் கணக்கை உருவாக்கி, விளம்பர அலகை உருவாக்கி, உங்கள் சொந்த அலகு ID ஐ ஒட்டி, திட்டத்தின் build.gradle இல் SDK சார்புநிலையைச் சேர்த்த பிறகுதான் உண்மையான விளம்பரங்கள் தோன்றும்.

குழந்தைகள் பயன்முறை
குழந்தையுடன் IDE ஐப் பயன்படுத்த: முதன்மைப் பட்டியலில் குழந்தைகள் பயன்முறை என்பதைத் திறக்கவும். திரை பெரிய பொத்தான்களுடன் எளிமைப்படுத்தப்பட்டுள்ளது மற்றும் 4 பாதுகாப்பான செயல்கள் மட்டுமே உள்ளன: திட்டத்தை உருவாக்கு (பாதுகாப்பான வார்ப்புருக்களிலிருந்து: கால்குலேட்டர், எண்ணை யூகி, வினாடி வினா, நட்சத்திரத்தைப் பிடி), திட்டத்தைத் திறக்கவும், இயக்கு மற்றும் கற்றல் பயன்முறை. இந்தத் திரையில் நீக்கு, ஏற்றுமதி, காப்புப்பிரதி அல்லது டோக்கன் அமைப்புகள் பொத்தான் இல்லை. முதல் முறை நுழையும்போது 4 இலக்க PIN ஐ உருவாக்கவும் — அந்த PIN ஐப் பெற்றோர் குழந்தைகள் பயன்முறையிலிருந்து வெளியேறப் பயன்படுத்துகிறார்கள் (Mode Anak இலிருந்து வெளியேறவும் பொத்தான் அல்லது பின்செல்லவும் பொத்தான்). இந்த PIN சிறு குழந்தைகளுக்கான இலகுவான பாதுகாப்பு, உண்மையான பாதுகாப்பு அல்ல.

Wear OS & TV பயன்பாட்டு உருவாக்குநர்
கடிகாரப் பயன்பாட்டை (Wear OS) அல்லது TV பயன்பாட்டை (Android TV) உருவாக்க: முதன்மைப் பட்டியலில் Wear OS & TV என்பதைத் திறந்து, இலக்கைத் (Wear OS, Android TV அல்லது இரண்டும்) தேர்ந்தெடுக்கவும். திட்டப் பெயரை நிரப்பி, புதிய Wear/TV திட்டத்தை உருவாக்கவும் என்பதை அழுத்தவும் — IDE Java திட்டத்தை உருவாக்கி பின்னர் அதைச் சரிசெய்கிறது — அல்லது ஏற்கனவே உள்ள திட்டத்தைத் தேர்ந்தெடுத்து இந்தத் திட்டத்தில் பயன்படுத்தவும் என்பதை அழுத்தவும். சரிசெய்தல்கள்: அறிக்கையில் uses-feature, TV க்கான LEANBACK_LAUNCHER வகை + பதாகை, மற்றும் சரிசெய்யப்பட்ட activity_main.xml அமைப்பு (Wear: சிறிய திரை; TV: D-pad க்கு ஏற்ற பெரிய திரை). முழு விளக்கம் திட்டத்தில் wear-tv.txt இல் எழுதப்படுகிறது. இது திட்ட வார்ப்புரு — உருவாக்கம் + சோதனைக்கு இன்னும் Wear OS அல்லது Android TV சாதனம்/முன்மாதிரி தேவை; TV பதாகை (banner.png 320x180) தானாக உருவாக்கப்படாது, அதை நீங்களே சேர்க்க வேண்டும் (எடுத்துக்காட்டாக ஐகான் உருவாக்கி வழியாக).

திட்ட வரைபடம்
திட்டத்தின் கட்டமைப்பைப் பார்க்க: முதன்மைப் பட்டியலில் திட்ட வரைபடம் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, வரைபடத்தைக் காட்டு என்பதை அழுத்தவும் — IDE கோப்புறைகள் மற்றும் கோப்புகளின் பட்டியலை அவற்றின் அளவுகளுடன், மொத்த அளவு, கோப்பு வகைக்கு ஏற்ப அளவு மற்றும் முக்கியக் கோப்புகள் (முதன்மைக் கோப்பு, அறிக்கை, அமைப்பு, சரங்கள், ஐகான், வலைப் பக்கம்) ஆகியவற்றைக் காட்டுகிறது. அதே வரைபடத்தைத் திட்டத்தின் மூலத்தில் எழுத peta-proyek.txt ஐச் சேமிக்கவும் என்பதை அழுத்தவும். bin/ கோப்புறை (உருவாக்க முடிவுகள்) மற்றும் .git/ கோப்புறை (உள்ளூர் களஞ்சியம்) ஆகியவை வரைபடத்தில் சேர்க்கப்படவில்லை, ஏனெனில் அவற்றின் உள்ளடக்கத்தை மீண்டும் உருவாக்க முடியும்.

APK அளவு கணிப்பான்
உருவாக்குவதற்கு முன் உருவாக்கப்பட்ட APK இன் அளவை மதிப்பிட: முதன்மைப் பட்டியலில் APK அளவு கணிப்பான் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, மதிப்பீட்டைக் கணக்கிடு என்பதை அழுத்தவும். IDE வகை வாரியாக விவரங்களைக் (குறியீடு/DEX, வளங்கள், சொத்துக்கள், சொந்த நூலகங்கள், அறிக்கை + resources.arsc, மேல்நிலை), மொத்த மதிப்பீடு, 5 பெரிய கோப்புகள் மற்றும் சிறியதாக்கும் பரிந்துரைகளைக் (எடுத்துக்காட்டாக பெரிய படங்கள் தெளிவுத்திறனில் சிறியதாக்கப்படுகின்றன, பெரிய ஒலிகள் கால அளவில் வெட்டப்படுகின்றன) காட்டுகிறது. இது மதிப்பீடு, துல்லியமான அளவு அல்ல — உண்மையான அளவு aapt2 சுருக்கம், பயன்படுத்தப்படாத குறியீட்டை நீக்குதல் (R8) மற்றும் உருவாக்க முடிவு வளங்கள் காரணமாக வேறுபடலாம்.

APK பகுப்பாய்வி
முடிக்கப்பட்ட APK இன் உள்ளடக்கத்தைப் படிக்க (Android Studio இல் APK பகுப்பாய்வியைப் போல): முதன்மைப் பட்டியலில் APK பகுப்பாய்வி என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, உருவாக்க முடிவின் APK பகுப்பாய்வு என்பதை அழுத்தவும். IDE அந்தத் திட்டத்தின் bin கோப்புறையில் உள்ள சமீபத்திய APK ஐப் படித்து, தொகுப்புப் பெயர், பதிப்பு, குறைந்தபட்ச மற்றும் இலக்கு SDK, பயன்படுத்தப்பட்ட அனுமதிகளின் பட்டியல், dex கோப்புகளின் எண்ணிக்கை, பகுதி வாரியாக அளவு விவரம் (நிரல் குறியீடு, வளங்கள், சொத்துக்கள், சொந்த நூலகங்கள், கையொப்பம்) மற்றும் 10 பெரிய உள்ளீடுகளை அறிவிக்கிறது. APK ஐ எந்தப் பகுதி பெரிதாக்குகிறது மற்றும் உருவாக்கப்பட்ட பயன்பாடு எந்த அனுமதிகளைப் பயன்படுத்துகிறது என்பதை அறிய இது பயனுள்ளதாக இருக்கும்.

திரை அளவு முன்னோட்டம்
பல திரை அளவுகளில் திட்டத்தின் தோற்றத்தை ஒரே நேரத்தில் சரிபார்க்க (Android Studio இல் உள்ளதைப் போல): முதன்மைப் பட்டியலில் திரை அளவு முன்னோட்டம் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, திரை அளவைச் சரிபார்க்கவும் என்பதை அழுத்தவும். IDE திட்டத்தின் அனைத்து அமைப்புகளையும் படித்து, அகலம் நிலையாக எழுதப்பட்ட (எடுத்துக்காட்டாக 400dp) மற்றும் 320, 360, 411 அல்லது 480 dp திரை அகலத்தை மீறும் கூறுகளை அறிவிக்கிறது, ஏனெனில் சிறிய திரை கொண்ட தொலைபேசியில் அத்தகைய கூறு மறைக்கப்படலாம் அல்லது வெளியே வழியலாம். match_parent அல்லது wrap_content அகலம் கொண்ட கூறுகள் திரைக்கு ஏற்ப தானாகச் சரிசெய்யப்படுகின்றன மற்றும் சரிபார்க்கத் தேவையில்லை.

வள மேலாளர்
திட்டத்தின் அனைத்து வளங்களையும் ஒரே இடத்தில் பார்த்து நிர்வகிக்க (Android Studio இல் வள மேலாளரைப் போல): முதன்மைப் பட்டியலில் வள மேலாளர் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, வளங்களைப் பார்க்கவும் என்பதை அழுத்தவும். IDE வகை வாரியாகக் கோப்புகளின் எண்ணிக்கை மற்றும் அளவு (drawable, layout, values, mipmap மற்றும் பிற), strings.xml, colors.xml மற்றும் styles.xml இன் உள்ளடக்கத்தை அறிவிக்கிறது. அதே திரையிலிருந்து, பெயர் மற்றும் மதிப்பை நிரப்புவதன் மூலம் strings.xml இல் புதிய சரத்தையும் colors.xml இல் புதிய நிறத்தையும் சேர்க்கலாம் — பெயர் சரிபார்க்கப்பட்டு நகல்கள் நிராகரிக்கப்படுகின்றன, இதனால் XML கோப்பு சேதமடையாது.

இலகு செயல்திறன் கண்காணிப்பு
இயங்கும் பயன்பாட்டின் RAM மற்றும் செயலி பயன்பாட்டைக் கண்காணிக்க (Android Studio இல் Profiler போல, இலகு பதிப்பு): முதன்மைப் பட்டியலில் இலகு செயல்திறன் கண்காணிப்பு என்பதைத் திறந்து, முதலில் சரிபார்க்க விரும்பும் பயன்பாட்டை இயக்கவும் (எடுத்துக்காட்டாக முயற்சிக்கப்படும் உருவாக்கப்பட்ட பயன்பாடு), அதன் தொகுப்புப் பெயரை நிரப்பவும் — அல்லது திட்டத்தைத் தேர்ந்தெடுத்து திட்டத்திலிருந்து தொகுப்புப் பெயரை நிரப்பவும் என்பதை அழுத்தவும் — பின்னர் கண்காணிப்பைத் தொடங்கவும் என்பதை அழுத்தவும். ஒவ்வொரு 2 வினாடிகளிலும் IDE அந்தப் பயன்பாட்டின் RAM (PSS) மற்றும் CPU ஐத் தொலைபேசியின் இலவச RAM உடன் பதிவு செய்கிறது; சராசரி மற்றும் உச்சத்தின் சுருக்கத்தைப் பார்க்க நிறுத்தவும் என்பதை அழுத்தவும். கூடுதல் அனுமதி இல்லை. Android இன் புதிய பதிப்புகளில் மற்றொரு பயன்பாட்டின் செயலியைப் படிக்கும் அணுகல் கணினியால் கட்டுப்படுத்தப்படுகிறது, எனவே CPU ஐப் படிக்க முடியாவிட்டால், அறிக்கை அதை அப்படியே கூறுகிறது மற்றும் RAM கண்காணிப்பு தொடர்கிறது.

அணுகல் தணிக்கை
வெளியீட்டிற்கு முன் ஒரு திட்டத்தின் அமைப்பு திரை வாசிப்பாளருக்கு (TalkBack/Jieshuo) ஏற்றதா என்பதைச் சரிபார்க்க: முதன்மை பட்டியலில் அணுகல் தணிக்கை என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, பிறகு அமைப்புப் பட்டியலை ஏற்றுக என்பதைத் தட்டி ஓர் அமைப்புக் கோப்பைத் தேர்ந்தெடுங்கள். IDE அந்த XML கோப்பைப் படித்து, லேபிள் இல்லாத பொத்தான்களை அவற்றின் வரி எண்களுடனும், மீண்டும் மீண்டும் பயன்படுத்தப்பட்ட லேபிள்களையும், ஒன்றையொன்று மூடும் கூறுகளையும் தெரிவித்து, பிறகு Jieshuo உரக்க வாசிப்பது போன்ற கவன வரிசைப் பதிவை உருவாக்குகிறது. ஒரு பொத்தானுக்கு லேபிள் இல்லை என்றால், அதன் லேபிளை நிரப்பி, பிறகு தானாக லேபிளைச் செருகுக என்பதைத் தட்டுங்கள் — லேபிள் contentDescription ஆக அமைப்புக் கோப்பில் எழுதப்படும். இந்தச் சரிபார்ப்பு அமைப்பு XML ஐ மட்டுமே படிக்கிறது; Compose காட்சிகளும் முடிக்கப்பட்ட APK களும் இன்னும் வருடப்படவில்லை.

செயலிழப்பு உடற்கூறாய்வு
தனித்துவமான ID கொண்ட செயலிழப்புப் பதிவிலிருந்து செயலி ஏன் தானாகவே மூடுகிறது என்பதை அறிய: முதன்மை மெனுவில் «செயலிழப்பு உடற்கூறாய்வு» என்பதைத் திறந்து, பதிவுப் பட்டியலிலிருந்து செயலிழப்பு ID ஐத் தேர்ந்து, «சரிபார்» என்பதை அழுத்தவும். IDE பதிவில் உள்ள வகுப்பு மற்றும் வரி எண்ணை திட்ட மூலத்துடன் பொருத்தி, காரணத்தை இந்தோனேசிய மொழியில் விளக்குகிறது (எடுத்துக்காட்டாக வெற்றுக் குறிப்பு, இன்னும் கேட்கப்படாத அனுமதி, அல்லது JSON பிழை), குறியீட்டு இணைப்புப் பரிந்துரையுடன். மூல வரி செயலிழப்பு நிகழ்ந்தபோது இருந்ததைப் போலவே இன்னும் இருந்தால் மட்டுமே «திருத்தத்தைப் பயன்படுத்துக» என்பதை அழுத்தவும்; அது மாறியிருந்தால், இணைப்பு நிராகரிக்கப்பட்டு, நீங்களே சரிபார்க்க IDE கேட்கிறது. உருவாக்கப்பட்ட செயலியின் செயலிழப்புகளுக்கு, «திட்டத்தில் செயலிழப்புப் பிடிப்பானைச் செருகு» என்பதை அழுத்தி, பின்னர் APK ஐ வழக்கம் போல் உருவாக்கவும்: அந்த உருவாக்கப்பட்ட செயலி தனது செயலிழப்புகளைத் தானே பிடித்து அதன் பதிவை தொலைபேசியில் எழுதுகிறது, அந்தப் பதிவை «உருவாக்கப்பட்ட செயலியின் செயலிழப்புப் பதிவைக் கண்டறி» பொத்தான் மூலம் காணலாம். நேர்மையான வரம்பு: Android 11 மற்றும் அதற்கு மேல் பொது Download கோப்புறைக்கு பதிவை நகலெடுப்பது அனைத்துக் கோப்புகளுக்கும் அணுகல் அனுமதி இல்லாமல் தோல்வியடையலாம்.

குறுக்கு-முன்னுதாரண மாற்றி
எளிய Java குறியீட்டை Kotlin ஆகவோ, எளிய XML அமைப்பை Compose குறியீடாகவோ மாற்ற: முதன்மை பட்டியலில் குறுக்கு-முன்னுதாரண மாற்றி என்பதைத் திறந்து, திட்டத்தையும் கோப்பையும் தேர்ந்து, பிறகு முன்னோட்டம் என்பதைத் தட்டுங்கள். IDE மாற்ற முடிவை உரையாகக் காட்டுகிறது — முதலில் அதைச் சரிபாருங்கள், ஏனெனில் அது அடையாளம் காணாத வரிகள் அப்படியே விடப்படும், Java வில் உள்ள static என்ற சொல் Kotlin இல் நீக்கப்படும் (பயன்படுத்தும் முன் அதன் பொருளைச் சரிபாருங்கள்). XML இலிருந்து Compose க்கு மாற்றுவது உரை, குறிப்புகள், திசை ஆகியவற்றை மட்டுமே மாற்றும் — அளவு, நிறம் மற்றும் பிற பண்புகள் இன்னும் சேர்க்கப்படவில்லை. முடிவு சரியாக இருந்தால், இலக்குக் கோப்பை எழுத கோப்பில் பயன்படுத்துக என்பதைத் தட்டுங்கள்; மூலக் கோப்பு மாறாது. பாதுகாப்பான, பொதுவான வடிவங்கள் மட்டுமே மாற்றப்படும்.

உள்ளூர் நுண் சேவையகம்
இணையம் இல்லாமல் சேவையகம் தேவைப்படும் செயலியைச் சோதிக்க: முதன்மை மெனுவில் «உள்ளூர் நுண் சேவையகம்» என்பதைத் திறந்து, வழி வரையறைகளை எழுதி (எடுத்துக்காட்டாக GET /halo பின்னர் அதன் JSON பதில்), «சேவையகத்தைத் தொடங்குக» என்பதை அழுத்தவும். IDE அதே தொலைபேசியில் சிறிய HTTP சேவையகத்தை இயக்குகிறது (HTTP மட்டும், TLS இல்லை, அதே Wi-Fi பிணையத்திற்கு) மற்றும் ஒவ்வொரு கோரிக்கையும் பதிலும் திரையில் பதிவு செய்கிறது. வழிகள் {nama} போன்ற அளவுருக்கள் மற்றும் எளிய API விசையைப் பயன்படுத்தலாம். சேவையகத்தை உருவாக்கப்பட்ட APK இல் தொகுக்கவும் முடியும்: «சேவையகத்தைத் திட்டத்தில் தொகு» என்பதை அழுத்தவும், சேவையக மூலம், சொத்துகள் மற்றும் மேனிஃபெஸ்ட் திட்டத்தில் செருகப்படுகின்றன, எனவே உருவாக்கப்பட்ட செயலி இயங்கும்போது தானே சேவையகமாகிறது. IDE இல் உள்ள சேவையகம் அதன் திரை மூடப்படும்போது நிற்கிறது.

பாதுகாப்பு தணிக்கையாளர்
வெளியிடுவதற்கு முன் திட்டக் குறியீட்டில் பாதுகாப்பு இடைவெளிகளைச் சரிபார்க்க: முதன்மை மெனுவில் «பாதுகாப்பு தணிக்கையாளர்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, «வருடலைத் தொடங்குக» என்பதை அழுத்தவும். IDE திட்டக் குறியீடு, மேனிஃபெஸ்ட் மற்றும் உள்ளமைவை ஸ்கேன் செய்து, அதிக ஆபத்து முதல் குறைந்த ஆபத்து வரை கண்டுபிடிப்புகளைத் தெரிவிக்கிறது — குறியீட்டில் திறந்து விடப்பட்ட API விசை, அனுமதி இல்லாமல் வெளிப்படுத்தப்பட்ட கூறு, அதன் JavaScript இடைமுகத்துடன் JavaScript ஐ இயக்கும் WebView, பலவீனமான குறியாக்கவியல் (MD5, SHA1, DES), TLS இல்லாத http முகவரி, மற்றும் குறியீட்டில் நேரடியாக எழுதப்பட்ட கடவுச்சொல் — அவற்றின் கோப்புகள் மற்றும் வரி எண்களுடன். திருத்தம் பாதுகாப்பான கண்டுபிடிப்புகளுக்கு (எடுத்துக்காட்டாக MD5 ஐ SHA-256 ஆக அல்லது http ஐ https ஆக மாற்றவும்), «திருத்தத்தைப் பயன்படுத்துக» என்பதை அழுத்தவும்; API விசைகள் மற்றும் கடவுச்சொற்களுக்கு, IDE திருத்தப் பரிந்துரையை மட்டுமே காட்டுகிறது, ஏனெனில் மாற்றீட்டை மேம்பாட்டாளரே தீர்மானிக்க வேண்டும். ஸ்கேன் இப்போது உருவாக்கப்பட்ட APK க்குள் உண்மையான DEX பைட்கோடையும் பகுப்பாய்வு செய்கிறது (குறியீட்டில் உள்ள உரை வடிவங்கள் மட்டுமல்ல), எனவே அழைக்கப்பட்ட ஆபத்தான API கள் மற்றும் DEX இல் உட்பொதிக்கப்பட்ட ரகசியங்களும் பிடிக்கப்படுகின்றன; வடிவத்தைப் பின்பற்றாத இடைவெளிகள் இன்னும் ஸ்கேனிலிருந்து தப்பிக்கலாம் — பயன்படுத்துவதற்கு முன் சரிபார்க்கவும்.

இடைமுக சோதனை ரோபோ
உரைக் காட்சிகள் மூலம் செயலித் திரையைத் தானாகச் சோதிக்க: முதன்மை மெனுவில் «இடைமுக சோதனை ரோபோ» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, «தானாக சூழ்நிலையை உருவாக்குக» என்பதை அழுத்தவும். IDE திட்ட மேனிஃபெஸ்ட் மற்றும் அமைப்பைப் படித்து, காட்சியை உரைப் படிகளாக எழுதுகிறது (பொத்தானை அழுத்தவும், புலத்தை நிரப்பவும், காத்திருக்கவும், திரும்பவும்). காட்சி இயக்கப் பதிவை அதன் நேர முத்திரைகளுடன் பார்க்க «உலர் ஓட்டத்தை இயக்குக» என்பதை அழுத்தவும் — இந்த உலர் ஓட்டம் இன்னும் வரிசையின் உருவகப்படுத்துதல் மட்டுமே. உண்மையான சோதனைக்கு, «திட்டத்தில் சோதனை முகவரைச் செருகு» என்பதை அழுத்தவும்: IDE காட்சி சொத்துகளுடன் சோதனை முகவரை திட்டத்தில் செருகுகிறது; APK ஐ வழக்கம் போல் உருவாக்கி, நிறுவி, பின்னர் «சோதனை» ஐகானைத் திறக்கவும் — அந்த முகவர் உருவாக்கப்பட்ட செயலிக்குள் இயங்கி உண்மையில் பொத்தான்களை அழுத்தி, உண்மையான புலங்களை நிரப்பி, உருட்டி, பின்னர் அதன் அறிக்கையைத் திரையில் பிடித்த உண்மையான செயலிழப்புகளுடன் காட்டுகிறது. அந்த முகவரை மீண்டும் நீக்க «திட்டத்திலிருந்து சோதனை முகவரை நீக்கு» என்பதை அழுத்தவும். முகவர் செயலியின் சொந்த செயல்முறைக்குள் இயங்குகிறது, எனவே அணுகல் சேவை அல்லது கணினி தன்னியக்கம் தேவையில்லை.

குறியீட்டு நேரப் பயணம்
Git கட்டளைகளைத் தட்டச்சு செய்யாமல் திட்டத்தை முந்தைய குறியீட்டு நிலைக்குத் திருப்ப: முதன்மை பட்டியலில் குறியீட்டு நேரப் பயணம் என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, நேரப் புள்ளி லேபிளை நிரப்பி (காலியாக இருக்கலாம்), பிறகு நேரப் புள்ளியைப் பதிவு செய்க என்பதைத் தட்டுங்கள். IDE திட்ட மூலக் கோப்புகளின் நகலை அவற்றின் hash களுடன் திட்டத்திற்குள் உள்ள .riwayat கோப்புறையில் சேமிக்கிறது. நேரப் புள்ளிப் பட்டியல் அனைத்தையும் காட்டுகிறது; இரண்டு புள்ளிகளைத் தேர்ந்து பிறகு சேர்க்கப்பட்ட, மாற்றப்பட்ட அல்லது நீக்கப்பட்ட கோப்புகள் மற்றும் செயல்பாடுகளைக் காண ஒப்பிடுக என்பதைத் தட்டுங்கள். பழைய நிலையை மீட்க மீட்டெடுக்கவும் என்பதைத் தட்டுங்கள் — மீட்பதற்கு முன் IDE எப்போதும் முதலில் தற்போதைய நிலையின் காப்புப்பிரதியை உருவாக்குகிறது, எனவே எதுவும் இழக்கப்படாது. அசல் திட்டத்தைத் தொந்தரவு செய்யாமல் மாற்றங்களை முயற்சிக்க திட்டத்தைப் புதிய கோப்புறைக்கு நகலெடுக்க சோதனை நகலை உருவாக்குக என்பதைத் தட்டுங்கள். மூலக் கோப்புகள் மட்டுமே பதிவு செய்யப்படும்.

தொகுதித் தொழிற்சாலை
ஒரு திட்டத்தின் ஒரு பகுதியை மற்றொரு திட்டம் பயன்படுத்தக்கூடிய தொகுதியாகப் பொதி செய்ய: முதன்மை பட்டியலில் தொகுதித் தொழிற்சாலை என்பதைத் திறந்து, மூலத் திட்டத்தைத் தேர்ந்து, பொதி செய்ய வேண்டிய திரை, வகுப்பு, சரம் மற்றும் அனுமதிக் கோப்புகளைத் தேர்ந்து, பிறகு தொகுதியாகப் பொதி செய்க என்பதைத் தட்டுங்கள். IDE JSON மெட்டாடேட்டாவுடன் (தொகுதிப் பெயர், பதிப்பு, பயன்படுத்தப்பட்ட சரங்கள் மற்றும் அனுமதிகள்) ZIP காப்பகத்தை எழுதுகிறது. ஒரு தொகுதியை மற்றொரு திட்டத்தில் நிறுவ, தொகுதித் தொழிற்சாலை என்பதைத் திறந்து, இலக்குத் திட்டத்தைத் தேர்ந்து, பிறகு தொகுதியை நிறுவுக என்பதைத் தட்டி தொகுதியின் .zip கோப்பைத் தேர்ந்தெடுங்கள் — இணைப்பு ஏற்கனவே உள்ள குறியீட்டை மேலெழுதாமல் சரங்களையும் அனுமதிகளையும் சேர்க்கிறது, ஒரு கோப்பின் பெயர் இலக்குத் திட்டத்தில் ஏற்கனவே பயன்படுத்தப்பட்டால் அதை இணைக்காது. தொகுதி நூலகங்களையோ கட்டமைப்பு அமைப்புகளையோ கொண்டு வராது.

பலவடிவக் கேடயம் மற்றும் சொத்துப் பெட்டகம்
வெளியிடுவதற்கு முன் அடையாளப் பெயர்களைச் சீரற்றதாக்கி திட்ட சொத்துகளைக் குறியாக்க: முதன்மை மெனுவில் «பலவடிவக் கேடயம் மற்றும் சொத்துப் பெட்டகம்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, «பெயர்களைச் சீரற்றதாக்கி சொத்துகளைக் குறியாக்கு» என்பதை அழுத்தவும். IDE மூலக் குறியீட்டில் வகுப்பு மற்றும் முறைப் பெயர்களை ஸ்கேன் செய்து, சீரற்ற பெயர் வரைபடத்தை உருவாக்கி, தொகுக்கப்பட்ட DEX கோப்புகளுக்குள் அந்தப் பெயர்களை மீண்டும் எழுதுகிறது (மாற்றுப் பெயர்கள் அனைத்து ஆஃப்செட்களும் செல்லுபடியாகும்படி அசல் பெயர்களைப் போலவே நீளமாக உருவாக்கப்படுகின்றன, பின்னர் DEX தலைப்பு செக்சம் மற்றும் SHA-1 கையொப்பம் மீண்டும் கணக்கிடப்படுகிறது), திட்ட சொத்துக் கோப்புகளை திட்டத்திற்குள் உள்ள brankas-aset கோப்புறையில் AES-GCM மூலம் குறியாக்குகிறது, மற்றும் செயலிழப்புப் பதிவுகளைப் படிக்கும்போது அசல் பெயர்களை மீட்டெடுக்க முடியும்படி குறியாக்கப்பட்ட மீட்பு வரைபடத்தை (perisai-peta.brankas) சேமிக்கிறது. குறியாக்க விசை இப்போது திட்டப் பெயரிலிருந்து அல்லாமல், மேம்பாட்டாளர் கடவுச்சொல்லிலிருந்து PBKDF2, 20,000 மறு செய்கைகளுடன் பெறப்படுகிறது. வெற்று உரை, குறிப்புப் பெயர் மற்றும் பிழைத்திருத்தப் பெயராகவும் பயன்படுத்தப்படும் பெயர்கள் வேண்டுமென்றே மீண்டும் எழுதப்படுவதில்லை, மேலும் உருவாக்கப் பாதையில் DEX மீண்டும் எழுதும் செருகல் புள்ளிகள் இன்னும் உண்மையான தொலைபேசியில் சோதனைக்காகக் காத்திருக்கின்றன.

நம்பிக்கைச் சங்கிலி மற்றும் சூழல் காவலர்
வெளியிடுவதற்கு முன் கையொப்ப விசைச் சங்கிலி மற்றும் தொலைபேசிச் சூழலைச் சரிபார்க்க: முதன்மை மெனுவில் «நம்பிக்கைச் சங்கிலி மற்றும் சூழல் காவலர்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, «சங்கிலி மற்றும் சூழலைச் சரிபார்» என்பதை அழுத்தவும். IDE திட்டத் தொகுப்புப் பெயரிலிருந்து 5 தலைமுறை விசைச் சங்கிலியை உருவாக்கி அதன் ஒருமைப்பாட்டைச் சரிபார்க்கிறது, நினைவகத்தில் உள்ள குறியீட்டுப் பகுதிகளின் உள்ளடக்கத்தை வட்டில் உள்ள கோப்புகளுடன் ஒப்பிட்டு உண்மையான நினைவக ஒருமைப்பாட்டைச் சரிபார்த்து, பெயரிடப்படாத இயக்கக்கூடிய (RWX) வரைபடங்கள், வெளிநாட்டு நூலகங்கள் மற்றும் memfd வரைபடங்களைத் தெரிவிக்கிறது, பின்னர் தனது சொந்த செயல்முறையின் நினைவக வரைபடம் மற்றும் சாதனப் பண்புகளை Frida, Xposed அல்லது முன்மாதிரியின் தடயங்களுக்காக ஸ்கேன் செய்கிறது. பெட்டக விசை AndroidKeyStore இல் உள்ள AES விசையால் மூடப்படுகிறது, அது கிடைக்கும்போது வன்பொருள் பாதுகாப்புச் சிப்பைப் பயன்படுத்துகிறது, மேலும் விசைச் சுழற்சி இப்போது உண்மையானது, ஸ்கீமா v3 கையொப்பச் சான்றிதழ் வம்சாவளியைப் பயன்படுத்துகிறது: பழைய விசை புதிய விசைக்கான சுழற்சியின் ஆதாரத்தில் கையொப்பமிடுகிறது, APK அந்த வம்சாவளியுடன் மீண்டும் கையொப்பமிடப்படுகிறது. முடிவு உரைச் சான்றுகளுடன் «பாதுகாப்பானது», «எச்சரிக்கை» அல்லது «ஆபத்தானது» என்ற ஆபத்து நிலை. கணினி நினைவகத்தைப் படிக்க மறுத்தால், சரிபார்ப்பு பாதுகாப்பானது என்றல்லாமல் «சரிபார்க்க முடியாது» என்று தெரிவிக்கப்படுகிறது; மற்றும் ஒரு விசை உண்மையில் வன்பொருள் பாதுகாப்புச் சிப்பைப் பயன்படுத்துகிறதா என்பதை உண்மையான சாதனத்தில் மட்டுமே உறுதிப்படுத்த முடியும்.

உரை மர அமைப்புக் கட்டிடக் கலைஞர்
பார்க்காமல் திரையை வடிவமைக்க: முதன்மை மெனுவில் «உரை மர அமைப்புக் கட்டிடக் கலைஞர்» என்பதைத் திறந்து, திட்டம் மற்றும் அமைப்புக் கோப்பைத் தேர்ந்து, «அமைப்பைச் சரிபார்» என்பதை அழுத்தவும். IDE XML அமைப்பை உரை மரமாகப் படித்து, ஒவ்வொரு உறுப்பின் நிலை விவரிப்பையும் சத்தமாகப் படிக்கிறது (எடுத்துக்காட்டாக கீழ் வலது, திரை அகலத்தில் 45 சதவீதம்), பின்னர் உறுப்புகளுக்கு இடையே ஒன்றுடன் ஒன்று இணைவதையும் 360 dp அகலத்தில் திரைக்கு வெளியே செல்லும் உறுப்புகளையும் கணித ரீதியாகத் தெரிவிக்கிறது. இப்போது கணக்கிடப்படுபவை LinearLayout மற்றும் எளிய dp அளவுகள், முழு ConstraintLayout (அனைத்து கட்டுப்பாடுகள், சார்பு, சங்கிலிகள், வழிகாட்டிகள், தடைகள், சதவீத அகலங்கள், 0dp match_constraint மற்றும் பரிமாண விகிதங்கள்) மற்றும் Compose திரைகள் (அவற்றின் அளவு மாற்றிகளுடன் Column, Row மற்றும் Box) ஆகியவற்றை உள்ளடக்குகின்றன. இயங்கும்போது மாறும் MotionLayout மற்றும் ConstraintSet மட்டுமே நிலை தெரியவில்லை என்று தொடர்ந்து தெரிவிக்கப்படுகின்றன, ஏனெனில் அவற்றின் மதிப்புகள் செயலி இயங்கும்போது மட்டுமே உள்ளன.

வடிவமைப்பு அமைப்பு ஸ்டுடியோ
அனைத்துத் திரைகளிலும் திட்டங்களிலும் தூரங்கள், எழுத்துருக்கள் மற்றும் மூலைகளை ஒரே மாதிரியாக்க: முதன்மை மெனுவில் «வடிவமைப்பு அமைப்பு ஸ்டுடியோ» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, வடிவமைப்பு டோக்கன்களை எழுதி (எடுத்துக்காட்டாக jarak=8, huruf=16, sudut=12), கூறுகளைத் தேர்ந்து, «கூறுகளை உருவாக்கு» என்பதை அழுத்தவும். IDE டோக்கன்களைச் சரிபார்க்கிறது — அடிப்படை தூரம் 4 முதல் 16 dp, அடிப்படை எழுத்துரு 12 முதல் 20 sp, மூலைகள் 0 முதல் 32 dp, மற்றும் குறைந்தபட்ச தொடு பகுதி 48 dp — பின்னர் பயன்படுத்தத் தயாரான XML கூறுகளை (komponen-studio.xml) XML கருப்பொருள் (tema-studio.xml) மற்றும் Compose கருப்பொருள் (tema-studio.kt) உடன் திட்டக் கோப்புறையில் எழுதுகிறது. டோக்கன்களை திட்டங்களுக்கு இடையே பகிரப்படும் டோக்கன் நூலகத்தில் பெயரிடப்பட்ட தொகுப்பாகவும் சேமிக்கலாம், மேலும் ஒரு ஒத்திசைவுக் கட்டளை நூலகத்தின் சமீபத்திய டோக்கன்களை அந்தத் தொகுப்பைப் பயன்படுத்தும் அனைத்துத் திட்டங்களுக்கும் பயன்படுத்துகிறது. கூறுகள் அமைப்பில் ஒட்டப்பட்டு பின்னர் «உரை மர அமைப்புக் கட்டிடக் கலைஞர்» மூலம் சரிபார்க்கப்படும் உரையாக உருவாக்கப்படுகின்றன; டேப்லெட்டில் இரண்டு நெடுவரிசை சரிசெய்தல் இயங்கும்போது சாதனக் கண்டறிதலுக்குப் பதிலாக திரை அகலத் தகுதியைப் பயன்படுத்துகிறது.

பொருள் சார்ந்த மறுசீரமைப்பு மற்றும் AST வழிசெலுத்தல்
வரையறைகளைக் கண்டறிந்து, தற்செயலாக அதே பெயரைக் கொண்ட மற்ற குறியீட்டை உடைக்காமல் குறியீட்டுப் பெயர்களை மாற்ற: முதன்மை மெனுவில் «பொருள் சார்ந்த மறுசீரமைப்பு மற்றும் AST வழிசெலுத்தல்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, அனைத்து வகுப்புகள் மற்றும் முறைகளை அவற்றின் கோப்புகள் மற்றும் வரி எண்களுடன் பார்க்க «திட்டக் குறியீடுகளை ஸ்கேன் செய்» என்பதை அழுத்தவும். குறியீட்டுப் பெயரைத் தட்டச்சு செய்து, அதன் வரையறை மற்றும் அதை அழைக்கும் அனைத்துக் கோப்புகளையும் பார்க்க «திட்டக் குறியீடுகளை ஸ்கேன் செய்» என்பதை மீண்டும் அழுத்தவும். பெயரை மாற்ற, புதிய பெயரைத் தட்டச்சு செய்து, ஒவ்வொரு கோப்பிலும் தோன்றும் எண்ணிக்கையைப் பார்க்க «பெயர் மாற்ற முன்னோட்டம்» என்பதை அழுத்தி, பின்னர் «பெயர் மாற்றத்தைப் பயன்படுத்து» என்பதை அழுத்தவும். அட்டவணையாளர் இப்போது கையால் உருவாக்கப்பட்ட AST பாகுபடுத்தியைப் பயன்படுத்துகிறார் (Java மற்றும் Kotlin துணைக்குழுவிற்கான லெக்சர் மற்றும் மறுநிகழ்வு பாகுபடுத்தி), எனவே கோப்புகளுக்கு இடையே முறைப் பெயர் மாற்றங்கள் தீர்க்கப்படுகின்றன, மற்ற கோப்புகளில் அழைப்பவர்களும் மாறுகிறார்கள்; குறியீட்டுத் தொகுதியை புதிய செயல்பாட்டிற்கு எடுக்கும் பொத்தான் இப்போது இந்தத் திரையில் உள்ளது. இந்தப் பாகுபடுத்தி இன்னும் குறைந்தபட்சமானது: மிகவும் சிக்கலான ஜெனரிக்குகள், அளவுருக்கள் கொண்ட குறிப்புகள் மற்றும் பெயரிடப்படாத வகுப்புகள் அப்படியே ஸ்கேன் செய்யப்படுகின்றன, அதே நேரத்தில் பிரதிபலிப்பு மற்றும் இடைமுகம் வழியாக அழைப்புகள் தீர்க்கப்படுவதில்லை.

படிப்படியான பிழைத்திருத்தி மற்றும் நினைவக ஆய்வாளர்
பதிவுகளிலிருந்து யூகிக்காமல் நிரல் ஓட்டத்தின் நடுவில் மாறி உள்ளடக்கங்களை ஆய்வு செய்ய: முதன்மை மெனுவில் «படிப்படியான பிழைத்திருத்தி மற்றும் நினைவக ஆய்வாளர்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, செயல்படுத்தல் தடத்தை எழுதவும் (ஒரு வரிக்கு ஒரு படி, வடிவம் வரி எண், குறியீடு, பின்னர் | ஆல் பிரிக்கப்பட்ட மாறிகள் மற்றும் மதிப்புகள், எடுத்துக்காட்டாக 10|int total = harga * jumlah;|harga=5000, jumlah=3, total=15000), நிறுத்தப் புள்ளி வரி எண்ணைத் தட்டச்சு செய்து, பின்னர் «பிழைத்திருத்தத் தடத்தை இயக்கு» என்பதை அழுத்தவும். IDE முதல் நிறுத்தப் புள்ளி வரை இயங்கி, Jieshuo வழியாக செயலில் உள்ள வரியை அதன் மாறி மதிப்புகளுடன் சத்தமாகப் படிக்கிறது. ஒரு வரி முன்னேற «ஒரு வரி முன்னேறு» என்பதை அழுத்தவும், அழைக்கப்பட்ட செயல்பாட்டிற்குள் நுழைய «செயல்பாட்டிற்குள் நுழை» என்பதை அழுத்தவும் (அழைப்பு அடுக்குடன்), அல்லது அடுத்த நிறுத்தப் புள்ளிக்கு முன்னேற «நிரலைத் தொடர்க» என்பதை அழுத்தவும். இந்தத் தடப் பிழைத்திருத்தி இன்னும் பதிவு செய்யப்பட்ட அல்லது கையால் எழுதப்பட்ட தடத்தைப் பின்பற்றுகிறது; அதன் அருகில் JDWP கம்பி நெறிமுறையின் தூய Java வாடிக்கையாளர் உள்ளார், அது கைகுலுக்கல் செய்யலாம், நிறுத்தப் புள்ளிகளை அமைக்கலாம், உள்ளே, மேலே மற்றும் வெளியே படியெடுக்கலாம், மேலும் TCP வழியாக அல்லது கேட்கும் முறையில் VM ஐ இடைநிறுத்தி தொடரலாம். சாதாரண செயலிக்குள்ளிருந்து உண்மையான செயல்முறையை நிறுத்துவது இன்னும் முழுமையாக சாத்தியமில்லை, ஏனெனில் ஒரு செயல்முறையின் JDWP சாக்கெட் adbd வழியாக மட்டுமே வெளிப்படுத்தப்படுகிறது — நிரூபிக்கப்பட்ட பாதைக்கு வயர்லெஸ் பிழைத்திருத்தம் மற்றும் ஷெல் வழியாக இலக்கைத் தொடங்குவது தேவை, இது செயலியால் செய்ய முடிந்ததைத் தாண்டியது.

ஆஃப்லைன் சார்பு மேலாளர்
இணையம் இல்லாமல் மூன்றாம் தரப்பு நூலகங்களைப் பயன்படுத்தவும், உருவாக்கத்திற்கு முன் பதிப்பு மோதல்களைத் தவிர்க்கவும்: முதன்மை மெனுவில் «ஆஃப்லைன் சார்பு மேலாளர்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, «சார்புகளைச் சரிபார்» என்பதை அழுத்தவும். IDE திட்டத்தின் அனைத்து .gradle கோப்புகளையும் படித்து, Download/brankas-bersama கோப்புறையில் திட்டங்களுக்கு இடையே பகிரப்படும் பெட்டகத்தைச் சரிபார்த்து, மோதல்களைத் தீர்க்கிறது — இரண்டு நூலகங்கள் ஒரே கலைப்பொருளின் வெவ்வேறு பதிப்புகளைக் கேட்டால், மிக உயர்ந்த பதிப்பு பயன்படுத்தப்பட்டு மோதல் தெரிவிக்கப்படுகிறது. நூலகத்தைப் பதிவிறக்க, அதன் ஆயத்தொலைவுகளைத் தட்டச்சு செய்து (வடிவம் குழு:கலைப்பொருள்:பதிப்பு, எடுத்துக்காட்டாக com.google.code.gson:gson:2.10.1) பின்னர் «சார்புகளைச் சரிபார்» என்பதை அழுத்தவும்: ஆன்லைனில் இருக்கும்போது, AAR, JAR அல்லது WHL கோப்புகள் உண்மையில் Maven, Google அல்லது PyPI இலிருந்து அவற்றின் இடைநிலை சார்பு வரைபடத்துடன் (மறுநிகழ்வு, சுழற்சிகள் துண்டிக்கப்படுகின்றன, ஆழம் 25 நிலைகள் வரை) பதிவிறக்கப்படுகின்றன, மேலும் வெற்றிகரமாகப் பதிவிறக்கப்பட்ட கோப்புகள் மட்டுமே கிடைப்பதாகப் பதிவு செய்யப்படுகின்றன. ஆஃப்லைனில் இருக்கும்போது பகிரப்பட்ட பெட்டகத்தில் ஏற்கனவே உள்ள நூலகங்களை மட்டுமே பயன்படுத்த முடியும். Maven பதிப்பு வரம்புகள் தீர்க்கப்படுவதில்லை, மேலும் பதிவிறக்கப்பட்ட கோப்புகள் அவற்றின் SHA-1 மூலம் மட்டுமே சரிபார்க்கப்படுகின்றன, PGP சரிபார்ப்பு இல்லாமல்.

தரவுத்தள மற்றும் சேமிப்பு ஆய்வாளர்
அட்டவணை உள்ளடக்கத்தை அச்சிடும் குறியீட்டை எழுதாமல் திட்ட தரவுத்தள உள்ளடக்கத்தை ஆய்வு செய்து சோதிக்க: முதன்மை மெனுவில் «தரவுத்தள மற்றும் சேமிப்பு ஆய்வாளர்» என்பதைத் திறந்து, திட்டம் மற்றும் தரவுத்தளக் கோப்பை (.db, .sqlite அல்லது .sqlite3) தேர்ந்து, «தரவுத்தளத்தைத் திற» என்பதை அழுத்தவும். IDE முழு SQLite பக்க பாகுபடுத்தி (வழிதல் பக்கங்களுடன் கூடிய B-மரம்) மூலம் அதன் அனைத்து அட்டவணைகளின் திட்டத்தையும் படித்து, முதல் 20 வரிசைகளை Jieshuo சத்தமாகப் படிக்கும் உரை அட்டவணையாகக் காட்டுகிறது. SELECT வினவலை எழுதி «வினவலை இயக்கு» என்பதை அழுத்தவும் (எடுத்துக்காட்டாக SELECT nama FROM pengguna WHERE kota = 'Makassar') — வினவல்கள் இப்போது JOIN, GROUP BY, ORDER BY மற்றும் LIKE ஐ ஆதரிக்கின்றன, மேலும் தொலைபேசியில் உண்மையான Android SQLite இயந்திரம் வழியாக இயங்குகின்றன. மதிப்பை மாற்ற, வரிசை எண் (1 = முதல் வரிசை), நெடுவரிசைப் பெயர் மற்றும் புதிய மதிப்பைத் தட்டச்சு செய்து, «செல் மதிப்பை மாற்று» என்பதை அழுத்தவும் — அந்த மதிப்பு .db கோப்பில் மீண்டும் எழுதப்படும். அட்டவணையின் தற்போதைய நிலையை திட்டத்தில் <தரவுத்தள-பெயர்>.cadangan.txt கோப்பாகச் சேமிக்க «காப்புப்பிரதியைச் சேமி» என்பதை அழுத்தவும். SharedPreferences மற்றும் DataStore ஐயும் படிக்கலாம். இன்னும் படிக்க முடியாதவை: குறியாக்கப்பட்ட தரவுத்தளங்கள், உறுதி செய்யப்படாத WAL மாற்றங்கள், மற்றும் சிறப்பு DataStore Proto இல் வகைப்படுத்தப்பட்ட மதிப்புகள் (பொதுவான புலக் காட்சியாக மட்டுமே காட்டப்படும்).

அலகு சோதனை தொழிற்சாலை மற்றும் ஃபஸ்ஸிங்
செயலியைப் பகிர்வதற்கு முன் தர்க்க இடைவெளிகளைக் கண்டறிய: முதன்மை மெனுவில் «அலகு சோதனை தொழிற்சாலை மற்றும் ஃபஸ்ஸிங்» என்பதைத் திறந்து, திட்டம் மற்றும் குறியீட்டுக் கோப்பைத் தேர்ந்து, «சோதனைகளை உருவாக்கி இயக்கு» என்பதை அழுத்தவும். IDE கோப்பில் உள்ள செயல்பாட்டுக் கையொப்பங்களைப் படித்து, சாதாரண மற்றும் எல்லைச் சோதனை வழக்குகளை உருவாக்குகிறது (வெற்று உரை, null, அதிகபட்ச எண்கள், விசித்திர எழுத்துகள்), பின்னர் உண்மையில் அந்தச் சோதனைகளை இயக்குகிறது: திட்டக் குறியீடு தொகுக்கப்படுகிறது, ஒவ்வொரு @Test முறையும் 5 வினாடி வரம்புடன் செயல்படுத்தப்படுகிறது, எனவே முடிவு அவற்றின் உண்மையான மதிப்புகளுடன் உண்மையான தேர்ச்சிகள் மற்றும் தோல்விகள். ஃபஸ்ஸிங்கும் திட்டச் செயல்பாடுகளில் உண்மையில் இயங்குகிறது (பிரதிபலிப்பு வழியாக, ஒரு அழைப்புக்கு 2 வினாடிகள், அதிகபட்சம் 20 முறைகள்), மற்றும் வரி உள்ளடக்க சதவீதம் அசல் வரி எண்களைப் பாதுகாக்கும் கருவி மூலம் உண்மையில் கணக்கிடப்படுகிறது. முடிவு எத்தனை சோதனைகள் தேர்ச்சி பெற்றன, தோல்வியடைந்தன, எத்தனை குறியீட்டு வரிகள் மற்றும் செயல்பாடுகள் கண்டறியப்பட்டன, எந்தச் சோதனை வழக்குகள் உருவாக்கப்பட்டன என்பதைத் தெரிவிக்கிறது. உருவாக்கப்பட்ட சோதனைகள் JUnit உடன் அதே API ஐப் பயன்படுத்துகின்றன, ஆனால் குறிப்பு மற்றும் உறுதிப்பாடு வரையறைகள் உருவாக்கப்பட்ட சோதனைக் கோப்பின் உள்ளேயே எழுதப்படுகின்றன, ஏனெனில் உண்மையான JUnit நூலகம் செயலியில் சேர்க்கப்படவில்லை.

தீவிர சாதன நிலை உருவகப்படுத்தி மற்றும் நினைவகக் கசிவு தணிக்கையாளர்
கணினி அதன் செயல்முறையை நிறுத்தும்போது, பிணையம் துண்டிக்கப்படும்போது, திரை சுழலும்போது, அல்லது மின்கலச் சேமிப்பு இயக்கத்தில் இருக்கும்போது செயலியின் தாங்குதிறனைச் சோதிக்க: முதன்மை மெனுவில் «தீவிர சாதன நிலை உருவகப்படுத்தி மற்றும் நினைவகக் கசிவு தணிக்கையாளர்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, «உருவகப்படுத்துதலை இயக்கு» என்பதை அழுத்தவும். IDE திரை சுழற்சி உருவகப்படுத்துதலுடன் மூன்று அழுத்தக் காட்சிகளை இயக்கி, அவற்றின் திரை மூடப்பட்ட பிறகும் நினைவகத்தில் வைக்கப்பட்டுள்ள பொருள்களைக் கண்காணித்து, பின்னர் இழந்த தரவு மற்றும் கசியும் பொருள் சங்கிலிகளைத் தெரிவிக்கிறது. சேமிப்பு மற்றும் மீட்டெடுப்பு நிலை இப்போது நிலையான எடுத்துக்காட்டிலிருந்து அல்லாமல், பயனரின் சொந்த திட்ட மூலத்திலிருந்து படிக்கப்படுகிறது; உள்ளூர் லூப் பேக் சேவையகம் பிணையத் துண்டிப்பை அளவிட சோதனையின் நடுவில் உண்மையில் நிறுத்தப்படுகிறது; உண்மையான ஹீப் டம்ப் எடுக்கப்பட்டு பகுப்பாய்வு செய்யப்படுகிறது, இரண்டு டம்புகளை ஒப்பிட்டு GC வேர்களிலிருந்து வைத்திருக்கும் சங்கிலியைக் கண்காணிக்க; மற்றும் செயலியின் சொந்த செயல்முறை அதன் நிலையைச் சேமித்த பிறகு உண்மையில் நிறுத்தப்படுகிறது, பின்னர் மீண்டும் திறக்கும்போது எந்தத் தரவு திரும்பும் என்று சரிபார்க்கப்படுகிறது. சாதாரண செயலியிலிருந்து இன்னும் சாத்தியமற்றவை: தொலைபேசி வானொலி அல்லது Wi-Fi ஐ அணைப்பது மற்றும் பிற செயலிகளைக் கட்டாயமாக நிறுத்துவது — இரண்டிற்கும் கணினி அனுமதி தேவை; அதற்குப் பதிலாக, பின்னணி செயலிகள் killBackgroundProcesses மூலம் நிறுத்தப்படுகின்றன, அதன் அனுமதி ஏற்கனவே மேனிஃபெஸ்டில் உள்ளது, திரையில் நேர்மையான அடையாளத்துடன்.

திட்ட வரைபடக் கட்டிடக் கலைஞர்
பெரிய செயலி யோசனையை படிப்படியான வேலைத் திட்டமாக மாற்ற: முதன்மை மெனுவில் «திட்ட வரைபடக் கட்டிடக் கலைஞர்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, செயலி யோசனையை எழுதவும் (எடுத்துக்காட்டாக தவணைகளுடன் கூடிய சிறிய மளிகைக் கடை காசாளர் செயலி), பின்னர் «வரைபடத்தை உருவாக்கு» என்பதை அழுத்தவும். IDE தொகுதிகள், கோப்புப் பட்டியல் மற்றும் சிறிய மைல்கற்களை உருவாக்கி, அவற்றை திட்டக் கோப்புறையில் cetak-biru.txt ஆகச் சேமிக்கிறது. ஒரு மைல்கல் முடிவடையும் ஒவ்வொரு முறையும் «அடுத்த மைல்கல்லை முடிந்ததாகக் குறி» என்பதை அழுத்தவும், அல்லது சேமிக்கப்பட்ட வரைபடத்தை மீண்டும் திறக்க «சேமித்த வரைபடத்தை ஏற்றுக» என்பதை அழுத்தவும். «AI அமைப்புகள்» இல் செயலில் உள்ள AI வழங்குநர் தேர்ந்தெடுக்கப்பட்டு அதன் விசை கிடைத்தால், வரைபடம் அந்த வழங்குநரால் உருவாக்கப்படுகிறது; விசை இல்லை என்றால் அல்லது வழங்குநரை அணுக முடியவில்லை என்றால், IDE ஆஃப்லைன் முக்கியச் சொல் வடிவங்களுக்குத் திரும்பி அந்த வரம்பை நேர்மையாகக் கூறுகிறது. வழங்குநரின் பதில் வடிவத்திற்கு மட்டுமே சரிபார்க்கப்படுகிறது (தொகுதிகள் மற்றும் மைல்கற்கள் உள்ளன), உள்ளடக்கத்தின் உண்மைக்கு அல்ல — உருவாக்குவதற்கு முன் எப்போதும் வரைபடத்தை மதிப்பாய்வு செய்யுங்கள்.

குறியீடு தர்க்க ஓட்டக் கதைசொல்லி
தொடரியலை வரி வரியாகக் கேட்காமல் நீண்ட குறியீட்டைப் புரிந்துகொள்ள: முதன்மை மெனுவில் «குறியீடு தர்க்க ஓட்டக் கதைசொல்லி» என்பதைத் திறந்து, திட்டம் மற்றும் குறியீட்டுக் கோப்பைத் தேர்ந்து, «குறியீடு விளக்கம்» என்பதை அழுத்தவும். IDE ஒவ்வொரு வரியையும் இந்தோனேசிய வாக்கியமாக மாற்றுகிறது (எடுத்துக்காட்டாக மொத்தம் 100000 ஐ விட அதிகமாக இருந்தால், அடுத்த தொகுதியை இயக்கவும்), முறைகளுக்கு இடையே அழைப்பு வரைபடம் மற்றும் முறைகளுக்கு இடையே தரவு ஓட்டப் பகுப்பாய்வு (அனுப்பப்பட்ட, பயன்படுத்தப்பட்ட அல்லது புறக்கணிக்கப்பட்ட மதிப்புகள்) ஆகியவற்றைக் காட்டுகிறது, மற்றும் நுட்பமான சாத்தியமான பிழைகளை அவற்றின் வரி எண்களுடன் குறிக்கிறது — == உடன் ஒப்பிடப்பட்ட String, மூடாமல் திறக்கப்பட்ட ஸ்ட்ரீம், மற்றும் இரண்டு வெவ்வேறு முறைகளில் எழுதப்பட்ட மாறி. «AI அமைப்புகள்» இல் செயலில் உள்ள AI வழங்குநர் தேர்ந்தெடுக்கப்பட்டால், அந்த வழங்குநரிடமிருந்து ஓட்டச் சுருக்கமும் கிடைக்கும்; கிடைக்கவில்லை என்றால், திரை ஆஃப்லைன் விளக்கத்தைப் பயன்படுத்தி அந்த வரம்பைக் கூறுகிறது. விளக்கம், அழைப்பு வரைபடம் மற்றும் தரவு ஓட்டம் ஆஃப்லைன் உரை வடிவப் பகுப்பாய்வைப் பயன்படுத்துகின்றன, முழு AST பாகுபடுத்தி அல்ல — திறக்கும் அடைப்புக்குறி தனி வரியில் உள்ள முறைகள், வகுப்புப் புலங்கள், மற்றும் பிரதிபலிப்பு வழியாக அழைப்புகள் கண்காணிக்கப்படுவதில்லை — மற்றும் தரவு பந்தய எச்சரிக்கைகள் உண்மையில் மாறி மாறி மட்டுமே பயன்படுத்தப்படும் மாறிக்குத் தோன்றலாம்.

செயலி தொகுப்பு தொழிற்சாலை மற்றும் Play Store தயார்நிலை
தொலைபேசியிலிருந்து நேரடியாக Google Play Store க்கு செயலியைத் தயார் செய்ய: முதன்மை மெனுவில் «செயலி தொகுப்பு தொழிற்சாலை மற்றும் Play Store தயார்நிலை» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, «AAB தொகுப்பை உருவாக்கு» என்பதை அழுத்தவும். IDE உண்மையான BundleConfig.pb உடன் திட்ட மேனிஃபெஸ்ட், வளங்கள் மற்றும் சொத்துகளிலிருந்து .aab கோப்பை உருவாக்கி, தொகுப்பு அமைப்பைச் சரிபார்த்து, பின்னர் தொகுப்பை உண்மையான மாறுபாடு APK களாகப் பிரிக்கிறது (அடிப்படை, கட்டமைப்பின்படி, மொழிப்படி, மற்றும் உலகளாவிய) அந்தப் பிரிவிலிருந்து அளவிடப்பட்ட அளவுகளுடன், மதிப்பீடு அல்ல. தொகுப்பு APK கையொப்பத்திற்குப் பயன்படுத்தப்படும் அதே திட்ட விசையுடன் JAR v1 மூலம் கையொப்பமிடப்படுகிறது, மேலும் அதன் கையொப்பச் சங்கிலி மறைக்குறியீட்டு ரீதியாகச் சரிபார்க்கப்படுகிறது. இந்தத் திரை Play தயார்நிலையையும் தணிக்கை செய்கிறது — இலக்கு SDK 35 க்குக் கீழே இருந்தால் «உயர்» என்று குறிக்கப்படுகிறது, ஏனெனில் Play Store க்கு 35 அல்லது அதற்கு மேல் தேவை, மேலும் காணாமல் போன 64-பிட் நூலகமும் «உயர்» என்று குறிக்கப்படுகிறது. உண்மையான bundletool சாதனத்தில் இயங்க முடியாது, ஏனெனில் bundletool க்கு JVM தேவை, அதே நேரத்தில் Android இல் JVM இல்லை; மேலே உள்ள பாதை சாதனத்தில் மிக நெருக்கமான உண்மையான பாதை.

OTA புதுப்பிப்பு இயந்திரம் மற்றும் படிப்படியான வெளியீடுகள்
பயனர்களை முழு APK ஐ மீண்டும் பதிவிறக்கும்படி கட்டாயப்படுத்தாமல் சிறிய திருத்தத்தை அனுப்ப: முதன்மை மெனுவில் «OTA புதுப்பிப்பு இயந்திரம் மற்றும் படிப்படியான வெளியீடுகள்» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, பழைய மற்றும் புதிய பதிப்பு உள்ளடக்கத்தை எழுதி, «இணைப்புத் தொகுப்பை உருவாக்கு» என்பதை அழுத்தவும். IDE வேறுபாட்டைக் கணக்கிட்டு, புதிய உள்ளடக்கத்தின் SHA-256 கைரேகையுடன் இணைப்புத் தொகுப்பை (patch-ota.zip) உருவாக்கி, இந்தச் சாதனம் முதல் 10 சதவீத வெளியீட்டு கட்டத்தில் உள்ளதா என்று சரிபார்க்கிறது. இணைப்புகள் இப்போது எந்தக் கோப்பிலும் பைனரி டெல்டாவை ஆதரிக்கின்றன (DEX மற்றும் APK உட்பட), RSA-2048 கையொப்பத்துடன் தொகுக்கப்பட்டு, பயன்படுத்துவதற்கு முன் நம்பகமான பொது விசையால் சரிபார்க்கப்படுகின்றன, மேலும் மேம்பாட்டாளர் சேவையகத்திலிருந்து அதன் வெளியீட்டுப் பட்டியலுடன் பதிவிறக்கலாம்; பயன்பாடு தோல்வியுற்றால், பழைய கோப்பு அப்படியே இருக்கும். இயங்கும் செயலிக்கு இணைப்பைப் பயன்படுத்துவது திட்ட விசையுடன் மீண்டும் கையொப்பமிட்டு PackageInstaller வழியாகச் செய்யப்படுகிறது, ஏனெனில் இயங்கும் செயல்முறையின் குறியீட்டை அதன் உள்ளிருந்து மாற்றுவது சாத்தியமில்லை — APK பூட்டப்பட்டுள்ளது, DEX ஏற்கனவே ஏற்றப்பட்டுள்ளது.

குழு குறியீடு மதிப்பாய்வு ஸ்டுடியோ
சக ஊழியரின் மாற்றங்களை மதிப்பாய்வு செய்து, Git அம்புக்குறிகளைப் படிக்காமல் இணைப்பு மோதல்களைத் தீர்க்க: முதன்மை மெனுவில் «குழு குறியீடு மதிப்பாய்வு ஸ்டுடியோ» என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்து, மூன்று உரைப் பதிப்புகளை (அடிப்படை, உள்ளூர், சக ஊழியர்) தட்டச்சு செய்து, «குழு மதிப்பாய்வைத் திற» என்பதை அழுத்தவும். IDE மூன்றையும் Java தொடரியல் அலகுகளின் அடிப்படையில் இணைக்கிறது — ஒரே வரியில் இரண்டு மாற்றங்கள் ஆனால் வெவ்வேறு அறிக்கைகளில் இனி மோதலாகக் கருதப்படுவதில்லை — மேலும் ஒவ்வொரு மோதலையும் வாக்குத் தேர்வாகக் காட்டுகிறது: உள்ளூர் பதிப்பைப் பயன்படுத்தவும், சக ஊழியர் பதிப்பைப் பயன்படுத்தவும், அல்லது இரண்டையும் இணைக்கவும் — முடிவு வரி வரிசை சரியாக இருக்கும்படி அசல் மோதல் நிலையில் செருகப்படுகிறது — பின்னர் முடிவை திட்டத்தில் gabung-hasil.txt இல் எழுதுகிறது. கீழே திட்டப் பணிப் பலகை உள்ளது: பணித் தலைப்பைத் தட்டச்சு செய்து «பணியைச் சேர்» என்பதை அழுத்தவும்; பணிகள் திட்டத்திற்குள் உள்ள .tugas கோப்புறையில் உரையாகச் சேமிக்கப்பட்டு, செயலிக்குள் உள்ள Git இல் கமிட்கள் வழியாக ஒத்திசைக்கப்படுகின்றன, எனவே பலகையை எந்த கமிட் வரலாற்றிலிருந்தும் மீண்டும் படிக்கலாம். இந்தத் தொடரியல் பிரிப்பான் முழு AST பாகுபடுத்தி அல்ல, செயலிக்குள் உள்ள Git ஒவ்வொரு கமிட்டிற்கும் முழு ஸ்னாப்ஷாட்டைச் சேமிக்கிறது; சிறப்பு ஒத்திசைவு சேவையகம் இல்லை.

குறியீட்டு அமைப்பு குரல் கட்டளை
எடிட்டருக்குள் குரல் மூலம் குறியீடு எழுத: எடிட்டரில் ஒரு திட்டத்தைத் திறந்து, பிறகு குறியீட்டு அமைப்பு குரல் கட்டளை பொத்தானைத் தட்டுங்கள். இந்தோனேசிய மொழியில் கட்டளைகளைப் பேசுங்கள், எடுத்துக்காட்டாக buat fungsi tambah dengan parameter a angka dan b angka, buat kelas Mobil, அல்லது buat variabel teks nama sama dengan Budi — IDE பேச்சை இலக்கணப்படி சரியான Java, Kotlin, Python அல்லது Compose குறியீட்டுத் தொகுதியாக மாற்றி கர்சர் நிலையில் செருகி, பிறகு Jieshuo மூலம் சுருக்கமான சுருக்கத்தை உரக்க வாசிக்கிறது. குரல் கட்டளை அமைப்பின் உள்ளமைந்த குரல் உள்ளீட்டுச் சேவையைப் பயன்படுத்துகிறது, கூடுதல் ஒலிவாங்கி அனுமதி தேவையில்லை, ஏற்கனவே பதிவு செய்யப்பட்ட கட்டளை வடிவங்களை மட்டுமே அடையாளம் காண்கிறது; அந்த வடிவங்களுக்கு வெளியே உள்ள பேச்சு குறியீடாக மாற்றப்படாது. சொற்களால் பேசப்படும் எண்கள் (எடுத்துக்காட்டாக 'lima') இன்னும் இலக்கங்களாக மாற்றப்படவில்லை.

உள்ளூர் ஒத்துழைப்பு அறை (இணையம் இல்லாமல்)
இணையம் இல்லாமல் ஒரே அறையில் ஒன்றாக வேலை செய்ய: முதன்மை பட்டியலில் ஒத்துழைப்பு என்பதைத் திறந்து, பிறகு உள்ளூர் ஒத்துழைப்பு அறை பகுதியைத் திறங்கள். ஒரு தொலைபேசி அமர்வைத் திறக்கிறது (IDE உள்ளூர் IP முகவரியையும் 6 இலக்க PIN ஐயும் காட்டுகிறது), மற்றொரு தொலைபேசி அந்த முகவரி மற்றும் PIN மூலம் சேர்கிறது. உரை மாற்றங்கள் வரி வேறுபாடுகளாக அனுப்பப்படுகின்றன, கட்டப்பட்ட APK சோதனையாளரின் தொலைபேசிக்கு அனுப்பப்படலாம், சோதனையாளரின் தொலைபேசியிலிருந்து செயலிழப்பு அறிக்கைகள் திரும்பப் பெறப்படுகின்றன. ஒரு அமர்வு ஒரு நண்பருக்கு மட்டுமே; இரண்டு பேர் ஒரே நேரத்தில் சரியாக அதே வரியை மாற்றினால், கடைசி மாற்றம் பயன்படுத்தப்படும். PIN உள்ளூர் வலையமைப்பில் வெற்று உரையாக அனுப்பப்படுகிறது. இந்த அறை இன்னும் உண்மையான தொலைபேசியில் சோதிக்கப்படவில்லை.

AI அமைப்புகள்
செயலிகளை உருவாக்க AI வழங்குநர் மற்றும் API விசைகளை அமைக்க: முதன்மை மெனுவில், அமைப்புகள் குழுவில், «AI அமைப்புகள்» என்பதை அழுத்தவும் («இணைப்பான்» பொத்தானுக்கு அடுத்து). கிடைக்கும் பட்டியலிலிருந்து பயன்படுத்த வேண்டிய வழங்குநரைத் தேர்ந்து, ஒரு மாதிரி தோல்வியுற்றால் IDE தானாகவே அதே வழங்குநரின் அடுத்த மாதிரியை முயற்சிக்கும்படி «வழங்குநர் பிழையானால் மாதிரியை மாற்றவும்» என்பதைச் சரிபார்க்கவும். காப்பு விசைகளைச் சேர்க்க «API விசைகளை நிர்வகிக்கவும்» என்பதை அழுத்தவும் (பெயர் மற்றும் விசையைத் தட்டச்சு செய்து, «சேமிக்கவும்» என்பதை அழுத்தவும்; விசைகள் மறைக்கப்பட்டு காட்டப்படுகின்றன, கடைசி 4 எழுத்துகள் மட்டுமே தெரியும்). விசைகள் தொலைபேசியில் சேமிக்கப்படுகின்றன, செயலியை உருவாக்கும்போது தேர்ந்தெடுக்கப்பட்ட வழங்குநரைத் தவிர வேறு எங்கும் அனுப்பப்படுவதில்லை. தேர்ந்தெடுக்கப்பட்ட வழங்குநர் இப்போது உண்மையில் «திட்ட வரைபடக் கட்டிடக் கலைஞர்» மற்றும் «குறியீடு தர்க்க ஓட்டக் கதைசொல்லி» ஆகியவற்றால் பயன்படுத்தப்படுகிறார்; «AI பயன்பாட்டு உருவாக்கி» திரையில் செயலியை உருவாக்குவது இன்னும் தொலைபேசியில் உள்ளூர் AI ஐப் பயன்படுத்துகிறது (இணையம் இல்லாமல்).

இணைப்பான்
APK ஐ பகுப்பாய்வு செய்து பிறகு அனுப்ப: முதன்மை பட்டியலில், அமைப்புகள் குழுவில், இணைப்பான் என்பதைத் தட்டுங்கள் (AI அமைப்புகள் பொத்தானுக்கு அடுத்து). தொலைபேசியிலிருந்து APK கோப்பைத் தேர்ந்தெடுங்கள், IDE அதன் உள்ளடக்கத்தைப் படிக்கிறது (தொகுப்புப் பெயர், பதிப்பு, செயல்பாடுகளின் பட்டியல்), பிறகு கணினி பகிர்வு பட்டியல் (எடுத்துக்காட்டாக WhatsApp அல்லது Drive) வழியாக அனுப்ப APK அனுப்பவும் என்பதைத் தட்டுங்கள்.

மொழி மற்றும் குரல்
செயலியின் மொழியை மாற்ற: அமைப்புகள் என்பதைத் திறந்து, பிறகு பயன்பாட்டு மொழி என்பதைத் திறந்து, பிறகு ஒரு மொழியை அல்லது கணினியைப் பின்பற்றவும் என்பதைத் தேர்ந்தெடுங்கள். முதன்மைத் திரையும் பெரும்பாலான திரைகளும் செயலியை மூடாமலோ மறுதொடக்கம் செய்யாமலோ உடனடியாகத் தேர்ந்த மொழிக்கு மாறும்; சில திரைகள் (எடுத்துக்காட்டாக Terminal, ஒத்துழைப்பு, AI அமைப்புகள் மற்றும் விசைகளை நிர்வகிக்கவும்) மீண்டும் திறக்கப்படும் வரை பழைய மொழியையே பயன்படுத்தும். கணினியைப் பின்பற்றவும் என்பதைத் தேர்ந்தால், மொழி தொலைபேசியின் கணினி மொழியைப் பின்பற்றும்.

ஒவ்வொரு திட்டத்திற்கும் இயல்புநிலைக் கையொப்பம் மற்றும் Anti Tamper
பதிப்பு 5.7 முதல், தனிப்பட்ட கையொப்பத்தைப் பயன்படுத்தாத திட்டம் அந்தத் திட்டத்தின் சொந்த உள்ளமைக்கப்பட்ட விசையால் கையொப்பமிடப்படுகிறது (திட்டத்தின் உள்ளே உள்ள tanda-tangan-bawaan கோப்புறையில் ஒரு முறை உருவாக்கப்பட்டு, பின்னர் தொடர்ந்து பயன்படுத்தப்படுகிறது), எனவே உள்ளமைக்கப்பட்ட கையொப்பம் திட்டத்திற்குத் திட்டம் வேறுபடுகிறது — இனி அனைத்துப் பயன்பாடுகளுக்கும் ஒரு பகிரப்பட்ட விசை இல்லை. tanda-tangan-bawaan கோப்புறையை நீக்க வேண்டாம்: அந்த விசை இல்லாமல், புதிய APK அதே திட்டத்தின் பழைய APK ஐ மேலெழுத முடியாது. ஒவ்வொரு திட்டத்தின் அமைப்புகளும் (தனித்த கட்டமைப்பு, தனிப்பட்ட கையொப்பம், Anti Tamper, தேர்ந்தெடுக்கப்பட்ட keystore, SDK) இப்போது திட்டத்தின் உள்ளே உள்ள settings.gradle கோப்பில் சேமிக்கப்பட்டு, திட்டம் உருவாக்கப்படும் ஒவ்வொரு முறையும் மீண்டும் படிக்கப்படுகின்றன. அமைப்புகளில், கையொப்ப வகையில், உருவாக்கப்பட்ட பயன்பாட்டின் Anti Tamper தேர்வுப்பெட்டி உள்ளது: செயலில் இருந்தால், சாதனத்தில் உருவாக்கப்பட்ட பயன்பாடு ஒவ்வொரு முறை திறக்கப்படும்போதும் அதன் கையொப்பத்தையும் dex உள்ளடக்கத்தையும் சரிபார்க்கிறது; அது மீண்டும் கையொப்பமிடப்பட்டால் அல்லது வேறு ஒருவரால் மாற்றப்பட்டால், பயன்பாடு இயங்க மறுக்கிறது. Frida/Xposed போன்ற பிழைத்திருத்திகள் மற்றும் ஊசி கருவிகளும் கண்டறியப்படுகின்றன, மேலும் பயன்பாட்டுச் சாளரம் திரைப் பதிவிலிருந்து பூட்டப்படுகிறது.

டெமோ வீடியோ உருவாக்கி
உருவாக்கப்பட்ட பயன்பாட்டின் டெமோ வீடியோவை உருவாக்க: முதன்மைப் பட்டியலில் டெமோ வீடியோ உருவாக்கி என்பதைத் திறந்து, திட்டத்தைத் தேர்ந்தெடுத்து, வீடியோ தலைப்பை நிரப்பி, Demo வீடியோ ஸ்கிரிப்டை உருவாக்கவும் என்பதை அழுத்தவும் — IDE 5 நிலையான காட்சிகள் (தொடக்கம், முதன்மைத் தோற்றம், அம்சம் 1, அம்சம் 2, முடிவு) கொண்ட video-demo.txt ஐ விவரிப்பு உரை மற்றும் ஒவ்வொரு காட்சியின் கால அளவுடன் எழுதுகிறது. திட்டத்தின் படங்களிலிருந்து (ஐகான் + இருந்தால் திரைக்காட்சிகள்) ஒவ்வொரு 5 வினாடிகளிலும் தானாக மாறும் video-demo.html ஐ உருவாக்க HTML Slideshow ஐ உருவாக்கவும் என்பதை அழுத்தவும். இது .mp4 வீடியோ அல்ல — உண்மையான வீடியோவிற்கு, தொலைபேசி உலாவியில் video-demo.html ஐத் திறந்து பின்னர் திரையைப் பதிவு செய்யவும், அல்லது இயங்கும் பயன்பாட்டைப் பதிவு செய்யும்போது video-demo.txt இல் உள்ள விவரிப்பைப் படிக்கவும்.

Android Studio பாணியில் புதிய தோற்றம்
IDE இன் தோற்றம் இப்போது Android Studio போல நேர்த்தியாக்கப்பட்டுள்ளது (தோற்றம் மட்டும் — அனைத்து பொத்தான்கள், பட்டியல்கள் மற்றும் ஓட்டங்கள் முன்பு போலவே இருக்கும்): வெளிர் சாம்பல் பின்னணி, தடித்த கருப்பு திரைத் தலைப்புகள், வெள்ளை உரையுடன் நீல பொத்தான்கள் மற்றும் மெல்லிய விளிம்புடன் கூடிய வெள்ளை உள்ளீட்டுப் பெட்டிகள். முதன்மைப் பட்டியல் பொத்தான் வரிசையை மாற்றாமல் காட்சி ரீதியாகத் தொகுக்கப்பட்டுள்ளது (உருவாக்குநர் அம்சங்கள், மேகம், தீம் & பிற, குரல், குறியீடு & புதிய அம்சங்கள், கருவிகள்). Terminal இன்னும் Android Studio இல் உள்ள Terminal சாளரத்தைப் போன்ற இருண்ட பலகத்தைப் பயன்படுத்துகிறது, மேலும் குறியீடு திருத்தி இன்னும் வெள்ளை பின்னணி மற்றும் கருப்பு உரையை வைத்திருக்கிறது. அனைத்து உரைகளும் Jieshuo ஆல் இன்னும் தெளிவாகப் படிக்கப்படுகின்றன.

அமைப்புகள்
பயன்பாட்டை அமைக்க: முதன்மைத் திரையில் விருப்பங்கள் பட்டியலைத் திறந்து, அமைப்புகள் என்பதை அழுத்தவும். அதன் உள்ளே 12 வகைகள் உள்ளன: GitHub அமைப்புகள் (பாதுகாப்பு, தனிப்பட்ட கையொப்பம், உருவாக்க வரலாறு மற்றும் GitHub டோக்கன்), சாதனத்தில் APK உருவாக்க அமைப்புகள் (keystore கடவுச்சொல் மற்றும் உருவாக்க வரலாற்றைச் சாதனத்தில் சேமிக்கவும்), தீம் (பயன்பாட்டு நிறம்), கையொப்பம் (தனிப்பட்ட கையொப்பத்திற்கான keystore ஐ உருவாக்கி, உருவாக்கப்பட்ட பயன்பாட்டின் Anti Tamper தேர்வுப்பெட்டி), திட்டக் கோப்புறை (திட்டக் கோப்புறையின் இடம்), மொழி மற்றும் குரல் (இடைமுக மொழி மற்றும் குரல் பயன்முறை பேச்சு வேகம்), உரை அளவு மற்றும் தோற்றம் (திருத்தி எழுத்துரு அளவு), உருவாக்கம் (திட்டத்தை உருவாக்கு திரைக்கான இயல்புநிலை இலக்கு SDK மற்றும் இயல்புநிலை கட்டமைப்புப் பிரிப்பு), அறிவிப்புகள் (உருவாக்கம் முடிந்ததும் ஒலி), தானியங்கி காப்புப்பிரதி (திட்டக் காப்புப்பிரதி அட்டவணை), டெவலப்பர் சுயவிவரம் (நன்கொடைத் திரையில் காட்டப்படும் பெயர், WhatsApp எண் மற்றும் கணக்கு) மற்றும் தனியுரிமை மற்றும் தரவு (அமைப்புகளை மீட்டமைத்து, பயன்பாட்டுத் தரவை நீக்கவும்). ஒவ்வொரு வகையிலும் வகைப் பட்டியலுக்குத் திரும்ப முந்தைய பக்கத்திற்குத் திரும்பு பொத்தான் உள்ளது. இப்போதுதான் சேமிக்கப்பட்ட (இன்னும் பயன்படுத்தப்படாத) அமைப்புகள் திரையில் நேர்மையாக விளக்கப்பட்டுள்ளன.

டெவலப்பருக்கு நன்கொடை
நன்கொடை அளிக்க அல்லது டெவலப்பருக்கு வணக்கம் கூற: முதன்மைத் திரையில் கருவி பற்றி பொத்தானுக்கு அருகில் உள்ள டெவலப்பருக்கு நன்கொடை பொத்தானை அழுத்தவும். நன்கொடைத் திரையில் BRI கணக்கை நகலெடுக்கவும் பொத்தான் உள்ளது — டெவலப்பரின் கணக்கு எண்ணை நகலெடுக்க அதை அழுத்தி, பின்னர் உங்கள் வங்கிப் பயன்பாட்டில் ஒட்டவும். WhatsApp இல் டெவலப்பரை வாழ்த்தவும் பகுதியும் உள்ளது: உங்கள் பெயர் மற்றும் சொந்த ஊரை நிரப்பி, WhatsApp இல் அனுப்பவும் என்பதை அழுத்தவும் — WhatsApp வாழ்த்துச் செய்தி ஏற்கனவே நிரப்பப்பட்ட நிலையில் திறக்கிறது, WhatsApp இல் அனுப்பவும் என்பதை அழுத்தி பின்னர் பயன்பாட்டிற்குத் திரும்பவும். WhatsApp மற்ற பயன்பாடுகள் தானாகச் செய்திகளை அனுப்ப அனுமதிக்காது, எனவே அனுப்புதல் இன்னும் WhatsApp இல் நீங்களே செய்கிறீர்கள்.

முனையத்தின் பிடித்த கட்டளைகள்
Terminal இல் அடிக்கடி பயன்படுத்தப்படும் கட்டளைகளைச் சேமிக்க: Terminal ஐத் திறந்து பிடித்தவை என்பதை அழுத்தவும். புதிய பிடித்தத்தைச் சேர்க்கவும் என்பதைத் தட்டி, பெயர் (எடுத்துக்காட்டாக கோப்பைப் பார்க்கவும்) மற்றும் அதன் கட்டளை (எடுத்துக்காட்டாக ls -la) ஆகியவற்றை நிரப்பி, சேமிக்கவும் என்பதை அழுத்தவும் — பிடித்தது தொலைபேசியில் நிரந்தரமாகச் சேமிக்கப்படும். பிடித்தப் பெயரைத் தட்டினால் அது முனையத்தில் நேரடியாக இயங்கும்; பிடித்தத்தை நீக்கவும் என்பதைத் தட்டி, நீக்க ஒன்றைத் தேர்ந்தெடுக்கவும் (உறுதிப்படுத்தலுடன்). ஏற்கனவே 3 உள்ளமைக்கப்பட்ட பிடித்தவை உள்ளன: கோப்பைப் பார்க்கவும் (ls -la), இடத்தைச் சரிபார்க்கவும் (df -h) மற்றும் திரையை அழிக்கவும் (clear) — அனைத்தையும் நீக்கலாம். வெற்றுக் கட்டளையைச் சேமிக்கவோ இயக்கவோ முடியாது; அப்படி நடந்தால் Terminal செய்தி மற்றும் குரல் மூலம் உங்களுக்குத் தெரிவிக்கிறது.

பகுப்பாய்வு & தரம்
பயன்பாட்டுப் பயன்பாட்டுச் சுருக்கம் மற்றும் செயலிழப்பு அறிக்கைகளைப் பார்க்க: முதன்மைத் திரையில் டெவலப்பருக்கு நன்கொடை பொத்தானுக்கு அருகில் உள்ள பகுப்பாய்வு & தரம் பொத்தானை அழுத்தவும். இந்தத் திரை பயன்பாடு எத்தனை முறை திறக்கப்பட்டது, எந்தத் திரைகள் அதிகம் திறக்கப்பட்டன, செயலிழப்புகளின் எண்ணிக்கை மற்றும் சுருக்கமான சரிசெய்தல் பரிந்துரையுடன் கூடிய சமீபத்திய செயலிழப்புகளின் பட்டியலைக் காட்டுகிறது. இந்தத் தரவு உங்கள் தொலைபேசியில் மட்டுமே சேமிக்கப்படுகிறது மற்றும் எங்கும் அனுப்பப்படுவதில்லை. அந்தத் தரவு அனைத்தையும் நீக்க உறுதிப்படுத்தல் உரையாடலுடன் கூடிய பகுப்பாய்வுத் தரவை நீக்கவும் பொத்தான் உள்ளது. கடைசித் திரை முதன்மைத் திரை மற்றும் இந்தத் திரைக்கு மட்டுமே பதிவு செய்யப்படுகிறது.

முடிவுரை
Create Aplikasi ஐப் பயன்படுத்தியதற்கு நன்றி. இந்தக் கருவி தொலைபேசியிலிருந்து Android பயன்பாடுகளை உருவாக்கக் கற்றுக்கொள்ள விரும்பும் உங்களுக்கும் அனைவருக்கும் உதவும் என்று நம்புகிறோம். ஏதேனும் சிக்கல் இருந்தால், இந்த வழிகாட்டியிலிருந்து படிப்படியாகச் சரிசெய்து, மீண்டும் முயற்சிக்கத் தயங்காதீர்கள்.
