ยินดีต้อนรับสู่ Create Aplikasi by Al Kautsar
Create Aplikasi คือแอปพลิเคชันสร้างแอป Android ที่ทำงานบนโทรศัพท์โดยตรง โดยไม่ต้องใช้แล็ปท็อป แอปพลิเคชันนี้ช่วยให้ทุกคนสร้างแอป Android ของตัวเองได้ รวมถึงผู้ใช้ที่เพิ่งเรียนรู้การสร้างแอปและผู้ใช้โปรแกรมอ่านหน้าจอ คู่มือการใช้งานแอปพลิเคชันนี้ฉบับสมบูรณ์มีอยู่ในหน้าจอ Tentang Alat (เกี่ยวกับเครื่องมือ) นี้

แอปพลิเคชันนี้คืออะไรและเหมาะกับใคร
Create Aplikasi คือเครื่องมือสร้างแอป Android ที่ทำงานบนโทรศัพท์ แอปพลิเคชันนี้เหมาะสำหรับทุกคนที่ต้องการสร้างแอป Android ของตัวเอง รวมถึงผู้เริ่มต้นและผู้ใช้โปรแกรมอ่านหน้าจอ แอปพลิเคชันนี้มีตัวแก้ไขโค้ด ปุ่ม Jalankan (เรียกใช้) สำหรับทดสอบโครงการ ปุ่ม Bangun (สร้าง) สำหรับสร้าง APK ตลอดจนเมนูสำหรับลงนามและติดตั้ง APK

วัตถุประสงค์ของแอปพลิเคชันนี้
แอปพลิเคชันนี้สร้างขึ้นเพื่อให้ทุกคนสามารถสร้างแอป Android ของตัวเองได้อย่างง่ายดายจากโทรศัพท์โดยตรง รูปลักษณ์ของมันถูกทำให้เรียบง่ายที่สุดเท่าที่จะเป็นไปได้ เพื่อให้ผู้ใช้ใหม่สามารถลองใช้ได้ทันที

วิธีสร้างโครงการใหม่ ทีละขั้นตอน
1. กด Buat Project (สร้างโครงการ) ในเมนูหลัก
2. เลือกประเภทโครงการ: HTML, Situs Web (เว็บไซต์), Java, Kotlin, Compose หรือ Python
3. กรอกชื่อแอปพลิเคชัน ตัวอย่าง: Garuda Decode
4. กรอกชื่อแพ็กเกจ (package name) ตัวอย่าง: com.android.garudadecode ชื่อแพ็กเกจต้องใช้ตัวอักษรพิมพ์เล็กและประกอบด้วยอย่างน้อยสองส่วนที่คั่นด้วยจุด
5. กรอกเวอร์ชันของแอปพลิเคชัน ตัวอย่าง: 1.0 และรหัสเวอร์ชันในรูปตัวเลข ตัวอย่าง: 1 หากเว้นว่างไว้ เวอร์ชันจะถูกกรอกโดยอัตโนมัติเป็น 1.0 และรหัสเวอร์ชันเป็น 1
6. กรอก SDK ขั้นต่ำและ SDK เป้าหมายหากจำเป็น หากเว้นว่างไว้ จะใช้ค่าเริ่มต้น SDK ขั้นต่ำคือเวอร์ชัน Android ต่ำสุดที่รองรับ ตัวอย่าง: 21 หมายถึง Android 5.0 SDK เป้าหมายสูงสุดคือ 36 (Android 16)
7. กดปุ่ม Pilih Izin (เลือกสิทธิ์) เพื่อเลือกสิทธิ์ของแอปพลิเคชัน ตัวอย่าง: INTERNET สิทธิ์ INTERNET ถูกทำเครื่องหมายไว้แล้วตามค่าเริ่มต้น ทำเครื่องหมายเฉพาะสิทธิ์ที่แอปพลิเคชันต้องการจริง ๆ เท่านั้น
8. หากต้องการ ให้ทำเครื่องหมาย "Gunakan arsitektur terpisah 64 bit dan 32 bit" (ใช้สถาปัตยกรรมแยก 64 บิตและ 32 บิต) เพื่อให้ขนาด APK เล็กลง และทำเครื่องหมาย "Gunakan tanda tangan pribadi" (ใช้ลายเซ็นส่วนตัว) หากต้องการใช้ keystore ที่สร้างเอง
9. กด Buat Proyek (สร้างโครงการ) โครงการใหม่จะถูกบันทึกในโฟลเดอร์ Download/project และปรากฏใน Kelola Project (จัดการโครงการ) ทันที

ประเภทโครงการที่มีให้ใช้
• HTML: รูปลักษณ์จาก index.html, style.css และ script.js ทำงานผ่าน WebView สร้างบนโทรศัพท์โดยตรง
• Situs Web: เว็บไซต์ที่มีเมนู (Beranda (หน้าแรก), Tentang (เกี่ยวกับ), Kontak (ติดต่อ)) จาก index.html, tentang.html, kontak.html, style.css และ script.js ทำงานผ่าน WebView สร้างบนโทรศัพท์โดยตรง
• Java: สร้างบนโทรศัพท์ MainActivity อยู่ที่ app/src/main/java/<nama-paket>/MainActivity.java รูปลักษณ์มาจาก app/src/main/res/layout/activity_main.xml ข้อความมาจาก app/src/main/res/values/strings.xml และธีมมาจาก app/src/main/res/values/styles.xml
• Kotlin: สามารถสร้างบนอุปกรณ์ (ออฟไลน์) โดยใช้คอมไพเลอร์ Kotlin ที่มาพร้อมกับแอปพลิเคชัน หรือผ่าน GitHub Actions MainActivity อยู่ที่ app/src/main/java/<nama-paket>/MainActivity.kt และไฟล์ res เหมือนกับโครงการ Java การสร้าง Kotlin ครั้งแรกจะช้ากว่าเนื่องจากขนาดคอมไพเลอร์ที่ใหญ่ และไฟล์ .java ที่อ้างอิงคลาส Kotlin ยังไม่สามารถสร้างได้ (ไฟล์ .java จะถูกคอมไพล์ก่อนไฟล์ .kt)
• Compose: แอป Android สมัยใหม่ที่อินเทอร์เฟซสร้างด้วย Jetpack Compose (ไม่ใช่เลย์เอาต์ XML) MainActivity อยู่ที่ app/src/main/java/<nama-paket>/MainActivity.kt โครงการ Compose จะถูกสร้างผ่าน GitHub Actions (เมนู Bangun ของโครงการ จากนั้น Bangun online (สร้างออนไลน์)) หรือใน Termux ด้วย Gradle เนื่องจาก Compose ต้องการไลบรารี Jetpack Compose ที่ไม่มีในอุปกรณ์
• Python: ตรรกะของแอปพลิเคชันเขียนด้วยภาษา Python (Chaquopy) ใน app/src/main/python/main.py และถูกเรียกใช้โดยโฮสต์ MainActivity.java ใน app/src/main/java/<nama-paket>/MainActivity.java โครงการ Python สามารถสร้างบนโทรศัพท์โดยตรงได้ (รันไทม์ Chaquopy มาพร้อมกับแอปพลิเคชัน) และผ่าน GitHub Actions ด้วย SDK ขั้นต่ำของโครงการ Python คือ 24 (Android 7.0)

โครงสร้างไฟล์ของโครงการ Java, HTML, Situs Web, Kotlin, Compose และ Python
โครงการ Java, HTML, Situs Web, Kotlin, Compose และ Python ถูกจัดเรียงเหมือนโครงการ Android ทั่วไป ภายในโฟลเดอร์ app มีโฟลเดอร์ src และภายในนั้นมีโฟลเดอร์ main ภายในโฟลเดอร์ main มี AndroidManifest.xml อยู่ข้างโฟลเดอร์ java โฟลเดอร์ res ที่มี layout/activity_main.xml และ values/strings.xml ตลอดจน values/styles.xml และสำหรับ HTML และ Situs Web มีโฟลเดอร์ assets ที่มี index.html (Situs Web มี tentang.html และ kontak.html ด้วย) โครงการ HTML และ Situs Web ก็มี MainActivity ของตัวเองใน app/src/main/java/<nama-paket>/MainActivity.java ซึ่งโหลด index.html ใน WebView และเป็นตัวเรียกใช้งานใน AndroidManifest โครงการ Python มีโค้ด Python ใน app/src/main/python/main.py และโฮสต์ MainActivity.java ใน app/src/main/java/<nama-paket>/MainActivity.java AndroidManifest.xml, layout, strings และ styles สามารถเปิดและแก้ไขในตัวแก้ไขได้เช่นเดียวกับ MainActivity โครงการเก่าที่ยังมี manifest อยู่ข้างโฟลเดอร์ app ก็ยังสามารถสร้างได้ เพราะเมื่อสร้าง แอปพลิเคชันจะตรวจสอบ AndroidManifest.xml ใน app/src/main/ ก่อน จากนั้นที่อยู่ข้างโฟลเดอร์ app และสุดท้ายคือไฟล์ข้อมูลโครงการ

กฎเรื่องสิทธิ์ (สำคัญ)
สิทธิ์ที่ทำเครื่องหมายเมื่อสร้างโครงการจะถูกบันทึกไว้เพียงที่เดียวตามประเภทโครงการ สำหรับโครงการ Java, HTML, Situs Web, Kotlin, Compose และ Python สิทธิ์ที่ทำเครื่องหมายจะถูกบันทึกไว้เฉพาะใน AndroidManifest.xml ที่อยู่ใน app/src/main/ ข้างโฟลเดอร์ java ภายในโฟลเดอร์โครงการเท่านั้น ไฟล์ข้อมูลโครงการสำหรับโครงการ Java, HTML, Situs Web, Kotlin, Compose และ Python ไม่มีรายการสิทธิ์ หากเลือก Java แล้วทำเครื่องหมาย INTERNET และ CAMERA สิ่งที่บันทึกใน AndroidManifest.xml จะมีเพียง INTERNET และ CAMERA เท่านั้น โดยไม่มีสิทธิ์อื่นร่วมด้วย เมื่อสร้าง แอปพลิเคชันจะอ่านสิทธิ์จากที่เดียวกัน: จาก AndroidManifest.xml ใน app/src/main/ สำหรับโครงการ Java, HTML, Situs Web, Kotlin, Compose และ Python (หากไม่มี จาก AndroidManifest.xml ที่อยู่ข้างโฟลเดอร์ app สำหรับโครงการเก่า) และจากไฟล์ข้อมูลโครงการสำหรับโครงการเก่า

วิธีใช้ตัวแก้ไข
เปิด Kelola Project แตะชื่อโครงการเพื่อเปิดตัวแก้ไข ในตัวแก้ไข สามารถเปิดไฟล์ เขียนโค้ด และบันทึกการเปลี่ยนแปลงได้ สำหรับโครงการ Java, HTML, Situs Web, Kotlin, Compose และ Python ไฟล์จะถูกจัดเรียงอยู่ภายในโฟลเดอร์ app/src/main หากต้องการแชร์โครงการ ให้ใช้ Ekspor ZIP (ส่งออก ZIP) (ดูส่วนด้านล่าง)

วิธีเรียกใช้โครงการ
ในตัวแก้ไข กด Jalankan เพื่อทดสอบโครงการ สำหรับโครงการ HTML และ Situs Web สิ่งที่เรียกใช้คือ index.html ผ่าน WebView หากเกิดข้อผิดพลาด ให้อ่านข้อความแสดงข้อผิดพลาด แก้ไขโค้ด แล้วเรียกใช้อีกครั้ง

วิธีสร้าง APK
ในตัวแก้ไข กด Bangun มีวิธีสร้างสองวิธี วิธีแรก Bangun di perangkat (สร้างบนอุปกรณ์): สร้างบนโทรศัพท์โดยตรงโดยไม่ใช้อินเทอร์เน็ต สำหรับโครงการ HTML, Situs Web, Java, Kotlin และ Python วิธีที่สอง Bangun online ผ่าน GitHub Actions: สร้างผ่านอินเทอร์เน็ตบน GitHub และสามารถใช้ได้กับโครงการทุกประเภท โครงการ Compose สามารถสร้างได้เฉพาะด้วยวิธีที่สอง (Bangun online) หรือใน Termux ด้วย Gradle เนื่องจาก Compose ต้องการไลบรารี Jetpack Compose ที่ไม่มีในอุปกรณ์ ผลการสร้างครั้งแรกยังไม่ได้ลงนาม หลังจากนั้นแอปพลิเคชันจะลงนามให้: โดยอัตโนมัติด้วยคีย์เริ่มต้น หรือด้วยลายเซ็นส่วนตัวหากช่อง "Gunakan tanda tangan pribadi" ถูกทำเครื่องหมายไว้เมื่อสร้างโครงการ

วิธีติดตั้ง APK
เมื่อ APK พร้อมแล้ว กด Pasang (ติดตั้ง) เพื่อติดตั้ง บน Android 8 ขึ้นไป โทรศัพท์จะขอ "Izinkan dari sumber ini" (อนุญาตจากแหล่งนี้) ก่อน เนื่องจากแอปพลิเคชันนี้ติดตั้ง APK จากภายนอก Play Store เปิดใช้งานสิทธิ์นั้นหนึ่งครั้งใน Pengaturan (การตั้งค่า) แล้วกลับมาที่แอปพลิเคชัน: การติดตั้งจะดำเนินต่อไปโดยอัตโนมัติโดยไม่ต้องกด Pasang อีก หากปุ่ม Pasang ไม่ปรากฏ ให้แน่ใจว่าการสร้างเสร็จสิ้นและ APK ถูกสร้างแล้ว

วิธีลงนามแอปพลิเคชัน
APK ทุกตัวต้องถูกลงนามจึงจะติดตั้งได้ มีสองตัวเลือก ตัวเลือกแรก คีย์เริ่มต้น: แอปพลิเคชันลงนามเองโดยอัตโนมัติ โดยที่คุณไม่ต้องทำอะไรเลย ตัวเลือกที่สอง ลายเซ็นส่วนตัว: สร้าง keystore ก่อนผ่านเมนู Buat Keystore (สร้าง keystore) ในเมนูหลัก เก็บรหัสผ่านของมันไว้ให้ดี จากนั้นทำเครื่องหมาย "Gunakan tanda tangan pribadi" เมื่อสร้างโครงการ Keystore จะถูกเก็บไว้ใน Download/project/signing

การส่งออกโครงการเป็น ZIP
Ekspor ZIP มีไว้เพื่อให้สามารถแชร์โครงการกับเพื่อนได้ วิธีทำ: ใน Kelola Project กดชื่อโครงการค้างไว้ จากนั้นเลือก Ekspor ZIP ผลลัพธ์จะถูกบันทึกใน Download/project/<NamaProyek>.zip โฟลเดอร์ bin จะไม่ถูกรวมอยู่ด้วย ดังนั้นขนาดจึงเล็ก เพียงไม่กี่สิบ KB ไฟล์ ZIP นั้นสามารถส่งให้เพื่อนหรืออัปโหลดไปยัง GitHub ได้

Ekstensi JAWS
Ekstensi JAWS ใช้เครื่องยนต์ส่วนขยายของ Jieshuo (CSR) ไม่ใช่โปรแกรมอ่านหน้าจอของมัน ด้วยเหตุนี้ การออกแบบจึงยังสามารถทำงานได้แม้ว่าผู้ใช้จะใช้ TalkBack วิธีทำ: เปิด Ekstensi JAWS ในเมนูหลัก เนื่องจากการคลิกอัตโนมัติทำงานด้วยตัวเอง บริการจึงต้องเปิดใช้งานก่อนใน Pengaturan Aksesibilitas (การตั้งค่าการเข้าถึง) หลังจากนั้นจึงสามารถสร้างการออกแบบใหม่ได้: พิมพ์ชื่อการออกแบบ กด OK แล้วกรอกช่องของมัน

Daftar Klik แยกไว้เพื่อให้เรียบร้อย
ภายในหนึ่งการออกแบบมีสองช่อง: ช่องสคริปต์และช่อง Daftar Klik (รายการคลิก) รายการปุ่มจะถูกบันทึกแยกไว้ในไฟล์ daftar_klik.txt หนึ่งชื่อต่อหนึ่งบรรทัด ตัวอย่างเนื้อหา: tombolSimpan, tombolHapus, tombolBuka หากต้องการเปิดแอปพลิเคชัน ให้เขียนเพียง >WhatsApp ในรายการนั้น การออกแบบเก่าที่ยังไม่มีไฟล์ daftar_klik.txt จะแสดงตัวอย่างเริ่มต้นนั้น

ฟังก์ชันง่าย ๆ ที่จัดเตรียมไว้
• klikTombol("tombolSimpan") — คลิกปุ่มหนึ่งปุ่มตามข้อความของมัน
• klikDaftarTombol(daftar) — คลิกรายการใน daftar_klik.txt หนึ่งปุ่มต่อหนึ่งบรรทัด ตามลำดับ จากนั้นบอกว่าสำเร็จกี่รายการและหาไม่พบกี่รายการ
• bukaAplikasi("WhatsApp") — เปิดแอปพลิเคชันตามชื่อของมัน หรือเขียน ">WhatsApp" ในรายการ
• klik(540, 1200) — คลิกที่พิกัดหน้าจอ
ฟังก์ชันทั้งหมดถูกทำให้เรียบง่ายก่อน เมื่อคุ้นเคยแล้ว สามารถเพิ่มฟังก์ชันเพิ่มเติมได้ในภายหลัง

เกี่ยวกับโปรแกรมอ่านหน้าจอ
แอปพลิเคชันนี้ออกแบบมาให้เป็นมิตรกับโปรแกรมอ่านหน้าจอ ช่องกรอกทุกช่องมีป้ายกำกับและตัวอย่างการกรอก และปุ่มทุกปุ่มสามารถเข้าถึงได้โดยไม่ต้องใช้ท่าทางที่ซับซ้อน Ekstensi JAWS ถูกสร้างให้ยังคงทำงานได้แม้ว่าผู้ใช้จะใช้ TalkBack เนื่องจากสิ่งที่ใช้คือเครื่องยนต์ส่วนขยายของมัน ไม่ใช่โปรแกรมอ่านหน้าจอของมัน

ความเป็นส่วนตัวและความปลอดภัย
โครงการและ keystore จะถูกเก็บบนโทรศัพท์ของคุณ โทเค็น GitHub ใช้สำหรับการสร้างออนไลน์เท่านั้นและถูกเก็บไว้ภายในแอปพลิเคชันนี้ อย่าแชร์โทเค็นหรือรหัสผ่าน keystore ของคุณกับใคร หากใช้ลายเซ็นส่วนตัว ให้เก็บ keystore และรหัสผ่านของมันไว้ในที่ปลอดภัย เพราะหากสูญหาย APK เก่าจะไม่สามารถอัปเดตด้วยลายเซ็นเดียวกันได้

ข้อกำหนด
Android 5.0 หรือใหม่กว่า สิทธิ์พื้นที่จัดเก็บ: บน Android 11 ขึ้นไปใช้สิทธิ์เข้าถึงไฟล์ทั้งหมด บน Android 10 ลงไปใช้สิทธิ์พื้นที่จัดเก็บปกติ (อ่าน/เขียนพื้นที่จัดเก็บ) เนื่องจาก Android 10 ไม่มีสิทธิ์เข้าถึงไฟล์ทั้งหมด การสร้างบนอุปกรณ์ต้องใช้โทรศัพท์ที่มีโปรเซสเซอร์ ARM (32 หรือ 64 บิต) การสร้างออนไลน์ผ่าน GitHub Actions ต้องใช้อินเทอร์เน็ตและโทเค็น GitHub โครงการ Kotlin สามารถสร้างบนอุปกรณ์ได้ แต่การสร้างครั้งแรกจะช้ากว่าและใช้หน่วยความจำมากกว่าเนื่องจากขนาดคอมไพเลอร์ Kotlin ที่ใหญ่ โครงการ Compose จะถูกสร้างผ่าน GitHub Actions หรือใน Termux ด้วย Gradle โครงการ Python ต้องใช้ Android 7.0 หรือใหม่กว่า (SDK ขั้นต่ำ 24) และ APK ที่ได้จะมีขนาดใหญ่กว่าเนื่องจากรวมรันไทม์ Python (Chaquopy) พร้อมไลบรารีมาตรฐานของมัน

Terminal
เมนู Terminal บนหน้าจอหลักเปิดเทอร์มินัลภายในแอปพลิเคชันนี้ คำสั่งเช่น ls สามารถใช้ดูเนื้อหาของโฟลเดอร์โครงการ cd สำหรับย้ายโฟลเดอร์ และ git สำหรับจัดการโค้ด ผลลัพธ์ของคำสั่งจะแสดงเป็นข้อความที่โปรแกรมอ่านหน้าจออ่านได้ และมีปุ่ม Bacakan hasil (อ่านผลลัพธ์) สำหรับฟังผลลัพธ์ล่าสุด เทอร์มินัลนี้ใช้เชลล์ระบบของโทรศัพท์ ดังนั้นโปรแกรมแบบโต้ตอบเช่น nano และ vim ยังไม่สามารถใช้ที่นี่ได้

Lisensi (เวอร์ชันที่ต้องชำระเงิน)
หากต้องการขายแอปพลิเคชัน ให้ทำเครื่องหมาย "Aktifkan Lisensi" (เปิดใช้ใบอนุญาต) เมื่อสร้างโครงการ จากนั้นกรอกหมายเลข WhatsApp ของคุณ แอปพลิเคชันที่สร้างได้จะขอรหัสใบอนุญาตเมื่อเปิดครั้งแรก: ผู้ใช้เห็น ID อุปกรณ์ของตน กดปุ่ม Kirim ID Perangkat (ส่ง ID อุปกรณ์) เพื่อส่ง ID นั้นไปยัง WhatsApp ของคุณ จากนั้นคุณตอบกลับด้วยรหัสใบอนุญาต รหัสใบอนุญาตคำนวณจาก ID อุปกรณ์และรหัสผ่านโครงการ (lisensi_seed ในไฟล์ข้อมูลโครงการ) — เก็บรหัสผ่านนั้นไว้ให้ดีและอย่าแชร์ หลังจากกรอกรหัสที่ถูกต้อง แอปพลิเคชันจะเปิดและไม่ขอรหัสอีก

Pembuat Ikon Otomatis
ไอคอนของโครงการใหม่ยังโปร่งใสอยู่ ดังนั้นจึงมี Pembuat Ikon (ตัวสร้างไอคอน) ในเมนูหลัก วิธีทำ: กด Pembuat Ikon เขียนตัวอักษรหนึ่งหรือสองตัว (เช่น อักษรย่อของชื่อแอปพลิเคชัน) เลือกสีพื้นหลังและสีตัวอักษร ดูตัวอย่างของมัน จากนั้นกด Simpan ke Proyek (บันทึกไปยังโครงการ) เพื่อใช้ไอคอนนั้นในโครงการที่เลือก หรือ Simpan ke Download (บันทึกไปยัง Download) เพื่อใช้ไฟล์ PNG ของมันที่อื่น หลังจากโครงการถูกสร้างแล้ว แอปพลิเคชันยังเสนอให้สร้างไอคอนด้วย ไอคอนเก่าของโครงการสามารถเปลี่ยนได้ทุกเมื่อจากเมนูโครงการใน Kelola Project (กดชื่อโครงการค้างไว้ จากนั้นเลือก Ganti Ikon (เปลี่ยนไอคอน))

Template Proyek Siap Pakai
หากไม่ต้องการเริ่มจากโครงการเปล่า ให้เลือกเทมเพลตเมื่อสร้างโครงการ: Kalkulator (Java), Catatan (Java), Daftar Tugas (Kotlin), Kalkulator Web (HTML), Situs Profil (Situs Web) หรือ Penghitung (Compose) การเลือกเทมเพลตจะเปลี่ยนประเภทโครงการให้ตามเทมเพลตนั้นโดยอัตโนมัติ และโครงการจะถูกสร้างด้วยโค้ดเริ่มต้นที่พร้อมอยู่แล้ว — เพียงเรียกใช้หรือแก้ไข หากประเภทโครงการถูกเปลี่ยนด้วยตนเองอีกครั้งหลังจากเลือกเทมเพลต เทมเพลตจะถูกยกเลิกและโครงการจะกลับไปว่างเปล่า สำหรับเทมเพลต HTML และ Situs Web เทมเพลตจะแทนที่เนื้อหาของ index.html รวมถึงสคริปต์ HTML ที่พิมพ์ในแบบฟอร์ม

Cadangan dan Pulihkan Proyek
เพื่อให้โครงการไม่สูญหาย จึงมีคุณสมบัติการสำรองข้อมูล วิธีทำ: ใน Kelola Project กดชื่อโครงการค้างไว้ จากนั้นเลือก Cadangkan (สำรองข้อมูล) ข้อมูลสำรองจะถูกบันทึกเป็น ZIP ในโฟลเดอร์ Download/backup พร้อมชื่อโครงการและวันที่ ตัวอย่าง: GarudaDecode-2026-11-14-123045.zip เนื้อหาของมันเหมือนกับ Ekspor ZIP (เนื้อหาโครงการทั้งหมด โดยไม่มีโฟลเดอร์ bin) หากต้องการกู้คืน: เปิดเมนูใน Kelola Project เลือก Pulihkan cadangan (กู้คืนข้อมูลสำรอง) จากนั้นเลือกไฟล์สำรองของมัน หากชื่อโครงการมีอยู่แล้ว แอปพลิเคชันจะถามว่า: Timpa proyek lama (เขียนทับโครงการเก่า) หรือบันทึกด้วย Nama baru (ชื่อใหม่)

Bagikan dan Impor Proyek
หากต้องการแชร์โครงการกับเพื่อน: ใน Kelola Project กดชื่อโครงการค้างไว้ จากนั้นเลือก Bagikan (แชร์) โครงการจะถูกส่งเป็น ZIP ผ่านแอปแชร์ (WhatsApp, Telegram และอื่น ๆ) หากต้องการรับโครงการจากเพื่อน: เปิดเมนูใน Kelola Project เลือก Impor proyek (นำเข้าโครงการ) จากนั้นเลือกไฟล์ ZIP ของมัน ไฟล์ ZIP นั้นต้องมีไฟล์ข้อมูลโครงการ — หากไม่มี ไฟล์จะถูกปฏิเสธพร้อมข้อความที่ชัดเจน เนื่องจากไฟล์นั้นไม่ใช่โครงการ Create Aplikasi หากชื่อโครงการมีอยู่แล้ว แอปพลิเคชันจะถามว่า: Timpa proyek lama หรือบันทึกด้วย Nama baru

Pencarian dan Filter Proyek
หากโครงการมีจำนวนมาก ใน Kelola Project จะมีช่องค้นหาและตัวกรองประเภท พิมพ์ชื่อโครงการในช่องค้นหา รายการจะถูกกรองทันที (ตัวพิมพ์ใหญ่และตัวพิมพ์เล็กไม่ถูกแยกแยะ) ตัวกรองประเภทจำกัดรายการให้เหลือเพียงประเภทเดียว: Semua (ทั้งหมด), HTML, Situs Web, Java, Kotlin, Compose หรือ Python เมนูของแต่ละโครงการยังสามารถเปิดได้ตามปกติจากรายการที่กรองแล้ว
