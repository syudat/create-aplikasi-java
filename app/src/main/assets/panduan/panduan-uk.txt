Ласкаво просимо до Create Aplikasi by Al Kautsar
Create Aplikasi — це застосунок для створення застосунків Android, який працює безпосередньо на телефоні, без потреби в ноутбуці. Цей застосунок дозволяє будь-кому створювати власні застосунки Android, зокрема користувачам, які тільки вчаться створювати застосунки, та користувачам програм читання з екрана. Повний посібник із користування цим застосунком доступний на цьому екрані Tentang Alat (Про інструмент).

Що це за застосунок і для кого він
Create Aplikasi — це інструмент для створення застосунків Android, який працює на телефоні. Цей застосунок призначений для всіх, хто хоче створювати власні застосунки Android, зокрема для початківців і користувачів програм читання з екрана. Цей застосунок надає редактор коду, кнопку Jalankan (Запустити) для тестування проєкту, кнопку Bangun (Зібрати) для створення APK, а також меню для підписування та встановлення APK.

Мета цього застосунку
Цей застосунок створено для того, щоб будь-хто міг легко створювати власні застосунки Android безпосередньо з телефона. Його вигляд зроблено якомога простішим, щоб навіть нові користувачі могли одразу спробувати.

Як створити новий проєкт, крок за кроком
1. Натисніть Buat Project (Створити проєкт) у головному меню.
2. Виберіть тип проєкту: HTML, Situs Web (Вебсайт), Java, Kotlin, Compose або Python.
3. Заповніть назву застосунку, наприклад: Garuda Decode.
4. Заповніть назву пакета (package name), наприклад: com.android.garudadecode. Назва пакета має використовувати малі літери та складатися щонайменше з двох частин, розділених крапкою.
5. Заповніть версію застосунку, наприклад: 1.0, і код версії у вигляді числа, наприклад: 1. Якщо залишити порожнім, версію буде автоматично заповнено як 1.0, а код версії — як 1.
6. За потреби заповніть мінімальний SDK і цільовий SDK. Якщо залишити порожнім, буде використано значення за замовчуванням. Мінімальний SDK — це найнижча підтримувана версія Android, наприклад: 21 означає Android 5.0. Максимальний цільовий SDK — 36 (Android 16).
7. Натисніть кнопку Pilih Izin (Вибрати дозволи), щоб вибрати дозволи застосунку, наприклад: INTERNET. Дозвіл INTERNET уже позначено за замовчуванням. Позначайте лише ті дозволи, які справді потрібні застосунку.
8. За бажання позначте "Gunakan arsitektur terpisah 64 bit dan 32 bit" (Використовувати окремі архітектури 64 біт і 32 біт), щоб розмір APK був меншим, і позначте "Gunakan tanda tangan pribadi" (Використовувати особистий підпис), якщо хочете використовувати власноруч створене keystore.
9. Натисніть Buat Proyek (Створити проєкт). Новий проєкт зберігається в папці Download/project і одразу з'являється в Kelola Project (Керування проєктами).

Доступні типи проєктів
• HTML: вигляд із index.html, style.css і script.js, працює через WebView. Збирається безпосередньо на телефоні.
• Situs Web: вебсайт із меню (Beranda (Головна), Tentang (Про нас), Kontak (Контакти)) з index.html, tentang.html, kontak.html, style.css і script.js, працює через WebView. Збирається безпосередньо на телефоні.
• Java: збирається на телефоні. MainActivity знаходиться в app/src/main/java/<nama-paket>/MainActivity.java. Вигляд походить із app/src/main/res/layout/activity_main.xml, текст — із app/src/main/res/values/strings.xml, а тема — із app/src/main/res/values/styles.xml.
• Kotlin: може збиратися на пристрої (офлайн) за допомогою компілятора Kotlin, що входить до застосунку, або через GitHub Actions. MainActivity знаходиться в app/src/main/java/<nama-paket>/MainActivity.kt, а файли res такі самі, як у проєкті Java. Перше збирання Kotlin повільніше через великий розмір компілятора, а файли .java, які посилаються на класи Kotlin, ще не можуть бути зібрані (файли .java компілюються перед файлами .kt).
• Compose: сучасний застосунок Android, інтерфейс якого створено за допомогою Jetpack Compose (а не макетів XML). MainActivity знаходиться в app/src/main/java/<nama-paket>/MainActivity.kt. Проєкти Compose збираються через GitHub Actions (меню Bangun проєкту, потім Bangun online (Зібрати онлайн)) або в Termux із Gradle, оскільки Compose потребує бібліотек Jetpack Compose, яких немає на пристрої.
• Python: логіка застосунку написана мовою Python (Chaquopy) в app/src/main/python/main.py і запускається хостом MainActivity.java в app/src/main/java/<nama-paket>/MainActivity.java. Проєкти Python можуть збиратися безпосередньо на телефоні (середовище виконання Chaquopy входить до застосунку), а також через GitHub Actions. Мінімальний SDK проєктів Python — 24 (Android 7.0).

Структура файлів проєктів Java, HTML, Situs Web, Kotlin, Compose і Python
Проєкти Java, HTML, Situs Web, Kotlin, Compose і Python влаштовані так, як загалом проєкти Android. Усередині папки app є папка src, а в ній папка main. Усередині папки main знаходиться AndroidManifest.xml поруч із папкою java, папка res, що містить layout/activity_main.xml і values/strings.xml, а також values/styles.xml, а для HTML і Situs Web — папка assets, що містить index.html (Situs Web також має tentang.html і kontak.html). Проєкти HTML і Situs Web також мають власний MainActivity у app/src/main/java/<nama-paket>/MainActivity.java, який завантажує index.html у WebView і стає лаунчером у AndroidManifest. Проєкти Python мають код Python у app/src/main/python/main.py і хост MainActivity.java у app/src/main/java/<nama-paket>/MainActivity.java. AndroidManifest.xml, layout, strings і styles можна відкривати й змінювати в редакторі, так само як MainActivity. Старі проєкти, чий маніфест досі знаходиться поруч із папкою app, також можна зібрати, оскільки під час збирання застосунок спочатку перевіряє AndroidManifest.xml у app/src/main/, потім той, що поруч із папкою app, і нарешті файл даних проєкту.

Правила дозволів (важливо)
Дозволи, позначені під час створення проєкту, записуються лише в одному місці, залежно від типу проєкту. Для проєктів Java, HTML, Situs Web, Kotlin, Compose і Python позначені дозволи записуються ТІЛЬКИ в AndroidManifest.xml, що знаходиться в app/src/main/, поруч із папкою java, усередині папки проєкту. Файл даних проєкту для проєктів Java, HTML, Situs Web, Kotlin, Compose і Python не містить списку дозволів. Якщо ви виберете Java й позначите INTERNET та CAMERA, то в AndroidManifest.xml буде записано лише INTERNET і CAMERA, без жодних інших дозволів. Під час збирання застосунок читає дозволи з того самого місця: з AndroidManifest.xml у app/src/main/ для проєктів Java, HTML, Situs Web, Kotlin, Compose і Python (якщо його немає — з AndroidManifest.xml поруч із папкою app для старих проєктів) і з файлу даних проєкту для старих проєктів.

Як користуватися редактором
Відкрийте Kelola Project, торкніться назви проєкту, щоб відкрити редактор. У редакторі можна відкривати файли, писати код і зберігати зміни. Для проєктів Java, HTML, Situs Web, Kotlin, Compose і Python файли влаштовані всередині папки app/src/main. Щоб поділитися проєктом, скористайтеся Ekspor ZIP (Експорт ZIP) (див. розділ нижче).

Як запустити проєкт
У редакторі натисніть Jalankan, щоб протестувати проєкт. Для проєктів HTML і Situs Web запускається index.html через WebView. Якщо станеться помилка, прочитайте повідомлення про помилку, виправте код, а потім запустіть знову.

Як зібрати APK
У редакторі натисніть Bangun. Є два способи збирання. Перший, Bangun di perangkat (Зібрати на пристрої): збирає безпосередньо на телефоні без інтернету, для проєктів HTML, Situs Web, Java, Kotlin і Python. Другий, Bangun online через GitHub Actions: збирає через інтернет на GitHub і може використовуватися для всіх типів проєктів. Проєкти Compose можна зібрати лише другим способом (Bangun online) або в Termux із Gradle, оскільки Compose потребує бібліотек Jetpack Compose, яких немає на пристрої. Результат першого збирання ще не підписано. Після цього застосунок його підписує: автоматично ключем за замовчуванням або особистим підписом, якщо поле "Gunakan tanda tangan pribadi" було позначено під час створення проєкту.

Як встановити APK
Коли APK готовий, натисніть Pasang (Встановити), щоб його встановити. В Android 8 і новіших версіях телефон спочатку запитає "Izinkan dari sumber ini" (Дозволити з цього джерела), оскільки цей застосунок встановлює APK ззовні Play Store. Увімкніть цей дозвіл один раз у Pengaturan (Налаштування), а потім поверніться до застосунку: встановлення продовжиться автоматично, без потреби знову натискати Pasang. Якщо кнопка Pasang не з'являється, переконайтеся, що збирання завершено й APK створено.

Як підписати застосунок
Кожен APK має бути підписаний, щоб його можна було встановити. Доступні два варіанти. Перший, ключ за замовчуванням: застосунок підписує сам автоматично, вам нічого не потрібно робити. Другий, особистий підпис: спочатку створіть keystore через меню Buat Keystore (Створити keystore) у головному меню, добре збережіть його пароль, а потім позначте "Gunakan tanda tangan pribadi" під час створення проєкту. Keystore зберігається в Download/project/signing.

Експорт проєкту в ZIP
Ekspor ZIP надається для того, щоб проєктом можна було поділитися з друзями. Ось як: у Kelola Project довго натисніть назву проєкту, а потім виберіть Ekspor ZIP. Результат зберігається в Download/project/<NamaProyek>.zip. Папка bin не входить, тому розмір невеликий, лише кілька десятків КБ. Цей файл ZIP можна надіслати другові або завантажити на GitHub.

Ekstensi JAWS
Ekstensi JAWS використовує механізм розширень Jieshuo (CSR), а не його програму читання з екрана. Завдяки цьому конструкція може продовжувати працювати, навіть якщо користувач використовує TalkBack. Ось як: відкрийте Ekstensi JAWS у головному меню. Оскільки автоматичне клацання працює саме по собі, службу потрібно спочатку ввімкнути в Pengaturan Aksesibilitas (Налаштування доступності). Після цього можна створити нову конструкцію: введіть назву конструкції, натисніть OK, а потім заповніть її поля.

Daftar Klik відокремлено для порядку
Усередині конструкції є два поля: поле скрипту і поле Daftar Klik (Список клацань). Список кнопок зберігається окремо у файлі daftar_klik.txt, по одній назві на рядок. Приклад вмісту: tombolSimpan, tombolHapus, tombolBuka. Щоб відкрити застосунок, просто напишіть >WhatsApp у цьому списку. Старі конструкції, які ще не мають файлу daftar_klik.txt, показуватимуть цей приклад за замовчуванням.

Прості функції, що надаються
• klikTombol("tombolSimpan") — клацає одну кнопку за її текстом.
• klikDaftarTombol(daftar) — клацає список у daftar_klik.txt, по одній кнопці на рядок, по порядку, а потім повідомляє, скільки вдалих і скільки не знайдених.
• bukaAplikasi("WhatsApp") — відкриває застосунок за його назвою, або напишіть ">WhatsApp" у списку.
• klik(540, 1200) — клацає за координатами екрана.
Усі функції спочатку зроблено простими. Коли звикнете, згодом можна додати додаткові функції.

Про програму читання з екрана
Цей застосунок розроблено дружнім до програм читання з екрана. Кожне поле для заповнення має підпис і приклад заповнення, а всі кнопки можна досягти без складних жестів. Ekstensi JAWS зроблено так, щоб воно продовжувало працювати, навіть якщо користувач використовує TalkBack, оскільки використовується його механізм розширень, а не його програма читання з екрана.

Конфіденційність і безпека
Проєкти та keystore зберігаються на вашому телефоні. Токен GitHub використовується лише для онлайн-збирання й зберігається всередині цього застосунку. Нікому не повідомляйте свій токен або пароль keystore. Якщо ви використовуєте особистий підпис, зберігайте keystore та його пароль у безпечному місці, оскільки в разі їх втрати старий APK не можна буде оновити тим самим підписом.

Вимоги
Android 5.0 або новіший. Дозвіл на сховище: в Android 11 і новіших використовується дозвіл доступу до всіх файлів, в Android 10 і старіших — звичайний дозвіл на сховище (читання/запис сховища), оскільки Android 10 не має дозволу доступу до всіх файлів. Для збирання на пристрої потрібен телефон із процесором ARM (32 або 64 біт). Для онлайн-збирання через GitHub Actions потрібні інтернет і токен GitHub. Проєкти Kotlin можна збирати на пристрої, але їхнє перше збирання повільніше й використовує більше пам'яті через великий розмір компілятора Kotlin. Проєкти Compose збираються через GitHub Actions або в Termux із Gradle. Проєкти Python потребують Android 7.0 або новіший (мінімальний SDK 24), а підсумковий APK більший, оскільки містить середовище виконання Python (Chaquopy) разом із його стандартною бібліотекою.

Terminal
Меню Terminal на головному екрані відкриває термінал усередині цього застосунку. Команди на кшталт ls можна використовувати для перегляду вмісту папки проєкту, cd — для переходу між папками, а git — для керування кодом. Вивід команд відображається як текст, який програма читання з екрана може прочитати, і є кнопка Bacakan hasil (Прочитати результат), щоб прослухати останній результат. Цей термінал використовує системну оболонку телефона, тому інтерактивні програми, такі як nano та vim, тут ще не можна використовувати.

Lisensi (платна версія)
Щоб продавати застосунок, позначте "Aktifkan Lisensi" (Увімкнути ліцензію) під час створення проєкту, а потім заповніть свій номер WhatsApp. Зібраний застосунок попросить код ліцензії під час першого відкриття: користувач бачить ідентифікатор свого пристрою, натискає кнопку Kirim ID Perangkat (Надіслати ідентифікатор пристрою), щоб надіслати цей ідентифікатор на ваш WhatsApp, а потім ви відповідаєте кодом ліцензії. Код ліцензії обчислюється з ідентифікатора пристрою та пароля проєкту (lisensi_seed у файлі даних проєкту) — добре зберігайте цей пароль і не повідомляйте його. Після введення правильного коду застосунок відкривається й більше не просить код.

Pembuat Ikon Otomatis
Значок нових проєктів досі прозорий, тому в головному меню доступний Pembuat Ikon (Створювач значків). Ось як: натисніть Pembuat Ikon, напишіть одну або дві літери (наприклад, ініціали назви застосунку), виберіть колір фону та колір тексту, перегляньте його попередній вигляд, а потім натисніть Simpan ke Proyek (Зберегти до проєкту), щоб використати цей значок у вибраному проєкті, або Simpan ke Download (Зберегти до Download), щоб використати його файл PNG деінде. Після створення проєкту застосунок також пропонує створити значок. Старий значок проєкту можна змінити будь-коли з меню проєкту в Kelola Project (довго натисніть назву проєкту, а потім виберіть Ganti Ikon (Змінити значок)).

Template Proyek Siap Pakai
Якщо ви не хочете починати з порожнього проєкту, виберіть шаблон під час створення проєкту: Kalkulator (Java), Catatan (Java), Daftar Tugas (Kotlin), Kalkulator Web (HTML), Situs Profil (Situs Web) або Penghitung (Compose). Вибір шаблону автоматично змінює тип проєкту відповідно до цього шаблону, і проєкт створюється з уже готовим початковим кодом — просто запустіть або змініть його. Якщо тип проєкту знову змінити вручну після вибору шаблону, шаблон скасовується, і проєкт знову стає порожнім. Для шаблонів HTML і Situs Web шаблон замінює вміст index.html, зокрема скрипт HTML, введений у формі.

Cadangan dan Pulihkan Proyek
Щоб проєкти не губилися, доступна функція резервного копіювання. Ось як: у Kelola Project довго натисніть назву проєкту, а потім виберіть Cadangkan (Створити резервну копію). Резервна копія зберігається як ZIP у папці Download/backup із назвою проєкту й датою, наприклад: GarudaDecode-2026-11-14-123045.zip. Її вміст такий самий, як у Ekspor ZIP (увесь вміст проєкту, без папки bin). Щоб відновити: відкрийте меню в Kelola Project, виберіть Pulihkan cadangan (Відновити резервну копію), а потім виберіть її файл резервної копії. Якщо назва проєкту вже існує, застосунок запитає: Timpa proyek lama (Перезаписати старий проєкт) або зберегти з Nama baru (Нова назва).

Bagikan dan Impor Proyek
Щоб поділитися проєктом із другом: у Kelola Project довго натисніть назву проєкту, а потім виберіть Bagikan (Поділитися). Проєкт надсилається як ZIP через застосунки для обміну (WhatsApp, Telegram та інші). Щоб отримати проєкт від друга: відкрийте меню в Kelola Project, виберіть Impor proyek (Імпортувати проєкт), а потім виберіть його файл ZIP. Цей файл ZIP має містити файл даних проєкту — якщо його немає, файл відхиляється з чітким повідомленням, оскільки цей файл не є проєктом Create Aplikasi. Якщо назва проєкту вже існує, застосунок запитає: Timpa proyek lama або зберегти з Nama baru.

Pencarian dan Filter Proyek
Якщо проєктів уже багато, у Kelola Project є поле пошуку та фільтр типів. Введіть назву проєкту в поле пошуку, і список одразу відфільтрується (великі та малі літери не розрізняються). Фільтр типів обмежує список лише одним типом: Semua (Усі), HTML, Situs Web, Java, Kotlin, Compose або Python. Меню кожного проєкту й надалі можна відкрити як зазвичай із відфільтрованого списку.
